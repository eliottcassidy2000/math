# A minimal three-coordinate grammar for rooted one-seam tournaments

The changed question is whether exposing a single old vertex and **moving the mark into the new piece** can return a finite-dimensional physical state. It can. ## 2. State, operation, and graph-level recursive classification

All graphs are finite tournaments. Let `H(T)` count directed Hamiltonian vertex words, with `H(empty)=1`. For a root r put

- `e_r(T)`: Hamiltonian paths ending at r;
- `s_r(T)`: Hamiltonian paths starting at r;
- `R_r(T)`: ordered spanning covers `(P,Q)`, where P may be empty and Q is a nonempty directed path starting at r;
- `L_r(T)`: ordered spanning covers `(P,Q)`, where P is a nonempty directed path ending at r and Q may be empty;
- `P_T(2)`: ordered spanning two-path covers with both path slots allowed to be empty.

The returning state is `x(T,r)=(h,e,R)=(H(T),e_r(T),R_r(T))`.

For nonempty rooted pieces `(A,a)` and `(G,b)`, define `K(A,a;G,b)` by orienting every cross edge from A to G, **except** the single edge `b -> a`. Preserve all internal arcs, and mark the output at b. Thus the new root, not a, is retained for the next operation.

For an integer k at least one, define `C_k` recursively:

1. the rooted singleton is in `C_k`;
2. if `(A,a)` is in `C_k` and `(G,b)` is any rooted tournament with `1<=|G|<=k`, then `(K(A,a;G,b),b)` is in `C_k`.

Equivalently, members admit an ordered block decomposition `G_0,G_1,...,G_t`, where `G_0` is one vertex, later blocks have size at most k, each block has a selected vertex `r_i`, and all cross-block edges point forward **except** `r_i -> r_(i-1)` for `i=1,...,t`. The final mark is `r_t`. Internal blocks are unrestricted tournaments. This is an exact existential graph classification, not a uniqueness assertion about decompositions or graph isomorphisms. To reverse a last step, delete a block containing the final mark, whose only backward cross arc goes to the preceding exposed root.

Every root generated by this grammar reaches every vertex of its graph. Indeed the new b reaches the old a, which reaches every old vertex, and any old vertex reaches every new vertex other than b. No assertion that every rooted tournament with this reachability property belongs to `C_k` is made.

## 3. Complete transfer theorem

For the gadget `(G,b)` abbreviate

    g = H(G),       s = s_b(G),       L = L_b(G),
    E = e_b(G),     Q = R_b(G),       B = P_(G-b)(2),
    delta = 1 if |G|=1, and 0 otherwise.

**Theorem 1 (returning rooted interface).** The actual output graph has

    h' = g h - s e + L R,
    e' = E h - delta e,
    R' = Q h + B R.                                      (1)

Consequently each fixed gadget gives the integer matrix

             [ g   -s       L ]
    M_G,b =  [ E   -delta   0 ],                         (2)
             [ Q    0       B ]

and every finite gadget word returns the same three-coordinate interface. The negative entries are exact forbidden-boundary corrections, not formal negative-count pieces.

**Proof of the Hamilton count.** A Hamiltonian path avoiding `b->a` is an A-path followed by a G-path. The only invalid such concatenations have the first ending at a and the second starting at b. Their count is `s e`, giving `g h-s e`.

A Hamiltonian path using `b->a` has the unique run decomposition

    A_before, G_before, A_after, G_after,

where `A_after` starts at a and `G_before` ends at b. The first A run and final G run may be empty. These are independently an R-cover of A and an L-cover of G. All other cross boundaries are valid because a and b have already been assigned to their designated runs. This gives `L R`.

**Proof of the endpoint count.** A Hamiltonian path ending at b cannot use `b->a`. Thus it is an A-path followed by a G-path ending at b, initially giving `E h` choices. A forbidden A-to-G boundary could occur only if this G-path both starts and ends at b, hence only if G is a singleton. In that case precisely e choices are removed.

**Proof of the root-starting cover count.** In a cover whose second path starts at b, first suppose the seam `b->a` is unused. The second path stays entirely in G. All A vertices form one Hamiltonian path in the first slot, followed by its possibly empty G part. There are exactly `h Q` covers.

If the seam is used, it must be the first edge of the second path. The A portions form an R-cover of A. The vertices of `G-b` form two arbitrary path slots, one following the first A portion and one following the second. This gives `R P_(G-b)(2)=R B`. Empty first slots cause no exception. The two cases are disjoint and exhaustive. QED.

The scalar first row is inherited from the one-arc join law. The endpoint and two-cover rows provide the actual returning state, which scalar realizability alone does not establish.

### A fourth deletion coordinate integrates stationary-root moves

Put `d=H(A-a)` and `d_G=H(G-b)`. Deleting the **new** root b removes the only reversed cross edge and leaves the ordered join `A -> (G-b)`. Therefore

    d' = d_G h.                                         (3)

Thus (1) also lifts to the four-coordinate state `(h,e,R,d)`. In that state it composes with the independently checked stationary-root operations

    K_old: (h,e,R,d) -> (h+R-e, d, 2R-d, d),
    D:     (h,e,R,d) -> (h, 0, 2R, d),                  (4)

where `K_old` adds one vertex beating only the root but retains the old mark, and D adds a universal sink and retains the mark. The combined synthesis is treated separately in the Session 195 prime-growth packet; the exact numerical census in Section 6 below uses **only** (1), not (4).

## 4. Small physical matrices and indefinitely growing strong pieces

Rows below are outgoing-neighbor bitmasks on vertices `0,...,n-1`.

1. Singleton `(G,b)=([0],0)`:

       S(h,e,R) = (h-e+R, h-e, h+R).

2. Transitive edge with b its sink, `([0,1],0)`:

       C(h,e,R) = (h+2R, h, h+2R).

3. Transitive edge with b its source, `([0,1],1)`:

       (h,e,R) -> (h-e+R, 0, 2h+2R).

4. Directed triangle `([4,1,2],0)`:

       J(h,e,R) = (3h-e+3R, h, 3h+4R).

5. The four-vertex gadget `([8,1,3,6],1)`:

       (h,e,R) -> (5h-e+9R, 2h, 6h+12R).

The fifth gadget applied to the singleton produces the rooted H13 graph

    rows = [26,16,3,6,12], root=2, (h,e,R)=(13,2,18).

These formulas are exact all-order identities for arbitrary rooted input A, not fitted recurrences.

**Corollary 2 (unbounded strong class).** Starting at a singleton and repeatedly using the triangle gadget gives strong graphs of order `1+3t` for every `t>=1`, with feedback vertex number at least t. The first returning triples are

    (1,1,1), (5,1,7), (35,5,43), (229,35,277).

**Proof.** The new b reaches all old and new vertices as established in Section 2. Each new gadget vertex reaches b inside its triangle. An old vertex other than a reaches b through the direct forward cross arc, while a reaches a different gadget vertex and then b. Thus the whole graph is strong. Each of the t disjoint gadget blocks contains a directed triangle, so any vertex set whose deletion leaves a transitive tournament must meet every one of them. The state formula is J. QED.

The three-state grammar therefore goes beyond every fixed bound on feedback vertex number. This does not contradict S193's infinite continuation-rank theorem: its contexts cyclically wrap an intact module, whereas the present contexts single out a vertex and replace the mark.

### Three coordinates are necessary for this linear grammar

**Theorem 3 (minimal rational linear dimension).** No two-dimensional rational vector state with fixed linear gadget updates and a linear Hamilton-count output represents all inputs and continuations of `C_2`. The three-coordinate state (1) is therefore minimal under these assumptions.

**Proof.** Use the three physical input states

    x0=(1,1,1),   x1=S x0=(1,0,2),   x2=C x0=(3,1,3),

and the three contexts identity, S, C. Their Hamilton-count matrix is

    [1 1 3]
    [1 3 5]
    [3 5 9],       determinant = -4.

Any two-dimensional linear realization factors this matrix through a vector space of dimension at most two, contradicting its nonzero determinant. The initial-state encoding need not itself be linear. QED.

## 5. Endpoint floors, module splitting, and a sharp rearming limitation

If `|A|>=2`, the new b beats a and loses to every other old vertex. Hence A is not a module in the output. The S194 intact-module obstruction is not being evaded by a formal substitution; its hypothesis is genuinely absent.

The S194 endpoint-floor theorem still applies, because every old graph remains an induced subtournament. Formula (1) is consistent with it. For a non-singleton gadget, `e'=E h`; a positive new endpoint count is at least h. For a singleton gadget, `e'=h-e` sums all old endpoint counts except that at a. If A is nontrivial strong and all old endpoint counts are at least q, then `e'>=2q`. No endpoint-one resurrection is claimed. The grammar works precisely because its interface permits e and R to grow.

There is nevertheless a permanent arithmetic obstruction for some rooted parents.

**Theorem 4 (rooted content obstruction).** Let `c=gcd(h,e,R)`. Every Hamilton count obtained by any finite sequence of operations (1), with arbitrary actual gadget sizes and marks, is divisible by c.

**Proof.** Every transfer matrix has integer entries. Thus every new coordinate remains divisible by c, and induction applies. QED.

A concrete strong hostile is obtained by applying C twice to the singleton:

    rows = [28,17,26,2,8], root=3,
    (h,e,R) = (9,3,9),   d=3.

Every later output from this marked parent has H divisible by three. In particular neither `29=3*9+2` nor `31=3*9+4` can be reached. This remains true for target-dependent gadget choices and unbounded gadget orders. It also persists in the combined four-state grammar (3)-(4), because its entire state is divisible by three and every update is integer-linear.

Therefore this is a **genuine reusable interface but not a universal every-parent ternary rearming mechanism**. A scalar target might still have another primitive rooted presentation, and the obstruction says nothing against constructing 29 or 31 independently. Replacing the graph, changing old arcs, or changing the operation family is outside this obstruction.

## 6. Exact arbitrary-depth spectrum within a fixed gadget bank

Let a finite bank contain actual nonempty rooted gadgets. Begin only from the singleton. Target-bounded membership is decidable without a guessed depth cutoff.

For every physical rooted input and gadget,

    0<=e<=h,   R>=h>=1,
    L>=g>=1,  Q>=g>=1,  0<=s<=g,  B>=1.

The inequalities `R>=h` and `L>=g` follow by splitting every Hamiltonian path just before, respectively after, its root. Equation (1) consequently gives

    h' >= max(h,R),       R' >= h+R > R.                 (5)

For example `g h-s e >= (g-s)h>=0`, hence `h'>=LR>=R`; also `R>=h` makes `h'>=(g-s+L)h>=h`. These conclusions do not assume strict increase of h.

**Theorem 5 (complete finite search).** Fix a positive integer X. Initialize the queue with `(1,1,1)`. For each queued state and each bank gadget, compute (1). Whenever `h'<=X`, record that h' is attained. Queue the new state only when also `R'<=X`, and only if it was not already visited. This process terminates and records **exactly** the Hamilton counts at most X obtainable by arbitrary-length bank words.

**Proof.** Every queued state is physical, so recorded values are genuine. There are at most finitely many triples `1<=h<=R<=X`, `0<=e<=h`; the visited set ensures termination. Conversely, consider any word with final Hamilton count at most X. Hamilton counts never decrease. Every state before its final step has R at most X by the next step's inequality `h'>=R`. Thus every preterminal state is visited inductively, and the final count is recorded even if its final R exceeds X. No valid count is removed. QED.

There are no zero-state-growth loops here: even when h is unchanged, R strictly grows. A stronger quantitative bound follows directly from (5). With `F_1=F_2=1` the Fibonacci sequence, every word of t steps satisfies

    h_t>=F_(t+1),       R_t>=F_(t+2).                  (6)

Indeed the seed satisfies these bounds, and `h'>=R`, `R'>=h+R` give the induction. Thus any successful word with final H at most X has

    t<=max{j>=0: F_(j+1)<=X}=O(log X).

Under a bank of maximum gadget order k, its graph order is at most `1+kt`. For example `F_22=17711` and `F_23=28657` imply at most21 steps and at most106 vertices for any successful order-at-most-five-gadget word with target at most20,000. These are upper bounds, not minimum witness orders. The search itself uses the exact state test rather than a guessed depth limit.

### Complete order-at-most-five bank

The certificate enumerates **every labelled tournament** of orders one through five, and every possible mark. This is

    1+2+8+64+1024 = 1099 graphs,
    1+4+24+256+5120 = 5405 rooted gadgets.

Every gadget is independently counted by both terminal/initial-removal subset DP and literal permutation/cut enumeration. Deduplicating only the seven transfer constants gives **65 distinct matrices**. Every matrix retains a physical representative in `inventory.json`. This is an exhaustive labelled inventory; it does not depend on an isomorphism-generation program.

The complete arbitrary-depth closure under these 65 matrices has the following exact bounded spectrum:

- Through X=1000: 12,711 retained states and 493 attained odd counts. The missing odds are exactly `{7,21,67,163,173,247,511}`.
- Through X=20,000: 1,085,407 retained states and 9,993 attained odd counts. The missing odds are again exactly `{7,21,67,163,173,247,511}`.

Thus every odd integer from 513 through 19,999 belongs to this particular rooted grammar. The table does **not** prove that every larger odd belongs to it. Conversely the seven displayed missing values are excluded from this grammar at **all depths**, not merely up to a tested graph size. The five values other than 7 and 21 are architecture omissions, not new gaps in the tournament spectrum. The combined four-coordinate grammar has additional operations and is intentionally reported separately.

`witnesses.json` supplies literal output adjacency rows, final roots, triples, and full gadget construction words for the selected counts `11,13,41,43,47,127,137,139,299,983`. For example an H43 witness is

    rows=[124,121,74,32,12,20,56], root=2, state=(43,2,66).

The main open task has become more concrete but remains open: characterize the integer state language of this or an enlarged grammar well enough to prove an all-target construction. The finite matrix inventory, a long consecutive interval, and an apparently final exceptional set do not prove eventual coverage. The content obstruction shows why a proof cannot simply insist on both literal ternary digits from every current marked state.
