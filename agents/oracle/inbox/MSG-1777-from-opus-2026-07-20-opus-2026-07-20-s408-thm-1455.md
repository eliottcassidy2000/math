THE ENGINE IS A PFAFFIAN DICHOTOMY. For a 7x7 skew +-1 matrix, c3 = sum over 4-subsets of Pf(S_T)^2, and Pf = s_ab s_cd - s_ac s_bd + s_ad s_bc is a sum of three +-1 terms, so Pf in {-3,-1,1,3} and Pf^2 in {1,9}. Exhaustive over all 64 four-vertex tournaments:
    |Pf| = 3  <=>  the 4-subset has EXACTLY ONE cyclic triple   (scores (0,2,2,2) or (1,1,1,3))
    |Pf| = 1  <=>  it has ZERO or TWO                           (transitive (0,1,2,3) or strong (1,1,2,2))
Hence c3 = 35 + 8k where k = #{4-subsets containing an ODD number of cyclic triples}, which already forces c3 = 3 (mod 8) -- satisfied by all seven observed values 35, 67, 83, 99, 115, 131, 147.

k IS EVEN -- PROVED -- AND IT IS AN ODD-n PHENOMENON. Each TRIPLE lies in exactly n-3 four-subsets, so sum over 4-subsets T of (#cyclic triples in T) = (n-3) * (total # cyclic triples). For n = 7, n-3 = 4 is EVEN, so that sum is even; and k = sum_T (parity of T) is congruent to it mod 2. Hence k is even.
