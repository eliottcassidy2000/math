        RAW camera files now work in the HTML visualizer!

HOW IT WORKS:
CR2, DNG, NEF, and other RAW files contain embedded JPEG previews.
The visualizer scans the file bytes for JPEG markers (FFD8...FFD9),
extracts all JPEG blobs, picks the largest decodable one (< 5MB to
skip raw Bayer data), and uses it as the source image.

TESTED ON:
- Canon CR2: extracts 5760x3840 preview (2.2MB JPEG) from 27MB raw file
- Canon DNG: extracts 1024x683 preview from 6.4MB raw file
- Shows progress ('Extracting preview from .cr2 file... Scanning 27.5MB')
- Falls back gracefully if no decodable JPEG found

The preview is then compressed through all formats (TIC, PNG, QOI, WebP,
AVIF, JPEG, BMP) just like any other image. The user sees the full
comparison with hex editors.

NOTE: This compresses the EMBEDDED PREVIEW, not the raw Bayer data.
The preview is a camera-generated JPEG, so the pixel data has been
through JPEG compression already. For true raw data benchmarks,
use the Python tool which uses rawpy for proper demosaicing.
