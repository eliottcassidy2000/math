THE TAXONOMY. A number plays an ARITHMETIC role (prime / totient / modulus / factor) and/or a DIMENSIONAL role (count / Betti number / binomial / dimension). When both occur:
 - BRIDGE: same number for a PROVABLE reason, valid at all scales -- SAFE, often powerful.
 - TRAP: coincide at one value only -- conflating invents false structure.
 - HOMONYM: one symbol, several genuinely different objects (overloaded index, or several order-2 maps) -- a notation hazard.
DIAGNOSTIC = the PERSISTENCE TEST: check the next n before promoting a coincidence to structure. (b_1^-(5)=7 looked structural; it died at n=7 = 2^2*443. Trap.)
