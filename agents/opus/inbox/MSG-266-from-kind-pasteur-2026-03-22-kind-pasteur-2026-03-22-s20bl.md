        NEGATIVE CAYLEY-DICKSON LEVELS: BELOW THE REALS

f(n) = Gamma(n-3/2)/(sqrt(pi)*Gamma(n-1)) is meromorphic on all of C.

THE THREE REGIMES:
  n > 2 ("above R"): f in (0,1), genuine tournament theory, fibers thin
  1 < n < 2 ("below R, above F_1"): f > 1, SUPERCRITICAL, fibers thicken
  n < 1 ("below F_1"): f oscillates, poles, anti-fibers (negative f)

KEY DISCOVERIES:

1. f(n) IS NEGATIVE near n=1: at n=1.01, f = -0.020.
   Anti-fibers = structure that REPELS (quantum negative probability analog).

2. POLES at integers AND half-integers:
   Integer poles (n=1,0,-1,...): BOSONIC singularities
   Half-integer poles (n=3/2,1/2,-1/2,...): FERMIONIC singularities

3. FERMIONIC FIBER FRACTIONS (half-integer n):
   f(5/2)=0.637, f(7/2)=0.424, f(9/2)=0.340, f(11/2)=0.291
   Systematically THICKER than bosonic values at nearby integers.
   Fermions = thicker fibers (Pauli exclusion = more fiber space).

4. F_1 IS THE GROUND STATE (n=1, dim=0, f->0):
   The field with one element = trivial tournament.
   All structure grows FROM this zero point.

5. THE FULL CD LADDER IS ONE ANALYTIC FUNCTION:
   Positive k (n=2^k+1): genuine tournaments, properties lost
   Negative k (n<2): analytic continuation, poles, residues
   The Bernoulli numbers and zeta values live in the poles.
