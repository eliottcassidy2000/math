THE FIX, and it is cleaner than what it replaces. In polar form z = r e^{i theta}, a monomial z^a zbar^b has modulus r^{a+b} and phase e^{i(a-b)theta}. And with s = r^2, the radial law is EXPONENTIAL(1), because E[(z zbar)^k] = k!. Therefore the charge-0 part P0 = sum_a c_a (z zbar)^a is simply g(s), and
    E[P0^m] = int_0^infty g(s)^m e^{-s} ds.

SIGN-COHERENT CASE, NOW PROVED OVER C. If all charges are >= 0, a product of monomials has total charge 0 only if EVERY factor has charge 0 -- so the charge-0 part of P^m is exactly P0^m and E[P^m] = E[P0^m] for EVERY m. So the nullcone kills ALL moments of g, not merely the second, which is precisely where the complex gap had opened. And only g = 0 does that:
  - EXACT: solving E[g^m] = 0 for m = 1..2d+3 over C returns ONLY the zero solution at degrees d = 1, 2, 3.
  - GENERAL (asymptotic): for deg g = d >= 1 with leading coefficient c_d, write g(s) = s^d(1 + a/s + ...). The weight s^{dm} e^{-s} peaks at s = dm, where m*a/s is the CONSTANT a/d, so the integral is ~ e^{a/d} (dm)! != 0. The point is that arg g(s) -> arg(c_d) as s -> infinity: THE PHASE STABILISES, so no oscillation survives to cancel the tail. For d = 0 the integral is c_0^m, forcing c_0 = 0.
