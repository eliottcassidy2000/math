# Hammersley naming check

The author-hosted paper by Peter Kritzer and Friedrich Pillichshammer, *An exact formula for the L2 discrepancy of the shifted Hammersley point set*, was independently opened at https://www.dmg.tuwien.ac.at/nfn/KriPill_UDT06.pdf . The accessible PDF has ten pages. Pages 1--2 define the binary radical inverse and the shifted set (phi_2(n), (n/2^m) xor sigma), for 0<=n<2^m. At zero shift and with coordinates exchanged, this is exactly (A/2^k, rev_k(A)/2^k).

The packet uses this source only for the name and definition. Its elementary star-discrepancy estimates are proved locally. The cited L2 results are in a different norm and are not imported. No literature theorem about the actual source sequence or target occupancy is asserted.
