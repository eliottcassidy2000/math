# Reviewed bounded-error counting checkpoint

This separate all-order packet proves that source approximation errors bounded by a fixed constant occur at only N^{o(1)} actual source indices through N. Therefore bounding BOTH source errors cannot cover an odd target tail with the twelve fixed central forms. This does not exclude a one-sided bound, a growing allowance, or unrestricted exact occupancy, which remains OPEN.

The original proof, README, and manifest are preserved in `originals/`. `PROMOTION.diff` records only status, sibling/dependency links, and packet-local reproduction paths. The source verifier and receipts are unchanged. `dependencies/CORE_PROOF.md` is the byte-preserved previously reviewed product-bound dependency. The separate independent report is `audit/REPORT.md`, with promotion approval in `audit/PROMOTION.md`.

Run `python3 verify.py` or `python3 -O verify.py` from this packet directory. The verifier is standalone. `MANIFEST.sha256` inventories the complete release except itself.
