# Bounded Hammersley-error obstruction

Independently audited all-order proof. A word of length k with R>=1 Z-runs has
source error e>=R*2^(-k/(2R)). A fixed bound on e therefore forces R=o(k),
and only N^{o(1)} actual source indices through N have bounded error.

Bounding BOTH source errors consequently cannot cover a tail of the odd
targets using the twelve templates. This does not refute unrestricted
occupancy or a method bounding only one error.

Portable exact checks are in verify.py and matching normal/optimized reports.
