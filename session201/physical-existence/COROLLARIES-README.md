# Audited physical inverse corollaries

The separately reviewed continuation is in COROLLARIES.md, with its report in audit-corollaries/REPORT.md. It adds asymmetric inventory budgets with LR>=3(n-1), and a conditional J-crossing bound floor(sqrt(16n/7)). The coefficient16/7 is sharp for that letter inequality and specified-word cuts only. Neither claim implies target occupancy.

Run `python3 verify_corollaries.py`, then `python3 -O verify_corollaries.py`; both supplied receipts are identical.
