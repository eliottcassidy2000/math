# The root-change lattice is an explicit cubic order

**PROVED, independently audited in the stated scope.** This sidecar explains the
arithmetic structure behind the signed-section calculation. It uses an
explicit order generated by a cubic algebraic integer; it neither identifies
that order with the full ring of integers nor assumes a Diophantine-
definability theorem. The physical section still requires the separate
source-grammar proof in PROOF.md.

## 1. Integral coordinates and a genuine algebraic unit

The zero-f coordinate lattice is

    f=U-D+E-d=0,
    (D,E,U,d)=(a+2e+p,e,a+2e+2p,e+p), a,e,p in Z.

The physical J operation restricts to

    (a,e,p) -> (p,a+e+p,e).                       (1)

Its integer matrix has determinant1 and characteristic polynomial

    X^3-X^2-X-1.

This polynomial is irreducible over Q: its only possible rational roots are
1 and -1, and neither is a root. Let theta be any root and let
R=Z[theta], an explicit cubic order. Define the integral coordinate map

    Psi(a,e,p)=a+(e-p)theta+p theta^2.            (2)

It is a lattice isomorphism Z^3 -> R: its coefficient change has determinant1.
Using theta^3=1+theta+theta^2, one checks exactly

    Psi(Js)=theta Psi(s).                        (3)

Also `theta^-1=theta^2-theta-1` lies in R. Thus J really acts as multiplication
by an algebraic unit on this specified integer lattice, rather than being
called a unit operation by analogy.

## 2. The adjoint pairing is multiplication followed by an integer functional

Let ell:R->Z be the coefficient functional

    ell(x0+x1 theta+x2 theta^2)=x0+2x1+4x2.

For any two raw vectors in the zero-f lattice, direct substitution gives

    K(v,w)=ell(Psi(v)Psi(w)).                    (4)

In the basis 1,theta,theta^2 its Gram matrix is

    [[1,2,4],[2,4,7],[4,7,13]],

whose determinant is -1. It is therefore a perfect integral bilinear pairing.
Multiplication by theta is self-adjoint for this pairing because ring
multiplication is commutative, agreeing with the physical identity
`J^T Q=QJ`. This verifies the actual map and preserved readout, not just a
similar recurrence.

## 3. Why the 6/7 boundary enters a physical state

The formal signed boundary `z=(-1,-7,-1,-7)` has
`Psi(z)=13-7theta`. The actual source `t.ZZ=(5,1,5,1)` has image `3+theta`.
The exact order identity

    theta^6(13-7theta)=3+theta                    (5)

is the same as `z.J^6=t.ZZ`. For example
`theta^6=4+6theta+7theta^2` and
`theta^7=7+11theta+13theta^2`, so (5) follows by subtraction.
This explains the small integral coefficients in the signed-boundary
transfer without appealing to an outside conjecture.

The singleton and the edge have images theta-1 and theta^2-theta,
respectively. The O and Z operations are not being identified with
multiplication by units; in particular O does not preserve the zero-f
lattice. Only the specified J restriction has the unit interpretation.

## 4. The physical guard cannot be removed

Integer-lattice invertibility is not physical invertibility. The genuine
source `t.ZZ=(5,1,5,1)` has the unique inverse under J *within the zero-f
lattice*

    (1,0,4,3),

which is not physical because U=4<2d=6. There is an actual J predecessor,
`t.O=(1,0,4,1)`, but it lies off the zero-f lattice. J forgets the old d;
choosing the algebraic-lattice inverse silently makes the wrong choice.

This is exactly why the intrinsic section proof forces each predecessor's
last letter before filling in its deletion coordinate. In that proof the
appropriate zero-f faces are proved, so the integral unit inverse becomes
a valid physical inverse at those steps. Merely recognizing an algebraic
integer, a unit, an integral solution, or a point in a positive cone cannot
supply those physical guards.

The connection to the user's arithmetic themes is constructive: identify
an explicit integral algebra, an exact unit action and pairing, then prove
the additional physical membership statements needed to use them. It is
not a claim that ring definability implies tournament target coverage.
