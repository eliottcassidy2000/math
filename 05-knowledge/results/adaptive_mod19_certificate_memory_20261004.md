## 2. The selector is now a checked program

The [implementation and proof](adaptive_boundary_selector_20261004.md) expose
three different outcomes:

* `ROOT`: the source is1, with its empty first-hit route.
* `REDUCED`: a finite actual prefix reaches J and advertises one or more
  smaller positive odd dependencies a with either a=J or U(a)=J.
* `PENDING`: the declared bounded policy found no such conclusion.

`REDUCED` is not itself a completed certificate. The discharge operation
requires an existing certificate for one advertised child, checks the join,
and constructs the original source's canonical first-hit inverse AST. An
already completed actual suffix can also be reused when its source exceeds
the original input: the suffix itself supplies the proof, so this operation
does not need numerical descent.

All stored macros are checked both by literal exact valuations and by their
affine identity against the immutable source. The library includes inherited
core words and repeated1,12,112 blocks, all eligible sibling alternatives,
the new virtual contraction rule, and learned exact cylinders. The default
per-macro cap is128 odd steps. Macro budget, actual trajectory length,
integer bit cost and proof-memory size are kept separate.

On all4095 odd sources3..8191, an eight-macro budget yields4029 reductions
for the adaptive policy versus4007 for the inherited policy. These counts
are smaller obligations, not home certificates. A separate root-only test
on the512 odd inputs1..1023 gives332 completed certificates for the inherited
policy and350 for the initial adaptive policy at the same macro budget.
Among the162 initial adaptive misses,15 are `PENDING` and147 have a reduced

## 5. Mod19 builds actual recursive routes, with a sharp four-step bound

The [nineteen-ray theorem](mod19_route_lifts_20261004.md) proves:

> Every residue modulo every19^a contains infinitely many positive odd
> sources with an explicit first-hit route to1 of at most four odd steps.
> Four is the smallest possible uniform bound.

Eighteen rays are predecessors of1 or5. The exceptional residue is
`6=-1/3 mod19`; it needs the internal-exponent family

\[
 n_t=\frac{53\,2^{8+18t}-5}{9},\qquad
 \text{word }(1,7+18t,5,4).
\]

Its first route is `1507 ->2261 ->53 ->5 ->1`. A complete six-case modular
proof excludes odd ranks at most three in this residue. For every ray,

\[
 v_{19}(n_t-n_u)=1+v_{19}(t-u).
\]

Each next source digit therefore selects one next parameter digit. The
compiler answers arbitrary finite19-adic address requests without expanding
the source. At precision80 its parameter has336 bits while the constructed
source exceeds10^100 binary digits.

This bank contains only `(19/18)log_2 X+O(1)` sources below X. It has full
19-adic support and natural density zero. Asking for the residue of19 returns
87381, which has its own checked route; that is not a certificate for19.
An exact match to the supplied integer is still required.

The selector package implements that check as `lookup_ray_certificate(n)`.
It uses `n mod19` to choose a candidate ray, then verifies the integer identity
`Dn+B=A*2^(18t)` with a nonnegative integer t. Only a successful exact match
returns the ray's completed AST. The optional helper is excluded from the
policy-comparison tables;190 members and190 same-residue nonmembers were
checked separately.

There is a useful derived observation. Both the bank and its complement in
the positive odd integers meet every19-adic residue class: the bank does by
the theorem; the complement does because each odd residue progression has
positive natural density while the bank has density zero. Consequently no
procedure seeing only finitely many19-adic digits, even adaptively, can
decide exact membership in this bank on every source. The terminating
procedure must retain another coordinate, such as the integer itself or a
height bound. An end-of-expansion marker would already supply extra height
information and is not part of that digit-only interface. This concerns
bank membership, not the Collatz conjecture.

## 6. Why19 is the first shared ternary digit, and how the hierarchy continues

In an inherited inverse row,

\[
 n_b=(2^{\kappa+6b}u-1)/3.
\]

The ternary address constrains `b mod3^(a-1)`. For a19-adic unit hub, the
19-adic address constrains `b mod(3*19^(k-1))`. These constraints share the
same block index. For a>=2 they are compatible exactly when their residues
agree modulo3; at a=1 there is no shared-digit obstruction. The two source
moduli are coprime, but the parameter clocks need not be.
The [joint address selector](mod19_recursive_observers_20261004.md) proves the
exact condition, handles nonunit hubs, and returns a completed child of the
supplied certified parent.

For an odd prime p different from3, set

\[
 d_p=\operatorname{ord}_p(2),\qquad
 R(p)=\max(0,v_3(d_p)-1).
\]

The six-exponent block has order `d_p/gcd(d_p,6)`. At noncollapsed p-adic
precision, the shared part of its clock with `3^(a-1)` is exactly

\[
 \boxed{3^{\min(a-1,R(p))}.}
\]

Thus R(p) counts shared ternary digits. It remains unchanged when p-adic
precision increases: an order lift can add powers of p, not powers of3.
Nineteen is the first possible prime with R(p)>0, since this requires
`9|ord_p(2)`, hence `9|p-1`, and19 has order18.

| Prime | Order of2 | Order of64 | Shared ternary depth R(p) |
|---:|---:|---:|---:|
|19|18|3|1|
|87211|54|9|2|
|5779|5778|963|2|

This supplies the promised recursive connection to the earlier missing
cyclotomic factors. Put

\[
 C_r=\frac{2^{2\cdot3^{r-1}}-2^{3^{r-1}}+1}{3}.
\]

The first values are `C_1=1,C_2=19,C_3=87211`. For r>=2, every prime
divisor p of C_r has order `2*3^r`, so R(p)=r-1. Each level therefore
introduces one more shared ternary digit. The proof does not assume C_r
is prime. The first empty levelC_1=1 is the same primitive-factor exception
seen at `2^6-1=63`.

The golden branch's next prime5779 differs from87211, as the previous audit
required. Their shared-depth invariant nevertheless agrees: both retain
two ternary digits in this inverse-address problem. The extra factor107
in `ord_5779(64)=9*107` is retained separately. This is an exact common
invariant, not renewed equality of the two prime sequences. Proofs and
controls are in [the resonance-depth note](mod19_resonance_depth_20261004.md).

The inherited112 word gives another faithful, but differently typed, view:
`F(n)=(27n+19)/16` is multiplication by1/2 modulo19 after retaining its carry,
and `11n+19` turns it into a multiplicative shell coordinate at all depths.
Its exact integer guard remains `n=7 mod32`. The full formal19-adic orbit is
not automatically a legal repeated integer word; the selector checks the
dyadic guard before applying it.

## 7. A concurrent torus construction gives the same clock, by an exact map

The incoming [checked-switch geometry](checked_switch_phase19_20261004.md)
partitions the Paley19 directions into three triangular torus layers.
The [inverse-ray/torus bridge](inverse_ray_torus_clock_20261004.md) identifies
their permutation with the inverse-family block clock, including prime-power
refinements. This uses the residue ring `Z/(p^k)`, not the field with p^k
elements.

Let p be a prime congruent to7 modulo12, Q the group of square units modulo
p^k, and H its order-three subgroup. The layer is the coset qH. Cubing gives

\[
 Q/H\;\xrightarrow[\cong]{\ qH\mapsto q^3\ }\;Q^3,
 \qquad 4qH\longmapsto64q^3.
\]

For an anchored inverse ray with unit `alpha=2^kappa*u`,
`3n_b+1=alpha*64^b`. Consequently

\[
 \Phi_\alpha(qH)=\frac{\alpha q^3-1}{3},\qquad
 \Phi_\alpha(4qH)=64\Phi_\alpha(qH)+21
 \pmod{p^k}.
\]

The affine carry21 is necessary. The resulting source addresses belong to
an anchored torsor; one inverse ray traverses one clock orbit within it.
At19 all three layers are one orbit. At87211 there are14535 layers split
into1615 orbits of length9. Thus the shared ternary depth2 belongs to each
such orbit; it does not mean that nine layers exhaust the geometry. The
unit-hub guard is essential; nonunit hubs need the valuation peel from
section6. The map returns residue addresses, not new certificates for
arbitrary integers with those addresses.

There is a literal recursive edge decomposition at every prime-power scale.
Each unit-direction layer gives a triangular torus with `p^k` vertices.
For differences of valuation v, restrict to a fibre modulo p^v and divide
its coordinates by p^v. There are `phi(p^k)/6` tori at every level
`v=0,...,k-1`, each with `p^(k-v)` vertices. Their edges partition every
unordered pair of distinct residue vertices. For361:

| Difference valuation | Tori | Vertices per torus | Total edges |
|---|---:|---:|---:|
|0|57|361|61731|
|1|57|19|3249|
|Total|114|mixed|64980 = binomial(361,2)|

Identifying equal residue vertices glues these surfaces into a singular
complex. A vertex has60 separate cellular hexagonal links, not one link
of a larger surface. Keeping the fibre and layer labels recovers the114
disjoint tori. The geometric layer refinement and the clock refinement
are different operations: within a persistent valuation stratum, each layer
has p child tori, each a p-sheet cover, whereas their clock states may
participate in one longer orbit. The newly added top valuation stratum
collapses to vertices under reduction; the whole normalized union is not
a surface covering of the previous level.

An intrinsic tournament also survives every scale. For distinct x,y, orient
x toward y when the first nonzero p-adic digit of y-x is a square modulo p.
This is the iterated lexicographic product of the prime Paley tournament,
with lower digits compared first. It respects the valuation strata and has
no off-diagonal ties. At361 it is not a field Paley tournament. This gives
an exact recursive tournament/torus object while retaining the lost integer
and route coordinates explicitly.

The geometric congruence restriction does not end the shared-depth tower.
For r>=2, `C_r=3 mod4`, and every prime factor of C_r is1 modulo6 by its
exact order `2*3^r`. At least one factor must therefore be7 modulo12 with
odd multiplicity. Every positive shared depth has a prime supporting this
oriented torus/tournament construction. Not every factor qualifies: at r=4,
163 does, whereas135433 and272010961 are1 modulo12. The theorem gives a
choice at every level, not a canonical increasing sequence of chosen primes.

## 8. What the next iteration should optimize

The demonstrated productive operation is **retain all checked segments,
close proofs from known roots, then inspect a shared missing frontier**.
The earlier family-learning loop remains useful: promote a reusable checked
segment to a whole cylinder when its exact guard and boundary proof pass.
Future experiments should measure how many unresolved obligations each new
observation or family discharges, keeping source identity and proof provenance
exact. Merely adding more residue classes to a lookup table cannot replace
this test.

For mod19 and later cyclotomic primes, retain the shared block digits when
joining selectors. An independent CRT product would invent unreachable
address combinations. Increasing the shared-depth invariant gives a precise
new family of compatibility tests for the procedural generator.

The unresolved all-input questions remain explicit: will every source find
a usable rule, can the required macro/precision/discovery budgets be controlled,
and can unresolved boundary members always be discharged? The finite root-only
closure and the infinite certified families do not settle these questions.

Every component has a standalone exact script and saved output. The component
proofs and the selector's512 completed routes were independently audited.
Normal and optimized Python runs agree. The session uses the existing
meta-patterns of retaining the observer and finite head, separating local
support from bounded-height coverage, and exposing the obstruction before
choosing the scale. No new meta-pattern or scarce theorem identifier was
promoted from this one session.
