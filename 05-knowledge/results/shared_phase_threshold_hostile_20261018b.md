## No retraction, but all 570 boundary patterns extend

**Nonretraction.** The unique 5-cycle of `B` is its pentagon on `0..4`.
Every homomorphism from `C5` to `B` maps bijectively onto that pentagon:
`B` is triangle-free, so a closed walk of odd length5 cannot fold to a
shorter odd cycle. The independent finite check enumerates its ten possible
closed walks, all the dihedral pentagon maps.

The copy introduced for `(6,2)` contains its copied vertex2 on a pentagon,
and the source vertex6 is joined to that copied vertex2. A retraction fixing
the source would have to send the copied vertex into `0..4`, while its edge
to6 requires it to land in `N_B(6)={5,7}`. These sets are disjoint.
Consequently **no source-fixed graph retraction exists**.

**Full support.** Name the six colours `0..5`, grouped into pairs
`{0,1},{2,3},{4,5}`. Given any proper source colouring `p`, put its unchanged
pattern on each copy, except flip all binary shades on copy i when
`p[a_i]=p[b_i]`. In notation, its colours are

```
c(i,z) = p[z] xor epsilon_i,
epsilon_0=0,
epsilon_i = 1 if p[a_i]=p[b_i], otherwise 0.
```

A global shade flip is a palette permutation, so all old copy edges remain
proper. The only new edge at each copy is its one spoke: if its two initial
colours agree the flip separates them; if not, the unchanged colours already
separate them. There are no edges between distinct exterior copies. Thus
**every** proper source colouring extends. The finite receipt contains and
replays all 570 canonical source patterns and their full 112-colour witnesses.
For terminal `24`, **123 equal patterns and 447 separating patterns survive**.

This graph also has empty relative six-core: delete unmarked vertices of
degree at most5 repeatedly. Each exterior copy can be peeled. Such deletion
preserves extension of every prescribed six-colouring of the source,
because a deleted vertex can be recoloured in reverse order. Thus the
configuration is rejected both by a local extension criterion and by the
explicit shade mechanism. This is why it is a control, not a near-proof.

More generally, take arbitrary properly six-coloured source copies and join
them by one edge for each edge of a tree of copies. An independent global
shade bit per copy always repairs the coupling: different colour pairs impose
no condition, and a same-pair join imposes one binary equation. A forest has
no inconsistent cycle equations. With one source bit fixed, if `s` of the
joins have the same pair label, there are exactly `2^(L-1-s)` shade repairs
on `L` copies. Colour pair labels alone lose this information.
