# Engine provenance

`fixed_cube_engine.py` is copied unchanged from `session13-census/mixed_symmetry_census.py` in the shared session workspace. Its intended published predecessor is `05-knowledge/results/odd_mixed_prime_census_20261020/mixed_symmetry_census.py`.

The file retains the predecessor's main routine, but this extension does not invoke that routine. It imports the permutation, fixed-cube, unrestricted isomorphism, twin-sign, and census-summary helpers. The extension and replay replace functions explicitly as documented in README.md.

This is code reuse, not an independent software implementation. The independent degree-eleven certificate has no import from this engine.
