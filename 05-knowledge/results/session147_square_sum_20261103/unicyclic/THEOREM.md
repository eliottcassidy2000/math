# Hamilton paths and edge deletions in unicyclic graphs

This is a general, elementary graph-theoretic derivation, not a claim of a new square-sum breakthrough. A Hamilton path means a spanning simple path; orientations are identified. Let G=(V,E) be a finite, connected, simple unicyclic graph and C its unique cycle. Since G is simple, |C|≥3. Let B=E\E(C), the bridges, and let S be the set of cycle vertices of degree exactly 3.

## The path theorem

Each Hamilton path is precisely G−e for an edge e of C such that G−e has maximum degree at most 2. In particular, all bridges belong to every Hamilton path. The admissible deleted edges form the set D below:

- If a vertex outside C has degree ≥3, or a vertex on C has degree ≥4, then D is empty.
- Otherwise D={uv in E(C): S is contained in {u,v}}.

Consequently the number of unoriented Hamilton paths is |C| if S is empty; 2 if |S|=1; 1 if |S|=2 and its two vertices are adjacent on C; and 0 in every other case, including either degree obstruction above.

**Proof.** Every bridge is required in a connected spanning subgraph. A unicyclic graph has |E|=|V|, while a Hamilton path has |V|−1 edges, so a Hamilton path omits exactly one edge, necessarily of C. Conversely, deleting any e in C gives a connected spanning tree. Such a tree is a path if and only if all its degrees are at most 2. Only the endpoints of e lose one degree; all other degrees are unchanged. This immediately yields the degree obstructions and, otherwise, the requirement that the endpoints of e cover S. A cycle edge has two endpoints, each cycle vertex is incident with exactly two cycle edges, and two distinct cycle vertices share exactly one cycle edge if adjacent and none otherwise. These facts give the stated counts. Each permissible deleted edge produces a different path edge set, hence a different unoriented path. ∎

**Nonvacuous edge classification.** If D is nonempty, the edges forced in every Hamilton path are exactly E\D. An edge is present in no Hamilton path exactly if D consists of that single edge. If |D|≥2, the edges in D are optional: each is omitted from exactly one Hamilton path and used in all the others. If D is empty there is no Hamilton path, so calling any edge forced or forbidden would be vacuous. Nonedges cannot occur in a path.

## All edge-deletion component counts

For any F⊆E, the number of connected components of G−F is

    c(G−F) = 1 + |F| − 1[F meets E(C)].

Indeed G−F has |V| vertices, |V|−|F| edges, and cycle rank 1 if F leaves C untouched and 0 otherwise. Apply c=|V|−|E(G−F)|+cycle rank. Equivalently, the first deleted cycle edge destroys the only cycle without increasing the component count; every other deletion increases it by one. In particular, deleting exactly two edges yields three connected components if and only if both are bridges. The number of such two-edge cut sets is binomial(|B|,2). To find a specified three-way size profile, including 3/4/5 when |V|=12, it is necessary and sufficient to enumerate bridge pairs and inspect the three component sizes. This statement concerns edge deletions, not induced subgraphs or vertex cuts.

## Square-sum application

Let G_n have vertices 1,…,n and edges ij for distinct i,j whose sum is a square. Direct edge enumeration shows that G15, G16 and G17 are connected unicyclic graphs with unique cycle 1–3–6–10–15–1; S={1,3}; and no degree obstruction. Thus D={1–3}, so each has exactly one unoriented Hamilton path. Edge 4–5 is a bridge and is forced, 1–3 is the unique admissible deletion and therefore forbidden in every Hamilton path, and 2–4 is absent because 2+4=6 is not a square. These claims are nonvacuous since the paths exist. The accompanying checker calculates the cycle and confirms the degree hypotheses rather than assuming them.

## Reproducible checks and limits

Run `python check.py` and `python -O check.py`; the retained `check.out` and `check_O.out` are identical. Every connected labelled simple unicyclic graph on 3–6 vertices is generated by edge-set enumeration, and all its unoriented Hamilton paths are independently found by vertex permutations. Exact path edge sets are compared with the admissible cycle-deletion construction, and forced/forbidden edge statements are checked whenever at least one path exists. All edge-deletion subsets are separately checked by graph traversal against the component-count identity. The totals are 1, 15, 222, 3660, respectively, 3898 graphs in all. Six malformed/disconnected inputs must be rejected, and off-cycle branching and a degree-4 cycle vertex are tested as no-path obstructions. The code uses explicit exceptions and checks rather than Python `assert`. These finite tests support, but do not replace, the proofs above. The direct G15–G17 check uses the proven criterion and independently enumerates graph edges; it does not attempt factorial path enumeration at those orders.
