## A weighted tail-deletion certificate

Use the earlier deletion proof. Let A be the set of old sites beaten by x. A path not ending at x can be written P₁,x,P₂, where P₂ begins at b in A. Remove the maximal terminal block of P₁ whose vertices are all beaten by b, and let S be its vertex set. The shortened left part concatenates with P₂ to form an old Hamiltonian path on T−S. This path, b and the ordered deleted block recover the original path. A nonempty block must end outside A, since its last vertex precedes x. Define e_A(S) to be the number of Hamiltonian paths on T[S] ending outside A. For fixed b and nonempty S the sharpening is
```
H(T−S)e_A(S) ≤ [e_A(S)/H(T[S])] H(T).
```
It follows from the product inequality for induced disjoint supports, itself immediate from the odd-cycle packing identity. The weight is a rational fraction, not just a test for whether any terminal order is possible. Include weight 1 for S=∅ and weight 1 for paths ending at x. This proves
```
H(T+x)/H(T) ≤ 1 + Σ_(b∈A) (1 + Σ_(∅≠S⊆N_T^+(b)) e_A(S)/H(T[S])).
```

Only the last six old sites enter the right side: b is at distance at most three from x, and can beat a site to its own left only at distance at most three. All other out-neighbors of b are to its right, within the same window. When there are fewer than six old sites one can pad with earlier universal sources, retaining the same actual backward set A, all displayed weights, and both Hamiltonian counts. In particular this is a finite *upper certificate* for arbitrary old orders, not extrapolation from small growth ratios.

Inside six sites there are exactly twelve edges that can point back. Enumerate their 4,096 orientations, run exact subset path DP for each T[S], and evaluate the bound for all eight masks. Integer/Fraction replay gives the table above. The weaker strategy of counting each subset with at least one admissible endpoint gives 32 at mask 7; the weighted factor is what closes the last case at 31.
