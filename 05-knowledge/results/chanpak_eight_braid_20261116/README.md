# Eight sharp masks, dyadic steering, and three moving strands

Research session, 2026-11-16. All tournament checks are for literal span-3 ribbons. Chan–Pak and the constant-rank lower-growth conjecture remain open.

**Repeatable control:** from one literal seed, the same four-dimensional image can be restored while following **any infinite requested stream of odd residues modulo 32**. At every reachable return state, two eight-letter return blocks suffice for the next request. The exact finite controller replays 524,288 states. This restores the image, not the entire integer vector, and does not select the absolute count.

1. **8/8 sharp bounds.** [The sharp mask table](SHARP_EIGHT.md) gives the exact extension factors **1, 9, 17, 19, 33, 33, 39, 31** for masks 0 through 7, for all old prefixes. The weighted tail-deletion proof uses the fraction of paths on each removed set ending at an allowed endpoint, then checks 4,096 possible six-site layouts. All eight factors are attained and remain sharp in any old odd residue modulo 16. Thus a global factor 8 is false even though all eight cases are solved.
2. **8/8 modular control.** [Literal transitions](MOD_TRANSITIONS.md) gives all eight half-increments modulo 8 from one strong prefix, and all 64 odd old/new pairs modulo 16 with both endpoints strong. A one-letter fan is not an infinite steering policy: repeatedly requesting the unchanged residue forces sink letters. A two-letter bank avoids that immediate failure.
3. **Scale-up without spending rank.** [The rank-four bank](RANK4_STEERING.md) hits **all 512 odd residues modulo 1024** from one strong seed in five append steps. Every intermediate tournament is strong and the rank stays four throughout. A separate [return bank](RANK4_RETURN.md) hits all **1,024 odd residues modulo 2048** from that seed while restoring the exact same rank-four image. Those higher-residue choices are from the seed only, not the uniform online theorem modulo 32.
4. **Three leashes and two hands.** [Three moving strands](THREE_LEASHES.md) separates endpoint permutations, signed braid motion, rank, and the actual image subspace. The two elementary signed crossings undo any *recorded finite* braid, but labels alone cannot undo a hidden pure braid. Even paired crossing sums and a mod-8 matrix can both vanish on a nontrivial braid. On literal ribbons, actual rank-three volume likewise disappears modulo 8 on a concrete strong example. The two-sided sharp 39 estimate bounds every semantic minor and supports an exact variable-precision residue controller when a target height is fixed.
5. **An actual numerical analogue of the QRH method.** [Dyadic completion and smoothing](QRH_DYADIC.md) uses the conductor decomposition of a finite Fourier box to prove an O(√q) cyclic proximity bound, with an explicit absolute-diameter obstruction. Separately, the symmetric interaction of three coordinates of fixed total reduces to an Eisenstein norm. It has only 6/8 residues at a fixed total; two choices of total fill the dyadic classes. Permuting the same strands cannot substitute for changing that total. This is an arithmetic model, not a theorem that every norm value has a tournament lift.

The fraction 7/8 in the [September QRH source](https://github.com/openai/math/blob/main/preprints/The-Quasi-Riemann-Hypothesis-September-30-2026/paper.pdf) is a zero-free half-plane boundary, not a count of cases. Replacing it by 8/8 would weaken that statement. No analytic hypothesis is used in the ribbon proofs.
