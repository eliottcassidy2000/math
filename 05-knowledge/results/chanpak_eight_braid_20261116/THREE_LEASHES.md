# Three moving strands: what a swap forgets, and what a rank certificate needs

## Literal leash model

Model three distinct dog positions in a plane, relative to the walker, as three paths that never collide, with time as an additional coordinate. Fix the endpoint configuration, allowing the labeling to be permuted. The resulting path class is a three-strand braid, not a knot until one chooses a closure. A hand that only swaps two labels records the endpoint permutation in S₃. A hand that actually passes one strand over or under another can implement an elementary crossing or its inverse. These are two different capabilities.

In [Artin's braid presentation](https://doi.org/10.2307/1969218), B₃ is generated by σ₁,σ₂ with σ₁σ₂σ₁=σ₂σ₁σ₂. Thus if both signed adjacent crossings are physically available at the live boundary, one can cancel any *finite recorded* braid by performing its inverse in reverse order. A permutation alone does not specify that inverse. The pure braid (σ₁σ₂)³ leaves positions unchanged but has exponent sum 6, hence is not the identity. There is also no last braid to invert for an arbitrary infinite motion. Online undo needs extra control; attaching a fixed finite word cannot simultaneously erase two distinct histories.

Even all pairwise signed crossing totals combined with one mod-8 observation can miss a tangle. Map σ₁,σ₂ to the determinant-one matrices

    U = [[1, 1], [0, 1]],      V = [[1, 0], [-1, 1]].

They satisfy UVU=VUV, so this is a braid-group homomorphism by the presentation. The pure commutator [σ₁⁸,σ₂⁸] has zero signed crossing total for each labeled pair: these totals add under concatenation of pure braids and negate upon inversion. Its matrix is

    [[4033, 512], [512, 65]] ≡ I (mod 8),

but not I over the integers, proving the braid is not trivial. This example does not require that this representation be faithful. It emphasizes why making all eight residue cases agree is not, by itself, a statement about full crossing history.

## A rigorous rank analogue for ribbon transfers

This is a separate linear-algebra model, not an identification of ribbon letters with braids. A ribbon prefix product has image E in the exact minimal observable transfer. Rank cannot increase, unlike a reversible braid. In rank three, choose any frame u,v,w of E. The projective Plücker line [u∧v∧w] is an exact representation of E: changing basis, including either adjacent swap, multiplies the wedge by one nonzero scalar. Appending a letter acts by the third exterior power; the wedge vanishes exactly when the rank drops. For variable ranks use the appropriate exterior power at the surviving rank, or track the image basis itself.

Two “hands” can hold an independent pivot pair during an update. If Au and Av survive independently, subtract their unique linear combination having the same two selected pivot coordinates as Aw. The residual is zero precisely when Aw lies in span(Au,Av). If the chosen pair becomes dependent, first search the three possible pairs for two surviving pivots; if none survive the next rank is ≤1. A change of pivot or strand label cannot manufacture a lost dimension.

An equivalent concrete finite-horizon summary encodes only intersections with future kernels. Write D_w(E)=dim(E∩ker M_w) for a future word w (products act in chronological order). For a leading action A followed by w, the exact rule is

    D_w(AE) = dim(E∩ker(M_w A)) − dim(E∩ker A).

This follows from the surjection A:E∩ker(M_w A) → AE∩ker M_w, whose kernel is E∩ker A. It locates the certification obligation: a lookahead ℓ table updates from an ℓ+1 table; using a fixed short table forever needs a proof of closure on the reachable set. Equal suffix tags and ranks do not give that closure in the known physical alias from the preceding session.

## Bounded-39 consequence: an integer interval for each semantic minor

The sharp factor-39 bound for right extension also holds for **left** extension: reverse the order of positions and take the converse tournament. These two operations together preserve the size and direction class (forward or backward) of every span, and converse preserves H by reversing each Hamilton path. Thus deleting the leftmost vertex is equivalent to deleting the rightmost of another span-3 ribbon.

Fix finite semantic prefix and suffix families p_j,s_i used in a Hankel representation. Each entry of the prefix evaluation matrix is K_w(i,j)=H(p_j w s_i), where p_j includes the initial vertex if that convention is used. Deleting p_j and s_i leaves exactly the induced ribbon on w, so for any nonempty w,

    0 ≤ K_w(i,j) ≤ 39^(|p_j|+|s_i|) · H(w).

For a minor of size r on row indices I and column indices J, factor out the displayed row and column powers, then apply the determinant expansion:

    |det K_w[I,J]| ≤ r! · 39^(sum_{i∈I}|s_i| + sum_{j∈J}|p_j|) · H(w)^r.

The inequality is rigorous and uses no zero-distribution hypothesis. If a modulus exceeds the right side, a zero residue of that minor certifies exact zero; a nonzero residue always certifies nonzero. An odd prime or several coprime moduli work equally well. Reducing only mod 8 is a valid fast filter for a visible nonzero minor, not a complete rank decision. One can lift only the ambiguous pivot minors by enlarging the modulus; a known height cap says how far to lift. This is the precise “signed motion plus error bound” point of contact with bounding an uncertain quantity in a narrow enough interval to select the exact integer, not a claim that the quasi-Riemann hypothesis yields a ribbon conjecture.

This bounds the proof cost of exact rank checks and makes the needed state information explicit. It does not provide a finite partition of all reachable three-planes or prove the lower-growth inequalities on constant-rank stretches.

## Literal mod-8 rank alias

This is not only a warning for arbitrary matrices. In the existing minimal-model proof, take the same canonical strong word v=(0,1,7,0,2) after the first vertex. Its semantic Hankel matrix K_v=O M_v B has rank three, H=17, and an explicit nonzero 3-minor equal to 32 (zero-based rows 0,2,5 and columns 0,2,5). Yet every 3-minor is divisible by **16**, so a test of all raw semantic minors modulo 8 sees none. A short exact replay avoids enumerating minors: K_v[0,0]=17, a unit modulo 4. Subtract from each other row the modulo-4 multiple of row zero matching its first entry. Every entry of every other row is then a multiple of 4. Every 3-minor of this transformed matrix is a multiple of 16 since it uses at least two of those rows. Undoing the unimodular row operations preserves common divisibility of the minors. This tests the physical word, not just a possible failure of modular linear algebra. The other member u=(0,2,7,0,2) has a nonzero 3-minor 36 already visible modulo 8; after appending the same letter 1, only the v-image drops to rank two.

For scale information, the integral Smith diagonals of the four semantic matrices are (1,2,2), (1,4,4), (1,2,6), (1,4), respectively, in the order u,v,u1,v1. The 2-adic divisibility of the *raw* volume of the three strands is therefore not the same as their independence. One can normalize the exact rational image to a primitive Plücker vector before reducing, but knowing only raw data modulo 8 is not enough to make that normalization. This distinction is the algebraic counterpart of real braid information being absent from a truncated observation.

Run `python check_three_leashes.py` from this package, with the earlier `verify_rank_alias.py` packet adjacent as in the archive. It checks the literal false negative by exact integer row operations and the braid matrices with standard integer arithmetic. It also reports the maximal semantic observation lengths used to state an explicit modulus cap.

## Finite exact controller when a target is fixed

There is a practical use of adaptive precision apart from the braid analogy. Fix X≥1 and a power of two M>39X. Seed the first-vertex frontier and keep its coordinates modulo M. For each extension, if the state is live then its true H is ≤X, so the new H is between 1 and 39X and is recognized **exactly** by its residue. If the new H exceeds X, go to a permanent overflow state: later H cannot decrease. Otherwise keep the residue frontier and continue. This recognizes either H≤X or H=N for any fixed N≤X by a finite literal automaton, over words of arbitrarily many letters; unbounded length by itself does not force a precision error. No rank information is presumed for this smaller controller.

To check rank as well on live prefixes, keep the entire raw transfer product modulo a large enough modulus and evaluate its semantic Hankel matrix modulo that modulus. The archived semantic basis has maximum suffix length 4 and prefix length 7, the latter including the mandatory first vertex. A sufficient modulus for exact rank decisions on the live region H(w)≤X is larger than every `r!·39^(11r)·X^r` for the tested sizes r (for testing rank-three volume, `6·39^33·X^3` suffices). A single automaton for all target values does not follow, and this finite controller gives no density or growth lower bound. It makes a fixed-height uncertain rank decidable with a chosen absolute-error budget, beyond a fixed mod-8 snapshot.

## Rank cost of the literal 8/8 residue fans

For a canonical ribbon word, include its initial vertex as the first 0 in the notation below. All ranks in this section are exact rational ranks in the after-first minimal transfer (dimension 61), not a rank over a residue ring.

* Seed (0,1,3,3,2,5) has H=25 and rank four. Appending masks 0,…,7 gives H=[25,61,43,53,103,115,95,81] and ranks **[3,3,3,3,4,4,4,4]**. Its 8/8 odd mod-16 fan spends rank for half its outputs.
* Seed (0,0,3,5,2,4) also has H=25 and rank four. Its eight literal one-letter counts are **[25,43,61,53,103,95,115,81]**: the same value set, still 8/8 modulo 16. Every one of these outputs retains rank four. Moreover every odd class modulo 32 has a two-letter representative retaining rank four at both steps. With rows ordered by residues 1,3,…,31, the respective (first letter, second letter, H) triples are (5,7,257), (7,6,163), (6,2,229), (7,5,295), (3,3,137), (3,7,107), (6,4,237), (6,3,303), (7,0,81), (6,0,115), (6,6,277), (7,4,183), (7,1,249), (7,7,219), (4,6,317), (5,0,95).

See `check_rank_fan.py`. Rank retention is not automatically retention of the image subspace; distinguish the two before iterating an absolute or modular selector. This is a finite literal residue result, not an asymptotic growth lower bound.

## An exact repeatable image refresh for the whole mod-32 fan

The sixteen selected unrefreshed two-letter outputs above have sixteen pairwise distinct image subspaces; none equals the seed's image E. This is certified by reduced row-echelon forms of the transposed semantic matrices. Merely preserving rank does let the image rotate.

There is a stronger physical construction. For the seed (0,0,3,5,2,4), put S=(0,3,5,2,4). Append three steering letters followed by this common **refresh** S. The following sixteen blocks map E **onto E** and cover every odd mod-32 residue, from this seed:

The checker verifies each entire return by exact equality of image coordinates and rank four. Since the final image is E and rank never increases, each individual letter retains rank four along any of these blocks started at E. Every finite or infinite concatenation of the displayed blocks therefore preserves rank four at every step and returns to the very same image at the block boundaries. This is a repeatable “untangle the image” mechanism, not just a favorable short suffix. There is also a simpler pure refresh (3,0,3,5,2,4), which returns E onto E and can be repeated indefinitely.

An image is not a point: returning to E need not restore the actual integer state vector or its residue. The displayed outputs prove the whole fan from the stated seed, not automatic steering from every later vector in E. Indeed, after taking the residue-1 branch, these same sixteen blocks hit only `{1,3,5,9,11,13,17,21,27,31}`; selecting one witness per original residue lost viable later choices. Checking steering in a larger block bank requires a separate finite mod-32 transition test. Nor is a return to the exact image an absolute-count or density result.

## Uniform two-block steering from every reachable return state (mod 32)

Using all three-letter steering prefixes before S, rather than just one winner per original residue, gives **168** exact image-return blocks. Their controller is an exact four-coordinate integer lattice. Select semantic pivot rows (0,2,3,4), let C be any basis of the initial image, and write D for its square matrix on these rows. For a candidate return R, compute its action on C using raw transfer lifts, and call that result Y. If Z is Y on the same pivot rows, the exact return test is `det Z ≠ 0` and `Y = C D⁻¹ Z`. The induced action on the pivot-coordinate columns is ZD⁻¹. This tests all 512 three-letter prefixes.

The pivot projections of the integer columns of the seed semantic matrix generate a lattice with Hermite basis
```
[32 14 10 27
  0  2  0  1
  0  0  2  1
  0  0  0  1].
```
The verifier checks this lattice is closed under every projected return action. In this basis the starting point is (−43,−5,4,53), and H reads out as the integer row (32,14,10,27). Reducing these integer maps modulo 32 is therefore an exact, finite controller at the return boundaries.

Exhausting the closed reachable orbit gives 524,288 states. With exactly one further return block, 523,008 states can hit all sixteen odd classes and the other 1,280 hit fifteen. With **exactly two** further return blocks, every state can hit all sixteen. Thus an arbitrary infinite sequence of odd residues modulo 32 can be scheduled at sixteen-letter block boundaries without rank loss, restoring the same image E at each eight-letter boundary. This does not prove steering at every higher modulus or guarantee any prescribed absolute H.
