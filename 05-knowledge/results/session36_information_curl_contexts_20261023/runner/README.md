# Runner-comb observability and the interval sidecar

**Scoped theorem, sharp hostile controls, quantitative stability, independently audited. LRC(14) remains open.**

The geometric object is not determined by how many measurements were made. It is determined only up to the differences that every permitted future measurement annihilates.

For danger radius 1/14, knowing the complete phase-overlap responses at speeds 1,7,...,7^(J-1) leaves exactly the zero-mean 1/7^J-periodic ambiguity. The same ambiguity survives every speed whose 7-adic valuation is below J, even an infinite bank of arbitrarily large speeds.

A component bound repairs this sharply: if one regular-closed interval carrier has fewer than 7^J components, its response is unique, even against arbitrary functions in [0,1]. At exactly 7^J components there are disjoint equal-mass carriers with identical responses; the next probe distinguishes them. The inverse is quantitatively stable in L1, with an explicit Holder bound and no endpoint-separation assumption.

Three limitations are exact, not cosmetic:

- A finite number of probe speeds with complete phase functions is NOT a finite number of phase samples. Any prescribed finite scalar sample bank misses a pair of tiny one-interval carriers.
- Forgetting the phase origin loses translates, even with every speed and one component.
- Haar overlaps cannot see isolated points. The genuine weak-safe set for speeds {1,...,13} has six isolated points and zero response to every Haar probe.
