## 1. The same primitive port survives global symmetry breaking

[The protected-port construction](ports/PROOF.md) takes three copies of
the inherited rigid eight-vertex B in a cyclic join. Protect a named root
inside the first copy; replace the second by the equal-profile A→TT1.
The global automorphism group changes from C3 to the identity, while
**every allowed marked path-cover observation and every future protected
root-child program remains identical**. The marked root was moved by the
old global rotation, so the point stabilizer and global group are kept
separate.

The construction has an explicit unbounded strong host family. For actual
host modules with H=25^n and P2=2^(10n+m), a fixed two-by-two response
matrix gives the output H and root-deletion count q. An elementary finite
modulus certificate proves the sharp primitive guard

    gcd(H,q)=1 iff m is odd and m≠n+1 (mod3).

Choosing m=4n+3+6k makes the guard permanent. The actual induced growth
n→n+1 adds twelve vertices and changes the host responses by

    (h,p)→(25h,2^14p).

The same root survives forever. Neutral recoloring can restore and remove
the global symmetry at each stage. Growth changes the marked values by
the stated rule; the neutral step preserves them exactly. Four actual
birth probes have gcd equal to the full marked content, supplying a
bounded escape from any specified odd divisor. This is not a claim that
one probe is prime or avoids every divisor simultaneously.

The late [geometric comparison](INCOMING.md#late-session312-a-neutral-return-can-leave-the-geometric-chart)
sharpens this distinction: the symmetric three-B join has an explicit
rank-two 3-adic determinant chart, while the neutral partner containing D
has none. The repair preserves the protected counting response while
leaving that geometric representation class.

A released sink w inside T has exactly two wrong incidences for migration:

    (M,T)→(TT1→M, W^d(T)→A),       arbitrary d≥0.

Every old vertex, every old-old arc, and the named exterior ports survive.
The fresh-block replacement preserves every protected marked observation.
The completed cycle can be repeated indefinitely. With the declared rigid
seed, all endpoint tournaments are globally asymmetric.

    (Wf)(t)=t f(t+1)+t²f(t)−t f(t−1),

information and unbounded observation depth; they are not just reorderings
of a fixed ordinal component bank. The graph determines its construction
address, and a proved size/count bound gives an exact finite inverse for
any target in this language.

## 5. What is still needed for the complete proof

The fixed reservoir language has at most O(Y^(1/4)) outputs below Y,
despite indefinite strong-module renewal and no common prime divisor.
The protected neutral family is deliberately3-divisible before a selective
exit. The determinant extension census is finite. These restrictions have
different causes and are not global nonattainment statements.

The remaining proof obligation is a target-dependent entry/return system
that supplies every residual prime and7p gate: it must choose new actual
module responses, carry the required marks, leave congruence fibres when
readiness needs to change, and avoid the sparse fixed-language bound.
The new constructions close the symmetry/marked-port and perpetual
physical-refill subproblems in explicit families. They do not yet close
that universal selection obligation.
