# 24:13 and 120: from a modular wheel to a physical inverse

- [Archive ledger: 24 and 13](ARCHIVE.md). The order-12 clock of 13
  at 24, B_24 and B_120 denominators, pure-A Niemeier rank, Monster
  involution sections, overlapping Pythagorean triples and doubles,
  square-sum non-onsets, and a norm-69 Pell move that fails to
  preserve the tape interface.
- [Exact all-width marked ray](ray/RAY.md). Two bounded carries give
  a four-state compressed graph for the full 24:13 language, and
  a bivariate generating function for width and signed gap.
- [Exact length and amplitude wheels](PORTS.md). For half-gap d,
  widths are exactly 12|d|+24k+38b. Every even spine width ≥408
  has a +2 edit on this ray. At a fixed width only four joint
  marked phases mod120 are possible. The exact program entropy,
  combined with H=Θ(3^n), bounds distinct absolute counts by
  O(X^0.071771).
- [An all-ratio ceiling](ALL_RAYS.md). Even if a different marked
  ratio is chosen for each target, any zero-determinant construction
  with a bounded two-port boundary gives O(X^((3/2) log_3 2))
  absolute counts up to X. This is a density-zero bound.
- [All 60 odd **count** residues mod120](COUNT_WHEEL.md).
  Every residue contains arbitrarily large physical +2 pairs
  on the same sparse marked ray. This is exact modular coverage,
  and a quantitative counterexample to treating it as absolute
  coverage.
- [Two genuine 7-free Riesel descent wheels](descent/RIESEL_DESCENT.md).
  Periods 72 and 120 select realizable prime factors for every
  exponent on explicit rays. Ordinal sum lifts the chosen quotient
  to the exact target. This only removes those rays as least-missing
  candidates, not all odd numbers.
- [Requirements and obstructions for a universal descent wheel](UNIFORM.md).
  A scalar affine rule with nonzero intercept cannot come from a
  fixed opaque substitution of arbitrary tournaments. A separate
  +2 bridge lands in the unit class 83 mod120 infinitely often,
  but only logarithmically often up to X.

Chan–Pak remains open. Next target: a physical descending row for
some of the prime and 7p lanes, with explicit state preserved under
induction. The all-ratio ceiling favors a seam that controls a
nonzero determinant instead of eliminating it. Merely covering their residues has now been shown too weak
even with exact local +2 repairs.
