# Which connections survived, and what they actually preserve

**Session237; audited partial theorems.** This is the conceptual close-out,
not a proof of Chan–Pak completeness.

## The productive common object is Q, not a shared exceptional number

The binary pair-energy Q was already a fixed-port tail arithmetic coordinate.
It is now also the positive defect H-2E-1 of a literal apex endpoint. This
supplies an actual map between the arithmetic and endpoint pictures. Keeping
Q/2 gives the normalized full-count residue automaton; keeping Q gives the
endpoint automaton. The factor2 changes the minimal memory at even modulus.

The loop closes in three directions: physical paths prove positivity and
extremality; binary recurrence gives exact finite memory; block pumping proves
all formal modular states physically occur. It still loses integer magnitude
and target occupation. The two permanent forbidden full counts survive every
fixed-modulus projection.

This is stronger than a formula analogy but weaker than a universal constructor.
The sufficient state for one operation is not automatically sufficient for a
larger operation grammar. The equal-order reroot twins demonstrate the failure
with actual six-vertex tournaments, not nonphysical integer states.

## Hostile tests that matter

- K3 embeds as a selected cycle carrier, but cannot be the full Omega because
  I(K3,2)=7. This distinguishes realizability of a pattern from exact counting.
- Every fixed-modulus arithmetic state is reachable, while full H=7 and21
  remain impossible. Congruence completeness is not target completeness.
- A rigid H=9 core has content3 at one root. Symmetry breaking is not enough.
- Two equal-order equal-interface cores have different root escape and converse
  states. An unlabelled numerical interface is not operation-complete.
- Nonsink endpoints with E=0 in a transitive tournament satisfy H=2E+1, so
  positive E must be stated in the nontrivial equality theorem.
- Normalized full count (H-1)/2 modulo M is not actual H modulo M. The fourfold
  even-modulus endpoint memory saving uses the former comparison only.

## Positive directions now specified more narrowly

1. **Root-deck synthesis.** Use the finite content certificate to prune a
   fixed-port bank's large-prime task, then retain root-resolved responses
   when adding reroot/converse operations. The new physical twins are cheap
   regression tests for any proposed quotient. No finite-dimensional closure
   under arbitrary root change has been proved here. The inherited
   [Session227 strong collision family](../session227_chan_pak_constructions_20261108/multiroot/PROOF.md),
   of size binom(2m,m) at one order and interface, is a larger future stress
   test. The present work does not establish different reroot behavior inside
   that family.
2. **Controlled completions.** Seek selected carriers whose extra-cycle
   partition sum has a bounded transfer state, rather than arbitrary graph
   embeddings. Port chains and bounded-span ribbons are inherited positive
   examples. The new corona bound quantifies what a generic embedding fails
   to control; it is not a lower bound for every unrelated reduction.
3. **Beyond endpoint extremality.** Exact half-bound equality is lacunary:
   endpoint values are powers of2. A constructive use of universal endpoints
   must operate away from this extreme face and control the growing response
   cost. No optimal formula for other endpoint values is asserted.
4. **Actual arithmetic occupation.** The minimal automata settle fixed-modulus
   memory, not unbounded integer inversion. Any complete selector still owes
   physical predecessors, absolute height and target landing.
