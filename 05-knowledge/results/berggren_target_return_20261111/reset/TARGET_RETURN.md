### Actual retained-source maps

At k1, S_1 has eight vertices in the inherited append order. Retain its
vertices(0,5,6,7), and map them to vertices(5,1,6,7) of R_1. This preserves
all comparisons. At general k, replace0→5 by the full increasing TT_k

A better retained map uses the converse of R_k. At k1 it is

    S_1 retained:       (0,2,4,5,6,7)
    converse(R_1):      (5,1,0,6,4,2).

At general k the TT_k block is mapped in reverse order, because the target

map, including the reversed internal block.

These are two different valid gauges. The better-retained map is not a
claim that S_k contains R_k in the original orientation.

## 3. A closed six-coordinate compiler for every unique-start parent

For a unique-start rooted core retain

    c=(h,e,s2,p2,e2,s3)
      =(P(1),E(1),S(2),P(2),E(2),S(3)).

Use the inherited exact tail-word polynomials L_m,D_m,B_m of FUNNELS F3.
For a tail word w of length t the entire state updates as

    h'  = L2*s2+B1*h−D1*e,
    e'  = L1*h−0^t*e,
    s2' = 2^t*s2+D2*h,
    p2' = 2*(L3*s3+B2*p2−D2*e2),
    e2' = L2*p2−e2,
    s3' = 3^t*s3+D3*p2,                         (4)

where0^0=1. The terminal singleton has state(1,1,1,2,1,1).
This follows by substituting m=1,2,3 into the inherited polynomial
identities; S(3) only needs P(2), so no further coordinate is introduced.
Consequently this is a closed exact linear compiler for arbitrary funnel
depth. Six is sufficient; no minimality claim is made.

The ready-child count is h+e2−1. The inherited unique decomposition and
rank order retain the actual class address, while(4) computes its response.
Equal six-states are not identified as isomorphic tournaments.

`funnel_six_state.py` enumerates all196417 strong unique-start parent
classes through order15, with exact integer states, and checks all609
classes through order9 independently by subset path-cover counting.
The latter count includes orders3..9. This removes the exponential subset
table from each large-rank value evaluation. It improves enumeration of
this classified slice; it does not extend A000568 itself.

## 5. A completely known growing-defect continuation

For any rooted tournament, one birth beaten only by the root maps

    (h,F,s) → (h+F−s, h+F, h−s).

Two births, marking the latest newborn, therefore map

    (h,F,s) → (h+2F, 2h+2F−s, F).               (6)

These are exact path-bijection identities, not fitted recurrences. Every
new marked root has indegree one. Starting from Q_k in(2), the first two
states have

    H0=297D+71,   b0=1;
    H1=891D+215,  b1=192D+47;
    H2=3057D+739, b2=594D+143.

At k1 this is665→1997→6853, with defects1,431,1331. All subsequent counts
and defects follow the fixed matrix(6), whose characteristic polynomial
is X^3−3X^2−X−1. The kernel grows with the iteration number, so this is
outside the older bounded-defect branching classification.

It still does not follow a prescribed+2 address. A step from defect b
exceeds3h+2 by exactly2(b−1). After j steps the surplus over the ideal
ternary target is

    2 sum_(i=0)^(j−1) 3^(j−1−i)(b_i−1).          (7)

Thus the missing requirement is explicit: remove a prescribed even
surplus at the actual current baseline while retaining a usable state.
The existence of an abstract pure-H gap is insufficient.

For the first nonzero surplus, the desired next count is2673D+647 and
the actual overshoot is3057D+739; the width is384D+92. The concurrent
arithmetic lane evaluates the known H13 pure-gap actuator at this width.
Its smallest source pair is6900D+1649 and7284D+1741, already larger than
the overshoot. Since Hamilton-path count is monotone under taking induced
supertournaments, neither whole actuator can be installed inside that
overshoot. This is a scoped baseline obstruction for that actuator family,
not an obstruction to every possible compensator.
