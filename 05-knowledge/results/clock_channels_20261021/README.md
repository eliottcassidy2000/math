# Static observers and integer clocks

[Proof](FINITE_OBSERVERS_INTEGER_CLOCKS.md) gives an explicit grounded source family with fixed literal first-descent time but unbounded odd/ROOT/primitive clocks. Exact same-register pairs show that finite static observations do not retain the complete clock. Finite alphabets with unbounded words/counters are explicitly not excluded.

Run `python3 verify_clock_channels.py` and `python3 -O verify_clock_channels.py`; compare receipts (263 checks).
