# Conditional all-size guarded packet decomposition

The central result is an endpoint-union route: in an authenticated common-
target binary supply, every accepted endpoint difference decomposes into
primitive balanced charge trades. Every changed slot switches once and no
intermediate uses a resource outside the endpoint inventories.

An elementary proof gives a group-dependent event bound of 2D(Q). For the
original order-eight Q=(C2)^4+C128 this is 264, not a native sharpness claim
and not an all-order constant. The fixed sixteen-slot primitive circuit
remains one unsplittable atom in its own pinned fiber.

A separate supply-conditional partial-sum buffer theorem explains how genuine
external charges can reduce projected support while preserving exact enlarged
guards. It does not assert such native buffers exist. The general lossless
finite-incidence encoding has a Graver decomposition, but arbitrary lattice
generators need not connect capacity-bounded fibers.

Read THEOREM.md for precise hypotheses, proofs and obstruction taxonomy, and
REFERENCES.md for primary references and inherited native scope.

## Reproduction

From any working directory, with the original math repository read-only:

    python3 -B check.py --repo /path/to/math --out normal.json
    python3 -O -B check.py --repo /path/to/math --out optimized.json
    cmp normal.json optimized.json

The checker uses only the Python standard library and no `assert` statements.
It checks SOURCE_PINS.json before the native replay and never writes into the
repository supplied with --repo. The only write is the explicit --out target.
The inherited checker is invoked in the same ordinary/optimized mode.

Finite controls include:

- Every ordered label array of lengths 0–5 for the trivial group, C2, C3,
  C4 and C2+C2, every distinct accepted endpoint pair, and every order of
  the resulting primitive atoms.
- A length-132 minimal zero-sum sequence in (C2)^4+C128, the length-131
  zero-sum-free predecessor, and their exact F2 group-algebra products.
- Read-only native replay of all twenty actual source options and all six
  inherited primitive circuits; independent primitivity checks; all forty
  normalized alternative resources; and all six orders of three disjoint
  native four-slot atoms connecting a twelve-change endpoint pair.
- A synthetic charged-buffer control built from the exact sixteen-circuit
  labels, explicitly not a native buffer existence certificate.
- Hostiles for omitted margins, omitted dyadic coordinates, owner and resource
  quotient loss, scalar versus rowwise current, coincident owner roles,
  neutral workspace, multi-target incidence, and lattice span versus bounded
  connectivity.

MANIFEST.json records this package's artifact hashes, excluding itself.
