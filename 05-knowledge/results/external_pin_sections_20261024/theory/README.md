# Conditional receiver sections and actual repair choices

`RECEIVER_BANKS.md` proves two useful operations and their routing consequence:

* incomplete compatible blocks can complete one another by a strict charge-
  support/defect bound at the SAME actual boundary and exact grades;
* one existing binary repair slot succeeds exactly when its label avoids the
  adjacent-grade hole differences;
* a complete graded receiver INSIDE the core lifts a compatible helper
  skeleton while keeping core and helper populations separately fixed.

The exact native difference certificate has32 forbidden labels. All eight
existing outside-core sources avoid them; five have switching cost3. This
supports three fixed cheap core records plus up to seven additional fixed
outside-core records, provided one repair remains free. The resulting
receiver routes retain every actual endpoint:20 slots/52 or53 clocks in the
complete interior band,20 slots/85 clocks on every nonempty boundary fibre.
These are finite-native applications of the conditional all-size theorem,
not all-order native supply results.
