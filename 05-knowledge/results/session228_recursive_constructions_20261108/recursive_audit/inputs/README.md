# Recursive cyclic compiler

Canonical packet: PROOF.md, verify.py, CHECK.json, CHECK.optimized.json.
The proof gives an exact target-bounded algorithm for unrestricted recursive joins and binary singleton-cycle substitutions from a finite physical seed bank. The finite packet uses every tournament through order five and target 4095. It is not a Chan–Pak proof or an unrestricted coverage improvement.

Normal and optimized verifier outputs byte-match. `explore.py` and `test_seed.py` are exploratory provenance only; the canonical verifier imports neither.
