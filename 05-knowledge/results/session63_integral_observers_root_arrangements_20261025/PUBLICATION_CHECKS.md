# Verification and publication scope

The packet has three distinct evidence layers: separately stated proofs;
declared finite exact universes; and mechanical byte/reproduction checks.
Passing the last two is not a proof of an unstated all-parameter theorem.

## Source and audit integrity

`FIRST_SOURCE_VERIFICATION.json` records every copied source and its exact hash.
The cancellation auditor's receipt pins the producer's final mathematical text
and scripts. The twist auditor's `AUDITED_SOURCE_SHA256.txt` pins the revised
finite-field motive hostile and the separate characteristic-zero analogue.
All native checksum files are preserved. The README maps historical scratch
paths to package paths without changing audited proof bytes.

## Frozen replays

The publication replay runs seven substantive scripts in separate ordinary and
optimized copies, requires exact saved stdout and paired stderr, rejects bare
Python assertions, and requires every packet byte to remain unchanged. The
source-parsed cancellation audit uses the explicitly pinned repository files.
The independent projective P6 census uses the copied recovery histogram through
its explicit `--reference` argument; no producer code is imported by that audit.

The exact replay receipt is added after the runs finish. Native checksums,
Markdown links, UTF-8, whole-file-set integrity and optimization-safe negative
controls are checked separately. Current receipts, not this workflow description,
establish which runs actually completed.

## Remote publication

Only explicitly owned paths are staged. Publication freezes the local parent,
whole tree, path set, blob hashes and modes, then uses an expected-head update
without force. Independent Git fetch verifies the published tree and exact
bytes afterward. Incoming packets, byte-zero truth banners and documentation
budgets are preserved. Exact-commit CI is inspected separately; absence of CI
is never called a passing check. Remote receipts live in the publication work
area until a later checkpoint can include them without self-reference.

successful ordinary/optimized executions. Every saved stdout matched exactly,
paired stderr matched, and all frozen source bytes were unchanged. The
source-parsed provenance check and independent projective census are included.

The exact file-set verifier rejects both byte mutations and extra files in
ordinary and optimized mode (`FIRST_FILESET_NEGATIVE_CONTROLS.json`). The
bundle receipt checks UTF-8, native checksums, assertion-safe scripts and local
links. These are verification claims, not a claim that remote publication or
CI has already completed.
