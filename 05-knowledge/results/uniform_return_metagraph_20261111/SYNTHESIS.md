## 3. A canonical classification for every fixed branching defect

For a strong rooted tournament set I=N^-(r), d=|I|>=2,
R=T-({r} union I), and b=F_r(2)-H(T). Tagged positive exposure capacities give

    b >= (2^d-2) H(R).

Thus d and the nontrivial strong SCCs of R are bounded at fixed b, even while
H(T) and order grow. The stronger conclusion is now a canonical decomposition:

* P is the maximal initial residual SCC prefix whose vertices all beat I.
* The remaining coloured tail W, including I but excluding r, has bounded
  order depending only on b.
* P is nonempty exactly when q=s. Every nonneutral stratum is finite at
  fixed b; in particular every odd branching-defect stratum is finite.

The new bound on the tail comes from actual tagged five-cycles. An ordinary
singleton after any bad contact creates a distinct positive atom; it cannot
be repeated without increasing b. The only unlimited freedom is therefore
the initial prefix's transitive gaps. This proves more than finite-state
recognition. [Canonical dyadic classification](arithmetic/DYADIC_DEFECT.md).

For each bounded tail and ordered nontrivial prefix core list, put
h=product H(P_j), Q*=product Q_(P_j)(2), and let m be the total number of
singleton prefix vertices. There are explicitly computed E>0, q0 and C with

    b=hC,       H(T)=E Q* 2^m+h(q0-C).

If there are c nontrivial prefix cores, the exact number of rooted classes
at that m is binom(m+c,c). All gaps and automorphisms are retained. The group
is Aut(W,I) times the product of the prefix core groups, independent of m.
Thus fixed-defect class counts are eventually polynomial, and their scalar
Hamilton spectra are finite unions of dyadic rays plus finite exceptions.

The whole seven-coordinate rooted interface depends on the prefix only
through(H(P),Q_P(2)). Moving transitive gaps or permuting prefix cores therefore
preserves every common O/Z/J continuation and fixed rooted-amalgamation
context, while generally changing the actual source class. A physical
one-arc S5a-to-S5b switch inside such a prefix preserves all seven coordinates
and every other arc. This supplies a genuine operation linking the five-core
bank to the canonical families; arbitrary core permutations are not claimed
to have a neutral physical implementation.

This gives a concrete obstruction to a tempting proof route: a fixed bounded
branching-defect bank represents only O(log X) distinct values below X. A
general Chan–Pak proof must use the d1 stratum, increasing defect, or operations
that leave such a bank. The theorem neither rules out those possibilities nor
asserts that the arbitrary associated exponential Diophantine equations are
already solved.
