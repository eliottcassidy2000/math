## 2. A two-integer normal form for every fixed block

Write D(n)=(f(n)-1)/2 for the incoming digital function. Explicitly,

    D(0)=0,

Let a fixed nonempty marked block have actual profile(H,E,p,q,s,t,F_B), with the same conventions as the previous packet. Then its full raw-H image under arbitrary singleton contexts is exactly the set of values

    Q_B(x,y)=F_B+(p+Ey)x+qy
             +(H-s)(x mod2)+(H-t)(y mod2)

**Proof and actual reconstruction.** Start from the fixed source(F,q,g,h)=(1,0,0,1). A chronological prefix whose binary value is x has state(f(x),x,x mod2,1). Apply the actual block. Its new coordinates are

    F0=H*f(x)+px+(H-s)(x mod2)+F_B-H,
    q0=Ex+q,    g0=H-t,    h0=H.

The incoming singleton formula for suffix address y gives F0+q0*y+g0*(y mod2)+H*(f(y)-1), which is exactly(1). Conversely reconstruct the prefix from the ordinary binary digits of x and the suffix from the complemented digits of y, least significant first. Both are actual vertex additions.

## 4. An independent port audit beyond subset-DP size

Given actual adjacency and k named feedback vertices whose deletion leaves a transitive order, enumerate the k! possible orders of those ports. For each order assign chain vertices to its k+1 gaps. A gap records whether it is empty, or whether its last chain vertex can reach its right port. On its first chain vertex, enforce the left-port edge. Increasing chain order supplies every internal chain edge. At the end reject bad last vertices and empty internal gaps whose consecutive ports lack an edge.

This is a bijection with Hamiltonian vertex words: every such word has one port order and one gap assignment; every accepted assignment is a full directed path. The resulting arithmetic-operation bound is O(k!*3^(k+1)*(k+1)*n), with growing integer bit costs. This is a direct bounded-feedback counting method, not a claimed new general complexity result.

Removing local vertex0 from D leaves a transitive triple. Our one- and two-D words therefore have two and three marked feedback ports respectively, including the external vertex. `audit_port_words.py` verifies the actual remaining order, rather than assuming it from a numerical profile. It agrees with ordinary subset DP on all1099 labelled nonempty tournaments through order5, checks all six new target witnesses, and checks112 long physical words through66 vertices. The largest tested count is36893708471144335229, so the Python audit's exact integers also avoid a silent64-bit overflow boundary.
