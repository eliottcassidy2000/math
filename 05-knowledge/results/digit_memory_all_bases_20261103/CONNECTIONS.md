Formally, for a source set X, allowed partial operations and an observer O,
adjoin a failure state and declare x~y when every allowed future word has
the same observed response. This is the largest operation-stable equivalence
contained in equality of the present observation. The proof is to prepend
one allowed operation to each test word. This inherited contextual principle
does not bound the size of the quotient: DM2 is finite, DM3 can require a
valuation register or the whole integer, and TM1 can hide arbitrarily many
bits from a full unpointed profile.

Weighted sums are safe only when the future consumer is constant on each
class or the full conditional response is retained. Cardinalities alone do
not justify equal weights, independent digits, or source-specific positivity.
