## A. The useful common principle is equality at the consumer interface

Source: redundant grid choices. Target: rectangle choices. Map: rho,
with explicit zero-padding section j. Preserved predicate: every
future function of the child clique table, with named assignments fixed.
Destroyed information: unused raw choices. Sidecar: the original grid,
row/column order, grouping rule, widths and recursion depth. Decisive
test: `nextT_same_on_fibres`, now kernel checked at every allowed size.

This is stronger than testing many observables. It proves equality of
the object they all receive. It is also weaker than claiming a globally
smallest carrier: distinct rectangle choices can still produce equal
tables on special inputs. No uniform further quotient is proved here.

The inherited Fano calculation distinguishes an eight-state legality
carrier from a128-state weighted branch carrier. The present quotient
preserves the weighted table, not just its legality. This explains why
discarding nonrectangle choices is justified while discarding crossing
signs is not. The comparison keeps distinct moduli and signs; it does
not identify the Fano syndrome with the rectangle choice space.

## B. A producer can fix an information loss that a decoder cannot

The map c -> P2^E c modulo3 can be constant when3 divides P. No
clever inverse can recover c from that constant reading. Removing
the unused choices before evaluation yields a different reading
2^E c modulo3, which distinguishes a Boolean count immediately.

The important ordering is therefore:

    identify semantically duplicate branches;
    preserve their exact weights and intended normalization;
    compile the quotient;
    choose modular observers using the new prime support.

For weighted tournament enumeration, fibre sizes are often genuine
stabilizer or source multiplicities, not artificial padding. They remain
in the quotient weights. A000568 cannot use the factoring normalization
unless a corresponding exact counting identity is established. Source
names and shared-port correlations are the things that decide whether
the fibre is artificial.

## C. What the recent circuit improvement actually suggests

Mishra--Santhanam's October19 primary preprint states a3.5n-O(log n)
full-B2 lower bound. Its new organizing device is substitution in an
underlying space of independent parameters, dynamically reparameterized
as the elimination proceeds. [Primary paper](https://eccc.weizmann.ac.il/report/2026/260/download),
Theorem1.1 and Section1.2. This is a cited preprint, not a proof audited
in full in this session.

The common theme with R1 is to work in the coordinates actually used
by the next operation. The mathematical directions differ: R1 removes
duplicate computation for an upper bound; gate elimination charges
unavoidable lost gates for a lower bound. An affine change of coordinates
in an analysis is not automatically a free circuit implementation.
That boundary is made explicit by incoming Session117's
[affine-geometry audit](../session117_ramsey_circuit_interfaces_20261030/affine_ramsey/AFFINE_RAMSEY_GATE_GAP.md).

The same session's
[potential-frontier theorem](../session117_ramsey_circuit_interfaces_20261030/challenge_audit/POTENTIAL_FRONTIER.md)
classifies the provisional three-weight row template exactly:

    0<=c<=4,   b>=max(c,2c-2,4c-7).

At coefficient4 the smallest permitted dimension penalty is9. This
is an algebraic theorem about a specified set of inequalities, not a
certification of a4n circuit theorem. An improvement needs a stronger
deletion estimate, a richer state, or a proof that adverse rows cannot
occur in arbitrary combinations on actual shared circuits.

Concrete next experiment: expose two shared boundary gates, enumerate
small **acyclic shared DAGs** realizing consecutive worst rows, and keep
the affine input map plus which output wires coincide. Reject a proposed
quotient immediately if one continuation separates its two states. A
finite success would yield candidate joint invariants; an all-size
coverage theorem would still be required. We do not replace DAGs by
formulas, charge shared gates twice, or extrapolate a finite census.

The recent point-defect family is already ruled out as a hardness
amplifier: incoming Session117 proves exact costs at most2n-2. The
concurrent equality-function example also shows exponential residual
rank with only linear gate cost. These close two tempting routes and
focus attention on actual gate-elimination structure.

## D. Algorithm-to-proof transfer must preserve the input clock

The incoming [Circuit Interfaces B1--B2](../ramsey_circuit_interfaces_20261030/CIRCUITS.md)
give a shared-wire B2 circuit a3-CNF encoding with exactly n+s variables
and at most4s+1 clauses, with a unique internal-wire completion for each
accepted n-bit input. This is a valid counting bridge. A subexponential
bound in the enlarged n+s encoding is not automatically a useful
saving in n for every polynomial circuit size. The same warning applies
to interpreting the newer factoring entry as a solution of ETH or a
general lower-bound theorem.

The rectangle adapter is compatible with the unique-completion idea:
it removes auxiliary *choice padding*, then leaves the actual encoded
witness count untouched up to its proved binary scale. It does not
establish a generic fast3-CNF counter. Any such use needs a correct
top-level network embedding and full cost analysis.

## E. Toward LRC and Collatz: one rigorous transfer and one firm boundary

For a fixed finite universe of source histories, a proved weighted
fibre quotient can reduce a verification sum while preserving every
named target response. The same proof as R7 applies if histories in a
fibre have identical future response tables, with the original source
weights aggregated rather than removed. Signed internal contributions
remain signed.

This can accelerate a finite exact certificate. It cannot show that
all LRC speed sets enter a certified family, or that every positive
Collatz source reaches a terminal state. A purported quotient that
forgets source phase, clock or a zero-measure exceptional target does
not satisfy the required equality. The cheap hostile test is an actual
pair of sources with the same proposed code and different next target
responses, before considering any average estimate.

The returned result is therefore a reusable, formally checked
normalization move, plus a precise compiler obligation. No general
open problem is being claimed solved by analogy.

## Late incoming comparison: a real LRC attachment compiler

Commit3c1180551a supplies an independently developed
[complete phase-cover rule](../terminal_fees_phase_covers_20261030/LRC.md).
For a fixed core safe set with intervals[L_i,R_i], a prescribed positive
speed v succeeds exactly when some component satisfies
`v(R_i-L_i)>=g_r({v L_i})`, where g_r is the forward distance to the
next safe phase. Its O(k) rational-operation query avoids enumerating
O(v) teeth. We read the proof; its finite tests were not repeated here.

This is a concrete second instance of replacing redundant enumeration
by a proved consumer interface. The distinctions are useful: its
complete intervals retain point components and actual phase, while
our rectangle section retains the entire next table. The LRC Boolean
answer for one attachment cannot compose two attachments; its true
joint safe set must remain available. Thus a minimal carrier for one
query may be strictly smaller than a carrier closed under composition.
This incoming result reinforces R4's choice to retain the full boundary
function. Core preprocessing and arbitrary-core coverage remain open
obligations, just as compilation and global time costs remain here.
