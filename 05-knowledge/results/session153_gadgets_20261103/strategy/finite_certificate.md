# Finite residue certificate for a multi-interface induction

Status: an elementary conditional reduction, not a tournament spectrum theorem. Its value is to separate the arithmetic check (finite) from the substantive graph construction (not supplied). It permits different gadget moves by residue and several interface types rather than a single uniform wrapper.

Let S be a finite set of interface types. For each s in S, let N_s be an odd positive integer. A witness of type s is a finite tournament with a specified port structure, and its value H is its actual directed Hamiltonian path count. For a finite directed multigraph on S, assign to each edge e: s -> t integers a_e >= 2 and b_e. The *graph-theoretic input* is a proved constructive operation on every type-s witness with odd H >= N_s, producing a type-t witness with H' = a_e H+b_e. Explicit output port structure and counts, including all orphan paths, are necessary. This is not assumed to follow from scalar H alone.

Set L=lcm_e(2a_e). Choose odd K at least every N_s, every a_e N_s+b_e, and strictly greater than every b_e/(a_e-1). Suppose, independently, that:

1. For every type s and every odd n with N_s <= n < K, a type-s witness of H=n is explicitly certified.
2. For every type t and odd residue r modulo L, there is an incoming edge e:s -> t such that r is congruent to a_e+b_e modulo 2a_e. (In applications one may use different target types or restricted residue sets, but closure of all inverse descendants must then be shown.)

Then every odd n >= N_t has a type-t witness, for every type t. Proof: strong induction simultaneously on n. The base is (1). For n>=K, choose e by (2). x=(n-b_e)/a_e is an odd integer; K>=a_e N_s+b_e implies x>=N_s. The strict bound on K gives x<n. The induction hypothesis supplies a type-s witness of H=x, and the verified e-gadget produces the desired type-t witness at n. The residue test is finite: inspect L/2 odd classes for each type, and verify K by integer arithmetic. Even r need not be considered. If some b_e is negative the same proof works; n odd and the displayed congruence guarantee odd integral x. The certificate is noncircular only when the seed witnesses, port definitions, and graph operations are proved independently, not postulated as scalar-spectrum facts.

Arithmetic-only illustration: one interface, N=23, K=71, three maps x -> 3x-2, 3x, 3x+2. Their output residues cover 1,3,5 modulo 6, respectively, and all inverse targets of n>=71 are odd, at least 23, and strictly smaller. Thus explicit witnesses for the 24 odd values 23 through 69 plus three valid graph operations would prove all odd counts >=23. This is a *conditional illustration*: no such operations are asserted. In fact the maps cannot hold on all odd witness counts starting at 1: 3x-2 at x=3 would yield forbidden count 7. Interface/domain guards are therefore essential, and a proof from restricted seeds cannot be obtained by suppressing the small forbidden cases.

The THM-4094 prime-lane reduction remains a separate potential shortcut: one may prove witnesses only for p !=7 and 7p with p !=3. A residue transition that descends to an arbitrary odd target cannot assume that parent belongs to either prime lane. It either needs witnesses in a larger closed auxiliary language (as above), or a separate proof that the chosen inverse remains inside the two lanes; primality is not preserved by generic affine inverses. Congruence coverage, finite checks, and observed large intervals alone do not supply this closure.
