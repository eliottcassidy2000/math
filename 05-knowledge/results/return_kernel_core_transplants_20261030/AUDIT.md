## Exact connection contracts

1. **Actual affine returns -> additive kernel.** At an identity return
   modulo5^e, map(1+5^e alpha,5^e beta) to(alpha,beta). It preserves the next
   identity predicate and chronological composition modulo5^(e+1). It loses
   higher-order commutators: for e=1, affine maps(6,0) and(1,5) commute
   modulo25 but their products have translations30 and5, different modulo125.
   Thus this is a one-level quotient, re-created from native excursions at
   each lift; no fixed25-state all-depth observer is asserted.
2. **Kernel -> paid clock.** Map(alpha,beta) to(-alpha mod5)/5. Exact target
   detection still uses both coordinates, but a non-one fee1 covers every
   possible transition, while the actual all-one increment(4,4) costs1/5.
   The potential proves an upper bound. It is not an exact return decoder.
3. **Core -> certified chamber.** Map the complete lower envelope to its
   maximum, rational centers, fastest descending owners and first corner
   level. It preserves every safe point above that level. A bare maximum
   or a bare list of slopes omits the horizon and is insufficient.
4. **Chamber -> recursive native speeds.** The recurrences in LRC.md retain
   every original constraint and construct new integer speeds. The map
   preserves exact maxima and their marked sides under its guards. It does
   not solve the reverse problem of placing prescribed arbitrary speeds in
   this constructor.

  integer Collatz trajectory has reached1. Finite words preserve their
  original source cylinder and integer clock. No Haar or average argument
  occurs in the new lifting proof.
- Lower-layer charge resets only where the actual preceding affine map is
  identity modulo that precision. The next digit remains in F_5^2, and the

  identity is not charged; the unfinished suffix has no next-layer return.
  All-one primitive blocks have exactly T_e letters, fee1/5, increment(4,4).

  endpoint pairs. Their telescoping pays arbitrary chronological switches.
  The E9 two-clock margin is greater than1, so it supplies the required
  non-one fee at e=9 without any finite search at that level.

  It is below1, blocking naive repetition of the same lifting argument.
- The E11 reduction keeps native minima, possibly infinity. Positive
  per-clock cost bounds a minimizing word's clock, so every finite infimum
  is attained. Concatenating actual minimizing words proves necessity;
  cutting the actual word proves sufficiency. Nine short families remain

## Independent finite certificates and controls

`excursion.cpp` is a producer. For each e=1,...,4 it solves the finite
first-return problem on affine states modulo5^(e+1), retaining whether a
non-one has occurred. Kernel endpoints are absorbing, so paths are primitive.
It writes25 costs, literal minimizing words, and a generated lower-bound
potential. Certificates are independently verified by `audit_excursion.cpp`,
which uses repeated exact modular halving and a separately tabulated valuation,
rather than the producer's inverse-power update and height loop.

Every allowed edge must satisfy h(target)<=h(source)+cost. The root value is0;
all reachable non-one states must have finite potentials. Endpoint costs are
therefore lower bounds for every first-return path. `audit_kernels.py` then
replays every minimizing word using unbounded integer P,Q,B and actual gcd
valuations, establishing the matching upper bounds. These are exact minima
over all lengths, not best values found below a clock cutoff.

The verifier proves all omitted letters by

    min(h)+N(cutoff+1)-D*e >= max(h,endpoint costs),

with D=8*5^(e+1), N=5*5^(e+1)-5. A larger omitted letter is more expensive,
whatever its residue. In particular a large non-one congruent to1 is never
mistaken for the exceptional letter1. A corrupted reachable potential is
required to be rejected. Generated `.dist` files are not committed; their
SHA256 hashes and edge counts are in `kernel_audit.json`.

at levels1–4, plus their infinite-letter tails. There are100 full-integer
