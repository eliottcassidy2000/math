# Independent audit: self-converse pointing identity

Status: PASS for even n≥2; the n=0 endpoint needs a separate one-line argument.
Session30,2026-10-22. This audit does not claim literature novelty.

## Mathematical directions

The score-completion map is an isomorphism-equivariant bijection between
almost-regular tournaments on a labelled even set and regular tournaments on
that set plus a prescribed new vertex. Any ordinary or converse isomorphism
extends uniquely by fixing the new vertex, because its incident arcs are fixed
by the old score defects. Conversely restricting a root-preserving ordinary or
converse isomorphism gives the corresponding map of the deleted tournament.
Thus unlabelled classes correspond to rooted regular classes, not unrooted
regular classes in general.

For a tournament on at least two vertices, ordinary and converse automorphisms
are disjoint sets. Its ordinary automorphism group G has odd order: Cauchy's
theorem would otherwise produce an involution, and a swapped vertex pair would
have its oriented arc reversed. For a self-converse tournament, the extended
group has order2|G|. Its Sylow2 subgroups have order2 and are generated by
anti-involutions. Sylow conjugacy, replacing an odd-coset conjugator h by hτ
when necessary, proves conjugacy under G itself. An anti-involution on an odd-order tournament
has exactly one fixed vertex. Therefore these fixed vertices form one G-orbit.

If any anti-automorphism fixesv, its order is2m with m odd, and its m-th power
is an anti-involution fixingv. Consequently exactly one rooted class of each
self-converse odd tournament is self-converse. A non-self-converse tournament
has no such rooted class. This proves the proposed bijection, including both
directions and the necessary loss of ordinary root multiplicity.

At n=0, the completion has one vertex and the identity is both an ordinary
and a converse automorphism. The permutation-set construction of G± is not a
disjoint union and does not literally have twice the size. The counting claim
still holds: both families contain one object. Treat this case separately.
This minor boundary repair does not affect any positive-order result.

## Independent exhaustive control

The supplied complete bank contains15 regular order9 classes and85 almost-
regular order8 classes. Its completeness was certified in the separate
session30-loop-audit packet by canonical labels and exact automorphism mass.
Here audit.cpp imports no producer code. It enumerates every vertex permutation
of each representative:15·9!+85·8!=8870400 permutations in all.

For each representative it tests ordinary and converse preservation directly,
counts the anti-involutions, records their fixed vertices, and builds the full
ordinary-automorphism vertex orbits. It verifies:

- ordinary and converse group sizes agree whenever the latter is nonempty;
- converse maps exist if and only if anti-involutions exist;
- every anti-involution has exactly one fixed vertex in odd order and none in
  even order;
- the fixed vertices occupy exactly one automorphism orbit for every regular
  order9 representative;
- the15 regular order9 classes have85 vertex orbits in total;
- all15 regular order9 classes are self-converse;
- exactly15 of the85 almost-regular order8 classes are self-converse.

Thus the restricted converse-merged class count is(85+15)/2=50. This count
uses an involution acting on the set of isomorphism classes. It does not assert
closure of these classes under fixed-Hamilton-path nonspine complementation,
and it determines neither edge multiplicities nor complete metagraph wiring.

## Reproduction

Compile and run from this directory:

    g++ -O2 -std=c++17 audit.cpp -o audit
    ./audit < bank.txt > permutation-results.txt

The compiled binary is not a publication artifact. bank.txt records the exact
input bits. permutation-results.txt columns are order,bits,Aut count,anti count,
anti-involution count,vertex-orbit count,admissible-fixed-vertex-orbit count.
receipt.json records the aggregate checks and scope.

## Additional from-scratch small control

small_control.py generates all labelled tournaments of orders2,3,4,5 directly,
filters for the appropriate almost-regular or regular scores, and canonicalizes
under all vertex permutations. Each order has one isomorphism class and that
class is self-converse. Orders2/3 have labelled counts2/2; orders4/5 have24/24.
This corroborates both pointing and labelled completion without using any
producer input. Run python3 small_control.py after compiling audit.cpp.
