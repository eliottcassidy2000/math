## 0. Blind derivations (before reading the proofs)

* **Theorem 1(a).** `s(2^a m) = (2^(a+1) - 1) sigma(m) - 2^a m` with the first term of valuation `v_2 sigma(m)` (the cofactor `2^(a+1) - 1` is odd) and the second of valuation exactly `a`. Three cases: `v_2 sigma(m) < a` gives `v_2 s = v_2 sigma(m) <= a - 1` (lost); `> a` gives `v_2 s = a` (kept); `= a` gives `v_2 s >= a + 1` (strengthened). Proved.
* **Theorem 1(b).** For odd `p` and odd `e`, `sigma(p^e) = (p^(e+1) - 1)/(p - 1)`; lifting the exponent (`p` odd, `e + 1` even) gives `v_2(p^(e+1) - 1) = v_2(p-1) + v_2(p+1) + v_2(e+1) - 1`, so `v_2 sigma(p^e) = v_2(p+1) + v_2(e+1) - 1`. For even `e` the sum has `e + 1` odd terms, hence is odd. Multiplicativity adds the contributions; each odd-exponent prime contributes at least `1`. Proved.
* **Theorem 1(c).** `a = 1` is lost iff `sigma(m)` is odd iff `m` has no odd-exponent prime iff `m` is a square. Odd squares in `[N/2, N)`: `(sqrt N - sqrt(N/2))/2 + O(1)`; odd `m` there: `N/4`; ratio `2(1 - 2^(-1/2)) N^(-1/2) = (2 - sqrt 2) N^(-1/2)`. Proved.
* **Theorem 1(d).** Loss needs `v_2 sigma(m) <= a - 1`, hence at most `a - 1` odd-exponent primes, i.e. `m = q r^2` with `q` squarefree, `omega(q) <= a - 1`. Summing Landau's `pi_k(x) ~ x (log log x)^(k-1)/((k-1)! log x)` over `k <= a - 1` and over `r` (split at `N^(1/4)`: for `r <= N^(1/4)`, `x = N/r^2 >= N^(1/2)` so `log x >= (log N)/2` and `sum 1/r^2` converges; for `r > N^(1/4)` the trivial `sum N/r^2 = O(N^(3/4))`) gives `O_a(N (log log N)^(a-2)/log N)`. The exponent `a - 2` is right (`k = a - 1` is the dominant term). Lower bound at `a = 2`: `m = p r^2`, `p ≡ 1 (4)`, `p` not dividing `r`, has `v_2 sigma(m) = v_2(p+1) = 1`; already `r = 1` gives `≍ N/log N`. Proved. Blind extra: the same construction with `q` a product of `a - 1` distinct primes `≡ 1 (mod 4)` shows the bound is **sharp for every** `a >= 2`.
* **Proposition 2.** `v_1 = 1` iff `3n + 1 ≡ 2 (4)` iff `n ≡ 3 (4)`; then `n' = (3n+1)/2 ≡ 3 (4)` iff `3n + 1 ≡ 6 (8)` iff `n ≡ 7 (8)` (`3^(-1) ≡ 3 mod 8`). In general `v_1 = k` iff `n ≡ 3^(-1)(2^k - 1) mod 2^(k+1)`, one odd class among `2^k`, so the law is geometric of ratio `1/2` on every residue system, whence the size-free statement. Proved.
* **Proposition A.** Birkhoff for the stationary ergodic sequence `log_2 3 - v_l` (integrable, or nonnegative-part argument if `E v = infinity`, which still gives slope `-infinity`). The keep-or-refresh chain: for any law `pi`, `(pi P)(w) = p pi(w) + (1-p) 2^(-w)`, so `pi P = pi` iff `pi = geometric(1/2)`; the chain is irreducible, aperiodic, regenerative, hence ergodic; started from a geometric draw it is stationary. Proved.
* **Proposition B.** Product of independent survivals; `prod(1 - p_k) > 0` iff `sum p_k < infinity` *provided every* `p_k < 1`; `sum c (N_0 r^k)^(-1/2)` geometric, `sum c/(log N_0 + k log r)` harmonic. Proved with that proviso.
* **Tenth note, Proposition 1.** With `m_(j+1) = (3 m_j + 1)/2^(v_j)`, the identity `2^(D_j) m_j = 3^j n + sum_(t<j) 3^(j-1-t) 2^(D_t)` holds with `D_j = v_0 + ... + v_(j-1)` **cumulative**; with per-step valuations it is false (`n = 7`: `A_2 = 63 + 3 + 2 = 68 = 2^2·17`, valuation `2 = 1 + 1`). * **Tenth note, Proposition 3.** `U(2^(K+1) t - 1) = 3·2^K t - 1`, so `U^j(m) = 3^j 2^(K+1-j) t - 1 ≡ 3 (mod 4)` for `j < K`; `U^K(m) = 2·3^K t - 1 ≡ 1 (mod 4)` iff `t` odd (else the run continues). ## 4. Overclaims and attributions

* Literature: Erdős 1976 (one-sided) versus EGPS 1990 (two-sided) is stated the right way round as far as the auditor's own recollection goes; Landau's theorem is the right attribution for fixed `k` (Hardy–Ramanujan is only needed for uniformity in `k`, which is not used); Davenport 1933 and Deléglise 1998 are cited for exactly what they give. No misattribution found. All literature statements remain recollections, as both notes flag.
* "PROVED elementary" for Theorem 1 overstates (d), which uses Landau's theorem.
