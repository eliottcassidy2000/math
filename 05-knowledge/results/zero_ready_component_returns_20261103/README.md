## A procedural inverse rather than a word-length cutoff

The new grammar appends either a sink or a vertex beating only the retained
mark. Eight integer coordinates close under these two operations. Encoding
the zero positions of a nonempty word by an integer r turns the exact
target condition into

    K r + q(a(r)-1) + d(r mod 2) = D,
    max(1, ceil((D-d)/(K+q))) <= r <= floor(D/K).

The coefficients are explicit functions of the actual seed and prefix
clock; a(r) has a short binary recurrence. Every positive r decodes to
exactly one word ending in zero. Thus the inverse is complete for every
word length and clock in each specified seed family. Every accepted
nonempty-word witness satisfies `order <= floor(log2 H)+3`.

The small inherited seed bank has 219 eight-coordinate keys, each retaining

seeds is not a finite bank of output components, because the appended words
have unbounded length. See [proof and first returns](inverse/NOTE.md).

## The remaining proof obligation

Assuming a target-acceptance lemma makes the bridge to our methods precise:
for each required actual source and each offset, produce an accepted
reader witness with enough vertices for all old names and the declared
port roles. The complete inverse finds its word; the native compiler then
transports the actual source to that actual witness. The finite tree
verifies this implication three times along every branch. What is missing
is a constructive acceptance/reentry theorem for an unbounded seed grammar,
with the joint attachment conditions available at the next step.

Even arbitrary-depth closure from this one seed would not by itself prove
the spectrum: these two affine branches omit one residue class modulo 3,
and prime/7p targets need not have predecessors in the same lane. A complete
proof must additionally supply a terminating reduction and entry coverage
for the required prime and 7p targets. Exact spectrum coverage, if assumed
as an axiom, does not prove these stronger named-source conditions.
