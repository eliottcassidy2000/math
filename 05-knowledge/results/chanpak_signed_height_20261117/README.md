# Signed height selection: change the state, then change the source

The earlier [three-letter bank](../chanpak_pubsub_branching_20261117/PROOF.md) kept one arc reversal worth exactly two Hamiltonian paths, but only on a narrow progression. This packet draws on old Stern–Brocot and Berggren ordinals, Zeckendorf registers, toothpick self-similarity, turnpike, aliquot affine elimination and taxicab boundary work to separate the information needed for scale from the information needed for the repair.

1. [Change the invariant](root/PROOF.md). Use all signed lines (2^i+1)h−R=1, i≥2, and a literal migration to climb one line or jump down any number of levels. The address is determined by an exact digit-defect calculation. A different strong finisher on every line makes the original source reversal add exactly two. The entire line-changing grammar still supplies at most O(X^(1/6)) counts up to X.
2. [Decode the height](invariant/PROOF.md). A shifted two-adic valuation says which line was used, whether the last step climbed, and what the previous line was. Thus a target can recover its word without a forward census. There is also a small independent binary grammar on 5h−R=1 and a binary subgrammar at every new line.
3. [Change the source](source/PROOF.md). Literal changes to the source give new phases while preserving the arc repair. The proof identifies why one uniform inflated port, or a paired transitive inflation of equal widths, cannot play that role. A distinct Mersenne-sign line also admits a different repaired source.
4. [Translate a target into its source fiber](archive/PROOF.md). The determinant-one coordinate J=4H+5P₂ makes N and J a lossless address of (H,P₂), with physical guard conditions. The exact inverse for changing extreme-back-edge sources is a separate comparison, not an exact +2 family.

The critical distinction is that changing the signed invariant moves the scale, but cannot change the phase class of a fixed source: that particular source is confined to 3923 mod 19428 for every exact +2 two-coordinate reader. New sources escape that modulus but their profiles have not been selected for arbitrary targets. Chan–Pak remains open.
