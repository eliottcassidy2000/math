# Mixed visibility depths and the shared-port edge-cover rule

This extends HIERARCHICAL_KERNELS.md on the same named-cell carrier. The vertex set, exact internal groups W_k and actual owner meanings are unchanged. The extension proves arbitrary-depth compatibility and observation counts; global regularity and a prescribed path require the additional guards below.

## 1. Exact mixed-depth chart group

Allow a depth l_ij in {0,...,k} for each pair of cells, with the equality-prefix block B_(l_ij) or its complementary transpose according to the chosen outer orientation. Depth zero means a uniform block and imposes no chart relation.

For d=0,...,k-1, let G_d be the graph on ALL named cells with an edge ij exactly when l_ij>=d+1. Include isolated cells when counting its components; write c_d=c(G_d).

An element g of W_k has a unique local rotation a_g(w) in F3 at each INPUT prefix w of length d<k. Its output digit at that node is input digit plus a_g(w). These coordinates are independent as a parameterization; their composition is not coordinatewise addition, since the first map transports the prefix used by the second.

Two maps have the same depth-l restriction exactly when their a(w) coordinates agree for every input prefix of length <l. Thus every coordinate at depth d must be common across each component of G_d, and there are no further restrictions. The exact compatible named-cell chart group therefore has order

    |H|=3^( sum_(d=0)^(k-1) 3^d c_d ).

This formula counts a group with semidirect composition, not an abelian group guessed from its order. The nested graphs G_0 superset ... superset G_(k-1) retain the shared upper-frame constraints.

Its minimum actual-owner pointwise base is exactly

    b(H)=3^(k-1) c_(k-1).

Indeed full-resolution components are precisely components connected by depth-k blocks. Their entire charts must coincide. For every such component and every bottom prefix, simultaneously rotating that bottom triple in its cells is an actual independent group element; partial-depth blocks cannot detect it. This forces one owner for each pair

    slot = (full-resolution component, bottom prefix).

Conversely, one owner for each bottom prefix in a representative cell of each full-resolution component kills its whole chart W_k and hence every chart. Owners may equally be spread among cells of the component: those charts are already identical.

## 2. Regularity is a weighted balance condition

Let n=3^k and s_ij=3^(k-l_ij). For the outer arc i->j put weight w_ij=2s_ij-n. The exact outdegree of any vertex in cell i is

    (mn-1)/2 + (1/2)(sum_(i->j) w_ij - sum_(j->i) w_ji).

Thus global regularity is equivalent to zero signed weighted divergence at EVERY cell. A regular outer tournament alone does not suffice for arbitrary depths. If the outer tournament is regular, the condition equivalently says that the sums of s_ij over outgoing and incoming outer arcs agree.

A positive arithmetic family uses the regular circulant outer tournament on odd m, with steps 1,...,(m-1)/2, and chooses depth l_s depending only on the undirected step {s,-s}. Each step contributes one incoming and one outgoing block of the same degree at each vertex, so balance is automatic. In this family

    c_d=gcd(m, {s : l_s>=d+1}),

with the empty-step convention c_d=m. This follows because the components of the undirected Cayley graph are the cosets of the subgroup generated by those steps. It gives exact arithmetic component counts, not an analogy between unrelated clocks.

For example, m=9,k=2 with l_3=2 and l_1=l_2=l_4=1 gives a regular 81-vertex host, c_0=1,c_1=3, group order 3^10 and owner base 9.

## 3. Actual path and arc flags: the incidence graph is decisive

The reversed-cell lexicographic path from the main note remains directed if every boundary along the chosen outer Hamiltonian path uses depth at least one. In particular, it works when ALL l_ij>=1. At depth zero the all-2 and all-0 words have the same empty prefix, so that boundary argument fails; no unconditional path claim is made for those cases.

Take this actual path P, or any supplied actual Hamiltonian path for which the following slot incidences are recorded. Let S be the set of slots from section 1, so |S|=b(H). Each actual consecutive path arc has endpoints in one or two slots. Form the undirected slot-incidence graph J with an edge between distinct slots whenever an actual path arc joins them. A same-slot arc is an available singleton cover.

Then the minimum number of INDEXED actual arc flags that identify P within its H orbit is exactly

    |S| - nu(J),

where nu(J) is the maximum size of a matching. Singleton covers handle an isolated slot if one exists. In the lexicographic construction every slot has an internal triple arc, so a singleton cover is always available.

Proof: the independent bottom rotations imply that the flags must cover every slot. Conversely covering every slot fixes every internal chart, by section 1. Thus the problem is exactly minimum edge cover allowing singleton covers. A maximum matching covers 2nu slots with nu flags and the remaining |S|-2nu slots with one flag each, giving |S|-nu. Conversely any cover of q flags contains a matching of size at least |S|-q: in each nontrivial connected component of its selected edges choose one edge, while singleton covers contribute no positive lower-bound term. This is the standard edge-cover identity. Each chosen abstract cover edge is realized by an actual indexed arc in P, so no fictitious port is introduced.

The formula is sensitive to shared incidence, not just the number of slots or individual possibilities. The uniform-depth examples have a path-like cover construction reaching ceil(|S|/2); mixed-depth systems need not.

## 4. A regular order-63 hostile: fifteen owner slots need nine arc flags

Take the regular circulant tournament on seven outer cells, with steps {1,2,3}, and put T_2=R9 in every cell. Assign depth 2 exactly to the three edges among cells C={1,3,5}, and depth 1 to all other pairs.

The cells 1,3,5 form a directed cycle 1->3->5->1. Each of these cells has one incoming and one outgoing depth-2 edge; the others have none. Thus changing those three block degrees from 3 to 1 preserves weighted balance. The resulting 63-vertex tournament is ACTUALLY regular of outdegree 31, not merely an equitable-margin model.

The full-resolution components are C and four singleton cells {0},{2},{4},{6}. Consequently c_0=1,c_1=5, the exact named-cell chart group has order 3^16, and its actual-owner base has fifteen slots.

Use the actual Hamiltonian path that visits cells 6,5,4,3,2,1,0, with each cell's internal lexicographic path. Each full-resolution component has three slot vertices, joined as a three-vertex path. The four singleton components attach through the endpoint slots C0,C2 of the central component.

Delete those two central endpoint slots. What remains has five odd components: the four outer three-vertex paths and the isolated central middle slot C1. Any matching can match at most two of those odd components to the two deleted vertices, so at least three vertices are unmatched. Hence nu(J)<=6 on the fifteen slots. A matching of six edges is exhibited in receipt.json (also directly: match two outer-component boundary edges to C0,C2, and take one remaining internal edge in each of the four outer components). Thus nu(J)=6.

The exact indexed-arc observation cost is therefore

    15-6=9,

strictly greater than ceil(15/2)=8. The checker records nine actual path positions realizing a minimum cover. This is a native shared-port obstruction: every arc flag is an actual consecutive edge of an actual Hamiltonian path in an actual regular tournament. It is still scoped to the specified H orbit, not every Hamiltonian path of that tournament.

## 5. Converse, guards and scope

The chart groups above consist of ordinary automorphisms preserving the supplied named cells. A global converse operation or a cell permutation is not silently replaced by independent local reflections. Enlarging to a converse orbit requires its own compatibility data. Since these are genuine automorphism orbits, isomorphism-invariant guards remain constant; additional label-dependent or path-dependent observations can change the identification problem and must be included explicitly.

The number 63 here is the order 7·9 of a proved regular construction. No Collatz, forbidden-count, or other transfer is inferred from that numeral. The useful bridge is the exact shared-incidence matching rule and the nested prefix-frame group.
