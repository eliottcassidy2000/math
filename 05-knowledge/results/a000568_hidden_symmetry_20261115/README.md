# A000568: which symmetries does a Hamiltonian path count see?

This session adds exact, all-order refinements of the tournament class count and a local move law. It separates vertex symmetries, arithmetic symmetries of path-cover profiles, and the fine motion of an actual count. None of the results assumes that residue coverage gives equality at a prescribed target.

- **[Signed module cycle index and the hidden next symmetry layer](MODULES.md).** The odd order of tournament automorphism groups turns a signed decoration identity into an exact multivariate refinement of A000568. Set a rotation-module variable to zero to remove those classes exactly. The leading surviving nonrigid class correction has two coupled cyclic triangles, not two independent module rotations: its size is asymptotic to 2^(binom(n,2)−4n+14)/(16·(n−6)!). The same asymptotic holds for the strong part. Contracting automorphism orbits also yields an exact probabilistic quotient formula for paths that visit each orbit as one block.
- **[A dyadic recurrence with an exact cutoff](PARITY.md).** For n≥2^s every odd residue modulo 2^s has even ordinary class multiplicity. The strong-class residue parity series instead follows an eventual cycle of period dividing three times the group exponent. In modulo eight, for example, at every n≥2 divisible by six an odd number of strong classes have H≡5, and at least one of these classes is self-converse. This derives from degree on the fixed-path Boolean cube, not extrapolation. A higher-valuation statement applies to the path-marked counts, and Burnside with several marked paths exposes group data that a single marked path loses.
- **[An exact target filter for divisors five and seven](TARGETS.md).** Below 30,035 and prime to three, there are exactly five path totals with order-five symmetry, carried by six order-ten strong cores. All higher-order copies consist solely of ordered singleton padding around one of these cores. For order-seven actions at 7q, the interaction graph must be connected. A whole unmarked Paley-7 module always forces 63, sharply, whereas two coupled Paley blocks need not force even three. The interval-7/Paley-7 substitution provides an exact offset of 14 H(Q) with every multiple-run contribution unchanged.
- **[Arithmetic symmetry without graph symmetry](MODULES.md#arithmetic-symmetry-even-when-every-tournament-class-is-rigid).** A quotient can rotate module profiles modulo an odd modulus even when it cannot rotate the modules as graphs. The effect compounds recursively: arbitrarily large rigid strong families have exponentially many classes with identical exact covering profiles and large guaranteed divisors. On a fixed five-vertex quotient, changing adjacent sites can select any residue mod five, while the entire five-length family produces only polylogarithmically many absolute counts. This exhibits the missing ingredient rather than hiding it behind better modular coverage.
- **[Local reversal scale](DYNAMICS.md).** A rigid mark by an arc, or by a directed triangle, gives two different count scales in the class space. On a random tournament, reversing a cyclic triangle preserves the score term and even cancels the leading two-cherry contribution. The normalized root-mean-square count increment is asymptotically 3/n times that of an ordinary arc reversal. This is finer motion, but not a unit-repair or lattice local limit theorem. The labelled estimates transfer to the corresponding marked isomorphism-class laws.

The constructive question left by these results is whether a target can choose a marked interface that breaks the unwanted modular symmetry while cancelling the absolute offset. The five-block modular selector and the exact interval-to-Paley shift give concrete mechanisms to combine, but they do not yet supply a physical host for every target. **Chan–Pak remains open.**

Run the two standard-library controls with `python verify.py` and `python verify_five.py`. The first checks the dyadic seed counts, five-block templates and residues, diagonal-seven witness and triangle increment coefficients. The second uses two endpoint conventions to replay the finite core calculations supporting the all-order order-five classification. The proofs distinguish these finite inputs from their all-order consequences.
