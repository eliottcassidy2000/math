## Connection ledger

1. Stein centre translation -> commuting connection operators -> mixed derivative
   certificates. Preserves actual quotient membership; a fixed-centre scalar
   hides parameter dependence. The needed sidecar is a rational membership
   certificate over centre parameters, with its denominator locus.
2. Core graph -> two-port Euclidean ear construction -> external-field chromatic
   partition function. Retains all core interactions and all point coordinates;
   summing colors discards detailed boundary assignments. Support and count must
   be distinguished even when a partition ratio tends to zero.
3. Ordered interval word -> strong tournament -> exact Hamilton count residue.
   The map retains actual arcs and equal score data; mod 2^k discards integer
   height. A binary decoder is useful, but it does not restore exact landing.
4. Finite polynomial transfer -> weighted path graph -> local state potentials.
   The budget predicate survives over signed coefficients in the sufficient
   direction. Necessity requires a positive realization or exact cancellation
   analysis. No graph/tournament-to-Keller realization is claimed.
