# Bounded fresh deposit: test the splice, not just the digits

## Exact certificate

A reusable construction needs physical representatives, an arithmetic output,
and a continuation contract. Model a bounded interface by a vector x with
exact transitions x -> M_i x; homogeneous coordinates cover affine
transitions. Let B contain the rows that future joins need (not the
accumulated output H unless future joins actually read H through x).
Set E_0 = rowspan B and E_(j+1) = E_j + sum_i E_j M_i. Then E_j
is generated by rows B M_w of length |w| <= j. As soon as equality holds it
holds forever, so the stable space is already reached at j = d-rank(B), for
d the dimension. A signed physical switch x'-x is invisible to every future
boundary exactly when it is killed by this one finite matrix. If feasibility
depends on sidecars, first keep feasibility in the state. In a finite
phase graph, use a distinct E_(phase) and propagate along edges with their
physical labels; work on the direct sum and apply the same bound to that
dimension. Do not certify over illegal words.

Design use: collect all differences from literal representatives inside one
continuation class; compute their exact current H shifts and verify product
transitions on pairs, not independent marginals. In a quotient with an
explicit (H,x) state, a sharp contract would be
H' = 3H+b_(phase)+2j, x' compatible with the next phase, with j in
{0,1,2}; here b_(phase) must be known, not inferred by modular orbit
calibration. Allow the initial profile to depend on the arithmetic target.
Neither quotient linear algebra nor the digit recursion asserts existence
of a physical tournament switch.

If shifts arise from two physical choices v and w, the four-state
mixed difference H_11-H_10-H_01+H_00 must vanish for the shifts to add
while keeping the same baseline. This is the exact test for binary
independence; the endpoint-profile version is vector-valued, then projected
by the stable row matrix above. For more switches, all higher Boolean
Möbius differences must vanish (equivalently test every two-face, not only
the two-faces incident to the origin). A tensor-product join generally
fails: if H(x,y)=H_1(x)H_2(y), the mixed difference is
delta H_1 times delta H_2. That is why a factor-three ordinal shield can
scale a digit family without allowing an unscaled fresh digit in the same
product.

## Cutoff algebra, distinct from physical construction

For H' = 3H+2j with j in {0,1,2}, any odd N >= 3 has a unique odd
parent (N-2j)/3; use j = 2N mod 3 in {0,1,2}. N decreases strictly
throughout this range, and N=1 has no positive parent. The admissible nodes
with a missing positive parent are 23,25,63,65,67: the surviving children
of holes 7 and 21. Thus a single ready class for each of
1,23,25,63,65,67, together with a physical transition for every
nonforbidden child of every ready witness, is sufficient. At H=1 digits for
3,5 must be provided but the 7 digit cannot be. The centered alphabet
j in {-1,0,1} instead gives roots {1,19,23,61,63,65}; the self-arrow at 1
is ignorable. If a ready move is only certified above a threshold, every
target whose parent falls below the threshold is an explicit seed
obligation. This makes clear why 63 belongs in an initialization test even
though a 63 count already exists: it must carry the ready interface.

## Archive analogies with exact scope

- **Planar Jacobian / higher-order observability.** The 2026-08-30
  [planar Jacobian deck/observer note](../../../07-reflections/planar-jacobian-higher-order-observers-and-deck-equivariance-2026-08-30.md) uses
  ker(q) contained in the contact-depth predicate kernel and retains the
  12-fold deck coordinate in a formal-local exclusion. This motivates
  taking the closure of boundary rows under all continuation letters,
  not declaring global Jacobian progress or discarding the clock phase.
- **Hadwiger–Nelson / boundary relation.** For a graph separated into
  two induced pieces with shared boundary S and no other cross edges,
  exact k-colorability is the nonempty intersection of the two relations
  of extendable S colorings, using the same color labels. A path of
  length two is 2-colorable only with equal boundary colors; a path of
  length three only with opposite colors. Each side permits both colors
  at each vertex separately; their union is C5 and not 2-colorable.
  This is the clean caution for +2/+6 readiness measured separately.
  The archive HN/LRC unit-distance note similarly distinguishes the
  different invariants of one forbidden-distance graph: only transport an
  invariant with its hypotheses. No chromatic bound follows.
- **Least resistance / Paley run reductions.** In the October 14 archive
  [Paley least-resistance note](../paley_least_resistance_runs_one_modular_form_20261014.md), low-width
  join reductions discard variables exactly until a Y-junction leaves
  a character sum on a Legendre curve. Tournament analogue: collapse a
  serial transfer only when the continuation kernel supports it; keep
  the first mixed two-port term as an object worth classifying, not as a
  scalar discrepancy to fit. This suggests a search objective: minimum
  interface rank subject to a nonzero mixed junction response and a
  translation-stable digit direction, not minimum gadget order alone.
- **The 1024 deposit.** 2^10-10^3=24=8*3. The [decimal identity archive](../decimal_1024_extensions_20261116/FERMAT_AND_PRECISION.md)
  places 128-125=3 on the norm-three orbit of 1+cuberoot(2); a unit step is
  integral and invertible, so its modular orbits cycle. The note gives
  only two literal excursions with last coefficient zero, (1,1,0) and
  (-5,4,0). This is the exact caution: retaining a local recurrence allows
  modular returns freely while actual fresh zero-coordinate returns may
  be exceptional. The 3 in 8*3 is a primitive discrepancy only after
  division by the true common factor 8.
- **Fibonacci boxes and 24.** For e=(n-m,m,n,n+m), the crossing pairing
  e0*e2+e1*e3 and the adjacent pairing e2*e3-e0*e1 both equal n^2+m^2.
  This exact two-reader equality survives replacing (n,m); it suggests
  searching pairs of physical readers from different matching types
  with equal transport, rather than hoping repeated copies of one shield
  will produce cancellation. The older Fibonacci-box archive expressly
  corrects the false identification of positive Farey/Berggren child
  moves with modular-group torsion generators. The triple (5,12,13) and
  scaled (10,24,26) share 13 as primitive hypotenuse and 24 as doubled
  leg; the independent (7,24,25) shares 24 without scaling. The distinction
  is the same between repetition and changing a core. The 24 in B_24
  is an index: von Staudt–Clausen selects primes p with p-1|24,
  namely 2,3,5,7,13; in A_12^2, 24 is rank and h=13 gives 24*13 roots.
  These are exact reasons for the same numbers, not a proof of a shared
  object or identification with a tournament interface.
