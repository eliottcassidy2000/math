# A Moore-grid constraint machine: erasure recovery, 2-SAT, and no additive column shift

This uses the [edge-rooted grid](EDGE-ROOTED-GRID-AND-NATIVE-WINDOW.md) and continues the repo's [four-lens machine dictionary](../lenses_tm_ca_fractran_tournaments_20261101.md), [exact FRACTRAN guard precision](../stability_priority_moduli_20261102/FRACTRAN_PRECISION.md), and [finite-versus-profinite distinction](../chanpak_profinite_automata_20261122/BOUNDED-DECISION.md). No candidate degree-57 graph is produced. The statements are constraints on candidates or on a hypothetical graph, not undecidability claims.

## One finite tape; three ways to run it

Write \(s=56\) and tape the reciprocal permutations \(p_{ij}\) taking a column in row \(i\) to the matched column in row \(j\). For distinct rows \(i,j\) and each input \(x\), there must be exactly one hit at every output of
\[
                 x,\quad p_{ij}(x),\quad p_{tj}(p_{it}(x))\quad(t\ne i,j).
\]
Check reciprocity and the permutation property as well. Together these checks give the exact grid equation \(M^2+M=56I+J-R-C\). For pairs within a row the equation follows from the perfect matchings; on different rows the exact-one test is precisely the entrywise condition. The grid equation reconstructs both roots and head sets. A Turing-machine-style deterministic verifier just streams the routes and writes output-seen bits. There are \(O(s^4)\) route evaluations, before accounting for tape access; this is a certificate check, not a polynomial-time existence search.

On partial tapes, a graph cellular update has cells for row-pair permutations. If a row-pair route test is missing just one route, its target is forced by the set complement. When the route is a composition with one unknown leg, the other (known) leg is invertible and yields the missing leg. Propose updates from the old tape, merge equal proposals, and reject contradictions including repeated-target routes. The neighborhoods are the row triples, not nearest neighbors of a 1D line. A successful update fills a cell, so the iteration halts; stalling is not nonexistence. The erasure theorems below combine several local tests at once to move past stalls.

There is also an exact guarded FRACTRAN implementation, using [Conway's first-applicable fraction semantics](https://gwern.net/doc/cs/computable/1987-conway.pdf). Allocate one prime per cell state token (including unknown and any explicit Boolean alternatives) and encode a tape by its product, with a ready prime \(e\). For any compiled, finite, fully specified propagation rule \(\rho\), let \(u\) be its target's unknown token, \(v\) the token to write, and \(P\) the product of the other guard tokens it reads. Use fresh shadow copies \(P'\) of those guard tokens and a fresh controller \(c_\rho\). Compile the ordered rule as a pair of micro-instructions:
\[
               \frac{c_\rho P'}{e\,uP},\qquad
               \frac{e\,vP}{c_\rho P'}.
\]
Order the ready-phase instructions by the chosen deterministic scheduler; their restore instructions cannot apply in the ready phase. In the shadow phase only its own restore instruction can apply. Thus the first applicable guard makes one logical update in two multiplications. Read-only guard tokens cannot simply be included in numerator and denominator of a single fraction, since cancellation erases the test. Use explicit one-hot alternatives for negative tests, not absence of a prime as a positive divisibility test. This is a finite compiler for the propagator, not a small FRACTRAN program or a claim that the integer itself is a Hamilton count. The older [physical FRACTRAN tape](../chanpak_computational_tapes_20261115/ca_bridge_fractran.md) can encode the same register program if needed; it does not eliminate the search.

## One erased row is determined, with no branch choices

Erase all transports touching row \(r\), but retain the common column names. Choose an anchor row \(a\ne r\). For every other intact row \(i\), the \(i\to a\) route test has exactly one missing permutation, \(F_i=p_{ra}\circ p_{ir}\), forced by residual targets. Take \(F_a=\mathrm{id}\). Reject unless these residual maps are permutations. For an anchor label \(z\), write \(f(z)=p_{ar}(z)\) for the corresponding site's true column in the erased row. Its already determined neighbors in the intact rows have columns \(F_i^{-1}(z)\), one in each of the \(s-1\) rows. They must all be distinct: a grid vertex has exactly one neighbor in every other column. Hence \(f(z)\) is the unique unused column. Reject repeated forbidden columns, or repeated values of \(f\); otherwise set \(p_{ir}=f\circ F_i\) and take reciprocals. The full verifier is still needed, but there can be **at most one** completion. This erases 55 permutation matchings at once rather than waiting for the individual legs to propagate.

## Two erased rows: a polynomial 2-SAT gate before final reconstruction

Erase rows \(u,v\), retain row set \(K\), and choose anchor \(a\) in \(K\). For each distinct \(i,j\in K\), mark the output pairs not yet hit by the identity, direct transport, and all intact intermediate rows. Reject any collision in the known routes or a residual other than a simple 2-regular bipartite relation \(S_{ij}\). The latter is a union of even cycles. Each \(S_{ia}\), \(i\ne a\), must split into two permutation matchings \(F_i^0,F_i^1\), the routes through \(u,v\) to \(a\). Each cycle has one binary choice for which alternating matching belongs to which phase. Put \(F_a^0=F_a^1=\mathrm{id}\).

The **exact** condition for these choices to reproduce all intact-pair residual routes is 2-SAT. For \(i,j\ne a\) and input \(x\), a purported phase \(\epsilon\) sends \(x\) to \(y=F_i^\epsilon(x)\) in the anchor coordinates, then to \(z=(F_j^\epsilon)^{-1}(y)\). The result depends only on the cycle bit at source \(x\) of \(S_{ia}\), and the cycle bit at anchor label \(y\) of \(S_{ja}\). Prohibit each pair of bit values for which \(z\) lies outside the allowed row of \(S_{ij}\). Next prohibit coalescence of the two phases on one \(z\). It can happen only when the two unordered anchor options of \(x\) in \(S_{ia}\) coincide with those of \(z\) in \(S_{ja}\). In that case coalescence is determined by equality in phase zero, a condition on the two cycles containing \(x,z\). These are again binary prohibitions. Allowed and noncoalescing phases exhaust both residual targets. Constraints involving the anchor itself are already satisfied by the chosen decompositions. The clauses are polynomial in \(s\) (at most \(O(s^4)\) even with naive checks).

Satisfying this gate is **not** sufficient for a full two-row completion. To finish a particular assignment, in each erased-row fiber \(z\) look at the \(s-2\) neighbor columns \((F_i^\epsilon)^{-1}(z)\). They must be distinct. The two columns not encountered are its own and its neighbor's in the other erased row. The unordered pairs on the two erased rows must therefore agree as multisets. Match equal unordered pairs, assigning the two endpoint labels oppositely while enforcing bijective labels within both rows; then check the full tape. Each unordered pair can occur at most twice on either erased row, since each label appears exactly twice in the residual column sets. This final finite search is not claimed to reduce to 2-SAT. The supplied replay confirms every one-row erasure on Petersen and Hoffman–Singleton and the exact clause/residual equivalence for all 15 two-row erasures on Hoffman–Singleton, including all 960 cycle assignments.

## Two obstructions to a simple cellular automaton construction

**No column-only translation symmetry at all.** An automorphism of the grid that fixes each row setwise must permute the columns globally, since columns can be read from the rook zeros. Such a column permutation \(g\), if nontrivial, is fixed-point-free: a fixed column would give a fixed site in each row, and all the neighbors of such a site (one in each other row) would have to be fixed too. Those neighbors exhaust the other columns, forcing \(g=\mathrm{id}\). If any nontrivial column-only symmetry exists, a power yields one of prime order \(p\), consisting of \(m=56/p\) cycles; \(p=2\) or \(7\).

Take the eigenspace of the induced column permutation for a primitive \(p\)th root. It has dimension \(56m\) globally and \(m\) per row. It is invariant under \(M\). Inside it, the row-constant-across-rows subspace has dimension \(m\) and \(M\) acts there by \(-1\), since each column sees every other column exactly once across rows. On its orthogonal complement of dimension \(55m\), the grid equation gives only eigenvalues \(7,-8\): \(R\) and \(J\) vanish on the nontrivial column frequency and \(C\) vanishes on the row contrast. The entire restricted trace is zero because every diagonal row block of \(M\) is zero. If the 7-multiplicity is \(h\) then
\[
                  0=-m+7h-8(55m-h),\qquad 15h=441m.
\]
This would require \(5\mid m\), false for \(m=28,8\). Thus the edge-rooted symmetry group fixing both roots acts faithfully on the row labels and on the column labels separately. In particular no candidate whose transports all commute with a common nonidentity column shift can work, including every purely column-circulant or common additive-column automaton ansatz. Simultaneous moving rows and columns are not excluded.

**The binary linear evolution forgets time rapidly.** On the entire satellite tape over \(\mathbf F_2\), the identity gives \(M^2+M=J+R+C\). These three commuting matrices square to zero, so \(M^4=M^2\). The linear neighbor-parity automaton is always on a cycle of period dividing two after two steps. This is an exact diagnostic and distinguishes the architecture from a freely chosen long-period linear CA. It does not bound the nonlinear search or imply exact path counts.
