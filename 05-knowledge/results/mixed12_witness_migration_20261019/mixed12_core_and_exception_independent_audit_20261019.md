# Independent audit of the mixed (1,2) core family and exceptional inequality

Date: 2026-10-19. Scope: complete rooted-core generation for c≤2, the prefix/suffix coefficient interpretation, and the exceptional weighted inequality. The full list of per-majority-order witnesses belongs to the main mixed-(1,2) certificate packet.

## 1. Completeness of the rooted-core generator

Let (x,y) be an ordered critical incomparable pair with exactly one lower slave b, exactly two upper slaves a1,a2, and common incomparability set Z. The mandatory relations are

    b<y,       x<a1,       x<a2.

The only additional possible relations in this core are:

- b<z for z in Z;
- b<a1 and b<a2;
- z<aj for z in Z and j=1,2;
- relations internal to Z;
- a relation between a1 and a2.

Every opposite cross-direction is impossible. The relation z<b would imply z<y, aj<z would imply x<z, and aj<b would imply x<y. The reverse root-incident directions contradict the specified incomparability neighborhoods. No other relation type remains.

Choose any linear extension of the induced common poset and label Z naturally along it. Independently choose a linear extension of the induced upper-slave poset and label the two upper slaves naturally. Their chosen orders are used only to provide labels for enumeration, not imposed as extra relations. Thus only increasing-index internal edges need be generated in either group, while all actual isomorphism types remain covered.

Enumerating every subset of these allowed edges, taking transitive closure, and deduplicating is complete. The mandatory root relations and the allowed edge directions cannot create a root/common comparability or compare x and y. Transitive closure automatically includes every forced b-to-upper relation.

Here an admissible order is a core linear extension with x before y whose root span is at least the span of every incomparable core pair. These are not asserted to be actual majority orders; including extra possibilities is safe.

## 2. Why the projected-order and generator tests are sound

For an actual maximum-span majority pair, no exterior point lies between x and y: every exterior point is below both roots or above both. Projection to the core therefore preserves the root span, while every other core-pair span can only decrease. Hence its projected order appears among the admissible orders above.

The full extension counts factor over the core prefix before the first root and suffix after the last root. Expanding normalized counts into nonnegative prefix/suffix tree increments gives a coefficient indexed by an initial word u and terminal word v. This coefficient counts exactly the bare core extensions beginning with u and ending with v. Incompatible endpoints give a zero column.

Thus a nonnegative weighted sum of oriented-comparison rows with

    sum_j w_j [3N_j(u,v)-2E(u,v)] ≤ 0

for every generator (u,v) implies

    sum_j w_j p(pair_j in its projected-order direction)
      ≤ (2/3) sum_j w_j

for every actual exterior. If the projected order were a >2/3 majority order, the reverse strict inequality would hold. Arbitrary independence of generator weights is unnecessary: their actual values are nonnegative products of tree increments, which suffices.

## 3. The exceptional six-point core

Use labels (x,y,b,z,a1,a2) with predecessor masks

    (0,4,0,4,13,5).

Equivalently its relations are generated by

    b<y, b<z<a1, b<a2, x<a1, x<a2.

The candidate projected order is

    b, x, z, y, a2, a1.

The four pairs x∥z, z∥y, y∥a2, and a2∥a1 are all forward in this order. The exact universal inequality is

    3p(x<z)+4p(z<y)+p(y<a2)+p(a2<a1) ≤ 6.          (1)

Its positive weights total nine, so (1) contradicts a >2/3 majority direction on all four pairs.

There are 37 bare core extensions. The four comparison counts, in the order displayed in (1), are

    27, 24, 22, 23.

The weighted numerator is 222=6·37. The bare core therefore attains equality.
