## All-order involution and stable-cell argument

For at least two vertices, an ordinary tournament automorphism cannot have even
order: an even-order element powers to an involution swapping a pair, which
would reverse the arc between that pair. Thus if alpha is anti, alpha squared
has odd order m. The odd power tau = alpha^m is still anti and squares to the
identity. Empty and singleton cases are handled directly by identity; calling
identity an element of strict order two would be incorrect.

An anti-involution fixes at most one vertex, since two fixed vertices would
force their arc to reverse. Consequently it has exactly n mod 2 fixed vertices.
Refinement from a uniform color partition gives the same equivalence partition
on a tournament and its converse: outcounts into each cell transform into cell
size minus the original outcount, with the self correction in one's own cell.
An anti-isomorphism therefore permutes actual stable cells. Each such cell is
odd, because its induced tournament is regular. A fixed cell under tau has a
fixed vertex, since an involution on an odd set has one. Conversely, a fixed
vertex lies in a fixed cell. It follows that tau fixes exactly n mod 2 actual
stable cells and pairs all others in equal-sized pairs.

In particular, every stable-cell size occurs with even multiplicity in an even
self-converse tournament. This is a necessary condition, not sufficient: the
independent two-five-cell family contains sixty rigid non-self-converse
classes with the perfectly paired stable size pattern 5+5. The condition
excludes every positive-error order-ten family except 5+5. It uses no claim
that all points of a self-converse class are blue, and gives no metagraph
edge/loop identification.

A further valid corollary is e(T) even for every tournament and e(T) divisible
by four for every even-order self-converse tournament. Aut(T) has odd order,
so every vertex orbit is odd. An odd stable cell C therefore contains an odd
number r of orbits and contributes |C|(r-1), which is even. An anti-map
normalizes Aut(T), so cells paired by the anti-involution contribute equal
amounts; even order makes the full sum a sum of doubled even numbers. This
is only a necessary filter, not a self-converse characterization.

The anti-map odd-power mechanism is inherited: see THM-647,
`01-canon/theorems/THM-647-anti-redei-theorem.md`, especially its final constructive
remark and non-involutory-twist reduction. The new work here is its actual
stable-cell consequence and error-slice extraction, not priority for existence
of an anti-involution.

## Weighted SCC identity

Let S(z,t) count ordinary strongly connected classes, including the singleton;
let F_s(z,t) count self-converse strongly connected classes; let A(z,t) count
all ordinary classes, including empty; and let F(z,t) count all self-converse
classes, including empty. The exponent of t is the additive defect e.
The unique ordered SCC decomposition gives

    A(z,t) = 1 / (1 - S(z,t)).
    F(z,t) = (1 + F_s(z,t)) / (1 - S(z^2,t^2)).
    M(z,t) = (A(z,t) + F(z,t)) / 2.

Converse reverses the SCC word and converses each letter. A fixed word has an
arbitrary left half, its converse-reversed right half, and either no center or
a self-converse strong center. Each paired SCC doubles both order and defect;
this explains both squared arguments. Ordinary, not self-converse or merged,
strong classes are the outer-pair alphabet. The multivariate weighting is an
additive extension of the inherited ordered-SCC/reflection mechanism.

The audit tests the distinctions: its alphabet contains a non-self-converse
strong pair, and the coefficient z^14 t^28 includes the doubled defective
regular-seven component. The wrong denominator with unsquared t fails that
control. At order ten a nonstrong self-converse tournament cannot have a lone
positive-error component, because a mirrored defective pair requires at least
fourteen vertices, while any central defective component at order seven or nine
leaves an odd number of exterior vertices. Thus the fixed defect correction at
order ten comes entirely from the strong two-five-cell family.

## General prime-cell extraction independently checked

For the specified two-carousel p-cell family, p an odd prime and 1<=d<p/2,
write B=binom(p,d), c=binom((p-1)/2,floor(d/2)), R for the labelled d-regular
binary matrix count and S_sym for the symmetric such count. A nontrivial matrix
stabilizer is a full-slope line with slope s in F_p^*. Such a matrix has form

    M(x,y) = 1_D(y-s*x).

Translation classes are the translation necklaces [D]. Proper nonempty subsets
have free C_p action, so there are B/p necklaces for each slope. The normalized
converse sends (s,[D]) to (s^(-1),[s^(-1)*D]); only s=+1 or -1 can be fixed.
Slope +1 fixes every necklace. At slope -1 the fixed necklaces are reversible;
averaging the p reflections gives exactly c fixed necklaces, since each
reflection has one fixed point and (p-1)/2 two-cycles. Therefore

    nonrigid self-converse = B/p + c;
    rigid ordinary        = (R-(p-1)B)/p^2;
    rigid self-converse   = (S_sym-B-c)/p;
    rigid converse-merged = (rigid ordinary + rigid self-converse)/2.

Every rigid class has defect 2p(p-1). The total and fixed-class formulas being
subtracted are inherited from Session40 `regular-block-counts.md`; the rigid
extraction is the useful new consequence. It is not an exhaustive statement
about all order-2p tournaments for p>=7, and no composite-p extension is claimed.

`prime_necklaces.py` independently counts labelled regular matrices and symmetric
matrices by capacity recursion and constructs every nonrigid necklace class at
p=3,5,7. Its full matrix converse tests match the slope proof. The rigid
self-converse counts are 0 at (3,1), 4 and20 at p=5, and 32,984,5016 at p=7.
The p=7 matrix coefficients are exact dynamic programs, not enumeration of
68,938,800 matrix objects.

## Independent mixed-port boundary control

`ports_independent.py` additionally checks the producer's optional path-fibre
calculation on all 24 rigid self-converse nodes. A full vertex-subset dynamic
program counts Hamiltonian paths. A different pair-subset dynamic program
counts half paths choosing one vertex from each anti-involution pair and
requires the final middle arc v -> q(v); anti-symmetry forces the other half.
This avoids enumerating half-path permutations. Every per-representative count
agrees with the producer: 4200 anti-palindromic (blue) fibres and 337304 other
(black) fibres in total. Every one of the 24 nodes is mixed, not all-blue.
Identification with the blue fibre uses the PROVED part (a) of inherited
THM-644, `THM-644-gridsym-fiber-law-and-anti-redei.md`. In the rigid special
case needed here, paths give distinct base-path presentations: identical
presentations would yield an automorphism sending one path to the other.
Thus the path/presentation correspondence is bijective and part (a) identifies
the blue ones. This does not promote historically VERIFIED part (b) to a
general proved dependency. These are port counts, not
paired-line counts or endpoint adjacency.
