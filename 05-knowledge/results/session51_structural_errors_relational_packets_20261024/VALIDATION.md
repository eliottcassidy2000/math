# Session51 validation and provenance ledger

This ledger describes mathematical artifacts. Remote publication is separately
verified and announced; local readiness is not a claim that a pending upload
or commit has completed.

## Universal versus finite claims

The all-size claims are proofs with explicit hypotheses: prime cyclic-cell
recognition and gain/pin kernel, Boolean endpoint-interval/neutral-packet
classification, strong-component and converse generating functions, and
endpoint-score layer separation. Small exact universes provide independent
controls, not substitutes for these proofs. Ordinary and self-converse class
counts, actual path ports, exact matching partners, costs and timing all
retain their own stated domains.

## Reproduction and hostile controls

Follow the exact commands in each packet's README and verifier. Normal Python
and optimized Python, and the applicable O2/O3-NDEBUG compiled builds, were
compared. Load-bearing tests use active checks rather than relying on Python
assertions disappearing under optimization. Complete manifest-only copies
were replayed from unrelated temporary directories, without a repository,
sibling packet or network dependency.

Hostile tests include changed inputs, missing or added payloads, source
corruption, rejected unsupported regular cells, lost pins, incorrect inverse
gains, ignored cycle frustration, wrong converse and missing t-squared
weighting, wrong SCC coefficient indices, coalesced stable cells counted in
the wrong family, malformed parent actions, and false arithmetic certificates.
Their precise universes and outcomes are recorded in the corresponding
reports; no unspecified universal test coverage is claimed.
