## Mathematical review

1. The decoder computes the actual stable partition internally. It never
   accepts user-supplied equitable blocks as if they were canonical cells.
   Every automorphism therefore fixes each returned cell individually.
2. On R_p, an arc of cyclic length d has m-d common outneighbors, where
   m=(p-1)/2. The maximum identifies exactly the successor arcs. A unique
   full successor cycle followed by verification of every induced arc is
   a sound recognition procedure, not an assumption that prime regular
   tournaments are all cyclic. Automorphisms of R_p are exactly rotations.
3. A nonconstant equitable p-by-p crossing has a translation stabilizer
   subgroup of F_p^2 with no nonzero coordinate-axis element. Thus it is
   trivial or a non-axis line. The trivial case pins both cells to zero;
   the line case imposes one nonzero gain relation. Uniform crossings impose
   no condition. Coprime cell sizes have only uniform crossings.
4. On a gain component, a root parameter determines all rotations. A pin
   or a cycle gain different from one kills that parameter. Otherwise there
   is precisely one C_p factor. No arc condition is omitted: internal arcs
   and all crossings have been checked. Distinct primes decouple.
5. A free cell is transitive, and a frozen p-cell consists of p fixed
   vertices. Its error is p(p-1), exactly the implemented formula. The code
   produces actual generating vertex permutations, not just an abstract
   group-order prediction.
6. Recognition, stable refinement, crossing-translation tests, and gain
   propagation are polynomial in input size. The output uses generators,
   not a potentially exponential enumeration of all group elements.

The prime field assumption is material: it eliminates partially nonzero
parameters annihilated by nonunits. The actual R_p recognition assumption is
also material: arbitrary regular prime cells are not in the domain. Nothing
here computes all tournament classes, all unrestricted refinement errors,
Hamiltonian path counts, or missing metagraph incidence.

## Independent finite universes

The independent implementation of refinement and full automorphism search is
in `reference.py`, written for the order-ten audit before seeing this decoder.
`independent.py` compares the decoded group with literal arc-preserving vertex
maps, not merely internal rotations supplied by a proposed block presentation.
It closes the decoder's generators and compares the complete generated
permutation set, every vertex orbit, and the defining refinement-error sum.

- Every labelled tournament of orders0 through6: counts1,1,2,8,64,1024,32768,
  total33868. Every case belongs to the decoder domain and matches the full
  ordinary automorphism action and error.
- All2640 labelled regular-seven tournaments, independently generated by
  row-wise degree completion. Exactly720 are accepted, all with Aut order7.
  The1680 labels of the bad Aut3 class and240 labels of the Paley Aut21 class
  are rejected. This tests prime regularity versus actual R_p recognition.
- Internal R_p cells and two/three-cell gain systems for p=3,5,7,11,13.
  Tests include nonunit gains, balanced and frustrated cycles, actual
  generator closure, arbitrary relabellings, and converses. Largest order39.
- Rigid crossings for p=5,7,11,13, including pin propagation through adjacent
  gain edges and both-endpoint pinning when no gain edge joins the pair.
- Independent mixed3/5/7 cells with group order105.
- A cyclic-majority three-triangle presentation whose actual stable partition
  is one nine-cell. It is rejected, rather than decoded using chosen triples.
- Invalid loops, missing/double arcs, out-of-range bits, and negative rows
  are rejected.

The independent suite has175939 explicit checks. Normal and optimized output
and receipts agree byte for byte. Tests are exception-based and remain live
under `-O`.

## Adversarial mutation controls

Seven mutations were applied only to temporary physical copies. Each was
rejected by the independent suite in normal and optimized mode:

- deleting all rigid-edge pins;
- pinning only one endpoint;
- ignoring cycle inconsistencies;
- using the forward gain instead of its inverse on reverse traversal;
- generating unit rotations instead of the propagated rotations;
- bypassing cyclic-coordinate recognition;
- using p rather than p(p-1) as the frozen-cell error.

The wrong-generator and skipped-recognition variants fail actual generated
group equality, not just a group-order check. Other variants fail full
ordinary automorphism order or the literal error sum. Exact failure labels
are in `hostile-results.json`.

## Reproduction and packaging

    python3 -B independent.py > independent-normal.out
    python3 -B -O independent.py --output optimized.json > independent-optimized.out
    python3 -B hostile_replay.py > hostile-results.json
    python3 -B replay.py

Use `-B` because the producer's exact-membership verifier intentionally rejects
unlisted bytecode-cache files. The final replay verifies this audit's manifest,
physically copies only its listed payloads into a fresh directory, runs both
normal and optimized independent suites and producer suites, compares all
receipts with the pinned values, and verifies the producer's manifest there.
