# What a complete grammar must still prove

**Exact reformulation, not a Chan–Pak proof.**

Let

    B_n(y)=sum_[T], |T|=n y^{H(T)}.

This is the ordinary isomorphism-class Hamiltonian-count inventory, with one
term per class and multiplicities retained. Then A000568(n)=B_n(1). A procedure
which knows B_n(1) exactly, even at every order, has not recovered its support.
A substitution-response grammar needs full path-cover profiles; unrestricted
vertex growth needs still more, as the H9 hostile pair in this packet proves.

The existing weighted-core grammar does generate every tournament in principle:
retain all pair-free cores, their automorphisms, and positive weight orbits.
What remains difficult is not the existence of a formal grammar, but efficient
classification of its unbounded core alphabet and a uniform output selector.
This session does not claim to replace that alphabet by finitely many types.

For an odd target c, define

    m(c)=min{n:[y^c]B_n(y)>0},

when the set is nonempty. Adding a universal source preserves H exactly, so
the supports are nested and a witness at one order persists at every larger
order. The desired Chan–Pak statement is the finiteness of m(c) for every
positive odd c except7,21. A proof could supply any effective recursive upper
bound, or a well-founded inverse construction terminating at known seeds;
it need not classify every class or find the minimal witness.

## Three completed interfaces, three different losses

| Exact interface | What is now computable | What is not implied |
|---|---|---|
| Long permutation-cycle core plus short-family gcd field | Rich stratified A000568 correction packet, then exact integer recovery | A physical tournament with prescribed H |
| Pair-free core plus endpoint split types and lengths | Every single-arc structural rewrite; rank row from bounded templates | An unbounded target-specific sequence of rewrites |
| Order plus one physical strong-cap count | Complete path-cover profile, hence all uniform substitution responses | Isomorphism class, arbitrary attachment response, or arbitrary code realizability |

The common working principle is **eliminate the interior only after fixing the
interface that the next operation reads**. This phrase records the mechanism,
not a newly asserted universal theorem. The examples differ in their algebra:
positive rational Burnside sums, canonical transitive-module rewrites, and
superincreasing integer coding.

## A concrete next proof obligation

Use the new metagraph rewrite compiler to construct a family of named-root
interfaces indexed by c, not only by order or reduced rank. Retain enough of
the path-cover/cut response to prove that an actual operation reaches c from
a smaller target and does not lose the continuation property. The H9 pair
shows that a scalar or even an unrooted substitution code is insufficient.
The previous renewable nine-bank supplies a nonempty base interface, but it
has not yet supplied this all-target inverse descent.

This is compatible with faster exact A000568 computation: improving a class
census and proving output support are complementary, not equivalent tasks.
