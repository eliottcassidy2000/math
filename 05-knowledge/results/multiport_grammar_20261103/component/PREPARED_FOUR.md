## 2. Exact terminal preparation: sigma=2 and tau=0

Use the inherited square-zero vertex ring
`Z[z_v:v in V(T)]/(z_v^2)`, and let brackets extract the full vertex monomial.
P enumerates all paths, including the empty path with coefficient1. W enumerates
nonempty paths ending r; A_u those starting u; Q_ur those starting u and ending r.
Define

```text
H=[P], F=[WP], S=[PA_u],
L=[WPA_u], K=[P^2 Q_ur], G=L+K,
sigma=S-H, tau=G-F.                                    (2)
```

Slots are ordered, and their empty/nonempty conventions matter.

**Start deficit.** Cutting a Hamilton path immediately before u injects
Hamilton paths into the ordered two-slot covers counted by S. Conversely,
a cover counted by S fails to join only when its first path ends at r and
its u-starting path is the singleton u. Indeed u's sole out-neighbour r
must occur in every nontrivial u-starting path; if r is there, every vertex
of the disjoint first path beats u, so the join is legal. If the u-path is
singleton, every possible last vertex except r also beats u. Thus

```text
S-H=e_r(T-u).                                           (3)
```

A Hamilton path of T-u ending at r has w immediately before r, since w is
now its only in-neighbour. Deleting r leaves a Hamilton path of `A -> D`
ending at w. The one-way component order forces all of A first, in its unique
transitive order. Consequently

```text
e_r(T-u)=H(A)e_w(D)=2,
sigma=2.                                               (4)
```

**Joint deficit.** Since u has only the out-neighbour r, the only simple path
starting u and ending r is `u -> r`, hence `Q_ur=z_u z_r`. In L the W factor
already contains r, so A_u must be singleton. Therefore

```text
L=E_r(T-u,2), K=P_2(T-{u,r}).                            (5)
```

Partition a cover counted by F according to which slot contains u. If u is
in the first slot ending r, it is immediately before r; cutting off `u,r`
leaves the two ordered slots counted by K. If u is in the other slot, it
must be terminal because r is already in the first slot. Delete u to obtain
the cover counted by L. Conversely, append u to the second slot of an L
cover: all vertices there beat u, and an empty second slot gives singleton u.
Appending `u,r` to the first slot of a K cover is likewise legal, including
an empty first slot. This gives the exact bijection

```text
F=L+K=G, tau=0.                                        (6)
```

For an additional explicit check, `P_2(A -> D)=P_2(A)P_2(D)=224*2^k`.
Each of the two ordered slots respects the component order, proving this
product without a nonempty-slot assumption. Hence (1), (5) and (6) give

```text
K=224*2^k, L=28*2^k+17, S=252*2^k-27.                  (7)
```

The preparation `(sigma,tau)=(2,0)` holds for every k>=1. It is not inferred
from the three finite clocks checked below.
