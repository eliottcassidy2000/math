# Reproducing the audit

All programs here are the auditor's own. None of the packet's programs (`seeds.py`, `density.c`, `residue_law.c`,
`root_changes.c`, `verify.py`) is executed, except that `e_decide_p1_p6.py` imports `verify.predict` only to compare
it with the auditor's re-implementation of the registered P1 model. Packet files are read as inputs: the seed lists,
`p1_density.txt`, `p2_root.txt`, `p3_bankA_w2*.txt`, `p6_*.txt` and `root_changes_1e8.txt`, each read only to be
compared with the audit's own numbers.

Environment used: Windows 11, gcc 15.2.0 (`-O2`), Python 3.13.14 with numpy 2.3.2. Compile into a scratch directory
`$B` outside the repository, and run from this `audit/` directory.

```bash
B=/path/to/scratch/bin
gcc -O2 -o $B/a_identities a_identities.c
gcc -O2 -o $B/c_literal    c_literal.c
gcc -O2 -o $B/d_image      d_image.c
gcc -O2 -o $B/g_rootchanges g_rootchanges.c
gcc -O2 -o $B/h_parity     h_parity.c -lm
gcc -O2 -o $B/i_classmass  i_classmass.c

# THM-4888 (A) and the T identity, all m < 2^28 (about 1.5 min, 1 GB)
$B/a_identities 28 > out_identities_2p28.txt
# THM-4888 (B) classification, exact inverse, seed lists, nesting chains (seconds)
python3 b_states.py 4096 > out_states_U4096.json
# literal tournaments (seconds)
$B/c_literal W 9   > out_literal_words_L9.txt
$B/c_literal T 4 6 > out_literal_tails_L4_K6.txt
$B/c_literal S seed_words.txt 4 > out_literal_seeds_K4.txt   # seed_words.txt: BFS words of bank A + 10 P1 seeds
# tail images by full linear scan of m (seconds each)
printf '1 2 0 1\n' > root_seed.txt
$B/d_image ../p1_seeds.txt 16777216 33554432 1  > out_p1_w24_M1.txt
$B/d_image ../p1_seeds.txt 16777216 33554432 63 > out_p1_w24_M63.txt     # 265 kB, kept outside audit/ (big_outputs.sha256)
for w in 20 22 24 25 26 27; do $B/d_image root_seed.txt $((1<<w)) $((1<<(w+1))) 63 > out_root_w${w}_M63.txt; done
$B/d_image root_seed.txt 0 2097152 7 > out_root_below2p21_M7.txt   # likewise M = 3, 5; window [2^20, 2^21) M = 3, 7
python3 e_decide_p1_p6.py            # writes out_decisions_p1_p2_p6.json
# bank A, section 4 and P3
#   bankA_all / bankA_nobal / bankA_generic34 / bankA_r2d16 / bankA_bal35 .txt are written from out_states_U4096.json
for f in bankA_all bankA_nobal bankA_generic34 bankA_r2d16; do for M in 3 945 12288; do
  $B/d_image $f.txt 4194304 8388608 $M U > out_w22_${f}_M$M.txt; done; done   # M = 945, 12288 files kept outside audit/
python3 f_section4.py                # writes out_section4_w22.json
$B/d_image bankA_all.txt 4194304 8388608 0 P 19 24 > out_w22_pair_25_30_10_15__27_30_12_15.txt
for w in 24 26 27; do $B/d_image bankA_all.txt $((1<<w)) $((1<<(w+1))) 3 U > out_p3_bankA_w${w}_M3.txt; done
# parity-split capacity, exceptions to the kappa = 1 law
$B/h_parity 16777216 > out_parity_capacity.txt; $B/h_parity 67108864 >> out_parity_capacity.txt
$B/d_image seeds_exceptions.txt 4194304 8388608 63 > out_exceptions_w22_M63.txt
# root-change families, move-only DFS (no closed form): 3 s, 9 s, 264 s
$B/g_rootchanges 4000000 4000000 2     > out_rootchanges_X4e6.txt
$B/g_rootchanges 10000000 4000000 2    > out_rootchanges_X1e7.txt
$B/g_rootchanges 100000000 4000000 2   > out_rootchanges_X1e8.txt
$B/i_classmass 4000000 2 > out_classmass_X4e6.txt
```

The small numpy analyses are in `j_inline_checks.py` (one function per output, each using only the recurrence for Q
and a full scan of m):

```bash
python3 j_inline_checks.py D_identities       > out_D_identities.txt                 # (D)2, (D)3 on bank A; post-hoc mod-9 number
python3 j_inline_checks.py exceptions_summary > out_exceptions_w22_summary.txt       # kappa = 1 law on d = 1, R = 2d, balanced, generic seeds
python3 j_inline_checks.py shared_halves      > out_w22_shared_halves_detail.txt     # parity decomposition of the 60,807 overlap
python3 j_inline_checks.py pairwise_excess    > out_w22_pairwise_excess.txt          # 1225 pairwise overlaps, 50 non-balanced seeds
python3 j_inline_checks.py halves_product     > out_w22_halves_product.txt           # product over distinct half-images; blocks
python3 j_inline_checks.py intensity_weighted > out_bankA_intensity_and_weighted_test.txt  # 8.29/7.60/5.15; weighted test; "Scale"
```

Large intermediate files (per-class counts mod 945 and 12288, and the P1 seeds mod 63) are not kept in `audit/`. Their
sha256 values are in `big_outputs.sha256`. They are regenerated by the commands above.
