## Independent all-order derivation

1. **Scalar join.** In the unmodified ordinal join A→B, every Hamilton path consists of a Hamilton path of A followed by one of B. Exactly e(A,a)s(B,c)=ef such paths use the removed arc. Any path using c→a uses it only once. Its A restriction consists of a possibly empty path before that crossing and a path starting at a afterward; its B restriction consists of a path ending at c before the crossing and a possibly empty path afterward. Conversely any such two covers concatenate into one path: all other inter-part arcs point A→B. Reversing B=C^op identifies its c-ending covers with c-starting covers of C. Therefore N=hk−ef+uv, with the singleton and empty outside-piece conventions intact.

2. **Basic inequalities and sink test.** Split each Hamilton path immediately before its root to inject Hamilton paths into the u covers, giving u≥h. At a sink every Hamilton path ends there and the root-starting bin is a singleton, so e=u=h. Conversely the THM-4876 endpoint bound e≤(h−1)/2 for nonsinks excludes e=h. The endpoint bound itself has an elementary injection: move the final root in an ending-at-root path immediately before its first out-neighbor. This injects into paths not ending at the root; oddness of h makes 2e≤h imply 2e≤h−1. Thus the numerical test e<h detects nonsink physical ports exactly.

3. **Descent.** If a is nonsink, N≥2hk−(h−1)k/2=(3h+1)k/2. The right-port statement is symmetric. This bounds its own h by (2N−1)/3, since k≥1. To bound the other coordinate when only a is nonsink, N≥2k because h≥1. Then 3k≤4k−1≤2N−1. Properness also gives ef<hk, and integrality yields uv=N−(hk−ef)≤N−1. The cap is strict: (2N−1)/3<N. Examples: a rooted directed triangle with (3,1,3), paired with the singleton, gives N=5 and equality in 2N=(3h+1)k and 3h=2N−1. A source-rooted TT2 paired with the singleton gives N=3 and uv=N−1. These are genuine equality witnesses, not an assertion of asymptotic optimality of every bound.

4. **Degenerate boundary.** If both ports are sinks, e=u=h and f=v=k, so N=hk. Taking the first input a singleton copies k without descent. This is why the simultaneous-equality exclusion is essential. Equal h does not determine the output: source-rooted TT2 and TT3 have triples (1,0,2), (1,0,4) and give 3,5 against the singleton. Full physical interface information cannot be replaced by scalar membership.

5. **Finite inverse necessity and sufficiency.** Every physical proper pair occurs in the finite h,k,e,f ranges, with t=uv>0, t≤N−1, u≥h, v≥k. Positive-divisor enumeration lists its u,v. Conversely every accepted pair is backed by actual rooted graphs and yields exactly N by the scalar law. No assumption about a numerical cone is made. The optional endpoint bound prunes only impossible states.

6. **Existential deletion sidecar and representative bounds.** Deleting the root gives an odd positive count d≤h: each deletion path admits root insertion, and deletion recovers the original path, proving an injection. Thus testing odd d from 1 to h is complete. In the Session228 compression, d is the product of deletion-SCC Hamilton counts. Nontrivial deletion SCCs have order at most their count, by Camion; their total order is at most d. Before the first deletion SCC containing an out-neighbor of the root, inactive singleton SCCs can be removed while preserving all four coordinates. If u=d, the root is a sink and only nontrivial deletion SCCs remain. If V=u−d>0, every SCC following first activation multiplies V by at least 2; hence at most floor(log2 V) such SCCs, and at most 1+floor(log2 V) surviving singleton SCCs. Adding the root gives exactly the four stated representative bounds. Every positive membership answer returns a graph; exhaustive failure is decisive by this all-order bound. This is decidability, not an efficient algorithm or a test merely up to an empirically chosen order.

7. **Prime normalization.** SCCs of a tournament form a linearly ordered ordinal sum. The suffix starting at the root SCC is exactly its reachable set. In a cover with a root-starting bin, no vertex of the removed prefix can be in that bin, so the entire prefix is a Hamilton path in the other bin. Thus h,e,u all scale by the prefix count p (also d scales). N=pqN' follows by bilinearity. A nonsink retains its out-neighbor in the suffix, so normalization remains proper and N'≥3. Prime N forces p=q=1, preserving each triple.

8. **Strongness characterization.** For proper inputs, the output is strong iff both recorded roots reach their whole inputs. Necessity: the only B→A arc enters at a, so vertices unreachable from a stay unreachable from B; reverse the argument for C. For sufficiency when both inputs have at least two vertices, every A vertex can reach c using a cross edge and, if necessary, a path inside B; c→a connects to the root reaching all A, and cross arcs give all B. If A is singleton, C's reachable root is nonsink; choose an out-neighbor of c in C, equivalently a vertex reaching c in B, to close a directed route from a through B to c and back. The case C singleton is dual. Two singletons are excluded by properness. Hence prime representations admit strong normalized witnesses. Finally gcd(h,e,u) divides N, is positive and at most h<N, hence equals 1 for prime N; likewise for the other input.

## Independent computation and completeness boundaries

`check.py` imports no producer or prior implementation. It generates tournaments as Boolean adjacency matrices; computes h,e,u,d by literal permutation/split enumeration; counts joined Hamilton paths with a separately written memoized suffix recursion; computes reachability by set closure; normalizes via the root's reachable set; and enumerates divisors using square-root factor pairs.

The universe is all 1,099 labelled tournaments of orders 1–5 rooted at zero. Every rooted isomorphism class in these orders is represented. All 1,207,801 ordered pairs receive quantitative and boundary tests. All 5,625 ordered pairs with factor orders 1–4 receive literal join checks and every proper such pair receives the strongness iff test.
