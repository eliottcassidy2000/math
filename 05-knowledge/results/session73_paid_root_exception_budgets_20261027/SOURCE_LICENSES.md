# Source boundary

Repository-native Markdown snapshots are preserved at their exact declared Git
commits. Original paths, Git blob identities, byte counts and SHA256 values are
bound in `PROVENANCE_RULES.json`. These snapshots are inert evidence: the
portable replay executes only the current scripts named by `FILE_MANIFEST.json`.

External papers are cited by metadata and links. Downloaded PDF/HTML and other
third-party source payloads are not in this packet. No external license grant,
external novelty priority, or permission to republish a source is inferred.
