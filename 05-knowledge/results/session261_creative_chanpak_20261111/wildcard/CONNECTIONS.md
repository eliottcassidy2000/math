## Packing integration received from parent

A nonzero s-block rooted substitution coefficient provides s-1 disjoint inter-block external paths. Each begins in an out-neighbor and ends in an in-neighbor of the root. With at least s clone vertices, close s-1 such paths using distinct clones. Thus an entire clone ray with cycle packing<=r has s<=r+1 for every nonzero coefficient. This bounds the exponential bases in its positive Stirling expansion by r+1. The argument uses the parent's skeleton convention; it is not needed by the automaton proof.

A periodic block can contain several clones or vertex types, so its transfer eigenvalues can exceed r+1. For example the base9 in a length2 repeated block is consistent with a per-letter base3; do not apply the single-module bound to an arbitrary word block.
