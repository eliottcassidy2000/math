   remain a two-branch repair under untouched cloning. The coefficient scan
   disproves that in the declared template. The strongest survivor is the
   actual native operation lift plus two H-neutral97 clone families; the

   positive resets have explicit nontrivial transport; requiring the old
   exact mod-seven95 interface has no solution at this radius, even after
   re-marking. This obstruction is now part of the acceptance specification.

These were failed probes repaired before canonization, not changes to an
existing proved theorem. No scarce theorem identifier is reserved.

## Reproduction

From the worktree root, with Python and g++ on PATH:

    python -B -X utf8 05-knowledge/results/source_reset_branches_20261103/verify.py
    python -B -O -X utf8 05-knowledge/results/source_reset_branches_20261103/verify.py
    python -B -X utf8 05-knowledge/results/source_reset_branches_20261103/seal.py

The first two runs must produce the same frozen `receipt.json` in memory;
ordinary verification does not rewrite it. All critical checks use explicit
exceptions and remain active under-O. `--write` is reserved for intentional
receipt regeneration and `seal.py --write` for intentional manifest renewal.

specific inherited code/proof inputs, and checks relative Markdown links.
It excludes the shared rolling index from content pinning. All new claims
are in these result notes; no old sealed packet is edited. Source pins do
not upgrade inherited literature assertions into independently proved facts.
