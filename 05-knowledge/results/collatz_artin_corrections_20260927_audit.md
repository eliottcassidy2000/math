## 0. Blind derivations (before reading the proofs)

* **Proposition 1(a).** `U(a) = m` with `a` odd means `3a + 1 = 2^v m`, `v = v_2(3a+1) >= 1`, so `a = (2^v m - 1)/3` with `2^v m ≡ 1 (mod 3)`: `v` even if `m ≡ 1`, `v` odd if `m ≡ 2`, none if `3 | m`. Conversely every such `a` (with `v >= 1`) is odd (`2^v m - 1` is odd) and satisfies `v_2(3a+1) = v`, so it is a preimage. **`k = 0` must be excluded**: for `m ≡ 1 (mod 3)`, `2^0 m ≡ 1` and `(m-1)/3` is even. Tree shape: `3 a_i = 2^(k_i) a_(i-1) - 1`, so `a_i mod 3^t` is a function of `a_(i-1) mod 3^(t+1)` and `k_i`; by induction which length-`J` inverse words exist is a function of `m mod 3^J`, and the leaf status of the depth-`J` nodes (`a_J mod 3`) of `m mod 3^(J+1)`. So the note's "shape to depth `J` is a function of `m mod 3^(J+1)`" is true (and slightly more than needed). This is the all-branches form of the mod-6 lane's Theorem 4.1 (which is stated for the greedy inverse word `k_(i+1) = k_min(m_i mod 9)`); Theorem 4.1 is already an inverse-map theorem, so "in the inverse direction" adds nothing, and the note's own one-line argument is what proves the tree version. Proved.
* **Proposition 1(b).** Iterating `a_i = (2^(k_i) a_(i-1) - 1)/3` gives `a_j = (2^(K_j) m - c)/3^j` with `K_l = k_1 + ... + k_l` and `c = sum_(l=1)^(j) 3^(l-1) 2^(K_j - K_l)`, the mod-6 lane's `B_j` (its (4.1)) and, read forward, the carry `S` of the Apéry form `2^(K) m = 3^j a + S`. `c` depends only on the word. Bounds: `c < 2^(K_j) m` (the ancestor is positive), and `c/2^(K_j) = sum_l 3^(l-1) 2^(-K_l) <= sum_l 3^(l-1) 2^(-l) = (3/2)^j - 1` with equality iff all `k_l = 1`. **The note's `0 < c < 2^(k_1 + ... + k_j)` is false**: the word `(1, 1)` (`m ≡ 8 (mod 9)`) gives `a_2 = (4m - 5)/9`, `c = 5 > 4`; e.g. `17 <- 11 <- 7`. It holds when all `k_l >= 2` (the sum is then `< 1`) and fails as soon as the partial sums exceed `1`, which is the typical case for words with several `1`s (`70.4%` of the (start, orbit value) pairs of `3000` random starts). Relative size of the "rounding": the threshold for the word `pi` is `m <= (3^j N + c_pi)/2^(K)`, an additive shift `c_pi/2^K` in `m`; relative to `m` it equals `1 - 3^j n/(2^K m) = 1 - 1/prod_l (1 + 1/(3 a_l)) ≈ sum_l 1/(3 a_l)` over the intermediate ancestors: median `1.2·10^(-3)`, `99%`-quantile `0.16`, maximum `0.20` on the sample. It is a function of the word only.
* **Proposition 1(c).** Exact consequence of (a),(b): `w_N(m) = [m <= N] + #{ pi in Tree(m mod 3^(J+1)) : 2^(K_pi) m - c_pi <= 3^(|pi|) N }`, a function of `(m mod 3^(J+1), m)`, nonincreasing in `m` at fixed class, **with no direct dependence on `m mod 2^k`**; `J` must be the longest Syracuse path from a start `<= N` to `m`, at most the maximal depth (`195` for `N = 10^6`). For a band `I` and the event `E = {m ≡ 7 (mod 8)}` among `m ≡ 3 (mod 4)`, each word `pi` contributes the segment `I ∩ C_pi ∩ (-inf, t_pi]` of an arithmetic progression of odd modulus `3^(|pi|+1)`, in which the residues `3, 7 (mod 8)` alternate, so `|#7 - #3| <= 1` per segment and `|R_w - 1/2| <= (#contributing words)/(2 · sum w)`. This is the only deterministic statement, and it is vacuous: at the depths that carry the weight each word contributes a single value. Nor is there a probability space in which "the expectation is exactly `1/2`": `R_w` on a fixed band is a number, and its limit as `N -> infinity` is `sum_m d(m) X_m / sum_m d(m)` with `d(m) = lim w_N(m)/N` the basin density (empirically existing) and `X_m = [m ≡ 7 (8)]`: a band-specific constant, not `1/2`. The statement that survives is the **model**: the labels `X_m` behave as fair coins independent of the weights `d(m)`, in which case `E[R_w] = 1/2` and `Var(R_w) = 1/(4 n_eff)` (i.i.d. labels) or `(1/4)(n/(n-1))(1/n_eff - 1/n)` (exactly half the labels are `1`, a permutation). The words landing on one value share its label, so the variance scale is `n_eff` over distinct values and not the number of visits: the note's `n_eff` is the right scale for the model.
* **Proposition 2.** `2^v m = 3m' + 1 ≡ 1 (mod 3)`, so `m ≡ 2^(-v)`; `2^(-1) ≡ 2 (mod 3)`, hence `m ≡ 2` iff `v` odd, `≡ 1` iff `v` even; `2^k m ≡ 0 (mod 3)` never equals `1`, so multiples of `3` have no odd preimage. Consequence: all steps into a fixed `m` have the same valuation parity. Proved.
* **The 3-adic marginal above `N`.** A value `x > N` is entered by `v = 1` from below `N` iff `x = (3m'+1)/2` with `m' ≡ 3 (4)`, `(2N-1)/3 < m' <= N`: `83334` such values, all `≡ 2 (mod 3)`. For the rest the law is set by the size profile: if the density of visited values at size `y` is `rho(y) ~ y^(-alpha)`, then `x ≡ 2 (3)` is visited when one of its preimages `(2^k x - 1)/3`, `k` odd, is, and `x ≡ 1 (3)` when one with `k` even is; the ratio of the two chances is `sum_(k odd) 2^(-k alpha) / sum_(k even >= 2) 2^(-k alpha) = 2^alpha`, so `P(x ≡ 2 mod 3 | visited above N) = 2^alpha/(1 + 2^alpha)` and the arrival law is `P(k) ∝ 2^(-k alpha)` within each parity class. Haar (`alpha = 1`) gives `2/3`; the measured profile (`alpha = 2.056`) gives `0.806` against the measured `0.8025`, and the predicted arrival law `0.7595, 0.1826, 0.0439, 0.0106, 0.0025` against the measured `0.7593, 0.1837, 0.0432, 0.0103, 0.0026`. Under the i.i.d. Haar model the Cramér exponent of the drift, `E[(3/2^v)^theta] = 1`, is `theta* = 1` exactly (`3^theta = 2^(theta+1) - 1`), so excursion heights above `N` have tail `1/h` and the visited density falls like `x^(-2)`: `alpha = 2`, `P = 4/5`.
* **Seeds.** Linear: `sum_(k=0)^(n) (n^2 + k) - sum_(k=n+1)^(2n) (n^2 + k) = n^3 + (3n^2+n)/2 - n^3 - (3n^2+n)/2 = 0`, pivot `n^2 + n = 2T_n`. Squares: the difference for a general start `c` is `c^2 - 2n^2 c - n^2(2n+1)`, zero iff `c = n(2n+1) = T_(2n)` (or `c = -n`), pivot `c + n = 2n^2 + 2n = 4T_n`. Cubes: the difference is `c^3 - 3n^2 c^2 - 3n^2(2n+1) c - n^2(7n^2 + 6n + 1)/2` (its constant term is `2T_n^2 - T_(2n)^2`); no integer root (checked to `n <= 300`, all `c`). `T_n = m^2` iff `(2n+1)^2 - 2(2m)^2 = 1`; `x^2 - 2y^2 = 1` forces `x` odd and `y` even, so every solution `(3 + 2 sqrt 2)^k` gives a square triangular number. Schur: `1 + 1 = 2` and `2 + 2 = 4` force `1, 4` together and `2` apart; `1 + 3 = 4` sends `3` with `2`; `5 = 1 + 4 = 2 + 3` kills `[1, 5]`. `7825 = 5^2 · 313`, both `≡ 1 (mod 4)`, so `7825^2 = a^2 + b^2` has `((2·2+1)(2·1+1) - 1)/2 = 7` representations, and as a leg its hypotenuse would exceed `7825`: exactly `7` triples within `[1, 7825]`. Artin for `a = 5`: `Q(sqrt 5) ⊂ Q(zeta_5)` halves `[Q(zeta_n, 5^(1/n)) : Q]` for `10 | n`, adding `sum_(10 | n) mu(n)/(n phi(n)) = (1/40) prod_(q ∉ {2,5}) (1 - 1/(q(q-1))) = A/19`: density `A · 20/19`.

## 3. Overclaims and attributions

* The headline "the 2-adic future is exactly Haar under population measures" and the status "PROVED ... hence the orbit-weighted 2-adic statistics are Haar in expectation" state a model as a theorem (items 5, 6, 14, 37). The theorem is the structural one; the model is well motivated and consistent with the data; the band offsets are frozen, not fluctuations.
* "The `0.497` is resolved" / "was hub noise" (item 11): resolved as "a hub-structure offset of the allowed size, consistent with the fair-coin model", not as "noise".
* Proposition 1(b)'s carry bound is false (item 3), harmlessly.
* THM-4506 (O) glossed as 3-adic (item 19) and THM-4506 (H) paraphrased as a single-orbit worst-case statement (item 34): both wrong; the second would close an OPEN hypothesis.
* "The population average of `L` is a computable 3-adic constant" (item 33): asserted, not established.
* "THM-4505's `15 = 1 + ... + 5`" as an `n = 1` member (item 23): wrong; `(3,4,5)` is right.
* Attribution "Heilbronn's correction (reported by Lehmer's computations)" (item 31): compressed; Artin corrected, Heilbronn published, as far as recollection goes. The owner's `19/20` is the reciprocal of the factor `20/19`; the note uses the right one without saying so.
* THM-4476's recursion quoted in THM-4506's depth form with `L` for the multiplicity (item 32): loose, not wrong.

## 4. What remains open

* Whether the frozen band offsets obey the fair-coin model in the limit (a statement about the joint distribution of basin densities `d(m)` and `m mod 8`); shown consistent over `16` bands (`sum z^2/k = 0.37`), not proved. The existence of `d(m) = lim w_N(m)/N` is itself empirical (stable to `1%` over a decade of `N`).
* Whether a systematic visit-weighted offset of order `-0.002` exists in the mid bands (`9` of `10` bands `14`–`23` below `1/2`, p `= 0.02`, magnitude `-0.0020 ± 0.0025`); no mechanism is visible and Proposition 1 gives none.
* The visited-density exponent above the start range (`2.056` measured; `2` from the Haar model's `theta* = 1`) and hence the exact limit of the 3-adic marginal (`0.8025` measured; `4/5` at `alpha = 2`).
* The population average of the landing multiplicity as a "3-adic constant of the same kind as `c_D`" (asserted); HYP-9161's whole-orbit form (OPEN, and not touched by THM-4506 (H)).
* S13 Proposition 4 as cited (unverified here).
* The Artin/Heilbronn/Lehmer attribution (recollection on both sides).
