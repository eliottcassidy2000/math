# Canonical duality between the tetrahedral Fano models

Session23 extension, 2026-10-21. Independently reviewed in the stated scopes.

The cycle-space Fano plane is canonically S4-equivariantly dual to the edge-plus-formal-point Fano plane. Their natural point actions have orbit sizes4+3 and1+6, so an equivariant point-to-point identification is impossible. Exact incidence, coordinate, contragredient-action and negative controls pass. This is a combinatorial bridge, not a metric sphere identification or a claim to originate projective duality.
