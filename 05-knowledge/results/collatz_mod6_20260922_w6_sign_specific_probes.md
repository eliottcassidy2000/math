## 2. (i) The root asymmetry in the summand reading (S1)

Write the odd step of the halved map as a summand arrow `n -> n + c` with companion `c`, and the unhalved (`C`/`E`-graph) arrow likewise:

```text
halved   (k = 1 step of T_b): n -> (3n + b)/2 = n + c,  c_+ = (n+1)/2,  c_- = (n-1)/2
unhalved (arrow of E_b):      n -> 3n + b     = n + c,  c_+ = 2n + 1,   c_- = 2n - 1
```

A strict summand arrow (the shadow of [arithmetic_braids_20260917_summand](arithmetic_braids_20260917_summand.md), distinct positive parents) needs `c >= 1` and `c != n`.

**S1a (PROVED).** `(n+1)/2 = n` iff `n = 1`; `(n-1)/2 <= 0` iff `n = 1` (for positive odd `n`); `2n + 1 = n` has no positive solution; `2n - 1 = n` iff `n = 1`. Hence on both sheets and in both readings every odd arrow with `n >= 3` is a strict summand arrow, and the strict-summand shadow distinguishes the sheets at `n = 1` only, in a reading-dependent way:

```text
reading  | plus sheet at n = 1                         | minus sheet at n = 1
halved   | 1 -> 2 = 1 + 1: the excluded DIAGONAL (1,1)  | 1 -> 1 = 1 + 0: companion 0, NOT AN ARROW
unhalved | 1 -> 4 = 1 + 3: STRICT                       | 1 -> 2 = 1 + 1: the excluded DIAGONAL (1,1)
```

The census over odd `n <= 10^6` finds the non-strict set `[1]`, `[1]`, `[]`, `[1]` for halved plus, halved minus, unhalved plus, unhalved minus (S1 of the `.out`). Along the cycles, every `k = 1` step is a strict summand arrow (companions `2` on `{5, 7}`; `8, 12, 18, 20, 30` on the seven-cycle) and every `k >= 2` step is a descent, which is not a summand arrow in the halved reading at all (`(3 - 2^k) n + b < 0`); the two trivial cycles are the only cycle arrows that are not strict (plus `1 -> 1` with `k = 2`, a fixed point with companion `(1 - n)/4 = 0` in the accelerated reading, while its `T`-form step `1 -> 2` is the diagonal `(1, 1)`; minus `1 -> 1` with `k = 1` and companion `0`).

**S1b (PROVED; the exact algebraic form of the asymmetry).** In the family `n -> (a n + b)/2^k` with `k = v_2(a n + b)` (all factors of `2` removed), the point `1` is fixed iff `a + b` is a power of two. The companion map of the halved plus arrow is `n -> (n+1)/2` (`a = 1`, `b = 1`, `a + b = 2`): it fixes `1`. The companion map of the halved minus arrow is `n -> (n-1)/2` (`a + b = 0`): it is the unique member of the four `(a, b)` with `a in {1, 3}`, `b = +-1` that does not fix `1`, because it sends `1` to `0`, outside the positive integers. Table in the `.out`: `(3, 1): 4`, `(3, -1): 2`, `(1, 1): 2`, `(1, -1): 0`, and for comparison `(5, 1): 6`, `(5, -1): 4`, `(7, 1): 8`, `(7, -1): 6`. So the honest answer to "what breaks the symmetry at the start of the numbers" is: **the two sheets' odd maps both fix `1` (`3 + 1 = 4`, `3 - 1 = 2`), but only the plus sheet's companion map fixes `1`; the minus companion of `1` is `0`, which the positive half-line does not contain.** Everything else about the strict shadow is sheet-blind (S1a). Typed: source = the plus companion map `(n+1)/2`; target = the minus companion map `(n-1)/2`; map = `b -> -b`; preserved = the affine form and the strictness for `n >= 3`; lost = the fixed point `1` (it becomes `-1`, i.e. `0` after one step on the positive line); sidecar = positivity; test = the family table. Verdict for (i): a PROVED asymmetry, but it is a fact about the point `1` alone; it is the sign law at `n = 1` (the plus fixed point has `k = 2`, the minus has `k = 1`, S6), not a new invariant.

## 3. (ii) Berggren transport: hypotenuse counts and where the sheets touch (S2)

A `(3, b, k)` edge is `x -> y` with `3x + b = 2^k y`, `x, y` odd, `x != y` (`gcd(x, y) = 1` automatically since `gcd(x, y) | b`); its Pythagorean pair `(max, min)` has hypotenuse `(x^2 + y^2)/2`. Counts with hypotenuse `<= X`:

```text
X      | plus edges (triangles) | minus edges (triangles) | C_edge sqrt(X) | |plus - minus| | ratio
10^6   | 507 (507)              | 506 (505)               | 507.8          | 1              | 1.001976
10^7   | 1605 (1605)            | 1605 (1604)             | 1605.9         | 0              | 1.000000
```

At `X = 10^6` this reproduces the Berggren lane's `507`, `506`, `505` and the union `1012` triangles from `1013` directed edges (the triangle `(7, 5)` carries both minus readings `5 -> 7` and `7 -> 5`; the `b = +1` and `b = -1` triangle sets are disjoint). Per-`k` breakdown at `10^7`: plus `620, 447, 261, 138, 69, 35, 17, 9, 4, 3, 1, 1, 0`, minus `619, 447, 262, 137, 70, 35, 18, 8, 5, 2, 1, 0, 1` for `k = 1..13`; every per-`k` difference is in `{-1, 0, +1}`.

**S2a (PROVED).** `N_b(X) = C_edge sqrt(X) + O(log X)` with the sheet-blind constant `C_edge = sum_(k>=1) sqrt(2/(1 + 9/4^k))/2^(k+1) = 0.507819`, and `|N_+(X) - N_-(X)| <= 2 log_2(3 sqrt(2X) + 1)`. *Proof.* For fixed `k` and `b` the sources `x` form one residue class mod `2^(k+1)` (`3x + b = 2^k mod 2^(k+1)` makes `y` odd, and `3` is invertible), cut at the largest `x` with `x^2 + ((3x + b)/2^k)^2 <= 2X`, i.e. `x <= sqrt(2X/(1 + 9/4^k)) + O(1)`; the number of terms of an arithmetic progression of difference `2^(k+1)` below that bound is `sqrt(2X/(1 + 9/4^k))/2^(k+1) + O(1)`, which gives the main term after summing over `k <= log_2(3 sqrt(2X) + 1)` (beyond that no edge exists, since `2^k <= 3x + 1`). For the difference: the two sheets' progressions for the same `k` have the same difference and cut-offs that differ by less than one period, so their counts differ by at most `1`, and the exclusion `x != y` removes at most one more edge per sheet and `k` (`(1, 1)` is a plus edge at `k = 2` and a minus edge at `k = 1`); summing over the at most `log_2(3 sqrt(2X) + 1)` values of `k` gives the bound. QED. The script prints the looser form `2(k_max + 1)` with `k_max = 12, 13` (values `26`, `28`), `k_max` the largest realised `k`; the observed per-`k` differences all lie in `{-1, 0, +1}` (audit A2 checks this at both `X`), consistent with the `1 + 1` per `k` of the proof. Verdict: the asymptotic count is SHEET-BLIND; the `507` vs `506` at `10^6` is the `O(log X)` term, not a sign effect, and at `10^7` it is `0`.

**S2b (PROVED, inherited: the bijection is the control's S6 and the forward clause is Berggren Theorem 3.1; only the hypotenuse-window counts are this lane's, FINITE-EXACT).** The sheets touch at every `k = 1` edge: the `B3` child of `x -> y` (`k = 1`, sheet `b`) is the pair `(2x + b, y)`, which reads `(2x + b) -> y` with `3(2x + b) - b = 6x + 2b = 4y`, a `k = 2` edge of sheet `-b` (this is the generic clause of [berggren_edge_transport Theorem 3.1](collatz_mod6_20260921_berggren_edge_transport.md) and the bijection of [the control's S6](collatz_mod6_20260922_minus_sheet_positive_control.md); the script re-verifies the identity on every `k = 1` edge below `10^7`). Counts: at `X = 10^6` the plus sheet has `196` `k = 1` edges and `141` of their minus `k = 2` children also lie below `X`; the minus sheet `195` and `141`; at `X = 10^7`: `620`/`447` and `619`/`447`.
