## 2. An unrestricted count, without a class list

Let `a_n` count ordinary tournament isomorphism classes, including `a_0=1`.
For a partition lambda with odd parts `l_1,...,l_r`, set

```
e(lambda) = sum_i (l_i-1)/2 + sum_(i<j) gcd(l_i,l_j),
z_lambda = product_d d^(m_d) m_d!.

a_n = sum_(lambda |- n, all parts odd) 2^e(lambda)/z_lambda.       (1)
```

This is a quotient by the actual full relabeling action `S_n`, not a guess
based on cyclic-triple shapes. An even vertex cycle contains an antipodal
pair whose orientation is reversed by a permutation power, so contributes
zero. For an all-odd permutation, every unordered-pair orbit can be oriented
independently. A length-l cycle contributes `(l-1)/2` internal pair orbits;
two cycles contribute `gcd(l,m)` cross orbits. There are `n!/z_lambda`
permutations of the prescribed type. Burnside proves (1).

This is also the Davis formula recorded by the primary
[OEIS A000568 entry](https://oeis.org/A000568). Its
[b-file](https://oeis.org/A000568/b000568.txt) was retrieved on 2026-10-28;
its 51 values through order 50 are embedded in the checker and consulted
**only after construction**, as an audit. No external input file is needed.

An independent exponent calculation averages over the cyclic subgroup
generated by the given permutation. If its order is `L`, write

```
f(d) = sum_(l_i divides d) l_i,
e(lambda) = (1/L) sum_(d divides L) phi(L/d) binom(f(d),2).        (2)
```

Since `L` is odd, a power fixes an unordered pair exactly when it fixes both
vertices. Ordinary Burnside on the pair action proves (2), independently of
the gcd decomposition. The code also literally follows ordered pairs and
detects orientation-reversing returns, including every even-cycle zero case
through order 14. Neither verification enumerates tournament classes.

## 3. How canonical metagraph composition recreates the same answer

Let `B=Z_T` include the empty tournament, `F=B-1`, and let `P` be the sum
of normalized vertex-action cycle indices of prime tournaments of order
at least three. Let `S` denote the nonempty strongly connected species,
including the singleton. Canonical strong-module decomposition gives

```
T = SEQ(S),       S = X + P_species composed with (T-1),
P plethysm F = 1 - B^(-1) - p_1.                               (3)
```

The structural input is Gallai's theorem: maximal proper strong modules
partition a nonsingleton tournament, with transitive or prime quotient.
See [Boussaïri–Chergui–Ille–Zaidi, Theorem 16](https://arxiv.org/html/1805.04607v1).
At a prime root, decorations give isomorphic inflations exactly when the
actual quotient automorphism action carries one decoration to the other.
At a transitive root, maximal strongly connected components have intrinsic
order. These facts remove both slot overcounting and parenthesization
overcounting.

The entire explicit input is

```
B = sum_(lambda all odd) 2^e(lambda) p_lambda / z_lambda.
```

Because `F=p_1+terms of weight>=2`, substitution by `F` preserves the first
nonzero homogeneous part. Starting with `R=1-B^(-1)-p_1`, successively take
the weight-n part of the residual as `P_n`, and subtract `P_n plethysm F`.
This recovers the unique aggregate prime index to any requested finite
weight. It is not ordinary univariate inversion.

Now discard `B` and reconstruct ordinary counts from `P` alone:

```
t(x) = 1/(1-s(x)),
s(x) = x + P(t(x)-1, t(x^2)-1, t(x^3)-1, ...).                (4)
```

The coefficient at degree n is recursive: every root has at least three
nonempty slots, so the needed child degrees are smaller than n. The new
script implements this scalar reconstruction separately from prime-index
recovery. It matches (1) through 20.

**Noncircularity boundary:** (1) independently determines A000568. Recovering
`P` from this `B` and substituting back is a structural consistency round
trip, not an independent numerical discovery. It demonstrates that no
unspecified prime census remains in the aggregate formula; it does not
produce the prime representatives or an all-prime class atlas.

For comparison, the class-generating root-switch carrier retains pointed
states `(parent, attachment mask)/Aut(parent)`, with mask and parent moved
by the **same** identification. For `N>=1`, its rerooting matrix has one block per
ordinary child:

```
Q_U = 1_r (m_1,...,m_r),
Q^2=NQ,       a_N=tr(Q)/N=rank_Q(Q)=rank_F2(Q).
```

The empty order is treated separately: `a_0=1`; neither `tr(Q)/N` nor
rerooting is used at `N=0`. Here `m_i` are actual vertex-orbit sizes. They are odd because tournament
automorphism groups have odd order. Distinct row supports identify children
and generate the next representative bank. This is constructive closure,
but not a small scalar state. Counts alone cannot regenerate those rows.

## 4. A precise coarsest carrier for ordinary substitution

**Theorem (universal rigid-palette equivalence).** Fix `K>=3`. For two finite
inventories of ordinary prime tournament classes with root arities in
`3,...,K`, the following are equivalent:

1. Their aggregate vertex-action cycle indices agree.
2. Their ordinary inflation counts by total size agree for every finite
   nonempty finite palette of pairwise distinct nonempty rigid transitive
   child types.
3. Their ordinary inflation counts by total size agree for the **single**
   palette

   `TT_1, TT_(K+1), TT_((K+1)^2), ..., TT_((K+1)^(K-1))`.

For inventories of distinct prime classes, canonical prime-root uniqueness
ensures there is no cross-root identification. If an inventory carries
integer multiplicities, each copy is a separately tagged root and every
inflation count retains those tags: copies are counted with multiplicity,
**never deduplicated after the copy tags are forgotten**. The equivalence
holds either for sets of distinct classes or for this tagged-multiset
convention. Every child in every palette is nonempty, and palette entries
are distinct ordinary isomorphism types.

**Proof.** For independent color variables `y_1,...,y_K`, Burnside gives the
weighted color-orbit polynomial

```
C(y) = P(p_d := y_1^d + ... + y_K^d).                         (5)
```

Thus (1) implies (2), and (2) implies (3).

The substitution in (5) is injective on power-sum polynomials of weighted
degree at most K. An elementary proof avoids an abstract invariant-ring
theorem. For a partition lambda, expanding `product_(d in lambda) p_d`
assigns each factor to a color. If all factors use distinct colors, the
exponent partition is lambda; assigning two to one color merges parts and
strictly reduces the number of nonzero exponents. Therefore the coefficient
matrix from `p_lambda` to monomials with exponent partition mu is triangular
when partitions are ordered by decreasing number of parts. Its diagonal is
`product_d m_d!`, nonzero over Q. At most K colors are required. Different
homogeneous weights cannot mix.

Finally substitute `y_j=x^((K+1)^(j-1))`. Every exponent vector in (5) has
entries between zero and K. Its x-degree is its unique base-(K+1) encoding,
so distinct monomials cannot collide. Consequently the single univariate
inflation count series in (3) determines `C(y)`, which determines `P`.
This proves (3) implies (1). All palette children are actual rigid
tournaments of distinct sizes, not formal extra labels. QED.

**What 'coarsest' means.** Equality of aggregate cycle indices is exactly
indistinguishability by this entire observer family. Any purported sufficient
invariant that identifies two different indices is defeated by a finite
rigid palette. Thus the cycle index is a coarsest sufficient **quotient** for
universal ordinary composition; this is stronger than sufficiency alone.

It is also closed under the corresponding ordinary species sums, ordered
products and plethystic substitutions, hence supplies the counting side of
the canonical grammar in (3). Separate prime classes and separate abstract
groups are unnecessary for these aggregate ordinary counts.

**What is not claimed.** The huge palette is a separation certificate, not
an efficient test. This theorem is not a bit-complexity lower bound, not
minimality for the one fixed all-tournament series `t(x)`, and not a
class-faithful or symmetry-distribution carrier. Existing terminal-moment
compression can be smaller for a narrower, fixed finite-horizon observer.

## 5. The 81/27 hostile survives, for the right reason

Both twelve-vertex tournaments `T` and `U` above have the same **labelled**
67 cyclic triples. Their child cycle indices are also identical:

```
z = (p_1^4 + 2 p_1 p_3)/3.
Z_T = (z^3 + 2 psi_3(z))/3,
Z_U = z^3.
```

The first root coloring is constant, so its decorated quotient stabilizer
is C3. The second has a distinguished nonisomorphic child, so its stabilizer
is trivial. Consequently `|Aut(T)|=81` and `|Aut(U)|=27`; T has 36
automorphisms of cycle type `(3,9)` while U has none. The new checker directly
enumerates their full automorphism sets by adjacency-preserving backtracking;
it does not assume this product formula.

This does not refute section 4. That theorem sums over **all** decorations
in the given palette; it does not recover a particular decoration's
stabilizer from the children’s individual cycle indices. For individual
composition, retain ordinary child-isotype equality and the actual root
action. For stabilizer distributions, the Session80 table-of-marks plus
subgroup slot-orbit data is sufficient, whereas an individual cycle index
can already fail. For actual metagraph edges or attachment transport, more
aligned operation data are still required.

The strongest survivor is therefore not a symmetry-blind tournament
representation. It is an exact, observer-scoped aggregate quotient, with the
individual 81/27 distinction explicitly outside the information it promises.
