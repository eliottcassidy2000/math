## 0. The answer in one paragraph

For a graph in which every vertex has exactly one out-edge, "unique" has four
precise readings, and three of them are now theorems while the fourth is the
conjecture. **Labelling:** the Collatz graph `(N, T)`, `T(n) = n/2, 3n+1`, has
no automorphism except the identity; more strongly, two vertices not
divisible by 3 never have isomorphic backward trees (Theorem R), so the bare
unlabelled graph remembers every integer. **The map:** inside the family
`n/2, 3n+c`, the isomorphism type of the graph determines `c` (Corollary R2).
**Finite places:** no periodic function is invariant unless constant (every
residue graph `Gamma_M` is connected, Proposition M), and this also holds for
`3n-1`, which has three components; so which component a vertex lies in is
invisible modulo every `M` — it is an archimedean fact. **The component:** the
trivial component is categorical — up to isomorphism it is the only connected
"Collatz-typed" graph with a three-cycle through a branch vertex (Theorem C).
The conjecture is the statement that `(N, T)` is isomorphic to it, an
immediate equivalence; Theorem C's content is the local characterisation.
The cycle half of that statement is a family of first-order sentences, each a
finite check (lonely-runner type). The divergence half is not first-order at
all: the complete first-order theory of the Collatz graph, in the language
of the map alone, has models with infinite aperiodic orbits (Proposition L).
That is no barrier to proofs in PA or ZFC. The owner's Eckmann–Hilton remark
becomes exact. Every fibre is produced by two "multiplications", `u ↦ 2u` and
`u ↦ (u-1)/3`. They coincide only at the 3-adic number `u = -1/5`. That point
is the fixed point of `x ↦ 6x+1`, one of the two orders of composing ×2 with
the odd step; the other order, `x ↦ 6x+2`, fixes the common child `-2/5`. It
is the only place where a fibre can be symmetric, i.e. where the two preimage
subtrees are isomorphic. `-1/5` is 2-adically *odd*, so it is never an even
vertex of a graph on `Z` or `Q`: **no fibre of a rational Collatz graph is
symmetric**, and the separation lemma that excludes symmetric fibres also
yields rigidity of the whole graph.

Near-coincidences are Beck–Everett's harmful relations turned around. The
fibre at `w` stays balanced to depth `d` with `2v - 1 ≤ d ≤ 5v - 6`, where
`v = v_3(5w+1)`; the observed value is about `3v - 1`. A lonely-runner
counterexample is forced to balance its fibres, while the Collatz graph can
never balance one.

The primes enter exactly here. For `n/2, an + 1` with `a` an odd prime, the
backward trees identify the vertices iff 2 is a primitive root modulo `a^2`
(Theorem R_a). Remembering each vertex from its own past is Artin's question,
refined by Wieferich: yes for `3, 5, 11, 13, ...`, no for `7, 17, 23, 31,
...`. Rigidity of the whole graph needs only non-Wieferich `a` (audit
remark).

The forward side is the mirror image. The 2-adic structure is *universal*:
every map `n/2, (an+b)/2` is the same shift, the same De Bruijn graph. So the
integers are the diagonal on which a universal forward structure and a rigid
backward structure name the same point.

## 2. The backward tree is 3-adic (PROVED)

Throughout `T(n) = n/2` (`n` even), `3n + 1` (`n` odd) on `N = {1, 2, ...}`.
The preimages of `n` are `2n` and, exactly when `n ≡ 4 (mod 6)`, the odd
number `(n-1)/3`. The *unfolded backward tree* `B(n)` is the rooted tree of
backward paths (it differs from the set of predecessors only on the cycle
`1 → 4 → 2 → 1`, where paths wind). `X ~_D Y` means that the truncations at
depth `D` are isomorphic as rooted trees with unordered children.

**Lemma 1.** For `x ∈ Z_3` let `e(x)` be the rooted tree whose root has the
child `e(2x)`, and also the child `o((x-1)/3)` when `x ≡ 1 (mod 3)`; let `o(x)`
have the single child `e(2x)`. Then `B(n) = e(n)` for even `n` and `o(n)` for
odd `n`. The depth-`d` truncation of `e(x)` depends only on `x mod 3^⌈d/2⌉`,
that of `o(x)` on `x mod 3^⌊d/2⌋`.

*Proof.* `n ≡ 4 (mod 6)` iff `n` is even and `n ≡ 1 (mod 3)`, and an odd `n` is
never `3m+1` with `m` odd. Induction on depth gives the trees; the precision
satisfies `M_e(d) = max(M_e(d-1), M_o(d-1) + 1)`, `M_o(d) = M_e(d-1)`. ∎

**Lemma 2 (four shapes).** For `u ∈ U = 1 + 3Z_3` write `A(u) = e(u)`,
`node[X]` for a root with the single child `X`, and `P` for the infinite path.
With `z = (u-1)/3`, the root of `A(u)` has the two children `node[A(4u)]` and
`Y(u)`, where `Y(u) = P` if `u ≡ 1 (mod 9)` (type P), `node[node[A(4z)]]` if
`u ≡ 4 (mod 9)` (type L), `node[A(2z)]` if `u ≡ 7 (mod 9)` (type E). Every `B(n)`
is exactly one of `P` (iff `3 | n`), `A(n)` (`n ≡ 4 mod 6`), `node[A(2n)]`
(`n ≡ 2 mod 3`, either parity), `node[node[A(4n)]]` (`n` odd, `n ≡ 1 mod 3`);
the four shapes have first branching depth `∞, 0, 1, 2`. In particular
`e(x) ≅ o(x)` whenever `x ≢ 1 (mod 3)`: parity alone is invisible.

*Proof.* `e(2u)` has `2u ≡ 2`, hence the single child `e(4u) = A(4u)`; `o(z)` has
the single child `e(2z)`, which is bare if `3 | z`, `node[A(4z)]` if `z ≡ 1`,
`A(2z)` if `z ≡ 2`. ∎

The three root types are visible at depth 4: the vertex counts at depths
`1..4` are `(2,2,3,3)` for P, `(2,2,3,4)` for L and `(2,2,4,4)` for E.

## 3. The separation lemma (PROVED + FINITE-EXACT)

**Lemma 3.** Let `s(D)` be the largest `k` such that `A(a) ~_D A(b)` implies
`a ≡ b (mod 3^k)` for all `a, b ∈ U`. Then `s(D) ≥ 2` for `D ≥ 4` and
`s(D) ≥ 1 + s(D-5)` for `D ≥ 9`. Hence `s(D) ≥ 2 + ⌊(D-4)/5⌋`, and `A` is
injective on `U`: `A(a) ≅ A(b)` implies `a = b`.

*Proof.* `s` is non-decreasing. Let `A(a) ~_D A(b)`. The root types agree, so
`a ≡ b (mod 9)`; write `z_a = (a-1)/3`, `z_b = (b-1)/3`.

* **Type L.** The children have different shapes (first branching at relative
  depth 1 against 2), so the isomorphism matches them straight, and
  `A(4z_a) ~_(D-3) A(4z_b)`. Hence `z_a ≡ z_b (mod 3^s(D-3))` and
  `a ≡ b (mod 3^(s(D-3)+1))`.
* **Type E.** Both children have the shape `node[A(·)]`. A straight match
  gives `A(2z_a) ~_(D-2) A(2z_b)`, hence `a ≡ b (mod 3^(s(D-2)+1))`. A crossed
  match gives `A(4a) ~_(D-2) A(2z_b)` and `A(2z_a) ~_(D-2) A(4b)`. With
  `t = s(D-2)`, these say `12a ≡ 2b - 2` and `2a - 2 ≡ 12b (mod 3^(t+1))`, and
  adding them gives `14(a - b) ≡ 0`. So again `a ≡ b (mod 3^(t+1))`.
* **Type P.** The side child is bare, so the match is straight and
  `A(4a) ~_(D-2) A(4b)`, with `4a ≡ 4 (mod 9)` of type L. Applying the L case
  at depth `D-2` gives `a ≡ b (mod 3^(s(D-5)+1))`.

Monotonicity gives `s(D) ≥ 1 + s(D-5)`. A full isomorphism agrees at every
depth, so `a ≡ b` modulo every power of 3. ∎

The crossed case is the whole content: the duplicator may swap the two

## 4. Theorem R: the Collatz graph is rigid (PROVED)

**Theorem R.** (i) If `m ≠ n` are positive integers with `3 ∤ mn`, then
`B(m) ≇ B(n)`. (ii) The only automorphism of the functional graph `(N, T)` is
the identity. (iii) The same holds for `T` on `Z`, and on
`R_6 = Z_(2) ∩ Z_(3)` (rationals with denominator prime to 6, parity of the
numerator).

*Proof.* (i) By Lemma 2 the shape of `B(n)` (first branching depth `0, 1, 2`) is
an isomorphism invariant, and within a shape `B(n)` is `node^k[A(u)]` with
`u = n, 2n, 4n`; by Lemma 3 the tree determines `u ∈ Z_3`, hence `n ∈ Z_3`,
hence `n` (the map `Z → Z_3` is injective). (ii) An automorphism `σ` carries
`B(n)` isomorphically to `B(σ(n))`, so by (i) it fixes every `n` with `3 ∤ n`.
If `3 | n`, write `n = 2^j m` with `m` odd. Then `w = T^(j+1)(n) = 3m + 1` is
even and `≡ 1 (mod 3)`, so `σ(w) = w`. The two preimages of `w` are `2w`
(fixed, since `3 ∤ 2w`) and `m`, so `σ(m) = m`. The chain `2m, 4m, ..., n`
consists of unique preimages, so it is fixed too. (iii) Use `Q → Q_3`
injective in (i). The same forward argument works for numerators divisible
by 3 (with `m` of odd numerator, `3m + 1` is even and `≡ 1`). The fixed point
`0` of `Z` and of `R_6` is the only fixed point, since `3x + 1 = x` gives `x = -1/2`. ∎

Checked directly (`.out`, section B). The depth-25 backward trees of the
`1334` vertices `n ≤ 2000` with `3 ∤ n` are pairwise distinct. For
`n ≤ 6000`, every coincidence at depths 12, 16 and 20 is between 3-adically
close labels of the same shape, and the bare class is exactly the
multiples of 3. The integer trees coincide with the abstract `e/o` trees,
and an independent string encoding agrees with the hash-consed one.

**Corollary R1 (one labelling).** If a functional graph is isomorphic to
`(N, T)`, the isomorphism is unique: the maps `f : N → N` with `(N, f) ≅ (N, T)`
are the conjugates `π T π^(-1)`, each for exactly one bijection `π`.

**Corollary R2 (the map is determined).** Let `T_{3,c}(n) = n/2, 3n + c` with
`gcd(c, 6) = 1`.

(a) On `Z`: `(Z, T_{3,c}) ≅ (Z, T_{3,c'})` iff `c' = ±c`. Negation is an
isomorphism between the two sheets, and otherwise the label rescaling
below applies everywhere.

(b) On `N` (so `c ≥ 1` or `c = -1`): `(N, T_{3,c}) ≅ (N, T_{3,c'})` iff
`c = c'`. In particular the Collatz graph is isomorphic to no other `3n + c`
graph on `N`, including `3n - 1`.

*Proof.* `n ↦ n/c` conjugates `T_{3,c}` on `Z` onto `T` on `(1/c)Z`, a union
of components of `(R_6, T)` that is closed under both rules. So the backward
tree of `n` is the full abstract tree of the label `n/c`. An isomorphism `φ`
therefore has `φ(n)/c' = n/c` in `Z_3` for every `n` with `3 ∤ n`, i.e.
`φ(n) = (c'/c) n`. Taking `n = 1` and using symmetry gives `c' = ±c`, which
proves (a).

On `N` one caveat applies. The odd preimage `(n - c)/3` is negative for the
finitely many even `n < c` with `n ≡ c (mod 3)` (example: `c = 5`, where the
vertex 2 loses `-1`). So exactly those fibres are truncated, and only the
vertices on their forward orbits `E_c` have a backward tree that is not the
full abstract one. For `c = 5`, `E_5 = {1, 2, 4, 8}`.

* `φ` maps forward orbits to forward orbits, so `E_c ∪ φ^(-1)(E_c')` is a
  finite union of forward orbits.
* Such `n` with `3 ∤ n` and `gcd(n, c) = 1` exist outside it. The levels of a
  backward tree grow exponentially, each forward orbit meets a level at most
  once, and coprimality to `c` is inherited by preimages.
* For such `n`, `φ(n) = (c'/c) n`. This gives `c | c'`, and by symmetry
  `c = c'` (positivity excludes `c' = -c`).
* For `c = -1` it is simpler still: `(N, T_{3,-1})` has the 2-cycle `{1, 2}`
  and `(N, T)` has no 2-cycle. ∎

**Theorem R_a (prime multipliers: backward separation is Artin's question at
`a^2`).** Let `a` be an odd prime and `T_a(n) = n/2` (`n` even), `an + 1`
(`n` odd) on `N`. Labels now live in `Z_a`, with `e(x)` having the children
`e(2x)` and, when `x ≡ 1 (mod a)`, `o((x-1)/a)`. The backward trees of `T_a`
*separate the vertices prime to `a`* (each such vertex is determined by its
backward tree alone) **iff 2 is a primitive root modulo `a^2`**. In that case
`Aut(N, T_a) = 1` and `s_a(D) ≥ 2 + ⌊(D - a - 1)/(2a - 1)⌋`; for `a = 3` this is
Lemma 3 and Theorem R. The iff concerns separation only. Injectivity of
`u ↦ A(u)` and whole-graph rigidity hold more widely (audit remark below).

*Proof (if).* Let `κ(x)` be the least `k ≥ 0` with `2^k x ≡ 1 (mod a)`.

* **Shapes.** `e(x) = node^κ(x)[A(2^κ(x) x)]`, and `o(x) = e(x)` unless
  `κ(x) = 0`, in which case `o(x) = node^(a-1)[A(2^(a-1) x)]`. So the
  first-branching depth `d` and the `A`-label `u` return `x = 2^(-d) u`.
* **Branch vertices.** At a branch vertex `u` the continuation is
  `node^(a-2)[A(2^(a-1) u)]`. The side `o(z)`, with `z = (u-1)/a`, first
  branches at a depth in `{1, ..., a-1}`, or is bare when `a | z`. The two can
  be confused only when `κ(z) = a - 2`, i.e. `z ≡ 2 (mod a)`.
* **Crossed match.** It gives `2au ≡ u' - 1` and `u - 1 ≡ 2au' (mod a^(t+1))`.
  Their sum is `(2a + 1)(u - u') ≡ 0`, so `u ≡ u'`.
* **Bare side.** After a bare side, the next side down the spine is
  `z_1 = 2^(a-1) z + W`, where `W = (2^(a-1) - 1)/a` is the Fermat quotient.
  `W ≢ 0 (mod a)` exactly because 2 is a primitive root mod `a^2`, so that
  side is not bare.
* **Recursion.** Hence `s(D) ≥ 1 + s(D - 2a + 1)`, with the root types
  (`z mod a`) visible at depth `a + 1`.
* **Multiples of `a`.** For `n = 2^j m` with `a | m` odd, the vertex
  `w = am + 1 ≡ 1 (mod a)` is fixed. Its preimages are `2w` (fixed) and `m`.

*Proof (only if).*

* If 2 is not a primitive root mod `a`, every unit outside `<2>` has a spine
  that never branches. Its tree is the bare path, the same as for multiples
  of `a`.
* If 2 is a primitive root mod `a` but not mod `a^2`, then `W ≡ 0 (mod a)`.
  A spine whose first side is bare then has only bare sides, and every label
  `≡ 1 (mod a^2)` has the same comb-shaped tree. Such an `a` would be a
  Wieferich prime with 2 primitive; the known Wieferich primes 1093 and 3511
  have `ord_a(2) = 364` and `1755`, so this case is not known to occur. ∎

**Audit remark (SKETCH + FINITE-EXACT, from the independent audit).** Let

* `u ↦ A(u)` is injective iff `W_r ≢ 0 (mod a)`, i.e. iff `a` is not
  Wieferich. Along a spine the side residues advance by `W_r (mod a)`, so
  runs of bare sides are bounded.

  is bare is fixed through its forward image `am + 1`, which branches.
* Example `a = 7`: `s_7(D) = 1` for `D ≤ 10` and `2` for `D = 11..16`, so `A`

So whole-graph rigidity of `n/2, an + 1` holds for every odd prime not known
to be Wieferich. Backward *separation* needs 2 primitive mod `a^2`. The

## 5. The Eckmann–Hilton point `-1/5` (PROVED + FINITE-EXACT)

**Proposition EH.** Let `μ_2(x) = 2x` and `μ_3(x) = (x-1)/3` be the two preimage
maps at a branch vertex.

1. `μ_2(x) = μ_3(x)` iff `x = -1/5`. Equivalently, the two composites of the
   commuting multiplications with the carry — double then take the odd
   forward step, `x ↦ 6x + 1`, and take the odd step then double, `x ↦ 6x + 2` —
   have fixed points `-1/5` and `-2/5`. These are the branch vertex and its
   two coinciding children. The linear parts agree (both are `×6`: the
   interchange law holds for multipliers, which is Eckmann–Hilton), the
   translations differ by the carry, and the fixed points differ by the
   factor 2.
2. `A(u)` has a non-trivial automorphism iff some branch vertex of `A(u)` has
   label `-1/5`. At such a vertex the two children carry the same label `-2/5`,
   and `e(-2/5) ≅ o(-2/5)` because `-2/5 ≡ 2 (mod 3)`.
3. The only rational with 3-adic value `-1/5` is `-1/5`, whose numerator is
   odd. So no even vertex of the graph on `Z` or on `R_6` sits at the
   Eckmann–Hilton point, and every backward tree there is a rigid rooted
   tree. **No fibre of a rational Collatz graph is symmetric, because the
   only symmetric point is 2-adically odd.** Whole-graph rigidity (Theorem R)
   needs the separation lemma in addition. In a Collatz-typed graph in
   which label and parity do not identify vertices, such as the skew product
   of §6, other automorphisms appear. For `n/2, an + b` the point is
   `-b/(2a - 1)`, always odd because `b` is.
4. **Near balance.** For `w ≡ 4 (mod 6)` let `v = v_3(5w + 1)`. The deepest `d`
   with `B(2w) ~_d B((w-1)/3)` is `1` if `v = 1`, and satisfies
   `2v - 1 ≤ d ≤ 5v - 6` if `v ≥ 2`.

*Proof.* (1) Solve `2x = (x-1)/3`. (2) A non-identity automorphism swaps two
siblings below some fixed vertex. By Lemmas 2 and 3 the siblings are
isomorphic only when the branch label `x` has `A(4x) ≅ A(2(x-1)/3)`, i.e.
`4x = 2(x-1)/3`, i.e. `x = -1/5`; conversely the swap at such a vertex is an
automorphism. (3) `Q → Q_3` is injective. (4) `B(2w) = node[A(4w)]`, and
`4w - 2(w-1)/3 = 2(5w+1)/3`. If `v ≥ 2`, then `z = (w-1)/3 ≡ 2 (mod 3)` and
`B(z) = node[A(2z)]`, with labels agreeing modulo `3^(v-1)`. Lemma 1 gives
equality of the truncations to depth `2v - 1`, and Lemma 3 gives
`v - 1 ≥ s(d-1) ≥ 2 + ⌊(d-5)/5⌋`, i.e. `d ≤ 5v - 6`. If `v = 1`, the side
child has a different shape. ∎

## 6. Universal forward, rigid backward: the two multiplications (PROVED + CITED)

* **Forward is universal.** For every odd `a` and `b` the map `n/2, (an+b)/2`
  on `Z_2` is conjugate to the one-sided 2-shift by the parity-vector map
  (CITED for `3x+1`; the proof only uses odd multipliers), and its graph
  modulo `2^k` is the binary De Bruijn graph (Laarhoven–de Weger, proved
  there for `3x+1`; the same argument applies to every odd `a`, `b`). The
  2-adic, forward-in-time structure cannot tell `3n+1` from `5n+1` or `3n-1`.
* **Backward is rigid.** The 3-adic, backward-in-time structure determines
  every vertex prime to 3 (Theorem R).
* **The owner's "two identical multiplications".** ×2 is a shift on `Z_2` and
  a unit on `Z_3`; ×3 is a unit on `Z_2` and a shift on `Z_3`. The forward
  observer reads a vertex in `Z_2` (its parity vector), the backward observer
  in `Z_3` (its backward tree). On the diagonal `Z → Z_2 × Z_3` both readings
  name the same integer. The graph therefore carries two complete coordinate
  systems for each vertex, one per prime, read in opposite time directions,
  and they agree because the vertex is an integer.
* **The decoupled graph.** The *skew product* on `Z_2 × Z_3` takes parities
  from the first coordinate and labels from the second. It satisfies the
  local rules of §9 and is the universal Collatz-typed graph.
  * Its cycles are all diagonal and rational. A cycle's affine return map
    `x ↦ (3^p/2^A) x + β` has a unique fixed point in `Q_2` and in `Q_3`, the
    same rational.
  * Its acyclic components are plentiful: every point whose parity sequence
    is not eventually periodic lies in one.
  * It has automorphisms, all off the diagonal: the swaps below the points
    `(y_2, -1/5)` with `y_2` even, and the shifts of the all-even bare chains
    `(0, 2^k y)`, `y ∈ 3Z_3 ∖ {0}`.

## 7. Finite places see one component (PROVED + FINITE-EXACT)

**Proposition M.** For every `M ≥ 1`, the graph `Gamma_M` on `Z/M` with an
edge `{n mod M, T(n) mod M}` for every `n ≥ 1` is connected. Hence every
periodic `T`-invariant function on `N` is constant.

*Proof.* **Odd `M`.** Every residue has even and odd representatives, so
`s ~ 2s` and `s ~ 3s + 1` for all `s`. Then `s ~ 2s ~ 6s + 1` and
`s ~ 3s + 1 ~ 6s + 2`, so `6s + 1 ~ 6s + 2`.

* If `3 ∤ M`, this is `t ~ t + 1` for all `t`.
* If `3 | M`, it gives `t ~ t + 1` for every `t ≡ 1 (mod 3)`, and every `r`
  satisfies `r ~ 3r + 1 ≡ 1 (mod 3)`. For `t ≡ 1 (mod 3)`, both
  `t ~ t + 1 ~ 2t + 2` and `t ~ 2t ~ 2t - 1` hold, so `2t - 1 ~ 2t + 2`. As
  `t` runs over `1 + 3Z/M`, `u = 2t - 1` runs over `1 + 3Z/M`. So `u ~ u + 3`
  on that coset, which therefore lies in one class.

**`M = 2M'`.** Reduction modulo `M'` maps edges onto edges. Each fibre
`{s, s + M'}` is connected: the even `n ≡ 2s (mod 2M')` have
`n/2 ≡ s` or `s + M'`. So paths lift, and induction on the power of 2
finishes the proof. ∎

The same proof works for `3n - 1`. Checked (`.out`, section D):
`3n+1`, `3n-1`, `5n+1` and `7n+1` have `Gamma_M` connected for all `M ≤ 1500`,
while `3n+5` and `3n+7` have a two-component `Gamma_5` and `Gamma_7`.
**Reading.** The graph of `3n - 1` on `N` has at least three components
(cycles through 1, 5 and 17), yet no periodic function separates them. So
which component a vertex belongs to is not detected by any finite place. This
is the component-level counterpart of the local–global lane's finding for
cycle gates, and it is the precise sense in which the uniqueness of the
Collatz component is an archimedean question. The finite-place obstructions
that do exist are the `gcd(n, c)` invariants of `3n + c` with `|c| > 1`.

## 8. The logical type of the two halves (PROVED, elementary model theory)

**Proposition L.** In the language with one unary function symbol `f`:

* (a) For each `L`, "no cycle of length `L` other than the trivial
  three-cycle" is a first-order sentence, decidable by a finite computation:
  a cycle of length `L` is a parity word whose rational fixed point must be a
  positive integer.
* (b) Unconditionally, the complete theory `Th(N, T)` has a countable model
  with an element `c` whose forward orbit is infinite. Use compactness with
  the sentences `f^(k+L)(c) ≠ f^k(c)` for all `k ≥ 0`, `L ≥ 1`. Any finite
  subset of them, with `k, L ≤ B`, is satisfied in `(N, T)` by `c = 2^m` with
  `m ≥ 2B`, whose first `m` iterates are distinct powers of 2.
* (c) The component of `c` in that model is acyclic, since in a component
  with a cycle every orbit is eventually periodic.

So no set of first-order properties of the abstract graph implies the
absence of acyclic components, while the absence of non-trivial cycles is a
conjunction of first-order sentences. Here "divergent" can only mean
"infinite forward orbit": the language has no order. This is a fact about
the graph language alone. It is **not** a barrier to proofs in PA or ZFC,
which may use arithmetic and induction. (Audit correction: the first draft
proved (b)–(c) only under the hypothesis that `(N, T)` has no non-trivial
cycle, while stating the conclusion unconditionally.)

This is the sixteenth note's "cycle half is of lonely-runner type, divergence
half is global" as a theorem about definability. Rigidity is not
first-order either: a saturated elementary extension of `(N, T)` has
non-trivial automorphisms. Theorem R uses the infinite backward trees, which
first-order logic cannot see.

## 9. Categoricity of the trivial component (PROVED)

Call `(V, f)` *Collatz-typed* if there are a label `ℓ : V → Z_3` and a parity
`π : V → {0, 1}` such that, for every `v`, the preimages are:

* `{w}` with `(ℓ, π)(w) = (2ℓ(v), 0)`, when `π(v) = 1` or when `ℓ(v) ≢ 1 (mod 3)`;
* two vertices with labels `(2ℓ(v), 0)` and `((ℓ(v) - 1)/3, 1)`, when
  `π(v) = 0` and `ℓ(v) ≡ 1 (mod 3)`.

Then `ℓ(f(w)) = ℓ(w)/2` or `3ℓ(w) + 1` according to `π(w)`, and every backward tree
is `e(ℓ)` or `o(ℓ)`. `(N, T)` is Collatz-typed with `ℓ(n) = n` and `π(n) = n mod 2`;
so is the skew product of §6.

**Lemma C.** Every cycle of a Collatz-typed graph has rational labels. The
only label patterns of three-cycles are `(1, 4, 2)` with parities
`(odd, even, even)`, and `(0, 0, 0)` (all even, no branching).

*Proof.* The return map is `x ↦ (3^p/2^A)x + β` with `3^p ≠ 2^A`, so its fixed
point is rational. For length 3, an odd vertex must be followed by an even
one. The admissible patterns are therefore `(e,e,e)`, which gives `x = x/8`,
i.e. `x = 0`, and the rotations of `(o,e,e)`, which give `(3x+1)/4 = x`,
i.e. `x = 1`. ∎

**Theorem C.** A connected Collatz-typed graph that contains a three-cycle
through a vertex of in-degree 2 is isomorphic to `Gamma_1`, the component of
1 in `(N, T)`, by a unique isomorphism. (The equivalence
`Collatz ⟺ (N, T) ≅ Gamma_1` is immediate, because connectivity is an
isomorphism invariant. What Theorem C adds is that `Gamma_1` is
characterised among all functional graphs by the local rules and one branch
three-cycle.)

*Proof.* By Lemma C the cycle carries `(1, 4, 2)`. A connected graph with a
cycle has every forward orbit entering the cycle (shape lemma), so `ℓ` maps
`V` into the backward tree of the cycle in `(N, T)`, which is `Gamma_1`.

* `ℓ` commutes with the maps.
* It is injective: two distinct vertices with the same label and parity
  would, at their first common forward image, be two preimages with the same
  parity.
* It is surjective: each backward rule exists in both graphs.

Uniqueness of the isomorphism is Theorem R applied to `Gamma_1`, extended by
the identity on the other components. `Gamma_1` is closed under preimages. ∎

So "Collatz is the unique such graph" is exactly true in the categorical
sense. The trivial component is pinned down by local rules plus one
three-cycle, and the open content is whether `(N, T)` *is* that object. The
skew product shows that the local rules alone allow acyclic components
(§6). Proposition L shows that no first-order strengthening of them can
exclude such components.

## 10. Cycle balance (PROVED; FINITE-EXACT check)

**Proposition B.** On every cycle of the shortcut map `x/2, (3x+b)/2` (on `Z`
or on rationals with odd denominator), with `p` odd elements,
`Σ_even x − Σ_odd x = b p` and `3 Σ_even x^2 = 5 Σ_odd x^2 + 6b Σ_odd x + b^2 p`.
*Proof.* Sum `f(T(x)) = f(x)` over the cycle for `f(x) = x, x^2`. ∎ Checked on
twelve cycles of `3x+1` (`1, -1, -5, -17`), `3x-1` (`1, 5, 17`) and `3x+5`
(`1, 19, 23, 187, 347`). This is the moment form of the even/odd mass
balance that Beck–Everett's argument forces in its fibres. It holds on every
cycle, trivial or not: a constraint that cycles satisfy, not an obstruction to
them (compare the fourth note's Proposition 1, invariant measures are carried
by cycles).

## 11. Primes and tournaments (typed)

* **Artin and Wieferich (REAL, PROVED: Theorem R_a).** The backward trees of
  `n/2, an+1` (`a` an odd prime) separate vertices iff 2 is a primitive root
  mod `a^2`.
  * `a = 7`: `<2> = {1, 2, 4}` has index 2. Half of all unit labels (`1029`
    of `2058` modulo `7^4`) collapse into the bare class, so `7n+1` is not
    backward-rigid. Whether it is rigid using forward data is not decided
    here.

  So which multipliers have graphs that remember their labels from the past
  alone is the primitive-root pattern of 2, the subject of Artin's
  conjecture (the repo's S18 audit), refined by Wieferich primes. For `a = 3` the mechanism is
  that 2 topologically generates `Z_3^×`: the ×2-orbit of every 3-adic unit
  is dense, so every spine branches in every phase. This is the 3-adic
  counterpart of the orbit density behind Furstenberg's ×2×3 theorem on the
  circle. The analogy is typed and the mechanisms differ: non-lacunarity on
  `R/Z` there, a primitive root and the carry's fixed point `-1/5` here.
* **Denominators (NUMEROLOGY).** The Eckmann–Hilton point of `n/2, an+b` has
  denominator `2a - 1` (5, 9, 13 for `a = 3, 5, 7`). That this 5 equals
  THM-4522's mod-5 obstruction (5 is both `2·3 - 1` and the least prime not
  dividing 6) is a small-number coincidence. Test: for the pair `(2, 5)` the
  two numbers are 9 and 3.
* **Tournaments (ANALOGY).** The repo's lonely-runner extremal object is the
  Paley heptagon (HYP-3805), whose automorphism group has order 21: maximal
  symmetry. The Collatz graph has trivial automorphism group: maximal
  asymmetry. The set `{1, 2, 4}` is both the Paley connection set and the
  trivial Collatz cycle. This note first typed that as NUMEROLOGY. The
  audited nineteenth note (`collatz_paley_bridge_20261001.md`, Propositions

  * the trivial cycle's parity word `100` has real code `QR_7` and 2-adic
    code `NQR_7`;
  * every period-3 orbit of any 0/1-coded map gets such a code;
  * the Collatz input is Gersonides' `2^2 − 3 = 1`;
  * nothing extends beyond period 3.

  The only intrinsic binary relation on the graph itself is the fibre pair
  (even child, odd child), oriented by parity. It is not a tournament, so per
  AGENTS.md none is forced.

## 12. What is and is not proved

Proved: everything structural about uniqueness.

* The isomorphism type of the Collatz graph has trivial symmetry.
* It determines every label.
* It determines the map within its family.
* No periodic invariant separates its components.
* Its trivial component is categorical.

Not proved: connectivity, which is the conjecture. Rigidity gives no grip on
a hypothetical divergent component. Such a component would itself be rigid
and Collatz-typed, and the skew product supplies such components in
abundance off the diagonal. Whether one of them lies inside `N` is exactly the
divergence half. Proposition L shows that no first-order description of the
graph, in the language of the map alone, can rule it out. An argument
phrased in that language must therefore use something that distinguishes
`N` from its elementary extensions, such as induction or the archimedean
order. This constrains graph-language arguments, not proofs in PA or ZFC.
The fourth note's density statement and Tao's almost-all theorem use such
inputs; the rigidity here does not (eighteenth note, Theorem B).
