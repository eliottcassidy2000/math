## 7. The tournament's own credit word: the Landau slack path

Sort the scores s_1 <= ... <= s_n and put slack_k = s_1 + ... + s_k - C(k,2), k = 0..n (slack_0 = slack_n = 0). Landau 1953: slack_k >= 0 for all k, and every such sequence is realised.

**Theorem 7 (slack path).** For all n: (a) slack_k equals the number of arcs leaving the set of the k lowest-scored vertices; (b) slack_k = 0 iff those k vertices are dominated by their complement, iff they form a down-set of the condensation, so the interior zeros are the condensation cuts, the maximal zero-free intervals are the strong components, L(T) is the longest gap between zeros, and T is strong iff slack_k >= 1 for 0 < k < n (the strict-Landau form: Harary-Moser 1966, Theorem 9 numbering verified by one auditor and not located by another, so CITED-UNVERIFIED as to numbering; the repository has it as THM-354 in path-cut form); (c) converse reverses the path: slack_k(T^op) = slack_{n-k}(T), because the scores of T^op are n-1-s and k(n-1) - C(n,2) - C(k,2) + C(n-k,2) = 0; (d) for T1 => T2 (all arcs from T1 to T2) the path is slack(T2) ++ slack(T1) with a zero at the junction; (e) the number of cyclic rotations of the step sequence d_k = s_k - (k-1) that keep nonnegative prefix sums equals the number of strong components. *Proof.* (a) the k lowest vertices win exactly their internal C(k,2) games plus the arcs leaving the set; (b) equality iff all wins are internal; then every outside vertex beats all k, so no tie straddles a cut; (c) direct algebra; (d) C(b+j,2) = C(b,2) + jb + C(j,2); (e) a rotation keeps nonnegativity iff it starts at a zero. **PROVED.** At n = 4 the slack path is a complete invariant: 000 (TT4), 110 (source over C3), 011 (C3 over sink), 111 (STRONG), reversal = converse.
