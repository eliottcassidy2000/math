## 2. Converse is a complete context anti-involution, not an averaging operation

Reverse every arc and every directed path. Then

    star(H,Q,S,E,U,V,W)=(H,Q,E,S,V,U,W),
    (A⇒B)^op=B^op⇒A^op.

For W also interchange the two ordered slots, so the first-end and second-start
conditions exchange. These bijections prove the identities at every size.
For an arbitrary marked ordinal expression, including repeated copies, converse
reverses every composition order and exchanges the two endpoint channels. This
is an exact anti-involution on the COMPLETE seven-coordinate ordinal carrier.
For a general module context, reversing the entire context and path-slot order
has the same bijection on its full marked cover tensor. The seven coordinates
alone are not claimed complete for those more general contexts.

The formal projections (p+star p)/2 and (p−star p)/2 are useful observers, not
physical constructors. The latter has H=0 and so cannot be a nonempty tournament.
The former may be nonintegral: C3⇒{z}, selected z, has U=3,V=12, so its
formal averaged U is 15/2.

There is a stronger physical obstruction. For any marked A with profile
(h,q,s,e,u,v,w), the literal marked converse double A⇒A^op has

    H=h², Q=q², S=E=hs,
    U=V=uq+hv,
    W=2hw+u²+e²,
    D=h²−2hw−u²−e² ≤ 0.                         (1)

To prove the inequality, fix one selected vertex o. Every Hamilton path splits
uniquely immediately before o into a first path (possibly empty) and a second
path starting at o. This injects all h Hamilton paths into U, hence u≥h.
All remaining terms are nonnegative. Equality in (1) is possible only if
w=e=0 and u=h; this is an algebraic equality criterion, not an assertion
that this boundary has a physical inhabitant. The reverse double A^op⇒A
has the analogous formula with u,e replaced by v,s and also has D≤0.
Thus duplicating the marks to force balance cannot supply a positive-offset
source. This is stronger than one hostile seed or a bounded search.

## 3. Neutralize the finite head physically, with no growing response order

For any marked T, attach unmarked singleton caps

    N(T)={l}⇒T⇒{r}.

The exact map is

    (H,Q,S,E,U,V,W) -> (H,4Q,0,0,2U,2V,W).          (2)

No Hamilton path can start or end in the interior selected set. The ordinal

## 4. A physical prime-address code at one fixed positive offset

Let M_1,...,M_r be actual unmarked tournaments, with h_i=H(M_i)>0,
q_i=Q(M_i), and rho_i=q_i/h_i. Fix nonnegative multiplicities n_i.
For each vector 0≤a_i≤n_i, put a_i copies of M_i left of a marked singleton z,
and n_i−a_i copies right of it, in any fixed order within each side. Add the
two unmarked caps from (2). Call the resulting source T_a. Set

    P=product_i h_i^n_i, R=product_i rho_i^n_i.

Then, for EVERY such multiplicity vector, including all-zero multiplicities,

    H=D=P, W=S=E=0,
    U=2P product_i rho_i^(n_i−a_i),
    V=2P product_i rho_i^a_i, UV=4P²R.             (3)

W=0 since two disjoint paths cannot both use the unique selected vertex.
The order is exactly 3+sum_i n_i |M_i|. All sources have the SAME COMPLETE
UNMARKED COVER PROFILE: for each j≥1,

    Q_j(T_a)=j³ product_i Q_j(M_i)^n_i.           (4)

This follows by independently concatenating each ordered path slot across
ordinal blocks, including empty pieces. Equation (4) retains all cover orders,
not only H or Q; the changing marked location is the essential sidecar.

Suppose the positive rationals rho_i are multiplicatively independent.
Then every allocation vector has a distinct U, and therefore a distinct U−V:
for fixed positive C=UV, the map x -> x−C/x is strictly increasing on x>0.
There are EXACTLY product_i(n_i+1) response-distinct sources in this bank.
They satisfy U=V iff all n_i are even and a_i=n_i/2 for every i.
Indeed balance is product rho_i^(n_i−2a_i)=1. This is an iff classification,
including initial cases, rather than a sufficient palindromic recipe.

A finite exact independence certificate is any full-column-rank integer matrix

    B_(p,i)=v_p(q_i)−v_p(h_i),

for selected primes p. A multiplicative relation gives Bx=0 and hence x=0.
For a general dependent bank, the exact balance obstruction is instead the
integer kernel of the COMPLETE prime-valuation matrix with box constraints
0≤a_i≤n_i. Rank from a few chosen primes suffices for independence, but a
truncated matrix does not certify dependence or balance.

## 6. Exponential binary chirality without a positive-offset illusion

A separate control shows why finite state dimension is not a bound on the
number of distinguishable branches. Let A=C3⇒{z}, selected z. Its profile is
(3,24,0,3,3,12,0). In a word of k copies, choose each copy independently as
A (epsilon_i=0) or A^op (epsilon_i=1). Every word has the same complete unmarked
cover profile, H=3^k, and order 4k. The ordinal law gives

    U=3^k sum_i (1+3epsilon_i)8^(k−i),
    V=3^k sum_i (4−3epsilon_i)8^(i−1).             (7)

Base-eight digits 1 and 4 prove that all 2^k U-values are distinct. Converse
maps epsilon to its reversed complement and swaps U,V. Two caps again kill
S,E with only two added vertices. BUT for k≥2 every such word has D<0:
for the first two marked blocks, the W/H cross contribution is at least one,
and equality in that pair occurs only for A followed by A^op, which pays an
additional endpoint coupling one. Every other orientation pays at least four.
Further terms are nonnegative. For k=2 the balanced words have (H,U,V,D)
(9,108,108,−9) and (9,297,297,−135). This is a precise hostile to using
exponentially many response states as if they were positive-offset control.
