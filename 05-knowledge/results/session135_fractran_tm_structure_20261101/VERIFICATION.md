# Verification, representations and reproduction

Run `python3 verify_session.py` for manifest authentication, artifact-corruption
controls and isolated normal/optimized replays. Every principal verifier is
copied into its own temporary full packet. Only Python3 standard library is
needed; no network, repository checkout, optional package or published gzip
file is required. `SESSION_REPLAY.json` records the final actual executions.

## Principal consumers

- Acceleration: general guard/word controls and the separate finite-horizon,
  bounded-period-density and prime-renaming checker.
- PRIMEGAME: full basin verifier, raw-entry-bound verifier, analytic density
  bounds, and the small `density_approximation.py --cap 1` smoke test.
  Requested high-precision density computation is polynomial but expensive;
  no large requested-precision box is silently reported as executed.
- LRC: serialized FRACTRAN/TM comparisons, both rational encodings, complete
  closed-set harmonic controls and the declared560-row bounded smoke box.
- Square sums: literal predicate states, malformed raw words, all named-vertex
  controls, inherited witnesses/rotations, exact runtimes and graph arrivals.
- Machine translation: emitted ordinary TM tables, both directions of register
  compilation, rollback, invariant-face reduction and exact cost identities.
- Root interfaces: independently executed square-edge costs, odd-eighth
  point types and small circulant word/path bijections.
- Independent audit: seven distinct normal/optimized consumers with41 source
  pins, literal execution and separate enumeration/arithmetic implementations.

## Table completeness

The square-sum59/84 symbolic clauses define single ordinary TM steps. The
expander enumerates every concrete read tuple, checks unique keys and frozen
expanded hashes/counts, then the tests execute those ordinary transitions.
Gzip tables are local regenerated caches, not publication dependencies.

The single-tape pure-blue table and the full migration table are split into
hashed UTF8 row shards. The loader checks byte sizes, hashes and row counts
before concatenation. Those are already ordinary fully specified rows.
The15-tape compact stream's293 rows explicitly read/write the origin marker
on inactive tapes; they are not wildcard clauses or hidden macroinstructions.

## Scope and inheritance

All-input claims are proved in the manuscripts; finite replays are supporting
controls. Pinned inherited proofs are retained with original source identities
in archival input copies; they are not newly proved by copying them. Active
Markdown routes are checked separately from those byte-identical archives.
Concurrent conjecture-machine work is a source-only snapshots with pre-audit history, subsequent
source-audit corrections and failed-control qualifications, not a dependency of our results.

No bounded census, small machine description or finite-horizon quotient is
promoted to a general halting, LRC14 or unrestricted Hamiltonian-spectrum
resolution. Natural integer-input density is distinguished from uniform
valuation-box frequency and from literal prime-power observations.

The first end-to-end attempt caught an unpublished wrapper-only bug: its

audits and the20 producer/integration runs had passed, but that did not prove
the complete driver worked. The namespace/flags were separated, a two-audit
selection regression was added, and the full normal, optimized and relocated
wrappers passed. This final root result repeats ALL22 isolated runs after
the fix. The already-published first mathematical checkpoint was unaffected.
