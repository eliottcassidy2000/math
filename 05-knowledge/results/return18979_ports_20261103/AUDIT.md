## Types and quantifiers checked

* RC1 concerns all marks of a transitive substitution at one vertex of a
  strong source, for m>=2. Arbitrary exterior marks and other substitutions
  lie outside it. Its grandparent law overlaps incoming CL2, explicitly
  credited. The d^2 lower bound and strict twin increment cover the other
  indegrees/clone positions rather than extrapolating the unique-in-port case.
* RC2 allows arbitrary changes to the named root/spare stars, even moving
  the incoming port, but fixes all other endpoint arcs. It is not an
  obstruction to arbitrary native programs with unrestricted final edits.
  Each excluded in-port has a literal untouched directed triangle. The
  two successful extra-port menus have actual endpoint witnesses.
* The two-arc fixed-star repair preserves labels and the whole root star.
  Its4 native moves are implemented using the inherited uniform three-helper
  compiler. The temporary sources need not be strong. Actual endpoints are
  strong; count neutrality is explicitly false. All five Q4 charts are
  transported, not assumed unchanged.
* RC3 counts rooted base isomorphism classes, with r fixed and w intrinsic;
  it does not quotient converse, or identify differently rooted equal-H
  sources. The binary A is a physical source word, not a fractional
  tournament orientation. A=0 is only an arithmetic recurrence boundary.
* RC4's exclusion is for uniform family identities at the same clone
  parameter (also fixed parameter shifts). It neither excludes individual
  counts nor prohibits larger feedback families. The sign proof covers
  every integer A; the finite loop is a hostile control, not its premise.
* RC5's two births give +4 even though both source and target are1-ready:
  they are different cuts from the standard reset. Old relation, names,
  root, spare and exact cuts are all retained.
* SC1 uses a simple undirected graph and actual endpoint paths. SC2 quantifies
  over every distinct positive integer connector, via a finite complete
  factorization list. Paths are counted modulo reversal. Connector count
  and maximum connector height are distinct objectives.

    python -O -B -X utf8 05-knowledge/results/return18979_ports_20261103/reproduce.py

maintainers after deliberate reviewed changes, not part of verification.

negative output is compared with the saved receipt. No private data,
network access or remote submissions are required by the verifier.
