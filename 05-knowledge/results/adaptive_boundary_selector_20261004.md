# An adaptive Collatz selector that retains proof obligations and certified suffixes

2026-10-04. **PROVED** for the guarded operations and their certificate
composition. **FINITE-EXACT** for the declared universes and policy comparisons.
Universal coverage, a uniformly successful selector, and a runtime improvement
remain **OPEN / NOT CLAIMED**. This is an integration and reuse experiment, with
no priority claim for exact cylinders, sibling equivalence, or memoized orbits.

The concrete gain is a bounded proof-memory pipeline. It distinguishes a
smaller obligation from a completed route, learns a checked infinite cylinder
from a residual input, and retains every actual suffix of a completed proof.
With a fixed eight-macro budget on each input, four learned cylinders and the
sole initial certificate1 suffice for all512 odd inputs1..1023 in this
experiment. The finite result supplies no all-integer conclusion.

## 2. The proof object and its all-input soundness

Write `U(n)=(3n+1)/2^v2(3n+1)` on positive odd integers. A selected object retains
the original sourceN, a finite exact valuation wordw, its actual endpointJ,
the macro partition, phase annotations, and one of three statuses:

- `ROOT`: N=1 and the empty route.
- `REDUCED`: a nonempty finite set of odd a with0<a<N, each satisfying either
  a=J or U(a)=J.
- `PENDING`: the stated bounded policy exhausted its macro allowance. It
  proves no descent and supplies no home certificate.

For every actual macro word, the implementation checks every valuation and
independently composes its affine transfer. Ifw hasj letters, valuation sumA,
and carryB, the retained equality is `2^A J=3^j N+B`. Composition uses
`(P,Q,B) then (p,q,b) = (pP,qQ,pB+bQ)`, always againstN. It stops a literal
core macro at the first1, so root self-returns never enter a first-hit prefix.

**PROVED: sound discharge.** Supply a genuine home certificate for one
advertised a. Ifa=J, use its whole certificate as the suffix. Otherwise use
its parent pointer, which certifiesU(a)=J. Prepend the actual wordN->J, decoding
each edge into the inherited row/block inverse grammar. This certifiesN and
preserves its exact first-hit odd and ordinary ranks. The prefix does not hit1
early, and the suffix is already first-hit; therefore their splice is
first-hit. A missing child leaves a reduction, not a completed result.

For an increasing-source closure, accepting only already certified a<N is
sound by induction. With suffix memory, one may instead meet a fully certified
actual valueJ even whenJ>=N; prepend the checked actual prefix to that home
certificate. The certificate itself supplies termination, so this second
operation needs no magnitude comparison. It is a separate checked join
operation, never an inference from local contraction.

The fixed macro budget and per-macro cap bound all explicit word expansion.
The default word cap is128. Integer input size, guarded integer arithmetic,
certificate expansion, and the one-time inherited-bank construction have
their own costs. A macro count is not an odd-step count or runtime bound.

## 3. Rules, exact guards, and lost alternatives

The inherited policy regenerates the171 core rows, prioritizes a direct root
edge and the shortest matching core, and otherwise uses a single step,
Repeat12, or Repeat1. Its maximum stored core length is41. The comparison
normalizes the budget check to occur after each accepted macro. Both policies
use this same convention and per-macro cap.

The adaptive policy preserves that core precedence and additionally tries
the verified virtual ladder, all eligible sibling ancestors, and Repeat112
before the inherited fallback. The virtual rule retains its actual join;
e.g.79 has dependency67 and actual prefix
`79->119->179->269->101`, while67->101. All four actual prefixes grow.
The separate policy happens to prefer an inherited core at79. At207, the
virtual rule supplies dependency175 and is a one-macro gain over the baseline.
An s=5 ladder costs one macro but18 actual odd steps; a word cap16 rejects it.

**PROVED: exact Repeat112 guard.** For m>=1, a positive oddn begins with
`(1,1,2)^m` iff `v2(11n+19)>=4m+1`. Its signed rational cycle is
`-19/11 -> -23/11 -> -29/11 -> -19/11`, with exact valuations1,1,2.
An exact lengthj word with total denominatorQ occupies one odd residue class
mod2Q: this follows by inverse induction, retaining endpoint oddness at each
division. Applying it to this periodic cycle gives the stated guard. Its
closed transfer is

    11*16^m U^(3m)(n) = 27^m(11n+19)-19*16^m.

Thus maximal legalm is `floor((v2(11n+19)-1)/4)`, truncated by the declared
word cap. Every prefix has positive carry and coefficient>1, so it is a legal
growing-prefix compressor, not automatically a descent certificate.

Mod19 records `(11n+19) mod19^d`, shell and formal period. It does not authorize
Repeat112:7 and45 have the same mod19 coordinate, but only7 has the required
dyadic guard. No coverage gain is attributed to this annotation.

An optional exact lookup provides a different, sound use ofmod19. The
[nineteen completed rays](mod19_route_lifts_20261004.md) have equations
`D*n+B=A*2^(18t)`, t>=0, with one chosen ray per source residue mod19.
`lookup_ray_certificate(n)` uses nmod19 only to choose the candidate ray, then
requires exact integer division `(D*n+B)/A`, a positive power of two, and
exponent divisible by18. These conditions are necessary and sufficient for
membership in that selected ray. Its supplied at-most-four-edge AST then
certifies this actualn. Failure means no match in this sparse bank, not failure
of convergence. The helper is excluded from the policy comparison tables;
190 actual members and190 same-residue nonmembers n+38 are independent controls.
This separates constructing a new certified integer in a requested address
from certifying an arbitrary supplied integer that merely has that address.

Two alternative-retention hostiles are executable. At483, the join is17 via

if no proof for the smallest sibling11 was supplied. At893, its step to335

## 5. Learn a cylinder, then reuse every certified suffix

**PROVED: checked learned cylinder.** Suppose bounded exploration finds an
exact word with data(P,Q,B), Q>P. Set

    r=(Q-B)P^(-1) mod2Q,      e=(Pr+B)/Q.

If its least positive odd boundaryr has the exact first-hit-compatible word
and e<r, every `n=r+2Qk`, k>=0, has that word and endpoint `e+2Pk<n`.
The difference is `(r-e)+2(Q-P)k>0`. Exact valuations persist because the
initial difference2Qk is still even after each prescribed cumulative division.
If the least boundary fails, this learner returnsNone instead of claiming
the cylinder. In particular9 and17 discover the word(2), whose boundary1
does not strictly descend; these are explicit negative controls. This is a
specialization of the inherited cylinder mechanism, not a new global theorem.

Bounded exploration of27 discovers37 odd steps with total valuation59 and
endpoint23. The learned rule covers the entire infinite family

    n=27+2^60 k -> 23+2*3^37 k,     k>=0.

Within the finite training universe only27 directly belongs to this cylinder.
With the same eight-macro policy budget and only root1 initially certified,
adding this rule raises the home count350->370 through downstream reuse.

Now store every actual suffix of each completed certificate, keyed by its
exact source. Each entry retains an already certified parent source and a
cut position in that parent's AST; the code audits this pointer relationship.
These may include sources larger than the input currently being processed.
They are theorem-derived suffixes, not new oracle seeds. A later prefix may
join any such stored home route. Inputs settled by later suffix insertions
are removed from the final unresolved lists.

The substantive retained object is a reusable proof DAG: guarded source
cylinder, verified least boundary, actual transfer, alternate obligations,
and certified suffix cuts. Four successful training rounds do not imply that
every residual admits such a bounded word or that the process terminates on
all positive integers. The next unresolved mathematical obligation is a
coverage/selection theorem; increasing a finite census is not such a theorem.
