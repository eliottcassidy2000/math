normalizing such a path proves X -> U_true surjective. The coordinate
bijection consequently makes U -> U_true surjective, and the exact equal

Complement pairing and the reflection-fixed colour rule identify precisely
the stated coloured span, including loops counted twice and distinct parallel

Necessity is immediate from an actual span isomorphism and isomorphism or
converse-isomorphism witnesses.

The quantifier is existential over coordinates, representatives and individual
transporters. It is not uniqueness of any of these, nor a claim that the
counts reconstruct wiring. The explicit n >= 3 restriction is used to make
complement fixed-point-free. The candidate node map is assumed surjective,
as specified in the input definition.

The Burnside calculation is sound. Unordered vertex-pair orbits have exactly
sum_i floor(lambda_i/2) + sum_(i<j) gcd(lambda_i,lambda_j) orbits. Untwisted
compatibility is equivalent to every vertex cycle being odd. Twisted
compatibility is equivalent to at most one fixed vertex and all remaining
cycles having length 2 mod 4. The necessity argument using the square as a
tournament automorphism excludes lengths divisible by 4; the odd-cycle
argument excludes odd lengths above 1. The displayed parity check proves
sufficiency on each pair orbit. A self-converse ordinary class contributes
exactly n! fixed (T,sigma) pairs to the twisted sum. Thus S_n and K_n have
the precise meanings claimed, without importing a tournament census.

6. SIZE CORRECTION: REQUIRED WORDING REPAIR

Write k=K_n and E=binom(n,2). The number of labelled tournaments is 2^E and
the acting group S_n x C_2 has size 2 n!, so

  k >= 2^E/(2 n!).

With N=2^(E-(n-1)), this yields

  k^2/N >= R_n := 2^((n-1)(n+2)/2)/(4 (n!)^2).

At n=7, R_7=131072/99225 > 1. Moreover,

  R_(n+1)/R_n = 2^(n+1)/(n+1)^2 >= 4 for n >= 7.

The base cases n=3,4,5,6 have (N,k)=(2,2),(8,3),(64,10),(1024,34),
and all also satisfy N <= k^2. Therefore

  N <= K_n^2 for every n >= 3.

The same elementary lower bound gives n^2=O(log K_n), so the supplied
O(N n^2)-bit certificate is O(K_n^2 log K_n) bits. This is polynomial in the
number of entries of an explicit K_n by K_n matrix. It is also polynomial
in explicitly listed sparse weighted-support size: every nonempty node has
an incident line, so at least K_n/2 nonzero unordered support entries are
needed, with loops allowed. This argument does not cover a circuit, formula,
or histogram that implicitly describes all nodes; genuinely succinct input
representations require their own analysis.

Polynomial certificate size does NOT provide a polynomial-time method to
find a certificate or decide realizability. The verifier/search distinction
and exponential-in-n warning should remain. A minimal safe replacement is:

  "This certificate is exponential in n. No polynomial-time method to find
  it or recognize compressed wiring is claimed. When all K_n nodes are
  explicitly listed, its size is nevertheless polynomial in that explicit
  input size; more succinct descriptions need a separate size analysis."
