# Terminal compatibility and counts assembled from smaller parts

**2026-11-22, euler.** A target height is not itself a boundary state. This packet resolves the compatibility question negatively for the original backchain, gives an exact test for the second register there, and expands the construction to build from actual smaller tournaments.

| Result | Scope |
|---|---|

Adjacent positive gaps split the count into a multiplicative monoid of coupled pieces. An exact pressure bound shows only \(O(X^{23/24})\) heights through \(X\), even with arbitrary zero runs and ordinal products. Thus most odd targets have no second count in this grammar. |

There are two distinct auxiliary counts here: the **preceding prefix Hamilton count** in the backchain and the **ordered two-slot cover count** of a gap module. The transfer needs both in different places. Arbitrary-module stabilization is not a consequence of the old finite palette, and no theorem here settles cofinite coverage in the expanded grammar or the [Chan–Pak / bof–Royle conjecture](https://www.math.ucla.edu/~pak/papers/DominoPermanent16.pdf). The exact construction target is now a supply of compatible gap profiles from strong parts that is large enough to handle prime heights, while keeping the necessary next read under control.
