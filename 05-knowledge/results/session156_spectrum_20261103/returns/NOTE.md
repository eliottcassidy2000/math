# Physical predecessor classification for a mixed return

Status: an exact all-word classification for one target family and the seven macros of session 155; it neither closes a source bank nor proves any tournament-spectrum coverage. The positive cases remove a literal trailing `b`, so they are not a new reduction algorithm.

Let `t=(2,-1,0)`, `beta(h,x,y)=(y,h+2x-y)`, `U=(31,14,25)`, `U2=(95,41,75)`, and `D=L2 b L2`. All words are in processing order; `P_A` is the corresponding product. The seven macros, actual atom matrices, and initial source words are those of `session155_spectrum_20261103/returns/MIXED.md`. Let `A` be any word in `{L2,L6,L45,L13,b,q2,Lp2}`, and let `v=U P_A P_D`. Then

> There is an actual nonempty tournament observer `w` and an integer `m` with `w P_b P_D = 3v + m t` if and only if `A` ends in `b`.

The ports are the physical newest ports in the inherited literal source construction. For the positive direction, write `A=A' b`, let `g(A')` be the integer such that `t P_A'=g(A')t`, and take `w=U2 P_A'`. Then

    w P_b P_D - 3 U P_A' P_b P_D
      = (U2-3U) P_A' P_b P_D
      = 4 g(A') t,

because `U2-3U=t`, `tP_b=-t`, and `tP_D=-4t`. Both `w` and `v` are actual marked source graphs. For example `A'=Lp2 L6` gives `g(A')=12`, carry `48`, and concrete states printed by `check.py`.

For the converse use the physical inequalities `0 <= x <= y` and `h <= x+y`, valid for any actual nonempty tournament observer. In the original observer, `y-x` is a count of paths ending at the marked port; `h+x-y` is nonnegative; and `x+y` counts starts plus marked two-path covers, into which all Hamilton paths inject by cutting immediately before the port. These imply that `beta(w)=(a',b')` satisfies `a' >= 0`, `b' >= 0`, and `b' <= 3a'`: indeed `b'=h+2x-y >= x` and `b' <= 3x <= 3y`.

The quotient of `b` is `Q_b=[[5,8],[2,3]]`, with inverse `[[-3,8],[2,-5]]`, and `Q_D` is nonsingular. If `beta(U P_A)=(a,b)`, quotienting and cancelling `Q_D` forces the unique rational bulk

    beta(w) = 3(-3a+2b, 8a-5b).

The physical cone constraints force both

    11 b >= 17 a,      5 b <= 8 a.                     (*)

All bulks reached from `U` by these macros have positive entries. The starting bulk is `(25,34)`, which is strictly below the first bound. Every row slope `Q[i,1]/Q[i,0]` of L2, L6, L45 is strictly less than `17/11`, while both row slopes for L13, q2, Lp2 are strictly greater than `8/5`; since all entries are positive, any positive input gives a positive weighted average of the two row slopes. Thus if `A` is empty or ends in any macro other than b, (*) fails. This excludes even predecessors outside the 65-symbol bank, since only the universal physical cone was used. The proof does not characterize predecessor graphs beyond existence in the b-suffix case.

Reproduction: `python check.py` and `python -O check.py`. It checks the 13 named atom matrices independently by literal tournament reconstruction, endpoint-subset Hamilton DP and the inherited atom calibration, and directly checks both seeds. It recomputes every macro quotient and error gain, verifies exact strict slope inequalities, invertibility, the seed relation, and the nontrivial mixed-prefix example. The all-word conclusion is the symbolic cone and weighted-average argument above, not a finite word search. The calibrated transfer mechanism is inherited from the source construction; neither checking seed graphs nor this theorem classifies all physical observer states.

## Broader last-atom exclusion for the 65-symbol bank

The physical cone `h>=0, 0<=x<=y<=h+x, h<=x+y` is generated by rays `(2,1,1)`, `(1,0,1)`, `(0,1,1)`: the respective nonnegative coefficients are `(h+x-y)/2`, `y-x`, and `(x+y-h)/2`.     w P_b P_D = 3 (S P_c P_D) + m t

## A physical mixed reset from different source words

The cone test leaves room for actual returns from other targets. A small literal example uses

    V = state(q5 a) = (13,5,9),
    w = state(q1)   = (3,3,3).

The q5-a source has adjacency rows `(20,25,18,5,8)` with port 4; the q1 source has rows `(0,9,3,5)` with port 3. Here bit j of row i records `i -> j`. Literal subset DP on each graph and its `a` and `aa` continuations yields the full three-coordinate states. The source words are distinct from the U/U2 seed pair. Direct multiplication gives

    w P_b = (27,21,27) = 3V - 6t.

Consequently for `v=V P_D=(12784595,5894543,10188150)`,

    w P_b P_D = 3v + 24t.

The target `(q5 a) D` is a 24-vertex actual graph with port 23. The output `q1 b D` is a 26-vertex actual graph with port 25. Their direct H counts are 12784595 and 38353833; independently applying the inherited width-four frontier DP to the literal graphs verifies these large counts. Run `python actual_swap_check.py` for all graph rows, port labels, the DP counts, and their widths. This is an actual source-level mixed reset whose target ends in `a`, not a trailing `b` from the seven-macro theorem. It is nevertheless an ordinary finite seed identity transported through D, and does not establish a return cycle, a growing closed interface family, or new scalar-spectrum coverage.

There is also a second literal predecessor `w2=state(b a)=(5,2,3)=w+t`. Its 4-vertex graph has rows `(8,9,3,4)` and port 3. Hence

    w2 P_b P_D = 3v + 28t,

and its 26-vertex output has H=38353841=3H(v)+56 by direct frontier DP. For any further word `z` in the seven macro return language, writing `t P_z=g(z)t`, these two source identities transport to the actual infinite family

    H(q1 b D z)  = 3 H(q5 a D z) + 48 g(z),
    H(b a b D z) = 3 H(q5 a D z) + 56 g(z).

The letter gains are `(-2,6,45,13,-1,1,2)` in the macro order `(L2,L6,L45,L13,b,q2,Lp2)` and multiply in processing order. The two outputs have actual source words and retained ports; the unbounded suffix and the signs are not dropped. These identities are proved by transporting the two displayed seed differences, not by a finite graph census. They do not show that the output source words return to the input family, nor supply all ternary branches.
