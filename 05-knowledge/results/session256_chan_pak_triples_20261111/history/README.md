## 2. New transfer A: a nine-probe, response-complete atlas for five-core constructions

**Status: PROVED here from the inherited Session251 response formula.** This is a concrete transfer from the transverse-jet, moving-owner and lost-coordinate histories.

For one fixed core and cut, Session251 gives

```
F(A,B)=d(g(A)+g(B)−1)+(d+k+)AB+(d+k−)alpha beta
       +i+ A−i− alpha+o+ B−o− beta+j++j−,
alpha=A mod2, beta=B mod2,
g(0)=g(1)=1, g(2)=3, g(3)=1.
```

Define the **context signature**

```
S=(d,k+,k−,i+,i−,o+,o−,j),    j=j++j−.
```

The two separate j values are invisible to this consumer. They may matter in a richer interface; they cannot be recovered from this F, even from infinitely many flank queries.

### Theorem (nine probes determine every flank response)

The values at

```
P={(0,0),(1,0),(2,0),(3,0),(0,1),(0,2),(0,3),(1,1),(2,2)}
```

determine S uniquely. Hence two actual core-cut charts agree on every `(A,B) in N²` iff they agree on P.

**Proof.** Write `F_ab=F(a,b)` and `D_ab=F_ab−F_a0−F_0b+F_00`. On B=0,

```
F_A0=d g(A)+i+ A−i−(A mod2)+j.
```

Consequently

```
i+ = (F_30−F_10)/2,
d  = (F_20−F_00)/2−i+,
i− = i+−(F_10−F_00),
j  = F_00−d.
```

The corresponding A=0 formulas give

```
o+ = (F_03−F_01)/2,
o− = o+−(F_01−F_00).
```

Finally `D_ab=(d+k+)ab+(d+k−)(a mod2)(b mod2)`, so

```
k+ = D_22/4−d,
k− = D_11−2d−k+.
```

These reconstruct all eight coordinates, proving both implications. The second axis gives the redundant consistency identity

```
F_20−F_30+F_10 = F_02−F_03+F_01.
```

QED.

**Eight suffice:** remove `(0,2)` from P and reconstruct it as `F_02=F_00+2d+2o+` before forming D_22. The other eight still reconstruct S using the displayed formulas; the ninth probe is a useful exact consistency check. Therefore the response space has dimension eight over Q, and eight linear evaluations are minimal for arbitrary formal signatures. No claim that all eight-dimensional formal signatures are realizable is needed or made. The rank statement concerns the formal response family, not the restricted set of tournament cores.

**Graph interpretation:** each probe is an actual small flank context through the inherited constructor. This gives a finite semantic equality test, not a census of huge graphs. For d-known same-H comparisons, fewer probes suffice, but the universal bank above is convenient and retains a cross-axis error check.

**Immediate research use:** partition the five-core cut bank by S, keep one witness per response-equivalence class, and retain distinct H9 charts whenever S differs. Record equal-H repair arrows together with `Delta S`. Look first for arrows changing a deficient endpoint coordinate while preserving d and any already-paid coordinates. This is exactly what a transverse jet does: it resolves a scalar collision through a specified consumer.

**Scope:** equivalence applies to this one-apex/flank family only. It is not equivalence under arbitrary future tournament substitutions. A new consumer requires its own response completion.

**Cheap decisive test:** `python3 probe_bank.py` checks exact reconstruction on the eight basis signatures and the redundant consistency law, then checks the invisible `j+−j−` direction explicitly. It does not rerun historical theorem audits or claim new graph-realization coverage.

## 3. New transfer B: a finite exact quotient for all future linear contexts

**Status: PROVED conditional linear-algebra compiler; application requires a lawful finite signature action.** Historical inputs are the source-dependent groupoid, signed Walsh observers, and Session255's positive response frame.

Suppose actual graph operations act on a d-coordinate column signature x by known rational matrices `M_a`; output is `ell x`. A word `a1...ak` acts by `M_ak...M_a1`. Define

```
W_0=span{ell},
W_(r+1)=span(W_r union {v M_a: v in W_r, all letters a}).
```

This chain stabilizes in at most d−1 strict dimension increases if ell is nonzero. Once `W_(r+1)=W_r`, it is right-invariant and equals the span of all future-context rows `ell M_w`. Therefore actual sources x,y agree under **every** lawful word iff `v(x−y)=0` for every row v of a basis of the stabilized W. The common kernel is invariant under every M_a, so these rows give an exact reduced linear realization.

This is a finite *linear* quotient, not a finite-state integer automaton: row values can grow without bound. Affine operations can be homogenized by adjoining the constant coordinate1. Prefix legality needs its own retained controller; this lemma alone cannot extend an operation outside its lawful domain.

**What this adds to Session255:** difference-support observers are exceptionally efficient for comparable positive sources, but signed repairs may cancel. The row-space compiler handles arbitrary signed differences and proves contextual indistinguishability, without claiming modular information determines the exact count. It tells us precisely which repair coordinates are permanently invisible to the declared consumer.

**Proposed experiment:** load the exact O/Z/J matrices, compute W with fraction-free elimination, then compare the current four-coordinate frame with the nine-probe one-apex interface. If W is full, no linear compression is possible; that is a useful positive diagnosis of the required repair dimension. If W is proper, use the exact quotient to shrink subsequent synchronized modular searches. Keep actual graph witnesses alongside quotient states.

## 4. New transfer C: source-labelled repair groupoids and synchronized arithmetic controllability

**Status: OPEN construction programme with exact finite tests.**

Start with actual graphs of a fixed H. Give each source a signature S, a vertex/port chart, and its literal adjacency data. A repair arrow is an explicitly constructed graph replacement with same H and a recorded full response change. Compose only where its domain chart matches. Do not use an undirected spanning tree of H-labels as a substitute for a lawful operation.

Three historical lessons combine:

1. Gaussian prime-XOR: a nominally identical repair may depend on the source.
2. Hensel-normal atlas: divisibility, root and first-normal unit are distinct coordinates.
3. Grassmannian orbit banks: one cyclic operation generally fills only one-dimensional phase data.

For a modulus m, synchronize every repair letter across all prime-power registers and the domain controller. The finite state is `(source chart, response mod m, legality state)`. If exact H-equality must persist along a common positive continuation, append Session255's exact difference-support observer. If cancellation is allowed, use the declared exact linear invariant or keep an integer certificate; a residue test cannot certify exact equality.

**Decisive tests:**

- At fixed m, compute the orbit of each actual H401 repair seed under its legal count-neutral words, then compare with the full target residue fibre. Session255 already gives a modulo-seven missing doubling coset: add a genuinely different repair arrow rather than extending O longer.
- At p², compare generated orbit size with the admissible signature fibre size. A strict gap reveals the missing orbit-bank label. Test whether a second operation with nonzero commutator reaches a new bank.
- Test equal-H9 core-cut charts with the eight independent probes, then ask whether their response differences supply missing residue directions unavailable from repeated neutral flank extension.

**Success criterion:** a graph-realizable, source-labelled collection of repairs that reaches each required modular response class while keeping exact count constraints. **Remaining gap:** modular controllability still does not prove arbitrary target integer realization or the all-height five-core cover. It becomes useful only when combined with a descending target algorithm or a complete interval argument.

## 5. New transfer D: replace scalar ternary induction by chartwise descent and arithmetic jumps

**Status: OPEN, concrete alternative to another word-tree analogy.**

Berggren's strength is not that it has three branches. It has a lossless two-coordinate chart, disjoint inverse cones, and a strict decreasing arithmetic height. Keller renewal shows that useful arithmetic maps may be nonunimodular jumps rather than fixed branch words.
