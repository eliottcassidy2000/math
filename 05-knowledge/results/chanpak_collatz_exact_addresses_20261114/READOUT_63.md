# Exactly two chronological paths are needed to encode 63

**Scope: all orders, conditional only on established small-spectrum
classification below.** Let x_0,...,x_(n−1) be any distinct real observations.
Form a tournament with the time edges i→i+1 and, on all other pairs, an arc
from larger to smaller observation. The opposite order convention has the
same conclusion. Such a tournament never has exactly 63 directed Hamiltonian
paths. This is stronger than restricting observations to one Collatz orbit,
or requiring its comparisons to agree with generic valuation-word forecasts.

The [generic Syracuse-window description](../syracuse_window_alphabet_general_m_20261005.md)
already supplies the ordinal representation and the fact that the strongly
connected components are contiguous in time. The obstruction below is about
the resulting spectrum, and makes no assumption about a trajectory's affine
law or how it was initialized.

## Structure

By construction there is a Hamiltonian path P such that deleting its arcs
(not its vertices) leaves a DAG. Conversely, if a tournament has such a P,
a topological order of the remaining arcs, read as decreasing real values,
reproduces the tournament from observations assigned along P. Thus arbitrary
ordinal window representability is equivalent to having a Hamiltonian path
whose arcs meet every directed cycle. Reversing all arcs and reading P backwards
preserves the property.

Every Hamiltonian path visits the strong components in consecutive intervals,
in their unique condensation order. Thus the property descends to each
strong component. In particular any padded realization of 63 would yield
a strong component of count 63: all strong component counts multiply, the
only possible factorizations involving a proper factor carrying 7 need the
factor 7 or 21, and both are impossible in tournaments. By the
[all-order low-count inventory](../actual_hamilton_multiplicities_20261021/session24-multiplicities/PROOF.md) (the [same inventory pinned before this session](https://github.com/eliottcassidy2000/math/blob/0cccb5df3c796b4269b2a3331f7be5c4d4252cf5/05-knowledge/results/actual_hamilton_multiplicities_20261021/session24-multiplicities/PROOF.md#L117-L123))
the only strong count-63 possibilities are the two converse order-eight
classes of [THM-344](../../../01-canon/theorems/THM-344-n8-h63-complete-omega.md).
It suffices to rule out the representative with outgoing bit masks
(238,220,216,16,225,206,8,72).

## Five triangles as a certificate

In this representative there are five directed triangles
A=(0,1,4), B=(0,2,4), C=(1,4,5), D=(2,4,5), E=(3,4,7), in cyclic order.
No Hamiltonian path can meet all five with its arcs.

* If the path uses neither 4→0 nor 4→5, meeting A and C forces 1→4;
  otherwise the path would need both 0→1 and 5→1. Meeting B and D
  likewise forces 2→4, contradictory.
* If the path uses 4→0, meeting C and D forces at least one of 1→4 and
  2→4, since it cannot use both 5→1 and 5→2. If the path instead uses
  4→5, A and B likewise force one of 1→4 and 2→4.
* In either latter case, E can only be met through 7→3: vertex 4 already
  has a predecessor in {1,2} and cannot also have successor 7. But the
  only out-neighbor of 3 is 4, and the only out-neighbor of 6 is 3.
  Hence 3 and 6 would both need to be last on the path.

Every complete Hamiltonian path therefore leaves at least one of these
triangles intact. Reverse arcs to transfer the obstruction to the other
count-63 strong class. No classification of all ordinal-window counts,
or conclusion about arbitrary tournament constructions, is implied.

## Exactly two paths suffice

More generally, call a tournament representable by k chronological paths
if one real rank order together with k Hamiltonian paths reconstructs it:
where any of the paths traverses a pair consecutively, use the chronological
orientation, and otherwise use decreasing rank. Equivalently the union
of arcs of those k paths meets every directed cycle. This equivalence uses
the same topological sort as the one-path case.

In the displayed representative, use these two directed Hamiltonian paths:

    0,1,2,3,4,5,7,6
    0,2,4,5,1,7,6,3

After deleting both arc sets, every remaining arc goes from later to earlier
in the order

    3,6,7,2,5,0,4,1.

Label verification is included in [replay_readout_63.py](replay_readout_63.py).
This graph therefore has chronological-path cost exactly two, and so does
its converse. This does not mean the two path orderings are simultaneously
generated by a Collatz orbit. What it establishes is the smallest change to
the ordinal construction that suffices at 63: couple two paths through one
rank order, rather than tune the arithmetic of one path.

## Exact composition law for the path budget

Let κ(T) be the smallest k for which the above representation exists;
use k=0 for transitive tournaments and allow +∞ if no such family exists.
If the ordered strong components are T_1,...,T_r, then

    κ(T) = max_i κ(T_i),          H(T) = ∏_i H(T_i).

Necessity of the first identity follows by restricting each Hamiltonian
path to each contiguous strong component. For sufficiency take k equal
to the maximum finite component budget. If k=0 the ordinal sum is
transitive. Otherwise fill any component's short list of paths to length
k by repeating an available Hamiltonian path (a singleton has its trivial
path). Paste the paths component by component, by list position, using
the forward cross-arcs. Every directed cycle belongs to one component, so
the pasted lists hit every directed cycle. Infinite budgets are covered
by necessity.

Consequently each fixed-budget count spectrum is multiplicatively closed.
For example 63·3^a has an explicit at-most-two-path witness for all a≥0:
ordinally glue the 63 core and a directed triangles. Do not conclude that
63·3^a necessarily needs two paths for a>0; a different factorization and
a different core might fit into one path.

## A contrasting genuinely chronological infinite family (inherited)

In an all-ascent Syracuse window every nonconsecutive arc goes backward,
so the tournament is Moon's consecutive-edge T'_m. These windows really
occur, for example as initial windows of 2^p−1 with p≥m on the plus sheet.
A directed cycle starting at its smallest vertex must move along consecutive
vertices until its first backward edge, which can only return to the
start. Thus the odd cycles are exactly the odd intervals of length at
least 3, with unique cyclic orientations. The odd-cycle packing formula
then gives H_m=H_(m−1)+2∑_(odd l≥3) H_(m−l). Subtract the same
equation at m−2 to recover H_m=H_(m−1)+H_(m−2)+H_(m−3), with H_0=H_1=H_2=1,
and the m=3 case checked directly. This tribonacci formula is inherited,
not new: see [THM-4731](../../../01-canon/theorems/THM-4731-tiling-line-metagraph-self-lines-by-twisted-burnside-sigma-twins-depth-and-the-tribonacci-partner.md)
and the stronger polynomial identity in [Session137](../session137_overnight_proof_frontiers_20261102/cycle_carriers/THEORY.md).
The contrast is that a single chronological window gives a clean exact
infinite recurrence, but fails at a small attained target for a reason
that does not depend on its ability to solve valuation congruences.
