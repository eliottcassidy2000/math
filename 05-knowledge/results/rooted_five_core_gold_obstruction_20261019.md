# A genuine eight-point obstruction to core-only Gold strategies

2026-10-19. Exact scoped obstruction, independently checked. This is not a counterexample to Gold or to the classical balance conjecture.

## The poset

Start with the five-point core on $(b,x,z,y,a)$ generated by $b<z<a$, $x<a$, $b<y$. Adjoin a chain $t_1<t_2<t_3$, each of whose points is below $x,y,a$ and incomparable with $b,z$. This is the earlier conditional template $T(0,3,0,0)$; it is an actual eight-point poset, with maximum incomparability degree five.

Its 53 extensions induce the following counts on the eleven core orders:

| Core order | Count |
|---|---:|
| $b\ x\ z\ y\ a$ | 4 |
| $b\ x\ z\ a\ y$ | 4 |
| $b\ x\ y\ z\ a$ | 4 |
| $b\ z\ x\ y\ a$ | 10 |
| $b\ z\ x\ a\ y$ | 10 |
| $b\ z\ y\ x\ a$ | 10 |
| $b\ y\ x\ z\ a$ | 4 |
| $b\ y\ z\ x\ a$ | 4 |
| $x\ b\ z\ y\ a$ | 1 |
| $x\ b\ z\ a\ y$ | 1 |
| $x\ b\ y\ z\ a$ | 1 |

These also follow from the exact parameters $c=4,u=10,d=v=1$. They obey the realized moment bounds $c\le u\le c^2$, $d\le v\le d^2$.

## Every adaptive core-only strategy fails

Gold requires that, on every realized two-answer path, the sum of the surviving counts after the first and second comparison be at most the original count $E=53$. If a first answer leaves a heavy branch of mass $M$, and a proposed second comparison splits that branch into masses $r,M-r$, its worst-path deficit is

\[
53-M-\max(r,M-r).
\]

The following table gives the larger cell for each possible second uncertain core comparison. The second comparisons are ordered $(b:x,x:z,x:y,z:y,y:a)$.

| First pair | Heavy answer | $M$ | Larger cells for the five second choices | Best deficit |
|---|---|---:|---|---:|
| $b:x$ | $b<x$ | 50 | $(50,34,32,38,36)$ | $-29$ |
| $x:z$ | $z<x$ | 34 | $(34,34,20,30,24)$ | $-1$ |
| $x:y$ | $x<y$ | 35 | $(32,20,35,30,20)$ | $-2$ |
| $z:y$ | $z<y$ | 40 | $(38,30,30,40,25)$ | $-12$ |
| $y:a$ | $y<a$ | 38 | $(36,24,20,25,38)$ | $-5$ |

Every row is negative, even with the second choice optimized separately after each first answer. A comparable first pair leaves all 53 extensions and cannot begin a Gold strategy. A deterministic second comparison has larger cell $M$ and cannot improve any row. Thus **no adaptive two-comparison Gold strategy confined to the five core endpoints exists**.

The optimal core-only first pair is $x:z$. On its heavy branch $z<x$, the second comparison $x:y$ splits the 34 extensions as $20+14$, so the obstruction is already $34+20=54>53$. On its light branch, $z:y$ splits the 19 extensions as $10+9$. Hence the global best worst-path deficit is exactly $-1$, not just an upper bound.

## Exterior comparisons restore Gold

The full poset does have a fixed strict Gold strategy: compare $b:t_2$, then $z:t_3$. With rows and columns ordered false, true, its quadrant table is

\[
\begin{pmatrix}19&3\\16&15\end{pmatrix}.
\]

The row totals are 22 and 31, and every path has deficit at least $53-31-16=6$. Thus this control distinguishes failure of endpoint localization from failure of the underlying Gold property.

The arbitrary-degree rooted-five balance theorem remains valid, and this example has balanced core pairs. A Gold extension needs an exterior-sensitive witness rule; neither exact core moments nor full core-order probabilities can overcome an endpoint restriction that fails for an actual poset.
