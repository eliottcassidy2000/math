4. The 2-adic code orbit `−{1, 2, 4}/7` has Gauss period `ḡ`, and `−ḡ = g + 1 = τ_7`.

## 3. Visibility: the norm bound and the decomposition field of 2 (PROVED + FINITE-EXACT)

**Lemma 2 (norm bound).** Let `d > 3`, `d ≡ 3 (mod 4)`, `h(−d) = 1`. If a prime `p` splits in `K = Q(sqrt(−d))`, then `p >= (d + 1)/4`.

*Proof.* `O_K = Z[τ_d]` has norm form `N(x + yτ_d) = x^2 + xy + ((d + 1)/4) y^2`. A split prime is the norm of a principal prime `α`. Then `α ∉ Z`, since rational integers have square norms, so `y ≠ 0`. Hence `p = (x + y/2)^2 + (d/4) y^2 >= d/4`, and since `d/4` is not an integer, `p >= (d + 1)/4`. ∎

Equality holds for every Heegner `d >= 7`. The smallest split primes are `2, 3, 5, 11, 17, 41` for `d = 7, 11, 19, 43, 67, 163` (`.out` §4). This is the S650 horizon read from the field side.

**Corollaries.**

- (i) In a class-number-one imaginary quadratic field, 2 splits only for `d = 7`.
  - For `d ≡ 3 (mod 4)`: `(d + 1)/4 <= 2` forces `d <= 7`, and `d = 3` has 2 inert.
  - `d = 1, 2` ramify 2.
  - Scan: among squarefree `d ≡ 7 (mod 8)` up to 20000, only `d = 7` has class number one.
- (ii) Every prime below 41 is inert in `Q(sqrt(−163))`. Only 163 ramifies, and a split prime needs `p >= 41`.

**Proposition 3 (visibility).** Let `m` be odd and `H = <2> ⊂ (Z/m)^*`, the decomposition group of 2 in `Q(ζ_m)/Q`. Let `K` be an imaginary quadratic field of discriminant `D`. Then `K ⊂ Q(ζ_m)^H` iff `|D|` divides `m` and 2 splits in `K`. Consequently:

1. the decomposition field of a binary code with odd denominator `m` contains a class-number-one imaginary quadratic field iff `7 | m`, and that field is `Q(sqrt(−7))`;
2. Ramanujan's `Q(sqrt(−163))`, and every Heegner field other than `Q(sqrt(−7))`, lies in no decomposition field of 2. No parity code of any cycle of any 0/1-coded map can see it.

*Proof.*

- `K ⊂ Q(ζ_m)` iff `|D|` divides `m` (conductor–discriminant).
- `K` is fixed by `H` iff its character satisfies `χ_D(2) = +1`. As `D` is odd, 2 is unramified in `K`, so this says 2 splits.
- Then apply Corollary (i). ∎

**Which orbits carry CM points.**
