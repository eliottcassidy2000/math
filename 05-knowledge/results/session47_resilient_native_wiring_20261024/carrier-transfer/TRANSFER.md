## 2. Exact block extension over any modulus

Let the original graph be connected, with one retained root, and let A be its
integer root-reduced Laplacian, of size n. Grounding is legitimate because the
full Laplacian has zero row sums: the omitted root equation follows from all
remaining equations. For m>=2 put R=Z/m and H_m=ker(A mod m).

First suppose the enlarged graph has the old nonroot vertices literally
retained, plus k new vertices, with reduced Laplacian

    N = [ B   C ] ,     E = [ C ],     F = [ B  ].
        [ C^t D ]           [ D ]         [ C^t]

We do not assume B=A: the actual new old-vertex degrees are part of B.
A given x in H_m extends to a new harmonic (x,y) exactly when

    E y = -F x mod m.                                         (2.1)

Consequently the following three conditions are equivalent:

    Every old harmonic extends pointwise.
    F H_m is contained in im E.
    F^t z lies in im A^t for every z in ker E^t.                (2.2)

Proof: the first equivalence is the two block equations. For the second,
finite-ring character duality gives (ker E^t)^perp=im E and
(ker A)^perp=im A^t. This is valid over Z/m, including nonunits and composite m;
no rank calculation over a field is substituted.

An equivalent relation-contraction gate, using symmetry of N and A, is

    {d in R^n : (d,0) lies in im N} is contained in im A.       (2.3)

Indeed the annihilator of the coordinate projection of ker N is exactly the
set on the left. Thus extension fails precisely when the enlarged graph
creates a new old-supported relation detected by an old character.

The set pi(ker N) need not itself lie in H_m. Hence the surjection associated
with (2.2) is explicitly

    ker N intersect pi^(-1)(H_m)  -> H_m,

not an unjustified restriction map from every new harmonic to an old one.

For a selected list x_j, rather than all of H_m, solve (2.1) for those actual
vectors with their actual moduli. This weaker selected-bank task is not an
all-character theorem.

## 3. The Schur complement is exact only after its unit test

If det D is a unit modulo m, the new coordinate is uniquely

    y = -D^(-1) C^t x,

and pointwise extension of the entire old bank is equivalent to

    (B - C D^(-1) C^t) H_m = 0.                              (3.1)

Equivalently every row of the displayed Schur complement belongs to im A^t.
There is then an additive section. If D is not invertible, retain (2.1),
including both old and new rows. A rational inverse, rational Kron reduction,
or multiplication by det D cannot replace the finite-ring equation.

An exact hostile is the old root edge of weight 4, together with one new
vertex joined to each old endpoint by weight 2. At m=4,

    A=[4],     N=[ 6 -2 ],     D=[4].
                 [-2  4 ]

The projected new kernel is {0,2}, while the old kernel is all of Z/4.
The rational Schur complement is the integer 5: its modular kernel would
incorrectly exclude the genuinely extendible x=2. The cleared numerator is
20: its modular kernel would incorrectly include the nonextendible x=1.
Even an integral rational Schur complement can be wrong at the bad prime.

## 4. A section is stronger than pointwise extension

A prescribed ambient linear lift has the form P=[I;T]. It preserves every
old mod-m harmonic exactly when

    N P = Q A mod m                                           (4.1)

for some matrix Q over R. This is simply the row-annihilator test.

Moreover an additive section on H_m exists if and only if such an ambient
P exists. One direction is immediate. For the other, every R-linear map
H_m -> R^k extends to R^n -> R^k. To see this without a field assumption,
use integer Smith coordinates. A diagonal kernel coordinate is generated
by m/g with order g, where g=gcd(d_i,m). Its image must be killed by g,
hence is a multiple of m/g and extends by multiplication on the ambient
coordinate. Transport back through the unimodular coordinate change.
Additive group homomorphisms here are automatically R-linear.

Pointwise extension need not split. Retain an old double edge r--v, and add
two fresh vertices a,b, each connected by unit edges to both r and v:

    A=[2],     N=[ 4 -1 -1 ].
                 [-1  2  0 ]
                 [-1  0  2 ]

Modulo 4, the old nonzero harmonic x=2 has exactly two extensions:

    (2,1,3), (2,3,1).

Both have order 4, while x has order 2. Thus every old character extends,
but no additive section exists. Modulo 2 the old harmonic x=1 does not
extend at all. The missing coordinate is the order of the lift: choosing
arbitrary images of generators does not ensure their relations survive.

To make the failed modulus the true top Smith level, adjoin another unchanged
old vertex joined to the root by four parallel edges. Then

    A=diag(2,4),
    N=[ 4  0 -1 -1 ].
      [ 0  4  0  0 ]
      [-1  0  2  0 ]
      [-1  0  0  2 ]

The old dyadic exponent really is 4. Pointwise extension passes at modulus 4
and fails at modulus 2. So checking only the top modulus is genuinely
insufficient for pointwise transfer, not merely checking the wrong top.

## 5. The finite Smith-level theorem

**Theorem (dyadic transfer).** Fix integer A and N as above, with det A nonzero.
Let U A V=diag(d_1,...,d_n) be an integer Smith decomposition and let

    a_i = v_2(d_i),     S={a_i:a_i>0},     s=max S.

If S is empty, every old grounded dyadic bank is zero and transfer is vacuous.
Otherwise the following are equivalent:

1. Every old harmonic extends pointwise at every dyadic modulus.
2. Pointwise extension holds at each of the finitely many moduli 2^a, a in S.
3. There is a single integer T such that P=[I;T] sends every old grounded
   dyadic harmonic to a new harmonic, at every dyadic modulus.
4. The old bank has an additive section at the single top modulus 2^s.
5. There are integers T,Q and a positive odd integer d with

       d N [I;T] = Q A                                      (5.1)

   as an exact integer matrix identity.

**Proof.** (1) implies (2). For (2) implies (3), put v_i=V e_i. Since
A v_i=U^(-1)d_i e_i, the vector v_i is harmonic modulo 2^a_i when a_i>0.
Choose a solution y_i of E y_i=-F v_i at exactly that modulus. Choose any
integer representatives of y_i, and set y_i=0 when a_i=0. Because V is
unimodular, an integer matrix T exists with T v_i=y_i for every i.
Thus (N[I;T])v_i is divisible by 2^a_i.

In Smith coordinates every x in ker(A mod 2^k) is an integer combination of

    2^max(k-a_i,0) v_i mod 2^k.

The corresponding defect is divisible by 2^k, proving (3). This construction
is order-aware and builds one T, rather than a separate unstructured choice
of extension for every character.

(3) implies (1) and (4). Conversely (4) gives ambient P at modulus 2^s by
section 4. For k<=s, test 2^(s-k)x against its defect at the top level. For
k>=s, Smith coordinates give the exact equality

    H_(2^k) = 2^(k-s) H_(2^s),                              (5.2)

where representatives on the right are multiplied into Z/2^k. Thus the same
integer representative P works at all levels, proving (3).

Finally, for a fixed P put M=N P. Condition (3) says M v_i is divisible by
2^a_i for every i. Hence every denominator of the rational matrix M A^(-1)
is odd. Clearing its denominators gives (5.1). Conversely an odd d is a
unit modulo every power of two, so (5.1) implies (3). QED.

Checking all levels 1,...,s is therefore sufficient but unnecessarily broad.
Checking only level s is sufficient for a **fixed linear lift**, but not for
mere pointwise extension. Checking the distinct positive Smith levels is
sufficient for pointwise extension and constructs a common lift.

The same proof works prime by prime, replacing two by p and requiring d
coprime to p. Invariant factors alone identify the levels but not the
owner-marked v_i needed for the constructive certificate.

## 6. Endpoint records need not be an old-vertex inclusion

A native enlargement may retain endpoint records without literally embedding
the old metagraph vertices. Then do not force it into the block model.
Let z be the new grounded potential, and suppose actual endpoint evaluations
are encoded by integer matrices R_new and R_old. They can be coordinate
readouts or signed endpoint differences. The correct system for old x is

    N z=0,     R_new z=R_old x mod m.                        (6.1)

Set M=[N;R_new] and J=[0;R_old]. Then a selected x transfers exactly when
Jx is in im M; the whole bank transfers iff

    J ker A is contained in im M,

or equivalently J^t ker M^t is contained in im A^t. All matrices and their
owner meanings must be supplied. The Smith-level proof in section 5 applies
unchanged to (6.1): solve for each marked v_i at its own 2^a_i, assemble an
integer lift Z, and obtain an odd-denominator identity

    d (M Z - J) = Q A.

This preserves all requested readouts on all old dyadic harmonics. It need
not give R_new Z=R_old on arbitrary nonharmonic old vectors, and that stronger
ambient identity is not required.

There is an earlier collision gate. If two different old endpoint records
u,v name the same new canonical node, exact transfer forces x_u=x_v for all
transferred characters. For the full old bank this is equivalent to

    e_u-e_v in im L_old mod m.

Literal metadata retaining both names does not evade the equality. A map
from records to old labels need not descend to a function on canonical new
vertices; verify it before even testing harmonicity.

## 7. Positive abstract graph mechanisms and their native boundary

Two exact sufficient constructions illustrate what a real certificate looks
like. They are graph mechanisms, not claimed tournament carrier mechanisms.

- Attach any graph to an old vertex through that single old attachment.
  Extend the potential constantly over the attached graph. With P the
  constant pullback and J the old-row inclusion, L_new P=J L_old over the
  integers. Thus every old character transfers at every modulus. New
  internal harmonic modes may exist, so this proves inclusion, not equality
  of harmonic banks. A unit pendant tree contributes no new modes.
- Replace every old vertex by q clones and every old edge of conductance w
  by the complete bipartite set of q^2 edges, each of conductance w. Arbitrary
  internal fibre edges do not matter on constant fibre values. Then
  L_new P=q P L_old exactly. No division by q is used, including at primes
  dividing q. Again, a native realization needs separate authentication.

The cheapest hostile to endpoint-only transport is the retained double edge
r--v with one additional unit two-edge r--a--v path. The old reduced A=[2]
has nonzero harmonic 4 modulo 8. The new reduced matrix [[3,-1],[-1,2]] has
determinant 5, so its mod-8 harmonic bank is zero. The old endpoints and the
old edge survive literally, but the old dyadic character does not.

## 8. Harmonic transfer is not physical-row move transfer

Suppose P already transports the old bank and an actual proposed rewiring
changes the new reduced Laplacian by Delta N. The transported bank remains
harmonic after the move exactly when

    Delta N P annihilates ker A mod m,

equivalently every row of Delta N P is in im A^t modulo m. A fixed integer P
again needs only the old top modulus 256 for the full dyadic predicate.
Keep each actual new physical owner row; summing rows with the same old
record can hide a violation. Retain diagonal degree changes unless the
actual integer margins prove they vanish.

A small paired-edge hostile makes this visible. Old A=[4], new N=diag(4,4),
and P=(1,1)^t. The old character x=2 modulo 8 pulls back harmonically to
(2,2). Moving conductance two from the first fresh owner to the second gives
Delta N=diag(-2,2). Its two nonzero physical defects are (4,4) modulo 8,
although their collapsed old-owner sum is zero. The move uses the genuine
factor two, so that factor is not a cure for owner-row collapse.

For a target-570 enlargement the remaining work is therefore explicit:

1. Authenticate the actual enlarged Laplacian, root, and endpoint readout on
   canonical nodes, including any collisions of marked endpoint records.
2. Specify whether the promise is selected potentials, paired dyadic current,
   or the entire ordinary old harmonic bank.
3. For the last promise, solve the systems at 2,4,256 and retain an
   order-respecting common lift or the odd-multiplier matrix certificate.
4. Test every proposed event on every physical new owner row, with actual
   integer degree changes and the true paired conductance.
5. Independently preserve the shared literal pins, allowed Hamiltonian paths,
   full kernel lifts, converse clock reversal, normalized resource injection
   and immutable remainder. None is inferred from an electrical certificate.

optimization-sensitive assertions. It enumerates labelled weighted graphs,
not tournament isomorphism classes. Every old graph is connected, all old
edge weights are retained, and added weights are nonnegative. For each graph
