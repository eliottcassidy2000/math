# Two-slot triangles are locally universal: a positive width-three controller

**Status: PROVED; independent all-order proof review accepted.** The theorem
is all-modulus, not extrapolated from finite residue searches. Integer spectrum
completeness and globally bounded spectral substitution width remain OPEN.
No external priority claim is made.

## The theorem and its scope

Let G2 be the grammar with seed K1 and just two binary operations

```
J(T,U)=T->U,             B(T,U)=C3[T,U,K1].
```

Every generated tournament has substitution width at most3; every cyclic
node has at least one singleton child. Let S2str be the Hamilton-path counts
of its nontrivial strong tournaments.

> **Local universality theorem.** For every integer M>=1 and every residue z
> with `gcd(2,M) | z-1`, there are arbitrarily large, distinct values
> `H in S2str` with `H=z mod M`. Consequently
>
> `closure(S2str) = 1+2 Zhat`.

All CRT conditions are met by **one actual tournament**. Every modular
inverse used in the proof is replaced by a nonnegative power of a genuine
constructor. No negative vertex count, subtraction of tournaments, or
unrealized path-cover state is allowed.

The inherited Session136 certificates give `w(13)=w(19)=5` and `w(31)=6`,
so G2 misses13,19,31 as exact integers. Nevertheless the theorem approximates
each of them modulo every modulus, even with strong width-three witnesses.
This is a strict local/global resource separation, not full integer coverage.

Phase1 proves that the smaller grammar generated by J and only
`C(T)=B(T,K1)` misses all H congruent7 or11 modulo12. Thus allowing **two
nonsingleton cyclic children**, but still never needing three, changes the
scalar profinite closure from a proper subset to all odd profinite integers.

### A sharp local width collapse

Index widths by positive integers, giving the seed K1 width1. For a positive
integer h define its local width to be the least w such that,
for every M, some tournament of substitution width at most w has count
congruent to h modulo M. Then

```
local_width(1)=1,
local_width(h)=3 for every odd h>1,
local_width(h)=infinity for every even h.
```

The upper bounds follow from the theorem. Width at most2 constructs only
transitive tournaments and hence only H=1. For h!=1 choose a modulus not
dividing h-1 to exclude that resource. Parity excludes even h. Thus every
scalar congruence observer, even with arbitrarily large separately chosen
moduli, collapses the exact width hierarchy at3. For example the inherited
exact widths5,5,6 at h=13,19,31 all have local width3. This corollary does not
assert that exact widths are globally bounded.

## 1. Inheritance and the polynomial carrier

The inherited path-cover substitution kernel and source-padding hostile are
in Session136 `gluing/PROOF.md`, Sections1–5, under
`05-knowledge/results/session136_full_tournament_spectrum_20261102/`.
The exact widths above are its Sections8–9. Phase1 of Session137 supplies the
sharp divisor `c!(c-1)!`, exact modular context equivalence, and the mod12
smaller-grammar obstruction. These inputs are not claimed new here.

The separate Session136 `local_closure/PROOF.md` proves profinite universality
for one-apex tournaments, but those graphs need not have bounded substitution
width. We do **not** infer the present width-three theorem from that result.
Its positive-inverse and CRT-reset mechanisms motivate the actual controller
below. The new carrier, gate identities, exceptional-prime handling, and
fixed width-three realization are proved explicitly.

For a nonempty tournament T, let p_T(c) count unordered covers by c nonempty
directed paths, and define the integral polynomial

```
F_T(x)=sum_{c>=1} p_T(c)(x)_c,
(x)_c=x(x-1)...(x-c+1).
```

Write `h=F_T(1)=H(T)`, `g=F_T(2)=2(H(T)+p_T(2))`, and `f=F_T(3)`.
In particular F_T(0)=0. Source padding `P(T)=K1->T` multiplies F by x, and
ordinal join multiplies polynomials. These are inherited kernel consequences.

The useful binary cyclic law is

```
F_B(T,U)(x) = x [ F(x)G(x)
  +(F(x+1)-F(x))(G(x+1)-G(x))
  +(F(x-1)-F(x))(G(x-1)-G(x)) ].                    (1)
```

For the polynomial form of OCF, expand the inherited H-identity inside the
set-partition formula for p_T(c). Contract each cycle of a disjoint odd-cycle
collection to one atom. A collection C then contributes
`2^|C| S(n-sum_(gamma in C)(|gamma|-1),c)` to p_T(c). Using
`sum_c S(k,c)(x)_c=x^k` gives

```
F_T(x)=sum_C 2^|C| x^(n-sum_(gamma in C)(|gamma|-1)).
```

This is the inherited Stirling/OCF lift, not a new priority claim.
Identity(1) is bilinear in the two factor profiles. One direct derivation
checks the monomial basis `F=x^r,G=x^s`, represented by transitive factors.
Every odd cycle in `C3[L_r,L_s,1]` passes through the singleton, so a disjoint
odd-cycle collection has at most one cycle. Such a cycle chooses nonempty
increasing subsets of both transitive factors; their total size must be even.
The inherited OCF therefore gives exactly the two finite-difference products
in(1). The path-cover kernel is bilinear, and `{x^r:r>=1}` is a polynomial
basis, so the identity extends to all factor polynomials.

Two special unary operations are

```
C(T)=B(T,1),             D(T)=B(T,L2).
```

Their exact polynomial operators are

```
C F = x^2 F+x(F(x+1)-F(x-1)),
D F = (x^3-2x)F+(2x^2+x)F(x+1)+(x-2x^2)F(x-1).     (2)
```

Thus `H(C(T))=h+g` and `H(D(T))=3g-h`.
The minus signs in these **evaluation identities** do not authorize negative
constructors: C,D themselves are actual positive tournament operations.

## 2. The modulus, reset, and fixed auxiliary factors

Write

```
M=2^a 3^b n,             gcd(n,6)=1,
m=3^b n.
```

Choose an integer N with

```
N>=max(a,b)+4,
2^N=1 mod m,             3^N=1 mod n.               (3)
```

For example a sufficiently large multiple of `phi(m)phi(n)` works, with
`phi(1)=1`. Define the reset class of actual factors by the sidecars

```
g=0 mod2^a,              f=0 mod3^b.               (4)
```

Padding by P^N puts every actual factor into this class without changing H;
it preserves g modulo m. Every gate below preserves(4).

Set `U0=L_N`, and for any fixed auxiliary U define

```
F_U(T)=P^(N-1) B(T,U).
```

This is a genuine positive unary context. Define

```
D1=F_U0,
U2=D1(U0),               U4=D1^2(U0),
A=F_U2,                  A4=F_U4,
V=P^(N-3) D(U2),         Vgate(T)=J(T,V).           (5)
```

All factors and operations lie in G2. Dependence on M enters only through
these derived contexts and their repetition counts, not through a larger
bank of quotient operations.

On the n-part, U0 has F-values1 at x=1,2,3,4. Equation(1) shows that U2 has
values `(2,1,1)` at x=1,2,3, and U4 has `(4,1,1)` there. On the 3-primary
part their triples are respectively `(1,1,0)`, `(2,2,0)`, `(4,4,0)`.
On the dyadic part their H-values are1,3,9 and their g-values are zero.
These statements use only(1),(3), padding, and F(0)=0.

## 3. The actual gate table

For factors satisfying(4), retain only

```
H_2 = H mod2^a,
(H_3,g_3) = (H,g) mod3^b,
(h,g) = (H,g) mod n.
```

The gates in(5) act as follows. All fractions in the last two columns are
inverses of powers of two in odd residue rings.

| gate | dyadic H | 3-primary pair | n-pair |
|---|---|---|---|
| D1 | `3H_2` | `(2H_3,2g_3)` | `(2h,g)` |
| A | `9H_2` | `(4H_3,4g_3)` | `(5h-g,h)` |
| A4 | `27H_2` | `(8H_3,8g_3)` | `(11h-3g,3h-2g)` |
| Vgate | `-3H_2` | `(4H_3,-g_3/2)` | `(h,g/4)` |

Here are the checks that prevent a hidden higher-profile assumption.
Equation(1) at x=1 gives

```
h_new=3hu-gu-hv+gv,
```

where `(u,v,w)=(F_U(1),F_U(2),F_U(3))`. After the padding in F_U, its x=2
response is

```
g_new=(u-v)h+(3v-u-w)g+(w-v)f.                     (6)
```

On the n-part, w=v for U0,U2,U4, so f cancels. On the 3-primary part, f=0
by the reset and w=0. On the dyadic part only the H response is retained;
g and v vanish, giving `h_new=3hu`. The final padding preserves both reset
conditions. For V, equations(2) give before padding

```
h_D=3g-h,              g_D=4g+10f-6h.
```

Substituting U2's values gives exactly the last table row. Joining V preserves
the reset class because the relevant polynomial evaluations multiply.

D1,A,Vgate are **permutations** on the displayed finite controlled state:
their scalar factors are units, and A's n-matrix has determinant1. Thus their
inverses on that state are positive powers of the same actual gates. For an
explicit coarse bound, the controlled state has at most
`K=2^a(3^b n)^2` elements. Each inverse can be replaced by the gate to power
`K!-1`. Smaller matrix/unit orders may be used. Higher profile coordinates
need not return to their original values: the reset class is invariant, and
all future controlled gate responses depend only on the displayed state.
This distinction is essential.

Use ordinary composition order, rightmost operation first. Put

```
U = A D1^2 A^(-1) Vgate.
```

Multiplying the actual controlled matrices gives

```
U: H_2 -> -27 H_2,
   (H_3,g_3) -> (16 H_3,-2 g_3),
   (h,g) -> (h+(15/4)g,g).                           (7)
```

Let

```
r=2^a 3^b,              S=U^r,
tau=(15/4)r mod n.
```

The units `16` and `-2` are1 modulo3, so their orders modulo3^b divide3^b;
the order of `-27` modulo2^a divides2^a. Consequently S fixes both primary
anchors, including the full 3-primary pair, and acts on the n-pair by

```
S: (h,g) -> (h+tau g,g),
gcd(tau,n)=gcd(5,n).                                 (8)
```

Two more positive contexts are

```
R=D1^(-2) A,             E=D1^(-3) A4.
```

Both fix the dyadic H and the 3-primary pair **exactly**. On the n-part,

```
R(h,g)=((5h-g)/4,h),
E(h,g)=((11h-3g)/8,3h-2g).                            (9)
```

R has determinant1/4. E has determinant `-13/8`, so E must **not** be
inverted or assumed harmless at prime13. The safe preconditioning below
explicitly avoids its kernel.

## 4. Actual anchor seeds and the 2/3-primary unit lemma

Four actual G2 tournaments have pairs

| H | g=F(2) | construction |
|---:|---:|---|
| 3 | 12 | `B(1,1)` |
| 5 | 32 | `B(L2,1)` |
| 17 | 224 | `B(L4,1)` |
| 23 | 296 | `B(L3,L2)` |

Their full profiles and literal vertex counts are checked in the replay.
Ordinal joins multiply both columns.

**Unit lemma.** The integers5,17,23 generate the entire unit group modulo
`2^A 3^B` for every A,B>=0, using nonnegative exponents.

One finite base check gives all24 units modulo72=8*9. To justify the uniform
lift, suppose their generated subgroup is proper in the finite abelian unit
group at a higher modulus. Its quotient has a nontrivial character to C2 or
C3. The elementary structures

```
(Z/2^A)^* = C2 x C_(2^(A-2))     (A>=3),
(Z/3^B)^* = C2 x C_(3^(B-1))     (B>=1)
```

show that every character to C2 or C3 factors through reduction modulo72
(or its appropriate divisor at small A,B). Equivalently, the higher dyadic
kernel consists of squares and the higher 3-adic kernel of cubes, while the
other primary component has coprime order. This contradicts the base check.
The displayed unit structures follow, for example, by binomial induction
from the valuations of `5^(2^j)-1` and `4^(3^j)-1`; no unproved primitive-root
assertion or Artin-type conjecture is involved. Negative powers in a finite
unit group are replaceable by positive powers.

Now fix the desired parity-compatible z modulo M. Choose
`v=min(v_3(z),b)`, taking v=b when z=0 modulo3^b. By the unit lemma choose
nonnegative k,l,e so that

```
H_seed=3^v 5^k 17^l 23^e
```

agrees with z simultaneously modulo2^a and3^b. Explicitly solve for the unit
quotient modulo `2^a 3^(b-v)`, after dividing by3^v on the 3-primary side and
multiplying by its inverse on the dyadic side. Require k>0; if initially k=0,
add the order of5 in that unit group, without changing either anchor.
The actual seed is the corresponding ordinal join, followed by P^N reset.

Its second evaluation is, modulo the odd part,

```
g_seed=12^v 32^k 224^l 296^e.
```

The odd prime factors of H_seed belong to `{3,5,17,23}`, while those of
`g_seed` belong to `{3,7,37}`. Hence

```
gcd(H_seed,g_seed,n)=1.                              (10)
```

If5 divides n, forcing k>0 additionally gives

```
H_seed=0 mod5,             g_seed!=0 mod5.            (11)
```

This deliberate zero/nonzero sidecar is not cosmetic. The mod5 R/E action
has fixed diagonal vectors; starting from an arbitrary nonzero vector would
not support the next argument.

## 5. Steering the remaining odd part without changing the anchors

Write `n=5^c n0`, with `gcd(n0,30)=1`. All operations in this section are
S,R,E and thus preserve the already correct dyadic and 3-primary anchors.

### First make g a unit on n0

Initially(10) says that h,g do not both vanish modulo any prime dividing n0.
For each prime power p^d dividing n0:

* if p divides g, h is already a unit; take shear exponent0 modulo p^d;
* if p does not divide g, choose the shear exponent so
  `h+tau k g=1 mod p^d`.

The second choice is possible because tau and g are units there. CRT gives
one nonnegative exponent k simultaneously. After S^k, h is a unit modulo n0.
Apply R. Its new second coordinate is the old h, so g is now a unit modulo
n0. If c>0, the starting pair(11) becomes `(t,0)` modulo5 with t nonzero.

If c=0, g is already a unit modulo all n, tau is a unit, and a final shear
lands at any desired h. The rest of this section concerns c>0.

### The ten-state exceptional-prime control

Modulo5, equation(9) becomes

```
R(h,g)=(g,h),
E(h,g)=(2h+4g,3h+3g).                                (12)
```

The orbit of `(1,0)` is exactly

```
(0,1),(0,4),(1,0),(1,2),(2,1),
(2,3),(3,2),(3,4),(4,0),(4,3).
```

Every desired first coordinate occurs with a nonzero second coordinate.
Scaling gives the same assertion from `(t,0)` for each t!=0. This finite
claim is checked directly from the two displayed 2x2 matrices. A convenient
word table, read chronologically, is:

| start `(t,0)` | target h=0 | h=1 | h=2 | h=3 | h=4 |
|---|---|---|---|---|---|
| t=1 | R | RERER | E | ER | RE |
| t=2 | R | ER | RERER | RE | E |
| t=3 | R | E | RE | RERER | ER |
| t=4 | R | RE | ER | E | RERER |

All terminal second coordinates are nonzero. This is not a claim that R,E
act transitively on every nonzero vector: `(1,1)` is fixed, a required hostile.

### Safe implementation of that word at every other prime

Before each E in the chosen word, apply a shear to arrange `h=0 mod n0`.
Because g and tau are units modulo n0, this is possible. Equation(9) then
sends g to `-2g`, still a unit. This explicitly avoids E's prime13 kernel.

Before each R, shear to arrange `h=g mod n0`. R then sends the pair to
`(g,g)` modulo n0, so its second coordinate remains a unit.

These inserted shears do not change either coordinate modulo5, since tau is
a multiple of5. Thus the finite word table remains valid. At its end g is a
unit modulo both n0 and5, hence modulo n, and h has the desired residue z
modulo5.

### Final simultaneous landing

Solve

```
tau g k = z-h mod n.
```

Since g is now a unit and `gcd(tau,n)=5`, the sole solvability condition is
exactly the congruence modulo5 already arranged. A nonnegative solution k
therefore exists. Apply S^k. The resulting actual tournament has H=z modulo
n **and** the original correct residues modulo2^a and3^b. This proves the
all-modulus scalar realization theorem.

## 6. Positive inverses, strong witnesses, and unbounded fibres

Every gate is an actual context built using only J,B. The three inverse
symbols D1^(-1),A^(-1),Vgate^(-1) mean positive powers on the finite controlled
state, as proved in Section3. E is never inverted. All CRT and congruence
solutions are chosen as nonnegative integers. Thus the proof yields a finite
expression, not merely a reachable formal state.

At the end one may add n to the final S exponent: its action on the n-pair
is unchanged, and its actions on the other controlled coordinates are already
identities. This makes the last S block positive. Recall
`S=U^r` and `U=A D1^2 A^(-1) Vgate`; chronologically, the final primitive gate
is A. Its output is

```
P^(N-1) B(T,U2).
```

The outer padding is H-neutral but makes the graph nonstrong. **Delete only
this final neutral padding, after all continuation has ended.** The remaining
`B(T,U2)=C3[T,U2,1]` is strong, lies in G2, and has exactly the same integer
H. We do not assert that the padded intermediate controller outputs are strong.

Adding any further positive multiple of n to the final S exponent preserves
all residue conditions. For every B(T,U), the three cyclic blockwise concatenations give
`H(B(T,U))>=3H(T)H(U)`. Each U contains A,D1,D1, so it multiplies H
by at least27; joins and source padding cannot decrease H. Thus these choices give
arbitrarily large, distinct counts, each with a final strong G2 witness.
Rédei parity excludes the incompatible residues, completing the profinite
closure statement.

The proof is effective but supplies no useful minimal-order or bit-complexity
bound. Even the positive inverse bound K! can make expanded graphs immense.
Compact repetition recipes are legitimate finite graph descriptions, not
claims that their expansion is inexpensive.

## 7. Reproduction and hostile boundaries

Run from this directory:

```
python3 -B local_universality.py > normal.json
python3 -B -O local_universality.py > optimized.json
cmp normal.json optimized.json
```

The standalone standard-library program verifies:

* 176 values of the bilinear polynomial identity against actual substituted
  graphs, with independent literal permutation/cut profiles;
* actual H/g seed pairs `(3,12),(5,32),(17,224),(23,296)`;
* the full24-unit generation base modulo72;
* 1,950 gate and positive-inverse checks by **full polynomial-function
  operations**, not by reusing the predicted pair matrices, over M=2..40;
* 226 complete positive recipes replayed end-to-end as full polynomial
  functions, with inverse symbols expanded to actual positive gate powers;
* every parity-compatible target for M<=256 and selected larger mixed moduli,
  24,688 simultaneous constructor checks in total;
* all exceptional mod5 word-table entries and safe prime13 preconditions,
  including the explicit hostile `E(2,3)=(0,0) mod13` and the fixed
  diagonal `(1,1) mod5`.

The computed examples retain actual positive seed recipes, gate words,
nonnegative shear exponents, and the final simultaneous residue. The theorem
is the universal argument above, not the checked modulus range.

`operators.py` is a separate exploratory positive unary P/C/D orbit probe.
It finds every residue for every M<=128 but hits a stated20,000-state budget
at some larger powers. Those incomplete orbits are **not obstructions** and
are not dependencies of the proof. The uniform construction above covers
those moduli as well. No large Cartesian grammar closure is used.

**Loss ledger and limits.** The map retains H and selected polynomial
evaluations modulo one chosen M, together with reset sidecars. It discards
integer magnitude, full contextual equivalence, graph isomorphism, and
uncontrolled higher profile coordinates. Inverse gates restore only the
controlled state. E loses invertibility at13 and is used only with the stated
safe sidecar. Final removal of padding preserves H only because there is no
future continuation. The theorem establishes scalar local universality, not
all-context profile universality, integer completeness, or a uniform bound
on spectral substitution width for exact counts.
