# Fresh primary-source check

20 October 2026. These sources were retrieved in this review, rather than accepted only from the producer's source record.

1. J. Gwoździewicz, *Injectivity on one line*, arXiv:alg-geom/9305008v1, 19 May 1993. [Original PDF](https://arxiv.org/pdf/alg-geom/9305008v1). Theorem 1.1, page 1, assumes an algebraically closed characteristic-zero field and a polynomial plane map with nonzero constant Jacobian; injectivity on one affine line implies a polynomial automorphism. These are exactly the hypotheses used in the globalization argument. The original, not a secondary reformulation, fixes the scope.

2. Z. Jelonek, *A note on the Jacobian Conjecture*, arXiv:2011.03472v3. [Versioned text](https://arxiv.org/html/2011.03472v3). Theorem 2.7 repeats the one-line input and attributes it to Gwoździewicz. The displayed ambient-line notation omits a square; the original theorem above has the correct affine-plane statement. This is corroboration only.

3. A. Sathaye and J. Stenerson, *On Plane Polynomial Curves*, author-hosted text dated 10 September 2014. [Author PDF](https://www.ms.uky.edu/~sohum/ma561/affgeom/papnew.pdf). Section 3.1, item (3), on zero-based PDF page 8 gives the conductor/symmetry property for planar semigroups; zero-based page 7 relates these semigroups to one-place plane curves in characteristic zero. The low-delta packet proves the needed special result directly instead of relying on an unproved classification from this source. No claim that the hosted 2014 file is byte-identical to the 1994 chapter is made.

4. M. Suzuki, *Affine plane curves with one place at infinity*, Annales de l'Institut Fourier 49(2) (1999), 375–404. [Primary journal record](https://www.numdam.org/item/AIF_1999__49_2_375_0/), [DOI](https://doi.org/10.5802/aif.1678). The journal record confirms the title, bibliography and scope: an algebro-geometric account of the Abhyankar–Moh semigroup theorem and its inverse. It is background, not an additional unproved premise in this audit.
