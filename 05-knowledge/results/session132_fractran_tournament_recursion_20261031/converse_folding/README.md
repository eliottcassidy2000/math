# Half-size self-converse folding

[THEORY.md](THEORY.md) gives explicit inverse constructions and their correct groupoid/isomorphism-class scope. The literal checker verifies all self-converse classes and involutions through order6 and all pair/color orbits through half-order4. It retains the centralizer denominator and the C3 automorphism counterexample.

Run `python3 check_folding.py` and `python3 -O check_folding.py`; both outputs equal normal.json. The all-order theorem uses the proof, not finite extrapolation.
