## Exact universes and inherited filters

1. `head_search.py`: all ordinary tournament classes of orders 1–7,
   generated by all one-vertex extensions and exact degree-cell canonical
   forms. Counts 1,1,2,4,12,56,456. Only ports with the required starting
   H are tested for a particular kernel. This preserves every possible
   match. The search tests 505 ports.
2. `head_completion.py`: the inherited complete strong H<=375 inventory,
   every relevant strong port (8,525 tests), and every possible attainable
   exterior factor dividing the target kernel's content. Shifts stop
   exactly when the first target exceeds 375. This is a complete decision
   for each specified fixed kernel at all graph orders, **conditional on
   the inherited inventory**, by the SCC proof in R4. It is not a complete
   search over all construction methods or all larger shifts.
3. `port_transport.py`: all 95 stable port presentations on strong cores
   through seven and every other unselected old vertex, 322 cases. Full
   two-port tensors and strict dominance bounds decide every positive
   first-block size. Each case also has a literal size-two next-port test.
4. `cones.py`: all 60 marked core presentations underlying those 95 ports,
   their **entire** stable sets, full finite defect/slope tensors, and 60
   literal simultaneous size-two controls. The acyclic marked-set test is
   mandatory for the stated finite visit bound. No cyclic-port claim is
   inferred from these certificates.
5. `birth_atoms.py`: all ordinary bases through seven, all nonempty selected
   sets satisfying delta=1, every deletion, and every recursive legal
   predecessor chain. Counts concern old-edge-preserving births with
   unchanged old marks. Empty selected sets, reselection, and temporary
   nonunit states are not permitted by this grammar.
6. `marked_orbits.py`: actual automorphisms, checking every degree-preserving
   permutation against all edges. It quotients selected sets and stable
   subsets, never merely H or U. Equivalent entries are explicitly checked
   for matching U, predecessor existence and singleton reachability.
7. `arithmetic_births.py`: positive integers through 4096, proper nonunit
   multiplicative parents, distinct-parent closure, and loopless square
   graphs. Direct pair enumeration through 128 independently supplies 512
   controls. The complete all-order statements have elementary proofs in
   ARITHMETIC.md; 4096 is not used as evidence for an unproved extrapolation.

The ordinary tournament universe is the A000568 prefix, checked against
the inherited complete census. No table of labelled counts is substituted
for this universe. The output also explicitly distinguishes all marks on
ordinary representatives from marked isomorphism classes.

## Reproduction

Run from the repository root with Python 3; only the standard library and
the pinned repository modules are needed:

```text
python3 05-knowledge/results/seed_recursion_births_20261111/reproduce.py
python3 05-knowledge/results/seed_recursion_births_20261111/reproduce.py --optimized
```

`SOURCE_PINS.json` pins computation sources and inherited mathematical
inputs with SHA-256 after CRLF-to-LF normalization, so Windows checkout
conversion does not change the mathematical input. Each replay reruns
all eight engines, checks those pins, and requires every generated data
file to have exactly the same LF-normalized hash as before the run.
`REPLAY.json` and `REPLAY_OPTIMIZED.json` record the two modes separately.

The constructor itself is `realize.py`; its arguments and supported
domains are in README.md. The certificate files retain literal adjacency
rows, selected masks, port identities and source inventory references.
No numerical-only arrow is presented as a realizable graph operation.
