# Every nonzero time is non-rational in an infinite Hamiltonian family

**Status: PROVED + CITED CURVE INPUTS + INDEPENDENTLY AUDITED.**
Over any characteristic-zero field, let `a>=2`, let `f` be a nonconstant
polynomial, and put `I_a=p^a(p^3-y^2)`. The scalar-time formal Hamiltonian
flow generated by `f(I_a)` cannot send both `p` and `y` to rational
functions of `p,y` at any nonzero time. In particular none of these times
is a polynomial automorphism of the source. This concerns a specified
infinite family of completed repair operations; JC(2) remains **OPEN**.

The [independent audit](planar_jc_long_20260906_nonrational_audit.md)
accepts the proof, its field and topology comparisons, and all quantifiers.
The primary has 226 exact checks and the independent path 2,268; both
normal/optimized pairs are byte-identical.

## Precise statement and convergence

Let `K` be a field of characteristic zero and use

```
u=x^2 t, p=t(1+x^2t), y=xtp, D=p^3-y^2,
B_2=K[x,u,p,y] subset K[x,t],
{F,G}=F_x G_t-F_t G_x, delta(F)={F,f(I_a)}, I_a=p^a D.
```

The fields `K(x,t)` and `K(p,y)` agree: `x=yp/D`, `t=D/p^2`.
For `a>=2`, writing `f(z)-f(0)=z g(z)` gives

```
f(I_a)=f(0)+p^2D R,                 R=p^(a-2)g(I_a) in K[p,y].
```

Thus the completed Hamiltonian theorem applies. In particular it defines
inverse scalar-time automorphisms of the actual `D`-adic completion of
`B_2`. For the rationality test it suffices to work separately in the
complete valued field `K(s)((tau))`, using

```
p=s^2+tau, y=sp, D=tau p^2, I_a=tau p^(a+2),
{F,G}=tau(F_s G_tau-F_tau G_s).
```

This is an embedding of `K(p,y)`. It is not an identification with the
entire `D`-adic completion; the topology hostile in the companion theorem
still applies.

Write `f(z)=f(0)+f_k z^k+...`, where `k>=1` and `f_k!=0`.
The derivation `delta=f'(I_a){-,I_a}` raises `tau` valuation by at least
`k`, for every integer starting valuation. Indeed its `s` coefficient has
valuation at least `k`, and its `tau` coefficient at least `k+1`.
Consequently `E_lambda=exp(lambda delta)` exists for every `lambda in K`,
acts continuously on this complete field, obeys the additive group law,
and has inverse `E_(-lambda)`. It fixes `I_a` exactly.

**Theorem.** If `lambda!=0`, then

```
not ( E_lambda(p) in K(p,y) and E_lambda(y) in K(p,y) ).
```

Equivalently this particular completed operation does not restrict to a
rational selfmap of the source field. The assertion does not say that
either individual image is transcendental over that field.

## Infinite order detected by one leading coefficient

The exact identity

```
{p,I_a}=2p^(a-1)yD=2s tau p^(a+2)
```

gives

```
delta(p)=2k f_k s^((2a+4)k+1) tau^k + O(tau^(k+1)).
```

Every higher iterate has valuation at least `2k`, and `2k>=k+1`.
It follows that

```
E_lambda(p)-p
 =2 lambda k f_k s^((2a+4)k+1) tau^k + O(tau^(k+1)).    (1)
```

For every positive integer `n`, the same nonzero coefficient with
`lambda` replaced by `n lambda` occurs in `E_lambda^n(p)-p`.
Characteristic zero and `lambda f_k!=0` therefore show that the action
on `p` has infinite order. This argument does not substitute a numerical
value for the generic coordinate `s`.

## The generic invariant curve has genus at least two

Put `c=I_a`. This is transcendental over `K`, and let `F=K(c)`.
The function field `K(p,y)` over `F` has equation

```
y^2=p^3-c p^(-a).
```

There are two explicit birational hyperelliptic models:

| Exponent | New coordinate | Equation | Genus |
|---|---|---|---|
| `a=2r>=2` | `v=p^r y` | `v^2=p^(a+3)-c` | `r+1` |
| `a=2r+1>=3` | `v=p^(r+1)y` | `v^2=p^(a+4)-cp` | `r+2` |

Both right-hand sides have odd degree and are squarefree over an
algebraic closure of `F`. In the even case their only possible common
root with the derivative would be `p=0`, where the polynomial is `-c`.
In the odd case `0` is simple, with derivative `-c`; every nonzero root
has `p^(a+3)=c`, so the derivative is `(a+3)c!=0`.
In particular they are not squares, and the curve is geometrically
integral. The degree-two map to the `p` line ramifies at every simple
finite root and at infinity. Riemann--Hurwitz gives the displayed genus,
which is uniformly

```
g=ceil(a/2)+1 >= 2.                                    (2)
```

Suppose now that both formal images are rational. Since `E_lambda` is
an injective field map and fixes `c`, it restricts to an `F`-embedding
of this one-variable function field into itself. The correspondence
between function fields and smooth proper curves turns it into a
nonconstant selfmap of the smooth proper generic curve. This is precisely
the direction needed here; rationality of the inverse has not been
assumed. See [Stacks, Theorem 53.2.6](https://stacks.math.columbia.edu/tag/0BY1).

In characteristic zero this map is separable. If its degree is `d`,
Riemann--Hurwitz gives `2g-2=d(2g-2)+deg(Ram)`. By (2), `d=1`;
hence it is an automorphism.
See [Stacks, Riemann--Hurwitz](https://stacks.math.columbia.edu/tag/0C1B).

The automorphism group is finite. One way to check the precise hypothesis
is that the tangent sheaf has degree `2-2g<0`, so it has no global
sections. Thus the automorphism group scheme is zero-dimensional and of
finite type in characteristic zero, and has finitely many geometric
points. The `F`-automorphism group injects into this finite group.
The group scheme facts are given in
[Stacks, Section 109.7](https://stacks.math.columbia.edu/tag/0DST).
Therefore some positive iterate fixes `p`, contradicting (1).
This proves the theorem for every permitted `K,a,f,lambda`.

The argument deliberately uses the invariant `I_a`, rather than treating
`f(I_a)` as a new transcendental constant: a generic fibre of the latter
may split after extending the constant field.

## Comparison with the literal source specialization

The polynomial-source consequence needs a comparison, because the full
`D`-adic completion is not the Laurent completion. For the two fixed inputs
`p,y`, the Laurent flow has images in `K[s][[tau]]`, hence in `K[[s,tau]]`.
There is an injective homomorphism

```
sigma:K[[s,tau]] -> K[x][[t]],       s -> xt, tau -> t.
```

Indeed the coefficient of `s^i tau^j` becomes the coefficient of
`x^i t^(i+j)`, so no two monomials collide. Each coefficient of a fixed
power of `t` is a finite polynomial in `x`. This map intertwines the two
flows on `p,y`: it intertwines their polynomial derivations and their
convergent series. Suppose both literal source images were rational in
`K(x,t)`. The birational inverse `x=s/tau,t=tau` rewrites either proposed
image as `g(s,tau)/h(s,tau)`, with `h!=0`. Multiplication by the denominator
and injectivity of `sigma` force the corresponding Laurent image to equal
`g/h`, contradicting the theorem. Thus the literal source flow cannot send
both source coordinates to rational functions either.

Finally a polynomial specialization on `B_2` of the `D`-adic flow would
give polynomial images of `p,y` after the continuous map to the source
completion proved in the companion theorem. This too is impossible.
This argument requires no injectivity of that map on the full `D`-adic
completion and makes no unproved identification of its elements with
Laurent series.

## Equality boundary and hostile control

For constant `f` or `lambda=0`, the flow is the identity, and the conclusion
fails. The range `a>=2` places every generator in the universal source
carrier. No assertion about all other Hamiltonians is inferred.

Failure of local nilpotence is insufficient for this result. In the same
source plane, the Hamiltonian `u=x^2t` has

```
delta x=x^2, delta t=-2xt, delta^n x=n! x^(n+1),
x -> x/(1-lambda x),       t -> t(1-lambda x)^2.        (3)
```

The rational map in (3) preserves `u` and `dx wedge dt`, and has inverse
obtained by negating `lambda`. It is the rational expression of the
time-formal flow. It is not claimed to converge in the `D`-adic topology
used above. Its invariant generic curve has genus zero. Thus the first
failed implication is “non-locally-nilpotent implies every time is
non-rational”; the missing coordinate is the generic invariant genus.
The strongest survivor is the high-genus obstruction just proved.

## Consequence for the planar program and exact controls

This branch preserves actual source depth, the completed affine source
family, and the differential at all orders, yet fails rational
specialization at every nonzero time in the explicit family. It isolates
termination as a real additional obligation for these operations. It does
not exclude compositions of different formal operations, all universal
carriers, unrelated polynomial Keller pairs, or the remaining source
boundary. The next question is whether an operation with a genus-zero or
genus-one invariant can realize a useful finite response inside the
universal carrier.
