# Reproducible old-session detours

I sampled an archived repository tree, excluding filenames about
tournaments, Hamiltonian paths, metagraphs, spectra, audits and lonely
runner. In the tracked paths under 07-reflections and 05-knowledge/results
I kept .md paths containing 202607, 202608 or 202609, and drew twelve
without replacement with Python random.Random(202611141733). The tree was
the archived local HEAD beginning 1b91742ce55a; it was used for archaeology,
not as the source of current frontiers. One can run git ls-tree -r --name-only
at that revision to reconstruct the sorted input and then repeat the draw.

Five of the sample's reflection notes were read in detail:

- [Knot curvature mixed cohabitation, July 25](../../../07-reflections/knot-curvature-mixed-cohabitation-kernel-opus-20260725.md):
  its chamberwise mixed difference became the test for independence on
  the contact-switch cube. What transfers is the four-corner diagnostic.
  The tournament kernel, its adjacency correction, and its exact carry
  exception are independently derived here.
- [Rule 30 wrap and staircase, August 16](../../../07-reflections/rule30-newton-fiber-wrap-and-staircase-codex-20260816.md):
  matching separate boundary marginals did not identify the joint event.
  This prompted retaining the physical pair-cover coefficients with the
  dyadic high/low-address split, and checking an integer rather than just
  the residue. The collar gap calculation is a separate exact bit proof.
- [Fixed Berggren drift, August 16](../../../07-reflections/berggren-fixed-drift-language-mod12-and-harmonic-parity-smoothing-codex-20260816.md):
  the wordwise gauge vs uniform branch gauge distinction parallels a
  one-off exact intersection vs a single reindexing that works at all
  targets. No ternary-tree theorem is transferred.
- [Planar Jacobian selected and full observables, August 20](../../../07-reflections/jc2-rational-observable-nodes-and-pole-unit-frontier-codex-20260820.md)
  and [three cubics, August 15](../../../07-reflections/three-coordinate-cubics-one-discriminant-line-and-the-weighted-keller-monoid-codex-20260815.md):
  the output projection can deliberately forget the core count while
  retaining coefficients on a restricted chart. The two-axis example
  matches the three exposed coefficients with actual cores of count 9
  and 33. Extending its restricted projection to unrestricted addresses
  would forget an extra bit function and is not justified.
