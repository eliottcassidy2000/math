# Adaptive root switching: exact finite reachability

Start with the directed triangle on 0,1,2 with edges 0→1→2→0. At each step choose any existing root v and add a new vertex x with v→x and x→u for every other existing vertex u. Choices of root are unrestricted and can change at every step. The generated tournament is labeled by insertion order. A block of k transitive vertices attached to v as in `../gadgets/RESULT.md` is equivalent to k successive single-vertex insertions at root v, so this search also covers arbitrary block lengths and switches between blocks.

**Finite theorem.** Exactly the odd counts from 3 through 99 except 7 and 21 occur among triangle-seed outputs whose Hamiltonian-path count is at most 99. In particular, all odd counts 23 through 99 occur, but this does not establish an induction or any value beyond 99. `check.out` records, for each attained count, one sequence of zero-indexed roots; the integer labels of new vertices are assigned consecutively. The independent direct subset-and-last-vertex DP in `search.py` calculates the path counts, without using the gadget profile formula. All histories, including isomorphic duplicates, are retained. Replay `python3 search.py 99` and `python3 -O search.py 99` and compare with the matching frozen outputs. The algorithm checks strict growth using an explicit exception rather than assertions. The number of surviving histories at orders 4–10 is 3,12,60,321,378,117,0. Once the list is empty, no later outputs can exist under the cutoff, by strict monotonicity proved below.

**Why pruning is complete.** All generated tournaments remain strong: every old vertex reaches v within the old strong tournament, v→x, and x points to all old vertices other than v. For a strong tournament T with root v, let h=H(T), s be the number of paths starting at v, q=H(T−v), and F the path-pair count defined in the gadget theorem. Singleton insertion gives H(T')−H(T)=F−s. Every path starting at v restricts to a path on T−v, so s≤q. Since T is strong, v has an in-neighbor u; the singleton path A=(u) and any Hamiltonian path B on T−{v,u} form an additional admissible pair beyond those with A empty, showing F>q. Hence H(T')>H(T). Since H is integral, a branch whose count already exceeds the cutoff cannot later return below it, and the exhaustive rooted tree is finite. This proof does not require the false assertion q>s.

A second, structural restriction applies for every seed and every nonempty insertion history, irrespective of strongness: the last inserted vertex has exactly one in-neighbor, its chosen root. Thus a tournament with minimum in-degree at least 2 cannot itself be obtained this way, even with adaptive roots. This is an obstruction to reaching particular tournaments, not to reaching their path counts.

The missing 7 above has the following short direct proof. Every first insertion into the directed triangle is isomorphic and yields H=5. For the resulting adjacency rows 0101, 0010, 1000, 0110, the four rooted profiles (h,s,q,F) are (5,1,1,5), (5,1,3,9), (5,1,1,7), (5,2,3,6). The next insertion yields 9,13,11,9, respectively. Strict increase rules out 7 thereafter. The statement is limited to the triangle-seed construction and must not be confused with a new global nonexistence result for tournament path counts.

**Extension to 199.** The same exhaustive computation, run separately under normal and optimized Python, gives identical frozen outputs `check199.out` and `check199.opt.out`. It reaches every odd count from 23 through 199 and again misses only 7 and 21 among positive odds 3 through 199; all surviving histories are exhausted at order 11. Survivors by orders 4–11 are 3,12,60,360,1527,1308,417,0. Replay with `python3 search.py 199` (or `python3 -O search.py 199`). Independently, `python3 verify_witnesses.py check199.out` replays and checks all 97 printed witness histories using memoized recursive path counting rather than the enumeration DP; it verifies attainments but not completeness by itself.
