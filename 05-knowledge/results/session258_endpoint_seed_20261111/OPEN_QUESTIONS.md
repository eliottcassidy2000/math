# The next constructive obligations

All items below remain OPEN unless explicitly labelled otherwise.

1. **Strong-core odd-part surjectivity.** Construct, for each odd c, one strong S and selected O with W=H−1 and oddpart(U)=c. This is now the exact universal tail-seed problem; arbitrary singleton padding cannot change the odd part.
2. **Bound the first exponent.** Find a computable useful J(c) such that some q=c2^j, j≤J(c), passes the complete fixed-q core decision. A bound alone makes the candidate set finite, but the bound's existence statement must also be proved.
3. **Transport actual core moves.** Search for physical changes of (S,O) that preserve W=H−1 and give controlled transformations of oddpart(U). Carry the selected induced-capacity and endpoint-volume budgets together. A scalar numeration identity is not enough.
4. **A uniform backward-profile invariant.** Relate the27-coordinate positive suffix guards to the native two-register Zeckendorf target and its carry. Prove an invariant giving a successful legal predecessor, rather than merely a numerical predecessor.
5. **Pay the heads below each ray.** Universal tail seeds would only cover sufficiently high exponents on each line. Uniform low-exponent constructions are separately required for Chan–Pak, with actual total exceptions7,21.
6. **Interface changes after ready barriers.** The all-k99·2^k+23 and297·2^k+71 ready returns reach a barrier at1997 when k1. A nonzero-digit recursion must change its physical interface rather than assume an all-strong1-/2-ready return exists.
7. **Separate other ray mechanisms.** Doubling-vertex rays may begin below the first possible selected-set tail seed. Classify whether and how a doubling core can be converted to a tail core while controlling the exponent; the present absence results do not forbid it at higher multipliers.

The exact positive cut and strong-core classifications are completed results. The open items are constructive universal obligations, not missing checks of those classifications. Session258 deliberately uses inherited research at its stated scope and concentrates new verification on the newly claimed interfaces.
