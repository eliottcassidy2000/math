# Three trees cover the entire two-sided atom hull

The [proof](THREE_TREE_GOLD_COVER.md) gives a three-tree strict-Gold cover with uniform path margin greater than E/200 for all arbitrary-size seven-thin ambient posets with full root core Q=(0,0,0,6,0,19,2,18,86,151), roots (0,3). It strengthens the separately preserved five-tree theorem.

Only seven safe path inequalities and four weighted separation inequalities are needed; their largest coefficient is 2. A deterministic selection rule tests three margins computed from four comparison-event probabilities. The selected first question is (101/300,199/300)-balanced.

Normal and optimized standard-library exact controls agree: 37,055 guards over all 1,764 bounded chain models. A separate implementation reproduces the full atom count-table hash. This remains a fixed-core result, not a general seven-thin theorem.
