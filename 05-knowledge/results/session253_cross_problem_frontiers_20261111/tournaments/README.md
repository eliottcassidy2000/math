# Tournament lane deliverable

See [PROOF.md](PROOF.md) for five proved statements and the recovery/transfer ledger.

Main result: modulo 3, arbitrary tournament substitution uses only factor H and factor-order parity. A factor with 3|H is universally absorbing; a triangle quotient has zero germ exactly when all three factor parities agree. One singleton padding flips parity while keeping factor H unchanged.

Constructive result: C3[S=>T_r,1,1] has exactly H(S)+2^r Q_S(2) Hamiltonian paths. Seeds K1 and Q4 yield 1+2^(r+1) and 5+2^(r+5), jointly covering every residue modulo every 3^a. The construction is explicit and strong; bounded integer lift remains open.

General result: factorial path jets give finite substitution congruences modulo any prime power. Ordinal powers inside arbitrary fixed substitution contexts have uniform eventual period dividing the unit-group exponent, after exponent a modulo p^a.

Boundary: 5-divisibility is not absorbing. Q4 has H=5 but C3[Q4,1,1] has H=37. This is explained by the extra surviving half-grid coordinate.

Files: proof, standalone probe, identical ordinary/optimized transcripts, SHA256 hashes. No theorem IDs reserved and no Git changes made. No external novelty claim.
