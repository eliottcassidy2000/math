# Live portfolio and inheritance board

## Scope and posture

Anchor: Chan–Pak bounded integer coverage, via actual core/cut constructors.
Niche: Laurent carried rows, integral observers and p-adic jet modules.
Wildcard: Mahler-safe word entropy, path-cover substitution, and sparse
integer-support problems. Shift effort when a native problem gives a sharper
mechanism; do not force every useful result through Chan–Pak.

## Five live concepts

1. **Actual coloured interfaces.** Seven coefficients, nonnegative compiler,
   ordinal gluing. Predicate: integer target realization. Lost coordinate in
   bare H: endpoints and cuts. Closest mechanism: Session252 and the incoming
   positive compiler; hostile: equal-H9 cores repair different holes.
2. **Carried Laurent degeneration.** Inverse carry at a small-root collision.
   Predicate: response module and return noncancellation. Closest mechanism:
   September carried-factor and projective-jet notes. Investigate nilpotent
   Jordan type and Smith factors, not only determinant/content.
3. **Height-aware word languages.** Binary addresses and Mahler-safe words.
   Predicate: cheap exact output, not congruence coverage. Hostile: K1 already
   has universal modular support while missing genuine integers. Test height
   restoration against entropy loss.
4. **Factorial substitution jets.** Quotient paths decorated by block path
   covers. Predicate: exact Hamilton count modulo prime powers. Retain
   factorial valuations and block labels. Native opportunity: finite modular
   observer for huge non-P-recursive growth.
5. **Integral observer fibres.** Clustered confluent Vandermonde matrices.
   Predicate: full Smith partition rather than worst denominator. Recover
   prime-wall, Deuring and projective sidecars; seek first-layer generality.

## Exchanges and next gates

- Laurent ternary collision appears to retain Jordan type (2,1), precisely
  the square-zero algebra behind the tournament interface. Prove the module
  identification, then ask what actual realizability it does NOT transport.
- Mahler restrictions may provide linear height but destroy output density.
  Compute both sides before treating a safe language as a covering engine.
- Factorial valuation can make a huge substitution response finite modulo
  p^a, but a local observation still needs bounded integer lifting.
- Integral jet torsion can distinguish states with equal determinant/rank.
  Test the seven-coordinate tournament observer integrally.

Each final bridge must list source, target, map, preserved statement, loss,
necessary sidecar, and cheapest next test. New proof controls only; no large
inherited census replay. No priority claim or canon promotion without audit.
