The least-used sidecar is the set of **names still eligible for future use**,
which need not coincide with the vertices of small current indegree.

The new operation keeps exactly two named old vertices in slots0,1. Choose
either as root; add x with root->x and x->every other old vertex. Then discard
one of the three eligible names, possibly x. A discarded vertex remains in
the tournament but can never again be selected as a root. If an old slot is
discarded, x takes that slot. There are six commands `(root,discard)`, encoded
by `3*root+discard`, with discard2 meaning the newborn. Actual graphs and
the slot-to-vertex map are retained when decoding a witness.

Start from the directed triangle, retaining an oriented pair as slots0,1.
Triangle rotations identify all three such choices. The two slot names are
not quotiented during a construction. H is unchanged by this initial gauge.

This changes the temporal resource being bounded, rather than merely
increasing an indegree cap. A retained port can have arbitrarily large
indegree. Conversely, a low-indegree vertex can deliberately be forgotten.

## L1. Intrinsic future-live width

For a chronological triangle-seed root word `(r_3,...,r_(n-1))`, set

    L_t = {r_i : i>=t} intersect {0,...,t-1},  3<=t<n.
    width = max_t |L_t|, with width0 for the empty word.

**Theorem.** A triangle-seed adaptive descendant is generated by the two-port
language iff its root word has width at most2. This is an ordinary-class
invariant within the triangle-seed language.

Necessity holds because every old vertex used later must still be retained.
For sufficiency keep L_t plus unused fillers. The next required set satisfies
`L_(t+1) subset L_t union {t}` and has size at most2, so discarding one of the
three available names suffices. The current root belongs to L_t. Initial
triangle rotations normalize the retained pair. The previous
[unique ancestry theorem](../adaptive_metagraph_reformulation_20261103/ANCESTRY.md)
identifies root histories only by the initial triangle automorphism, which
preserves all these set cardinalities. Thus a different presentation cannot
silently lower the width.

The languages are incomparable with degree cap3. The history `(0,1,2)` has
width3 and root degrees1,2,3, so is a cap3 source outside this language. In
the other direction, retain0 and3 after the first root0 birth, repeatedly
use3 while discarding each newborn, then return to0. This has width at most2
but the final root0 indegree grows without bound. Thus the999 result below
is not an extension of the cap3 numerical claim.

## L2. Twenty-four positive coordinates and six exact matrices

Retain unordered spanning directed path covers, recording the paired start
and end of each component. An endpoint is slot0, slot1, or `*` for a forgotten
vertex. Equal endpoint signatures are grouped with their integer counts.
Discard signatures with two or more forgotten ends.

The discard is exact for future H: every future newborn dominates every
forgotten vertex. No future new edge can continue a path ending at a
forgotten vertex, so at most one such path can survive in a final Hamilton
path. A surviving cover has at most three components, because each other
component must end at one of the two distinct live ports. The paired
endpoints, rather than separate endpoint marginals, detect whether a new
join would close a cycle.

For a birth at slot r, choose zero or one old component ending at r to enter
x, and zero or one component whose start differs from r to leave x. Never
choose the same component on both sides. Merge the selected components
through x, or create its singleton component. Apply the specified forgetting
map to endpoints, and group identical output signatures with multiplicity.
This is a nonnegative integer linear map. Deleting x from an actual child
cover recovers exactly this choice, so the transfer is bijective before
grouping and counts every cover once. No port-arc or degree guess is needed:
all old incidence is already encoded in the cover weights.

Closing the literal triangle support under these six finite kernels gives
**24 signatures**. The full list, six sparse matrices, initial vector and
Hamilton observer are in [live_port.json](live_port.json). H is the sum of
the one-component coordinates. This is an explicit finite representation,
not a finite set of numerical states or a universal membership theorem.
The construction generalizes to any fixed number b of retained slots from
a seed with at least b vertices, with `b(b+1)` commands and at most b+1
surviving components.
