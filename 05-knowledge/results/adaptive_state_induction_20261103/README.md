## What the order-five obstruction requires the induction to retain

The [order-five hostile](../tournament_joint_parity_20261102/growth_obstruction.md)
has the same unmarked cover vector `(3,42,162,240,120)` in both sources,
but one source admits child H17,23,25,33 and the other admits29 instead.
Even the equal one-birth means27/2 lose the differing variances. Thus a
constructive attachment needs the incidence of endpoints in the **same
named cut**, with multiplicity; independent marginals are insufficient.

The new carrier keeps each component's paired start and end. A birth can
join an incoming and outgoing component, but may not use the same component
twice, which would form a cycle. Forgetting maps act only after this join.
This retains exactly the correlations needed for the declared two-port
future. Its seventeen observable coordinates are genuine continuation
counts, and a literal source program transports the names. For arbitrary
new cuts on discarded vertices, this restricted observer is not sufficient.

There is no contradiction with the new module-context classification.
Homogeneous outsiders cannot distinguish vertices inside the module; under
that restricted operation, the full unmarked cover profile is complete.
Arbitrary attachments can distinguish them. **The operation language fixes
the appropriate equivalence relation.**

## Reformulated constructive proof obligation

For each target p or7p in the required lanes, construct a reachable
seventeen-query vector with first coordinate equal to the target, together
with a six-command word and its port transport. The verified update
matrices make the transition algebra finite, but the set of actual query
vectors remains infinite. A proposed inverse must give all of the following:

1. A proved family of actual parent states, large enough to contain inverse
   parents outside the prime/7p lanes; finite seeds and precise guards.
2. A legal birth/discard choice and a strictly decreasing well-founded
   measure, including all boundary cases. Positive integral solutions of
   the query equations alone are not an actual-source certificate.
3. Coverage of the target residues **in the same source interface**, with
   the complete query vector and both names transported through every step.
4. If using native resets, an explicit selected-path program, its endpoint
   source, and a proof that it returns to the declared induction domain.
   The demonstrated excursions do not automatically preserve live width2.

The twelve-command envelope is valuable for observation and comparison,
but has infinitely many distinct positive carrier states already at H1.
It therefore loses the adaptive language's strict-H descent and finite
bounded saturation. The formal vector seven times the TT2 seed is positive
integral, has odd future outputs, and satisfies all linear identities, yet
cannot be an actual source because H7 is impossible. This retains the
actual-image guard in the strongest common observer.

Three next decisive tests are now precise: seek an invariant actual family
inside the two-live-port orbit; find a source-preserving return that changes
the valuation channel while remaining in that family; or extend the native
return excursions to a uniformly legal finite rule whose endpoint queries
are known. None is supplied merely by a recurrence, modular clock or finite
support check. The constrained targets and counterexamples here make these
tests smaller and more informative than another unstructured census.
