# Count-preserving resets need an operation and a source

**PROVED:** the low-count native obstruction, converse covariance of extension
support, and the exact homogeneous-context characterization below.
**FINITE-EXACT:** complete ordinary native carriers through order six, a
root-preserving H37 reset, closed same-H components of two specified seven-vertex
sources, and explicit two-native return repairs. The context lifts are all-order
consequences of the proved substitution law and exact finite base certificates.
No scalar-fibre connectivity, universal reset bank, or prime-lane closure is proved.

## 1. Inheritance and the research rounds

The anchor is to repair an attachment branch by changing its actual source
without changing its current Hamilton count. The niche is the distinction
between a native move and a homogeneous module replacement. The wildcard is a
family of contexts that detects exactly which replacements preserve all H counts.

## 2. A native level can have no moves at all

A native K_P keeps the arcs of its directed Hamilton word P and reverses all
other arcs. Re-marking only chooses a different legal P in the same tournament;
it changes neither its ordinary class nor any physical attachment response.

Search graphs below record support, not a probability kernel. For a specified
source representative, every directed Hamilton word carries unit weight;
the full outgoing mass is H. Ordinary frame incidence divides that path mass
by |Aut(T)|. The selected closed-component receipts retain these path
multiplicities and automorphism orders. Filtering to neutral moves does not
justify reusing the unfiltered normalization or a uniform class measure.

**Lemma.** Every native move from a nonstrong tournament of order n≥3 lands
in a strong tournament. Indeed, every Hamilton word traverses the ordered SCCs
in order. Its first vertex beats its last vertex in the source. That pair is
not a consecutive path pair, so K_P reverses it. The retained P plus its new
closing arc is a directed Hamilton cycle.

A strong n-vertex tournament has at least n Hamilton paths: cut a Hamilton
cycle at each vertex. Therefore:

> For n≥3 and h<n, the induced native graph on the ordinary H=h fibre has no edges,
> including no loops. Every source in that fibre is nonstrong.

This all-order obstruction is stronger than a failure of a particular search
heuristic. As a recovered explicit example, the H3 fibre consists of
1^a→C3→1^b with a+b=n−3, giving n−2 ordinary classes. The enumeration is
inherited from [the fixed-H species formula](../session153_gadgets_20261103/species/SPECIES_TROPICAL.md),
not new here. For n≥4 none of these classes has a neutral native edge.
Converse only pairs a with b. At n≥5 even adding converse does not connect
the whole H3 fibre. These statements concern **stepwise** H-preserving native
moves. A native excursion may leave the level and return to another source.

At order six there is also a strong obstruction: the H37 fibre has five
ordinary classes. In the script's minimum upper-triangle code, its neutral
components are

    {144},  {148,152,281,313}.

The isolated source is (32,17,3,7,13,30), and is self-converse. Thus adding
converse still does not connect this H37 fibre. The four-class component
contains the rooted hostile examined next.

## 4. What profile is sufficient for every homogeneous context?

Write c_k(T) for the number of **ordered** covers by k nonempty directed
paths. c_1=H and c_k=0 above |T|. A homogeneous context replaces one vertex
of a tournament quotient by T, with every outside vertex uniform on T.
Other quotient vertices may themselves carry arbitrary supplied blocks.

**Context congruence theorem.** For two nonempty tournaments T,U, the following
are equivalent:

1. c_k(T)=c_k(U) for every k.
2. Every homogeneous tournament context gives the same H when supplied T or U.
3. The test contexts C_r below give equal H for every r≥0.

For sources of order at most N, r=0,…,N−1 suffice in (3).

**Sufficiency, inherited run mechanism.** Split every global Hamilton word
into maximal runs inside the substituted blocks. The quotient run word and
the ordered internal path covers determine it uniquely. Thus its count is a
polynomial with nonnegative integer coefficients in the c_k of the blocks.
The same argument for an ordered global path cover, retaining cuts between
its paths, proves preservation of the entire global cover profile. This
recovers the existing substitution mechanism; equality of H alone is too weak.

**Necessity by a triangular test family.** C_r[T] has the old module T and
2r new singleton vertices in transitive order

    b1→a1→b2→a2→…→br→ar,

with T→b_i and a_i→T for every i. Put C_0[T]=T. A return from one T-run to
another must use at least a b and an a, so at most r+1 T-runs occur. Hence

    H(C_r[T]) = Σ_(k=1)^(r+1) w_(r,k)c_k(T).

The top coefficient is exactly r!. With r+1 T-runs, all2r outside vertices
lie in the r intervening gaps; every gap is b_i,a_j. The transitive order
requires i≤j. A perfect matching with all i≤j must be the identity, while
the r matched pairs can occur in any order. Thus w_(r,r+1)=r!>0. Induction
on r recovers each c_(r+1) from the context counts. This proves necessity.

The first coefficient rows are

    (1), (3,1), (9,10,2), (31,83,50,6), (117,684,908,336,24).

There is also an exact source-lattice guard. Put h_r=H(C_r[T]). Triangular
inversion gives c_3=(h_2−10h_1+21h_0)/2. Since ordering three nonempty paths
acts freely, c_3 is a multiple of 3!, and therefore

    h_2−10h_1+21h_0 ≡ 0 (mod12).

The actual A observations are (37,413,5441). Changing only the last entry
to5443 leaves three positive odd integers but violates this necessary guard.
This rejects an attempted query-state replacement; it is not a sufficient
realizability criterion or a new numerical spectrum exclusion.

For r≥1 these contexts are strong even when T is not: every vertex of T can
reach every other through one b_i,a_i, and every outside vertex communicates
through T. When sources already have equal H but differ in a higher cover
coordinate, their first separating test has r≥1 and is therefore strong.
This is a complete observer for **uniform substitution**; it is not a complete
observer for arbitrary nonuniform attachments or native adjacency.

For a concrete separating control, the isolated H37 class144 from §2 has
c_2=278, while A has c_2=302. Their strong C_1 wrappers therefore have
H=389 and413, respectively, despite equal input H. The extra coordinate
changes an actual future count, not merely a presentation of the same source.

### The H37 reset lifts at all orders

Every one of the five literal graphs in §3 has the identical profile

    (c1,…,c6)=(37,302,1044,1896,1800,720).

This is an exact finite identity, independently checkable by vertex words
and cut positions. The context theorem therefore lifts the entire reset to
any supplied homogeneous module context, preserving its H at every step.
All outside names remain fixed, and the physical name2 inside the module
remains fixed. In C_1,C_2,C_3 the five successive H values are respectively
413,5441,89789, giving strong examples at orders8,10,12.

The local operations now act only inside the six-vertex block. They are
**not** whole-tournament native edges. [THM-4804, module shattering](../../../01-canon/theorems/THM-4804-complement-lines-shatter-every-module-and-the-carousel-fibre-as-frobenius-orbits-of-a-normal-basis.md)
explicitly forbids retaining a proper nontrivial module across a whole-graph
native move. The operation type and clock must be recorded: four block-supported
native operations, no births, fixed order and fixed outside incidence.

Equal profiles do not preserve source mass. A and B are nonisomorphic rigid
strong tournaments. The canonical three-block compositions C3[A,A,A] and
C3[A,A,B] have equal H by the context theorem, but automorphism orders3 and1:
the first admits the outer cyclic rotations; the second does not. Their
ordinary frame masses H/Aut differ by a factor of three. No uniform class
weight or quotient transition probability follows from the reset.

### Recovered module-converse reset and its boundary

Reversing all internal arcs of a module preserves every c_k: reverse each
maximal module run in every covering path. This is an inherited special case
of the full-profile law. It commutes with any supplied ear cut that is uniform
on the module. In particular every adaptive root outside the module has the
same child count before and after reversal; any sequence avoiding roots in
the module preserves counts inductively. A root inside the module can change
its response because it breaks uniformity.

The complete order-six control bank verifies114 proper-module reversals and
2208 uniform cuts. It also gives a genuine nonisomorphic H3 pair with different
arbitrary-ear supports: source (4,1,2,7,15,31), module mask15, reset
(10,12,9,0,15,31). Ear mask39 after reset reaches45, unavailable from any
one-ear cut of the original source. The receipt retains the entire supports;
this is a source replacement, not an equality of arbitrary attachment kernels.

## 5. Closed neutral components do not repair the incoming H93/H95 sources

Use the exact incoming sources

    P93=(110,28,104,112,37,2,50),
    Q95=(110,92,104,48,37,66,24).

All paths of P93 lead to a different H, so its neutral native component is
one ordinary class. Q95 has two outgoing neutral path witnesses, both reaching
the same second ordinary class. That class has two neutral path witnesses
back. Its full neutral component therefore consists of exactly two classes.
The checker closes each component by checking **every** Hamilton word at
every encountered class, rather than stopping after a chosen depth.

Neither Q95 class has a one-ear hit285,287,289; P93 has none of279,281,283.
All three classes are module-prime: no proper nonsingleton module exists.
Thus arbitrary finite sequences of neutral native moves, re-markings and
proper module reversals cannot repair these one-ear failures.

Converse does not help. For every supplied ear cut S,

    ear(T,S)^op = ear(T^op,V\S),

on the same names. More generally converse bijects all k-new-vertex extensions
of T with all such extensions of T^op, preserving H and strongness. Native
moves transport under converse by reversing the named Hamilton word. Adding
converse to the reset language therefore only adds the reflected neutral
components, with identical attachment supports and no proper modules.
The same no-repair conclusion holds for the combined reset language.

This is a complete finite obstruction for these specified sources and these
specified reset generators. It does not exclude other H93/H95 representatives,
nonneutral excursions, or different source-replacement mechanisms.

## 6. Two-step endpoint returns cross that obstruction

A reset may preserve H only at its endpoints. The intermediate count is then
a required coordinate. Two literal native moves suffice for useful repairs:

|---|---|---|---|---|---:|---:|
| P93 | (0,2,5,1,3,6,4) | (6,4,3,0,2,5,1) | 93→111→93 | (102,20,104,35,45,2,58) | 33 | 283 |
| Q95 | (1,2,3,4,0,5,6) | (3,1,2,4,6,0,5) | 95→121→95 | (62,84,112,38,104,2,41) | 44 | 287 |

Each path is checked in its actual current source, with every old vertex name
unchanged. An ear mask means that the newborn beats precisely its set bits.
Literal eight-vertex permutation counts verify the final283 and287.

These results do not contradict the inherited at-most-three-birth exclusions:
the two native moves change old arcs. They show exactly which operation the
old-source barrier was forbidding. The reset itself changes no order; its
clock is two native steps, followed by one birth. Its endpoint H agrees with
the input, while its intermediate H need not be smaller.

The complete two-step search from P93 has58 distinct first-step ordinary
classes and seven returned H93 classes; three returned classes gain at least
one one-ear ternary branch. From Q95 the respective counts are74 and five;
three returned classes gain branches. No returned Q95 class gives289 by one
ear. These are complete **two-step endpoint** inventories from the named
sources, not full order-seven class censuses or all-word reachability claims.
Canonicalizing intermediate classes is safe for this unrooted endpoint/ear
question because all paths and all cuts are transported; §3 shows why the
same shortcut without a root coordinate would fail for a rooted question.
