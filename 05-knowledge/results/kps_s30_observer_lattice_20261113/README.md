## The two observers are almost complete together (THM-5155)

Each alone fails. The arc multiset cannot tell run slides and run-flanked core flips apart (THM-5154). The score
sequence cannot separate most classes.

Together they separate every merged class through order 8. At order 9 exactly six pairs remain. Each is
TT2 => S => TT1 against TT2 => S^op => TT1, where S is a rigid, non-self-converse strong 6-tournament whose score
sequence reads the same backwards:
- (1,2,2,3,3,4) four times;
- (2,2,2,3,3,3) once;
- (1,1,2,3,4,4) once.

Why these. Through order 9 the score sequence fixes the sizes of the strong components, so it sees how singletons
are distributed. A flip maps the core's internal scores s to |S| − 1 − s, which is invisible exactly when that
multiset is self-reversed. Each of the six pairs is also, up to global converse, a slide that the scores do not see.

The audit extended this to the non-strong order-10 classes: 62 coincidences, all of the same kind. It also found
other failure modes at higher order:
- order 13: reversing a two-core block A => B of equal-score strong 5-tournaments;
- order 15: two simultaneous flips.

HYP-9681 is therefore restated: every coincidence is generated by converse flips of modules, strong or not, each of
which preserves both observers.

## Selmer-refined spectrum (THM-5156)

The Monsky nullity nu(T) = dim ker(M^2 + M + I) over F_2 is taken with the diagonal of M chosen so rows sum to 0. Read
through Monsky's formula on the Legendre tournament, it is the BSD bridge already in the repository
(bsd_selmer_growth_20261013a.md §§2-3; integer32_twoedge_20261113 bridges B1): for a tournament on distinct primes ≡
3 mod 8, nu is the pure 2-Selmer dimension of y^2 = x^3 − N^2 x.

- nu is additive over ordinal joins. This is proved in bsd_component_recursion_20261013c and re-verified here on
  1,007 non-strong classes.
- So the nu = 0 tournaments are exactly the ordinal sums of strong nu = 0 ones, and the closure argument is exact in
  both directions. The chart class of THM-5152 is not closed under ordinal sums; this class is.
- With Busch's bound, every class of orders 1-9 decides the nu = 0 spectrum below 125.
