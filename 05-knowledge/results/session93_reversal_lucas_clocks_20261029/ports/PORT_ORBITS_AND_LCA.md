# Exact port information in the recursive reversal centralizer

**Status:** PROVED for the iterated ternary tournament family; exact finite controls below. These are consequences of its explicit wreath action, not a universal theorem for all tournaments or an external-priority claim.

## 1. The native action and its folded blocks

Let W_k be the tournament on ternary strings of length k, oriented by the first differing digit around0→1→2→0. Write A_k=Aut(W_k) and let alpha negate every digit. The inherited intrinsic-module proof gives

    A_k=A_(k-1)^3 ⋊ C3.

Let C_k=C_(A_k)(alpha). A centralizing automorphism fixes the three top-level blocks. Its action on block0 is in C_(k-1); its action on block1 is any g∈A_(k-1); and on block2 it is alpha g alpha. Consequently

    C_k ≅ C_(k-1) × A_(k-1) ≅ product_(j=0)^(k-1) A_j.

The companion [holonomy theorem](../holonomy/FULL_CENTRALIZER_GENERATION.md) proves that all of C_k is generated by based square-root triangle errors. Thus C_k-orbits describe exactly the port changes reachable by concatenating such marking loops. They do not describe black adjacency-changing moves.

A nonzero vertex has a first nonzero digit. If its suffix has length j and that digit is epsilon∈{1,2}, assign it the immutable tag(j,epsilon). Fold its suffix by leaving it unchanged for epsilon=1 and negating every digit for epsilon=2. The A_j factor then acts by the **same** ordinary action on both folded copies. Different j factors are independent. The all-zero vertex is a separate fixed point.

This is an exact coordinate map using the retained anti-involution. It is not a claim that arbitrary two marginal port orbits determine their alignment.

## 2. Complete tuple invariant from LCA depth and orientation

For an ordered tuple of strings in W_j, retain for every pair:

- the length of their longest common prefix, including j for equality;
- if distinct, the directed tournament arc between them.

**Theorem 1.** Two ordered tuples, allowing repeated vertices, lie in the same A_j-orbit iff all these pair data agree.

**Proof.** Automorphisms preserve prefix blocks and cyclic orientation, so necessity is immediate. For sufficiency, the longest-common-prefix data identify which marked vertices lie in each top child. A partial correspondence of the occupied children extends to a C3 rotation exactly when it preserves the cyclic arc on each pair. With one occupied child there is a unique rotation to its prescribed target; with two or three, pairwise directions enforce the same rotation. Repeat independently inside each occupied child. Unoccupied subtrees can use the identity action. This constructs the required automorphism. Equality data handle repeated ports. ∎

The construction is efficient when the source tuples are given: store one ternary rotation at each occupied prefix. There are at most rj prefix records for an r-port tuple. Comparing all pair data uses O(r²j) elementary digit operations; the compact transporter applies to one vertex in O(j) time. Expanding a full permutation costs at least its output size3^j. This is not a general tournament-isomorphism algorithm.

**Corollary for reversal ports.** For an ordered tuple in W_k under C_k, retain every individual tag(j,epsilon), including the zero-root tag, and within each j retain the preceding pair invariant on the **joint list of folded suffixes from both sides**. This is a complete C_k-orbit invariant and yields a compact transporter by the same algorithm, factor by factor.

The joint list matters. At k=2, ports(3,6) and(3,8) have the same individual C_2-orbits and the same original inter-block tournament arc. After folding, their suffixes are respectively(0,0) and(0,1), so no centralizer transporter matches the two pairs. The relative mirrored alignment is invisible to the original cross-block arc alone.

This supplies a concrete LCA-based repair of joint port data. LCA depths alone are insufficient: the cyclic direction at a branching node is a second required coordinate. Conversely, once these exact coordinates are supplied, no additional unidentified phase is needed for this family and action.

## 3. Exact one- and two-port orbit counts

For k>=0,

    |C_k \ V(W_k)| = 2k+1,
    |C_k \ (V(W_k)×V(W_k))| = 8k²+1.

For k>=1 the single-port orbits have sizes

    1, and two copies of3^j for each j=0,...,k-1.

Thus C_k fixes exactly three vertices when k>=1. All remaining named ports can be moved by suitable triangle loops, but only within their stated orbits.

**Proof.** Each folded A_j action is transitive, giving two tag-orbits per j plus the root. Ordered pair orbits for A_j are the diagonal and two cyclic directions at each of j possible first-difference levels, hence2j+1. Start with one class for each ordered pair of individual C_k-tags, giving(2k+1)². For the four ordered side choices within each common j, replace that one class by2j+1. The increment is8j. Summing gives(2k+1)²+8 sum_(j=0)^(k-1)j=8k²+1. ∎

Repeated ports are included. The number of distinct ordered-port orbits is therefore8k²−2k. These counts are not blue/black line counts or Hamilton-path counts; coincidences at one small order do not transfer their meanings.

## 4. Minimum named anchors needed to kill every triangle ambiguity

A base is a set of named vertices with trivial pointwise stabilizer. For k>=1,

    minimum base size of C_k = (3^(k-1)−1)/2.

At k=0 it is0. A named fixed root contributes nothing to this base bound.

**Proof.** In A_j, each of the3^(j-1) bottom-level triples has an independent cyclic rotation. A base must contain a vertex in each such triple. Conversely one vertex in each triple kills every bottom rotation and every higher rotation: each subtree has a retained descendant, so rotating its children would move a retained named vertex. Thus the minimum for A_j is3^(j-1) for j>=1.

For the centralizer factor A_j on two mirrored copies, a base must meet each paired bottom-triple support, but a point on either side suffices. Different factors have disjoint supports, so their base costs add. Summing j=1,...,k-1 gives the formula. An explicit optimal base takes, on side1 of each j block, all suffixes of length j ending in0. ∎

At order27, the triangle group has order243 and three minimal group generators, yet needs four named port anchors for a pointwise base. These are different resources: describing group generators, specifying a group element, and choosing enough fixed ports have different information costs. The generator theorem gives k(k−1)/2; this theorem gives the exact named-anchor cost.

## 5. Scope and reproduction

The tuple invariant and base bound use the full recursive tournament structure and a specified anti-involution. They do not make arbitrary LCA summaries complete, nor restore a forgotten alignment for an unrelated module grammar. In the blue quotient, the companion metagraph note proves that centralizer loops disappear on unmarked path presentations, while joint path-and-port observations can still detect relative positions.

`check_ports.py` uses no producer imports. It enumerates the literal groups through C_3 (order243), compares tuple invariants with their full orbits, verifies the port counts and optimal base, and checks compact transporters on larger recursive tournaments without enumerating their groups. All arithmetic and permutation tests are exact; normal and optimized runs must agree.
