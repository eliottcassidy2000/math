## Regular five

1. A nonidentity element of the actual internal C5 is a five-cycle. If it
   fixes every individual block row, those rows are constant; constant
   row degrees make the entire block uniform. The column version is the
   same. Thus a nonuniform equitable block has trivial one-sided kernels,
   even when some literal rows or columns repeat.
2. The two-sided rotation stabilizer has injective projections into C5,
   hence is trivial or a line. This proves the singleton or affine-five
   compatibility types. It uses the actual automorphism group, not all S5.
3. Connected functional propagation embeds the global automorphism group
   into root C5, giving orders1 or5. A single actual owner kills the latter
   because its action is free. The root's choice is shared through all
   attachments; no independent edge chart is allowed.
4. Equitable tournament cells have odd size. The only proper nondiscrete
   five-partition is3+1+1, whose singleton would have degree0,1,3,or4,
   contradicting internal regular degree2. Hence individualization really
   gives ordinary refinement, not merely a trivial stabilizer.
5. Discreteness propagates: an equitable nonuniform block must distinguish
   some target columns once source owners are singleton colours. A proper
   stable restriction on regular five is discrete by the previous item.

The report correctly separates zero-owner rigidity of a coupled system
from zero-owner success of ordinary equitable refinement, and preserves

## Regular seven

   swaps the endpoints of some arc. On seven points the possible nonidentity
   cycle types are7,5+1+1,3+3+1,3+1+1+1+1. The latter two excluded cases

   degree3 rules them out. This leaves7 and1+3+3.
