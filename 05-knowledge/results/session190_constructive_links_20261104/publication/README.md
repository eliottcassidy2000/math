These are frozen records of specific package snapshots and immutable Git commits. Their embedded package hashes and commit IDs identify precisely which snapshot they verify. Original prepublication labels such as REMOTE_PENDING are historical, not statements about the current branch; the later exact remote-readback records supply publication evidence.

Its original operational reproduction scripts preserve their staging paths and are historical audit artifacts; they are not the current repository's mathematical replay entry points. All publications use non-force expected-head updates. Remote byte comparisons include exact original or compressed-object bytes and Git blob hashes.
