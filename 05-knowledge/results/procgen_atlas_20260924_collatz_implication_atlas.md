## 0. The answer in brief

The owner asked for connections between Collatz's parts and famous problems "so that one can be shown to prove the other". Five kinds of arrows exist.

1. **Equivalence with a famous-type problem (new, Theorem M′).**
   * Take a *supercritical adjacent block pair* `B, B'`: length `L`, weight `a`, `3^a > 2^(L+1)`, and `R_B' = R_B + 1`.
   * Then no-divergence on `{B, B'}^N` is **equivalent** to `Z(3^a/2^L, [R_B, R_B+1]/(3^a - 2^L))`: no `xi > 0` has all of `xi (3^a/2^L)^j` in that residue interval.
   * This is a Mahler Z-number problem of exactly the type studied by Mahler, Flatto–Lagarias–Pollington, Bugeaud, Dubickas and Akiyama–Frougny–Sakarovitch.
   * Consequently **Collatz ⟹ T1 ⟹ these Mahler-type theorems**. This is the only "Collatz ⟹ famous-type statement" arrow found, and **PC ⟹ the same**.
   * For general constant-weight classes only the implication `Z(3^a/2^L, I_A) ⟹ T1 on A^N` holds (Theorem M). Mahler's own `3/2` problem sits at the excluded boundary `a = L`.
2. **Famous conjecture ⟹ a Collatz piece (CONDITIONAL).**
   * **Lang–Waldschmidt ⟹** the least nontrivial cycle length grows like `N^(1/2 - eps)` (Prop. LW). The computed record tracks `N^(1/2)`.
   * **abc ⟹** slices of Rozier's LBH (Rozier 2025; Prop. R2), and **LBH ⟹ Collatz** (Rozier 2017). abc cannot reach LBH itself, because a Collatz word carries unboundedly many carry terms.
   * **U(1/3) ⟹ HYP-9127** (in-house).
3. **Proved theorems ⟹ Collatz pieces.**
   * **Baker ⟹** bounded-complexity NC: no `m`-cycles for `m <= 91` (Simons–de Weger; Hercher).
   * **Catalan/Gersonides ⟹** the unit-gap clocks carry only the known small cycles, for both `T+-` and Collatz's permutation.
   * **Doob ⟹** Terras's density theorem.
4. **Inside the family.**
   * `PC ⟺ PC3K ⟹ T1` (Bernstein–Lagarias);
   * `PC ⟹ C2 ⟹ HYP-9127`; `PC ⟹ SP ⟹ T1 on A^N`;
   * `CST ⟹ NC`; `CST & T1 ⟹ Collatz`;
   * `Collatz ⟺ NC & T1`; `Collatz ⟺ G_C` transitive (Kohl 2017);
   * `Collatz ⟹ Q1`; `HYP-9126 ⟹ X_min ⟹ Q2`.
5. **Real but misdirected equivalences, and barriers.**
   * Every `Pi^0_1` famous problem (Goldbach, Legendre, RH, graceful tree, lonely runner) and the `Pi^0_2` twin-prime conjecture is equivalent to a statement about *some other* explicit generalized Collatz map (Conway; Kurtz–Simon). PRIMEGAME is checked here on 15 primes.

**The three coordinator nodes** (§§3.7, 3.8, 5):
* **Collatz's 1932 permutation.**
  * Exact relations: `T(n) = U(2n+1)`, and the shared gate with signed carries.

## 3. New results (PROVED here)

### 3.1 Theorems M and M′: Collatz no-divergence on block classes versus generalized Mahler problems

**Setting.** A *block* is a binary word `B` of length `L` with `a` ones (parity letters, `B[0]` first). On its cylinder, which is one class mod `2^L`,
`T^L(x) = (3^a x + R_B)/2^L`, where `R_() = 0` and `R_(ze) = m_e R_z + e 2^|z|` (`m_0 = 1`, `m_1 = 3`).
The cylinder of `B` is exactly the class `x = -R_B 3^(-a) mod 2^L`: on the cylinder `2^L | 3^a x + R_B`, and both sets are single classes mod `2^L` (B1: 6,138 exact checks).

Fix `1 <= a <= L-1` with `p = 3^a > q = 2^L`, and a set `A` of at least two such blocks. Put:
* `alpha = p/q`, `rho = q/p`;
* `I_A = [min_A R_B, max_A R_B]/(p - q)`;
* `Z(alpha, I)`: *no `xi > 0` has `xi alpha^j in Z + I` for all `j >= 0`*.

**Theorem M.**
* If some positive integer has a T-parity vector `u c` with `c in A^N`, then some `xi > 0` has `xi alpha^j in Z + I_A` for all `j`.
* Hence `Z(alpha, I_A)` implies that no positive integer has a parity vector eventually in `A^N`.

*Proof.*
1. `x = T^|u|(x_0)` has word `c`. Let `x_j = T^(jL)(x)`, so that `x_(j+1) = (p x_j + R_(c_j))/q`.
2. Put `xi = x + (1/p) sum_i R_(c_i) rho^i` and `t_j = (1/p) sum_(i>=0) R_(c_(j+i)) rho^i`.
3. Since `rho/q = 1/p`, `alpha t_j = R_(c_j)/q + t_(j+1)`. Hence `alpha(x_j + t_j) - t_(j+1) = x_(j+1)`, and by induction `xi alpha^j = x_j + t_j`.
4. `t_j in [R_min, R_max]/(p(1-rho)) = I_A`. ∎

**Theorem M′ (exact equivalence).** Suppose `A = {B, B'}` with `R_B' = R_B + 1` and `p > 2q`, and put `I = [R_B, R_B + 1]/(p - q)`. Then *some positive integer has a T-parity vector eventually in `{B, B'}^N`* **iff** *some `xi > 0` has `xi alpha^j in Z + I` for all `j >= 0`*.

*Proof of ⟸.*
1. Write `xi alpha^j = x_j + t_j` with `x_j in Z` and `t_j in I`. Then `e_j := q x_(j+1) - p x_j = p t_j - q t_(j+1)` is an integer.
2. It lies in `[R_B - q/(p-q), R_B + 1 + q/(p-q)]`. Since `q/(p-q) < 1`, the only integers there are `R_B` and `R_B + 1`.
3. So `x_(j+1) = (p x_j + R_(c_j))/q` with `c_j in {B, B'}`. By the cylinder fact, `x_j` lies in the cylinder of `c_j` and `T^L(x_j) = x_(j+1)`.
4. `x_j -> infinity`, so some `x_(j0)` is a positive integer with word in `{B, B'}^N`. ∎

*Checks.*
* The digit-forcing interval was checked for every instance below.
* The finite-horizon version was checked exactly for `(10, 7)` over all `x_0 <= 2^22`. For `d = 1, 2, 3`, the set of integer parts of `xi` that satisfy the confinement for `j <= d` (computed with exact rationals) equals the set of `x_0` whose word begins with `d` blocks from `{B, B'}` (computed by T-iteration): `8192 = 8192`, the same 16 integers, and `0 = 0` (B8).

**Instances.**
* Adjacent pairs with `3^a > 2^(L+1)`, for `L <= 20` (B8), in the form `(L, a)`: `alpha`, number of pairs, first pair:
  * `(10, 7)`: `2187/1024`, 4 pairs; `0111101110` (`R = 4726`), `1101100111` (`4727`). Here `I = [4726, 4727]/1163`.
  * `(16, 11)`: `177147/65536`, 5 pairs; `0111011111100110`, `1101111000111011`.
  * `(19, 13)`: `1594323/524288`, 1 pair.
  * `(20, 14)`: `4782969/1048576`, 8 pairs; `11101010111111110010`, `01111111011110110001`.
* General instances of Theorem M, with `|I_A| < 1` and `alpha|I_A| < 1` (B2):
  * `(4,3)` with `{1110, 1101}`: `alpha = 27/16`, `I = [19/11, 23/11]`;
  * `(5,4)` with `{11110, 11101}`;
  * `(7,5)` with `{1011011, 0111110}`;
  * the `Y3` blocks at `(10,9)`;
  * and every other supercritical `(L, a)` with `L <= 12` except the vacuous `(3,2)`.
* An exact survivor search for `Z(alpha, I_A)` over integer parts `<= 20000` finds no survivor beyond depth 23, 13, 2 and 7 respectively (B4).

**Where the proved Mahler-type results stop (Lemma M2 and literature).**
* `R_B != R_B'`, since distinct blocks have distinct cylinders. So `|I_A| >= 1/(p-q) > 1/p`.
* The proved exclusions all need length at most `1/p`:
  * Flatto–Lagarias–Pollington: spread `>= 1/p` [R via Bugeaud 2004 and AFS];
  * Dubickas 2009: the closed `[s, s+1/p]` for `q < p < q^2` [R];
  * Bugeaud 2004 Thm 1: `[s, s+1/p]` for almost every `s` [P].
* Theorem M′'s intervals have length `(alpha/(alpha-1))/p`: `1.88/p`, `1.59/p`, `1.49/p`, `1.28/p` for `L = 10, 16, 19, 20`.
* For comparison, at `3/2` only special positions are known beyond `1/p`: Dubickas's symmetric `||x(3/2)^n|| < 0.238` and `[0.14035, 0.52306]` [R].
* The mechanism: at Theorem M′'s length the confinement is *equivalent* to a free choice between two digits at every step, i.e. to Collatz-type 2-adic divisibility. Any exclusion at that length would therefore be a proof of a HARD slice of T1. The proved exclusions live where the admissible digit sequences are too constrained to carry that freedom.

**Existence results on the other side (CITED).**
* Tijdeman and Flatto: for `p > q^2`, infinitely many `xi` have `{xi (p/q)^n} in [0, 1/q)` [R].
* Akiyama–Frougny–Sakarovitch 2008, Theorem 3 [P]: for `p >= 2q - 1`, a union `Y_(p/q)` of `q` intervals of length `1/p` admits countably infinitely many `xi`. For `3/2` this is `[0, 1/3) ∪ [2/3, 1)`, Corollary 4.
* In the heuristic count, `alpha * |target| = 1` is the existence threshold (AFS's `Y` has exactly `alpha|Y| = 1`). Mahler's `3/2` problem has `3/4`. Theorem M′'s instances have `alpha|I| = alpha/(q(alpha - 1)) < 0.002`. They are single short intervals, and AFS's solutions do not supply them: those would need all digits inside the few cells of `Y` lying in `I`.

**Scope.**
* On constant-weight classes the jitter of the hard-class note's Proposition M vanishes at block times, so its coupled Z-number problem becomes a *classical* fixed-ratio one. Theorem M is that specialisation; Theorem M′ shows the decoupled relaxation loses nothing for adjacent pairs.
* `A^N` has density `a/L > log_3 2`, discrepancy `<= a` and entropy `log_2|A|/L > 0`. These are HARD-class slices of T1, untouched by capacity or repetition arguments.
* So a proof of any `Z(3^a/2^L, I)` instance would settle a HARD slice. Conversely, a divergent orbit on such a class would disprove a Mahler-type conjecture.

### 3.2 Proposition SP: the swap principle

For `1 <= a <= L-1` put `rho = 2^L/3^a` (`|rho|_2 = 2^(-L)`) and `Theta_S(rho) = sum_(s in S) rho^s in Z_2`. The map `S -> Theta_S(rho)` is injective.

**Proposition SP.**
* (a) **PC ⟹** `Theta_S(rho) notin Q` for every non-eventually-periodic `S` and every such `(L, a)`.
* (b) If `3^a < 2^L`, this holds unconditionally.
* (c) The same statement at Mahler's base `2/3` is **FALSE**.
* (d) At supercritical `(L, a)` it holds for Sturmian, quadratic and square `S`, by the in-house Theorems D (with Bugeaud–Kim), Q and Y (not re-audited here). Cubes at `(10,9)` are HYP-9127.

*Proof.*
* (a) Take distinct blocks `B, B'` of weight `a`. Iterating `x = (2^L T^L(x) - R_C)/3^a` gives `Phi_T(Y_S) = -(1/3^a)[R_B/(1-rho) + (R_B' - R_B) Theta_S(rho)]`. This was checked independently against Bernstein's formula modulo `2^3000` on 15 random cases (B7). `Y_S` is eventually periodic iff `S` is.
* (b) The word of `Phi_T(Y_S) != 0` has density `a/L < log_3 2`, which contradicts Monks–Yazinski Thm 2.7(b) [P].
* (c) Mahler's map satisfies `x = -(1/3) sum_(n in D) (2/3)^n`. For the (strictly increasing) orbit of `1`, `D` is not eventually periodic, yet `Theta_D(2/3) = -3`; checked modulo `2^4000` (B5), and `= -3g` in general (THM-2228). ∎

### 3.3 Why Mahler's own problem does not transfer: two-place orthogonality

The same Bernstein series has a 2-adic value and, in supercritical cases, a real value.
* For **Mahler's map** every positive integer has a 2-adic M-word, so the 2-adic side is free. A Z-number is exactly the real tail condition `f_n = (1/3) sum_j r_(n+j) (2/3)^j < 1/2` (THM-2228). The `.out` (B6) checks `{xi(3/2)^n} = f_n` exactly on 12 orbits.
* On a **Collatz block class** the real tails lie in `I_A` automatically, and the difficulty is 2-adic integrality.
* Theorem M′ shows that when the target interval is exactly the hull of a two-digit tail set, the two places *coincide*: the real confinement forces the 2-adic digits. Mahler's interval `[0, 1/2)` is a proper part of the tail hull `[0, 1]` of its digits `{0, 1}`, so there the real condition is a genuine extra constraint.
* Both problems are thus "two free digits plus one more condition", but the extra conditions sit at different places. That is why neither implies the other, and why `SP(2/3)` fails.

### 3.4 abc: the gate route is dead; free cofactors are alive

**Gate (PROVED comparison, `.out` C4).**
* abc (Waldschmidt Conj. 2.1 [P]) on `3^L + D = 2^K` gives only `D >= 2^(K/(1+eps))/C`. This is exponentially weaker than:
  * Rhin's explicit `|u_0 + u_1 log 2 + u_2 log 3| >= H^(-13.3)` [R, via Simons–de Weger Lemma 12], i.e. `D >= c 2^K K^(-13.3)`;
  * the truth at record clocks, about `2^K/K` (`log_2 D - K = -6.5, -15.7, ..., -49.4` for `K = 65, ..., 6.8*10^14`).
* Cycle bounds of the form "gate bound + product identity + verification" are monotone in the gate bound. So **abc adds nothing to Baker for cycles.**
* abc beats only Ellison's `2^K e^(-K/10)` (Thm 3 [P]), and only for `eps < 0.168`.
* Baker's explicit abc (Conj. 4, Publ. Math. Debrecen 65 (2004) [P]) gives `D >= (5/36) 2^K omega!/(K ln 2 + ln 6)^omega`. That is polynomial only when `omega(D)` is small.

**Proposition R2 (new).** Assume abc. For every `eps in (0, 1/2]` there is `c_eps > 0` such that every `n` with T-parity prefix `1^k 0^l` satisfies `n >= c_eps 2^(k + (1-eps) l - eps k log_2 3)`.

*Proof.*
1. The prefix means `n + 1 = 2^k A` with `A` odd and `3^k A - 1 = 2^l B`.
2. Apply abc to the coprime triple `(1, 2^l B, 3^k A)`, whose radical is at most `6AB`, together with `B < 3^k A/2^l`. This gives `2^(l(1+eps)) < kappa 6^(1+eps) A^(1+2eps) 3^(k eps)`. ∎

Remarks:
* Rozier's Theorem 2.1 [P] is the prefix with one even term.
* Unconditionally `A_min = 3^(-k) mod 2^l` can be `1` (when `2^(l-2) | k`). The data show `min_(k <= 2l) log_2 A_min / l` between 0.51 and 0.89 for `l <= 48` (C5).
* The prefixes produce abc-hits, e.g. `1 + 2^12 5^3 = 3^5 7^2 43` (quality 1.443, `n = 67423`).
* On two-block prefixes abc gives *more* than LBH, which predicts only `2^((1 - H(k/j)) j)`. abc cannot give LBH itself (Rozier 2025 §6 [P]; the n-conjecture's exponent `2n-5` grows).

### 3.5 Proposition LW and the cycle-length record

A nontrivial cycle with `L` odd terms, `K` steps and all elements `>= N` has `K/L in (alpha, alpha + log_2(1 + 1/(3N)))`, `alpha = log_2 3` (Eliahou's argument; Hercher's "previous methods").

**Proposition LW.**
* (a) If `|alpha - p/q| >= c q^(-mu)` for all `q`, then `L > (3 c N ln 2)^(1/mu)`.
* (b) Lang–Waldschmidt (Waldschmidt Conj. 2.5 [P]) with `m = 2`, `(a_1, a_2) = (2, 3)` gives `mu = 2 + 2 eps`. So **LW ⟹ `L_min(N) >= c_eps N^(1/(2+2eps))`**.
* (c) Unconditionally, Lagarias 2009 Lemma 2.2 (from Rhin: `|log_3 2 - p/q| >= q^(-14.3)/1200`) yields only `K > 21.4` at `N = 2^71` and `K > 87` at `2^100` (C3). ∎

**Computation** (C2; the continued fraction was checked against PARI to 60 terms).
* The crude bound reproduces Eliahou's `K = 17,087,915` at `N = 2^40`.
* It gives the threshold `N* = 4.3585*10^21 = 3780.4 * 2^60` for excluding `L = 72,057,431,991`. This is exactly Hercher's Remark 28 value `3781 * 2^60`.
* Hercher lowers the threshold to `2836*2^60` (Thm 27) and to `1536*2^60 = 3*2^69` (Cor. 29, which states more than `1.375*10^11` odd terms) [P]. So with Barina's `2^71`, **every nontrivial cycle has at least 137,528,045,312 odd terms and 217,976,794,617 T-steps** (CITED; the exact least values `q_23`, `p_23` are read off the continued fraction here, and the T-step value matches Wikipedia [R]).
* The next jump, to `L >= 890,638,885,193`, needs `N >= 3.83*10^22` even with Theorem 27's factor `3/4` (derived here). That is 16 times `2^71`.
* `L_min(N)/sqrt(N)` stays in `[0.37, 10.3]` for `N = 2^40..2^100`, as LW predicts.

### 3.6 Proposition CST

* (i) **CST ⟹ NC** (Lagarias 1985 §2.3 [P]).
* (ii) **T1 ⟹ TAU.** If `tau(n) = infinity`, then `T^j(n) >= (3^(a_j)/2^j) n >= n` for all `j`. A positive cycle forces `3^(a_j)/2^j -> 0`, so the orbit is not eventually periodic, hence it diverges.
* (iii) **CST ∧ TAU ⟹ Collatz** (`sigma = tau < infinity`, then strong induction). Hence `CST ∧ T1 ⟹ Collatz`. Also `Collatz ⟹ TAU`. ∎

CST is `Pi^0_1` and verified to `2.8*10^19` (Rozier–Terracol Cor. 5.4 [P]; 0 mismatches to `2*10^6` here, C7). So Collatz reduces to a finitely falsifiable statement plus T1. Collatz is not known to imply CST.

### 3.7 Collatz's 1932 permutation (coordinator node 1)

**Statement (CITED).**
* `g(3m) = 2m`, `g(3m+1) = 4m+1`, `g(3m+2) = 4m+3`, from Collatz's notebook of 1 July 1932. The question is "whether or not the cycle ... containing 8 is finite" (Lagarias 1985, Introduction [P]).
* The overview (arXiv 2111.02635 p. 3 [P]) writes the inverse `U(2n) = 3n`, `U(4n+1) = 3n+1`, `U(4n+3) = 3n+2`. It asks whether the iterates of 8 form an infinite set, raised by Klamkin in 1963, "unsolved". Its (C4) records that the permutation "was long ago conjectured to have finitely many cycles".
* Known cycles: `{0}, {+-1}, +-(2 3), +-(4 5 7 9 6), +-(44 59 79 105 70 93 62 83 111 74 99 66)` [P: Kohl manual; Matthews].
* Shanks 1965 [R]: the orbit of 8 exceeds `10^10`, and the cycle lengths `1, 2, 5, 12` are convergent denominators of `log_2 3`.
* Atkin 1966 [R]: no other cycle of period `< 200`.
* Keller [P via Kohl]: finitely many cycles of each length.
* Simons 2022 (arXiv 2205.10582 [P]): finitely many `m`-cycles via Baker/Rhin; none but the known ones for `m <= 2`; for `m = 3..5`, a further cycle needs all elements `>= 10^6`.

**Identities (PROVED; `|n| <= 10^6`, `.out` P1).**
* `g` is an odd permutation of `Z`.
* `U(m) = 3m/2` for even `m` and `round(3m/4)` for odd `m`. Equivalently `U = W` on evens and `floor(W/2)` on odds, with Mahler's `W(m) = ceil(3m/2)`.
* On odd `k`, `U(k) = (3k+s)/4` with the unique `s = +-1` making `4 | 3k+s`: this is Althöfer's one-player descending 3n±1 move. `U = T^2` on `1 mod 4` and `T_-^2` on `3 mod 4`.
* **`g(T(n)) = 2n+1`, i.e. `T(n) = U(2n+1)`, for every odd `n`.**
* `g(m) = 2 T_+^(-1)(m) + 1` for `m = 2 mod 3` and `2 T_-^(-1)(m) - 1` for `m = 1 mod 3`. So `g` = "the sheet-chosen odd predecessor, then `x -> 2x +- 1`". The owner's `(4A-1)/3` is its `1 mod 3` branch, and `T^3(4m+1) = T(m)` (odd `m`) is the "4x+1 recursion".

**Proposition G (shared gate; PROVED).**
* A `g`-step is `x -> (cx + d)/3` with `(c, d) = (2,0), (4,-1), (4,1)`. So a cycle point satisfies `n (3^k - 2^K) = D_w` (`K = k + #nonzero letters`) with a **signed** carry `D_w`, and `3^k/2^K = prod (1 + d_i/(4 n_i))`. A 3x+1 cycle point satisfies `n (2^K - 3^L) = B(w) > 0`.
* The four positive `g`-cycles sit on the clocks `2/1, 3/2, 8/5, 19/12`, with gates `-1, 1, -13, 7153` (P6). The signed `3x+-1` cycles sit on `1/1, 2/1, 3/2, 11/7`.
* The Catalan unit gaps are shared. The gates `13` and `7153`, which no `3x+-1` carry cancels (all 35 words on `8/5` have `q = 13`; the minimum on `19/12` is `q = 23`), are cancelled by `g`'s signed carries. The gate `-13` is Pillai's exceptional value `3 - 2^4 = 3^5 - 2^8` (C6; Bennett's list [P]).
* The convergent pattern is Shanks's observation, and the finiteness per `m` is Simons's theorem. New here: the signed-carry comparison, the census (every positive cycle with minimum `<= 10^6` and maximum `<= 10^24` is one of the four; 49,957 other orbits exceed `10^24` both ways, P3), and the Eliahou transfer (a cycle with all elements `> 10^6` has length `>= 665`).

**Typing (PROVED / FINITE-EXACT).**
* `g` is a full-branch expanding map of `Z_3`, and `U` of `Z_2` (branch measures `1/2, 1/4, 1/4`). Both are Haar-preserving (Matthews's Thm 6.2 [P] covers `g`).
* The drifts are positive both ways. The Haar probability that `g`'s log-walk ever descends is `0.763`, so no Terras theorem holds for `g` (P2).
* The Matthews–Watts conjecture [P] (product `32 > 27`) predicts almost all orbits divergent and finitely many cycles.
* The orbit of 8, followed `10^5` steps each way, never returns and grows at the predicted rates (P4).
* So "orbit of 8 infinite" is DRIFT-reversed, sheet-mixing (the sign is chosen by `m mod 3`) and `Pi^0_1`.
* Lehtonen 2008 [R] builds a variant permutation for which finite-cycle membership is undecidable.
* No implication with T1 or NC is known. Proposition G is a shared-structure relation.

### 3.8 Fairness and deterministic martingales (coordinator node 3)

**Pair sums (PROVED, F1).**
* A consecutive pairing is sum-preserving for `f_(q,r)` (`n/2` on evens, `(qn+r)/2` on odds) iff `(q,r) = (3,1)` with `{2i-1, 2i}` or `(3,-1)` with `{2i, 2i+1}`. Indeed `f(2i-1) + f(2i) = (q+1)i + (r-q)/2`.
* On the positive integers, any sum-preserving matching pairs all but finitely many evens `2i = (q-2)n + r` with odd `n`, which forces `q = 3`, and exactness forces `r = 1`.
* On `Z` degenerate reflection matchings exist (e.g. for `5x+3`).

**Martingale.**
* Under Haar measure the parity bits are iid fair (Lagarias 1985 Thm K [P]). Hence `M_j = 3^(a_j)/2^j` is a martingale, exactly because the mean forward ratio is `(3/2 + 1/2)/2 = 1`.
* The Lundberg exponent is `theta = 1` exactly, and the drift `log(sqrt3/2)` is the AM–GM gap (F2).
* Kontorovich–Lagarias use this random-product model but never the words "martingale" or "fair" [P]. The only published martingale treatment found is Applegate–Lagarias 1995 on leaf counts [R].

**Consequences (PROVED).**
* **Doob ⟹ Terras.** `M_j -> 0` a.s., since the log-steps are at least `log(3/2)`. The Haar mass of `{tau > k}` is `2.4*10^-4` at `k = 100` and `3.1*10^-6` at `k = 200` (F4).
* **Deterministic Doob.** `d{n : max_(j<=k) T^j(n) >= lam n} = P_k(lam) <= 1/lam` for every `k`.
  * The counts on `[2^40, 2^40 + 2^20)` equal `2^20 P_20(lam)` exactly for `lam = 2, 4, 8` (F5).
  * `lam P_inf(lam)` lies in `[0.81, 0.86]` for `lam = 2..10^6`, a Pareto(1) tail by Cramér–Lundberg with `theta = 1` (standard [R]).
* **Duality.** Kohl's image density (JSC 2008 Remark 1.2 [P]) is the Haar mean of `c/|a|`, which equals 1 for every rcwa permutation. By Jensen every permutation has log-drift `>= 0`, with equality only for constant ratio.
  * `T` is the mirror case: mean forward ratio 1, log-drift `< 0`.
  * Checked: `g` and `U` have image density 1 and drifts `+0.0566`, `+0.0589`; `5x+1` has mean forward ratio `3/2` (F2).
* Pair-sum exactness holds for one step only: `sum_(n<=X) T^k(n) - sum n = 0, X/2, 5X/4, 13X/4, ...` (F6).
* All of these are density statements, hence DEFECT-blind. No famous theorem about "deterministic martingales" reaches individual orbits.

## 5. Kohl's RCWA theory (coordinator node 2)

Sources [P]: Kohl's thesis (Stuttgart 2005), Adv. Appl. Math. 39 (2007), IJNT 4 (2008), J. Symb. Comput. 43 (2008), Math. Z. 264 (2010), J. Group Theory 20 (2017), and the GAP RCWA manual (v4.10.0). All are read in the literature sub-lane.

* **What the theory is.**
  * An rcwa map is affine on each residue class mod `m`, with modulus, multiplier and divisor.
  * `f` is *tame* iff the moduli of its powers are bounded (AAM 2007 Def. 1.3). For permutations this means `f` respects a finite residue-class partition (thesis Satz 2.5.8).
  * *Wild* means unbounded moduli: the residue-class structure never stabilises. This is the precise version of the owner's "incongruency".
* **What it proves about `3x+1`.**
  * `Mod(T^k) = 2^k`, so `T` is wild (AAM 2007 Ex. 1.4). More generally, every surjective non-injective rcwa map is wild (Thm 2.9).
  * `T` is not rcwa-monotonizable (IJNT 2008 Cor. 2.5).
  * Tameness would make the 3n+1 conjecture a finite computation (thesis Bsp. 1.8.5).
  * **Collatz ⟺ the group `G_C = <tau_(1(2),4(6)), tau_(1(3),2(6)), tau_(2(3),4(6))>` acts transitively on `N \ 0(6)`** (JGT 2017 Prop. 1.2).
  * Kohl conjectures that `T` is contracting with an 18-point centre, the union of the five known integer cycles. This would give Collatz on all of `Z` (thesis 3.6).
* **What it proves about Collatz's permutation.**
  * It is unbalanced (multiplier 4, divisor 3), hence wild (thesis Folgerung 2.5.12; JSC Criterion 6.3).
  * `Mod(g^k)/Mod(g^(-k)) = (4/3)^k`, so it is not conjugate to its inverse (thesis B.2).
  * It lies in the simple group `CT(Z)` (Math. Z. 2010 §5).
* **Wildness versus infinite orbits.**
  * No conjecture of Kohl links wildness to infinite cycles or divergence.
  * The thesis gives counterexamples:
    * a wild permutation with only finite cycles (B.4);
    * one with exactly one infinite cycle (B.5);
    * one whose single cycle covers `Z` minus 9 points (B.6).
  * Tame orbits are rigid: finite, or finite unions of residue classes (Folgerung 2.5.17).
  * Kohl's own heuristic for finite cycles is *drift* (a fair-coin recurrence, manual §7.4), not wildness.
* **Typing.** Wildness holds equally for `3x-1` and `5x+1` (both surjective and non-injective), so it is DRIFT- and SHEET-blind. It cannot prove T1 or NC; its value for Collatz is the reformulations (`G_C`, `sigma_T` on `Z^2`).
