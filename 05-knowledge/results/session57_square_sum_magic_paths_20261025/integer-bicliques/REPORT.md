# Ordinary integer square-sum bicliques: Session 57

## Scope and distinction

Let G_N be the simple graph on the distinct positive integer labels 1,...,N, with a~b exactly when a+b is a perfect square. A K_{r,s} means a subgraph, not necessarily induced. Its two parts must be disjoint; within-part edges are irrelevant. None of the following turns a bare K_{4,4} into a magic square of squares. Additional arithmetic decoration, notably the prescribed parallelogram identities, must be retained and tested separately.

## Complete common-neighbor parametrization

Fix 1 <= a < b <= N and delta=b-a. Each common neighbor x determines positive integers u<v with u^2=x+a and v^2=x+b. Put p=v-u and q=v+u. Then pq=delta, 0<p<q, p and q have the same parity, and

    u=(q-p)/2, v=(q+p)/2, x=((q-p)/2)^2-a.

Conversely each factor pair with those conditions yields exactly one common neighbor if and only if 1<=x<=N and x is not a or b. The correspondence is bijective: recovering u,v recovers p,q, and for p<sqrt(delta), delta/p-p is strictly decreasing in p. The checker enumerates every p=1,...,floor(sqrt(delta)), requiring divisibility and the listed conditions. Equal factors yield u=0 and cannot contribute for positive a,x.

If delta is 2 modulo 4 there are no common neighbors. If delta is odd, all factor pairs are odd and their number with p<q is floor(tau(delta)/2). If 4 divides delta, write p=2r,q=2s and rs=delta/4; the number is floor(tau(delta/4)/2). Bounds and excluded vertices may further reduce this count. Therefore a K_{2,4} necessarily has normalized divisor count at least 8. This is necessary, not sufficient. For example delta=96 admits four factor pairs but placing a and x in a small positive interval can eliminate them.

## Exact small minima

The minimum N for an ordinary K_{2,4} is 274. A witness is

    L={15,255}, R={1,34,106,274},
    square-root matrix = [[4,7,11,17],[16,17,19,23]].

The minimum N for an ordinary K_{3,3} is 673. A witness is

    L={1,193,673}, R={3,168,483},
    square-root matrix = [[2,13,22],[14,19,26],[26,29,34]].

Proof of minimality is finite complete enumeration, independently replayed by checker.py. For K_{2,4}, all binomial(274,2)=37401 pairs are enumerated, each common-neighbor list is generated by the factor bijection and independently compared against testing all x in [1,274] using integer square roots. The four smallest neighbors minimize the maximum label for a fixed left pair. For K_{3,3}, all pairs in [1,673] are examined. For each pair with at least three common neighbors, enumerate every right triple R and compute its entire common neighborhood L. If |L|>=3, the three smallest labels give the least possible maximum for that R. Every K_{3,3} contains a left pair and therefore appears. Taking the global minimum proves absence below 673. Because adjacency has no loops, L and R are automatically disjoint. The independent checker constructs adjacency by direct testing of all pairs and cross-checks every pair intersection against the factor enumerator.

The requested control L={1,97}, R={3,24,99,528} is valid, but far from minimal. A self-loop trap is a=8,b=248, where the otherwise candidate x=8 must be rejected.

## Closure search and bounded negatives

closure_search.py creates adjacency by enumerating each square s and all distinct positive a<b with a+b=s and a,b<=N. For k=3,4 it enumerates every seed pair {a,b}, its common-neighbor set C, and every k-subset R of C. Duplicate R are memoized. Compute L=N(R); a K_{k,k} exists with that R exactly when |L|>=k. This is a complete algorithm because every desired biclique contains a seed pair. It preserves integer labels; it never replaces arithmetic checks by abstract isomorphism.

At N=2000, no K_{4,4} exists. Only 2527 seed pairs have at least four common neighbors, and their unions produce 4127 distinct right quadruples. This is an algorithmic negative only in the stated complete universe, not a global impossibility statement. The K3,3 run tests 25115 distinct right triples from 15266 eligible seed pairs. Runtime was about 1.25 seconds in this environment. Runtime includes graph construction and both k values; no speedup ratio is claimed.

For decorated searches, N(S)=intersection of neighborhoods reverses inclusion and N(N(N(S)))=N(S). Thus maximal bicliques can be represented by closed pairs (N(R),R). But a decoration might occur on a nonclosed four-element subset of a larger closed side. Retain closures as containers and inspect their four-subsets for all required arithmetic identities; filtering only the full closure or forgetting labels is unsound. Pair-factor counts and modular impossibilities are safe early necessary filters. For a sorted four-set t1<t2<t3<t4, equality t1+t4=t2+t3 is a cheap, exact test for its opposite-sum parallelogram decoration if that is the decoration required by the separate bridge theorem.

## Literature check: avoid a terminology false positive

Alon, Angel, Benjamini and Lubetzky, *Sums and products along sparse graphs*, https://arxiv.org/abs/0905.0135 (author PDF https://web.math.princeton.edu/~nalon/PDFS/sumprod.pdf), studies square translates directly. Theorem 4.1 proves unbounded F3 and an infinite rational-square-translate construction; clearing denominators is applied to finite selected collections, not to infinitely many translates at once. Section 4.3 treats four or more shifts using higher-genus curves. This source does not justify claiming that the present positive disjoint K4,4 problem is impossible, solved, or equivalent to MSOS. No current global status claim is made here.

A misleading search hit is Ajitha, Arumugam and Germina, *On square sum graphs*, https://doi.org/10.1080/09728600.2009.12088866. Its graph labeling definition concerns injectivity of edge values f(u)^2+f(v)^2, not requiring f(u)+f(v) to be a square. Consequently its K_{m,n} theorem is inapplicable. A primary-source abstract explicitly exhibiting that alternate definition is https://ijsrmss.isroset.org/index.php/j/article/view/179 .

## Reproduction and failure behavior

Run `python checker.py` for independently checked minima and input/overlap/parity regressions. It catches exceptions, prints a FAIL object to stderr, and exits nonzero. Success prints PASS only after all checks. It uses exact integer arithmetic, no floating-point square test and no Python assert statements. Run `python closure_search.py 2000` for the bounded closure enumeration. JSON outputs record the precise N and counts. No claim about universes exceeding the recorded bounds follows from these files.

## Extended complete bound

The same closure enumeration was completed for N=10000: no K_{4,4}. It examined all 49,995,000 seed pairs, of which 195,219 had at least four common neighbors, producing 731,523 distinct right quadruples. The simultaneous K3,3 calculation had 660,224 eligible pairs and 1,836,298 distinct right triples, and reproduced minimum 673. Total elapsed time was 61.85 seconds. File closure_10000.json records the result. This remains only a finite exclusion, not a conjecture or proof of global nonexistence.

verify_k44.py independently checks the K4,4 exclusion without building adjacency: it enumerates factor-derived common neighbors for every delta and every left endpoint, then obtains possible fourth-side closures by factor-pair enumeration on the first two right endpoints and integer square tests against the remaining two. It may discard an entire delta only when the total number of positive difference-of-squares factor pairs is below four. It reports failure, not success, if any K4,4 is found or an exception occurs. Its JSON result includes exact universe and coverage counters.
