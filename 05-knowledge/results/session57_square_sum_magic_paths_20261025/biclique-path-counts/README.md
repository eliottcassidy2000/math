# Exact decorated K4,4 path-cover certificate

Let the two identified vertex classes be L_0,...,L_3 and R_0,...,R_3, with offsets S=(0,x,y,x+y). Edge L_i R_j has formal value C+S_j-S_i. Treat x,y as independent formal generators when counting distinct labels. The nine labels have multiplicities 4,2,2,2,2,1,1,1,1. Numerical specializations may collide; a distinct-entry application must exclude those collisions separately.

## Exact counts and direct proofs

There are 576 unoriented Hamilton paths: uniquely orient each to start in L, then choose the orders of its four L and four R vertices, giving 4!4!. There are 72 unoriented Hamilton cycles: the same 576 alternating strings describe each cycle eight times (four possible L starts, two directions).

Each edge occurs in 252 paths and 36 cycles, by edge transitivity and the respective seven/eight edge counts. There are 48 adjacent edge pairs and 72 disjoint edge pairs in K4,4. Every path contains six adjacent and fifteen disjoint edge pairs, so their incidences are 576*6/48=72 and 576*15/72=120. Every cycle contains eight adjacent and twenty disjoint edge pairs, giving 12 and 20. In particular, the union of all paths is all 16 edges and the intersection is empty.

## Minimal covering collections

All nine label values can be inspected on TWO Hamilton paths, and not one because a path has only seven edges. A witness is:

P: L0,R0,L1,R1,L2,R2,L3,R3.
Q: L1,R2,L0,R3,L2,R0,L3,R1.

Their label sets are disjoint, of sizes three and six. There are exactly 20,624 unordered pairs of distinct Hamilton paths whose label union contains all nine labels. Individual path label counts have distribution 3:8, 4:104, 5:232, 6:176, 7:56.

All sixteen identified edges require THREE paths, since two contain at most fourteen edges. A witness is P above together with:

A: L0,R1,L1,R2,L2,R3,L3,R0.
B: L1,R3,L0,R2,L2,R0,L3,R1.

There are exactly 675,264 unordered triples of distinct Hamilton paths covering all sixteen edges. As a supplementary cycle check, there are 36 unordered pairs of Hamilton cycles covering all sixteen edges.

The executable verifier enumerates all paths with shared, identified vertices and edges, rather than treating occurrences as independent copies. It enumerates pair coverage directly and triple coverage via exact integer-bitset intersection. Results and witnesses are also supplied in results.json.

## Group action, not numerical analogy

The full graph automorphism group is (S4 x S4) semidirect C2, of order 1152. The side-preserving subgroup S4 x S4 acts simply transitively on unoriented Hamilton paths: fixing a path and preserving the sides cannot reverse its unique L-starting orientation, so it fixes every vertex. Thus paths form a torsor for that subgroup, rigorously explaining 576=(4!)^2. The full group has a two-element path stabilizer generated by path reversal. Cycle stabilizers have orders eight in the side-preserving subgroup and sixteen in the full group (the dihedral symmetries of an eight-cycle).

These are UNDECORATED graph actions. Arbitrary independent permutations of L and R do not preserve the prescribed parallelogram labels. For labels fixed as formal expressions, the decoration-preserving automorphisms are precisely the identity and swapping the two sides while complementing each offset s to x+y-s. The verifier checks this over all 1152 graph automorphisms. If one allows changes of the parameter basis or relabelings of values, one must state that larger equivalence explicitly; the full graph group is not automatically a symmetry of the arithmetic problem.

## Coverage versus arithmetic and realizability

The graph alone forces neither squares nor a magic square. If the GLOBAL relation value(L_s R_t)=C+t-s is stipulated and valid, and each observed value on the covering pair is certified a square, those observations certify all nine distinct formal values as squares. Any other labelwise predicate transfers similarly. A third path is unnecessary for labelwise predicates, but three are required if one insists on inspecting each identified edge occurrence separately. If the relation is not already globally enforced, omitted edge occurrences can be assigned arbitrary values and label coverage does not repair that gap.

Given shared numerical C,x,y, the nine values can be arranged as

C+x       C-x-y   C+y
C-x+y     C       C+x-y
C-y       C+x+y   C-x

All rows, columns and both diagonals sum to 3C; the verifier checks the coefficient sums symbolically. This is an implication from the declared arithmetic relation plus square certificates, NOT a proof that any nondegenerate integer specialization exists. Positivity, square roots being integers, distinctness, and any additional geometric realization constraints must be checked independently. Arbitrary collections of two or three paths do not suffice: their actual union must satisfy the corresponding coverage condition.

## Stronger minimal nine-edge, two-path certificate

It is unnecessary to assume square-sum K4,4 in advance. Start with eight numeric vertices and all sixteen POTENTIAL cross edges, equipped with a valid shared numerical relation giving cross sums C+S_j-S_i. The following universal pair uses precisely nine different edges, one for each formal label:

P*: L0,R3,L1,R1,L2,R0,L3,R2.
Q*: L0,R3,L2,R1,L1,R2,L3,R0.

Shared edges and labels: L0R3 -> C+x+y; L1R1 -> C; L2R1 -> C+x-y; L3R0 -> C-x-y; L3R2 -> C-x.
P*-only edges: L1R3 -> C+y; L2R0 -> C-y.
Q*-only edges: L1R2 -> C-x+y; L2R3 -> C+x.

Thus checking those two square-sum paths requires only nine edge-square tests. The global relation certifies the other seven potential edges, producing the full square-sum K4,4 and the magic square above. All eight vertex identities and the five shared edge identities are retained.

Exactly 204 unordered label-covering pairs attain this nine-edge union. The complete union-size distribution among the 20,624 covering pairs is 9:204, 10:1852, 11:5600, 12:7720, 13:3760, 14:1488. These results and a witness are in minimal_union.json.

The sharp combinatorial converse is that nine distinct labels require at least nine inspected edge occurrences, hence no covering pair can share more than 7+7-9=5 edges. The displayed pair attains equality. This is minimality for a label-coverage certificate, NOT a theorem that an uninspected square condition cannot follow from other arithmetic facts. No such arithmetic independence claim is made. Without declared valid decoration, two Hamilton paths do not generally imply squarehood of the uninspected cross edges or any magic-square certificate.
