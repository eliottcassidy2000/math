# Prime-square lifting for strong tournament counts

**Status: PROVED; independently audited root-supplied argument, Session 25.**

For every odd prime p, write epsilon=(2/p), s(n) for the number of strong labelled tournaments on n vertices, c(n)=2^((n-1)/2) for odd n, and D(n)=s(n)-c(n). Then

s(p^2) = epsilon s(p) (mod p^2),
c(p^2) = epsilon c(p) (mod p^2),
D(p^2) = epsilon D(p) (mod p^2).

Consequently p^2 passes the strong-versus-circulant congruence if and only if p^2 divides D(p). This proves the prime-square equivalence, not just a finite numerical correspondence.

## Proof

Let G=C_(p^2) act by translations on the fixed label set Z/(p^2), and hence on the set X of strong tournaments on these labels. Let H be its unique subgroup of order p, generated by addition of p.

Every G-orbit has size1, p, or p^2. A point lies in X^H exactly when its stabilizer is nontrivial: every nontrivial subgroup of the cyclic group G contains H. Thus X minus X^H is a union of full p^2-element orbits. It follows that

s(p^2) = |X^H| (mod p^2).

This does not require any point of X^H to be fixed by all of G.

The H-orbits on vertices are the p cosets B_i of H, each of size p. In an H-invariant tournament, the induced tournament on each B_i is a circulant tournament of order p. There are

a = 2^((p-1)/2)

choices independently on each block. Each choice is strong: a nonzero step in its connection set generates the additive group of prime order, giving a directed Hamiltonian cycle.

For each unordered pair of distinct blocks, the p^2 connecting pairs of vertices split into p H-orbits, each of size p. Hence there are 2^p invariant orientation patterns between the blocks. Exactly one sends all arcs from the first block to the second, and exactly one sends them all in the opposite direction. The other

w = 2^p - 2

patterns have arcs in both directions.

Collapse each internally strong block to a labelled vertex. Retain an arc in each direction for which an original interblock arc exists. The result is a labelled semicomplete digraph: each pair has one directed arc or a digon. The original tournament is strong if and only if the contracted digraph is strong. For the reverse implication, paths in the quotient lift because within each block one can reach the tail of any desired outgoing arc. Forward implication follows by projecting paths.

Let S_p(z) be the integer polynomial summing z to the number of digons over all strong labelled semicomplete digraphs on these p quotient labels. Thus S_p(0)=s(p), and the exact fixed-object count is

|X^H| = a^p S_p(w).

Write S_p(z)=s(p)+B_p z+z^2 R_p(z). Here B_p counts the strong semicomplete digraphs with exactly one digon; the digon is already uniquely determined, so no extra marking multiplicity is introduced.

The cyclic permutation C_p of these p labels acts freely on that set. Indeed, any nonidentity element is a p-cycle. If it fixed such a graph, it would preserve its unique digon's unordered pair of endpoints. But a p-cycle for odd p has no invariant two-element subset. Thus p divides B_p.

Fermat gives p divides w. Consequently B_p w and w^2 R_p(w) are both divisible by p^2, and

S_p(w) = s(p) (mod p^2).

Euler's criterion gives a=epsilon+pt for an integer t. Since p is odd, the binomial expansion gives

a^p = epsilon (mod p^2):

the first nonconstant term is p*epsilon^(p-1)*pt, divisible by p^2, and all subsequent terms are also divisible by p^2. Therefore

s(p^2) = a^p s(p) = epsilon s(p) (mod p^2).

Finally c(p)=a and c(p^2)=a^(p+1), so

c(p^2) = epsilon a = epsilon c(p) (mod p^2).

Subtracting proves the claim for D. As epsilon is a unit modulo p^2, the divisibility equivalence follows. QED.

## Boundary and hostile audit

- p must be odd. At p=2, a 2-cycle can preserve a two-element subset and the circulant-block tournament construction fails.
- p=3 is fully covered. Here a=2, w=6, epsilon=-1; s(9)=c(9)=7 modulo9. No exceptional argument is required.
- No assertion that H-fixed tournaments are full G-circulants is made. The proof counts all H-fixed tournaments, including those whose G-orbits have size p.
- Mixed interblock orientations do not need to be uniform or mutually complete in both directions. One arc of each direction suffices after contraction because each block is internally strong.
- The polynomial coefficient is exactly the count of one-digon semicomplete digraphs; it is not a count of individual tournaments weighted by Hamiltonian paths.
- The argument proves the general prime-square equivalence, but does not verify a claimed finite search through p<=3000. That computation remains separately sourced.
- No inference about individual H(T), presentation spectra, or metagraph adjacency follows merely from this aggregate congruence.
