## 4. The native complement grammar as a graph on labelled tournaments

**Definitions.** For a tournament T on [n] and a Hamiltonian path P of T, the native complement is `tau_P(T) = T^op xor E(P)`: every arc off P is reversed and P is kept (it is a Hamiltonian path of the result). This is the operation of the weighted-renewal / clock-even / session73 grammar; re-marking the path is free there, so the move graph G_n has vertex set all 2^(n(n-1)/2) labelled tournaments and an edge T -- tau_P(T) for every Hamiltonian path P of T. The same P applied twice is the identity, so the relation is symmetric. The exception budget of T relative to the transitive baseline is its distance d(T) from the transitive tournament Tr (order 0 < 1 < ... < n-1) in G_n.

**Lemma 1 (composition).** As sets of toggled pairs, one move toggles the complement of E(P) in the pair set, so two moves toggle `E(P_1) xor E(P_2)`: `tau_(P_2) tau_(P_1) (T) = T xor (E(P_1) xor E(P_2))` with P_1 a Hamiltonian path of T and P_2 one of tau_(P_1)(T). In particular two moves change at most 2(n - 1) pairs, k moves at most k(n - 1) pairs when k is even and at most ... the complement of a path when k is odd.

**Theorem P (parity invariant; PROVED).** One move toggles (n - 1)(n - 2)/2 pairs. For n = 1, 2 (mod 4) this number is even, so the parity of the number of forward arcs (i -> j with i < j) is invariant under every complement move and every re-marking; the labelled n-tournaments split into two halves that no word of the grammar connects. The full converse toggles all n(n - 1)/2 pairs: for n = 2 (mod 4) this is odd and the converse joins the two halves; for n = 1 (mod 4) it is even and the obstruction survives the converse. Consequently, for n = 1 (mod 4), n >= 5, the native in-place grammar (relocation, complement, converse) reaches at most half of the labelled tournaments from any start; at n = 5 the regular tournament Z_5{1, 4} is unreachable from the transitive one. For n = 0, 3 (mod 4) the toggle count is odd and no parity obstruction exists.

**Theorem C2 (two-move criterion; PROVED).** d(T) <= 2 iff some total order r has backward-pair set D_r(T) = E(P_1) xor E(P_2) with P_1 a Hamiltonian path of T and P_2 a Hamiltonian path of tau_(P_1)(T). If f(T) = 2(n - 1) then d(T) <= 2 iff some f-optimal backward graph is the disjoint union of the pair sets of two directed Hamiltonian paths of T (the second one reversed in the intermediate tournament). Proof: `Tr_r = T xor D_r(T)` and Lemma 1; when |D_r| = f = 2(n - 1) the two paths cannot share a pair. For P_11, f = 20 = 2(n - 1) exactly, so the two-move question for the transitive class is a finite test on the f-optimal orders.

**Proposition B (clock-linear bounds; PROVED).** Relative to the reversed best order of T, one move changes the backward set by the n - 1 path pairs, so f(tau_P(T)) <= f(T) + n - 1 and therefore d(T) >= ceil(f(T) / (n - 1)). The score bound f(T) >= L(T) = (1/2) sum_i |s_(i) - i| (sorted out-degrees s_(i); each backward arc of an order moves two scores by one) gives for every regular tournament on q vertices f >= (q^2 - 1)/8, hence d >= ceil((q + 1)/8): a linear-in-q exception budget for every regular clock. Session73's one-step forest ceiling 2q - 4 is exceeded by (q^2 - 1)/8 as soon as q >= 17, so no regular tournament on at least 17 vertices is one complement from a forest frame (for P_11 the exact f = 20 > 18 of session73 is needed; the score bound gives only 15).

**Theorem L (score monotonicity; PROVED).** For every tournament T and every Hamiltonian path P, |L(tau_P T) - L(T)| <= 1.
