## 2. The low end of the strong spectra at orders 9 and 10 is exact; witnesses beyond

**Augmentation principle (CITED Moon 1966 + the insertion lemma of THM-1370).** Every strong tournament on n >= 4 vertices has a vertex whose deletion leaves a strong tournament, and H(T - v) <= H(T). Hence every strong n-tournament with H <= B is a one-vertex augmentation of a strong (n-1)-tournament with H <= B, so S_n ∩ [1, B] is computed exactly by augmenting the strong (n-1)-classes with H <= B in all 2^(n-1) ways. [`strong_low_spectrum_augment_20261027.cpp`](../../04-computation/experiments/strong_low_spectrum_augment_20261027.cpp) canonizes all 2^21 labelled 7-tournaments by brute force (456 classes, 353 strong), builds the 6,008 strong 8-classes by augmentation plus canonization (a second validation of the atlas), and then augments the 951 strong 8-classes with H <= 200 to order 9 and the surviving strong 9-tournaments with H <= 200 to order 10. ## 3. The two gap pairs on their actual fibres

The owner's question is whether {7, 21} (the odd values no tournament attains as a Hamiltonian-path count) relates to {2, 5} (the untouchable primes: no n has s(n) = sigma(n) - n equal to 2 or 5; conjecturally the only prime untouchables). Session73's arithmetic report already gave the structural verdict that the two scalar image grammars have different multiplication laws (raw-H values form a multiplicative monoid under the ordered join; aliquot-touchable values do not: 4 = s(9) and 13 = s(27) but 52 is untouchable), so the pairs do not identify a common grammar. This section puts the two complete fibre tables side by side, which is the exact content behind the analogy.

| | aliquot s(n) = sigma(n) - n | Hamiltonian-path count H(T) |
|---|---|---|
| natural value domain | positive integers; among primes only 2, 5 are untouchable (conjecturally) | odd integers (Redei) |
| complete inverse cutoff | n <= (m - 1)^2 for s(n) = m > 1 (a composite n has a proper divisor at least sqrt(n), so s(n) >= 1 + sqrt(n); the classical height bound) | strong sources of v have order n with f(n) <= v (the floor law), so F_s(v) is finite |
| empty fibres | s^-1(2) = s^-1(5) = empty; the odd untouchables are 5 and (conjecturally) nothing else; even untouchables have positive density | H^-1(7) = H^-1(21) = empty (THM-1370); Chan-Pak's Conjecture 6.2 asserts no other odd gap, verified below 80,557 by Royle and, in the strong form, to 80,265 by HYP-9029 / THM-4104 |
| why the first gap | 2 lies below the least composite value s(4) = 3 | 7 lies in the crevasse between the order-4 strong ceiling 5 and the order-5 strong floor 9 (THM-1370) |

## 4. The native complement grammar as a graph on labelled tournaments

**Definitions.** For a tournament T on [n] and a Hamiltonian path P of T, the native complement is `tau_P(T) = T^op xor E(P)`: every arc off P is reversed and P is kept (it is a Hamiltonian path of the result). This is the operation of the weighted-renewal / clock-even / session73 grammar; re-marking the path is free there, so the move graph G_n has vertex set all 2^(n(n-1)/2) labelled tournaments and an edge T -- tau_P(T) for every Hamiltonian path P of T. The same P applied twice is the identity, so the relation is symmetric. The exception budget of T relative to the transitive baseline is its distance d(T) from the transitive tournament Tr (order 0 < 1 < ... < n-1) in G_n.

**Lemma 1 (composition).** As sets of toggled pairs, one move toggles the complement of E(P) in the pair set, so two moves toggle `E(P_1) xor E(P_2)`: `tau_(P_2) tau_(P_1) (T) = T xor (E(P_1) xor E(P_2))` with P_1 a Hamiltonian path of T and P_2 one of tau_(P_1)(T). In particular two moves change at most 2(n - 1) pairs; k moves toggle E(P_1) xor ... xor E(P_k) when k is even (at most k(n - 1) pairs) and the complement of that set when k is odd (at least n(n - 1)/2 - k(n - 1) pairs).

**Theorem P (parity invariant; PROVED).** One move toggles (n - 1)(n - 2)/2 pairs. For n = 1, 2 (mod 4) this number is even, so the parity of the number of forward arcs (i -> j with i < j) is invariant under every complement move and every re-marking; the labelled n-tournaments split into two halves that no word of the grammar connects. The full converse toggles all n(n - 1)/2 pairs: for n = 2 (mod 4) this is odd and the converse joins the two halves; for n = 1 (mod 4) it is even and the obstruction survives the converse. Consequently, for n = 1 (mod 4), n >= 5, the native in-place grammar (relocation, complement, converse) reaches at most half of the labelled tournaments from any start; at n = 5 the labelled circulant Z_5{1, 2} (seven forward arcs, odd) is unreachable from the transitive tournament (ten forward arcs, even), as is every labelled tournament of odd forward parity. The obstruction separates labelled tournaments only: a transposition of two labels flips the forward-arc parity, so every isomorphism type has labelled copies in both halves (12 of the 24 labelled regular 5-tournaments lie in the component of the transitive tournament). For n = 0, 3 (mod 4) the toggle count is odd and no parity obstruction exists.

**Theorem C2 (two-move criterion; PROVED).** d(T, transitive class) <= 2 iff some total order r has backward-pair set D_r(T) = E(P_1) xor E(P_2) with P_1 a Hamiltonian path of T and P_2 a Hamiltonian path of tau_(P_1)(T). If f(T) = 2(n - 1) then d(T, transitive class) <= 2 iff some f-optimal backward graph is the disjoint union of the pair sets of two directed Hamiltonian paths of T (the second one reversed in the intermediate tournament). Proof: `Tr_r = T xor D_r(T)` and Lemma 1; when |D_r| = f = 2(n - 1) the two paths cannot share a pair. For P_11, f = 20 = 2(n - 1) exactly, so the two-move question for the transitive class is a finite test on the f-optimal orders.

**Proposition B (clock-linear bounds; PROVED).** Relative to the reversed best order of T, one move changes the backward set by the n - 1 path pairs, so f(tau_P(T)) <= f(T) + n - 1 and therefore d(T, transitive class) >= ceil(f(T) / (n - 1)). Session73's G3 tariff (ports report, section 5) is sharper, |f(tau_P T) - f(T)| <= n - 3 for n >= 4, giving d >= ceil(f/(n - 3)) (3 for P_11); in the census it is attained by the same two tournaments. Theorem L below supersedes both. The score bound f(T) >= L(T) = (1/2) sum_i |s_(i) - i| (sorted out-degrees s_(i); each backward arc of an order moves two scores by one) gives for every regular tournament on q vertices f >= (q^2 - 1)/8, hence d >= ceil((q + 1)/8): a linear-in-q exception budget for every regular clock. Session73's one-step forest ceiling 2q - 4 is exceeded by (q^2 - 1)/8 as soon as q >= 15 (q^2 - 16q + 31 > 0), so no regular tournament on at least 15 vertices is one complement from a forest frame (for P_11 the exact f = 20 > 18 of session73 is needed; the score bound gives only 15).

**Theorem L (score monotonicity; PROVED).** For every tournament T and every Hamiltonian path P, |L(tau_P T) - L(T)| <= 1. Hence d(T, T') >= |L(T) - L(T')| for any two tournaments, d(T, transitive class) >= L(T), and d(T, forest-framed class) >= L(T) - (n - 1) (a forest frame has f <= n - 1, so L <= n - 1). For a regular tournament on q vertices L = (q^2 - 1)/8, so d(P_q, transitive) >= (q^2 - 1)/8 = 6, 15, 45, 66, 120 at q = 7, 11, 19, 23, 31 and d(P_q, forest frames) >= (q - 1)(q - 7)/8 = 0, 5, 27, 44, 90: the exception budget of the Paley clocks in the native grammar is quadratic in the modulus, not linear. *Proof.* In T^op every out-degree becomes n - 1 - d_v; restoring the path arcs changes only the two ends, +1 at the start and -1 at the end (an internal vertex of P loses one out-arc and gains one). So the score multiset of tau_P(T) is the reflection s -> n - 1 - s of that of T with one entry raised by one and one lowered by one. The reflection fixes sum_i |s_(i) - i| (sorted scores reflect to sorted scores and |(n-1-s) - (n-1-i)| = |s - i|), and the quantity sum_i |s_(i) - i| = min over bijections of sum_v |s_v - pi(v)| is 1-Lipschitz in each score, so it changes by at most two; it is even (the signed sum vanishes), so L is an integer and changes by at most one. QED. Theorem L is independent of f: at order 7 the bound d >= L is attained by 15,771 tournaments while ceil(f/(n-1)) is attained by two.
