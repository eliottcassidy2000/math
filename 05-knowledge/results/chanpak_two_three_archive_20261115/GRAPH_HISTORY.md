# Where 2 and 3 really meet: graph and geometry ancestry, and a Chan–Pak obstruction

## A fixed-skeleton clipping theorem

Let \(S\) be any fixed tournament on \(d\) positions. At position \(i\) substitute a tournament \(D_i=C_i\oplus TT_{s_i}\), where \(\oplus\) is ordinal sum, \(C_i\) is fixed, and \(TT_{s_i}\) is a transitive padding block. The physical tournament is the lexicographic substitution with all cross-block arcs prescribed by \(S\). There is no bound on the padding lengths. For every \(X\ge2\), this family realizes at most
\[
(\lceil \log_2X\rceil+3)^d
\]
distinct Hamiltonian-path totals at most \(X\). Empty cores are allowed provided the resulting slots are nonempty. No acyclicity, bounded-run, interchangeable-ports, or fixed-total-order hypothesis is needed.

**Proof.** Let \(P_j(D)\) count ordered partitions of \(V(D)\) into \(j\) nonempty directed paths. A Hamiltonian path of the substitution projects to a word of maximal consecutive runs, with adjacent letters distinct and directed along \(S\). If a word uses letter \(i\) exactly \(j_i\) times, its total lift multiplicity is \(\prod_iP_{j_i}(D_i)\). Nonnegativity is essential. A word has a lift iff each \(j_i\) lies between 1 and \(|D_i|\), since splitting any Hamiltonian path gives a cover in every admissible number of slots. This run-content substitution is the inherited THM-3121 kernel.

For any admissible \(j\ge2\) and \(s\ge2\), put the padding vertices surjectively in \(\ell=\min(j,s)\) prescribed ordered slots. If \(j>\ell\), split a fixed Hamiltonian path of \(C\) among the other \(j-\ell\) slots; if \(j=\ell\), place that entire path at the head of the first slot. Every distinct pad assignment gives a distinct cover. Since each chosen pad subset has a unique directed order,
\[
P_j(C\oplus TT_s)\ge\ell!\,\ell^{s-\ell}\ge 2^{s-1}.
\]
The first inequality on the right uses only assignments putting the first \(\ell\) fixed pad vertices in different slots. Thus if \(H\le X\) and \(s_i>\log_2 X+1\), **every feasible run word visits \(i\) exactly once**. Set \(K=\lceil\log_2 X\rceil+2\) and replace each \(s_i>K\) by \(K\). Shortening cannot create any newly feasible word, since feasibility is exactly the per-letter order constraint. It cannot kill any formerly feasible word either: shortened letters formerly occurred once. Every surviving multiplicity is identical because \(P_1(C_i\oplus TT_{s_i})=H(C_i)\), taking \(H(\varnothing)=1\) here. All realized sublevel counts therefore come from the finite cube \(0\le s_i\le K\). This argument avoids the false claim that a fixed skeleton has finitely many run words independently of block order: a 3-cycle can have arbitrarily long words.

**An obstruction even for changing low-count core classes.** Suppose each substituted tournament is now unrestricted except that \(H(D_i)\le Y\). Compress it as an ordered list of nontrivial strong components plus a single total for singleton components. To see that the locations of the singletons can be discarded *for this uniform reader*, fix a number of labeled optional slots. Each global optional cover restricts to an optional cover of each component, and those restrictions concatenate uniquely in ordinal order; its count is their product. A singleton therefore multiplies the optional \(q\)-slot count by \(q\). Binomial inversion restores each nonempty-slot count \(P_j\). All run-word contributions are preserved by moving every singleton to the end, even though the original and compressed tournaments need not be isomorphic or endpoint-equivalent for selective readers.

By [Busch's lower bound](https://www.combinatorics.org/ojs/index.php/eljc/article/view/v13i1n3), an \(n\)-vertex nontrivial strong component has \(H\ge5^{(n-1)/3}\). Path counts multiply along the SCC list, so the total core order per position is \(O(\log(2Y))\): use \(n\le(3/2)(n-1)\) for \(n\ge3\). The number of possible reduced cores (each singly obtained by deleting all singleton SCCs) is at most the number of labeled tournaments on up to that many vertices, hence \(e^{O((\log(2Y))^2)}\). Applying the theorem to all core packets gives
\[
\#\{H\le X\}\le \exp(O_d((\log(2Y))^2))\,(1+\log X)^d.
\]
If all selectable readers come from a finite set of skeletons and \(Y=\exp(o(\sqrt{\log X}))\), there are only \(X^{o(1)}\) hits. For small enough \(\epsilon>0\) depending on the skeleton set, taking \(Y=\exp(\epsilon\sqrt{\log X})\) still gives \(o(X)\) hits. Consequently almost all odd targets require a genuinely larger intrinsic module count, a growing skeleton, or a nonuniform reader, **within this architecture**. It says nothing against an exact placement theorem using selective arcs or genuinely growing SCC cores. This is not Chan–Pak, but is an all-order reason to retire a whole class of “just desynchronize the clocks” solutions. The proof uses physical positivity and clipping, not a modular approximation or a census.

**Selective-seam corollary.** Fix a core of \(r\) vertices and a transitive spine of arbitrary length. Label each spine vertex by its complete external direction vector in \(\{0,1\}^r\). If this label word uses at most \(b\) maximal constant runs, contract each run into a skeleton vertex. Cross-arcs between those runs are transitive and their cross-arcs to the core are uniform by the definition of the labels. Our theorem applies, with at most \(r+b\) positions and only \(b\) free pads. There are at most \(\sum_{a=1}^b (2^r)^a\) contracted label words before choosing their multiplicities. Therefore bounded-signature-run selective contacts still yield at most
\[
\sum_{a=1}^b(2^r)^a\left(\lceil\log_2X\rceil+3\right)^a
\]
sublevel totals. With \(r\) fixed this bound is \(X^{o(1)}\) whenever \(b=o(\log X/\log\log X)\), and for small enough \(c>0\) still \(o(X)\) if \(b\le c\log X/\log\log X\). Thus a fixed-apex decoder aspiring to hit almost all targets must make the *signature alternations* grow, not just lengths, even if the number of distinct signatures is bounded and every residue class already has witnesses.

## A sharper design question

Ask for an inverse chart with **three separately certified parts**: (i) local choice of residues/slots, (ii) bounded representative in the *right absolute-height strip*, and (iii) preservation of the reader after each shortening or recontact. The “single-visit clipping” argument shows exactly why changing the padding of small cores will not achieve (ii), even if it achieves (i) with two independent clocks and overlapping digit sets at some fixed scales. A promising next calculation is to model one selective seam that can reach inside the padding: either show that it restores the same clipping obstruction by factoring through a bounded number of transitive subpads, or exhibit how it violates clipping while keeping the marked endpoints ready. Only the latter can turn the Rule 30 free-input analogy into a genuinely different Chan–Pak construction. Treat sparse positive families as a guide to where to change the source, not as evidence of nonrealizability.
