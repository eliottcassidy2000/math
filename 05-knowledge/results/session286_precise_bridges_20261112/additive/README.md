# Additive bridge lane

- [PROOF.md](PROOF.md): exact projected-residue bottleneck, completed-bank
  two-sided semigroup criterion, sharp boundary-hole classification, and the
  mixed-core/all-finite-integral-ratio supply boundary.
- `verify.py`: standalone arithmetic and inherited literal support controls;
  `RESULTS.json` is its exact receipt.
- `mixed.py`: reconstructs the40 distinct physical packets from64 literal
  root cuts, exhausts all packet transitions through length4, and checks the
  finite base for an all-length no-saturation theorem; `MIXED.json` is its
  exact receipt. It uses roughly a few hundred MB and about a minute on this
  environment. Timing is descriptive, not a benchmark claim.

Run from anywhere with Python3:

```
python3 verify.py
python3 -O verify.py
python3 mixed.py
python3 -O mixed.py
```

No imports outside the standard library, no random samples, no network inputs.
The completed-bank arithmetic theorem is a *conditional physical transfer*;
this lane does not supply such completed physical banks. Its all-length
negative theorem applies only to the named mixed alphabet (and the deletion
threshold statement to its explicit generalized class), not to all tournaments.
Chan–Pak remains open.

`padded_bank.py` uses only the sibling `mixed.py` elementary path counter.
Run normally and with `-O`; it outputs `PADDED_BANK.json`, six explicit
fourteen-vertex full-central witnesses, plus the failed-slide sidecar control.
