# Wildcard: microscopic phase can survive a scalar spectrum

Read [PROOF.md](PROOF.md). The precise bridge is from old LRC cyclic
homometry to actual full-packet tournament twins, and from a common root-arc
reversal to an exact central count switch. Johnson exchange identities give
exact interaction tomography and variance on each fixed-cardinality fiber.
These are constructive/observer results, not Chan–Pak completeness.

Run `python3 verify.py` and `python3 -O verify.py` from this directory or any
working directory. The verifier is standalone. `scout.py` and `search13.py`
are optional exploratory scripts using the inherited Session285 coefficient
producer; their outputs are finite search records, not proof receipts.
