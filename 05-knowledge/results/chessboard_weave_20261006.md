**Proposition 1.2 (the rings are what the bishop sees; PROVED).** On the `N x N` board the number of squares a bishop reaches from `(i,j)` on the empty board is `2N - 3 - 2 ring(i,j)` (13, 11, 9, 7 on 8x8), the queen's is `4N - 5 - 2 ring`, the rook's is the constant `2(N-1)`. *Proof.* With `a = min(i, N-1-i)` and `b = min(j, N-1-j)` (distance to the nearest edge), and by symmetry `i, j <= (N-1)/2`, the four diagonal rays have lengths `min(i,j)`, `i`, `j`, `N - 1 - max(i,j)`, summing to `N - 1 + 2 min(a,b)`, and `min(a,b) = N/2 - 1 - ring`. ∎ So the horizontal/vertical rings are exactly the level sets of the diagonal sliding range: the two structures the owner names are welded by the bishop.

**Proposition 1.3 (the knight's ring law; PROVED, checked `N <= 16`).** On the `2m x 2m` board the `4(2m-1)(2m-2)` knight edges split as
`8(m-1)` inside a ring (exactly 8 in every ring `k >= 1`, none in ring 0), `16 C(m,2)` between adjacent rings, `16 C(m-1,2)` jumping two rings, none jumping three. Every knight edge joins the two colours. On 8x8: `24 + 96 + 48 = 168`, and by ring pair `(0,1):16, (0,2):16, (1,1):8, (1,2):32, (1,3):32, (2,2):8, (2,3):48, (3,3):8`.
*Proof.* Use centred half-integer coordinates `(x,y)`, radius `r = max(|x|,|y|)`. A knight vector changes one coordinate by 2 and the other by 1, so `|Delta r| <= 2`. ## 2. The lonely runner as a sliding piece (anchor)

`bishop reach = (N - 2) + 2N lambda(centre).`

"Unlimited amounts until an obstruction is reached" is Cusick's view obstruction (THM-386): LRC with `n` speeds says every positive rider meets the closed central cube `[1/(n+1), n/(n+1)]^n`, the inner `(n-1)^n` block of the `(n+1)^n` subdivision (a tight rider only touches its boundary and never enters its interior). **Theorem 2.1 (two speeds: loneliness lives on the anti-diagonal; classical, re-proved).** For coprime positive integers `a, b` with `s = a + b`,

`delta(a,b) := max_t min(||ta||, ||tb||) = floor(s/2)/s`,

i.e. `1/2` when `s` is even (the `(a,b)`-leaper keeps its colour) and `1/2 - 1/(2s)` when `s` is odd (it changes colour). The minimum over all riders is `1/3`, attained only by the knight `{1,2}`.
*Proof.* Because `gcd(a,b) = 1`, the closed orbit `{t(a,b)}` is the connected subgroup `L = {(x,y) : bx - ay in Z}` of the torus. `lambda >= c` (`0 <= c < 1/2`) at a point iff it lies in the square `[c, 1-c]^2`. The linear form `f = bx - ay` maps this convex square onto the closed interval of centre `(b-a)/2` and half-length `s(1/2 - c)`. So `delta >= c` iff that interval contains an integer. If `s` is even the centre is an integer and `c` may be any value below `1/2` (and `t = 1/2` gives `1/2`). If `s` is odd the centre is a half-integer and we need `s(1/2 - c) >= 1/2`. ∎ Verified for all 489 coprime pairs `a < b <= 40` by exact evaluation over the candidate times (`..._rider_rings.out`). The colour of the leaper is the parity of `s`; the loneliness deficit `1/2 - delta` is `0` on one scaffold and `1/(2s)` on the other, largest (`1/6`) for the knight. In the space of directions `delta` is constant on each anti-diagonal `a + b = s` (so the level set `delta = 1/2` is the union of all even anti-diagonals).

**Theorem 2.2 (the two scaffolds are the two extremes, and their weave is the tight progression; classical, re-proved).** For `m >= 1`: `delta(1, 3, ..., 2m-1) = 1/2`; `delta(2, 4, ..., 2m) = 1/(m+1)`, tight for `m` speeds; `delta(1, 2, ..., 2m) = 1/(2m+1)`, tight for `2m` speeds. Proof of the bound: by Ore's bipartite `f`-factor criterion with `f = 2`, a 2-factor fails to exist after deleting `D` only if some `S` in one colour class and `T` in the other have `2|S| - 2|T| > e(S, T^c) - d`, with `d` the deleted edges between `S` and `T^c`; this needs `|S| > |T|`, and 8-regularity gives `e(S, T^c) >= 8(|S| - |T|)`, so `d >= 6(|S| - |T|) + 1 >= 7`. (The 2-factor bound only bounds `beta` from above; `beta >= 7` is the exhaustive computation.) Each minimum blocking set still leaves an open tour; the fewest deletions killing every open tour is 8. This is the knight form of HYP-9168: the cheapest way to kill every Hamiltonian object is a Hall obstruction. (On the bounded boards the blocking number is 1, trivially: a corner has degree 2.) The 6x6 per-edge closed-tour counts by orbit are `a1-c2: 9862, b1-a3: 8611, c1-e2: 7438, b1-d2: 6195, b1-c3: 4918, b2-d3: 2424, c1-d3: 1900, c1-b3: 1775, c2-e3: 636, c2-d4: 620`; the odd ones form four hexagons such as `b1-d2-f3-e1-c2-a3`, each with 2 moves inside the outer ring and 4 ring-1/ring-2 moves.

**The frame (closed: PROVED by forcing; open: FINITE-EXACT; lane `knight`).** The two-square-wide frame (rings 2 and 3, 48 squares) has no knight tour, open or closed (exact DFS and CP-SAT for both). For closed tours there is a short proof: by the size identity (`e(ring 3) - e(ring 2) = 28 - 20 = 8`, and ring 3 has only 8 internal knight moves) a closed tour of the frame would need all 8 moves inside ring 3 and none inside ring 2; degree forcing then fixes all 48 tour edges and splits the frame into four forced 12-cycles (for example `a1 b3 a5 b7 d8 f7 h8 g6 h4 g2 e1 c2`), re-derived independently by the orchestrator (`..._frame_forcing.out`). The board minus its central 2x2 has closed tours (witness in `..._knight_holes.out`); the central 4x4 and rings 1-2 alone have none.

**HYP-9168 itself (lane `hp_blocking`; scripts `..._hp_blocking_engine.c`, `_exhaustive.py`, `_run.py`, `_theory.py`, outputs alongside).** For a tournament `T`, `beta(T)` is the fewest arcs whose deletion leaves no Hamiltonian path, and the Hall bound `hall(T) >= beta(T)` starves a set of predecessors.
* **Reformulation (PROVED, König; checked against the literal `(X, Y)` definition on all labeled tournaments with `N <= 6` and all classes `N = 7`).** `hall(T) = min{ e_T(A -> B) : |A| + |B| = N + 2 }`, the fewest deletions destroying every spanning *1-path-cycle factor* (one path plus disjoint cycles: a matching of size `N - 1` in the out/in bipartite double). So HYP-9168 says: **in a tournament, the cheapest way to kill every Hamiltonian path is to kill every path-plus-cycles factor.**
* **FINITE-EXACT, `N = 10` (new): `beta = hall` for all 9,733,056 classes** (`gentourng 10`, split in two pieces, 2440 s; exact branch and bound with HP-guided branching, protection and a packing lower bound, proving that no set of `hall - 1` arcs kills every HP). The engine agrees with brute-force subset enumeration on all 530 classes with `N <= 7` (also with root symmetry breaking) and on 5000 damaged digraphs. Hall histogram at `N = 10`: `1:13727, 2:203041, 3:1161890, 4:3007400, 5:3434830, 6:1664367, 7:234468, 8:13333`; the two-source/two-sink bound is not optimal in 3368 classes (180 at `N = 9`).
* **VERIFIED (random):** uniform random labeled tournaments, `N = 11` (10000), `12` (10000), `13` (1000), `14` (200); 300 random almost-regular tournaments at `N = 10`: `beta = hall` throughout.
* **Scope (FINITE-EXACT counterexamples).** The equality is false for oriented graphs that are not tournaments: among 5000 tournaments with up to `N/2` arcs removed (`N = 6, 7, 8`), 20 have `beta < hall`, already for a tournament minus one arc (`hall = 3, beta = 2`). Any proof must use semicompleteness.
* **Two proof routes, tested and failing as stated.** (i) Gutin's theorem (a multipartite tournament has a Hamiltonian path iff it has a 1-path-cycle factor) holds on all 399,912 multipartite tournaments obtained from classes `N <= 7`, so blocking sets whose deleted pairs form disjoint cliques can never beat `hall` — but for some classes no minimum blocking set has that form. (ii) The merge count: the fewest deletions blocking every simple merge of a path `P` with a disjoint cycle `C` is exactly `MB(P,C) = sum_delta (1 + asc_delta) >= |C|` (verified on 1500 random instances), yet `min_F sum_i MB(P, C_i) < hall` for 3 classes at `N = 6` and 65 at `N = 7` (deficit up to 3; witness `T = 110010111001110101111`, `F = (2,4,6,1) + (0,5,3)`). A proof must merge cycles with each other or reroute the path. (iii) Minimum blocking sets need not be Hall obstructions: some have size `beta = hall` yet leave a 1-path-cycle factor ("exotic minima", FINITE-EXACT census `N <= 8`): 14 in 3 classes at `N = 5`, 6 in 4 classes at `N = 6`, 21 in 3 classes at `N = 7` (the regular ones; every exotic minimum there isolates a vertex, `N - 1 = 6 = hall` deletions), none at `N = 8`. So `beta >= hall` cannot be proved by showing that every minimum blocking set starves a set; it has to be a counting statement.
* **New partial theorem: `beta >= min(hall, 3)` (PROVED; lane, key step re-checked by the orchestrator), so HYP-9168 holds for every tournament with `hall(T) <= 3`, at every `N`.** Take `D` with `|D| < hall`; then `T - D` has a 1-path-cycle factor; merge its cycles into its path one at a time. For a path `P = p_1 ... p_m` and a disjoint cycle `C = c_0 ... c_{k-1}` group the pairs `(p_j, c_i)` into `k` diagonals `i + j = delta (mod k)` and read `x_j = [p_j -> c_{delta - j}]`: `x_1 = 0` gives a front merge, `x_m = 1` a back merge, and otherwise some `x_j = 1, x_{j+1} = 0` gives a middle merge (`p_j -> c_i, c_{i-1} -> p_{j+1}`), all inside one diagonal. So every diagonal carries a merge, merges on different diagonals use different arcs, and a stuck merge needs `|D| >= k >= 3` (tournament cycles have length at least 3). Exact count: blocking every simple merge costs `MB(P,C) = sum_delta (1 + asc_delta)` (brute force on 1500 instances). The same argument proves HYP-9168 for any `T` all of whose 1-path-cycle factors have merge count `>= hall` (every class with `N <= 5`, 391 of 456 at `N = 7`). It fails beyond that because single-factor counting misses interleaving: in the regular witness above, `D = {0->2, 1->3, 3->6}` blocks every simple merge of the factor yet `T - D` keeps the Hamiltonian path `0123456`.
* **Regular tournaments (PROVED).** The out/in bipartite double of a `k`-regular tournament is `k`-regular, so any `N - 2` cover vertices miss at least `2k = N - 1` arcs: `hall = N - 1` exactly for regular `T` (and `hall <= N - 2` otherwise). The old corollary ("a regular tournament survives the deletion of any `N - 2` arcs") is therefore exactly HYP-9168 restricted to regular tournaments.
* **Structured families (FINITE-EXACT):** all 32 circulants on `Z_11` (`beta = 10`), all 64 on `Z_13` via 6 multiplier-orbit representatives (`beta = 12`), Paley `QR_11` (10), `QR_11` minus a vertex (8), transitive tournaments and all single-arc reversals for `N = 10, 11, 12` (169), 72 hub compositions `h -> A => B -> h` with cyclic/regular/transitive blocks up to `N = 14`; random: 300 regular `N = 11`, 200 almost-regular `N = 12`. No counterexample anywhere.
* **Semicomplete digraphs (2-cycles allowed) break it (FINITE-EXACT):** `beta < hall` for 30 of 665 labeled ones at `N = 4` and 210 of 58025 at `N = 5`; a 2-cycle is cheap to isolate, exactly where the merge lemma's "length `>= 3`" fails. **k-path version** (fewest deletions leaving no cover by `<= k` paths = `min_{|A|+|B| = N+k+1} e(A,B)`): FINITE-EXACT for `k = 2, 3`, all `N <= 7` — a natural strengthening.
* **Independent cross-check (orchestrator).** A second implementation with a different algorithm — `hall` by the König form as the sum of the `N + 2 - |A|` smallest in-degrees from `A`, and `beta >= hall` by SAT (CaDiCaL) with lazy Hamiltonian-path cuts — on 111 sampled `N = 10` classes (every 97333rd class of `gentourng 10`, plus 11 classes with `hall = 8` found by a sparse scan): `beta >= hall`, hence `beta = hall`, for all of them (at most 405 lazy cuts; 173 s; `..._hp_blocking_indep.out`).
