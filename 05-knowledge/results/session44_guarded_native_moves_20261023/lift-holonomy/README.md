## 2. Exact finite cover theorem, including its completeness boundary

Let B be a finite connected undirected multigraph, with loops allowed and a
chosen root o. Each vertex v has a **nonempty entire accepted fibre** F_v
identified with a torsor for V=F3^r. Its chart includes all retained kernel
coordinates. For each oriented base edge e:u->v supply a bijection

    T_e(a)=M_e a+c_e,       M_e in GL(r,3),
    T_(reverse e)=T_e^(-1).

Also supply any finite list of invertible affine internal maps I_(v,j) of
F_v. An internal map supplies all edges a--I_(v,j)(a) and their reverses.
The lifted graph L has exactly these edges and no others. Loops or repeated
edges do not change the connectivity assertion.

The word **accepted** is an input obligation. In a native application,
every listed map must have an actual path/source/target transporter or an
independent native endpoint-move certificate, preserve every required shared
owner/arc port, and preserve the full supplied guard on every state where the
move is claimed. If a port is transported rather than fixed, its specified
owner relabeling must be part of that certificate. A mod 8 guard must be the
actual marked predicate, not a residue invented from a kernel cardinality.

Choose a spanning tree and write S_v:F_o->F_v for its root-to-v transport,
with S_o=id. For every oriented edge and every internal generator form

    h_e = S_v^(-1) T_e S_u,
    h_(v,j) = S_v^(-1) I_(v,j) S_v.

Let H be the subgroup of AGL(r,3) generated by these maps. Tree-edge
h_e are identities, so only non-tree returns and internal generators matter.

**Theorem.** The connected components of L are exactly

    C_O = {(v,S_v(a)): v in B, a in O},        O an H-orbit in V.       (1)

Consequently L is connected iff H acts transitively on the root fibre;
|C_O|=|B||O|, and every component meets every base fibre in |O| states.

**Proof, both directions.** In tree coordinates an edge maps a to h_e(a),
and an internal edge maps a to h_(v,j)(a). Every lifted path stays in one
H-orbit, so a connected component is contained in (1). Conversely, a
root-to-u tree path, e, and the reverse v-to-root tree path realize h_e
as an actual lifted walk. The analogous excursion realizes h_(v,j).
Reversibility realizes their inverses. A word in these generators therefore
connects each root point with every point in its H-orbit; tree paths then
reach every indicated vertex over every v. Thus (1) is connected. QED.

For a disconnected base, apply the theorem separately to each component.
For r=0 it says the lift is just the connected base. Empty fibres, unequal
fibre dimensions, noninvertible transports, or edges legal only on some
states are **not** this cover interface. One must retain the actual finite
relation or refine the carrier; silently completing a partial matching is
unsound. The checker gives two fibres F3 with only the edge 0--0: there are
five components, whereas falsely completing it to the identity matching
gives three.

The completeness clause is essential. A supplied subset of all legal native
moves can certify native connectivity when it connects everything. Its
several components are only an **upper bound** on the number of components
of a larger move graph. To claim those components are the actual full native
components, prove that every additional legal move remains inside them or
that the move list is exhaustive. The theorem never invents native edges.

### Translation specialization and cheap separating certificates

If every based generator is a translation a->a+t_g, let

    W = span_F3{t_g},                  d=dim W.

Then H is exactly the translation group W, its orbits are the cosets a+W,
and

    number of components = 3^(r-d),
    size of each component = |B|3^d.                                (2)

This includes internal translations only after bringing them into the same
root gauge. Row reduction gives d. Every k in W^perp gives an invariant

    (v,a_v) -> k dot S_v^(-1)(a_v) in F3.                           (3)

A basis of W^perp separates all components. This is a small disconnection
certificate; generator expressions plus tree walks give actual paths for
connectivity. There is no polynomial bound promised for orbit enumeration
of arbitrary large affine input.

The rank shortcut does not hold for general affine generators. On F3,
h(a)=-a has orbits {0},{1,2}: orbit sizes need not be powers of three or
uniform. Nor is connectivity a section-existence statement. Translation by1
on F3 is transitive but has no fixed point; identity holonomy has three
fixed points and three lifted components. THM-2622 and (1) answer different
questions.

### Charts, converse, and shared ports

Replacing each chart by an affine bijection C_v conjugates every edge to
C_v T_e C_u^(-1). The new tree transports are C_v S_v C_o^(-1), so every
based generator is conjugated by C_o. Orbits, component sizes and
connectivity are invariant. An authenticated native converse is precisely
such a graph isomorphism if its coordinate action is affine. Even without
an affine chart, an explicitly authenticated bijection still transports
components; it simply leaves this affine compiler's algebraic interface.

For actual tournament paths the relevant operation is

    (T,P,K_P(T)) -> (T^op, reverse(P), K_P(T)^op).

Clock j becomes n-1-j and arc endpoints reverse. Actual fixed/shared ports
must be transported with those clocks, not re-pinned to a printed coordinate.
On converse-merged electrical classes the phase is unchanged. Exchanging
the two ends of the complement line instead negates it. These distinct
operations must not be collapsed into a bare sign convention.

## 3. A genuine native order 20 carry, obstruction and repair

Start with the prior two-C9-cell source and add a source singleton s and a
sink singleton t. Name the actual vertices

    s=0; A_i=1+i; B_j=10+j; t=19,       0<=i,j<9.

Inside either C9 cell orient i->j when j-i is in {1,2,3,4} mod 9. Between
cells orient A_i->B_j iff i=j mod 3, reversing the other cross pairs. The
source beats all other vertices and all vertices beat the sink. This is
an actual order 20 tournament, not a regular one. The unpadded order 18 core
is the inherited strongly connected source.

For a,b in Z/9 set

    P_(a,b) = (s, A_a,A_(a+1),...,A_(a+8),
                   B_(b+2),B_(b+3),...,B_(b+1), t).

Its only nontrivial Hamiltonian junction is A_(a+8)->B_(b+2), which holds
iff a=b mod 3. There are exactly 27 accepted paths in this specified cyclic-
cut family. Each is obtained from P_(0,0) by the actual source automorphism
that rotates A by a and B by b. Both literal endpoint owners s,t are fixed.
This is a complete 81-candidate check for the specified chart language, not
a census of all Hamiltonian paths or all tournament automorphisms.

Retain q=a mod 3 and write

    a=q+3u, b=q+3v,        q,u,v in {0,1,2}.

The connected base is C3 on q; each fibre is the **whole** F3² on (u,v).
Declare the reversible native moves

    (a,b) -> (a+1,b+1) and (a-1,b-1) mod 9.                          (4)

These are actual two-cell automorphisms. In the chosen coordinates, the
forward 0->1 and 1->2 edge maps are identity, while 2->0 maps
(u,v)->(u+1,v+1). The tree-root holonomy is therefore translation by (1,1).
Its rank is one. The27 retained paths have exactly **three components of
nine paths**, with separating label

    v-u = (b-a)/3 mod 3.                                           (5)

The quotient is connected; the supplied actual lift graph is not. This is
not a failure of Hamiltonian validity or of port preservation. It is the
missing kernel direction. The wrap cannot be discarded merely because
q returns to zero after three applications.

There is an authenticated repair: add the internal moves

    (a,b) -> (a+3,b) and (a-3,b) mod 9.                              (6)

Each rotates only the first cell, still preserves a=b mod 3, and still fixes
s,t. In each ternary fibre it is translation by (1,0). Together with (1,1)
it spans F3², so the new supplied graph is connected. These are explicit
atomic automorphism moves, not asserted to be an elementary tile operation
or an exhaustive native metagraph generating set.

Every step preserves the actual source and carries each partner K_P(T)
onto K_(gP)(T) arc by arc. Therefore, for **any supplied potential x on
converse-merged tournament classes of order 20**,

    x_[T]-x_[K_(gP)(T)] = x_[T]-x_[K_P(T)] mod 8.                    (7)

In particular any actual harmonic electrical character has this invariance.
Equation (7) follows from equality of source/target classes, without knowing
the numeric potential. It does not assert existence of a nonconstant
order 20 character, recover a full electrical atlas, or substitute a
synthetic mod 8 clock. The checker authenticates the stronger literal
isomorphisms, all indexed endpoints, the native partner involution, and
all converse squares. Thus the guard-preserving claim has a genuine native
realization and a clearly stated numerical boundary.

## 4. Twisted character blocks: base gap 8/9 is only one sector

Assume a reversible Markov chain on the supplied lift: each oriented edge
has a nonnegative probability p_e independent of the fibre point, the
outgoing probabilities sum to one, and

    pi_u p_e = pi_v p_(reverse e).

Internal generators are treated as base loops with inverse weights.
Require pi_v>0. The stationary lift measure is pi_v/3^r. Discard
zero-probability moves before computing support holonomy and its rank d;
apply the statement separately if the positive-probability base support
is disconnected. State-dependent weights, unequal
fibre multiplicities or missing reverse rates need a different analysis.
We use the Poincare gap, not the absolute-value gap; extra eigenvalue1
directions make the **global** gap zero even when a within-component
relative gap is positive.

In tree coordinates first suppose all transports are translations by t_e.
For chi_k(a)=exp(2pi i k dot a/3), functions chi_k(a)h(v) form an invariant
block. Direct substitution gives

    (P_k h)(u) = sum_(e:u->v) p_e chi_k(t_e) h(v).                  (8)

The blocks are orthogonal, each is self-adjoint in ell²(pi), and their
spectra together are the full lifted spectrum. P_0 is the base chain.
Hence a bound on P_0 alone controls none of the other sectors. If
k annihilates all holonomy/internal translations, P_k=P_0 in tree gauge.
For connected base support, the multiplicity of eigenvalue1 is exactly
the 3^(r-d) such sectors, matching (2). A direct proof uses equality in the
Dirichlet form: eigenvalue1 functions are constant on each supported edge,
so precisely on components. Characters of V/W give those constants.

For genuinely affine maps, a target mode chi_k becomes

    chi_k(M_e a+c_e) = chi_k(c_e) chi_(M_e^T k)(a).

Single characters may mix. The invariant blocks are the dual-frequency
orbits under the subgroup generated by all M_e^T in tree gauge, with
phase-weighted transitions as displayed. The zero mode is still the base
chain. This proves a block decomposition, not a uniform gap estimate.

**Abstract, even connected and positive semidefinite.** Let the two-state
base chain be

    B = [[5/9,4/9],[4/9,5/9]],        spectrum {1,1/9}.

    1, 1/9,
    1-3epsilon/2 (twice), 1/9-3epsilon/2 (twice).

All eigenvalues are positive and its gap is exactly 3epsilon/2, tending
to zero. Thus even full-rank translational holonomy does not quantitatively
control mixing without a weight/congestion bound.

**Authenticated native component.** On the order 20 family give each move
in (4) probability 8/27 and the identity probability 11/27. The C3 quotient
has diagonal 11/27, off-diagonal 8/27 and spectrum 1,1/9,1/9: gap 8/9.
The actual graph is three C9 components. Within each component the spectrum
is

    lambda_j = [11+16 cos(2pi j/9)]/27,        0<=j<9.

Its within-component gap is

    16/27 [1-cos(2pi/9)] < 8/9.                                  (9)

No floating approximation is needed. The checker proves that the

    (z-27)(z-3)^2 (z^3-33z²+171z+1293)^2.

This is a native **supplied move-chain** obstruction, not an identification

## 5. Certificate contract, verification, and next boundary

A reusable certificate supplies:

1. Every accepted state or a proved complete torsor chart; all literal
   shared owner/arc ports, native path/source/target records and guards.
2. For every edge/internal map, full-domain invertibility and an actual
   legal-move proof, including reverse and converse transport.
3. A spanning tree, tree transports, jointly based holonomy generators,
   and either their literal orbit partition or the translation row basis.
4. Exhaustiveness if claiming the components of an entire native move
   graph; otherwise the result is explicitly restricted to the supplied moves.
5. Fibre-uniform weights and detailed balance if using the spectral blocks.

The source->target map sends a retained state(v,a) to(v,S_v^(-1)a).
It preserves **exact supplied-edge connectivity** and guard/port records
through their authenticated transport. Forgetting the root coordinate
loses the obstruction; its required sidecar is the holonomy orbit or
separating characters (3). The cheapest decisive test is a connected base
with identity lift maps; the native decisive test is the C9 wrap above.

The dependency-free checker uses independent literal graph traversal and
root-orbit compilation, exact rational characteristic polynomials, and
actual tournament arcs. It tests all 216 AGL(1,3) triangle assignments;
all 432 AGL(2,3) chord holonomies with deterministically chosen internal
maps, and their 432 affine-gauge transforms; all 819 ordered pairs of
translation generators in dimensions1,2,3; all 34,992 affine character
identities in AGL(2,3), plus 729 exact translation-block basis entries; singular/disconnected/partial
input hostiles; and the 27 full native paths. Native code independently
rebuilds the inherited construction rather than accepting a prior count.
