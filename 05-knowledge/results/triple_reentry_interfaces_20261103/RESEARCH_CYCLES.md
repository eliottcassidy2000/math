## Cycle A — small determining probes versus simultaneous units

**Hypothesis tested:** perhaps the same size<=2 bank that determines the
quadratic response contains a unit whenever any cut does.

**Outcome:** false, with the smallest arbitrary-source witness at order five
and modulus255; for strong sources the first order is six and smallest
modulus1335. These minima include every positive modulus via exact prime
factor supports, not a numeric modulus cutoff.

**Why it fails:** CRT allows different primes to select different cuts;
interpolation allows signed linear combinations. Neither supplies one
common legal attachment. The surviving statement is exact response recovery
and primewise nonzero recovery. The repair is the prime-support transversal
compiler with names retained. Its antichains classify all moduli for a fixed
finite bank.

**Metanalysis:** compare the six live concepts. Reentry still needs a joint
source; F=U+S explains what valuations radicalization loses; the zero slot
and reflected ports show the same danger in deleting shared constraints;
Berggren's uniqueness is the ingredient absent from an arbitrary collection
of successful congruences. The next probe must allow both baseline polarities.
