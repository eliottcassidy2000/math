# Complete labelled oriented census, orders one through six

**Status: FINITE-EXACT**, independently checked as specified below. All graphs
are loopless; loops would not change the vertex-distinct path counts.
The isomorphism census is finite; see the main theory packet for the separate
all-order oriented-spectrum theorem and [CORE_TRANSPORT.md](CORE_TRANSPORT.md)
for exact all-order joint fibres over semicomplete H7 and H21.

## Pair conventions

Pairs `(i,j)` are in lexicographic order with `i<j`. The base-three code has
least-significant digit at the first pair. Digit 0 means `i->j` (raw `10`),
digit 1 means `j->i` (raw `01`), and digit 2 means empty in the oriented
interpretation, or both directions (raw `11`) in the semicomplete interpretation.
The `matrix` in witnesses.json is the **decoded ordinary adjacency matrix**,
not the raw `11=empty` encoding. This distinction is essential.

## Same raw array, different semantics

jointN.csv records the complete joint distribution `(H_oriented,H_semicomplete)`.
All 14,348,907 arrays at order six satisfy equal parity; equality of the actual
counts occurs exactly on the 32,768 tournaments. The analogous equality count
is `2^(n choose 2)` at every checked order. These are finite checks here;
any all-order proof belongs to the theory packet.

At n=5 a particularly clear dual-target witness is code 937. Oriented decoded
rows are `00100/10010/00011/00001/11000`, missing {0,3} and {1,2}, with H=7.
The same raw array under ordinary `11=both` semantics has H=21. Its four
tournament completions have H values 11,13,13,15. This is one class of 120
labelled arrays, not an identity between the targets.

All semicomplete H7 arrays decode to oriented H1 at every order, by
[core transport](CORE_TRANSPORT.md); the finite counts are 72, 720 and
6480 arrays at n=4,5,6 respectively. Semicomplete H21 arrays at n=5 decode
to oriented H1:960, H3:560, H5:120, H7:120. At n=6 they decode to
H1:17280, H3:11040, H5:1440, H7:1440, H15:1440.

Conversely n=5 oriented H7 arrays lift to semicomplete counts
H11:240, H15:240, H17:360, H19:360, H21:120, H23:120.
At n=6 oriented H7 lifts range from 11 to 173, while oriented H21 lifts range
from 35 to 67 (not every odd intermediate value is attained). Complete
conditional histograms are in target_decode_histograms.json. The extremal
difference is n!, attained by the all-empty/all-reciprocal raw array.

## Exact algorithm and independent checks

Start a table with one count at each directed path graph. A ternary upward
zeta transform adds the empty-coordinate entry to each of the two directed
entries, for each pair. The result counts each permutation exactly once in
every oriented graph containing its path arcs. The algorithm uses integers.

For a path-count polynomial, no monomial uses both directions of one pair.
Thus `f(both)=f(forward)+f(backward)-f(empty)`, with other pairs held fixed.
Applying this coordinate transformation to the completed oriented table gives
the full semicomplete table in the same raw index convention. This is an exact
multiaffine identity, not interpolation evidence. Complexity is O(m*3^m+n!*n)
with m=n(n-1)/2, apart from orbit classification.

verify.py independently uses subset endpoint DP on *every* array through n=5,
and on 3398 deterministic cases at n=6: all 396 target representatives,
extreme codes and 3000 seeded random samples (duplicates removed). It separately
enumerates all permutations for the target representatives. The full
semicomplete marginal at n=6 matches Session234's independently computed
histogram entry for entry. Thus the oriented full sweep is exhaustive, but
its second-algorithm check at order six is sampled, not exhaustive.
