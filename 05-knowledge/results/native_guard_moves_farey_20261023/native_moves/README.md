# Actual guarded native moves

Current proof and scope: [NATIVE_GUARDED_MOVES.md](NATIVE_GUARDED_MOVES.md).

This packet finds actual same-source, pinned, original-mod-eight-preserving
observer moves that change target class. It exhausts all 1,866 Hamiltonian
paths of four original order-eight sources, certifies the exact minimum
changed-clock budgets in 1,576 pinned fibres, and identifies a reusable
strong-four local swap mechanism.

Two pairs of source-specific moves also form balanced selections of native
black ports. Every selected path, its converse partner, pins, target and
frozen electrical phase is retained. Their higher dyadic debts and the
literal one-port obstruction to doubling are explicit. They are selected
subnetwork moves, not a replacement realization of the full native wiring.

Reproduce with `python -B check.py` or `python -O -B check.py` in this folder.
`receipt.json` retains the complete actual path universe, exact lower-budget
components, spanning trees, original file hashes and both paired rectangles.
