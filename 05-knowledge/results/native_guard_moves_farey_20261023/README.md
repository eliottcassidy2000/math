## 2. The original guard has two very different footprints

For a supplied native merged-network potential `x`, an actual path port has

    phi_x(T,P)=x_[T]-x_[K_P(T)] modulo 8,

where `K_P` preserves path arcs and reverses all other arcs. The network
guard is the sum of these actual owned phases at each node, with literal
edge multiplicities. It requires the marked character and authenticated
target owners; it is not a function of a vertex inside T alone.

[The guard theorem](guards/README.md) proves, arc by arc,

    K_(gP)(T)=g K_P(T),       phi_x(T,gP)=phi_x(T,P),

for every actual automorphism g of T. Thus the original phase exposes
**zero free coordinates** on the prior automorphism-orbit compiler. Its
kernel moves are genuinely safe. Converse with path reversal preserves
the merged phase; reversing an oriented complement port negates it.

Across different paths outside one orbit, the dependence is substantial.
For each of the four original switch sources, the exact minimum is **six
indexed owner clocks**, or **three indexed arc flags**, to determine even
the single original three-bit phase. Every five-clock bank has a saved
conflicting pair of actual Hamiltonian paths. The full fibres have
409, 407, 523 and 527 paths, and all eight phase residues occur in each.

There is a structural explanation for the thirteen optimal six-clock banks:
leave two holes at distance one or two. Swapping their two remaining owners
would reverse a required arc, so the entire path is uniquely determined.
This gives an all-size sufficient bank of n−2 owner clocks; the four
order-eight sources make it sharp for this phase and observation menu.
No adaptive-query lower bound is claimed.

## 4. An all-size block mechanism with a sharp cost

The [coupled-phase theorem](moves/COUPLED_PHASE_MOVES.md) uses actual regular
hosts built from an odd number t of odd cyclic cells of size q. Their
declared contiguous path family has binary differences
`d_i=a_(i+1)-a_i in {0,1}`. Pinning the first and last actual owners fixes
the total integer weight only modulo q.

One-cell moves are exactly `01 <-> 10`. They connect each fixed integer
weight layer and cannot cross between layers. A block

    0^q <-> 1^q

changes q−1 internal phases and preserves both pinned ends. These blocks
and swaps connect every unfiltered pinned fibre. The cost q−1 is sharp:
the cumulative integer difference must cross all nonzero residues before
it can complete one turn.

If an authenticated guard accepts whole integer-weight layers, the exact
cost between weights k and l is `(q-1)|k-l|/q`. Gaps in the accepted weights
therefore prescribe the smallest successful block. Shared interior pins
split the path into intervals; with a guard on their weight vector, the
cost is `(q-1)/q` times its L1 difference. Connectivity reduces exactly to
the corresponding finite weighted graph. An actual order-27 example
requires two intervals to change together, at sharp phase budget four.

The original electrical phase is known to factor through the **entire
difference word** in these hosts, by the common-rotation automorphism.
Factorization through weight alone has not been proved. The latter theorem
therefore remains conditional for that guard, and its larger regular hosts
are not covered by the order-eight electrical atlas.
