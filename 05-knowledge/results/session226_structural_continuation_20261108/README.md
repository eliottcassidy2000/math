   state, not the tournament. Four scalar graft observations recover that

   [Proof](graft/PROOF.md), [audit](graft_audit/AUDIT.md).

3. **Arbitrary physical seeds and nonunit intercepts.** For any finite physical

   the prior unit-intercept/single-seed scope, including zero and nonunit
   intercepts whenever a common odd residue gap exists. A five-line hostile
   shows why the unrestricted finite-line problem remains open.
   [Proof](root_descent/PROOF.md), [audit](structural_audit/AUDIT.md).

   limiting fixed-length two-J law, the full prime-valuation vector is strictly

   [Proof](modular/PROOF.md), [audit](modular_audit/AUDIT.md).
