# Arbitrary root-containing families with a pair child

The all-order theorem combines scalar strictness, hereditary profile equality, a positive marked-pair quartic, and a compressed singleton anchor. It distinguishes the original core from every root-containing original-module XOR target under the stated ordered-exterior hypothesis. For critical prime quotients, nontrivial children and one pair suffice; the fixed battery has at most quotient-order plus 18 queries.

The result is for the whole core or ordered SCC padding. Arbitrary strong outer contexts are explicitly excluded from this combined result. It is detection from one source, not reconstruction among all targets.

Normal and optimized checks agree: 260 original-module families, including 32 scalar-strict crossing cases and 114 cases in each equality branch. The verifier checks 5,829 distinct full augmented physical tournaments. Complete target rows, selected modules, masks and exact values are retained in both receipts. The C++ counts use exact 64-bit integers with an explicit order bound. The verifier imports only elementary primitives from ../arbitrary_third_root_family/verify.py and binds that dependency.
