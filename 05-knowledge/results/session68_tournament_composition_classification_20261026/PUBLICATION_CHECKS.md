# Final publication gates

All author-native files are preserved byte-for-byte in NATIVE_SOURCE_MANIFEST.json.
Independent proof acceptance is pinned by session68-audit/FINAL_INPUT_MANIFEST.json
and FINAL_ROOT_PROSE_ADDENDUM.md. The first-checkpoint audit remains unchanged.

The packet envelope verifies every file before replaying these six independent
or producer paths with isolated normal and optimized Python in a temporary copy:

1. Decorated-tree and complete ternary-fibre classification checker.
2. Literal line/endpoint flux checker.
3. Independently written orbit/BFS/Hamilton-word/path-cover checker.
4. Arithmetic necklace, field, converse and CRT checker.
5. Independent field/odometer/CRT checker.
6. Independent random-source recovery verifier, including the 24 original Git
   blobs and exact bounded excerpts. No sampled historical code is executed.

Both envelope modes compare exact bytes to the same frozen receipts. Six mutation
controls are rejected in both modes; unchanged controls are accepted. Normal and
optimized producer/audit receipt pairs remain separate native files.

Repository gates are python3 agents/check_docs.py and git diff --check. Portable
replay and mathematical proof acceptance are not claims of formal verification,
a complete all-order census, or independent certification of every historical
source. Publication parent/commit/tree/blob checks and exact-SHA CI queries are
recorded separately; empty reported check lists are not a passed CI result.

The author-native sample_dispositions.md retains its frozen trailing blank line.
A per-path whitespace attribute disables only blank-at-EOF for that file; all
other whitespace gates and all native hashes remain intact.
