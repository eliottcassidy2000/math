## A precise connection: composition keeps an affine cocycle

There is an algebraic common pattern, stronger than a shared numeral.
For composable affine maps, offsets obey

\[
 (a,b)\circ(c,d)=(ac,ad+b).                                      \tag{1}
\]

Discarding b retains the multiplier but forgets the action on a point.
The incoming [Collatz character theorem THM-4604](../../01-canon/theorems/THM-4604-collatz-words-are-the-reducible-locus-carries-are-the-extension-cocycle-and-traces-only-hear-the-tuning.md)
already identifies exactly this lost carry in triangular representations.
The new [composed source-weight theorem](collatz_composed_weight_floor_20261011.md)
uses it positively: when all affine fixed points lie in one interval,
the composite fixed point is a convex average. Weight distortion therefore
does not compound with word length. At r=6 it remains below1.565.

For an action P_g on functions and a chosen affine origin c, the
displacement Delta_g=P_g c-c obeys the parallel identity

\[
                 \Delta_{gh}=P_g\Delta_h+\Delta_g.                \tag{2}
\]

In the [new planar calculation](mobius_affine_source_return_20261011.md),
c=u/2 and the full source equation is P_g H-K=Delta_g. Testing only
P_g H in A forgets Delta_g and rejects a real return. Restoring it yields
the explicit involution(x,t)->(-1/x,x²t), preserving -(u+p)/2.
Adding rational fibre offsets reveals its full fibre-affine stabilizer:
a Klein four group of rational symplectic maps. On
Y²=X(X-1)(X+kappa), these are translations by the three nonzero points
of order two. This identification is proved by the chord formulas. A final primary-source
check of the known Legendre section group strengthens it: M5 classifies
all rational symplectic maps fixing this invariant, not only the
fibre-affine ones. The next source search must therefore change the
invariant rather than rediscover symmetries of this already closed family.

Thus (1) and (2) provide an actual shared composition law. The target
predicates are different: Collatz needs a native integer dependency with
a grounded endpoint; the planar problem needs an exact source-function
return. The algebra does not transport either predicate without its
additional data.

## Incoming seams and the missing information in the ROOT target

The [pants packet](pants_boundary_holonomy_20261011b.md) supplies the exact
sequence0->H¹(Gamma;F2)->H¹(Sigma_g;F2)->Z1(Gamma;F2)->0.
Compatible cuff bits leave g independent seam bits. The fibre is a
torsor until reference identifications are chosen. This is a precise
example of why “the right number of local data” need not give a decoder.

At genus two the missing seam class has two binary coordinates. The
elliptic two-torsion group above also has two. After choosing bases one
can map a(0,0)+b(1,0) on the elliptic curve to the two non-tree seam bits
(a,b); this preserves group addition. It is a **noncanonical linear
comparison**, not a geometric identification of those surfaces or a
Collatz certificate. Retaining the basis and origin is exactly its cost.

The [signed boundary compiler](plane_six_reframes_parity_20261011b.md)
retains named ports, parity paths, and actual lifts. An even path and an
odd path can each be valid fragments yet fail when glued. The
[integrated learner](plane_cycle_boundary_integration_20261011b.md)
responds by retaining a witnessed odd cycle and checks its negative
certificate against *every* finite label assignment. A finite list of
true cycles alone is not complete negative coverage.

For Collatz this suggests the following concrete proof-state contract:

* immutable integer source and native residue address;
* exact affine multiplier **and** offset, with actual common-future words;
* clock/credit account and a disjoint source-address convention;
* source-weight interval and its refinement error;
* an endpoint marked ROOT only after an independent terminal certificate.

These fields are partly already implemented in the repo. The next change
should add a previously unavailable guard or prove a positive endpoint
measurement, rather than compressing away an unresolved port. A failed
candidate should export the missing native transition or terminal as a
specific obligation. Unlike finite graph labellings, the integer source
universe is unbounded, so the learner's finite termination theorem does
not transfer automatically.

The incoming [crowding theorem](plane_girth_crowding_20261011b.md) makes
the scale issue equally concrete: at fixed positive point separation,
sufficiently high girth forces three colours by exponential tree growth
versus quadratic area. This is a scoped elementary theorem. It does not
give one threshold uniform over all separations. The analogous Collatz
question is whether a floor survives the growing source/refinement scale,
not merely whether every fixed finite computation succeeds.

certificate. The atomic source law retains every such integer explicitly.

The current actionable inequality is therefore the inherited compiler

\[
 V(m)\ge\frac{L_q-7/q^7}{\nu_6(m)},\qquad q>m,                    \tag{3}
\]

where L_q must be an independently justified lower bound for the weighted
ROOT score on that exact residue cell. The new bounded-distortion theorem
can transport such a bound through arbitrarily long native contracting
words. The missing step is producing L_q>7/q^7 at every source without
presupposing its ROOT certificate.
