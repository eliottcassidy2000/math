# Counting the rank 32 record family by its parameter height

## The family has arithmetic height exponent one twelfth

Use the exact L,p,q,D,E displayed on
[ICARM curve4239](https://elliptic-rank.icarm.cloud/curve/4239), with

    y^2+(Lx+B)y=x(x+D)(x+E),
    B=pE+qD+pq(L-p-q).

The certificate computes c4(T),c6(T) from the standard Weierstrass
identities. They have degrees8 and12 and are coprime over Q: their
reductions modulo101 have gcd1 and preserve both leading degrees.
The numerator and denominator of j have degree24 with no common factor.
In particular the j-map P1 -> P1 has degree24 and is nonconstant.

Let t=h/k, gcd(h,k)=1, k>0, and B0=max(|h|,k). Homogenizing the
coefficients with weights2,4,6,8,12 yields an integral model and homogeneous
invariants c4(h,k),c6(h,k) of degrees8,12. Because they have no common
projective zero, compactness on max(|h|,|k|)=1 gives

    max(|c4(h,k)|^3, |c6(h,k)|^2) comparable to B0^24.      (H1)

The comparison constants depend only on this fixed family. Passing to a
minimal integral model changes them by bounded factors. To see this,
homogeneous Bezout identities imply a constant C and degree N with
`C h^N,C k^N` in the ideal generated by the two homogeneous invariants.
Their gcd at a primitive pair therefore divides a fixed C. Any integral
model scale u satisfies u^4|c4 and u^6|c6, hence u is uniformly bounded.
This supplies the arithmetic minimalization guard in (H1).

There are order B0^2 reduced rational parameters of height at most B0.
Only finitely many are singular. A given j-value has at most24 parameters,
so identifying repeated j-values or Q-isomorphism classes changes the
count by a bounded factor. It follows that the number of distinct smooth
Q-isomorphism classes in this fixed family of minimal invariant height

    H=max(|c4_min|^3,|c6_min|^2) <= X

is **Theta(X^(1/12))**. This is a family count, not a count of rank32
specializations. The exceptional high-rank specialization is not assumed
typical, and no rank distribution is inferred from the finite census.

## A named section survives before any rank calculation

The definition of B supplies the polynomial section

    x=-pq,       y=p(pq-E).

Indeed `y+Lx+B=q(D-pq)`, so their product is
`-pq(E-pq)(D-pq)`, exactly the right side. This is an exact source-preserving
point identity. It alone proves neither its infinite order nor the
independence of the other sections needed for generic rank17. The
homogenized parameter and coordinate scales are part of the source.

## What the height exponent says about the rank heuristic

The [PPVW model](https://math.mit.edu/~poonen/papers/bounded-ranks.pdf)
balances ambient count exponent5/6 with rank-tail exponent(r-1)/24;
their conjectural cofinite threshold is21. This is not a universal rank
bound. The paper also warns that special families can carry additional
structure absent from the model.

The incoming Session97 note proposes a **conditional diagnostic**:
if a generic-rank-r0 family with count exponent alpha satisfied a shifted
tail `P(rank>=r0+s)=H^(-(s-1)/24+o(1))`, its critical total rank would be
`r0+1+24alpha`. We have now certified alpha=1/12 for the specified
fibration, so that expression becomes r0+3 (20 if r0=17).
This is not a new rank20 prediction: the shifted tail law is unproved
and cannot be imported from the ambient model without justification.
The calculation isolates exactly which arithmetic distribution input is
still missing. Neither20 nor21 acquires a tournament meaning from this
calculation.
