# Exponentially many cyclic parents survive a singleton selector

**PROVED, scoped.** We count regular cyclic parents inside an explicit wreath-product symmetry, classify them by a collective phase slope, and obtain an exponential owner-multiplicity obstruction. This strengthens the distinction between small chart intersections and a small cover. It does **not** prove a lower bound for every possible compressed representation or solve unrestricted tournament enumeration.

The common-bank and pair-closure inputs are the Session 113 composite theorem. The same-endpoint singleton selector is inherited from `phase_budget_shared_orbits_20261030/INTERSECTIONS.md`; it is not claimed anew.

## 1. Exact parent count and phase classes

Let r,m≥3 be odd, n=rm, g=gcd(r,m). On vertices (i,j) in Z/r × Z/m let

    W = C_m wr C_r,
    (t,z):(i,j) ↦ (i+t,j+z_i),
    s(z)=Σ_i z_i mod m.

Write R(W) for the set of regular cyclic subgroups of W, equivalently cyclic subgroups generated by an n-cycle. Then

    K = |R(W)| = φ(r)φ(m)m^(r−1)/φ(rm)
                = m^(r−1) φ(g)/g.                         (1)

**Proof.** If an element is an n-cycle, its outer action must traverse all r fibres, so gcd(t,r)=1. In that case its r-th power translates every fibre by s(z). It is an n-cycle exactly when gcd(s(z),m)=1. There are φ(r) outer choices and φ(m)m^(r−1) internal vectors with unit sum. Every regular cyclic subgroup has exactly φ(rm) n-cycle generators. Division proves the first formula. The second follows prime by prime from φ(r)φ(m)/φ(rm)=φ(g)/g. QED.

When g>1, each regular cyclic parent H has a well-defined slope

    ρ(H) = s(z)/t mod g ∈ (Z/g)^×,                        (2)

computed from any generator (t,z). A different generator is a k-th power with gcd(k,rm)=1; both t and s multiply by k, so their ratio is unchanged. Every slope occurs, with exactly

    |{H:ρ(H)=ρ}| = m^(r−1)/g.                            (3)

Indeed the unit reduction map (Z/m)^×→(Z/g)^× is surjective and every fibre has φ(m)/φ(g) elements. For each unit t there are that many permitted sums s with s=ρt mod g. Count the internal vectors and divide by φ(rm), as above. For g=1 there is one trivial slope class and (3) reads m^(r−1).

Thus the *number* of cyclic parents and the *collective phase* of a parent are separate retained quantities.

## 2. Each slope generates a different, pairwise-invisible group

For a unit slope ρ define

    G_ρ = {(t,z)∈W : s(z)−ρt=0 mod g}.                   (4)

This is an index-g subgroup. Its regular cyclic subgroups are exactly the parents of slope ρ, and those parents generate G_ρ.

To prove generation, choose a unit ν mod m lifting ρ. The vertex permutation hν:(i,j)↦(i,νj) normalizes W and sends s to νs. It carries the Session 113 group G_1, generated by the two regular cyclic parents <a>,<vav^−1>, to G_ρ. Both transported parents have slope ρ. Hence the subgroup generated by all parents of that slope contains G_ρ and is contained in it.

The same conjugation, or the unused-fibre correction proof, gives:

- G_ρ and W have identical orbits on all ordered t-tuples with t<r.
- Their orbits first differ at arity r when g>1.
- The two-closure of every G_ρ is W.
- Every G_ρ-invariant tournament is a W-invariant tournament.

Distinct slopes give distinct groups: an element with outer shift 1 and internal sum ν belongs precisely to the group with ρ=ν mod g. Therefore φ(g) different groups, each generated by many regular cyclic parents, have exactly the same tournament bank and all the same tuple orbits below arity r. This explicitly classifies the phase ambiguity in the regular-parent roster; it does not mean that those parent subgroups themselves have identical pair orbits.

## 3. Exact common native-chart intersection for the entire roster

A W-invariant tournament is S[R], with S and R arbitrary circulant tournaments on r and m labels. Its common bank has

    d=(r+m−2)/2

independent orientation coordinates. For a fixed named Hamilton path P, let q(P) be the number of outer or inner signed distance-pair coordinates touched by consecutive edges of P. Suppose those pins are consistent in this common bank, equivalently P is legal in at least one S[R].

For each H∈R(W), let C_H(P) be the native chart obtained by retaining P-legal sources in F_H and complementing all non-path edges. Then

    |⋂_(H∈R(W)) C_H(P)| = 2^(d−q(P)).                   (5)

Every point in this intersection has **exactly K parent owners within the specified roster R(W)**. It may have additional owners outside W; (1) is therefore a lower bound on unrestricted parent multiplicity.

**Proof.** All W-invariant sources are fixed by every H in the roster. Conversely the roster includes the original two parents <a>,<vav^−1>, whose common tournament bank is exactly the W-invariant bank. Thus the intersection over the entire roster is exactly that bank. A consistent path pins precisely q(P) independent coordinates. Every chart uses the same fixed bit-translation mask, which is injective and commutes with intersection. QED.

For the natural path P=(0,1,…,n−1), q(P)=1, so (5) is 2^(d−1). For the inherited alternating selector P*, with the same endpoints 0,n−1, q(P*)=d, so (5) is **one**. Both statements now hold simultaneously for all K parent owners, not merely the original two.

In particular choose m=3 and r=3^k (k≥1). Then

    n=3r,       K=2·3^(r−2)=2·3^(n/3−2).                (6)

The singleton selected output has exponentially many parent owners. Reducing a common intersection to one point has not reduced the number of parent records describing that point. Distinct parent owners need not give distinct chart support sets; the result concerns named parent ownership, not a count of distinct supports or unlabeled tournaments.

At such a point, summing the K parent indicators gives K. The correct owner correction is K−1. Subtracting one for each parent pair instead subtracts binom(K,2), overcorrecting by

    binom(K,2)−(K−1)=(K−1)(K−2)/2.                     (7)

This is an explicit all-size obstruction to treating pair-incidence counts as owner corrections. It does not say that all pairwise chart intersections in the roster are singletons; (5) is the intersection of the entire roster.

## 4. A source-coverage tradeoff, not an output-coverage assertion

Suppose a family of consistent paths is intended to cover all 2^d source tournaments in this W-bank by their legal-source sets. If every chosen path pins at least d−c common coordinates, each such set contains at most 2^c sources. Thus at least

    2^(d−c)

paths are required. In particular all singleton selectors require at least 2^d source records to cover the complete bank. If the intended source class first fixes the natural path orientation, the corresponding bound is 2^(d−1−c) when positive.

This elementary counting bound applies to that explicit source-cover representation. Different paths use different complement masks, so it must not be silently reinterpreted as a bound on coverage of a fixed output family. Nor does it prohibit describing the entire product bank compactly by its d orientation bits, or grouping many parent owners symbolically using W and (1).
