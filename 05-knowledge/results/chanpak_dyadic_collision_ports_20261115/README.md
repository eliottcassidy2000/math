## Reproducibility

Run `python dyadic.py`, `python verify_collisions.py`, `python verify_ports.py`, and
`g++ -O3 -std=c++17 verify_slots.cpp -o /tmp/check_slots && /tmp/check_slots`.
The scripts are exact digit, affine-equation, tournament and path-projection controls. The all-order bounds follow from the structural proofs rather than extrapolation from these finite checks. The [prior collision criterion](../chanpak_near_floor_crossing_20261115/DENSITY.md) states the target constant for the full absolute second moment.
