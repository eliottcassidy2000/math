# Strong reusable bit cubes after the converse quotient

Use the inherited [equal-profile bit blocks](../session168_computational_structures_20261103/turing/NOTE.md): the two order-five lexicographic edge masks 8 and 10, with bit 1 the forward direction. Call them \(B_0,B_1\). Both are strong, they are nonisomorphic and each is self-converse. They differ only at the arc \(02\) and have the same full ordered-slot profile \(f(q)=q^5+6q^3+2q\). They share the path \(0,4,3,2,1\), which does not use \(02\).

For a nonempty tape word \(w=w_1\cdots w_K\), let \(U_w=C_3\oplus B_{w_1}\oplus\cdots\oplus B_{w_K}\), ordinary ordinal sum. The left directed-triangle sentinel is distinguishable by SCC order from any data bit. Form \(T_w=C_3[U_w,1,1]\), i.e. \(U_w\to a\to b\to U_w\). This is strong, since the quotient is a directed triangle, including for vertices in the same expanded part. A common Hamilton chart is \(a,b\) followed by a fixed spanning path in each ordered component of \(U_w\); data toggles change only free nonspine bits.

The uniform profile is exact. Independent slot cutting gives \(Z_{U_w}(q)=Z_{C_3}(q)f(q)^K\). If the outer \(a,b\) are in one designated slot in order \(a,b\), there are \(q Z_{U_w}(q+1)\) covers. In order \(b,a\) the intervening \(U_w\)-piece is nonempty, giving \(q(Z_{U_w}(q)-Z_{U_w}(q-1))\). Their occupying distinct slots gives \(q(q-1)Z_{U_w}(q)\). Hence
\[
 Z_{T_w}(q)=q[Z_{U_w}(q+1)+qZ_{U_w}(q)-Z_{U_w}(q-1)],
 \qquad H(T_w)=3\cdot9^K+12\cdot84^K ,
\]
independent of all payload bits.

The full cube is **induced even in the converse-merged ordinary single-arc graph**. The unique proper module of size \(|U_w|\) is \(U_w\), so it is recognizable: a module meeting \(U_w\) and an outside vertex projects to a nonsingleton module of the prime three-vertex quotient, so must include both external vertices, and any omitted \(u\in U_w\) would distinguish them. The only SCC of size three inside \(U_w\) sits at the left. In the converse it sits at the right; \(K\ge1\) prevents a collision between forward family and reversed family. Within a fixed orientation type, SCC order reads the entire word.

For inducedness, flipping the outside pair makes the tournament nonstrong. Flipping one outside contact destroys the existence of any module of size \(|U_w|\): if a proposed module contains exactly one outside vertex, the other distinguishes it from the old vertices (apart from the exceptional new contact, which can affect only one old vertex); if it contains both, it omits two old vertices, at least one of which distinguishes the outside pair; if it contains neither, it is \(U_w\) itself and fails uniformity. If instead a flip stays inside \(U_w\), it either changes one marked SCC locally, or a cross flip merges an interval of old SCCs, which cannot leave the same multiset of component sizes. An internal flip cannot move the sentinel to the opposite end, for it either leaves the unique left size-three component present, creates extra components, or destroys it and cannot simultaneously create a new one at the other end. Thus the only edges between family classes are one-bit flips.

Allow inserting a fresh blank block at the right end of, or immediately after the left sentinel in, \(U_w\); old arcs need not move or change. Under a **supplied Turing controller**, a bounded number of bit blocks can encode each cell's alphabet symbol and optional head/state tag. A transition changes a bounded number of bits and can append one blank cell when the head crosses the current boundary. This is an unbounded strong tournament tape with actual named moves; at any fixed capacity all payloads have identical slot profile. For a fixed universal controller the explicitly defined, growing configuration reachability can therefore express halting. This is not a claim the native complement/axis-flip metagraph is an autonomous Turing machine: those specific moves are not the single-bit operations above, and they preserve order. At a fixed order any finite computable transition rule on tilings, with no external unbounded store, has decidable reachability by enumerating its finite state graph. Gluing in an external controller or permitting graph growth changes the problem.
