# Finite checks and proof boundaries

The executable `check_finite_cases.py` uses exact integer and rational arithmetic and the Python standard library. It is a sanity check of the arithmetic specialization, not a formal verification of the measure-theoretic proofs.

Run:

    python check_finite_cases.py

Observed output:

    PASS: 92 reduced rational pairs, denominators 1 through 12.
    Pinned pi/3 defect optima and common-frequency compatibility agree.
    gamma/pi=2/3; |H|=6; min(D_pi/3 + D_gamma)=2/3; one minimizing pair=(1/3, 1/3)
    gamma/pi=1/2; |H|=12; min(D_pi/3 + D_gamma)=1/3; one minimizing pair=(1/3, 0)
    gamma/pi=1/3; |H|=6; min(D_pi/3 + D_gamma)=0; one minimizing pair=(0, 0)
    gamma/pi=1/6; |H|=12; min(D_pi/3 + D_gamma)=1/2; one minimizing pair=(0, 1/2)

For each reduced fraction p/q with 0≤p<2q and 1≤q≤12, the checker:

1. Builds the finite subgroup generated by π/3 and pπ/q.
2. Checks all frequency residues for the common-frequency condition.
3. Enumerates every sign pattern satisfying π/3-antiperiodicity, by enumerating the independent signs on its six-element orbits.
4. Verifies the sharp constrained minimum 0 in the odd/odd case and gcd(3,q)/q otherwise.

The four displayed unrestricted examples enumerate every signing, up to global color reversal, in their finite Cayley multigraphs. They illustrate why a general maximum-cut formula is more precise than any one arbitrarily selected odd-walk bound.

The accompanying proof does not rely on these finite checks. It also does not verify the source blueprint's global results or its formal proof claims, and it does not assert a numerical lower bound for monochromatic-plane placement density.
