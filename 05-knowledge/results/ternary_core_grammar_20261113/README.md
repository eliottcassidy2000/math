# Ternary core grammar, neutral preparation, and the omissions 7 and 21

**PROVED scoped / CITED / FINITE-EXACT, 13 November 2026. Chan–Pak OPEN.**

The session replaces a finite bank of dyadic rays by a complete grammar of
rooted strong cores, and supplies a concrete H-neutral change that enters
an indefinitely repeatable marked construction. It does not prove that
every admissible odd target can be selected by that grammar.

* [Unbounded grammar and rooted count descent](GRAMMAR.md): every nontrivial
  strong tournament is either nearly transitive or has a nearly transitive
  ear that can be removed while keeping a specified physical root. The
  remaining core has at most one third of the original H count. This is a
  deduction from Busch's structural and merge lemmas, with a constructive
  reassociation proof. Forward entry is automatic from strongness; exact
  target selection is still missing.
* [The two exclusions and the role of three](EXCLUSIONS.md): SCC products,
  atomic counts and merge surplus give a common proof of the known omissions.
  The count21 question reduces to two displayed 8×8 tables. Multiplication
  by3, a triangle attachment's 3H+surplus, the two-birth response3H+2(F−H),
  and a three-bin exponential mode are distinguished combinatorially.
* [Neutral preparation with proved infinite entry](NEUTRAL.md): a physical
  core replacement keeps count25, its named root and an incoming port, but
  changes (h,s,q,F) from(25,5,5,25) to(25,3,3,27). It enters count79 and then
  the inherited renewal79→4769→289487→17572865→…, with every endpoint guard
  proved. An ordinal suffix gives a uniform multiplicative-context version.

The complete triangle-attachment probe evaluated **10,014,992 cross
matrices** over all **2,618 rooted strong cores through order seven**.
It exposes all-order operation obstructions at source counts below45:
for example, no strong count15 source can reach47 or49 by a shared-vertex
triangle attachment, even after arbitrary H-preserving replacement.
These are failures of a proposed operation, not forbidden Hamilton counts.

A more flexible triangle-ear grammar does have explicit certificates for
**every odd count from9 through2881 except21**. It changes the parent count
as well as its core when necessary. Its all-order value completeness is a
named open hypothesis, and the certificates do not set a new coverage record.

The implementation also verifies the root-preserving atomic parse on every
rooted strong class through seven. [Audit and reproduction](AUDIT.md) retain
the source universe, independent controls, known overlaps and limitations.

The exact missing theorem is a target-dependent selection of a smaller
realizable parent, an atom and a cross matrix producing the requested full
count. Neither a complete grammar for supplied graphs nor an infinite
renewal sequence proves that selector. The earlier473 repairs and universal
odd-seed coverage remain open.
