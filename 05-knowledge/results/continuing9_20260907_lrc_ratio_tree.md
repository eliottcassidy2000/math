## 2. Exact prescribed-clock realization criterion

Let `T` be a connected labelled tree on `N>=2` vertices. Give each directed
edge `i->j` a positive rational ratio `r_ij`, meaning `u_j/u_i=r_ij`.
Choose a root and define positive rational path products `R_root=1` and
`R_j/R_i=r_ij`. Let `U*` be the gcd-one positive integer normalization of `R`.
It is unique by the inherited projective reconstruction.

Fix a positive integer clock `t` and proposed positive divisors `d_i|t`.
For every prime `p|t`, put

```
k_p=v_p(t),  h_i(p)=v_p(R_i),  m_p=min_i h_i(p).
```

**Criterion.** A primitive row of distinct positive integers realizing all
the directed ratios and satisfying `gcd(t,u_i)=d_i` exists if and only if

```
R_i are pairwise distinct, and
min(k_p,h_i(p)-m_p)=v_p(d_i)  for every p|t and every i.       (1)
```

When it exists it is exactly `U*`. Indeed the primitive normalization has
prime valuations `h_i(p)-min_j h_j(p)` at every prime, including primes not
dividing `t`; clipping at `k_p` is exactly the gcd operation. This proves both
directions. Primes not dividing the clock affect the actual row, extra ratios,
and physical phase, but impose no additional clock-margin equations.

Equivalently, suppose `gcd(d)=1`, write `b_i=v_p(d_i)`, and choose an anchor
`a` with `b_a=0`. Then the p-condition is

```
h_i-h_a=b_i       if b_i<k_p,
h_i-h_a>=k_p      if b_i=k_p.                              (2)
```

The first condition compares every pair of unsaturated anchors through its
entire tree path. Local edge compatibility tests only the corresponding
one-edge conditions. If all vertices are unsaturated for a prime, local
compatibility propagates correctly along the tree. Saturated vertices are
the only place this prime can hide an inconsistency.

**Small hostile.** At `t=2`, prescribe margins `(1,2,1)` and tree ratios
`u_1:u_2=1:4`, `u_2:u_3=2:3`. Both primitive pairs belong to the strict atlas
(their sums are5), and both local margin tests pass. The unique primitive
row is `(1,4,6)`, whose clock margins are `(1,2,2)`. Its valuation path goes
`0,2,1`; it cannot connect two prescribed2-free endpoints. This is a
three-vertex obstruction; one edge alone cannot display it.
Distinctness is separate: the ratios `1:2` and `2:1` can reconstruct equal
endpoint speeds even when their clock data pass.

A consistent connected ratio graph has the same criterion after requiring
the product of ratios around every cycle to be1. This is an elementary
extension, not a new circle-phase or graph-saturation theorem.
