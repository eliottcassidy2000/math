# Recursive host births and symmetry sections

[Proof](PROOF.md) · [Standalone verifier](verify.py) · [Exact replay](REPLAY.json)

The complete ordinal/C3 family has an exact first-appearance grammar inside
balanced ternary tournament towers. Its embedding depth is an **alphabetic
minimax tree cost**, not merely size or an unordered list of component costs. A one-register greedy dyadic allocator computes that exact cost, without a cubic split search.
For example C3→1→1 first embeds at tower order9, but 1→C3→1 needs order27.
The complete depth3 host has3047 nonempty induced types,3027 newly appearing
there; the recursive rule, not this census, supplies every later depth.

A symmetry-refined cyclic-necklace recursion classifies every rooted
one-vertex extension of these towers. Every root-stabilizer exponent from0
to(3^e−1)/2 occurs. Occupied-ancestor sections give an exact pointwise-
stabilizer floor and hence universal divisibility for arbitrary multi-vertex
extensions, even after their visible symmetry is destroyed. An analogous
prime-layer subgroup rule works at every odd prime.

The inherited modular species, tower, and endpoint-action mechanism are
credited in the proof. None of these results classifies all prime tournament
quotients or proves Chan–Pak. Independent session review is recorded by the
session coordinator.
