# Conversed-child anchor integration

`PROOF.md` explicitly generalizes an already inherited compressed exposed-anchor argument to any nonempty conversed child, including a singleton, through every fixed ambient. Its genuinely new use is to remove the converse ambiguity of Session189 transitive-child distance reconstruction under full-response equality. The remaining all-transitive-child candidate is quotient-only converse; that candidate is not excluded here.

`controls.py` builds and checks four named source/target/whole-core-converse comparisons in a strongly connected cyclic ambient. Their distinguished children are a singleton, a cyclic triple, a transitive five-set, and a prime five-set. All physical masks, all graph incidences and the distinction between target and restored converse remain in `controls.json`. The twelve complete response polynomials in `bank.json` retain all40,449 canonical coefficients, including every named cubic and quartic zero. These support28 literal three-graph query comparisons.

Reproduce using already available tools:

    python controls.py prepare > prepare.stdout
    g++ -O3 -std=c++17 bank.cpp -o /tmp/s189_anchor_bank
    /tmp/s189_anchor_bank regenerated.json < graphs.txt
    cmp bank.json regenerated.json
    python controls.py > normal.json
    python -O controls.py > optimized.json
    cmp normal.json optimized.json

The core proof is inherited and is cited precisely; this is not presented as a new parity method. The actual-query restoration is exact over the integers and precedes using the whole-converse cubic identity, so no arbitrary-comparison quartics are discarded.

Only files named in `RELEASE_FILES.json` belong to this frozen packet. Other exploratory mixed-quartic and flat-root files in the working directory are separate work and are not approved by this packet.
