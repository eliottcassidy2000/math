# Prime-seven profile and singleton-position certificate

This packet proves arbitrary-child fixed-ambient prime-seven quotient-converse separation except for exactly one family: the carousel `(14,28,56,112,97,67,7)` with seven even children of order at least four. Its standalone theorem is `PROOF.md`. A separately reviewed companion modulo-sixteen theorem is needed for that last family; it is not inferred from this packet's local data.

The complete named physical coefficient banks, all zero/cubic/quartic coordinates, exact run channels, cycle safety data, quotient labels, singleton-position records, and full type witnesses are retained. Do not replace these data files by summaries or hashes.

Run `python3 verify.py > normal.json` and `python3 -O verify.py > optimized.json`, then compare. Both frozen receipts currently PASS and are byte-identical. The verifier compiles five standard C++17 programs into a temporary directory, uses only standard Python, regenerates every data artifact, independently cross-checks all mathematical counts, and compares complete bytes with the frozen data. It makes no network requests and installs nothing.

The complete labeled quotient census has2,097,152 tournaments and973,680 prime labels in197 disjoint orbits. There are4,864 endpoint-zero singleton-position records,242,208 independently checked integer run coordinates,3,990 independently checked anchor primitives,65,536 nontrivial type records, and262,144 direct full-cube Hamilton/cycle query checks. The odd-total proof restricts actual query values by exact cycle parity, not polynomial coefficient positions.

`PUBLICATION_FILES.json` is the frozen publication allowlist. Compiler binaries, raw intermediate model inputs, exploratory `explore.py`, and progress logs are excluded. Large data may be losslessly compressed for publication only with a checked reassembler that restores the exact filenames and bytes before `verify.py` runs.

The independent review is a separate packet. The theorem is not unrestricted named-response injectivity, and its original-module highest-node consequence requires its own reviewed integration.
