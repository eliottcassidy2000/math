# Joint review and data restoration

The [independent review](../prime7_audit/REVIEW.md) approves the profile and
modulo-sixteen packets at their stated scopes. Together they cover prime
seven-name quotient converse separation with arbitrary nonempty children,
profile-preserving replacements, and every fixed ambient. This is not
unrestricted named-response injectivity or separation of arbitrary quotient
pairs. Original-module highest-node integration is a separate theorem.

All complete data, including named cubic/quartic zeros and the full physical
label ownership table, are retained losslessly in `../ARCHIVES_CP04.json`.
From the parent directory restore them before running any verifier:

    python3 restore_receipts.py ARCHIVES_CP04.json

Then follow each producer and audit's reproduction instructions. No binary
executable is included; the reproducible verifiers use the existing C++17
compiler and Python standard library without installing software.
