# Independent prime-eight audit

Approved proof scope and exact checks are in `REVIEW.md`. Three independent programs each have byte-identical normal/optimized PASS receipts. Complete canonical orbit arrays, joint endpoint matrices, residual anchor arrays, physical graphs and literal counts are retained.

Run `audit.py`, `physical_audit.py` and `label_audit.py` normally and with optimized Python. Large JSON artifacts may be losslessly archived only if a checked reassembler restores the exact filenames and bytes. The publication allowlist is `PUBLICATION_FILES.json`.
