## 1. Transfer and rank

Multiplying a source batch weight by 2^(r*(m+k)) gives precisely the source
moment W_(ell*k+r), with the remaining factor in M4. Its index is available:
ell*k+r<=ell*k+S'=S-ell*e<=S. A terminal transition from S>0 has k>=1;
the apparently missing W_0 is therefore never requested. At S=0 the
separate terminal scalar is retained. Negative exponents are legitimate
positive rational factors, as the implementation's Fraction arithmetic
requires.

The Vandermonde rank min(S,h) is exact over Q. All-singleton future
completions with r actual cycles and S-r excess units read every W_r,
1<=r<=S, with nonzero intrinsic coefficients. Thus the minimality claim
applies to every individual future aggregate, not only the final total.
The admissible common-defect family and the 8,-6,1 horizon hostile satisfy
their stated hypotheses.

## 2. The sign invariant makes adaptive support monotone

For a literal prefix with processed lengths d, multiplicities k_d and
excesses e_d, its only sign is (-1)^(sum e_d). Meanwhile

    u-m=sum(d-1)*k_d+sum d*e_d = sum e_d modulo 2.

All lengths are odd. Thus M8 holds, including batches with zero excess
and rational positive factors. At fixed u,m, every contribution has the
same nonzero sign and cannot cancel another contribution there.

At a nonterminal stage the retained response includes d=1, so f(1)=m.
Given S,D,m, every old response coordinate is reconstructed as
f(d)=d*m-D(d). Consequently old scalar states in one (S,D) fibre are in
bijection with its supported cycle counts m. There is no additional
old-state multiplicity hidden inside the h used in the storage theorem.

Once a bank has h>S and becomes dense, any valid batch shifts its semantic
support injectively by m->m+k and multiplies every supported coefficient
by a nonzero factor. When different contributions meet at the same
destination m, M8 gives the same destination sign. They cannot delete any
of that support. Hence h_destination>=h_parent>S_parent>=S_destination.
This proves that a dense bank never requires sparse reconstruction.
Sparse-only mergers are converted exactly when their support exceeds the
current horizon. Each nonterminal key therefore uses exactly min(S,h)
scalar coordinates, bounded by the old h scalar states.

The zero-vector convention is necessary for this particular support proof:
an all-zero moment vector may still represent a nonempty signed support.
The adaptive code retains such a nonterminal key, while terminal zero
scalars are removed in both methods. Safe zero-vector pruning is a
different continuation-kernel optimization, correctly excluded from the
claimed literal support correspondence. The sign argument concerns the
actual initialized recurrence; arbitrary externally supplied signed banks
need not satisfy M8.

## 4. Evaluation quotient audit

In `EVALUATION_QUOTIENT.md`, the moments are exactly the values of
H(Y)=sum_m w_m Y^m at the distinct nodes 2,...,2^S. Its observation kernel
is the ideal generated by A_S=product_(r=1)^S(Y-2^r). The batch identity
H'(Y)=c*Y^k*H(2^(ell*k)*Y) gives M4 by evaluation. Every destination node
maps to a retained source node, proving the stated polynomial divisibility
and that the map descends to the quotient. The terminal evaluation at
Y=1 is also available because a nonzero completing batch has k>=1.

This is a product of rational fields, whereas the cyclic Hasse algebra
in matching characteristic is local and nilpotent. The note correctly
keeps these distinct. Its warning about reducing denominators modulo a
coefficient prime is necessary and correct; repeated modular nodes alone
do not define a valid integer-counting recurrence.

## 5. Reproduction of the independent prefix check

Run from this directory, optionally with `python -O`:

    python -c "from pathlib import Path; t=Path('INDEPENDENT_REVIEW.md').read_text(); exec(t.split(chr(96)*3+'python\n')[1].split(chr(96)*3)[0])"

```python
from collections import defaultdict
from fractions import Fraction
from itertools import combinations
from math import comb,factorial,gcd,prod
import runpy,json
producer=runpy.run_path('check.py')
def need(x,m):
    if not x:raise RuntimeError(m)
def weight(H):
    cycles=[d for d,k,e in H for _ in range(k)]
    exponent=sum((d-1)//2 for d in cycles)+sum(gcd(a,b) for a,b in combinations(cycles,2))
    numerator=(-1)**sum(e for d,k,e in H)*(1<<exponent)*prod(comb(k+e-1,e) for d,k,e in H)
    denominator=prod(d**k*factorial(k) for d,k,e in H)
    return cycles,Fraction(numerator,denominator)
checks=0;prefixes=0;samples=[]
for n in range(1,19):
    histories=[()];expected=[]
    for ell in range(n if n%2 else n-1,0,-2):
        bank=defaultdict(lambda:defaultdict(Fraction));terminal=Fraction(0)
        for H in histories:
            s=n-sum(d*(k+e) for d,k,e in H);cycles,w=weight(H);m=len(cycles);prefixes+=1
            need((w>0)==((n-s-m)%2==0),'literal prefix sign')
            if s==0:terminal+=w;continue
            ds=tuple(d*m-sum(gcd(c,d) for c in cycles) for d in range(1,min(ell,s)+1,2))
            bank[(s,ds)][m]+=w
        need(all(w for supports in bank.values() for w in supports.values()),'same-count cancellation')
        cells=sum(min(s,len(support)) for (s,ds),support in bank.items())+int(bool(terminal))
        expected.append((ell,cells))
        following=[]
        for H in histories:
            s=n-sum(d*(k+e) for d,k,e in H)
            for k in range(s//ell+1):
                for e in (range((s-ell*k)//ell+1) if k else (0,)):
                    rest=s-ell*(k+e)
                    if ell==1 and rest:continue
                    following.append(H+((ell,k,e),) if k else H)
        histories=following
    value,data=producer['adaptive_target'](n)
    observed=[(r['length'],r['scalar_cells']) for r in data['rows']]
    need(observed==expected,('exact adaptive min(S,h)',n,observed,expected))
    need(sum((weight(H)[1] for H in histories),Fraction(0))==value,('literal terminal coefficient',n))
    checks+=len(expected)
    if n in (6,10,14,18):samples.append((n,sum(c for ell,c in expected)))
print(json.dumps({'status':'PASS','stage_checks':checks,'literal_prefix_records':prefixes,
                  'adaptive_scalar_totals':samples},indent=2))
```
