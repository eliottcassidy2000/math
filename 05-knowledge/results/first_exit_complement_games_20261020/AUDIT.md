## Proof checks

* `A=3^m` is an integer coefficient; `A/d` is the slope. `C/d` is
  positive charge, not the full carry `B/d`. The actual shifted endpoint
  is `(A(n-1)+A+B-d)/d`. The reset identity therefore has numerator
  `C-A-B+d`; direct orbit and suffix implementations agree.
* The fixed-(m,K) maximizer of C is proved by a strict swap inequality
  and then the number of ones. The only global equality is `(4,1,1,1,1)`.
  It is **not** a first-exit extremal. No trajectory is reordered.
* The all-length tail uses the explicit inherited BC1 tail, including
  its cited logarithmic input. Finite m1..64 calculations alone would
  not establish the all-length claim.
* The analytic cone imports Ellison's actual exceptional-exponent list;
  m>=19 puts the least clock exponent beyond every exception. Every
  elementary constant is bounded rationally. The logarithmic depth
  assumption is an assumption, not a result about all sources.
* Exact-cylinder refinement retains modulus2d and intersects the source
  interval before testing the least member. Payment is increasing in n
  once d>A. The infinite exponent tail follows from an inequality at
  the least source, not an empirical truncation.
* The separate coarse proof stops at coefficient crossing. Its last
  exponent is at least2, so extra terminal divisions only improve the
  positive bound. Paid crossing proves actual first exit there; this
  order of implications avoids assuming Terras equality.
* Graph games use a freely chosen starting vertex and allow repeat
  edges in a spanning walk. The all-edge Euler problem is separated.
  The minimum-edge equality argument invokes the degree-sum lemma only
  at a nonedge of the available graph. The n7 family retains named
  separators and shared leaf neighbours.
* All171 geometric distances are exact in a four-dimensional rational
  algebra. A second derivation uses the rational and irrational parts
  of the cross-distance formula over Q(sqrt(-3)). Both yield precisely
  one new edge between the hubs. A full four-colouring is retained.
* The palette kernel subtracts intersection, not an independent-colour
  expectation. All singleton masks are realizable. Its indefinite
  signature is a property of this boundary kernel, not ROOT transport.
