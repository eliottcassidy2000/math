# From modular fork selection toward absolute targets

**PROVED scoped / FINITE-EXACT; Chan–Pak remains open.**

- [Balanced windows](BALANCED-WINDOWS.md): the modular selector and real height can be controlled separately. For any fixed odd modulus, compatible target readings, chosen order parity, and sufficiently large \(X\), a strong apex tournament in that residue class hits \(H=X+O_m(\sqrt X)\). For the factor-seven parent, center or either marked exit there is a corresponding physical window with error \(O_m(X^{1-\frac12\log_3(3/2)})\). Both are honest shrinking relative windows, not residue-only statements.
- [Heegner and Ramanujan targets](HEEGNER-TARGETS.md): the five register lengths \(1,2,5,8,20\) admit a marked decomposition of the nine-vertex arc lattice; they are not independent Boolean dimensions for synthesis. A balanced three-run apex gives the exact family \(H=2^{2a+b+2}-(2^b-1)\) and an absolute inverse. It gives \(11^2\) on nine vertices. The [signed seven-core shell](MERSENNE-RAIL.md) realizes every \(2^q-7\) for \(q\ge4\) strongly, removing the parity restriction of the symmetric apex word. The nearest odd integer to \(e^{\pi\sqrt{163}}\) is an exact 44-vertex ordinal count; a second construction above it gives a numerical straddle.
- [Nine-vertex registers](NINE-REGISTERS.md): the exact doubling clock cannot be a single relabelling of nine vertices; the twelve affine-line grammar has no single-arc \(\pm2\) exits. All fixed nine-port transitive inflation charts together give only \(O((\log X)^9)\) heights through \(X\).
- [Signed absolute bridge](SIGNED-BRIDGE.md): a larger restricted exact inverse using inherited signed shells and dyadic fillers, and a same-arc bridge between two prime counts just above six million. Separately even the modularly rich two-move \(P,W\) controller gives only \(X^{o(1)}\) exact heights from fixed seeds.

## The remaining exact step

For an odd target \(N\), a witness with \(H\equiv N\bmod m\) at odd \(m\) would be exact if \(|H-N|<2m\), since the difference is even. The balanced result now controls archimedean size and residues **on the same physical filler**, but its error and guard-length constants depend on the fixed modulus. They do not justify increasing \(m\) with \(N\) until the exact threshold. The order-nine bound illustrates the missing argument precisely: a pre-existing in-range fixed-order witness can be recognized by residues, but the modular constructor can increase the order. The next task is either a joint modulus/height bound or actual local repairs that fill the remaining congruent window. The explicit exact families here are test charts for such a repair, not a coverage claim.
