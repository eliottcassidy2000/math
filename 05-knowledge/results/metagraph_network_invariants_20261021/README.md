    python3 -B probe.py
    python3 -B hostile.py
    python3 -B voltage_audit.py
    python3 -B replay_review.py
    python3 -B replay_review.py --optimized
    python3 -B replay_review.py --negative

unchanged independently audited code with explicit input paths. Its negative
mode recreates only the temporary historical layout expected by the unchanged
mutation harness; it never changes producer or repository inputs.
