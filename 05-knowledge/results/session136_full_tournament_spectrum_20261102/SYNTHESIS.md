# What the new frameworks change

The target is still the exact integer spectrum S={H(T)}. The conjecture S=positive odds minus{7,21} remains OPEN. The session separates several questions that previously shared the word "spectrum".

## 1. Local arithmetic is already complete in a restricted family

Strong one-apex tournaments hit every compatible residue modulo every modulus, with one actual graph satisfying simultaneous CRT requirements. Yet this family misses13 exactly. Thus modular universality is not a step that remains to be guessed from small tables: it has a constructive proof here, together with an explicit failure of the local-to-exact inference.

The root interface checker gives concrete witnesses: counts2007,2013,1021 agree modulo1000 with7,13,21 respectively. Their binary recipes produce strong tournaments of orders13,13,12. These examples are not the all-moduli proof.

Next useful obligation: obtain magnitude-controlled target constructors, rather than additional residue coverage. A congruence argument with graph structure or a bound on H remains potentially useful; the theorem excludes only filters on H alone.

## 2. The right substitution state is contextual, not scalar

A tournament inserted as a homogeneous block can be visited several times by a global path. Its number of spanning path covers is the information needed to compose. Contexts with m exterior vertices see exactly the first floor(m/2)+1 path-cover coordinates, and the first differing coordinate c needs exactly2c-2 exterior vertices to detect.

For exact counts there are already infinitely many distinguishable states with H=1: different transitive module sizes give different values2^n+1 inside a directed triangle. For capped counts, however, interacting modules of order n with2^n+1>B saturate. A finite algebra therefore computes all expression depths for any finite substitution grammar.

This turns "more complicated construction" into a precise resource: the least maximum quotient order required to realize h. The audited finite algebras certify widths5 for13 and19, and width6 for31. Adding a small graph as an initial seed is not the same as allowing it as an operation with arbitrary blocks substituted into its vertices.

Next useful obligation: determine whether the necessary quotient width stays bounded across all attained values, and whether a fixed finite quotient bank can realize every permitted odd value. Neither assertion is proved by a cap127 fixed point.

## 3. Insertion minima have geometry, and symmetry sharpens it

The ear response is exactly H+2 times a cut in a canonical positive directed network. Strict uncrossing forces low-response cuts to have compatible splits. Consequently a single parent can have large internal holes near its minimum even when its arithmetic response lattice is saturated.

Vertex-transitive symmetry restricts these low cuts to blocks of imprimitivity. Primitive symmetry leaves only singleton/complement cuts. For circulant parents the minimum over exponentially many cuts reduces to one subgroup representative for each proper divisor of the order. This reduces the number of response queries, not the complexity of computing each Hamiltonian-path count.

For the cyclic tournament of order11 with H93027, exactly1062 odd levels are absent in its bottom response band. These are missing from this parent's ear image, not from the full spectrum. Cross-parent overlap must do the work that a one-parent interval argument cannot.

## 4. A finite obstruction basis need not be a small one

Each core has a birth d=max_v H(T-v) and death h=H(T); it is a minimal forbidden tournament exactly for thresholds in[d,h). Keeping actual core identities yields a locally finite descent graph and a conservation law connecting basis changes, births, and exact-count fibres.

The number of explicit basis entries has unavoidable superpolynomial spikes. This does not rule out compressed certificates: the finite substitution algebra is itself an example of exploiting structure rather than listing every forbidden tournament. It does explain why "just enumerate the whole obstruction basis" cannot be a uniformly small representation.

## 5. Minimum witness size differs from induced-core size

SCC factors can be repacked using previously verified finite strong-witness banks. Every attained h>1 consequently has some witness of order at most ceil(22 log_{80267}h), improving the general induced-core bound without preserving inclusion, strongness, or future context.

The qualifier "attained" is essential. This is a smaller finite search universe, not a proof that a prescribed odd number occurs. The large positive witness bank is inherited rather than regenerated in this session.

## Information-loss ledger

- Same H: can have different deletion envelopes, path-cover profiles, and minimum realization costs.
- Same GF(2) similarity: the explicit nilpotent order6 pair has H1 versus41.
- Same modular residues across all finite tests: does not imply exact membership.
- Finite cap: preserves the selected threshold observer, not uncapped counts.
- Equal scalar count under replacement: does not preserve the original embedding or marked boundary.
- A one-parent gap: is not a global spectral gap.
- A finite grammar's all-depth obstruction: is not an obstruction for every tournament.

The remaining global problem is to construct exact values with the required structural resources, or prove a new genuine exclusion. None of the frameworks silently assumes that step.
