23 October 2026. **PASS** for the finite order-eight claims in README.md.
Root reviewed the C++ producer and Python consumer after their independent
enumerations passed. This review does not assert a new all-order census.

The producer's completeness argument has two parts. Canonical words are
minimized over every permutation within the sorted score classes, giving
unique isomorphism representatives. Their exact stabilizer counts and
the orbit-mass sum 2^28 certify a complete labelled universe. Every literal
Hamiltonian path then induces a fixed-path mask. The owner-collision check,
coverage of every mask, and exact automorphism multiplicity check jointly
authenticate ownership. The action on a full ordered path is free, because
an automorphism fixing every path position fixes every vertex.

The independent Python path traversal forms only the newly created chord
bits when appending a vertex; it does not use the producer's completed-path
encoding routine. All leaves agree with the exported owner map. It then
reconstructs the complement and reflection actions, all endpoint capacities,
and every sparse ordinary/merged edge entry. The complement-edge selector
chooses one representative of each two-element complement orbit. The
closed-port selector chooses its closed endpoint independently. These
different selections must not be conflated or doubled.

The endpoint transport (a,b) -> (8-a,6-b) follows by complementing only
non-path arcs; it is independently checked on all literal masks. Reflection
also reverses the path and changes source endpoint scores to (7-b,7-a).
The counterfeit uses this latter rule on both members of its reflected
switch. It preserves the retained row/column capacities and paired-black
evenness while changing actual merged edge multiplicities.

The capacity-peeling assignments are necessary in every feasible table:
a sole neighbor must receive the whole residual capacity. Zero-capacity
vertices are removed without creating credit. Each assignment is checked
against the native table. Where all target signatures are distinct, the
allowed target is unique directly; no additional peeling theorem is needed.
Conversely, the explicit feasible switch is essential to establish failure
of the weaker observer—residual solver mass alone would not suffice.

The guarded wedge API is pinned by normalized source hash and evaluated on
the actual target tournament. Its accompanying packet proves class
separation and states its matrix domain; this packet checks the complete
port-level consequence. The result does not say that arbitrary integer
arrays with matching signatures are realizable tournaments.
