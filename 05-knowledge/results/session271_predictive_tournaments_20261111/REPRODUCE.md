# Reproduce the predictions and scoped controls

Python3, mpmath1.3.0, NumPy and SymPy are used. Existing installed packages
sufficed. Programs use no network. Run from repository root:

    python3 -B 05-knowledge/results/session271_predictive_tournaments_20261111/reproduce.py

This runs only new deliverable controls and regenerates the ensemble table.
It does not recheck exact A000568 values, the million-target atlas, inherited
proofs, or all repository mathematics. Results are in FINAL_CHECKS.json.

To regenerate the larger but bounded stochastic/search tables too:

    python3 -B 05-knowledge/results/session271_predictive_tournaments_20261111/reproduce.py --full

The original prediction tables were generated by their committed programs.
The final quick pass is separate from the original full generation. Timing is
not a claimed performance result. Random seeds, sample sizes and the exact
scope of each row are in the lane READMEs and JSON. Stochastic means and sd
are empirical summaries, not confidence-certified intervals. Nine heuristic
search runs use exact integer H evaluations but find no exact target hits.
