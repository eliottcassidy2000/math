# Reproduction and mathematical scope

Run `python3 -B reproduce.py` in this directory. Python3 and a C++17
compiler are sufficient. Executables are built in temporary directories
and removed. No inherited large spectrum or classification census is
rerun. [REPLAY.json](REPLAY.json) records the new engines' outcomes.

| Engine | Declared universe and purpose |
|---|---|
| actuators/compile.py | Complete bounded ternary return graphs; direct digit and general phase identities |
| history/probe.py | Signed finite heads, observer residues, exact least periods and table-factor clocks |
| history/port_probe.py | Complete short block grammars, fixed-port fibres and literal H25 controls |
| history/native_controls.py | Independent literal inflations and the universal two-link zero-digit operation |
| history/native_repair.cpp | Complete specified local arc search and exact finite ordered-run coefficients |
| prime_layers/compile.py | Prime-power lifts, CRT relation lattices and signed word-fibre controls |
| prime_layers/periodic.py | Complete multiplier5 return certificate and actual multiplier7 paired charts |
| prime_layers/phase_clocks.py | Prime phase catalog3–43, structural-family controls and clock11 witnesses |
| tournament/probe.py | Simultaneous ternary defects, prefix preparations and actual root changes |
| tournament/birth_search.py | Complete named small root/birth menus, native width54 pair and content/SCC controls |
| tournament/one_birth_close.py | All32,768 newborn cuts of the specified5991 graph |
| tournament/composite_clock.py | Composite341 actuator, arbitrary-prefix preparation and four literal231421/231423 witnesses |

Every engine's receipt gives its exact parameters. Proofs in the notes
establish arbitrary-length statements. A complete finite graph is used as
a proof certificate only after the coefficient-band theorem proves that
every possible return is in its declared universe. Finite coverage,
unbounded prefix completion, and prescribed-target completeness are kept
separate throughout.

Current inputs were read from baseline `f8de0ab39d54` and the incoming
target-return/Session257 checkpoints. The [history atlas](history/HISTORY.md)
and [prime-layer inheritance](prime_layers/PROOF.md) identify older sources.
No theorem namespace has been reserved or promoted to canon.

The [manifest](MANIFEST.json) hashes the final packet files; it excludes
itself. Mathematical statements are in the maintained proof notes and
synthesis, not inferred from a run log.
