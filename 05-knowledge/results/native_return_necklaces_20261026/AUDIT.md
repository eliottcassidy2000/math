## Proof review

- **N1:** all four operations use the actual marked complement and singleton
  joins. Reset output edges are nonconsecutive because the anchor is the
  first vertex and the old order is at least three. The old source edge
  survives every append; flip parity corrects its changed orientation.
  An active port change is explicit. The compiler does not erase a bit by
  an invertible operation on a fixed readout. Source weights can be carried
  injectively, but this statement supplies no positivity estimate.
- **N2:** synchrony of the path lists is necessary. It makes the complement
  masks identical. Different source-dependent paths fall outside the
  theorem. Reindexing matrices without retaining literal labels would hide
  the invariant and invalidate the conclusion.
- **N3:** the LCA is in an expression tree, not necessarily the canonical
  strong-module tree. The adjacent hinge is the sole exception to the LCA
  free-bit rule. Both maps from expression trees to presentations can be
  many-to-one. Enumeration is not an isomorphism census. The literal
  relocation escape agrees with the incoming half-edge hostile.
- **N4:** the joint mask/translation word uses simultaneous rotation. Field
  degree records only that cyclic stabilizer unless an actual quotient
  automorphism theorem is supplied (the carousel theorem supplies one).
  A primitive clock and a cut are distinct sidecars. Growth by one does not
  supply a finite-field embedding.
- **N5:** the binary and real equations have the same integer support
  matrix but different arithmetic. Both are proved separately by the reset
  segment recurrence. Row and column permutations need not be the same;
  singular norms, unlike eigenvalues of the original inverse, permit this.
  Reset spacing one and a single reset on a one-cycle satisfy the formula.
  The tridiagonal boundary is `(2,...,2,1)`, not the periodic Laplacian.
  The golden and cubic polynomials are checked by literal determinants.
  The discount changes the norm while retaining timestamps; its removal
  can cost exponentially in span and remains an explicit open obligation.
- **N6:** exact valuations require modulus `2^(s+1)`, not `2^s`. Prefix
  valuations follow because the first term after a prefix has uniquely
  smallest valuation in the remaining affine carry. The odd multiplier
  `3^h` is invertible on address residues, so the low address bit cannot be
  a reset. No comparison of the integer endpoint with its source is proved.
- **F1:** bit states are distinguished from the pointed-set basepoint.
  Taking bit zero to be that point changes which maps are allowed but
  still does not realize the entire four-map semigroup. The archived full
  states remain distinct, and forgetting them is a separate operation.

## Computational independence and limits

The single checker uses separate mathematical formulations: recursive
joins versus permutation comparisons, direct cyclic state enumeration
versus composed affine maps, impulse propagation versus integer matrix
inversion identities, and literal Collatz iteration versus affine cylinder
formulas. Normal and optimized runs must be byte-identical. The receipts
include the script hash and every finite universe. SHA256SUMS pins the
packet's delivered contents. Reproduction commands are in README.md.

The tests control implementations and boundary cases. All-order conclusions
depend on the written proofs; no finite sample establishes universal
Collatz entry, weighted ROOT cancellation, legal relocation coverage, or
six-colour forcing.
