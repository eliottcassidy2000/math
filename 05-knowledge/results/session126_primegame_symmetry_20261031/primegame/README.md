# PRIMEGAME and its explicit cellular-automaton compilation

This portable standard-library-only research packet contains two audited lanes:

- [`fractran/FRACTRAN_PRIME_EXPONENT_REPORT.md`](fractran/FRACTRAN_PRIME_EXPONENT_REPORT.md): exact prime-factor dynamics, the divisor-loop proof, first ten prime outputs, seed/FUS comparisons, and independent arithmetic checks.
- [`fractran_ca/ACTUAL_RADIUS_ONE_CA_REPORT.md`](fractran_ca/ACTUAL_RADIUS_ONE_CA_REPORT.md): a concrete 385,025-symbol homogeneous radius-one CA, its all-positive-integer READY observer theorem, exact timing, first five prime outputs, and independent local-rule checks.

Exact historical identification is documented in [SOURCE_ATTRIBUTION_CLARIFICATION.md](SOURCE_ATTRIBUTION_CLARIFICATION.md): the user's list matches Conway 1987, while a separately published alternate tail must not be substituted.

## Verify from any working directory

Use an absolute or relative path to this packet's runner:

```sh
python -B /path/to/primegame/run_all.py
python -B -O /path/to/primegame/run_all.py
```

The runner executes all seven included scripts in dependency order, propagates optimization mode, and compares every regenerated result and trace to its recorded SHA-256. The counted suites perform **2,992,899 explicit checks**. Checks use explicit exceptions and therefore remain active under `-O`.

The bulk integer trace (1,910,703 bytes) and CA READY trace (59,031 bytes) are omitted from the publication payload because they are reproducible. The runner regenerates, checks, and removes them if they did not already exist. To keep them:

```sh
python -B /path/to/primegame/run_all.py --keep-traces
```

The compact 131-configuration CA microtrace is retained and independently regenerated by `fractran_ca/write_sample_microtrace.py`. Individual scripts are source-relative; `fractran/independent_audit.py` requires the integer trace produced first by `fractran/verify_primegame.py`.

For payload integrity, run from this directory:

```sh
sha256sum -c SHA256SUMS
```

`manifest.json` records retained files, exact reproducible-output hashes, omitted-trace hashes, and the verification scopes. `verification_receipt.json` records successful normal, optimized, and relocated execution. The publication packet was copied to a different directory and run there from an unrelated working directory, without any dependency on the original scratch lanes.

## Scope

The arithmetic trace checks ten prime outputs; the actual CA trace checks five. General claims are supported by the supplied proofs, not extrapolation. CA integer semantics are asserted at READY times only. No identification of prime registers with tournament-metagraph nodes is asserted. No third-party executable, package, or network request is needed.
