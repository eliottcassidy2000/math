# An exact Turing-machine cutoff, in contrast to a local search

Let \(h\) be positive and odd. Attainability of exact counts \((h,h+2)\) by one arc flip is decidable in time \(2^{O((\log(h+2))^2)}\). If a seam exists, it exists on at most \(1+\lfloor 3\log_5(h+2)\rfloor\) vertices. For \(h=E_{61}-1\), the cutoff is **157 vertices**; this is not a claim to have searched that range.

**Proof.** Strong components of a tournament are linearly ordered and each Hamiltonian path concatenates one path in each component. At least one orientation of a nonzero flip puts both marked ends in a single strong component. Indeed if an arc between distinct components has an intermediate component, the latter supplies a two-edge old path from the tail to the head. If the tail component is nonsingleton, an out-neighbor of the tail in that component supplies such a path; if the head component is nonsingleton, an in-neighbor of the head does likewise. All these paths give a directed cycle after the flip. The remaining case of consecutive singleton components merely swaps their order without changing the count.

In the orientation where both endpoints belong to one strong component \(C\), all earlier components dominate \(C\) and all later ones are dominated by \(C\), also after reversing the internal arc. The product of outside counts therefore divides both \(h\) and \(h+2\), so it equals 1. Delete those components and retain the same seam. [Busch's strong-tournament minimum](https://www.combinatorics.org/ojs/index.php/eljc/article/view/v13i1n3) gives \(H(C)\ge5^{(|C|-1)/3}\) and proves the cutoff. Enumerate labelled orientations up to this order, and use subset/last-vertex path DP to test each marked flip. This gives the stated decision time.

For any increasing divisibility sequence of unbounded moduli, an exact seam implies witnesses at all precisions with a common finite order bound. Conversely, if modular witnesses exist at every precision **with a common order bound**, one labelled witness recurs infinitely often. The difference between its absolute count and the target is divisible by unbounded moduli and is zero. Indeed a single modulus \(q>B!+h\) already suffices at orders at most \(B\), using the bound \(H\le B!\).

This is not a technical compactness gap: [the fixed six-core chart](../chanpak_mirimanoff_unit_lifts_20261122/RESET-PORT.md) supplies congruence witnesses at every precision for the ordered pairs \((7,9)\) and \((21,23)\), even though 7 and 21 are [absolute gaps](../../../06-writeups/research-document-for-mathematicians.md). For a false target the modular witnesses must eventually escape every finite order bound. More prime tracks cannot substitute for length control.
