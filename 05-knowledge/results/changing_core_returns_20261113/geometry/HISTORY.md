# Older geometry recovered as actual repair obligations

**Status:** the root-transport theorem and the finite-observer lemma below are
PROVED here. Older claims retain the scoped status of their linked sources;
reflections are provenance only. No Jacobian, Hodge, Hadwiger–Nelson, LRC(14),
or Chan–Pak conjecture is claimed solved. No literature-priority claim is made.

## Inheritance and live concept board

The closest proved mechanism is Session 298's exact-H marked preparation.
The canonical hostile is its unprepared D=0 phase, where every R^k N R output
has b=3t. The corrected near miss is the HN lattice-cap proof, whose original
one-direction and similarity shortcuts fail although the repaired cap holds.
The least-used useful sidecar is the **literal run skeleton with a named
distinguished run**: it retains exactly the incidence information needed to
compile root relocation into full Hamiltonian counts.

Six live concepts were compared: exact target fibres; actual orbit generators;
positive path-cover kernels; arithmetic entry residues; geometric/incidence
lifts; observer loss at equality walls. The first meaningful pull, the general
kernel law, joined the first three. The H9 hostile forced arithmetic entry
back into the board despite strict convexity. The HN recovery identified
uniformity as the exact boundary for carrying the kernel law to selective ports.

## 1. Planar Jacobian: a fibre action is useful only at its proved strength

**Inherited PROVED mechanism:**
[THM-2230, planar Jacobian response fibre](../../../../01-canon/theorems/THM-2230-planar-jacobian-response-fiber-and-exact-target-shear-quotient.md).
In characteristic zero, if P has a constant nonzero Jacobian mate, the kernel
of its response derivation D_P is k[P]. Every nonempty response fibre is
Q_R+k[P], and target shears Q->Q+H(P) act simply transitively on that fibre.
The quotient is a vector/module quotient; k[P] is not being called an ideal.
This does not prove P is a coordinate or settle the planar Jacobian conjecture.

**Precise transplant:** source = a response fibre with its allowed shears;
target = marked tournaments at a fixed full H; map = replace the abstract
generator by a literal adjacent interchange of the named root in a uniform
transitive module. Preserved predicate = exact response in the first setting,
exact H and q in the second. Lost data = the root interface if one keeps only
the unrooted class. Necessary sidecar = (s,F), plus root phase and exterior
incidences. The cheapest decisive test is a three-vertex nonuniform candidate,
which fails H-neutrality (3->1).

The [new theorem](PROOF.md) proves an actual neutral **suborbit**, with an
isometric path and strict convex response. It does not say this is the whole
H-fibre. That distinction is essential: THM-2230 has a completeness theorem
for its shear fibre; no corresponding tournament completeness is available.
Conversely, the new finite-difference law supplies quantitative optimization
inside the orbit, information not obtained merely by naming a target fibre.

## 2. HN: exact normalization and gluing survive; informal geometry does not

**Recovered corrected PROVED mechanism:**
[Session 61 lattice-cap repair](../../session61_hadwiger_six_seven_20261025/lattice-cap/LATTICE_CAP_REPAIR.md),
which takes precedence over the superseded parts of THM-418/419. For a planar
lattice norm layer, three unoriented equal-norm directions force a rational
Gram form, by the determinant identity

```
det(r(u),r(v),r(w)) = det(u,v) det(u,w) det(v,w),
r(u)=(u1^2,u1*u2,u2^2).
```

A genuinely nonarithmetic form can have **two**, not just one, direction pairs.
In the arithmetic branch the proof divides the field embedding by an actually
attained norm vector before reducing at a ramified prime. This carries the
specific norm layer to norm one. The old assertion that the relevant kernel
sublattice is always similar to the original is unnecessary and false.

**Repair transfer:** an arithmetically normalized state is not automatically
a physically normalized tournament. Dividing a coordinate vector by a gcd
needs a construction realizing the divided vector and preserving the required
target. A residue calculation becomes a valid obstruction or guard only after
the actual state and its map have been fixed. The root theorem performs its
normalization by real arc operations, with H fixed before the residue guard
is inspected. It never divides the tournament state to improve a gcd.

**Recovered PROVED gluing mechanism:**
[Session 254 HN parallel paths](../../session254_four_frontiers_20261111/hadwiger_nelson/PROOF.md)
constructs arbitrarily many induced length-four unit-distance paths between
fixed ports, with private interiors and no extra cross edges. For palette6,
the two boundary response weights are 105^r and 104^r. Their ratio tends to
zero, while the second weight stays positive at every finite stage.

Source = a boundary response of an induced geometric graph; target = a run
skeleton in a uniform tournament module. Map = integrate out private internal
vertices while retaining the boundary state. Preserved predicate = exact
extension count; lost data = external incidences if one stores only a scalar.
Necessary sidecar = all edges touching the boundary and possible cross edges.
The rule applies to a selective tournament port only after its different
external incidence types are recorded. The kernel proof works because all
vertices in C share one type; the three-cycle hostile shows why collapsing
two types is invalid. The HN ratio is also a clean warning that asymptotically
small defect is not exact zero defect, just as a huge D does not ensure gcd1.

**Further recovered PROVED obstruction:**
[Session 140 HN/Collatz geometry](../../session140_collatz_hexagonal_geometry_20261102/hadwiger_nelson/PROOF.md),
Sections4–5, distinguishes arbitrary unit-distance realization from uniformly
separated or bounded-stretch lattice realization. Explicit exponentially
growing inverse families cannot inject with uniformly bounded edge stretch
into a polynomial-growth lattice. Its separate cycle-displacement criterion
requires the exact sum of selected edge lifts to vanish on a cycle basis;
vanishing after reduction is insufficient.

The useful import is a guard, not an analogy asserting tournaments are a
lattice: a residue-labelled repair cycle must still be lifted to a common
physical graph/root and checked at every intermediate step. A low-dimensional
picture is not evidence of injectivity, bounded distortion, or completeness.
The new root orbit does have a proved isometric one-dimensional description;
no such assertion is made about the entire repair graph.

## 3. Hodge: distinguish exact graph currents from realizability

Two older routes have different types.

- [THM-4739, tournament metagraph currents](../../../../01-canon/theorems/THM-4739-kirchhoff-and-hodge-laws-of-the-tournament-metagraph-intransitivity-currents-second-order-determination-and-the-consecutive-start-port-ledgers.md)
  gives exact potential/current identities and a gradient/curl decomposition
  using the filled complete-graph triangle complex. Its finite determination
  experiments show that first-order ports suffice at n=4 but not n=5, and
  even stronger listed port data leave many candidates at n=6. Those finite
  counts are not an all-order metagraph determination theorem.
- [THM-509, two-layer baby-Hodge dichotomy](../../../../01-canon/theorems/THM-509-the-two-layer-baby-hodge-dichotomy.md)
  separates automatic spectral/Hankel positivity from integral realization.
  The finite tournament hole (c3,c5)=(8,10) at n=6 lies in the corresponding
  convex hull. Its stronger general nonlinear-moment exclusion language is
  explicitly conjectural; it is not used here.

Source = a graph cochain or a relaxed moment vector; target = physical repair
words with actual intermediate tournaments. The safe map sends an actual
operation to its exact change of a recorded invariant. Such changes telescope
along a cycle. The converse is not automatic: zero total formal change does
not provide the missing physical edges. Required sidecars are the operation
word, named ports, legality of intermediate states, and full H response.

The historical [Hodge cycle-lifting reflection](../../../../07-reflections/hodge-conjecture-cycle-lifting-lrc14-codex-s232.md)
is useful provenance for this demand for actual generators. It is not evidence
about algebraic cycles. Here the adjacent root swaps are explicit generators,
and their exact H changes vanish individually. The kernel law proves which
marked responses those generators can realize. Convexity of a scalar response
does not turn its arithmetic feasible set into an interval: H9 has D=(0,4,12),
but only the middle phase permits the specified native return.

## 4. Rational/irrational and real/transcendental: a sharper observer guard

**Inherited PROVED mechanism:**
[THM-4088, arithmetic-type blindness](../../../../01-canon/theorems/THM-4088-order-tournament-arithmetic-type-blindness-and-lrc-margin-density.md).
A strict scalar-order tournament sees only order, so it cannot recover
rationality, exact algebraic degree, or transcendence. Arithmetic sidecars such
as denominators, determinants, heights, and quantitative residuals are needed.

**PROVED elementary extension: finite strict polynomial observers.** Let
P_1,...,P_N be real polynomials in d real parameters, and let x satisfy
P_i(x)!=0 for every i. Every coordinate of x can be perturbed to any prescribed
one of rational, algebraic of a chosen exact degree>=2, or transcendental,
while leaving **all** signs unchanged. Consequently any finite tournament
whose actual pairwise observable is the sign of one of these polynomials,
with no ties, has the same orientation and the same Hamiltonian count after
such changes of parameter arithmetic type.

Proof: continuity supplies an open box around x on which all signs agree.
Each of the three specified types is dense in the real line; fixed exact
degree d is witnessed by rational affine translates of 2^(1/d). Choose each
coordinate independently in its assigned open interval. This proves the
claim. Rational coefficients are not needed for this local statement. If all
P_i have rational coefficients and there is only one parameter, the finitely
many possible sign-changing walls are algebraic roots of the nonzero P_i.

A quantitative version retains a sidecar: if |P_i(x)|>=eta>0 and each
polynomial has gradient l1-norm at most L in a convex neighbourhood, then
||y-x||_infinity<eta/(2L) retains the signs. An explicit rational grid can
therefore realize the same tournament once that neighbourhood and derivative
bound are certified. This is an open-chamber statement, not a claim about
exact polynomial equalities or integral parameters.

The equality boundary is decisive. A Euclidean equilateral triangle of side1
cannot have all coordinates rational: its determinant area would be rational,
but its area is sqrt(3)/4. Strict approximate-distance inequalities allow
rational perturbations, whereas the exact unit-distance predicate does not.
Likewise exact Hamiltonian targets are discrete: crossing orientation walls
requires evaluating the changed graph, not a continuity argument for H.
The new module theorem supplies such a wall-crossing operation and proves
that its particular H remains unchanged.

The original historical [rational/irrational reflection](../../../../07-reflections/the-rational-irrational-duality.md)
contained a provenance-only arithmetic slip: its displayed floor/ceiling witness
with integer N and offset1/14 is called 'generically IRRATIONAL', although
(integer+1/14)/N is rational. The valid content is the open-set/margin bridge;
THM-4088 gives the correct stronger density statement. No LRC proof status is
inferred from that historical wording.

Odd/even is a different kind of split: parity of actual integer controller
coordinates survives in the gcd and residue guards. It is not an arithmetic
type of a free real coordinate. Treating rational/irrational and odd/even as
the same duality would erase exactly the discrete information needed for (4)
in the root-transport proof.

## 5. Recovered core enumeration: integrate, do not rediscover

The structural search found an exact prior classification, not a new one:
[THM-4463](../../../../01-canon/theorems/THM-4463-homogeneous-tournament-contacts-and-pinned-scale-floor.md)
already makes homogeneous-pair components into maximal transitive modules;
[the weighted-core count](../../weighted_core_transport_20261020/core_count.md)
already identifies every unlabelled tournament with a pair-free quotient and
positive chain weights modulo its automorphism group. It also provides the
exact fixed-core cycle-index generating function and an orbit-increment
recurrence. Its explicit warning remains: group order alone does not suffice;
the permutation action or cycle index is required. This is not a new closed
scalar recurrence for A000568.

The independent primary-literature precedent is Boudabbous and Pouzet,
[The morphology of infinite tournaments, Theorem1](https://arxiv.org/html/0801.4069v1#S1.SS1),
arXiv:0801.4069v1 (2008): a tournament has a unique decomposition into acyclic
blocks over an acyclically indecomposable quotient. For finite tournaments
these blocks are transitive. This is cited solely as established structural
precedent, not as a new result here or as a metagraph connectivity theorem.

The new bridge adds root-response information to that old complete object
coordinate system. Each marked root is specified by a weighted-core vertex
and an internal chain position, modulo weight-preserving core automorphisms.
The new strict-convexity theorem classifies the response along every such
position interval. Keeping only the core's weight-count generating function
would lose the arcs needed to calculate C_j,B_j and the arithmetic return.
An old enumerative compression and a new exact-target preparation therefore
fit together without identifying their different preserved predicates.

A second prior recovery sharpened the result: [O4 of the 6325 observer](../../return6325_observer_20261103/PROOFS.md)
already proves the adjacent-twin contraction identities for F and s. Iterating
that old mechanism now proves that every forward difference of D is
nonnegative, with an exact source-root equality boundary. Newton reconstruction
then computes every marked phase at widths1..M from only M first-phase state
counts. This is a concrete improvement for the marked response atlas; it does
not newly enumerate unlabelled tournaments or change the old cycle-index formula.

The separately recovered [false-twin quotient defect note](../../twin_quotient_defect_weights_20261020/TWIN_QUOTIENT_DEFECTS.md)
concerns undirected graphs and an edge-sign character, a different type from
tournament homogeneous pairs. Its useful warning is exact: the split/join
pair K_(6,6) and K_(3,3,6) has defect weights -2 and+1, so a pairing of objects
does not by itself cancel weighted defects. The unbounded family extends the
mismatch. Any enumeration or return cancellation here must retain actual
orbit multiplicities rather than copy a graph-sign involution into tournaments.

## 6. What is now available, and what is still missing

The recovered operations yield a concrete reusable method: certify a uniform
transitive module, retain its exact run skeleton, walk the named root through
an isometric H-neutral interval, and filter the resulting exact states by
the physical return's arithmetic guards. The interval response is fully
classified by (1)–(3) in [the proof](PROOF.md); arithmetic admissibility is
an additional calculation, not an optimization corollary.

Selective ports can escape a uniform-block obstruction, but they deliberately
leave this theorem's hypotheses. Their next useful object is a multitype run
skeleton retaining each external incidence signature, together with a proof
that the selected root move fixes the full target. No claim is made that this
larger grammar is already closed, that it supplies every source target, or
that a finite observer classifies the full metagraph at all sizes.
