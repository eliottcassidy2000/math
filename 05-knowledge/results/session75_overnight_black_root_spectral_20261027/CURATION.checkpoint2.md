# Checkpoint2 curation scope

All checkpoint1 native files, manifests and audit evidence remain unchanged.
Current producer and auditor deliverables are selected by explicit file lists
and hashes; curated bytes and modes are preserved. Auxiliary black-core probes,
unused input dumps, caches, operational files and compiled outputs are excluded.

The dyadic auditor's original `MANIFEST.audit.json` is retained byte-for-byte
as its full historical inventory. The following optional verbose reconstructed
outputs are deliberately **not stored** in the packet:

- `reconstructed/independent_sources_N512.json`
- `reconstructed/independent_sources_N1024.json`
- `reconstructed/independent_sources_N4096.json`

These are regenerated and fully hash-verified on demand, not silently skipped.
`replay_dyadic_reconstruction.py` runs the independent auditor with
`--producer producer_revision2 --write-sources TEMPORARY_DIRECTORY` outside
the frozen packet. It checks the complete native-source comparison receipt,
then compares all three generated byte hashes with the unchanged original audit
manifest, requires the exact three-file output inventory, and deletes its
temporary outputs. The job runs normally and under `-O`; a deliberately wrong
expected hash must fail at the detailed-ledger hash gate in both modes.

The full compact native ledgers, frozen revision2 producer copy, original source
bindings, independent reconstruction program and paired comparison receipts
are included. Every original audit-manifest entry is covered either by the
curated-file bindings or by this explicit generated-output check. The producer's
active native manifest remains fully checked. Omitting redundant stored bytes
does not weaken the full native-source reconstruction or its evidence bindings.

Old producer/auditor status sentences are historical byte snapshots. Separate
status-promotion diffs and final-byte acceptances record authorized later status
changes without altering the audited proofs, code or receipts. The superseded
revision1 dyadic manifest is lineage, not an active checksum specification for
revision2 output.
