## Input completeness audit

`audit_jobs.py` independently constructs direct-product permutations as Cartesian products (Paley7 affine permutations, R5 translations, C3 translations), selects kernels by direct evaluation of a homomorphism to F3, verifies transitive projections, reconstructs every orbital, and checks exact unordered-pair coverage and fixed arcs. It uses explicit exceptions rather than assert. Normal and `python -O` results are identical. Job generation itself is also identical normal/optimized.

- Original window: 24 configurations, 83 subgroup jobs, 73 module and 10 nonmodule cases.
- Alternate order-12 window: 6 configurations, 45 subgroup jobs, 33 module and 12 nonmodule cases.

The alternate order-12 generator only replaces the original order list by `[12]`. It is separate from the original order-12 element-type scan and does **not** purport to reproduce that scan.

Completeness depends on the analytic orbit-product / vertex-transitive / index reductions supplied by the parent audit. Given those reductions, enumeration of the full group and every nonzero functional modulo scalar supplies every index-1/index-3 subgroup with transitive projections. Only a kernel supported on one C3 coordinate is nontransitive; a kernel supported on the P7 multiplier coordinate remains transitive by the translations.

## Why arbitrary versus full automorphism orbits is safe

The scanner does not require the generated G-orbits to equal the full Aut(T)-orbits. This is harmless **over-enumeration**, not a missed case: every candidate with actual group G is present, and exact full Aut(T) is used at the final gate. The phrase "with the prescribed orbit structure" must mean the prescribed G-orbits, not a checked equality with actual Aut(T)-orbits. No block-preservation restriction is imposed on the independent automorphism counter.

## Exact automorphism counter

For base vertices 0,1,...,n-1, the counter finds the orbit size under the pointwise stabilizer of earlier base vertices, using exact permutation-extension backtracking. At each step only degree/refinement invariants and adjacency to already mapped vertices prune candidates. Existence is returned only after a full bijection preserving all arcs is formed. Multiplying these orbit sizes is the orbit-stabilizer theorem. Tests independently compare against brute permutation enumeration on all 33,867 labelled tournaments through order 6, and check C3/R5/P7 and C3[R5]/R5[C3] controls.

## Path-count algorithms and numerical safety

The Held-Karp recurrence counts directed simple paths by used vertex subset and last vertex. The module DP has a bijective interpretation: decompose a Hamilton path into maximal same-block runs, count the quotient-compatible run-label word, and independently choose the ordered path cover in each block. Consecutive equal labels are prohibited, so the decomposition is unique and no path is counted twice. The rectangular-orbital input condition is independently checked and ensures all cross-block arcs are uniform.

All n are at most 22 and all free-orbital counts at most 15, so mask and Gray-code shifts are in range. Unsigned 128-bit arithmetic is sufficient even for the conservative decomposition bound 22! * 2^16 (< 2^86). The portable replay checks final H <= UINT64_MAX for each strong tournament; no such rejection has occurred. Final counts and exact aggregate receipts are in `SUMMARY.json`. All 83 original output lines match exactly after normalizing the path prefix. There are 185,642 strong tournaments, 48,908 exact-aut candidate calls, 93,646 module-vs-Held-Karp checks, zero failures and zero hits. The separate order-12 run has 46,968 strong tournaments, 10,104 candidate calls, 45,384 module-vs-Held-Karp checks, zero failures and zero hits.

This also validates original uint64 arithmetic for these jobs: Held-Karp is only used through n=16, so every count is bounded by 16!; block path-cover counts use blocks of size at most 7; there are at most 6 blocks, so every run-word-state count is at most 6^22 < 2^64. Products of block-cover counts are below 100800 * 6^5 < 2^30. Every product added to the Hamilton-path total counts disjoint valid paths and is bounded by the exact final H, which the 128-bit replay checked below 2^64. All additions are nonnegative.

The candidate filter is necessary: if tc(T)=t in {7,21}, H/t=|Aut(T)| is an integer divisible by |G|. Thus the test skips no target. Automorphisms act freely on Hamilton words, which justifies H/|Aut| and its integrality.
