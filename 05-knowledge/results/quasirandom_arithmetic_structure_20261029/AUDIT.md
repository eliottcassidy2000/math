## Proof review and hostile cases

Positive integer arguments keep the square-class characters independent of
the fixed negative character(-1/q). Negative arguments would require an
affine adjustment. Primes dividing arguments are explicitly removed.
Fixed rank and conductor are essential for applying PNT as stated. The
decorated telescoping has only one edge between each pair, so each residual
factor really separates into f(x)g(y). The empirical code histogram is
descriptive; exact uniformity is a CRT-fibre theorem and limiting PNT theorem.

Sylvester terms need not be prime or squarefree for Jacobi reciprocity.
The linear cut witnesses failure of randomness, not computational hardness.
The19 derivative uses the unreduced orbit2,3,7,43;1755 is only a reduced
derivative representative, not the literal derivative16575. The lifted
fixed point5417 is not the integer source2. The all-size period proof uses
the first nonzero return digit17 and derivative1 mod19, not extrapolation.

Wieferich delay, Paley mixing and circulant rigidity concern distinct
operators. The Monster's even order forbids it as a tournament automorphism
group; its quasirandom-group theorem applies to actual incidence/convolution.
The composite-base valuation function is not a group action. FLT solves
local congruences, while the ordered-carry witness prevents a global reset.
