# Exact-cover output reproduction

The recorded files `endpoint636_exact_cover.out` and
`r632_mixed_exact_cover.out` were generated by the same exact
branch-and-bound source, now maintained at:

```text
04-computation/lrc14_mixed_rank_depth_recursive_signatures_thm4296/exact_cover.py
```

The source uses SciPy/HiGHS only to obtain a floating LP solution, converts
every nonzero weight to `fractions.Fraction`, and verifies every class load
exactly before using the rational dual in the exhaustive pivot DFS.  Thus a
floating-point result is never accepted as an exact lower certificate.

From the repository root, with Python, NumPy, and SciPy available:

```bash
src=04-computation/lrc14_mixed_rank_depth_recursive_signatures_thm4296
packet=05-knowledge/results/lrc14_mixed_rank_depth_recursive_signatures_thm4296
endpoint="$packet/results/endpoint"
scratch_dir=$(mktemp -d)

normalize_lf() {
  python3 - "$@" <<'PY'
from pathlib import Path
import sys
for argument in sys.argv[1:]:
    path = Path(argument)
    payload = path.read_bytes()
    path.write_bytes(payload.replace(b"\r\n", b"\n").replace(b"\r", b"\n"))
PY
}
cmp_frozen() {
  normalize_lf "$1"
  cmp "$1" "$2"
}

python3 "$src/exact_cover.py" "$endpoint" \
  LOCAL_100 LOCAL_256 COMMON_ACTIVE CARRIER_UNION \
  > "$scratch_dir/endpoint636_exact_cover.out"

python3 "$src/exact_cover.py" "$endpoint" \
  r632_mixed89_atlas \
  > "$scratch_dir/r632_mixed_exact_cover.out"
```

The generator omits wall-clock timing, so both outputs are byte-stable.  Check
them directly:

```bash
cmp_frozen "$scratch_dir/endpoint636_exact_cover.out" \
  "$endpoint/endpoint636_exact_cover.out"
cmp_frozen "$scratch_dir/r632_mixed_exact_cover.out" \
  "$endpoint/r632_mixed_exact_cover.out"
```

## End-to-end r632 atlas regeneration

The frozen `mixed89.tsv` used above can itself be regenerated.  First build
the complete rank-eight atlas, then feed its `(256,632)` slice to the
rank-nine mixer:

```bash
mkdir -p "$scratch_dir/r632_rank8" "$scratch_dir/r632_mixed"
g++ -std=c++20 -O3 -DNDEBUG -I. \
  "$src/r632_response_atlas.cpp" \
  -o "$scratch_dir/r632_response_atlas"
"$scratch_dir/r632_response_atlas" \
  "$packet/inputs/post_exchange_r632_failures72.csv" \
  "$packet/inputs/reconstructed_final8951.txt" \
  "$packet/inputs/additions45.txt" \
  "$packet/inputs/endpoint638_response_witness9.txt" \
  "$scratch_dir/r632_rank8" \
  > "$scratch_dir/r632_rank8_response_atlas.out"
cmp_frozen "$scratch_dir/r632_rank8_response_atlas.out" \
  "$endpoint/r632_rank8_response_atlas.out"
cmp_frozen "$scratch_dir/r632_rank8/R632_LOCAL_100.tsv" \
  "$endpoint/r632_rank8_atlas/R632_LOCAL_100.tsv"
cmp_frozen "$scratch_dir/r632_rank8/R632_LOCAL_256.tsv" \
  "$endpoint/r632_rank8_atlas/R632_LOCAL_256.tsv"

python3 "$src/exact_cover.py" "$endpoint/r632_rank8_atlas" \
  R632_LOCAL_100 R632_LOCAL_256 \
  > "$scratch_dir/r632_rank8_exact_cover.out"
cmp_frozen "$scratch_dir/r632_rank8_exact_cover.out" \
  "$endpoint/r632_rank8_exact_cover.out"

g++ -std=c++20 -O3 -DNDEBUG -I"$src" \
  "$src/r632_rank9_mixed_response_atlas.cpp" \
  -o "$scratch_dir/r632_rank9_mixer"
"$scratch_dir/r632_rank9_mixer" \
  "$packet/inputs/post_exchange_r632_failures72.csv" \
  "$scratch_dir/r632_rank8/R632_LOCAL_256.tsv" \
  "$scratch_dir/r632_mixed/rank9.tsv" \
  "$scratch_dir/r632_mixed/mixed89.tsv" \
  > "$scratch_dir/r632_rank9_mixed_response_atlas.out"
cmp_frozen "$scratch_dir/r632_mixed/rank9.tsv" "$endpoint/r632_atlas/rank9.tsv"
cmp_frozen "$scratch_dir/r632_mixed/mixed89.tsv" "$endpoint/r632_atlas/mixed89.tsv"
cmp_frozen "$scratch_dir/r632_rank9_mixed_response_atlas.out" \
  "$endpoint/r632_rank9_mixed_response_atlas.out"
```
