# Session43: observers, restricted gaps, phase guards and valuation geometry

This session investigates what survives after choosing a Hamiltonian observer, restricting an averaging measure, replacing integer charges by finite residues, or identifying arithmetic states. Proofs retain the source, action, weights and missing coordinates explicitly. Open conjectures are not declared solved by analogy.

Research lanes:

- Native Hamiltonian observer bundles and compatible shared-frame path assembly.
- Which restrictions preserve the graph/tournament coupling bound, and exact counterexamples when conditioning changes it.
- Finite angular guards, Gaussian power moments and bounded-degree planar rigidity.
- The literal divisor-height cycle 4→2→5→3→7→4 and geometric covering families.
- Cyclotomic path-cover valuations and their distinct binary/ternary observables.

The final synthesis will distinguish inherited results, new all-size proofs, exhaustive finite controls and remaining native completeness obligations. Every publication checkpoint is independently verified; source code and audit receipts accompany the results.
