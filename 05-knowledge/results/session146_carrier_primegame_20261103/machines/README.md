# Finite odd-pair triangle as an ordered FRACTRAN machine

**Status: PROVED construction; FINITE-EXACT checks.** This is a finite-instance compiler, not a new theorem that every even integer is a sum of two odd primes. The user did not specify a unique triangle: our explicit interpretation is the finite triangular region of index pairs 0 <= i <= j < N, representing a=2i+3, b=2j+3, with source predicate a+b=T and both entries prime. For each fixed N and T, a separate finite program and a finite input vector are constructed. T need not be even; odd T gives no pair. The labels are odd integers >=3, not all integer primes: 2 is outside this chosen region. The represented triangle and its label map are reversible; an output (i,j) gives (2i+3,2j+3), and conversely i=(a-3)/2, j=(b-3)/2. Duplicates a=b are allowed.

## A literal program

For N=2, T=8, there is a single candidate (3,5). Bits x0,x1 use register primes 2,3. Input is 5 * 2^x0 * 3^x1 for x0,x1 in {0,1}. The first-applicable FRACTRAN list, in exact order, is

    7/10, 19/5, 22/7, 13/33, 19/11, 51/13.

The only legal initial inputs are 5, 10, 15, 30. Their respective halts are 19, 38, 57, 102. Output control 17 means accept, 19 means reject; the bits are restored at either halt. The number 30 follows 30 -> 21 -> 66 -> 26 -> 102. In particular, the first fraction must precede 19/5. Swapping them makes 30 reject. FRACTRAN acts on positive integers by multiplying by the *first* fraction yielding an integer and halts if none applies. The other positive integers are formal inputs to that arithmetic map but are outside this machine's promised semantics; in particular they need not have one control prime or Boolean registers.

## General compiler, guard proof, and termination

Fix N>=1 and T>=0. Let x=(x0,...,xN-1) be any Boolean vector, and list every pair (i,j) of the specified region satisfying (2i+3)+(2j+3)=T, in lexicographic order. Denote the resulting finite sequence e_k=(i_k,j_k), k=0,...,m-1. Choose pairwise distinct primes r_i for the data, state primes s_k,u_k,v_k,w_k and accepting h_k, and one rejecting prime h_R, disjoint from all r_i. If m=0, the initial control is h_R and the list is empty. Otherwise initial control is s_0. Define next_k=s_(k+1) if k+1<m, else h_R. For each k append these six fractions, in this order:

    u_k/(s_k r_i), next_k/s_k, (v_k r_i)/u_k,
    w_k/(v_k r_j), next_k/v_k, (h_k r_j)/w_k.

The fractions are in lowest terms by prime distinctness. For every legal initial input s_0 product_i r_i^x_i, precisely one state control occurs. At s_k, the first rule applies iff bit i is one and removes r_i temporarily; then the u_k rule restores it. Otherwise the following fallback applies. The same pattern tests j at v_k and restores the bit at w_k. Thus all data are restored at every s_k and terminal h_k or h_R. If i=j this remains valid, since the first read has restored the bit before the second read. Each accepted output h_k records the lexicographically first e_k with both input bits one; h_R records that none exists. At each one-hot state, other pairs' fractions have denominators containing their different state primes, so no earlier block interferes. Terminal controls occur in no denominator, so both outputs halt. All paths terminate in at most 4m primitive FRACTRAN steps (the zero-pair instance takes zero), as each failed candidate costs one or three steps, and a successful candidate four.

This is a compiled *family*, not one fixed FRACTRAN list that takes unbounded N. Its input bit vector is an explicit length-N Boolean object, not an unbounded characteristic function. Its arithmetic encoding forgets the semantic origin of the bits: arbitrary Boolean vectors are supported, but interpretation as primality requires an independently established primality vector. In this implementation the latter is obtained by trial division: x_i=true iff a_i>=2 and no integer d with 2<=d<=floor(sqrt(a_i)) divides a_i. The upper bound makes every checked d a proper divisor, and every composite has such a divisor. This process halts for each finite input. The proof and construction need no prime-pair conjecture.

A tempting test fraction (u r_i)/(s r_i) reduces to u/s and no longer tests the bit; the consume/restore split is essential. First-applicable priority is also essential; this is not a nondeterministic rule system.

## Modulo 290 prefilter

Optionally the compiler drops a pair if either member a fails gcd(a,290)=1 and a is neither 5 nor 29. Since 290=2*5*29 and all a are odd and >=3, the only prime exceptions are 5 and 29. This preserves the source predicate *when the input vector really is primality*. It does not identify primes: 15 and other composites may be marked in a formal vector, and pruning such a vector may change its output. The 15+15 control exhibits exactly this loss. Modular selection is therefore only a sufficient composite rejection, not a primality test or a substitute for it.

## Explicit one-tape TM and strict radius-1 cellular automaton

For each fixed N,T define a deterministic one-tape machine. Its nonhalting states q_w are indexed by every binary word w of length at most N; q_H and q_E are halting states. Its finite tape alphabet consists of blank `_`, 0, 1, output markers R and A_(i,j) for all 0<=i<=j<N, and the auxiliary symbol #. On input x_0...x_(N-1), all other tape cells blank, start in q_empty scanning cell 0. For |w|<N, each of the two exact rows is delta(q_w,b)=(q_(wb),b,R) for b=0,1; on every other tape symbol it enters q_E without writing or moving. For |w|=N, on blank it writes A_(i,j), where (i,j) is the lexicographically first pair satisfying (2i+3)+(2j+3)=T and w_i=w_j=1; it writes R if there is no such pair. In either case it enters q_H without moving. On every nonblank symbol in q_w with |w|=N it enters q_E without writing or moving. This is a complete finite transition specification by cases, not a wildcard instruction: expanding the finite sets of w, symbols and pairs gives every ordinary transition row. The target truth table is compiled once into the transition table. A legal input halts in exactly N+1 transitions, leaves the N bits unchanged and writes its output in cell N. The state count is 2^(N+1)-1 nonhalting prefix states plus two halting states, not a space-efficient universal program. Malformed input outside the promised blank-ended length-N encoding is outside the source predicate; the explicit error rows cover an early blank, a non-bit within the word, and a nonblank at cell N, not arbitrary distant nonblank tape cells.

A genuine shift-equivariant radius-1 CA simulates this TM on legal configurations. Its alphabet contains pairs (a,q), with a any TM tape symbol and q either absent, one prefix state, q_H, or q_E. Let d(q,a)=(a',q',move) denote the explicit TM transition above; for q_H or q_E define the stationary transition (a,q,S). The CA updates all cells simultaneously from their left and center cells (the right neighbour is ignored). First, if the left cell has a head whose transition moves right, it proposes to send its next state into the center. Independently, a center head writes its transition's a' and retains q' only for a stationary move; a right-moving center head leaves its written symbol without a head. An unheaded center receiving a proposed state attaches that state to its unchanged tape symbol. If a center already has a head and receives an incoming state, replace that center by (#, absent); this arbitrary deterministic collision rule fully specifies the multihead case. With neither center head nor incoming state, the cell is unchanged. These cases define one identical local map at every integer site, so the global map commutes with shift. Starting from the legal single-head encoding, induction gives precisely the TM configuration after every synchronous update: exactly one head exists, transitions write the old head cell, and a right move transfers the state one cell. Stationary halting heads and all other cells remain fixed. The local map is total even on formal multihead configurations, but no source-predicate interpretation is claimed there. This is a strict CA, unlike the inherited globally selected PRIMEGAME quasi-CA. It is another fixed-(N,T) family, not a single uniform CA deciding an unbounded prime-pair conjecture. `ca_step` implements the local map on the inspected finite window with blank exterior; the legal head never leaves that window.

## An actual PRIMEGAME-to-triangle bridge

The inherited THM-4852, `01-canon/theorems/THM-4852-primegame-phase-law-both-published-lists-agree-selector-cellular-automaton-in-base-29-primorial.md`, states that both Conway's owner list and Guy's fast list, started at 2, have phase entries 2^n 7^(D(n)-1), for n=1,2,..., with D(n)=n/spf(n); pure powers 2^n are emitted exactly at prime n. Thus, for a fixed N, an observer can record pure powers 2^(2i+3) for i=0,...,N-1, and stop once phase n=2N+2 is entered. The observation at each step keeps all ten valuations; an entry may be detected with the 3,5 and state-prime valuations zero, the 2 valuation equal to 2N+2, and the 7 valuation nonnegative. Once a reset starts, its first step makes the 3 and 5 exponents positive; they stay positive through the reset and 1/7 cleanup, until a state prime returns. Thus the specified 3,5-free observations occur at phase entries, which advance in order. The observer then supplies those N bits to the finite FRACTRAN triangle compiler. By the phase law every requested bit is exact and the stopping event occurs, so this composite is a finite, terminating PRIMEGAME-derived pair decider for each fixed N,T. It does not assert an unconditional bound on an unbounded search for pair representations.

The executable simulates both precise ordered lists over valuation vectors, stops at that phase, and compares every resulting bit with trial division for N=1,...,5, and then checks 110 stream-to-pair instances. Its generous simulation budget is a test-harness cap: exhausting it raises an error, not a compositeness verdict; the mathematical termination is instead from the cited phase law. The triangle fraction program itself has the proved 4m bound, and its runner uses that bound by default.

The source law is inherited, not a new proof of the PRIMEGAME phase law. Session135's `05-knowledge/results/session135_fractran_tm_structure_20261101/SYNTHESIS.md` supplies the established exact-machine background. The fixed PRIMEGAME's unbounded values live in exponents; here control and data primes are introduced afresh for each finite N,T. Both make ordered applicability a genuine semantic guard. The THM-4852 prime-primorial selector is a quasi-cellular selector, not automatically a shift-commuting cellular automaton. No equivalence between this finite selector and the full PRIMEGAME orbit, no fixed universal bound over N, and no unbounded Goldbach conclusion is asserted.
