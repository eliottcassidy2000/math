The source-to-target maps are deliberately typed. A path receipt preserves
the actual start, endpoint and odd-step count; averaging away the endpoint
loses the equation needed for signed credit. A balanced lift preserves
parent signs and old modes; it destroys a coherent quotient-module
interpretation. A prime substitution preserves the full weighted action
and child types; discarding them loses isomorphism and regularity data.
Each map has a separate literal test, so analogy is not used as a proof.
