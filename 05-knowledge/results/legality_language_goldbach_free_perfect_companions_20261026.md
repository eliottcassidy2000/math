## 1. Legal re-marking guards reconstruct tournaments (THM-4806, Theorem R)

Conventions (strong-atom README, section 1): a re-marking `R_p` of a tournament reads it in the vertex order `p` and is *legal* iff `p` is a directed Hamiltonian path; the *named legality language* is `L(T) = {p in S_n : p is a Hamiltonian path of T}`. The guards reconstruct `T` iff `T -> L(T)` is injective on labelled tournaments. Call an arc `u -> v` of `T` *dark* when no Hamiltonian path of `T` contains it, and `T^(uv)` the tournament with that one arc reversed. Two tournaments on the same vertex set have the same language iff every arc on which they differ is dark in both (a path using such an arc belongs to only one of them).

**Theorem R.** (i) *(single-pair lemma)* For every tournament `T` on `n >= 3` vertices and every pair `{u, v}`, the arc of `T` between `u` and `v` lies on a Hamiltonian path of `T`, or the reversed arc lies on a Hamiltonian path of `T^(uv)`. Hence `L(T) != L(T^(uv))` for every `T` and every pair: no single arc can hide from the named guards, at any size. (ii) *(reduction)* `L(T)` determines the ordered partition of the vertex set into strong components, and `L(T)` is the concatenation of the languages of the components; so two tournaments with the same language have the same strong components, the same inter-component arcs, and the same component languages, and all-order injectivity is equivalent to injectivity on strong tournaments. (iii) *(exact range)* `T -> L(T)` is injective on all labelled tournaments of order `n <= 8`.

*Proof of (i).* Let `W = T - {u, v}` with strong components `W_1 -> W_2 -> ... -> W_m` (every arc between different components goes forward; each `W_i` is a singleton or strong, hence has a Hamiltonian cycle by Camion, so a Hamiltonian path of `W_i` can start or end at any prescribed vertex). Suppose `u -> v` in `T`, and suppose neither orientation is on a Hamiltonian path of its tournament. In `T`, a path `u v B` with `B` a Hamiltonian path of `W` starting at `b` exists whenever `v -> b` and `b in W_1`; so `W_1 -> v` (every vertex of `W_1` beats `v`). A path `A u v` with `A` ending at `a in W_m`, `a -> u`, exists whenever some vertex of `W_m` beats `u`; so `u -> W_m`. For `1 <= j < m`, a path `A u v B` with `A` a Hamiltonian path of `W_1 u ... u W_j` ending at `a in W_j` and `B` one of `W_(j+1) u ... u W_m` starting at `b in W_(j+1)` exists whenever `a -> u` and `v -> b`; so for every `j`: no vertex of `W_j` beats `u`, or no vertex of `W_(j+1)` is beaten by `v`. In `T^(uv)` the same three facts hold with `u` and `v` exchanged: `W_1 -> u`, `v -> W_m`, and for every `j`: no vertex of `W_j` beats `v`, or no vertex of `W_(j+1)` is beaten by `u`. Now `W_1 -> u` and `W_1 -> v`. If `W_i -> u` and `W_i -> v` then some vertex of `W_i` beats `u`, so `W_(i+1) -> v` (by the `T` condition), and some vertex of `W_i` beats `v`, so `W_(i+1) -> u` (by the `T^(uv)` condition). By induction every `W_i` beats both `u` and `v`; in particular `W_m -> u`, contradicting `u -> W_m` (`W_m` is non-empty since `n >= 3`). QED

*Proof of (ii).* Every Hamiltonian path of `T` visits `C_1` entirely before `C_2`, and so on; every vertex of `C_1` starts some Hamiltonian path (Camion), so the set of first vertices of the words in `L(T)` is `C_1`; deleting `C_1` from every word gives `L(T - C_1)`, because any Hamiltonian path of `T - C_1` is a suffix of one of `T` (prepend a Hamiltonian path of `C_1`). Induction. Inter-component arcs all point forward, so they are determined. QED

*Proof of (iii).* Exhaustive: for every labelled tournament of order `n <= 7` the language was enumerated and a 64-bit hash of the multiset of path codes compared across all tournaments; for `n = 8` every tournament has a Hamiltonian path, so every collision pair can be relabelled into the marked-path carrier `X_8` (if `L(T) = L(T')` then `T'` contains the standard path whenever `T` does); all `2^21` members of `X_8` were hashed. No collision at any order. The single-pair lemma was also tested directly for every tournament and every dark arc with `n <= 7`: no violation. QED

Dark arcs are not rare in strong tournaments: the smallest example has five vertices (`c, u, v, a, w` with `u -> c, v, w`; `c -> v, a, w`; `v -> a`; `a -> u, w`; `w -> v`: nine Hamiltonian paths, and `u -> v` on none of them, while `w -> v -> u -> c -> a` is a Hamiltonian path after the flip). In a transitive tournament every arc `i -> j` with `j >= i + 2` is dark. So reconstruction is not "every arc is read off a path"; it is that the language, which also records which permutations are *not* paths, separates tournaments. The gap between (i) and all-order injectivity is real: two tournaments differing on several pairs could in principle both avoid all differing pairs even though each single flip is visible, and the flip path of (i) may use another differing pair. HYP-9417 (1) conjectures injectivity for all `n`.

**The strong form, and why it suffices (PROVED implication; FINITE-EXACT evidence).** Call the *strong form* of (i) the statement: for every dark arc `u -> v` of `T`, the tournament `T^(uv)` has a Hamiltonian path through `v -> u` that uses no other dark arc of `T`. *If the strong form holds for every strong tournament, then `T -> L(T)` is injective for all orders.* Proof: let `L(T) = L(T')`, `T != T'`; by (ii) they have the same strong components, and the differing pairs `D` lie inside components and are dark on both sides (an arc of a component is dark in `T` iff dark in the component, since Hamiltonian paths of a component extend to `T` by concatenation and restrict from `T`). Take `e = u -> v in D` inside the strong component `C`; the strong form for `C` gives a Hamiltonian path `P` of `C^(uv)` through `v -> u` avoiding every other dark arc of `C`, hence avoiding `D - {e}`; all arcs of `P` other than `v -> u` are arcs of `C` outside `D`, i.e. arcs of `C'`, and `v -> u` is the `C'` orientation, so `P` is a Hamiltonian path of `C'` through a differing pair, which extends to one of `T'`, contradicting that every path of `T'` avoids `D`. QED. The strong form is **false for non-strong tournaments** (the transitive tournament on 4 vertices with dark arc `2 -> 0` already fails: every flip path through `0 -> 2` must use the dark arc `3 -> 1`), and that is why (i) alone does not give injectivity; but it **holds for every strong tournament tested** ([`legality_strong_lemma_20261026.cpp`](../../04-computation/experiments/legality_strong_lemma_20261026.cpp), [`.out`](../../04-computation/experiments/legality_strong_lemma_20261026.out)): all labelled tournaments of order `<= 7` (48,720 dark arcs inside strong tournaments, zero violations; 186,480 violations in non-strong ones), all of `X_8` (2,195 dark arcs in strong members, zero violations), and random samples of `X_9` (30,000) and `X_10` (3,000). Dark arcs are rare in strong tournaments: 120 of the 544 strong labelled 5-tournaments carry exactly one, 1,440 of 22,320 at order 6 exactly one, 38,640 of 1,677,488 at order 7 carry 48,720 in all. HYP-9417 (1) records the strong form for strong tournaments as the proof target.

**Consequence for the carrier.** The named guard family `{g_p : p in S_n}` with `g_p(T) = [p in L(T)]` separates every two tournaments of order `<= 8`, so the coarsest quotient of `X_n` on which all named guards are well defined is the identity partition, and no proper closed compression of the full named guard family exists at these orders; this reproduces C5's injectivity through `n = 7` and extends it to `n = 8`. Under the fresh (unnamed) multiset dynamics of HYP-9416 the question is different and stays open there.

## 2. Growing alignment memory: what the past Vitali documents supply

Session70's hidden fibre is an ordered sum of `k` blocks, each a choice of `X` or `Y` (rigid seeds with the same rooted endpoint types), closed by a wrapper triangle. Its guard matrix for the block-subset guards is the Boolean zeta matrix `Z[A, B] = [A subset B]`, which is the `k`-fold tensor power of the `2 x 2` matrix `((1, 1), (0, 1))`. Read this way, the growth of alignment memory has a one-line mechanism: *the hidden state is a product of `k` independent two-state attachment sites, each invisible to endpoint data and visible to one named guard; the named guard algebra is the tensor product of the block guard algebras.* Linear memory `2^k` is the dimension of the tensor power, the truncation ranks `d_t = sum_(j<=t) binom(k, j)` are the dimensions of its degree-`<= t` part, and the deterministic cost `k` is the number of factors. This is C4's product amplification restated (strong-atom README, C4) and is not new; it is the mechanism the directive asks for, and it says that memory grows linearly in the number of independent attachment sites and not because of symmetry, selection, or measure theory (A1 and section 6 of the session70 report rule those out).

## 3. Coverage of odd values without the Goldbach antecedent (THM-4806, Theorem G)

An odd value `v >= 3` of `s(n) = sigma(n) - n` has sources of two kinds (S57's split, now exact in [`goldbach_dependent_odd_values_20261026.cpp`](../../04-computation/experiments/goldbach_dependent_odd_values_20261026.cpp)): *(S)* semiprimes `pq` with `p + q = v - 1` distinct odd primes, the Goldbach shape; *(O)* every other source: odd non-squares `n = p m` with `m` odd composite and `p` a prime at most the least prime factor of `m` (then `s(n) >= 1 + m`, so `m <= v - 1`), and even `n = u^2` or `n = 2u^2` (the even `n` with `sigma(n)` odd), `n <= 2v - 2`. A value with (S) sources only is *Goldbach-dependent*; the (O) census needs no Goldbach input and is exact. The program reproduces S57's counts (`8,250`, `56,266`, `462,731` dependent values below `10^5`, `10^6`, `10^7`, plus the untouchable 5 which this count includes), after a correction of its own: the sources `2u^2` with `u` even had been omitted in a first version and change the counts by about one in ten thousand.

**Theorem G (shape lemmas, PROVED).** (i) An odd `v` has a source of shape `p^2 q` (`p`, `q` distinct odd primes) iff `(p + 1) | (v - 1)` and `q = (v - 1)/(p + 1) - p` is an odd prime different from `p`; a source `p^k` (`k >= 3`) iff `v - 1 = p + p^2 + ... + p^(k-1)`. (ii) If `v - 1 = 2q'` with `q' > 3` prime, then `v` has no source of shape `p^2 q` or `p^k`, `k >= 3`: the divisors of `2q'` are `1, 2, q', 2q'`, so `p + 1 in {2, q', 2q'}` forces `p = 1`, `p = q' - 1` even, or `q < 0`; and `p | v - 1` forces `p = q'` and `1 + p + ... + p^(k-2) = 2`. So such `v` depend on Goldbach unless a source with three or more odd prime factors, or an even square or twice a square, exists.

*Proof.* `s(p^2 q) = (1 + p + p^2)(1 + q) - p^2 q = 1 + p + p^2 + q(1 + p)`, so `v - 1 = (p + 1)(p + q)` ... precisely `v - 1 - p - p^2 = q(p + 1)`, i.e. `v - 1 = (p + 1)(q + p)`; integrality and the rest as stated. `s(p^k) = (p^k - 1)/(p - 1)`. QED

**Census (FINITE-EXACT).** To `10^7` (the `10^8` run is reported in section 8): 462,732 of the 4,999,999 odd values are Goldbach-dependent (share 0.09255); by decade the share is 0.4378 (`10^2`), 0.2584 (`10^3`), 0.1525 (`10^4`), 0.1067 (`10^5`), 0.0903 (`10^6`), fitting `c / ln(5 x 10^d)` with `c = 1.40, 1.39` on the last two decades. The dependent values below 180: `5, 9, 11, 17, 19, 23, 25, 27, 29, 35, 37, 39, 45, 47, 51, 53, 59, 61, 67, 69, 71, 75, 77, 79, 83, 85, 91, 93, 95, 99, 101, 103, 107, 111, 113, 115, 119, 125, 135, 139, 143, 147, 149, 151, 155, 159, 163, 165, 167, 171, 173`. The factorisation pattern of `v - 1` is enriched on thin shapes but no single shape dominates: `2 x p q` holds 21.5% of the dependent set (15.9% of all odd `v`), `2 x (three primes)` 13.3% (12.7%), `2 x p` 11.0% (7.0%), `4 x p q` 10.9% (8.2%); within the class `v - 1 = 2 x prime` the dependent share is 0.1466 against 0.0926 overall. So Theorem G (ii) explains an enrichment, not the dependent set: the semiprime-only values are the odd numbers whose every three-prime, prime-power and square shape misses, and their share decays slowly, consistent with `c / log v`.

**Reading through the square-sum problem.** The (S) coverage of `v` is the reflection matching `M_(v-1) = {x, v - 1 - x}` of THM-4510 (sum graphs as reflection orbits) restricted to the odd primes: `v` has a semiprime source iff that reflection sends some prime below `(v - 1)/2` to a prime. The Goldbach-dependent set is therefore the census of odd `v` whose coverage is carried by one reflection matching alone; the (O) shapes are the non-reflection part. The prime-sum graph (vertices the odd primes, edge `{p, q}` labelled `s(pq) = p + q + 1`) is the aliquot analogue of the square-sum graph `Q_n` (edges `{x, y}` with `x + y` a square): in both, a label is a sum and a value is covered iff a labelled edge reaches it; the prime-sum graph covers every odd label `>= 9` iff the distinct-prime Goldbach conjecture holds, exactly as `Q_n` has Hamiltonian paths for every `n >= 25` (Gerbicz, cited in the repo's square-sum notes) and fails only in the window `18-22, 24`. HYP-9417 (2) states the decay prediction.

## 4. The companions of even perfect numbers (THM-4806, Theorem P)

Let `N = 2^(p-1) M`, `M = 2^p - 1` prime (every even perfect number, Euclid-Euler). A *row source* of `N` is `m = 2^a q` with `q` an odd prime (the doubling row of `q`); the inherited formula gives `s(2^a q) = (2^a - 1) q + 2^(a+1) - 1`.

**Theorem P.** (i) `(2^a - 1) | (N - 1)` iff `a | (p - 1)`. (ii) `N` has a row source `2^a q` iff `a | (p - 1)` and `q_a = (N + 1 - 2^(a+1))/(2^a - 1)` is an odd prime; `a = p - 1` gives `q = M` and the source `N` itself; `a = 1` gives `q = N - 3`, which is divisible by 5 whenever `p = 3 mod 4` and is composite for every `p <= 31`. (iii) FINITE-EXACT: the row companions of the first eight even perfect numbers are `652 = 4 x 163` (p = 5), `10828 = 4 x 2707` (p = 7), `8623554304 = 2^8 x 33685759` (p = 17) and `2342443690808840128 = 2^6 x 36600682668888127` (p = 31); none for `p = 2, 3, 13, 19`. The other companions found by the shape census (even sources `2^a M'` with `M'` odd and at most four odd prime factors, within the enumerated bounds) are `10682 = 2 x 7^2 x 109` (p = 7) and `44655764 = 4 x 1669 x 6689` (p = 13); for `p = 2, 3, 5, 13` the census is exact (THM-4805: `25` is the only odd companion, 28 has none, 496 has only 652, 33550336 has only 44655764), and for `p = 19` no companion with at most four odd prime factors was found.

*Proof of (i).* `N - 1 = 2^(2p-1) - 2^(p-1) - 1`. Modulo `2^a - 1`, `2^x = 2^(x mod a)`; with `r = (p - 1) mod a`, `2p - 1 = 2r + 1 mod a`. If `r = 0` the residue is `2 - 1 - 1 = 0`. If `r >= 1`, the residue is `2^x - 2^r - 1` with `0 <= x < a`, a number in `(-2^a, 2^a)` that equals `0` only if `2^x = 2^r + 1` (impossible for `r >= 1`) and equals `+-(2^a - 1)` only if `2^x = 2^a + 2^r` or `2^x + 2^a = 2^r + 1` (impossible). QED. *(ii)* `(2^a - 1) q = N + 1 - 2^(a+1)` and `2^(a+1) = 2 mod (2^a - 1)`, so integrality is `(2^a - 1) | (N - 1)`. For `p = 3 mod 4`, `2^(p-1) = 4` and `2^p - 1 = 2` modulo 5, so `N = 3` and `5 | N - 3`. QED

So the companions of an even perfect number are governed by the divisors of `p - 1`: each proper divisor `a` of `p - 1` offers one candidate row companion `2^a q_a`, realised iff `q_a` is prime (`a = 2` for 496 and 8128, `a = 8` for `p = 17`, `a = 6` for `p = 31`); 28 is a hermit because `p - 1 = 2` offers only `a = 1` (`q = 25`) and `a = 2` (28 itself), and the three-prime shapes start above `2N`. HYP-9417 (3) predicts that the seventh perfect number is not a hermit (a companion with five or more odd prime factors), which the exact census cannot yet reach.

## 5. Two-ray addresses (Proposition, PROVED + FINITE-EXACT)

Checked against brute force for `2 <= x <= 10^4`. The combined table of aliquot124 (cells `2^j r^k`) has `sum_(k | g_odd) (floor(v_2(x)/k) + 1)` addresses for odd part `U > 1`; the difference is the mixed cells: `36` has four two-ray addresses (`36, 2 x 18, 4 x 9` on rows, `6^2` on a column) and five combined addresses (the extra `4 x 3^2`). ## 6. Square-sum, graceful trees, Petersen / K5 / K3,3: the merge
