## 2. The exact source-circuit criterion

Choose disjoint source sets A,B of the same size k, all outside{U,V}. For s in A, move its selected path from U to V; for s in B, use the reverse option. Put

    u = sum_(s in A) e_s - sum_(s in B) e_s,
    v = e_U-e_V.

The paired black perturbation is

    DeltaL=2(uv^t+vu^t).

It has zero row sums and preserves the source and target degree margins. Each actual old resource is removed only once; each new resource is inserted only once in the selected packet. No edge multiplicity is substituted for a missing literal path.

The exact all-H256 condition is that 2u and 2v lie in im(L mod 256). It follows row by row from the perfect finite kernel/image pairing. Direct integer certificates are supplied for these two charges, so acceptance does not require trusting a proposed harmonic basis.

In this original network, the independently audited 2-primary critical group has exponent 256. Therefore these image conditions imply preservation of every genuine dyadic harmonic bank at moduli 2^j. Odd-primary characters remain outside the claim. Beyond 256, the corresponding higher harmonic vectors scale; keeping the same unscaled integer X is a different, usually invalid operation.

A proper subset of source changes preserves target margins only if it contains equally many elements of A and B. In the complete paired-charge module, it is allowed precisely when those two subset sums agree. If no proper nonempty balanced subrelation exists, the complete pinned packet has only two allowed states: all-before and all-after. No smaller simultaneous changed-slot move can connect them while preserving the same margins and node-current signature.

This is the sense of **primitive packet circuit** used here. It does not mean no shorter sequence can exist after releasing pins, using additional outside slots, changing sources, or changing the declared resource inventory.

## 5. A general compatible-supply theorem

Let G be a finite abelian paired-charge group of size M. Suppose N distinct source owners each have a jointly authenticated binary U/V option, where the target paired charges agree. Assume all options preserve the same complete declared shared-coordinate record, all normalized resource orbits in the supply are disjoint, and all kernel lifts remain explicit. These are hypotheses about actual native supply, not consequences of charge counts.

If binom(N,k)>M for some k, two distinct k-subsets have the same sum in G. Cancel their intersection. The remaining source sets A,B are disjoint, nonempty, equal-sized and have equal charge sum. They give two injective packet alternatives with the same target margins and owned current signature. If the source labels are pairwise distinct, neither side can have size one.

This is an EXISTENCE theorem for two compatible packet alternatives. It does not promise a move from an arbitrary prescribed current assignment or supply a global remainder. To extend it, the old state must have the required current and resources, and every new resource must be available or be assigned by a complete compatible reassignment.

For M=2048, binom(14,7)=3432>2048. Thus any 14 jointly compatible source options suffice for some nonempty balanced exchange. Fourteen is the threshold of this displayed middle-binomial criterion, not a claimed optimal universal threshold. Our actual 28-source supply, and even its 20 cost-two subfamily, meet this count; the actual guard and resource authentication remain load-bearing.

If all N labels are distinct and binom(N,2)>M, a pair-sum collision cannot share an index, since cancelling that index would equate two distinct labels. It therefore gives a four-source circuit. For M=2048, N=65 is sufficient by this different criterion. Our current 20-source subfamily does not meet 65; its four-source collisions are found directly, not inferred from that bound.

A constructive dynamic program keeps a subset witness at each (cardinality,charge), as in the coefficients of

    product_s (1+z [label(s)]) in Z[G][z].

A second distinct witness at the same entry yields the exchange after intersection cancellation. There are O(N|G|) entries and O(N^2|G|) state transitions, plus actual witness-storage cost. The preprocessing that authenticates the native supply may be expensive; this does not bypass the known branching or shared-variable hardness boundaries. If resources or shared variables are not already jointly compatible, retain those factors instead of pretending this small DP certifies them.
