## 1. Inheritance and the exact object being completed

Session44, `coupled-moves/THEOREM.md`, supplies the actual kernel-lift
obstruction, lossless one-hot encoding, and alternating matching exchanges.
The incoming `native_guard_moves_farey_20261023/native_moves/
NATIVE_GUARDED_MOVES.md` supplies the hostile where aggregate black capacity
permits amplitude two but an actual source path has capacity one. The earlier
`metagraph_hall_bott_20261023/README.md` uses “Hall” in the physical
fractional-quantum-Hall analogy: it is not a marriage-theorem proof. Its
fixed electrical charge is inherited only with the actual owner atlas.

The present contribution is the missing global resource accounting: subtract
the immutable remainder, normalize source labels to physical owners, retain
the actual partner/converse orbit, and then use a constructive, sharply
scoped completion criterion. The least-used sidecar is the complete target
fibre, including paths excluded by pins. It supplies the new minimal hostile.

Concept board: fixed partner / physical owners / full kernel lifts /
unavailable resources / laminar neighborhoods / shared-variable join tree.
Anchor: partial injection. Niche: a polynomial laminar completion certificate.
Wildcard: a native triple obstruction invisible to all pairwise injections.

Let U be a fixed physical owner set of size n. A raw actual port is

    p = (A, P),

where A is an actual tournament matrix on U and P is an indexed Hamiltonian
path. A local source presentation on V comes with a specified bijection
rho: V -> U. Normalize both the matrix and path using rho before comparing
resources. Identical local integers in different sources are not automatically
shared owners; different local names are not automatically distinct resources.
For unequal underlying owner sets, retain the actual owner subset as part of
the key and require an explicit identification wherever sharing is asserted.

**Owner sharing is not tournament amalgamation.** The owner namespace U
coordinates distinct actual source matrices; it does not assert that those
sources are simultaneous induced subtournaments of one common host. Only
the explicitly declared shared owner occurrences and arc flags are equated.
All other source-specific arcs remain in their separate matrices. If a
common-host realization is claimed, every arc on every source overlap must
also agree and be checked; the completion theorem does not supply that
stronger hypothesis. In particular, the four-source packet below agrees on
its shared arc3->4 but has other conflicting arcs among its shared named
owners. It is a valid shared-observer packet, not a common-host amalgam.

Define k(A,P)=(K_P(A),P) and c(A,P)=(A^op,reverse(P)). The operation K keeps
the n-1 path edges and reverses every other edge. Both k and c preserve the
set of actual ports, are involutions, and commute. For n>=3 their action is
free: k changes at least one off-path edge, while c and kc reverse the
nonpalindromic ordered path. Therefore each resource orbit

    R(p) = {p, kp, cp, kcp}

has exactly four members. The k-pair is a literal line; c takes it to its
literal converse line. This statement concerns raw labelled ports, before
isomorphism quotienting. Ordinary or merged self-converse classes do not
shrink a raw four-element orbit. At n<3 use explicit orbit sizes and
stabilizers instead; the free-block theorem below is stated for n>=3.

**Two different resource carriers.** Raw owner-labelled orbits are not
the original metagraph's normalized unit tiles. The latter quotient out
path-normalizing relabellings; on one fixed canonical source this identifies
paths in the same source-automorphism orbit. Both are legitimate carriers,
but their capacities must not be interchanged. Section 2 first proves the
raw-orbit statement, and Section 2a gives the normalized tiling-unit version
needed for the original native metagraph.

Proof of commutation: transpose reverses every tournament arc and reversal
of P preserves its underlying consecutive-edge set. Thus both routes keep
the same path edges and reverse the same complementary edges. Applying K
twice reverses those complementary edges twice. This also proves every
partner is uniquely determined by its raw port.

**Complete-inventory rigidity.** If the complete actual port inventory and
its owner labels remain fixed, all k-pairs and c-pairs remain fixed. Any
bijection of slot names onto that same inventory changes only presentation,
not its total incidence multiset. A selected packet whose incidence multiset
changes is not a rewiring of this complete canonical object. It can instead
replace a subset of resources in a partial selection; this is the object
completed in the next theorem.

## 2. Exact orbit-resource completion theorem

Assume:

1. A finite immutable remainder F consists of already occupied raw ports.
2. There are d demand blocks, each carrying a free, labelled action of
   <k,c>. Its four slots must be assigned equivariantly to one raw orbit.
3. For each block i an authenticated finite relation lists every allowed
   base record. A record contains its actual source matrix, full path,
   physical owner map, all required local pins, per-slot guards, full lift
   label and the four equivariant images. Different full lifts are retained
   even if they have identical quotient labels.
4. Every shared physical owner value is fixed consistently across all its
   occurrences, or a particular consistent assignment of those values is
   being tested. After those values are fixed, **every nonresource
   requirement factors edgewise**: it is a conjunction of predicates on
   individual full block records, and every retained record passes them.
   This includes all per-slot and within-block guards. No unresolved
   cross-block target margin, aggregate electrical guard, joint lift
   constraint, or other coupled factor is allowed in this iff hypothesis.

Remove any candidate orbit meeting F. Let N(i) be the remaining orbit IDs
admitting at least one authenticated base record for block i. Keep the
records above each edge as witness decorations; do not discard their lifts.

**Theorem.** The requested equivariant selected packet extends F without
recycling any raw port iff the bipartite graph (blocks, orbit resources;
edges i--R for R in N(i)) has a matching saturating all demand blocks.
Every such matching, with each of its edges decorated independently by one
of that edge's allowed full base records, constructs an extension satisfying
all the edgewise requirements. Conversely, every such extension determines
exactly one matching plus those decorations.

Proof: an equivariant block consumes the whole four-port orbit. Distinct
orbits are disjoint. Thus two blocks collide precisely when they choose
the same resource, and the remainder forbids exactly the orbits removed.
All other declared restrictions were checked in the edge record. This
proves both directions and the witness reconstruction. If F is not closed,
the same criterion is still exact for newly added full blocks: even one
occupied member makes that entire candidate orbit unavailable. If a closed
total completion is also demanded, first require or complete F's closure.

**Coupled-guard boundary.** If a global joint guard remains, the graph
still exactly captures the resource condition, but a saturating matching
is only a necessary condition for a fully guarded completion. Merely
writing that guard as a full factor does not make it edgewise. A particular
decorated matching becomes a guarded witness only after that full factor
is checked, and not every matching or every decoration need pass. For
example, two blocks may have unique, distinct resources carrying charges
0 and1 modulo2. Resource matching succeeds, while the joint guard requiring
their charge sum to vanish fails. Section 4 handles genuine coupled guards
by a valid factor join tree or retained residual-state tables; it does not
obtain them from bare matching. The exact general criterion is existence
of a matching **and compatible full decorations passing every joint
factor**, not existence of a matching alone.

Unlike scalar edge-capacity summaries, this raw criterion explicitly
checks literal orbit identities and pin restrictions. It does not by
itself imply normalized native tile capacity; that separate specialization
appears below. A base record
uses one chosen full lift, but all permitted lifts remain in its edge fibre;
the criterion does not replace an entire kernel coset by one representative.
Multiple records above a single edge do not create extra capacity.

One can construct the matching by d augmenting-path searches, each scanning
at most E edges and d+R vertices: O(d(E+d+R)) elementary operations on an
explicit graph. A failed search gives the reached block set X and resource
set N(X) with |N(X)|<|X|. This is a checkable obstruction, not only a Boolean
verdict. No matching algorithm is asserted to be polynomial in n when
listing the native paths or guards is exponentially large.

For M explicitly listed order-n records, validating path legality, owner
maps, the K/converse square and literal equality takes O(M n^2) matrix
operations, plus the declared cost of guard authentication; sorting literal
orbit keys can be done in O(M n^2 log M). Authenticating completeness of
the relation is a separate task. A supplied list proves only sufficiency
unless its completeness in the claimed universe is established.

**Boundary for nonclosed demands.** If a block uses only some members of an
orbit, different blocks may legally share different members. Capacity-one
orbit matching is then sufficient but need not be necessary. If a block
uses several orbits, ordinary matching is not generally sufficient either.
Use the exact finite configuration factors: each candidate records its full
set of consumed raw ports, capacity one is imposed for every raw port, and
all closure/shared-owner/guard factors are retained. This is an exact
finite CSP/set-packing model, not a polynomial matching reduction. It is
the resource-aware specialization of Session44's integer compiler.

## 2a. Normalized native resources: full lifts decorate, not multiply capacity

For a raw port (A,P) on n owners, let w(A,P) be its original forward-bit
word on the nonconsecutive clock pairs (i,j), j>=i+2, in the atlas's fixed
ordering. Write m=(n-1)(n-2)/2. The operation F complements all m bits;
the operation R permutes clock-pair positions by

    (i,j) -> (n-1-j,n-1-i).

Actual k and c descend respectively to F and R. Hence the normalized tile
is tau(p)={w,Fw,Rw,FRw}; use (n,min tau(p)) as its unit resource key. Unlike
a raw orbit, a normalized tile need not have four distinct words: R may
fix a word. For n>=3, the clock pair (0,n-1) is fixed by R, so FR cannot
fix a word because it complements that bit; F also fixes no word. Thus
normalized tiles have size two or four in this range. The n<3 conventions
must be checked separately. Retain the actual tile size, original native colour
and multiplicity in electrical annotations; raw four-port closure alone
does not justify treating every normalized unit as black weight two.

For a fixed source A, two Hamiltonian paths P,Q have the same normalized
word iff the map P_i -> Q_i is an automorphism of A. Indeed, the consecutive
arcs are all forward for both paths and the word specifies every remaining
arc. Equality of words therefore preserves the entire source matrix, and
the converse is immediate. Such different actual lifts are precisely why
distinct raw resources can project to one normalized resource.

**Normalized-resource specialization.** Suppose a demand block consumes
one whole native normalized tile. Replace the right vertices in Section 2
by normalized tile keys, and subtract the already occupied normalized keys
of the immutable remainder before constructing neighborhoods. Above each
block--tile edge retain every authenticated actual owner/kernel lift and
its complete raw K/converse closure as possible decorations. Multiple raw
orbits or full lifts above this edge still provide only **one unit** of
native tile capacity. Require exactly the same edgewise factorization of
all nonresource constraints as in Section 2; otherwise keep the unresolved
joint factors and use Section 4.

Under these hypotheses, saturating matching is equivalent to completion
without reusing a normalized tile, with independent accepted decorations.
The proof is the same resource-injection proof, now for the specified unit
carrier. Distinct normalized tiles automatically have disjoint raw lifts;
the converse fails. A remainder occupying a different raw lift of the same
normalized tile still forbids that tile. If only raw port reuse is banned,
this normalized test is sufficient but can be unnecessarily restrictive.
If native tiling-unit reuse is banned, the raw test alone is insufficient.
The laminar and join-tree criteria below apply to either chosen carrier,
but neighborhoods, region pools and unavailable remainders must all use
that carrier consistently. In particular, disjoint raw region pools need
not be disjoint normalized tile pools. Extracting the four normalized
words takes O(n^2) operations per record, so the explicit-input complexity
bounds are unchanged.

## 3. Laminar eligibility: a short sufficient and necessary certificate

In the edgewise-factorized setting of section 2, suppose the nonempty sets N(i) are
laminar: any two are nested or disjoint. For each distinct neighborhood S,
let d(S) be the number of blocks i with N(i) contained in S, counting
repeated neighborhoods with their full multiplicity.

**Theorem.** A completion exists iff

    d(S) <= |S|    for every distinct neighborhood S.             (L)

This checks at most d inequalities, not all 2^d subsets. It explicitly
uses the neighborhoods *after* subtracting unavailable resources.
With an unresolved coupled guard, it certifies only the resource matching;
the separate joint-factor obligations remain unchanged.

Necessity: all d(S) blocks must use distinct resources in S.
Sufficiency: process blocks in nondecreasing neighborhood size and choose
any still-unused resource in the current S. Every earlier neighborhood
intersecting S is contained in S, by laminarity and the size order. Thus
at most d(S)-1 earlier choices used resources in S. Inequality (L) leaves
at least one free choice. The resulting assignments are authenticated
matching edges, so section 2 reconstructs the actual packet. QED.

There is no loss from ties or repeated neighborhoods. This condition is
testable in O(d^2 R) time by direct incidence-set comparisons, followed by
O(E+d log d) greedy selection; faster laminar-tree implementations are not
needed for the claim. A nonlaminar family may still be matchable, but (L)
alone is then not a certificate. For example, neighborhoods
{a,b},{a,b},{a,c},{a,c} pass both compressed inequalities (2<=2), but
four demands cannot fit their three-resource union. The full matcher
detects this obstruction.

## 4. Shared owners without globally fixing every value: disjoint blocks

The preceding theorem fixes shared values before matching. The following
construction permits them to vary while retaining all their correlations.
Partition demand blocks into regions B. Reserve mutually disjoint resource
pools R_B, each disjoint from F. A resource is assigned to at most one
region; this reservation may deliberately discard otherwise usable choices.
For each region enumerate an exact local table T_B. A row contains:

- every shared physical owner value on the region's interface V_B;
- a complete, locally injective resource assignment from R_B;
- its full kernel lifts, equivariant slot records, and local guards.

A row can be generated by matching or by the laminar greedy criterion.
Retain all feasible interface rows and their full witness decorations, not
merely separate pairwise marginals. Suppose the interface scopes have a
join tree: for every variable v, the regions containing v form a connected
subtree (the running-intersection condition).

**Theorem.** These local packets admit a global compatible injective
completion iff a bottom-up semijoin leaves a nonempty root table. For a
child B of parent A, remove every row of T_A that has no surviving row of
T_B agreeing on all coordinates in V_A intersect V_B. Then choose a root
row and recursively choose supporting child rows. Running intersection
makes all occurrences of each actual owner agree globally; disjoint
resource pools make all chosen local injections globally disjoint. This
proves sufficiency constructively. Any global solution supplies surviving
rows at each elimination, proving necessity within the specified reserved
pool instance. If the pool reservation removed possible cross-region
resource choices, the result is only sufficient for the original instance.

With explicit table sizes L_B and separator sizes h_AB, naive semijoin
cost is O(sum_AB L_A L_B (1+h_AB)); witness reconstruction has the same
or lower bound. Table generation is charged separately and can be
exponential. This is an all-size polynomial *verification/construction in
the explicit tables*, not an all-size compact native relation oracle.

All 27 full lifts of the inherited C9 two-cell relation a=b mod3 must
remain in a table. Joining two such tables by the actual middle owner
b=c mod9 gives 81 global full lifts, not 27^2. If that owner is fixed to
0 on one side and 3 on the other, each local table has three rows and the
quotient values agree, but the semijoin is empty. Actual owner coordinates,
not only their residues, are load-bearing.

**Necessary boundary checks.** Pairwise-compatible tables on a cycle need
not glue: constraints a=b, b=c, a!=c on binary owners pass each pair but
have no global row. A join tree is essential. Disjoint region resources
are equally essential: independently feasible local matchings may reuse
the same literal orbit. The native hostile below demonstrates the resource
failure even when every shared owner is fixed consistently.

For an aggregate modular guard, include its full factor in a valid join
tree or carry a subtree residual vector in (Z/mZ)^q and require root
residual zero. Naive merging costs an additional factor at most m^(2q)
per pair of interface rows. Exact integer residuals require explicit
bounded ranges or exact finite reachable-sum tables. This exponential
dependence is not hidden. A fixed per-slot mod8 phase alone does not imply
the aggregate current equation, any higher dyadic layer, or universal
harmonic-bank preservation.
