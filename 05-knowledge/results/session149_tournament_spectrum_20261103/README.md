# Session 149: tournament path spectrum and class symmetry

The complete Hamiltonian-path count spectrum and an intrinsic explanation of even tournament-class counts remain open. The packets below distinguish proofs from finite experiments and cite prior work; no novelty or priority is asserted without verification.

- [Converse-class symmetry](symmetries/README.md): small exact class diagrams and the previously known anti-involution/centralizer model. Converse has fixed classes, so it is not a free pairing. A sorted pairing is explicitly artificial.
- [Two-adic census divisibility](divisibility/PROOF.md): exact odd-order valuations and an even-order congruence, derived from Davis's formula.
- [Second even-order bit](divisibility_extension/PROOF.md): an independently audited congruence modulo four for the normalized count, conditional only on the cited Burnside formula.
- [Cyclic transitive-block path enumerator](compositions/COMPOSITION.md): an exact generating function, family formulas, and subset-DP controls.
- [Finite decision bound](decision/DECISION.md): known strong-tournament minima give a finite exact test for each target count; this does not settle the spectrum.
- [One-apex spectrum](spectrum/FINDINGS.md): an exact count identity and finite decision bound for a restricted family, plus a checked example. This does not classify the global spectrum.
- [Toothpick correction](toothpick/CORRECTION.md): the seeded configuration has a half-turn with one fixed segment, obstructing a literal equivariant injection from all tournament classes under converse.
- [Even-graph bridge](even_graphs/bridge.md): a sourced equinumerosity result and counterexamples to simple symmetry proposals.

Reproduction commands and scope limits are in each packet. Local computation verifies finite cases and does not establish unresolved all-order classifications.
