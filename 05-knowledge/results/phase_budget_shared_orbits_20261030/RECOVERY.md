## 3. The normalization correction and its survivor

    M(S)=1/2 iff every v/g is odd.                       (1)

The reverse direction uses t=1/(2g). Conversely, if each distance is1/2 at t,
then (2gt)(v/g) is an odd integer for each v. Bezout for the primitive speeds
