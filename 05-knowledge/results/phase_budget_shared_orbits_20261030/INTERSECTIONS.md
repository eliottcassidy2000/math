# Composite intersections and same-port alternating selectors

**PROVED elementary / FINITE-EXACT controls.** The incoming Session113
[composite phase theorem](../session113_symmetry_consumers_20261030/composite/COMPOSITE_PHASE.md)
already proves the two-parameter common-bank classification and hidden

## 1. An exact signed-partition carrier

On a named vertex set, x_{ij}=1 means i->j for i<j. A signed-partition chart
is the solution set of constraints

    x_e xor x_f = c_ef,       x_e=c_e,       c in F2.      (1)

An empty chart is allowed. The source frame, program, endpoint ports and
retained kernels are sidecars, not implicitly quotiented. A parity union-find
with a constant-zero vertex computes consistency and the number d of free
components; a consistent chart has2^d points. Contradictory cycle gains or
pins make it empty. This is the existing repository parity compiler, applied
to chart intersections, not a new union-find algorithm.

For a cyclic parent generated by a, invariance is exactly

    x_{unordered e} xor x_{unordered a(e)}
       = [a reverses the displayed endpoint order].      (2)

The carrier is closed under:

* intersections: concatenate equations;
* legal fixed Hamilton-path complements: pin the directed path edges, then
  flip the other bits, adjusting each equation's right side;
* relabelings and converse: signed coordinate permutations/translations;
* substitution into fixed nonempty named blocks: copy each quotient-edge
  bit to all corresponding cross-block edges, and add independent internal
  charts, with endpoint-order signs retained.

For substitution, every input edge variable has at least one output copy.
Thus the map on the supplied factor variables is injective. Equalities and
pins remain equalities and pins after copying; no general linear relation
with three or more variables is introduced. Fixed identified shared ports
are handled only when their variable identifications, distinct-vertex guards
and no-self-loop guards are explicitly included. The injectivity assertion
above concerns disjoint nonempty substitution blocks, not arbitrary gluing.
Variable-size decompositions, unrecorded clone mergers and forgotten source
ownership are not licensed by this statement.

For native charts with transported cyclic parents H1,...,Hk, the common
homogeneous directions are constant on unordered-edge orbits of
G=<H1,...,Hk>. Every retained pin fixes the entire orbit it touches. Consequently,
**if the affine equations are consistent**, then

    dim(intersection)=number of G edge-orbits untouched by any retained pin. (3)

This is exact even when different histories supply incompatible offsets;
the consistency check must precede counting. No enumeration of G is needed:
the generator actions on edges determine its orbits. The initial banks may
be disjoint while translated native charts intersect.

Unions need lists or signed indicator combinations of charts; a union is
not generally one chart. Exact intersection oracles feed the inherited
ranking and multiplicity formulas, but do not bound the number of charts or
the full isomorphism quotient. Arbitrary negative incidence conditions may
require NAE constraints: the five-vertex positive-DSU hostile in Session36
is a standing guard against treating this carrier as universal SAT.

### Weighted counts without resampling the source

Suppose the supplied source weight factors as product_e w_e(x_e), with
values in a commutative ring. In a free signed component C write
x_e=y_C xor eta_e. Its contribution to the exact weighted intersection is

    product_(e in C) w_e(eta_e) + product_(e in C) w_e(1 xor eta_e).

Multiply these contributions over free components and multiply the fixed
components' specified weights. This follows by summing each independent y_C
once, and works equally for integer, rational or signed weights. Count2^d
is the special case w_e(0)=w_e(1)=1. Fixed native moves transport weights by
their inverse signed coordinate map. After a substitution, a source quotient
factor belongs to one original variable, not once to every copied output edge.
Retaining factor ownership prevents raising a source weight to the number of
copies. Arbitrary nonfactorizing source measures require their actual pullback
or explicit summation; this formula is not permission to replace them by product
or uniform measures.

## 2. The inherited large composite overlap

Let r,m>=3 be odd, n=rm, x=i+rj. Put a(x)=x+1 modulo n and
v(x)=x+r modulo n for x=0 modulo r, fixing the other fibres; let b=vav^-1.
The incoming theorem identifies the common invariant tournaments as S[R],
where S and R are arbitrary circulant tournaments on r and m labels. There
are (r+m-2)/2 common orientation coordinates. The natural path0,1,...,n-1
pins just one outer coordinate. After the same legal path complement, the
intersection has exactly2^((r+m-4)/2) points with ports0,n-1.

The incoming collective character chi=sum z_i-t modulo gcd(r,m) is a
different coordinate: it is invisible to every tuple missing a fibre.
Equation(3) counts tournament-edge variables; it does not recover this
higher-arity transporter character. Any consumer testing shared transversals
must still retain chi or equivalent kernel lifts.

## 3. A constructive selector with the same endpoint ports

**Theorem.** For every odd r,m>=3 there is an explicit Hamilton path P* from0
to n-1 such that the two common-parent native charts obtained by complementing
along P* intersect in exactly one tournament.

For t=2s+1, define the alternating permutation

    W_t=(0,2s,1,2s-1,2,2s-2,...,s),
    alpha_t=2W_t modulo t.                               (4)

Visit outer fibres in alpha_r order, and inside every visited fibre visit
the internal coordinates in alpha_m order:

    P*=(i+rj : i in alpha_r, then j in alpha_m).           (5)

This is a permutation of all n vertices. Its first vertex is0; since
alpha_t ends at2s=t-1, its last vertex is(r-1)+r(m-1)=n-1.

To prove legality and completeness of the pins, the consecutive differences
in W_t are d_k=(-1)^k k modulo t, k=1,...,2s. The pair k,t-k has the same
difference, and the distinct differences are2,4,...,2s modulo t. Thus
alpha_t has differences in

    D_t={4,8,...,4s} modulo t,                            (6)

each occurring twice. This set contains exactly one of each pair {d,-d}:
if4k=-4l modulo t for1<=k,l<=s, then k+l=t, impossible since k+l<=t-1.
It therefore defines a circulant tournament with every edge of alpha_t
oriented forward. Choose S and R with connection sets D_r,D_m. Then P* is
legal in S[R]. Every outer distance pair is touched between fibres, and
every inner distance pair is touched within them. All common coordinates
are pinned consistently, proving that there is exactly one common source
tournament. The same fixed complement mask is an injective translation,
so the two output charts intersect in exactly one point as well. QED.

This construction uses the alternating graceful permutation as a tool. It
does not prove the graceful tree conjecture. It selects one member of the
common bank, rather than supplying a path valid in every common member.
It also does not make all arbitrary composite chart intersections points.
The same ports admit both the old exponentially large intersection and the
new singleton; retained internal incidence distinguishes them.

## 4. Controls and the remaining enumeration target

`tournament_audit.py` checks the three ranks (unrestricted, natural-path,
selector-path) by signed union-find and independent binary Gaussian elimination,
then enumerates the actual S[R] banks directly. The eight tested pairs are
(3,3),(3,5),(3,9),(5,5),(5,7),(7,7),(3,19),(11,3), reaching57 vertices.
Their old intersections have sizes2,4,16,8,16,32,512,32; every new intersection
has size1. The explicit orientation is checked against both parent generators
and every path edge. Arc-reversing and contradictory-sign hostiles are rejected.

The next open enumeration question is quantitative: can selector-adapted
signed-partition charts cover a useful complement-closed class with controlled
owner multiplicities and number of charts? Efficiently counting one specified
intersection does not answer that question. Applying a selector may restrict
away the source one wanted to cover, so source membership remains mandatory.
