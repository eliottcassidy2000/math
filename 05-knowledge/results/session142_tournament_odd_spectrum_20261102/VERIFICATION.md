# Verification and limitations

```sh
python3 -B /absolute/path/to/this/packet/replay_checkpoint1.py
cd /absolute/path/to/this/packet
sha256sum -c SHA256SUMS
```

The replay relocates only the selected frozen scientific files into a fresh
temporary tree and executes them from a separate unrelated working directory.
Ordinary and optimized(`-O`) Python must reproduce the frozen output bytes.
All gates use explicit exceptions, not assertions disabled by optimization.
The exact configuration and outcomes are in REPLAY_CONFIG_CHECKPOINT1.json
and REPLAY_CHECKPOINT1.json.

Scientific hostiles change a small strong spectrum, a polynomial determinant
claim and an independent exact identity. A same-size proof-byte corruption
must fail the source-integrity check in both modes. These prove the named
gates fail closed, not that every conceivable implementation bug is caught.
Both Git blob and SHA256 identities of selected source snapshots are verified
offline; the packet seal covers every published file except its own checksum
file. Independent review is a separate human-readable proof/status audit.

Infinite statements depend on their written proofs and cited hypotheses;
finite calculations are corroboration. The exhaustive n<=6 Boolean census
has33867 labelled inputs. The structural exclusion cover has272 overlap
presentations, not272 representatives of the entire labelled universe.
Arithmetic target-monoid tests do not establish tournament realization.

Documentation checks are deliberately scoped to startup budgets, unchanged
startup truth surfaces, owned-file conflict markers and curated publication
links. The full repository checker was **not run**, because it reads the
central mistakes ledger. This is not a full-repository documentation pass.
No Lean/Isabelle build, global spectrum proof, unrestricted construction
classification or independent rerun of the large inherited prefix is claimed.


## Checkpoint2

`python3 -B replay_checkpoint2.py` uses106 pinned selected files and reruns
the preserved checkpoint1 wrapper. New ordinary/optimized scientific runs
check the symmetry tables and actual binary language, plus independent
matrix/recursive counts and literal path-word/cover graph transfers. The
independent construction audit covers2196 actual S/R transfers on all
labelled parents of orders1..4 and every cut. Infinite statements remain
written-proof claims with the audited scope, not extrapolations.

The second wrapper has26 top-level executions:16 positive runs and10 expected
rejections. Hostiles falsify the prime threshold, binary response identity,
independent substitution minimum and neutral reset identity; same-size
proof corruption must fail. The first wrapper's nested checks are additional.
Source Git-blob/SHA identities and exact frozen producer/auditor selections
are checked offline. Archived checkpoint1 manifests describe its original
packet, while current SHA256SUMS seals both checkpoints and updated syntheses.


## Checkpoint3

`python3 -B replay_checkpoint3.py` relocates194 selected source files and
reruns the frozen checkpoint2 wrapper, which also reruns checkpoint1. The
new tests include both exact path-cover implementations, actual literal
prime-count witnesses, their independent adjacency reconstruction/count,
the unchanged portable inverse suite and C++17 full order19 subset DP
compiled at O0/O2. The order29 witness uses a direct graph partition formula,
not full subset DP.80498 inverse controls and598 small graph controls are
rerun; the inherited billion-pair100million-prefix scans are not.

The third wrapper has28 top-level executions:18 positive and10 expected
rejections, in ordinary/optimized Python. New hostiles falsify the cut
incidence bound, factorial/run convention, recovered count and independent
max-before/min-after count. Same-size proof corruption must fail. The
producer's malformed-graph/partition and wrong-count hostiles run inside
its portable suite as additional controls. All previous scientific bytes
and replay reports remain unchanged.

Two historical TSV sources exceed the transport batch ceiling. They are
unchanged files, published by referencing their already-existing remote
Git blobs, verified against the source path and published commit; no source
is truncated, omitted or rewritten. Final repository checkouts contain the
ordinary complete files, so offline replay requires no transport handling.
The final source manifest and packet seal verify their full original bytes.
