# Session 142: asymmetric prime lanes

`PROOF.md` proves that every tournament with prime Hamiltonian-path count
p>3 is asymmetric. For H=7p, p>=11, the automorphism group has order 1 or 7;
all such witnesses at prime p<593 are asymmetric, and an exact strong
10-vertex witness H=4151=7*593 makes the threshold sharp.

This is a structural strengthening of the inherited two-prime-lane frontier,
not a proof of the global spectrum conjecture. `verify.py` replays the small
complete tables and literal controls; normal and optimized receipts match.
