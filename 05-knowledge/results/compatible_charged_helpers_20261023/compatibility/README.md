# Exact compatibility costs for charged helper routes

**PROVED, scoped:** [Compatibility intervals and exact neutral-fibre lifting](NEUTRAL_FIBRE_LIFTING.md).

Fixing a genuine helper configuration turns its pairwise interactions with
old endpoint records into an interval of the old implication-upset lattice.
The joint electrical/current equation remains separate and retains actual
physical rows, diagonal margins, shared pins and normalized resource units.

For a move budget b, retain every charged component and every component
heavier than b. The remaining neutral components form connected fibres.
Two such interval fibres have exact minimum weighted distance

    w(L_alpha \ R_beta) + w(L_beta \ R_alpha).

Adding that boundary cost to the visible/helper change gives a quotient graph
which preserves **exactly** all b-budget packet-connectivity questions. Its
edges come with explicit full-record witnesses and a route reconstruction.
This neither supplies missing helpers nor converts lattice span into binary
feasibility.

Retaining equality of the actual first final-C3 owner in m+1 slots forces a
move of m+1 slots and3(m+1) clock occurrences, despite zero charge difference.
The boundary formula detects this cost. Kernel multiplicity remains one
capacity unit and converse sends the shared clock to2.
