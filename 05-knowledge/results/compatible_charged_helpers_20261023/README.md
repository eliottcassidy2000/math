keeps every actual shared owner and capacity constraint. Binary endpoint
mixtures form implication upsets. Each complete helper configuration restricts
them to an interval [L,R]. Aggregate physical-row charges remain an additional
joint factor, rather than being mistaken for a pairwise constraint.

After retaining charged and over-budget components, light neutral coordinates
can be removed without losing bounded connectivity. The exact least cost of
crossing between two neutral fibres is

    w(L_alpha \ R_beta) + w(L_beta \ R_alpha).

Adding that boundary cost to the actual visible/helper change produces an
exact connectivity quotient and a constructive route lift. It preserves
simultaneous forced changes; checking only interval intersection would miss
legal coupled moves, while ignoring the boundary cost would invent illegal
ones. Kernel choices remain owner records, never extra capacity.

An actual all-size C3-kernel construction attains arbitrarily large mandatory
shared-owner packets despite zero electrical difference and disjoint ports.
Thus an all-size theorem for arbitrary guards must retain a variable boundary
cost or restrict the compatibility structure. A universal constant support
bound independent of arbitrary shared pins is false in this interface.
