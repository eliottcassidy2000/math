## 1. The quotient and its complete invariant

For odd u>=3, write

```
V_u={v: 0<v<u, v odd, gcd(v,u)=1},
Xi(u,v)=(uv,(u²-v²)/2,(u²+v²)/2).
```

Every class of `(Z/uZ)^*/{+1,-1}` has a unique odd representative between
0 and u. In this representation multiplication by 2 is D_u. Therefore:

**S1.** Two triangles Xi(u,v), Xi(u,w) lie in the same D_u cycle iff
`w/v` belongs to the subgroup generated by 2 and -1 modulo u. The complete
cycle label is the coset in `(Z/uZ)^*/<2,-1>`.

*Proof.* D^j(v) represents +/-2^j v. Conversely any such unit equality
is exactly an iterate equality after taking the unique odd representative.
This proves both directions, without discarding the common outer root.

All cycles have length `d_u=min{k>=1:2^k=+/-1 mod u}` and there are
`phi(u)/(2d_u)` of them. A character trivial on both 2 and -1 is conserved.
One character need not be a complete invariant at general u; the full coset is.

## 2. u=17: a quadratic character, and a nontrivial switching phase

Here 2^4=-1 mod17 and 2 has order8. The subgroup <2,-1> has eight elements
and is exactly the quadratic-residue subgroup: 2=6² and -1=4² modulo17.
Thus the Legendre character `(v/17)` completely distinguishes the two cycles:

| Character | Inner roots in D order | Primitive triples in that order |
|---|---|---|
| +1 | 1,15,13,9 | (17,144,145), (255,32,257), (221,60,229), (153,104,185) |
| -1 | 3,11,5,7 | (51,140,149), (187,84,205), (85,132,157), (119,120,169) |

This is a conserved arithmetic sector, not an accidental failed search.

Let M_a denote multiplication by a followed by the same odd representative.
Multiplication by 3 exchanges the two sectors and commutes with D. It also
satisfies

```
M_3² = D³,                                               (S2)
```

because 9=-8 mod17. In fact 3 has order16 modulo17, and its quotient class
has order8. Thus the scalar action is C8, with a C4 subgroup and a C2
quotient. It is **not** C4 x C2. There is no scalar multiplication of order2
which exchanges the sectors: the only scalar involutions in the quotient
are identity and the class of 4 (odd representative13), both quadratic residues.

One may choose an involution exchanging the two four-cycles as abstract
permutations, but it cannot be a single scalar multiplier. This is the phase
that an unqualified XOR analogy would lose. See the explicit cube model in
the [dissection lane](prime_shells_20260921_dissections.md).

## 3. The same split is a quadratic field inside the real 17th cyclotomic field

Let zeta=exp(2*pi*i/17), x_v=zeta^v+zeta^(-v), and
`eta=x_1+x_15+x_13+x_9`. Multiplication gives x_v²-2=x_(2v), so the D
orbits are genuine four-cycles for x->x²-2 on this finite set. This is a
cyclotomic angle coordinate, not the triangle's Euclidean angle.

Direct reduction modulo `1+zeta+...+zeta^16=0` gives

```
eta²+eta-4=0,
P_+(X)=X⁴-eta X³-(2+eta)X²+(3+2eta)X-1,
P_-(X)=X⁴+(1+eta)X³+(eta-1)X²+(1-2eta)X-1.             (S3)
```

The first polynomial has roots in the + sector and the second in the -
sector. The nontrivial automorphism eta->-1-eta exchanges them. Their product is

```
X⁸+X⁷-7X⁶-6X⁵+15X⁴+10X³-10X²-4X+1.                  (S4)
```

For a reproducible algebraic proof of the reductions, expand
`product_(v in C)(X-zeta^v-zeta^(17-v))` in the ring above; its five
coefficients (constant first), written alpha+beta*eta, are

```
C+ : (-1,0),(3,2),(-2,-1),(0,-1),(1,0),
C- : (-1,0),(1,-2),(-1,1),(1,1),(1,0).
```

These finite polynomial identities are checked with integer coefficient
arithmetic, not floating-point factor recognition. Alternatively eta is the
sum over all eight nonzero square exponents; convolution of that set yields
the same quadratic identity.

Since eta is a root of the irreducible polynomial T²+T-4,
Q(eta)=Q(sqrt17). The two orbit sums are the pair `(-1+/-sqrt17)/2`.
Polynomial (S4) is irreducible over Q: Phi_17 is irreducible by Eisenstein
after translation, and the real element zeta+zeta^-1 has degree8 since zeta
satisfies a quadratic over it but is not real. Thus two **dynamical** orbits
can together form one **rational Galois** orbit. Over Q(sqrt17), each
quartic is irreducible, since the subgroup <2> acts transitively on its roots.

This is the same field-tower structure that underlies the constructible
regular 17-gon. No metric isometry of the eight triangles is claimed.

There is also a differential invariant that transfers. For any shell cycle
of length d, with 2^d=epsilon mod u, epsilon in {+1,-1}, the multiplier
of f(X)=X²-2 around that cycle is exactly

```
(f^d)'(x_v) = epsilon*2^d.                              (S4a)
```

Indeed f^d(2cos theta)=2cos(2^d theta), so differentiation gives
`2^d sin(2^d theta)/sin(theta)`. The denominator is nonzero for an odd
unit conductor, and the signed return makes the ratio epsilon.
Both u=17 cycles therefore have multiplier -16; the period/character
separates them while this local differential observable does not.

## 4. Prime-power lifting: splitting versus lengthening

Fix any odd prime p. Put

```
d=d_p, epsilon=2^d mod p in {+1,-1},
r=v_p(2^d-epsilon).
```

**S5.** For every e>=1 the shell with outer root p^e has

```
period d_(p^e) = d*p^max(0,e-r),
cycle count B_(p^e) = (p-1)/(2d) * p^min(e-1,r-1).      (S5)
```

*Proof.* Any signed return exponent modulo p^e must be d*j. Modulo p
its sign is epsilon^j. The other sign differs by2 and cannot be a return
modulo p. The binomial valuation identity for odd p gives

```
v_p(2^(dj)-epsilon^j)=r+v_p(j).
```

To prove that identity, write epsilon*2^d=1+p^r c, p not dividing c.
Raising to an exponent coprime to p leaves the valuation r; raising to p
raises it by exactly one, since the first binomial term has the unique
least valuation. Factor j into its p-power part and its coprime part.
The least j that reaches valuation e is p^max(0,e-r). Divide the
phi(p^e)/2 vertices by this common period to get the count. QED.

Also `r=v_p(2^(p-1)-1)`: the unsigned order is either d or2d, and the
remaining exponent factor dividing p-1 is coprime to p. Thus r>=2 is
exactly the base-two Wieferich condition. The unsigned order-lifting
criterion is also [CITED: Dular, Lemma4.5 and Proposition4.6](https://arxiv.org/pdf/1905.01765);
the signed quotient and triangle count above are proved directly.

By (S4a), the same r is `v_p((f^d)'(x_v)-1)`. Thus the Wieferich
condition is an extra order of p-adic closeness of the cycle multiplier
to1. This is a scalar identity in characteristic zero, not a theorem
about a distinct period-d cycle after reduction modulo p: primitive
p-th roots coalesce at1 over p, so all these x_v reduce to2 there.

The reduction of odd unit classes from p^(e+1) to p^e commutes with D and
has p lifts per vertex. Consequently every lower cycle has either one
cycle above it of p times the length, or p cycles of the same length.
Equation (S5) decides which occurs: **split while e<r, lengthen once e>=r**.

| p | d_p | r | shell p: cycles x length | shell p²: cycles x length |
|---|---:|---:|---|---|
| 17 | 4 | 1 | 2 x4 | 2 x68 |
| 1093 | 182 | 2 | 3 x182 | 3279 x182 |
| 3511 | 1755 | 2 | 1 x1755 | 3511 x1755 |

At 17 the same two sectors persist at every power and their cycles lengthen.
At the two displayed Wieferich primes, a new p-fold separation occurs on
the first lift. Exact modular powers verify r=2 for each; no claim is made
that these are the only Wieferich primes or that a new one was discovered.

## 5. Composite conductors need a common sign

Let u=product p_i^e_i, let d_i be the local signed periods, and L=lcm(d_i).
Each local `sigma_i=2^L mod p_i^e_i` is +1 or -1. Then

```
d_u = L if all sigma_i agree, and 2L otherwise.          (S6)
```

*Proof.* Any global signed return is a multiple of every d_i. At a
multiple L*t the local signs are sigma_i^t. If they disagree, every odd t
fails and t=2 succeeds. If they agree, t=1 succeeds. QED.

For 63=9*7, d_9=d_7=3, but 2³ has signs (-,+), so the global period is6.
For 65=5*13, L=lcm(2,6)=6, and the local signs are (-,-), so it is6 already.
Both have period6, for different local reasons; their counts3 and4 follow
from phi(63)/12 and phi(65)/12. The first hostile to using just lcm is15:
d_3=1,d_5=2, but d_15=4. Local reflections are identified only diagonally.

## 6. Comparison with inverse Collatz braids

For q=2^ord_p(2), c=(q-1)/p, define R_p(n)=qn+c. The inherited exact identity is

```
v_p(R_p^t(n)-n)=r-1+v_p(t).
```

Thus on odd residues modulo2*p^s its common period is p^max(0,s-r+1)
and its cycle count is p^min(s,r-1). Compare (S5): the same r controls
both consumers, with a one-level shift because division by p consumes
one factor of p. At a Wieferich prime r=2, the affine braid fixes the
first source digit, while the triangle shell gains p cycles at p².

The source map is an **inverse-fibre** recurrence for `(pn+1)/2`:
its target is multiplied by q and its odd core is fixed. It is not a
forward Collatz trajectory. The shared valuation transports the period
defect, not an assertion of positive-integer descent. Wolstenholme
quotients use another valuation test; see the [prime lane](prime_shells_20260921_primes.md).
