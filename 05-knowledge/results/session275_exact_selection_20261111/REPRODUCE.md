# Reproduction and scope

Python3 standard library only. Run from repository root. No external downloaded
atlas is needed to replay final claims; source masks are embedded. The exploratory
search scripts remain as research provenance, not dependencies of the proofs.

```
python3 -B 05-knowledge/results/session275_exact_selection_20261111/switches/replay.py
python3 -B 05-knowledge/results/session275_exact_selection_20261111/switches/expand.py
python3 -B 05-knowledge/results/session275_exact_selection_20261111/seams/check.py
python3 -B 05-knowledge/results/session275_exact_selection_20261111/descent/check.py
python3 -B 05-knowledge/results/session275_exact_selection_20261111/descent/escape.py
python3 -B 05-knowledge/results/session275_exact_selection_20261111/landscape/experiment.py
python3 -B 05-knowledge/results/session275_exact_selection_20261111/landscape/bridge63.py
python3 -B 05-knowledge/results/session275_exact_selection_20261111/landscape/portal.py
python3 -B 05-knowledge/results/session275_exact_selection_20261111/landscape/check_portal.py
python3 -B 05-knowledge/results/session275_exact_selection_20261111/review/verify.py
```

The landscape producer exhausts all fixed-path charts through7; independent
review replays smaller charts with permutation counts and explicit BFS, and
checks every literal63 bridge independently. It does not independently rebuild
the entire n6/n7 census. The new algebraic statements are proved in the notes;
finite controls do not substitute for their all-length arguments.

Final-source replay receipts and the review state exactly which inputs were
checked. No claimed Chan–Pak proof, eventual cutoff, external theorem verification,
or complete tournament classification is part of this packet.
