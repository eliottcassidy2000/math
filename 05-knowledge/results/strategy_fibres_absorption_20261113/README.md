# Reframing Chan–Pak through factorization, fibre transport and absorption

**PROVED scoped results / FINITE-EXACT experiments / CITED outside methods.
Chan–Pak remains OPEN.** This session changes which construction questions
to pursue. It does not extend a numerical coverage record or claim a full
metagraph classification. The target remains every positive odd Hamiltonian
path count except7 and21, as stated in
[Chan–Pak, Conjecture6.2](https://arxiv.org/html/2308.10214v2#S6.SS5), which credits
the 2016 conjecture of bof and Gordon Royle.

The central change is to separate **new target supply**, **transport between
witnesses of one target**, and **terminal correction**. A single repeatable
ready-return operator was being asked to do all three. The exact results
below show that these jobs have different invariants and different failures.

## Remove operations that cannot supply the critical targets

[The ordinal-cut theorem](orbits/PROOF.md) splits every word at the inherited
rank-one generator R into actual rooted ordinal-sum components. Each closed
excursion can be realized without R. Removing R preserves every prime and
seven-times-prime target and the multiplicative closure of the scalar language.
This matters because the inherited
[THM-4094, hamiltonian-matching-deficit-and-two-prime-lane-completeness](../../../01-canon/theorems/THM-4094-hamiltonian-matching-deficit-and-two-prime-lane-completeness.md)
reduces Chan–Pak to those infinite lanes, with known finite carry atoms.

[The singular-word refinement](orbits/SINGULAR.md) gives representations of
all represented critical targets avoiding R and the subwords XX, NN, XCN,
where X ranges over M3,M4,M5, C=M2, and N=M6. The argument retains actual
tournament factors on both sides of each rank-one identity. Coordinate gcd
alone would be unsafe: the strong count1757=7·251 has state(1757,994,1372),
whose gcd is the forbidden count7.

Complete searches with H<=10001 find517983 full states before removing R and
408813 afterward. The only lost scalar values are55,559,951,1837; none is
critical. The remaining language misses primes47,67,127,163,173,331,491 and
seven-primes511,959 in that range. These are language failures, not global
tournament omissions. No tail conclusion is inferred.

## Repair the actual witness for the specified consumer

[The fibre theorem](fibres/PROOF.md) uses five specified atoms S,T,Q,U,V with
(order,H)=(1,1),(3,3),(4,5),(5,9),(5,15). This is a chosen dictionary, not a
claimed canonical mathematical collection of five. Their ordinal words have
a minimal all-order repair basis

    TT <-> SU,     TQ <-> S²V,     QU <-> STV.

The first two moves generate all integer relations but cannot move inside
the H45/order9 fibre {QU,STV}. One extra singleton repairs the boundary:

    SQU -> TTQ -> TS²V -> S(STV).

The helper is returned and can be reused. The proof classifies all possible
two-bin path-cover responses P2 in each fibre and explicitly inverts a
prescribed response. QU and STV have P2 values2688 and2592. For the specified
strong consumer C1[D], the full next count is H(D)+P2(D), so this repair
question has an exact consumer-specific answer. The general finite-bank
theorem uses the nonnegative relation mechanism behind Markov/Graver bases.
It creates no new prime factors: its value is transport, not supply.

## Growth and locality constraints

[GROWTH.md](GROWTH.md) makes two inherited-bound consequences explicit.
In a pure-birth chain with k count-increasing steps, all k newborn cyclic
vertices persist. Hence

    c(T_initial)+k <= K(H_final) <= 3 log_3 H_final.

No infinite additive +2 birth chain exists, even with unlimited neutral
padding. Branching constructions and rewiring are outside this obstruction.
Conversely, if both endpoint counts already exist, logarithmic core witnesses
give an automatic O((log H)^2)-arc batch replacement. Assuming the desired
witness and allowing that whole batch does not advance existence.

The useful middle ground is constructive, limited transport plus a terminal
absorber. [A1](absorption/PROOF.md) proves a sufficient certificate: if an actual
connected witness graph has jumps at most2D, and every lower endpoint can
correct by0,2,...,2D−2, all intervening odd targets are attained. The output
need not be ready again. Neither hypothesis is proved uniformly here.
