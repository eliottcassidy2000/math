# The port-chain reset closes an ordinal-sum component

**PROVED, scoped elementary result; FINITE-EXACT companion audit.** This note
removes one inherited generator without losing any prime or seven-prime target.
It does not prove a tail-coverage assertion or the Chan--Pak conjecture. Other
singular generators remain in the reduced alphabet. “R-free” below means only
that the particular generator R is absent.

## 1. Exact setting

For a rooted tournament (T,u), use the inherited column

    s(T,u)=(h,E,O)^t,       s0=(1,0,1)^t,

where h is the Hamiltonian-path count. E, respectively O, sums over directed
paths P starting at u with an even, respectively odd, number of vertices,
weighting P by H(T minus V(P)). The empty complement has count one.

A marked block has internal tournament B, link vertex w, and new root v.
All old-to-block arcs point forward except w->u. The new root is v. The
inherited matrix law is exact for these actual rooted tournaments, not just
formal cone points.

Number the matrices in their inherited file order. Two are

    R=M1=[1 2 0; 0 0 0; 1 2 0]=s0 ell,
    C=M2=[1 2 0; 0 0 1; 1 1 0],       ell=(1,2,0).

R uses a two-vertex block with arc 1->0, link vertex 1 and new root 0.
C uses a singleton block, serving as both link and root. Let A be all thirteen
matrices and B=A minus {R}. A word is read in construction order: its last
matrix acts on the left.

## 2. Literal component-closing theorem

**Theorem 1.** Write any A-word uniquely as

    w=v0 R v1 R ... R v_(m-1) R vm,

where each vi is a B-word, possibly empty. Let T(v) be the rooted tournament
built from a singleton by v. Then the actual rooted tournament T(w) is
isomorphic to the ordinal sum

    T(v0 C) => T(v1 C) => ... => T(v_(m-1) C) => T(vm),

with root in the last summand. All arcs between summands point left to right.
The isomorphism preserves the root and total vertex count. More specifically,
in the original vertex labelling it swaps the two vertices born at each R and
leaves the order of all other births unchanged.

**Proof.** In R's block, vertex 1 has exactly the cross-arcs of C's new vertex:
it beats the old root, and every other old vertex beats it. Vertex 0 is a sink
of the entire new tournament. Therefore R first closes the old part by C,
then supplies a fresh singleton sink as root.

Every later block receives arcs from all old vertices except the current
root. All vertices in the closed part are distinct from that root. They
therefore beat every later vertex, forever. The suffix construction operates
on the fresh singleton exactly as it would in isolation. Repeating at every
R gives the stated ordinal sum, including empty excursions. At each cut,
R's two vertices are replaced in the presentation by C's singleton followed
by the next excursion's initial singleton; the vertex count is unchanged.
This also proves the explicit permutation. QED.

This is an actual decomposition, stronger than equality of count projections.
Its proof requires the concrete ports; an arbitrary rank-one matrix need not
have the same graph-level interpretation.

## 3. Full-state renewal and multiplicative closure

Put

    F={ell s(v): v a B-word},
    G={h(v): v a B-word},
    S={h(w): w an A-word}.

All these values are positive odd tournament counts. In particular, neither
7 nor 21 belongs to any of them. The equal first rows of C and R give

    ell s(v)=h(vC),                so F is a subset of G.            (1)

**Corollary 2 (full-state identity).** With the factorization of Theorem 1,

    s(w)=(product_(i<m) ell s(vi)) s(vm),
    h(w)=(product_(i<m) ell s(vi)) h(vm).                            (2)

One proof is immediate from R=s0 ell and linearity. Geometrically, a path
starting at the final root cannot enter an earlier ordinal-sum summand. Every
complement count is multiplied by the earlier summands' Hamiltonian counts,
so E and O scale by precisely the same product as h.

Consequently

    S=<F>_times G,              <S>_times=<G>_times.                 (3)

The first equality follows in both directions by inserting resets between
arbitrary chosen B-excursions. The second follows from (1), (3), and G subset S.
Thus adjoining arbitrary order joins makes this R redundant for *all scalar
values*, not only the two critical lanes. This does not say that every order
join of arbitrary B-words is itself an A-word.

## 4. Prime and seven-prime preservation, all sizes

**Corollary 3.** An odd prime p is in S if and only if it is in G. Also, for
every odd prime p, 7p is in S if and only if it is in G. This includes the
vacuous forbidden cases p=7 in the first assertion and p=3 in the second.

**Proof.** The reverse implications are G subset S. Suppose a prime is
represented by the product (2). Exactly one factor is p and all other factors
are one. That nonunit factor is either a tail in G or a return in F subset G.

Now suppose the product equals 7p. If no factor is the whole 7p, a nonunit
proper divisor divisible by seven must occur. For p distinct from seven this
divisor is 7; for p=7 any proper nonunit divisor of 49 is also 7. Such a factor
is impossible because every factor is an actual tournament count. Hence one
factor is 7p and all others are one, and (1) again supplies a B-word witness.
When p=3 the product cannot occur at all because 21 is forbidden. QED.

The same proof works for any value indecomposable into a product of two
nonunit attainable tournament counts; it also covers the carry atoms 63 and
343. Unit factors may be discarded for scalar membership, but remain in
Theorem 1 when preserving the graph and vertex count.

All transformations remain inside actual positive tournament states. We do
not subtract state coordinates, invert a matrix, replace integral reachability
by cone membership, or assume that a scalar witness retains a source port.

## 6. What the outside comparison changes

The useful connection is to renewal decomposition and factorization monoids:
a return to a distinguished ray separates primitive excursions from products
of completed excursions. It becomes a theorem here because the distinguished
rank-one operator is explicitly present and its graph ports give a permanent
ordinal-sum cut. No stochastic renewal theorem is imported.

| Contract | Content |
|---|---|
| Source | Actual thirteen-letter rooted tournament words |
| Target | Ordered lists of twelve-letter excursion words |
| Map | Split at R; append C to each closed excursion |
| Preserved | Rooted graph up to the specified permutation, vertex count, full state and H |
| Forgotten by scalar projection | Excursion boundaries, actual graphs, ports, presentation multiplicity |
| Needed sidecar | Block adjacency, link/root labels and word order |
| Cheapest decisive test | The two-vertex block of R; then prime/7p membership before and after its deletion |
| Failure boundary | General singular matrices need not close an ordinal-sum component; arbitrary orbit cones do not certify integral words |

The more distant thin-orbit comparison is useful mainly as a warning.
Bourgain--Kontorovich prove a density-one result in their Zaremba setting,
not every target ([Annals 2014](https://annals.math.princeton.edu/2014/180-1/p03)).
Rickards--Stange exhibit reciprocity obstructions in semigroup orbits, showing
that congruence tests need not detect all missing values
([Duke 2025](https://doi.org/10.1215/00127094-2025-0017)). These are CITED results
in their own settings. HYP-9661 already drew this boundary. Neither theorem
applies directly to the present singular three-by-three alphabet.

The actionable change is to stop crediting improvements caused solely by R
as evidence of new prime supply. Exact factorization proves that R cannot
supply either required infinite lane. Future inverse-target or residue
experiments can first delete it, retain the complete (h,E,O) state, and measure
the prime and seven-prime lanes separately. This removes a construction loop;
it does not solve the remaining inverse-target problem.
