# A rigid palette with small prefix sums and large phase response

**PROVED** K1-K3 below; **FINITE-EXACT** controls in
[check_kernels.py](check_kernels.py) and [JSON](check_kernels.json).
The rigid binary palette itself is inherited from Session68. Its signed
kernel and the present arithmetic analysis are explicit constructions.

## K1. The signed digit recurrence

Take X_0=+1 and recurse X_(k+1)=X_k X_k (-X_k). Its negative positions
give one inherited rigid binary palette of W_k; the sign-reversed word
gives the other type. At N=3^k, write its entries d(n),0<=n<N. Equivalently

    d(0)=1,
    d(3n)=d(n), d(3n+1)=d(n), d(3n+2)=-d(n).           (K1)

Thus d(n)=(-1)^(number of ternary digits equal to2). This finite-state
description does not assert that arbitrary tournament attachments have
two states. Its finite generating polynomial and infinite formal series obey

    D_k(z)=product_(j=0..k-1)(1+z^(3^j)-z^(2*3^j)),
    D_(k+1)(z)=(1+z-z^2)D_k(z^3),
    D(z)=(1+z-z^2)D(z^3).                             (K2)

Digit factorization proves the coefficient formula. The three Cartier
sections are D,D,-D, so the signed sequence has only two distinct sections.
The July [THM-2005 automatic atlas](../../../01-canon/theorems/THM-2005-support-dirichlet-automatic-tournament-atlas.md)
supplies the previously underused block-recurrence viewpoint. The object
here has signed coefficients rather than a support indicator.

## K2. Prefix discrepancy does not control a new clock

Let S(m)=sum_(n<m)d(n). From(K1),

    S(3m)=S(m),
    S(3m+1)=S(m)+d(m),
    S(3m+2)=S(m)+2d(m).                               (K3)

For the complete block0<=m<=3^k, the exact extrema are

    max S(m)=k+1,  min S(m)=min(0,2-k).                (K4)

Proof: the three consecutive blocks of partial sums are S_k,1+S_k,2-S_k,
because the full previous sum is1. Hence M' =max(M,1+M,2-m),
m'=min(m,1+m,2-M). Starting with M_0=1,m_0=0 gives(K4) by induction.
This is logarithmic discrepancy for initial intervals in this fixed order.

However at the quarter-turn phase z=i,

    D_k(i)=(2+i)^ceil(k/2)(2-i)^floor(k/2),
    |D_k(i)|=5^(k/2).                                 (K5)

The clock3^j mod4 alternates1,3, proving the formula. A logarithmic
unweighted prefix bound therefore permits a polynomial-in-N phase response
N^(log_3 sqrt5). The Gaussian norm5 is generated by evaluating the actual
kernel at i; it is not inferred from a repeated integer in another lane.

For any scalar weights w_0,...,w_(N-1), Abel summation gives the valid repair

    |sum_n d(n)w_n| <= (k+1)
             (|w_(N-1)|+sum_(n=0..N-2)|w_(n+1)-w_n|). (K6)

The weight variation is necessary information. Taking w_n=d(n) gives N,
so no O(log N) bound holds uniformly over all unit-size weights. Neither
(K4) nor(K6) proves a lonely-runner estimate without a map controlling the
actual source weights and their order.

## K3. Frobenius can destroy the whole spectral carrier

Let M_k be the N-square integer circulant with entries d(j-i modN).
Its eigenvalues are D_k(zeta^r), up to the harmless conjugate convention.
For |z|=1,

    |1+z-z^2|^2=1+4 sin^2(arg z)>=1.                  (K7)

Consequently M_k is invertible over C and its least singular value is
exactly1, attained at the constant vector. It has full rational rank N
despite the two-section digit description and logarithmic prefix sums.
The bounded description length of a kernel does not bound matrix rank.

In characteristic2 all d(n) reduce to1, so M_k has rank1. In
characteristic3, z^N-1=(z-1)^N and D_k(1)=1, so multiplication by D_k in
F3[z]/(z^N-1) is a unit: the rank is N. For the infinite series, the
recovered [THM-2172 Mahler/Frobenius theorem](../../../01-canon/theorems/THM-2172-frobenius-collapse-of-mahler-and-twisted-cyclic-packets.md)
gives the exact equation

    (1+z-z^2)D(z)^2=1 in F3[[z]].                     (K8)

This uses D(z^3)=D(z)^3 and cancellation of its unit constant term. Modulo2
the same signed source becomes the rational series1/(1-z). The coefficient
field is an essential coordinate, not an interchangeable drawing grid.

The [integer cokernel](COKERNELS.md) retains the information lost modulo2.
Its order contains the earlier76-state golden ring, but the connection now
comes from an exact circulant factorization. A changing-level Collatz
operator is a different object: the recovered
[September circulant note](../collatz_circulant_20260930_circulants_lucas_cubic_monotile.md)
already warns that a single-level spectral radius does not control its
cocycle. No dynamical transfer is asserted here.
