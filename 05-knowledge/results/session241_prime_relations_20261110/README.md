# Session241: natural-number relations inside tournament constructions

**ACTIVE RESEARCH CHECKPOINT, 10 November2026. No new theorem has yet passed independent audit. Chan–Pak completeness remains OPEN.**

This session merges prior prime, totient/Carmichael, repunit/Fermat and
tournament-construction work. The aim is an explicit map that preserves a
named arithmetic relation, with a stated loss and a hostile test, rather than
an analogy based on repeated primes.

## Inheritance and live portfolio

- **Anchor:** Chan–Pak realization. THM-4094's two-prime-lane reduction and
  Sessions226–228's physical rooted grafts are inherited. Multiplication cannot
  manufacture a prime target; modular reachability is not integer coverage.
- **Niche:** faithful arithmetic embeddings using Moon's near-transitive
  counts and pairwise-coprime Fermat numbers. Recover multiplication, gcd,
  lcm and divisibility at the count level, then test addition and ordinary
  induced containment as hostile predicates.
- **Wildcard:** Mersenne fans as a divisibility-coordinate chart, and exact
  inversion of a restricted Mersenne–Fermat rooted constructor.

The concept board is: integer prime valuations; strong-component products;
rooted four-state continuations; multiplicative orders; aggregate Camion
counts; totient inverse fibers. Each is a different carrier. In particular,
THM-4746's aggregate count `s(n)` is not a fixed tournament's path count `H(T)`.

Closest mechanisms include THM-4748's all-exponent Fibonacci fans,
THM-4749's multiplicity-degree law, and Session219's exact Fermat-factor run
threshold. Hostiles include absent path counts7 and21, attained63, equal-order
Fermat factors641 and6700417, and arithmetic value factorizations that are not
the strong-component decomposition of a fixed tournament.
