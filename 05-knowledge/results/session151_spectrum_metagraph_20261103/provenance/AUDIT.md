# Session 149–150 spectrum: provenance and rigor audit

## Claims and dependencies

- **100,001 prefix:** conditional finite certificate, not an independent standalone theorem. `session150/certificates_interval/README.md` supplies 234 explicitly checked order-12 strong witnesses for 80,407–80,873; THM-4104 supplies the allowed prefix through 80,405 and 80,875–84,259. `certificates_frontier/check_prefix.py` checks 591 witnesses and factors for 84,261–90,001 using the preceding prefix, and `certificates_100001/check_prefix.py` checks 1,022 witnesses and factors for 90,003–100,001 using the 90,001 prefix. Checks use direct subset DP and strong connectivity; parent selection need not be exhaustive. The THM-4104 audit has an independent reconstruction and sampled direct checks, not individual DP verification of all 7.7 million generated ears. Its proof-level reliance on exact formulas and audit should be explicit. Frozen outputs are reported PASS; this audit inspected the code and output; the Session 150 research team separately replayed the full THM-4104 independent audit and matched its frozen output byte-for-byte. 7 and 21 exclusions rely on existing results, not the witness search. It is a finite, computer-assisted existence claim, not asymptotic evidence proving all odds. Repository THM-4104 precedes the extension; priority beyond the repository is unknown.

- **Adaptive 199:** `adaptive/search.py` exhausts every labelled root history until all states above cutoff, and independently verifies strict growth at every enumerated edge. The universal growth proof justifies discarding a state above cutoff and termination once the state list empties. Distinct histories are retained, preventing unsafe isomorphism pruning. `verify_witnesses.py` checks all 97 reported witness histories with a second counting algorithm but does not itself prove completeness of the enumerator. This is a bounded computational theorem about a specific triangle-seeded construction, not all tournaments or an induction for all counts. 1 is excluded only because the construction starts at 3. The last-inserted vertex has indegree 1, so the generated graphs are a restricted class even if their scalar H values are plentiful.

- **Two lanes are prior repo work:** THM-4094 explicitly proves the equivalence to strong realization of all odd primes except 7 and all 7p with odd p except 3. Its arithmetic witnesses 49, 63, 343 handle the exceptional 7-adic cases. The session-150 status text properly attributes this. An elementary way to see why these particular exceptions appear: the multiplicative monoid M of positive odd integers excluding 7 and 21 has precisely the atoms (irreducibles in M) p for odd primes p ≠ 7; 7p for odd primes p ≠ 3; and 63 and 343. These listed values have no factorization into two nonunits of M. Conversely factor N=7^a m, 7∤m: if a=0 split into ordinary primes; a even use 49; odd a≥3 use 343; a=1 choose p≥5 dividing m to split off 7p, or m=3^k, k≥2, split off 63. This reformulation is not a priority claim or an independent solution to either infinite lane.

- **Finite-ray barrier:** `prime_induction/RESULT.md` has a valid, all-order modular proof for any finite collection of rays a_i+b_i 2^k, with constants included. Taking q=2^m−1 with m=12r+1 ensures 7 is invertible, each ray has at most m residue classes mod q, and φ(q)>2rm; Dirichlet then gives infinitely many primes in a reduced residue class avoiding both p and 7p. Ordinal products do not remove the obstruction when no factor has count 7: primality/divisors force p or 7p itself to be a factor (p=7 is a harmless exceptional prime). This is a restriction of a particular finite fixed-root model, not a density bound for spectra, an obstruction for root switching, or an assertion about primality on any particular exponential ray. This Dirichlet residue-class technique is classical; no novelty or priority asserted.

- **No fixed affine wrapper:** `obstructions/RESULT.md` proves that for fixed tournament Q with one uniformly substituted module T, H(Q[v←T]) cannot equal aH(T)+b for all finite T when b≠0. Singleton strong-component case is multiplicative; otherwise Camion's Hamiltonian cycle in the strong component yields at least 2^n−2 paths after substituting transitive T_n, while H(T_n)=1. The proof checks out as stated. It does not rule out restricted inputs, nonuniform interfaces, adaptive wrappers or profile-dependent induction. Prior repository path-cover kernels include THM-3121 and THM-3181. A targeted prior-art search cannot establish the theorem's novelty.

- **Session 149 finite decision:** `decision/DECISION.md` obtains 3^n≤h^3 after deleting singleton components from a witness. This is a valid corollary of component multiplication and the strong lower bound f(n)≥3^(n/3); the elementary packaging is not a new lower bound or efficient algorithm. It is sharp among singleton-free witnesses via ordinal sums of triangles, not necessarily sharp for minimum possible order. Strong factors can be enumerated up to f(n)≤h, but this proves decidability of each input only, not the global spectrum conjecture.

## External sources and boundary of priority claims

Arthur H. Busch, *A Note on the Number of Hamiltonian Paths in Strong Tournaments*, Electron. J. Combin. 13 (2006), N3, https://doi.org/10.37236/1141. The paper gives component multiplication and the sharp strong minimum; Moon and Yang explicitly state the three residue-class formulas and classify equality cases: https://citeseerx.ist.psu.edu/document?doi=78c085212810b466efaf3f903baeb284a695f719&repid=rep1&type=pdf.

Chan and Pak, *Computational Complexity of Counting Coincidences*, §6.5, Conjecture 6.2, https://www.math.ucla.edu/~pak/papers/DominoPermanent16.pdf, explicitly attributes the conjecture to bof and Royle. Royle's original computational report is https://mathoverflow.net/questions/232751/the-number-of-hamiltonian-paths-in-a-tournament ; use its strict less-than-80,557 boundary unless endpoint independently checked. Search located no external match for the specific finite-ray or uniform-wrapper formulations; that is not a literature-exhaustive novelty assessment. The exact number 100,001 is a repo extension from 80,405, not a verified global literature record. Always distinguish proof, computation, prior internal work, and tentative novelty.
