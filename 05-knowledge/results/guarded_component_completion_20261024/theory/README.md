# Separator sections and exact boundary work

The main result is [SEPARATOR_SECTIONS.md](SEPARATOR_SECTIONS.md): a full-record
tree compiler that counts compatible charge fibres, composes conditional
subgroup sections, and reconstructs exact minimum two-arrival boundary work.
It includes the source-fixed version needed by an adaptive controller.

The native scope is explicit: actual record domains, all shared factors,
normalized capacity, original guards and clocks are inputs, not consequences
of a short charge label. Width-one native shared kernels can still force
arbitrarily large simultaneous events.

`compiler.py`, `check.py` and `receipt.json` compare all messages against
literal global enumeration on the stated finite universes, including actual
native C3 kernels with exact boundary cost3m and a nonmetric fibre-distance
hostile. Normal and optimized execution retain every check.

[NATIVE_MINIMUM_RESET.md](NATIVE_MINIMUM_RESET.md) applies source-fixed sections
to the actual two-root, twelve-control family. Its complete216-trajectory
comparison proves a fixed-core-route optimum of103 peak clock occurrences
and415 total, with literal helper return. The previous demonstrated route
used114 peak and433 total; the uniform120 bound is not replaced.
`check_reset.py` and `reset_receipt.json` retain complete2048-charge minimum
sections for each encountered source, actual pin checks and physical rows.
