# THM-4731 — self-lines beyond the wall, twins, depth, and the tribonacci partner

## Setting (THM-643's frame with the labels reversed: the canon base path is `n -> ... -> 1`, here `0 -> 1 -> ... -> n-1`, so the canon's leg law `e_1 = e_n` and THM-648's `s(1) = (n-2)/2` read `s_0 = s_(n-1) + 1` and `s_(n-1) = (n-2)/2` here)

Tiles are the non-path pairs `{i < j}`, `j >= i+2`, `m = C(n-1,2)`; a tiling `t` is the tournament `T_t` with the path arcs and `i -> j` iff the tile bit is `1`. `kappa` flips every tile (the line pairing `{t, kappa t}`); `sigma` is the staircase reflection `(i,j) -> (n-1-j, n-1-i)`, which sends `T_t` to the converse of `T_t` read along the reversed path (THM-644 (a)); `e = floor((n-1)^2/4)` is the dimension of `Fix(sigma)`, the blue tilings. For a class `c`: `tc(c) = H(c)/|Aut(c)|` is its fibre (odd, THM-643 T1), `bm(c)` its blue multiplicity (odd on self-converse classes, `0` otherwise, T2). A *self-line* is a line whose two tilings lie in the same class (`Q_n` = its endpoints, THM-849); a *converse-merged self-loop* is a line whose tilings lie in the same class or in converse classes. `T(n) = A000568(n)` and `SC(n) = A002785(n)` count the classes and the self-converse classes.

## Statements

**1. (Self-lines by twisted Burnside sums; PROVED.)** For `g in S_n` let `S_g = {t : g . T_t = T_(kappa t)}`. Writing `y_e = T_t(u, v)` for the pair `e = {u < v}` (`y_e = 1` pinned for path pairs, a free bit for tiles), the condition is the linear system over `F_2`
`y_e + y_(g^-1 e) = [e is a tile] + [g^-1 reverses e]` for every pair `e`,
where `g^-1` reverses `e` means `g^-1 u > g^-1 v`. Grouping the equations along the cycles of `g` on unordered pairs: a cycle containing no path pair is consistent iff its twist bits sum to `0`, and then contributes one free bit; a cycle containing a path pair is pinned and must be consistent with the pinned values. So `S_g` is empty or an affine subspace of dimension the number of unpinned consistent cycles, `Q_n = union_g S_g`, and each `t in Q_n` lies in exactly `|Aut(T_t)|` of the `S_g` (THM-849 (11): `R_kappa(t) = {g : g T_t = T_(kappa t)}` is a torsor for `Aut(T_t)`). Hence `P_kappa(n) = sum_g 2^(dim S_g) = sum_(t in Q_n) |Aut(T_t)|`, and enumerating the solutions over all `g` gives `Q_n` with the automorphism order of every endpoint for free, at the cost of `n!` linear systems on `C(n,2)` unknowns instead of `2^m` tilings. The same system with the twist `[e is a path pair] + [g^-1 reverses e]` gives `Q'_n = {t : T_(kappa t) ~ T_t^op}`, which is the set of presentations whose Hamiltonian path is *reversal-neutral* (`T_t` isomorphic to `T_t` with the path arcs reversed), because `(kappa T)^op` is `T` with exactly the path arcs reversed; the twist `1 + [g^-1 reverses e]` on all pairs, unpinned, is the classical self-converse Burnside sum (the control). Converse-merged self-loop endpoints are `Q_n cup Q'_n`.

**3. (The sigma-twin theorem; PROVED.)** `sigma` maps lines to lines (`sigma kappa = kappa sigma`), fixes exactly the blue lines and acts freely on the black ones (THM-643; `kappa sigma` has no fixed tiling since the apex tile is `sigma`-fixed and `kappa` toggles it). The twin `sigma L` of a black line `L = {t, kappa t}` joins the classes `[T_t]^op` and `[T_(kappa t)]^op`, i.e. the same pair of converse-merged nodes as `L`. Hence in the converse-merged metagraph every black multiplicity, loops included, is even: the merged black multigraph is `2B` for a multigraph `B` (the *fundamental black graph*) with `2^(m-2) - 2^(e-2)` edges, whose degree is `tc(c)` (odd) at a merged non-self-converse node `{c, c^op}` and `(tc(c) - bm(c))/2` at a self-converse node. Corollaries: (i) the handshake law `#{self-converse c : (tc(c) - bm(c))/2 odd} = (T(n) - SC(n))/2 (mod 2)` (data `1, 2, 6, 40, 84` against `1, 2, 22, 184, 3352` non-self-converse merged nodes at `n = 4..8`); (ii) `SC(n)` is even for `n >= 3`, since `sum_(SC) bm(c) = 2^e` (THM-643 T5) is a sum of odd numbers; (iii) THM-849's `|Q_n^K| = 0 (mod 4)` is the twin statement for self-lines. Verified at `n = 4..8`: all `438,216` merged black multiplicities at `n = 8` are even and every twin joins the expected classes.

**4. (Leg law and scores of self-line endpoints; PROVED.)** If `t in Q'_n` (reversal-neutral path) then `s_0 = s_(n-1) + 1` for the out-degrees of the path's endpoints: reversing the path arcs changes only `s_0` (by `-1`) and `s_(n-1)` (by `+1`), and an isomorphism preserves the score multiset. For `t in Q_n` the same equation is THM-793's leg law `e_1 = e_n`. For `t in Q_n` the score multiset of `T_t` is moreover complement-symmetric (`{s} = {n-1-s}`): combine the leg law with the score-complement law `s + s' = (n, n-1, ..., n-1, n-2)` (THM-646, in this orientation) and `{s'} = {s}`. This does not extend to `Q'_n`, where reversal neutrality forces only the leg law (the audit counted `16, 88, 568, 10912, 89600` endpoints of `Q'_n` with asymmetric multisets at `n = 6..10`). At `n = 8` the `165` self-line classes realise exactly nine complement-symmetric score multisets; the regular multiset carries no self-line at odd `n` (the leg law forces `s_0 != s_(n-1)`), and the near-regular `(3^4, 4^4)` carries `43` of its `85` classes.

**5. (Symmetric-core depth; PROVED.)** Let `Delta_k` be the sub-staircase of the central path interval `[k, n-1-k]` (`C(n-1-2k, 2)` tiles, `floor((n-1)/2) - k` of them on the altitude). The *depth* of `t` is the least `k` with `t|Delta_k` sigma-symmetric; depth `0` = blue. `kappa` and `sigma` preserve depth, so every line and every class fibre has a depth profile, and
`#{t : depth(t) <= k} = 2^(m - (C(n-1-2k,2) - floor((n-1)/2) + k)/2)`,
e.g. `2^12, 2^17, 2^20, 2^21` at `n = 8` (tilings by depth `4096, 126976, 917504, 1048576`; lines by depth `2048, 63488, 458752, 524288`). Under THM-793's descent `p` (strip the outer ring), `depth(t) <= k` iff `p^k(t)` is blue at level `n-2k`, and `p` commutes with `kappa`: every black line of depth `k` is a ring-decorated lift of a blue line at level `n - 2k`, so the two endpoint tournaments induce on the central interval the two ends of a blue line. On a self-converse class the depth-`k` count is odd for `k = 0` and even for `k >= 1`. Pure-blue classes have all tilings at depth `0`; at `n = 8` the mixed classes have profile `(4093, 3576, 23428, 27612)` and the pure-black ones `(0, 123400, 894076, 1020964)`. (Remark: for every nonzero `v in Fix(sigma)` the translation by `v` is a fixed-point-free involution commuting with `sigma`, so THM-643's T3-T5 hold verbatim for `v`-lines with the same global counts; the owner's lines are `v = 1`, and mac-mini's THM-4730 treats specific members.)

## Proofs

**1.** For `u < v` write `a = g^-1 u`, `b = g^-1 v`. The condition `(kappa T_t)(u, v) = T_t(a, b)` reads `y_e + [e tile] = y_(e') + [a > b]` with `e' = {a, b}`, which is the displayed equation; the system is a disjoint union of cycles because `e -> g^-1 e` is a permutation of the pairs. The pinning `y_e = 1` on path pairs is the definition of a tiling. The torsor statement is THM-849 (11): if `g, g' in R_kappa(t)` then `g^-1 g' in Aut(T_t)`, and conversely; the sum `P_kappa(n) = sum_g #{t : g T_t = T_(kappa t)}` is THM-849 (12), and the pair-cycle consistency frame is its section 4. What is added is the affine description with the path pairs pinned and the enumeration of the solution sets, which turns the sum into the set `Q_n` with its automorphism orders. For `Q'_n`: `(T_(kappa t))^op(u, v) = T_(kappa t)(v, u) = 1 + (kappa T_t)(u, v)`, which adds `1` to every twist bit; and `(kappa T)^op` reverses the tiles twice and the path arcs once. ∎

**3.** `sigma(kappa t) = kappa(sigma t)` because the all-ones vector is `sigma`-fixed (THM-643). By THM-644 (a), `T_(sigma t)` is the converse of `T_t` relabelled along the reversed path, so `[T_(sigma t)] = [T_t]^op`; the same for `kappa t`. A black line is not `sigma`-fixed: `sigma t = t` would make it blue, and `sigma t = kappa t` is impossible (the apex tile). So `L -> sigma L` is a fixed-point-free involution on black lines preserving the merged endpoint pair, which proves the even multiplicities; `B` is the quotient. The degrees follow from T1, T2 and T4 of THM-643 (`tc` odd; `tc - bm` even on self-converse classes). The handshake is the parity of the number of odd-degree vertices of `B`. For (ii), `sum_(SC) bm = |Fix(sigma)| = 2^e` with every `bm` odd forces `SC(n) = 2^e = 0 (mod 2)` for `e >= 1`. ∎

**4.** As stated. For the multiset: on `Q_n`, `{s'} = {n - s_0, n-1-s_i, n-2-s_(n-1)}` and `s_0 = s_(n-1) + 1` give `{s'} = {n-1-s}`, while `{s'} = {s}` by isomorphism. ∎

**5.** A tiling is determined by its bits on `Delta_k` and outside; `sigma` preserves `Delta_k` (it maps `[k, n-1-k]` to itself) and the symmetric restrictions number `2^((|Delta_k| + f_k)/2)` (one bit per `sigma`-orbit of tiles in `Delta_k`), the outside bits being free; this is the closed form. `kappa` toggles every bit and `sigma`-symmetry of a restriction is preserved under complementation; the depth-profile parities on a self-converse class follow because `sigma` acts on the fibre with the blue tilings as fixed points. The descent `p` of THM-793 forgets exactly the tiles outside `Delta_1` and commutes with `kappa` and `sigma`; iterating, `p^k t = t|Delta_k` read as a tiling of the central interval, which is blue iff `depth(t) <= k`. ∎

**6.** (The structure lemma and the `H` recursion are kind-pasteur-S11's run-decomposition argument in another form, included to make the blue count self-contained.) *Structure lemma.* In `T*_n` the out-neighbours of `i` are `i+1` and all `j <= i-2`. Once a Hamiltonian path visits `0` it must continue `1, 2, ..., k` until `k+1` is already used (or `k = n-1`), so every path is `A, 0, 1, ..., k` with `A` a Hamiltonian path of the induced copy of `T*_(n-1-k)` on `{k+1, ..., n-1}`; the junction `last(A) -> 0` holds automatically for `k >= 1` and, for `k = 0`, iff `A` does not end at `1`. Hence `h(n) = 1 + sum_(j=1)^(n-2) h(j) + e(n)` with `e(n) = h(n-1) - e(n-1)` the number of paths ending at `0`; eliminating `e` gives `e(n) = 1 + sum_(j <= n-3) h(j)` and `h(n) = 2 + sum_(j <= n-2) h(j) + sum_(j <= n-3) h(j)`, whose difference is the tribonacci recursion. *Rigidity and self-converseness.* The scores are `s_0 = 1`, `s_i = i` for `1 <= i <= n-2`, `s_(n-1) = n-2`; an automorphism preserves scores, cannot swap `0, 1` (it would reverse the arc `0 -> 1`) nor `n-2, n-1`, and fixes all other vertices by their distinct scores. `i -> n-1-i` reverses every arc, so it is an anti-automorphism, the unique one since `Aut` is trivial; by THM-644 (a)-(b) the blue tilings of the node are the Hamiltonian paths `P` with `p_(n-1-i) = n-1-p_i` (anti-palindromic). *Blue count.* By the structure lemma such a path is `(n-1-k, ..., n-1), M, (0, ..., k)` with `2(k+1) <= n` (or the base path), `M` an anti-palindromic Hamiltonian path of the induced `T*_(n-2-2k)` on the middle interval, the junctions being automatic for `k >= 1` and, for `k = 0`, requiring that `M` neither starts at its top vertex nor (equivalently) ends at its bottom vertex. With `b(j)` the anti-palindromic count of `T*_j` (`b(0) = 1`) and `c(j)` those not starting at the top, `b(n) = 1 + c(n-2) + sum_(k=1)^(floor(n/2)-1) b(n-2-2k)` and `b(j) - c(j) = c(j-2)` (the paths starting at the top are the `k = 0` ones), `c(0) = c(1) = 0`. Induction gives `b(2j) = b(2j+1) =: B(j)`, and from `B(j) = 1 + C(j-1) + sum_(i <= j-2) B(i)`, `C(i) = B(i) - C(i-1)`, one finds `B(j) = B(j-2) + 2 + 2 sum_(i <= j-3) B(i)`, hence `B(j) - B(j-1) = B(j-2) + B(j-3)`: `B` is tribonacci with `B(0) = B(1) = 1`, `B(2) = 3`, i.e. `B(j) = h(j+1)`. ∎ (All of this is also checked exhaustively to `n = 15` in `tribonacci_partner_20261020.out`.)
