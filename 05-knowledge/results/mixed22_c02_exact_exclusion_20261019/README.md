# Mixed-(2,2), c=0,1,2 exact exclusion

Start with `mixed22_c02_exact_exclusion_20261019.md`. The theorem is scoped to
seven-thin maximum-span root morphologies with two lower slaves, two upper
slaves, and at most two common neighbors. It explicitly depends on Peczarski's
2008 six-thin theorem for projected spans at most three.

Run the two standard-library reproduction commands listed at the end of that
note. The main verifier independently reconstructs all 5,221 canonical cores
and checks the exact positive-cone certificates. Discovery tools are not needed.

The separate core-realization note and verifier document an actual balanced
poset that defeats a core-only screen. They are method-limit evidence, not a
counterexample to balance.
