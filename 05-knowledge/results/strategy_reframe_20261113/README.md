previous endpoint grammar. Every nonzero half-repair return using an
identified-root context, from the plane F+s=h+q, costs at least a factor

The second experiment gives a warning against chasing congruence barriers
alone: the inherited nine-rule grammar has every parity-allowed H residue
in its complete orbit for each of 104 tested moduli, including 45 and 420.
Nevertheless that language has a proved O(X^(3/4)) count bound and misses
the globally attained 53,084,231. This is finite local admissibility, not
an all-moduli or global existence theorem.

prime-lane induction, allowing target-specific core replacement. It is
sufficient for Chan--Pak and demands less than preserving our paired
interface. The obstacle53,084,231 factors as43*1,234,517, so it is not
itself an irreducible target in that reduction.
