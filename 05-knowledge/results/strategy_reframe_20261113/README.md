The main result is an all-order explanation for the rapid growth in the
previous endpoint grammar. Every nonzero half-repair return using an
identified-root context costs at least a factor five in H. Arbitrary
finite words of those contexts obey the same bound on each net return,
even when intermediate endpoint types change. This rules out implementing
the useful ternary induction h -> 3h+2 or 3h+4 while preserving this
particular paired state. It does not rule out the induction itself.
