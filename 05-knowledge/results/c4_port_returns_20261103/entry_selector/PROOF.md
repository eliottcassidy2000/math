the deleted component is (B-w) followed by a transitive reader chain, and
its Hamilton count remains q. The zero-ready full wrapper only contributes
additional transitive components to this deletion, so the same count is

Now apply C2 at the last reader a. In the graph with w deleted, the last
singleton a is replaced by the terminal directed triangle

    a -> y -> x -> a.

deletion count multiplies by exactly3. This is an all-order statement for
