# Why the obvious ternary refill does not enlarge the matched window

The [matched window](MATCHED_WINDOWS.md) gives four consecutive odd counts with common right state. That suggests multiplying the window by 3, then using three compatible extension choices to fill the three odd residue classes between the new steps. Here that tempting move has a complete all-order obstruction. It uses the exact (rather than modular) start readout.

Start with any anchored state (h,N,S,d) with S≥h and d=0. An ordinal extension with ordinary Hamilton multiplier 3 consists of one directed triangle, plus any number of singleton SCCs. This follows from SCC factorization and the [fixed-count fiber argument](../chanpak_crossing_scales_20261115/FIXED_COUNT_TIGHTNESS.md), or from the fact that total H=3 requires exactly one odd cycle in the positive packing expansion. The triangle is marked at i of its vertices, i∈{0,1,2,3}; its symmetry makes the counts depend only on i. The local cut parameters of that marked triangle are
```
a=3, Q=12, local N=3+2[i=1 or 2],
local S=3i, local d=i, end total t=9−3i, end bias f=3−i.
```
Each of these follows by listing the paths of sizes 1,2,3 in the triangle with specified starting or ending vertex.

At the triangle, the normalized start S/h changes by x→4x+i. Thus for the normalized start alone, a painted triangle is equivalent to two singleton marks αβ, where i=2α+β. Replace it by those two bits to obtain the **effective word** w. The actual final start is three times the ordinary start readout of w. Since the input S/h≥1, this readout determines w uniquely even if lengths vary: length l has the half-open range [2^l S/h,2^l(S/h+1)), with different lengths disjoint, and within each length the binary value is injective. Therefore different ordinal multiplier-three extensions with the same final start can only move the triangle to different adjacent positions of the *same* effective word.

Let S_0,d_0 be the readouts of the effective prefix before αβ, and let e=1 if the remaining effective suffix starts in 0 and e=0 otherwise (including an empty suffix). Write N_eff for the Hamilton count after all of w is treated as singletons. Directly comparing the cut update of a triangle and of its two effective singleton bits gives
```
N_real = 3 N_eff + J,
J(00)=J(11)=0,
J(01)= 3S_0−d_0+2h−2he,
J(10)=−3S_0+d_0−4h+2he.
```
For the derivation, the singleton pair increments N by (1−α)(S_0+d_0)+(1−β)(2S_0+2αh); the triangle gives the local parameters above. After the pair the start readouts differ by the predictable factor 3, while the signed starts differ by 2h(α−β). This affects only the first subsequent 0 (if 0 is the very first suffix bit), since any single bit resets the bias. The displayed formula includes that correction.

Now 0≤d_0≤h and S_0≥S≥h, since a nonempty prefix sets d_0 to either 0 or h. Hence a true 01 correction is at least 2h and a true 10 correction is at most −4h. Two positions of the same mixed type cannot be consecutive; their prefix starts differ by at least a factor of four. Within a sign the variable correction outside ±3S_0 ranges over an interval of length 3h. Thus two distinct same-sign values are separated by at least 9S_0−3h≥6h, and zeros and opposite signs cannot make a smaller nonzero gap. For one fixed final start, the possible distinct offsets J are at least 2h apart. Requiring the final bias to match only shrinks the possible set.

For the four-count input window with h=15, multiplication by 3 gives width 18 between extremes and internal spacing 6. Distinct choices of J separate these strips by at least 30−18=12. Therefore **no two adjacent odd counts at a common right state** can be obtained from that matched window using arbitrary ordinal multiplier-three extensions. The same argument excludes adjacency from the h=5 matched pair (width 6, separation at least 10).

In general an exact widening step would require several same-final-state offsets with different classes modulo twice the multiplier, *and* absolute separation small enough to overlap the scaled windows. In this particular primitive ternary grammar, the physical offsets fail before their residues can help. Changing the H-multiplier, changing the seam, or letting the triangle recontact the old core escapes the proof. It does not exclude wider windows found directly rather than generated by this one extension rule.
