## 2. Five connections that survived a decisive test

**Nested cosets -> homometric configurations -> source-sensitive cancellation.**
The map lifts odd quotient signs along a subgroup chain. Its preserved
predicate is the complete unmarked pair-distance multiset, because Fourier
supports occupy disjoint annihilator annuli. Its loss is the source-owned
row. The minimal useful sidecar is the marked runner and its incident
profile. Test: the C105 H5 flip leaves all global clocks unchanged but
changes the clock20 and22 counts at runner1. This provides both a working
construction and a hostile for the ROOT application.

**Mahler exponent -> Collatz exponent -> finite branch compiler.**
The common map is a normalized 2-adic exponential followed by a triangular
native digit reader. It preserves exact residue cylinders and refinement.
It discards Archimedean weights if one replaces the actual source by a Haar
sample. Sidecars are `125^j`, the affine offset, and the integer clock.
Test: all words through length14 occur once, while a finite atlas proves
half-descent for123577/131072 exponent classes in at most20 shortcut steps.
No infinite-path exclusion follows from this finite count.

**March chain/edge/isolate -> pentads -> matching charts.**
The chosen six-pentad ordering transforms a two-subset into the unique
common matching of two pentads; adjoining isolate--eighth-label completes
the K8 matching. It preserves an explicitly transported incidence predicate
and is invertible. It loses natural label equivariance. Sidecar: the outer
action and named port correspondence. Test:35 versus15 transposition-fixed
objects, and the reversal of intersecting-duad versus common-matching-edge
compatibility. This rules out a silent use of the count105 as geometry.

**Two invisible depths -> a three-component observation.**
The map is the actual update `(C_(r-1),C_r,E_(r+2))` to its next state, not
a guessed scalar recurrence. A vanished E observation does not kill C.
The coefficient `c_i=d-i-1` can vanish once; the invertible continuant update
then rules out triple vanishing at3,4,5, with two exceptional parameter
values handled exactly. Retain the state and d,v. The positive result is
uniform nonvanishing over n, not a uniform numerical lower bound.

**Rule105 -> rooted binary tree -> nonlinear Collatz innovations.**
Both free-input readers have output bit `input_bit xor function(earlier_bits)`.
This is exactly an automorphism of the rooted binary residue tree. It
preserves prefixes and uniform finite counting. The sidecar needed to make
a dynamical statement is which infinite address is the actual seed. Rule105
is affine at every bit; the Collatz/exponent compiler is already nonlinear
at bit3. Same representation category does not mean same dynamics.

## 3. Why Phi105 first shows a coefficient -2 in its low-degree window

The inherited golden-clock note already computes Phi105. The useful local
explanation is an overlapping-sieve calculation:

\[
\Phi_{105}(x)=
\frac{(1-x^{105})(1-x^3)(1-x^5)(1-x^7)}
{(1-x)(1-x^{15})(1-x^{21})(1-x^{35})}.
\]

Below degree8, the denominator contributes only `1/(1-x)`, and the three
negative gates have appeared while none of their pairwise products has.
Thus `[x^7]Phi105=1-1-1-1=-2`. This mechanism generalizes: for odd primes
`p<q<r<p+q`, the same truncated calculation gives
`[x^r]Phi_(pqr)=-2`. Examples include385=5*7*11 and715=5*11*13.
This is an elementary coefficient observation, not a new cyclotomic
classification or a claimed novelty.

The contrast with the silent-flip construction is informative. In the
cyclotomic inclusion-exclusion the three prime gates overlap without their
compensating intersections yet appearing. In P4 we deliberately reorganize
the same composite modulus into a **nested** chain, placing contributions in
disjoint annuli. A plausible proof technique is to search for an exact
change of organization from overlapping constraints to orthogonal layers,
while retaining the overlap correction. It is not legitimate to delete the
correction or to treat the number of primes as an energy bound.

## 4. New helper questions and first tests

1. **Weighted annulus compatibility.** Which source-owned pair kernels
   preserve the P4 reflection cube? Both ordinary diagonal norms and
   frequency-diagonal norms preserve layer orthogonality; the marked
   pair-distance kernel demonstrably does not. Classify that kernel, not
   an unspecified "weight". First test: compute the joint commutant of the
   three layer reflections and the actual finite ROOT Gram matrix.
2. **Quantitative three-observation recovery.** On a specified compact
   nondegenerate parameter domain, P6 plus continuity implies a positive
   minimum of `|E3|^2+|E4|^2+|E5|^2`. P6b now supplies the exact arithmetic
   floor q^-3 for rational v of denominator q and integer d. Seek a sharper
   bound in a declared growing-height regime, or an explicit shrinking
   sequence. The retained denominator is essential to what is proved.
3. **Exponent-tree zero tails.** For P2's exact grammar, can a residual
   binary address become permanently zero? Every positive integer exponent
   does that. Arbitrarily long one-growth prefixes exist, but they do not
   settle a fixed exponent. Track the actual affine carry along zero-bit
   refinement; a Haar-measure estimate alone cannot answer this question.
4. **Hybrid terminal libraries.** Combine P2's endpoint map with a grounded
   library from the existing125-power trajectories and the existing ROOT
   seeds. Measure genuinely new source coverage per retained endpoint,
   rather than counting half-descent cylinders as home certificates.
5. **Sparse versus stateful address rules.** The observed innovation degree
   k-1 through bit12 discourages low-degree Boolean truncation. It does not
   exclude a small stateful integer-register algorithm. Seek a carry-state
   recursion, as in the golden reader, whose complexity is explicitly paid.
6. **Natural port budget.** Can the six-pentad choice in P5 be implemented
   by an authenticated geometric boundary relation? First require agreement
   with the transported common-edge predicate. Failure already at this
   finite relation should stop a unit-distance search based only on105.
7. **Adaptive rather than fixed charts.** The historical graphic-rank
   identity chooses a basis on each activation cell. Can a finite set of
   source-preserving native packet bases be selected by the full exponent
   residue, with an explicit cost for changing the basis? P1 supplies an
   exact test space; it supplies no bound on the switching cost.

These questions are research targets, not inserted proved dependencies.
The old prime-square maximum-size claims, analytic LRC bounds in reflections,
and broad genus/Jacobian conclusions were not used as premises. In
particular none of these bridges proves a global Collatz basin, a new plane
chromatic bound, or the planar Jacobian conjecture.
