# Two independent H=23 clone lengths: exact inverse and Golay projection

Take outgoing adjacency rows `(26,52,57,50,32,1)` and substitute
transitive chains of lengths a,b≥1 for vertices 2 and 4 respectively
(zero-based). All external arcs of a chain follow the old vertex's arcs.
Then the actual Hamilton-path count is exactly

    H(a,b)=2^(a+b+2)+3·2^a+2^b−1,
    4H(a,b)+7=(2^(a+2)+1)(2^(b+2)+3).

Setting a=b=k recovers the stated (2^(k+1)+1)^2−2, but the two
coordinates are not interchangeable.

## The four run types

Contract each maximal chain segment of a Hamilton word to its chain's
marked symbol. The first mark, 2, has only predecessor 1 in the original
tournament; since an occurrence of 1 can precede at most one of its runs,
there can be only two runs, one initial if there are two. The second
mark, 4, has only successor 5; there can again be at most two runs,
one terminal if there are two. For i,j∈{1,2}, enumerate the unique
permutations of the multiset consisting of vertices 0,1,3,5 once,
mark 2 i times, and mark 4 j times. Keep precisely those with all
neighboring pairs present among the original arcs. This gives rows
(23,9),(11,4), where i is the row index. For two runs of an a-chain
assign any proper nonempty subset to its first run, in increasing
order, and the complement to its second; count 2^a−2. For one run
there is one choice. Likewise for b. Thus the count is
23+11(2^a−2)+9(2^b−2)+4(2^a−2)(2^b−2), as claimed.

## Three-test inverse and exact dyadic shell

For an integer target h≥1 put S=h+1 and k=floor(log₂S).
If it occurs, then a+b=k−2 because
S/2^(a+b+2)=1+3/2^(b+2)+1/2^(a+2) is in (1,3/2].
If a≠b, v₂(S)=min(a,b). If a=b, v₂(S)=a+2. Therefore,
with t=v₂(S), try a=t, b=t (separately, filling the other coordinate
using the sum), and a=b=t−2. Reject if invalid or the formula fails.
This is complete and involves no search over chain lengths.

The map is injective: k already fixes the sum; changing (a,b) to
(a+d,b−d) for d>0 changes the height by
(2^d−1)(3·2^a−2^(b−d)), which is nonzero. In particular at k≥4
there are exactly k−3 attained heights with 2^k≤h+1<2^(k+1).

At fixed sum s=k−2, the error above 2^k is 3·2^a+2^b, a strictly
convex function of real a on the allowed interval. The maximum is
at (s−1,1), by comparing the two endpoints, and equals
3·2^(k−3)+2. The minimum for s≥3 has b−a=1 when s is odd and
b−a=2 when s is even: shifting a up one changes the error by
3·2^a−2^(b−1), and shifting down changes it by −3·2^(a−1)+2^b.
The s=2 boundary is (1,1). Thus on an even shell k≥6 the equal-chain
diagonal misses the smallest count by 2^((k−4)/2). Asymptotically the
upper occupied boundary is 11/8 of the octave origin.

No target 2^m−1 occurs, because the residual is positive; no 2^m+1
occurs, because it would have residual 2, below the minimum.
For the even perfect-number shape E_p=2^(p−1)(2^p−1) with p≥3,
both E_p±1 are likewise absent: their S values E_p and E_p+2
are at least 7/4 of 2^(2p−2). These exclusions apply only to this family.

## A literal Golay weight projection, not a missing-count mechanism

Use the binary cyclic Golay code of length 23 generated by
g(X)=X^11+X^9+X^7+X^6+X^5+X+1. For a binary codeword of weight w,
give the marks lengths a=1+w,b=24−w. This puts all coded heights in
one and the same octave of h+1 (k=27). Its ordinary weight distribution
is supported at w=0,7,8,11,12,15,16,23 with multiplicities
1,253,506,1288,1288,506,253,1. Injectivity at fixed sum gives exactly
eight different heights, with precisely those multiplicities over the code.
For paired complementary codewords the count difference is
2(2^a−2^b), not zero. If one first decodes an arbitrary 23-bit word
within Hamming distance three and then forms the chains, perfectness
makes each of those multiplicities exactly 2048 times larger.
For completeness the replay generates all 4096 codewords, verifies their
weight enumerator and minimum distance 7 (by linearity, minimum nonzero
weight). The radius-three balls are disjoint and each has size
1+23+253+1771=2048, so they exhaust the cube. This is an exact partition
and histogram on one tournament-family shell; it does not imply a
Golay obstruction for general tournament counts or explain 7 and 21.

## Universal two-slot law and the rank-drop prime 7

The same argument permits arbitrary nonempty tournaments A,B as the
replacements. Write h_A=H(A), and let u_A count ordered two-path covers
allowing empty paths, so a two-run realization uses u_A−2h_A choices.
Use the same conventions for B. Substituting these into the four-run
table gives

    H = 4u_Au_B + 3u_Ah_B + h_Au_B − h_Ah_B,
    4H + 7h_Ah_B = (4u_A+h_A)(4u_B+3h_B).

The bilinear response matrix in coordinates (u,h) has determinant −7.
Thus the 7 in the factored law is the unique exceptional prime for the
two-slot bilinear form, not an adjustment chosen for the chain line.

For chains, the residues of H(a,b) mod 7 in rows a=0,1,2 mod 3 and
columns b=0,1,2 mod 3 are (0,5,1), (0,2,6), (0,3,2). In particular
the class 4 mod 7 is absent. Every lift of every other class is present
modulo 7^j, for every j≥1: take the table pair with the desired base
residue, hold a fixed, and let b vary within its class mod 3. The
powers of 2^3=8 exactly exhaust the units congruent to 1 mod 7,
since v_7(8−1)=1 and binomial lifting gives order 7^(j−1).
The coefficient 4·2^a+1 of 2^b is a unit at 7, so all lifts in
the selected residue class of H follow. The exponent b can be chosen
positive by adding its period.
