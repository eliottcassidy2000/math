# Five is a fiber dimension, not a universal list length

**Status: PROVED MAPS + EXPLICIT ANALOGIES / OPEN TRANSFERS.**

## Actual recovered structure

The mechanics theorem separates a fixed arbitrary analytic direction field
h from a four-real-dimensional Hermitian amplitude and one trace anchor.
The operator kernel closes at a finite jet: its size does not depend on the
complexity of h. This suggests the phrase **compatibility-generated finite
memory**. It is a mechanism to test, not a general meta-theorem for all
mathematics.

## Two bold, testable research hypotheses

**H1 (family-relative finite compatibility memory; OPEN).** There is a
useful tournament source class with two commuting physical growth moves,
a finite-dimensional exact root-interface lift, and annihilating mixed
finite-difference relations that preserve a nontrivial interval of target
counts. The physical moves and every coordinate must be supplied. The
stress theorem provides the discovery strategy, not evidence that H1 is
true for all tournaments.

**H2 (anchor section; OPEN).** Within a suitable complete interface family,
all large admissible odd target scalars admit an integral nonnegative
parameter section satisfying the same compatibility relations as the
physical source interface. Proving recurrence closure alone is insufficient;
the section must be constructive and respect actual realizability. A
counterexample can be a residue-compatible parameter point outside the
physical source cone.

The number5 has different causal explanations elsewhere: five Platonic
solids are a curvature classification; five known Fermat primes are not a
proved exhaustive list; a five-dimensional fiber is neither. The aim is to
identify the operator, cone, quotient or boundary that causes each count.

## An actual Pythagorean subcarrier

The Hermitian map gives more than a suggestive common quadratic. Restrict
to real symmetric rank-one matrices

```
H=[[m²,mn],[mn,n²]],        R=|mz+n|².
```

Then the three amplitudes give the exact null vector

```
(m²−n², 2mn, m²+n²),
```

whose first two squares sum to the third square. Thus the classical
Pythagorean spinor map is literally a slice of the stress-amplitude
carrier. The zero-stress-anisotropy set is the single point z=−n/m
when m≠0, even though the prescribed trajectory net h is arbitrary.
The primitive condition gcd(m,n)=1 and opposite parity must still be
retained to obtain a primitive positive triple, and m>n>0 to choose
that chamber. Neither condition is inherent in a real stress field.
The pressure coordinate and analytic net are forgotten by this slice.
This is a genuine map with explicit losses, unlike identifying the five
parameters with five named solids or five known primes.
