# Reproduction and scope

Run from the repository root. Python3 is required; the stress, period and
independent algebra controls also require SymPy (tested with the environment's
installed version, recorded in `REPLAY.json`). No new software installation
is required in the research environment.

```sh
python3 05-knowledge/results/session285_five_web_20261112/replay.py
```

This executes ten mathematical/provenance verifier programs normally and under `-O`,
compares each output byte-for-byte with its saved receipt, verifies the
compressed history catalog hashes, and writes `REPLAY.json`. The history
lexical scans are separately reproducible, not repeated by this wrapper:

```sh
python3 05-knowledge/results/session285_five_web_20261112/history/catalog.py --frozen-scope 05-knowledge/results/session285_five_web_20261112/history/searched_manifest.json.gz
python3 05-knowledge/results/session285_five_web_20261112/history/history_catalog.py
```

The first requires the frozen Git objects locally and scans the pinned
pre-session snapshot; unavailable objects are explicitly reported. A full
historical checkout is not required for the mathematical controls. The wrapper's
manifest reconciliation does require Git and the pinned commit/tree objects
(`7510e38f9c777a61a1b3210334077e0ebe0df2ad`), but not every historical blob. The
second uses the shallow commit boundary recorded in `commit_scope.json`;
fetching deeper history can change this separate provenance inventory.
Raw catalog JSON is generated by replay but not committed: the publication
contains deterministic gzip and compressed/raw SHA256 hashes.

The normal/optimized pairs check reproducibility, not independent discovery.
The four scripts under `audit/` implement separate algebraic/graph/path-count
checks. All-order claims rest on the accompanying proofs. The finite cyclic
scan is exactly its declared step-set universe, not all tournament classes.

Publication source identities are in `audit/SOURCE_HASHES.json`; the final
release receipt records the unchanged repository-wide documentation warnings.
