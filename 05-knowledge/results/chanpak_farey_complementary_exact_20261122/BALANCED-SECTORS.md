# A centered exact antidiagonal filter on the last two Farey spines

Use the canonical physical chart
\[
 H=k+qxy+tx+cy+r[x\text{ odd}]+e[y\text{ odd}]+h(f(x)+f(y)),\qquad
 T=2^{121}-2^{60}-1.
\]
The following is an absolute filter for prescribed low bits of \(S=x+y\), rather than just another modular witness. It extends the terminal-one sector of CUBE-ROOT-PHASE independently of restrictions on how the two complementary low words are chosen. It does not search unrestricted sums.

## Prime-by-prime before the square root

For each prime \(\ell\mid h\), precompute a table indexed by \(S\bmod 2\ell\) whose two entries record whether a left address \(x\) of the indicated parity survives
\[
 k+cS+q x(S-x)+(t-c)x+r[x\text{ odd}]+e[S-x\text{ odd}]\equiv T\pmod\ell .
\]
Use the actual parity of both operands, not unrestricted Legendre tests that could admit two different parities at different primes. For a fixed sum, intersect the parity masks. If the result is empty, no integer pair works. If nonempty this is only a necessary test; the exact integer equality is checked below. The tables can be generated by considering \(x\bmod2\ell\), so this treats all possible addresses without any finite-length assumption at the modular step.

## Exact centered root interval

Set
\[
 A=qS+t-c,\quad m=\left\lfloor\frac{A+q}{2q}\right\rfloor,\quad \beta=A-2qm,\quad
 D=k+q m(S-m)+tm+c(S-m)-T.
\]
Thus \(|\beta|\le q\), and after setting \(x=m+\epsilon j\) with \(j\ge0\), \(\epsilon=\pm1\), the positive digital residual before the parity corrections is
\[
 R=qj^2-\epsilon\beta j-D.
\]
It is necessary that \(0\le R\le hS+r+e\). On each half the quadratic \(Q_\epsilon(j)=qj^2-\epsilon\beta j\) is nonnegative and nondecreasing on nonnegative integers, by the choice of the nearest integer center. Hence each half admits an exact interval computed from the greatest integers with \(Q_\epsilon(j)\le D-1\) and \(Q_\epsilon(j)\le D+hS+r+e\). Resolve the shared central candidate only once, intersect with the requested aspect-ratio constraints, then compute the true residual and require exact divisibility by \(2h\), since \(f\) is even. Finally evaluate the two original bit recurrences and require actual equality. The factor-two aspect condition is exactly \(\lceil S/3\rceil\le x\le\lfloor2S/3\rfloor\).

The centered expression never forms the full discriminant of order \(q^2S^2\). For these charts and the tested aspect ratios its exact polynomial evaluations fit in signed 128 bits. A floating square root only seeds the integer square-root calculation: two correction loops verify the defining integer inequalities before using any endpoint. Thus the computation does not depend on a heuristic roundoff threshold. A negative threshold has no nonnegative candidates; the nearest-integer center is essential for this fact.

For a ratio bound \(R_0\ge1\), the total has a certified upper bound from \(xy\ge R_0S^2/(R_0+1)^2\), and a lower bound from \(qxy\le q\lfloor S^2/4\rfloor\) and \(0\le f(z)\le z\). Enumerate in that interval only the sums in the requested dyadic progression, with no restriction on the individual words.
