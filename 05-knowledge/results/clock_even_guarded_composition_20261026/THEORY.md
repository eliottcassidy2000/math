# A proposed theory of objects through their permitted continuations

The bold proposal is to organize the repo around **presentations of exact
response theories**: not just which objects exist, but which distinctions
survive gluing, transport, testing and resetting. Classical continuation
quotients and representation theory provide the language. The substantive
research is finding economical generators, proving closure, and identifying
the realization constraints for the repository's actual operations.

## The exact finite framework and its limits

For each boundary type b, declare a state set X_b and a language C_b of
admissible future contexts with one hole of that type. A context includes
all permitted marking changes, attachments, operations, and terminal tests.
Use an explicit failure outcome if illegality is observable. Suppose the
language is closed under substituting any permitted operation into a hole.
For deterministic semantics define

    x ~_b y iff response(c,x)=response(c,y) for every c in C_b.

**Elementary continuation theorem (PROVED).** This is the coarsest equivalence
preserving all declared contexts; all permitted substitutions descend to it.
Indeed, if an operation separated equivalent inputs, a later distinguishing
context composed with that operation would already separate the original
inputs. Conversely, every exact context-preserving carrier must distinguish
any two states separated by a context. This is the usual continuation/Nerode
mechanism, not a claim of a new abstract theorem.

For a finite X_b and real-valued counted responses, form the matrix whose
rows are states and columns are context responses. Its row equality is a
state distinction; its column rank is the minimal number of independent
linear expectations needed for those responses. The proof of the latter is
linear algebra: a basis suffices, and fewer linear coordinates cannot span
the requested function space. Neither number alone guarantees closure of
all *joint* observations under an arbitrary stochastic transition.

For deterministic maps on a finite state set, the inherited observable-algebra
theorem gives the sharper statement: the unital algebra generated by all
future observations is exactly the functions on the continuation quotient.
Products of observations require a common initial state. Multiplying separate
means cannot manufacture those products. For weighted nondeterministic gluing,
declare whether contexts sum, normalize, retain, or inspect the branch witness;
these different languages can give different quotients.

This explains the distinction between three minimizations:

- **state quotient:** equality of all deterministic context outputs;
- **linear response representation:** dimension needed to propagate selected means;
- **probabilistic lumping:** equality of probabilities into every retained class.

The earlier [U2 theorem](../unnamed_carrier_dissection_20261026/README.md)
is a useful genuine compression: if a reset's complete row depends only on
q(x), complement is an involution tau, and q is directly observed, then
(q(x),q(tau x)) is exact and minimal for that protocol. Reset deliberately
erases old alignment. The same conclusion does not follow for size-changing
blue attachments, which can inspect joint alignment before any reset.

## Joint incidence, transport, realization: a concrete carrier schema

A constructive carrier should store or encode three layers:

**Joint incidence.** Occurrences of every boundary port, their ordered path-run
membership, how runs are matched, and witness multiplicities. A quotient walk
may revisit a prime child; its two outer endpoints cannot encode the internal
visit pattern. Simultaneous observations belong to the same state, so their
joint law must be retained when contexts can inspect conjunctions.

**Transport.** Maps between port frames, local automorphism actions, and the
composition law for their signs/phases. In a binary normal basis, cyclic
rotation of an m-letter decoration is the Frobenius x->x^2 on F_(2^m).
For an element of degree d over F2, its cyclic orbit has size d and its
stabilizer in C_m has size m/d. Degree retains symmetry order; gluing different
frames can still require the relative phase. The earlier F8 Paley mechanism
adds an orientation character of order two, distinct from Frobenius order three.
The [prior field audit](../unnamed_carrier_dissection_20261026/CONNECTIONS.md)
also distinguishes F8 x F8 at seventh roots from F16 at fifth roots.
More explicitly, write the retained frame as z=F^(-i)(x_w), with F(x)=x^2.
An entrance re-marking by delta sends z to F^(-delta)(z). Complement does
not itself apply Frobenius: it changes the relation while ancestral labels
remain fixed. The old children may cease to be modules, so ancestry is a
separate coordinate if future contexts still query it.

The inherited [sharp 4p theorem F2](../tournament_composition_classification_20261026/fibre/RESULT.md)
makes this a quantitative boundary: for every odd prime p, the p-part of
automorphism order is constant within a labelled cyclic-triple fibre below
4p, and the bound is attained. At p=3 the 81/27 pair loses the quotient
rotation when one of three four-vertex children changes converse colour.
In normal-basis language, degree one versus degree p removes the cyclic
factor p. This threshold is for changing the unmarked type within that
fibre; a port marking can reduce a stabilizer earlier and is a different
operation. It is not a bound on the rank of all possible response algebras.

**Realization guards.** Actual directed paths; compatibility of reused vertices;
global connectivity after contraction; nonnegative inverse-Fourier masses;
integer lifts and finite-support tapes; or geometric non-overlap and boundary
matching. A formal tensor contraction is valid only when it counts complete
realized witnesses. Which guards are redundant is a theorem to prove.

Composition first matches named incidences and transports frames, then tests
guards and sums valid witness weights. A quotient is taken only after proving
that its equivalence respects every later allowed context. Associativity
requires a weight-preserving bijection of complete witnesses under the two
parenthesizations. The formula in FOURIER §F4 expresses this operation in
signed graph coordinates; it does not supply the missing witness bijection.

## Connection matrices provide a classical benchmark

In [Lovasz, *The rank of connection matrices and the dimension of graph algebras*](https://arxiv.org/html/math/0408232v1),
Theorem2.2, a twin-free weighted target graph with positive vertex weights and
real edge weights has k-labelled homomorphism connection-matrix rank equal
to the number of automorphism orbits on ordered vertex k-tuples. Gluing
labelled graphs creates the context algebra. This is a precise precedent
for recovering joint boundary orbits from a sufficiently rich test language.

The theorem concerns all those graph-homomorphism contexts. Our native
tournament path guards are a different language, with distinct positivity
and injectivity requirements. It cannot be cited as an all-size proof that
joint port responses classify strong atoms. The useful question is whether
the permitted tournament contexts generate the full relevant invariant
algebra, or which explicit characters remain invisible.

There is now a concrete changing-size counterpart in the incoming packet:
signed root-moving deletion-card isomorphisms give an unrestricted
[augmentation recurrence for A000568](../support_image_composition_20261026/even_graphs/RESULT.md).
Their signs multiply under transport and cancel odd children. Odd parents
must be retained, since deleting a leaf from sign-even P3 produces sign-odd
K2. Thus a class defined by surviving final observations need not be closed
under the intermediate operations required for composition. This parallels
children ceasing to be modules after native complement. The recurrence uses
graph and marked-card states, not merely the preceding scalar sequence values.

## Proposals with falsifiable obligations

**C: counted complement cyclicity (OPEN).** For native counted L, the constant
vector is cyclic on converse-invariant functions at every n. Exact proof by
finite enumeration holds through n7, including certified rank272 modulo a
checked prime at n7. Native guards may be what makes this operator far more
observant than the single-arc-flip operator of THM-848. Next test n8; a rank
defect would refute cyclicity, though pairwise response sequences might still
separate states. This is not the same claim as joint-port histogram injectivity.

**J: an economical full attachment presentation (OPEN).** Give generators and
relations for quotient-walk run matchings, phase transport and guards; prove
every permitted complement/re-marking/attachment is represented. Then prove
a minimality theorem relative to that exact language. Named legal-path guards
already reconstruct tournaments by THM-4807, so any smaller named carrier
must encode the same information more efficiently, not discard it.
The inherited free/joint strong-atom response classification is exhaustive
through n8 (6,008 strong classes), with even the free supports separating
there. Its all-size injectivity remains OPEN; neither the new scalar test
through n7 nor a formal change of basis supplies that missing proof.

**G: quantify correlation and precision costs (PROGRAMME).** The Vitali and
finite marked Penrose constructions supply actual conjunction tests on hidden
alignment bits. Seek sharp lower bounds for more restricted unnamed grammars:
which conjunction orders can they realize, and at what attachment size?
Arithmetic/tape division suggests a parallel cost measured in consumed digits.
An actual reduction must map contexts and preserve realization, not merely
match the two lower-bound sequences.

These proposals place the advances within harmonic invariant theory, context
algebras and arithmetic transducers. They leave real work: useful presentations
smaller than raw state enumeration, proofs of realization, and uniform bounds.
Existing META-PATTERNS cards on witness fibres, quotient sidecars and operation
closure already describe the general research move; no new card is warranted
merely by giving that move a broader name.
