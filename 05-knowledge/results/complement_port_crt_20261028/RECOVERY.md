## A concrete unifying composition statement

**PROVED elementary, standard mechanism; proposed organizing language.**
Represent a legal step by a witness set W with source and target maps
X <- W -> Y, an equivariant action when relabellings are allowed, a weight,
and an explicitly charged clock. Consecutive steps compose through the actual
fibre product W x_Y V, retaining the common intermediate state. Multiply
weights and add clocks. Reassociating triples of compatible witnesses is a
literal bijection, so this composition is associative. This is standard
relational/weighted-automaton composition, not a claim of a new general theory.

The mathematical work is to find the smallest realization of X,Y that still
supports those fibre products. Quotienting each marginal separately can
create false joins. The examples now locate three different losses:

The same syntax does not make these dynamical systems isomorphic. A true
