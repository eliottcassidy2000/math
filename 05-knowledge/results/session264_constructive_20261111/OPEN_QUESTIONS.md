# Constructive frontier after Session264

**Chan–Pak remains OPEN.** Every positive odd integer other than7 and21 is
still the target, not a conclusion of modular control or of the new compiler.

1. **Height-controlled moving-mark lifting.** Turn the exact affine F5 clock
   and full-state prime-field controller into a simultaneous integer height
   bound. The modular representatives currently grow rapidly. Session199's
   phantom profile shows why passing all congruence tests is insufficient.
   Prime761 and prime-power/full-CRT state control are narrower initial tasks.
2. **An arithmetic use of the rooted dipole.** The H29 modules have the same
   entire unmarked and root-deleted cover profiles but U,V move by±2. Their
   fusion-order switch has positive effect in every context. Can a new physical
   surrounding context turn a family of these switches into a controllable
   small-step interval, rather than a monotone ladder with large gaps?
3. **Bridge the interfaces, do not conflate them.** The moving-mark source has
   exact unit selected offset. Shared-root sources have one selected vertex
   and positive offset H, generally not1. Construct an actual conversion
   preserving a paid offset and useful endpoint response, with an explicit
   initial object; no matrix identification alone supplies this bridge.
4. **Use simultaneous return ports to synthesize a specified selector.** The
   new square-zero seam grammar handles multi-return cycles and exact packings.
   Find a family of actual port modules with a requested signed-state count
   and a reusable marked interface. Arbitrary matrices or conflict graphs are
   not automatically tournament-realizable.
5. **Higher dyadic filters by component merging.** The positive triangle-wrap
   operator and its finite skeleton compiler replace expensive induced-subset
   search in one grammar. Construct a modulus16 filter or find an exact new
   architecture. Bounded unsuccessful word searches do not rule out16-filter
   existence or arbitrary tournament blocks.
6. **Consume a selected residue without conditioning.** The new wrapper keeps
   the old endpoint and makes root-path length an actual gate position. Uniform
   mod8 channels are now literal endpoint-conditioned Hamiltonian families.
   Realize one selected position-residue channel as an unconditioned H or a
   returned active source. Merely reading that conditioned subset is not a
   physical scalar projector.
7. **Compose, then control resource growth.** The return trade, root matrix,
   and endpoint consumer genuinely interact. The next payoff must account for
   vertex cost, selected offset, deletion profile, integer height and initial
   states at the SAME time. Finite state dimension alone is not short inverse
   coverage, and a vast family of distinct counts is not cofinite coverage.
