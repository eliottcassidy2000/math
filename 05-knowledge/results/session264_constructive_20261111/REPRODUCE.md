# Reproduction and evidence scope

Run from the repository root with Python3, using the standard library:

    python3 -B 05-knowledge/results/session264_constructive_20261111/control/controls.py
    python3 -B 05-knowledge/results/session264_constructive_20261111/returns/multi_return_probe.py
    python3 -B 05-knowledge/results/session264_constructive_20261111/fusion/construct.py
    python3 -B 05-knowledge/results/session264_constructive_20261111/filters/controls.py

canonical `filters/controls.out` content. They test NEW operations; no inherited
result-verification campaign is included. Formula proofs provide the all-size
claims; finite experiments never replace the quantifiers.

## Exact universes and what their checks establish

- **Control:** 38 literal graph/closing checks,255 clock states,24 quotient
  orbits,15 prime translation identities, and261,630 finite residue vertices
  across the odd moduli3–31. The p5 spanning tree contains all250 states and is
  a finite component of the theorem. Composite full-state transitivity remains
  FINITE-EXACT; only the explicitly proved modulus scopes are all-order results.
- **Returns:** all labelled shores of orders1–3 with prefix mark sets and every
  pairing, totalling705 constructors by return count, plus24 seeded7/8-vertex
  cases. Full literal-cycle parsing, square-zero packing, exact path counts,
  determinant controls and cover counts at1,2,3 are compared. This is NOT an
  unrestricted tournament census. Explicit H29 trade masks and all cycles are
  retained, including a hostile where undeleted forward seams create false cycles.
- **Fusion:** 121 small pair constructions,64 associativity triples, ten repeated
  towers through five factors,16 literal common sorting contexts up to15 vertices,
  and four larger exact matrix-compiled ladders. The last are not full-graph
  enumerations. The all-context sign theorem comes from matrix multiplication
  and U,V≥h, not extrapolation from the16 contexts.
- **Filters:** 190 exact new-operation gates on31 one-apex word sources and20
  seeded arbitrary sources, multiple wraps, both endpoint consumers, two marked
  dipoles, and a non-preservation hostile. The positive odd-component compiler
  and direct path DP are separate routes. A selected residue is still a
  conditioned family, not a tournament scalar count.

## Exploratory bounded scanner

The primitive16 scans are stored, not necessary for the positive theorems.
Their source `filters/primitive_scan.cpp` is compiled with a standard C++
compiler, for example:

    g++ -std=c++17 -O3 05-knowledge/results/session264_constructive_20261111/filters/primitive_scan.cpp -o /tmp/s264-primitive-scan
    /tmp/s264-primitive-scan < 05-knowledge/results/session264_constructive_20261111/filters/scanner_positive8_input.txt

Use the three corresponding `*_input.txt` files for the finite primitive16
runs. The exact word ranges, integer overflow bounds, positive mod8 control,
and stopped-search meaning are stated in `filters/PROOF.md`. No filter-existence
or nonexistence theorem rests on the unsuccessful ranges.

## Provenance and publication discipline

`sampling.json`, the root and lane source ledgers, and the source-pin manifests
separate historical inspiration, accepted inputs, native maps and discarded
analogies. The Session199 modular-height escape and Session202 binary-append
boundary were recovered and retained rather than overwritten.

The final scoped replay is in `FINAL_CHECKS.json`; `MANIFEST.json` hashes the
packet files except itself. No Lean build or external-source audit was attempted
or claimed. Navigation checks apply to the maintained documentation surface.
Only owned explicit paths were staged. Main was updated by non-force ref
updates with the expected current parent and independently fetched afterwards.
