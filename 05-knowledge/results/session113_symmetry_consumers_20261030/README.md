# Session 113 — symmetry depends on its consumer

**Status: verified research packet, 2026-10-30.** Elementary scoped proofs and finite exact controls; no major open problem is closed.

The organizing rule is to specify **the action, the consumer, and the retained state** before quotienting. The same orbit information can be sufficient for a binary relation and insufficient for a marked constraint, physical derivative, or nonlinear identity.

## Main advance: a failed quotient, repaired by first-return phase

The old phase-gated Collatz envelope is **REFUTED** by explicit finite positive-source words. Its failure identifies missing first-return information, rather than disproving the actual-content target. Retaining one digit of multiplier phase and a pending-return bit repairs the consumer. The [independently certified E9 theorem](uniform_content/REPAIRED_CERTIFICATE.md) proves, for every finite positive valuation word with clock A,

    S_9 <= (488281/781250) A,

and, if any letter exceeds one,

    S_9 <= (488281/781250)(A - 2).

Both constants are sharp. The independent checker verifies 525,000,000 transitions, 126 entries, domain closure, and analytic tails covering every larger letter. This is a fixed-precision theorem, not Collatz convergence. The producer is explicitly restricted to E<=9 and writes portable little-endian signed64 vectors.
