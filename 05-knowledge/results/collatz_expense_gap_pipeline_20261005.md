## 3. Arithmetic support changes the measurement problem

For the actual normalized leaf law p_j=lambda(6j+3), fix m and write

    h_m(j)=x_|j-m|,     x_d=4*2^d/(2^d+1)^2,
    H_k=sum_j p_j h_m(j)^k.

The support consists of these shells, not the whole interval[0,8/9] away
from the target. For positive odd N define

    Q_N(h)=product_(d=1)^N (h-x_d)/(1-x_d),
    epsilon_N=product_(d=1)^N x_d/(1-x_d).

Then Q_N equals1 at the target, vanishes at the first N off-target shells,
and is nonpositive on every remaining shell. Consequently

    E Q_N <= p_m <= E Q_N+epsilon_N.

For odd N>=3 these minorants increase pointwise under N->N+2. Moreover

    epsilon_N <= (1024/81)*2^(-N(N-3)/2),
    sum_k |[h^k]Q_N| <512.

The direct-moment coefficients therefore remain uniformly conditioned as
the degree increases. This does not eliminate the cost of obtaining the
moments: conversion from the inherited primitive resolvent observables has
a separate conservative factor8^N.

There is an exact connection to the earlier product/generating-function
lane. At q=1/2, using (q;q)_N=product_(d=1)^N(1-q^d),

    epsilon_N=2^(-N(N-3)/2)/(1/2;1/2)_N^2.

The dyadic product is bounded below by9/32, which is the concrete reason
the error estimate is uniform. No modularity or prime-distribution claim
is imported from the resemblance to other q-products.

The support information can strictly improve a finite measurement problem.
The shell law with masses(1,333,333,333)/1000 at(1,x1,x2,x3) gives the cubic
floor1/1000. Exactly the same H0,H1,H2,H3 also admit a zero-target law on
the relaxed interval. That law uses the impossible shell1/2. This is a

## 5. The analytic route beyond the family

On the exact base operator P=A* at price1/2, two growing envelopes satisfy
proved all-source inequalities:

    V_p(b)=((3b+1)/4)^(1/12),
    P V_p <= (3280/3367)V_p;

    V_l(b)=(25+bitlength(3b+1))/28,
    P V_l <= (641/686)V_l.

Both have V(1)=1. A global inequality

    (I-P)phi <= delta_b+eta V,     |phi|<=M V

therefore proves

    g(b)>=phi(1)-eta/(1-kappa_V).

This admits genuinely unbounded witnesses while retaining the disappearing
boundary required for duality. Growth envelopes alone say nothing about the
sign of this lower bound at an unknown source. The critical inverse-ray
hostile has weighted norm1 and an undying boundary, so it remains excluded.

The patch theorem can now be used in either weighted space. Eliminating an
interior I while retaining ports J records both

    K=P_JJ+P_JI(I-P_II)^(-1)P_IJ,
    b=q_J+P_JI(I-P_II)^(-1)q_I.

The retained equation is (I-K)h<=b, with exact signed forcing and a localized
error bill. The operator changes by weight conjugation in the weighted case.
This is a precise target for combining families: supply the return data and
forcing globally, then prove the root readout positive. Unknown interiors
cannot be filled with guessed positive connections.

Exact state identification is more restrictive than this elimination. In an
exactly lumpable functional graph, isolating the forced source recursively
forces its parent path to remain singleton states. Schur elimination can
remove those states because it retains their return weights instead of
identifying their equations. This is the relevant lossless-compression
distinction; it does not prohibit other finite proof languages.
