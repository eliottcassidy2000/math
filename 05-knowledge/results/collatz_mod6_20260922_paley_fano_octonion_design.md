## 1. Counts on `T_7`, and the "21 directed 3-cycles"

**S1 (PROVED).** In a tournament on `n` vertices with scores `s_1, ..., s_n`, every triple of vertices is either a directed 3-cycle or transitive, and a transitive triple has a unique source (the vertex beating the other two). Hence the number of transitive triples is `sum_i C(s_i, 2)` and the number of cyclic triples is `c_3 = C(n,3) - sum_i C(s_i,2)`. For a regular tournament (`n` odd, all `s_i = (n-1)/2`): `c_3 = n(n-1)(n-2)/6 - n (n-1)(n-3)/8 = n(n-1)(n+1)/24 = (n^3-n)/24`. QED. At `n = 7`: `35 - 7*3 = 14`.

**S2 (FINITE-EXACT, session lead probe verified).** `T_7`: 21 arcs, scores `[3,3,3,3,3,3,3]`, 14 cyclic triples, 21 transitive triples, `C(7,3) = 35`, `(7^3-7)/24 = 14`, `tr A^3 = 42 = 3 c_3`. Every arc lies in exactly 2 cyclic triples (21 arcs, multiplicity set `[2]`): the cyclic triples form a 2-(7,3,2) design.

**S3 (FINITE-EXACT).** `h(T_7)`, the number of directed Hamiltonian paths, by subset dynamic programming: `189`. This agrees with `h(QR_7) = 189` in THM-338 and THM-1370 (which lists 189 as the n = 7 maximum).

**S4 (REFUTED).** "`T_7` contains exactly 21 directed 3-cycles": the count is 14. The paste's derivation "7 lines x 3 cyclic permutations = 21" counts the three rotations `(i,j,k), (j,k,i), (k,i,j)` of ONE directed 3-cycle as three cycles, and only over the 7 lines of one Fano plane; the number 21 coincides with the arc count and with the transitive-triple count, and the rooted (closed-walk) count is `tr A^3 = 42`, not 21. No reading of "directed 3-cycle" gives 21.

**S5 (REFUTED).** "which match its forbidden Hamiltonian path count": the holes 7 and 21 of THM-1370 are values of `h(T)` that NO tournament attains; `h(T_7) = 189`. There is nothing to match: 21 is not `h` of `T_7` or of anything else.

## 2. The 14 cyclic triples are two disjoint Fano planes

**S6 (PROVED; the statement is the session lead probe's, recorded concurrently in [block_spectrum_audit](collatz_mod6_20260922_block_spectrum_audit.md) S13 and [compression_and_lean_audit](collatz_mod6_20260922_compression_and_lean_audit.md) S10; the proof is this lane's).** Translation `x -> x+1` is an automorphism of `T_7`, so cyclicity of a triple depends only on its translation class. The 35 triples of `Z/7` fall into 5 classes of 7 (no triple is fixed by a translation since `3` does not divide `7`): the three arithmetic-progression classes `{x, x+a, x+2a}`, `a = 1, 2, 3`, and the two non-progression classes of `{0,1,3}` and `{0,1,5}`. By S21 (with `7 = 7 mod 8`, `2` a square) no progression triple is cyclic. On `{0,1,3}`: `0 -> 1` (difference 1), `1 -> 3` (2), `3 -> 0` (4): cyclic. On `{0,1,5}`: `0 -> 1` (1), `1 -> 5` (4), `5 -> 0` (2): cyclic. Hence the cyclic triples are exactly `dev{0,1,3}` union `dev{0,1,5}`, 7 + 7 = 14, disjoint. Each is a cyclic Steiner triple system: the differences of `{0,1,3}` are `+-1, +-2, +-3` and those of `{0,1,5}` are `+-1, +-4, +-5`, each exhausting `Z/7 \ {0}` once, so every pair lies on exactly one block. ## 3. Octonions from the Paley orientation

Fix the basis `1, e_0, ..., e_6` (imaginary index `r` in `Z/7`), and for the Fano plane `dev{0,1,3}` define `e_r e_s = +e_t` if `r -> s` in `T_7` and `-e_t` if `s -> r`, where `t` is the third point of the line through `r, s`; `e_r^2 = -1`; `1` is the identity. This is the braids2 map (F1) with Paley as the sign tournament.

**S10 (PROVED; CITED as the standard mnemonic).** The table satisfies `e_r e_{r+1} = +e_{r+3}`, `e_{r+1} e_{r+3} = +e_r`, `e_{r+3} e_r = +e_{r+1}` for all `r` (checked, `True`): this is the "`e_i e_{i+1} = e_{i+3}`, indices mod 7" rule of the usual Fano-plane mnemonic for the octonions (Baez, *The Octonions*, Bull. AMS 39 (2002), section 2, Fano-plane figure; the exact page and index convention there are UNCITED-RECOLLECTION, the rule itself is verified here on the constructed table).

**S11 (PROVED, by exact computation).** The algebra is alternative: the left- and right-alternative laws are quadratic in one variable, so over `Q` they hold iff their polarisations `(ab)c + (ba)c = a(bc) + b(ac)` and `a(bc) + a(cb) = (ab)c + (ac)b` hold on all `8^3 = 512` basis triples, and they do (`True`). It is a composition algebra: `N(xy) = N(x)N(y)` is biquadratic, so it holds iff its full polarisation `<xy,wz> + <xz,wy> = 2<x,w><y,z>` holds on all `8^4 = 4096` basis quadruples, and it does (`True`); 200 random integer pairs also satisfy `N(xy) = N(x)N(y)`, `(xx)y = x(xy)`, `(yx)x = y(xx)` (`True`). It is not associative: `(e_0 e_1) e_2 = -e_5` while `e_0 (e_1 e_2) = +e_5` (by hand: `e_0 e_1 = e_3`, then `e_3 e_2 = -e_5` because the line `{2,3,5}` is oriented `2 -> 3 -> 5`; `e_1 e_2 = e_4`, then `e_0 e_4 = +e_5` because `{4,5,0}` is oriented `4 -> 5 -> 0`; the `.out` prints the coordinate vectors `[0,0,0,0,0,0,-1,0]` and `[0,0,0,0,0,0,1,0]` in the basis `1, e_0, ..., e_6`, so the nonzero entry at 0-based index 6 is `e_5`; the explorer's draft wrote `e_6`, corrected by the audit). That an 8-dimensional alternative composition algebra with identity and positive-definite norm over `Q` is an octonion algebra is Hurwitz's theorem (CITED: Hurwitz 1898 for the dimension list `1, 2, 4, 8`; the classification of the 8-dimensional case as Cayley algebras is UNCITED-RECOLLECTION, Springer-Veldkamp); it is not needed here because S13 makes the isomorphism explicit.

**S12 (PROVED).** The same construction on the other Fano plane `dev{0,1,5}` (rule `e_r e_{r+1} = +e_{r+5}`; the paste as quoted never mentions a second table or `i -> -i`, this is the lane's own sidecar) is also alternative and a composition algebra (exact, `True`, `True`). ## 5. The 2-`(p,3,(p+1)/4)` design for every prime `p = 3 mod 4`

The affine group `G = {x -> ax + b : a in Q, b in F_p}` has order `p(p-1)/2` and acts by automorphisms (`a(j-i)` is a square iff `j-i` is). It is transitive on arcs: the stabiliser of the arc `(0,1)` is trivial (`b = 0`, then `a = 1`), so the orbit of `(0,1)` has size `p(p-1)/2` = the number of arcs; hence `G` is regular on arcs. Every arc therefore lies in the same number `lambda` of cyclic triples; counting incidences, `3 c_3 = lambda * p(p-1)/2` with `c_3 = (p^3-p)/24` (S1, `T_p` is regular of score `(p-1)/2`), so `lambda = (p+1)/4`. Every unordered pair is an arc in one direction, so every pair lies in exactly `(p+1)/4` blocks: the cyclic triples form a 2-`(p, 3, (p+1)/4)` design with `(p^3-p)/24` blocks. `lambda = 1` iff `p = 3` (one block), `lambda = 2` iff `p = 7`. **S20b (PROVED; audit addition, the general form of S20).** For any tournament `T` on `n` vertices: the cyclic triples of `T` form a 2-design (every unordered pair in the same number `lambda` of cyclic triples) iff `T` is doubly regular (regular, and every ordered pair `i != j` has the same number `k` of common out-neighbours), and then `n = 4k+3` and `lambda = k+1 = (n+1)/4`. Proof. For an arc `i -> j` write `N^+`, `N^-` for out- and in-neighbourhoods; the cyclic triples through the arc are indexed by `N^+(j) ∩ N^-(i)`, and `N^+(j)` is the disjoint union of `N^+(j) ∩ N^+(i)` and `N^+(j) ∩ N^-(i)` (`i` is not in `N^+(j)`). (=>) If every pair lies in `lambda` cyclic triples, then every cyclic triple through a vertex `i` uses exactly one out-arc and one in-arc at `i`, so counting them by out-arcs and by in-arcs gives `lambda s_i = lambda (n-1-s_i)`, i.e. `s_i = (n-1)/2` (`lambda >= 1` as soon as some triple is cyclic; if none is, `T` is transitive and neither side of the equivalence holds for `n >= 3`): `T` is regular. Then for every arc `i -> j`, `|N^+(i) ∩ N^+(j)| = s_j - lambda = (n-1)/2 - lambda`; the common out-neighbour count is symmetric in `i, j` and every unordered pair is an arc in one direction, so it is the same for all ordered pairs: doubly regular with `k = (n-1)/2 - lambda`. (<=) If `T` is doubly regular with `k` common out-neighbours: the arcs inside the sub-tournament on `N^+(i)` number `C(s_i, 2)` and also `sum_{j in N^+(i)} |N^+(j) ∩ N^+(i)| = s_i k`, so `s_i = 2k+1` for every `i` with `s_i > 0` (and `s_i = 0` forces `k = 0` and `n <= 3`, where the claim is trivial): `T` is regular, `n = 4k+3`. Then for an arc `i -> j`: `|N^+(j) ∩ N^-(i)| = s_j - k = k+1`, the same for every arc, and every pair is an arc in one direction, so every pair lies in `k+1 = (n+1)/4` cyclic triples. QED.
