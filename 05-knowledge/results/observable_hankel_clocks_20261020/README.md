# Observable Hankel clocks

Read [OBSERVABLE_HANKEL_CLOCKS.md](OBSERVABLE_HANKEL_CLOCKS.md). A recovered degree22 integer recurrence becomes a degree6 binary LFSR, with an exact bad-prime state filtration, a proved minimal-register staircase at higher2-adic precision, and a pointed orbit clock Z/3 × Z2. The global recurrence, Hankel image and invariant observation filtration are retained separately.

Run `python verify_hankel_clock.py` (requires SymPy); optimized Python gives the same output. Independent proofs and controls are in `review/`. No coloring headline, physical isomorphism or general major-conjecture closure is inferred.
