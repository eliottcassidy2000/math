**S6 (PROVED; residue criterion for a retrace).** Let `p` be odd, `3 !| p`, `k = v_2(3p+1)`, `u = (3p+1)/2^k` (a forward step `p -> u`). Then `G(u) = p` iff `(p = 1 mod 3 and k <= 3)` or `(p = 2 mod 3 and k = 1)`; if `3 | p` then `G(u) != p` (`G` never lands on a multiple of 3). Proof: `2^k u = 3p+1` is `4 mod 9` if `p = 1 mod 3` and `7 mod 9` if `p = 2 mod 3`, so `k` is an admissible letter at `u` and `G(u) = p` iff no smaller `k' = k - t` is admissible, i.e. iff `2^(-t)(3p+1) mod 9` is not in `{4,7}` for `1 <= t <= k`. With `2^(-1) = 5 mod 9` the backward orbit of `4` is `4 -> 2 -> 1 -> 5 -> 7 -> 8 -> 4` and that of `7` is `7 -> 8 -> 4 -> 2 -> 1 -> 5 -> 7`: from `4` the first hit of `{4,7}` is at `t = 4`, from `7` at `t = 2`. Hence the condition is `k <= 3` for `p = 1 mod 3` and `k <= 1`, i.e. `k = 1`, for `p = 2 mod 3`. QED. In residue form: `p = 1 mod 3` with `k <= 3` iff `16 !| 3p+1` iff `p != 5 mod 16`; `p = 2 mod 3` with `k = 1` iff `3p+1 = 2 mod 4` iff `p = 3 mod 4`; so `G(u) = p` iff `p mod 48` lies in `{1, 7, 11, 13, 19, 23, 25, 31, 35, 43, 47}`, `11` of the `16` odd classes coprime to 3 (verified for odd `p < 20000`). **Corollary (full retrace).** The greedy path from `M` retraces `n`'s forward orbit for exactly `ov(n)` steps, where `ov` is the number of consecutive indices `i = L_1, L_1-1, ...` whose predecessor `n_(i-1)` satisfies the criterion; it retraces fully (`ov = L_1`) iff every pre-peak iterate `n_0, ..., n_(L_1-1)` lies in the mod-48 set (`n_0 = n` is the only pre-peak iterate that can be a multiple of 3; when it is, it lies outside the mod-48 set and the retrace stops at `ov = L_1 - 1`). ## 4. The `G`-analogue of the bounded-strip theorem (S9-S10)

Notation: for a `G`-orbit `m_j = G^j(m_0)` with letters `k_j`, `K_j = k_1+...+k_j`, `3^j m_j = 2^(K_j) m_0 - B_j`, `B_j = sum_{s<=j} 3^(s-1) 2^(K_j-K_s)`, and `r_j = 3^j/2^(K_j)` (the discrepancy is `j log_2 3 - K_j`). The typed mirror with the guards note: source = forward Collatz with `q_j = 2^(K_j)/3^j` and `n_j = q_j^(-1)(n_0 + (1/3) sum_(i<j) q_i)` (D1); target = `G` with `r_j` and `m_j = r_j^(-1)(m_0 - sum_(s<=j) 3^(s-1)/2^(K_s))` on the positive sheet, `|m_j| = r_j^(-1)(|m_0| + sum_(s<=j) 3^(s-1)/2^(K_s))` on the negative sheet; map = exchange of the adic roles (`2 <-> 3`) in the carry; preserved = the additive form of the carry and the sign of the carry on the negative sheet; lost = the sign of the carry on the positive sheet, which is why the two sheets need different proofs; sidecar = the capacity constant `9/2` in place of `9`; test = the two sign laws `2^K > 3^L` for positive `G`-cycles and `2^K < 3^L` for negative ones (S4, every `q = 1` walk).

**S9 (PROVED; positive sheet, positivity alone).** For every `G`-orbit on the positive integers coprime to 3, `sum_{s>=1} 3^s/2^(K_s) <= 3 m_0`; hence `r_j -> 0` and `K_j - j log_2 3 -> +infinity`, and no positive `G`-orbit keeps `r_j` in any strip `[A, B]` with `A > 0`, nor even bounded below. Proof: `G` preserves positivity (`G(m) >= (m-1)/3 > 0` for `m >= 2`, `G(1) = 1`), so `3^j m_j = 2^(K_j) m_0 - B_j > 0`, i.e. `B_j < 2^(K_j) m_0`, and dividing by `2^(K_j)` gives `sum_{s<=j} 3^(s-1)/2^(K_s) < m_0` for every `j`; the partial sums of a positive series are bounded, so it converges and its terms tend to `0`. QED. This is the exact mirror of the guards' `b < 0` statement (D8), where positivity of the `3n-1` orbit forces `sum q_j <= 3n_0` and `q_j -> 0`: the positive `G` sheet plays the role of `3n-1`. (Checked: the partial sums to `300` terms are below `3 m_0` for every `m_0 <= 5000`, the ratio being largest, `3.000000`, at the fixed point `m_0 = 1` where the series is `sum (3/4)^s`.) Consistency: the positive cycle `{1}` has `3^L/2^K = 3/4 < 1`.

**S10 (PROVED; negative sheet, transfer of the guards' section 2a).** No `G`-orbit on the negative integers coprime to 3 satisfies `0 < A <= r_j <= B < infinity` for all `j`, nor for all `j >= j_0` (the tail from `m_(j_0)` is itself an orbit whose ratios are `r_j` times the constant `2^(K_(j_0))/3^(j_0)`). Write `p_j = -m_j > 0`; by S1 this is a `G_-`-orbit, `3^j p_j = 2^(K_j) p_0 + B_j` with the same `B_j`, all letters in `{0,1,2,3}`.

*Step 1 (linear bounds, the (D1) analogue).* `p_j = r_j^(-1)(p_0 + sum_{s<=j} 3^(s-1)/2^(K_s))`, because `B_j/3^j = (2^(K_j)/3^j) sum_{s<=j} 3^(s-1)/2^(K_s)`. Under the strip, `A/3 <= 3^(s-1)/2^(K_s) <= B/3`, so

`(A/(3B)) j <= p_j <= p_0/A + (B/(3A)) j` for all `j >= 0`.

*Step 2 (no repeated state).* If the orbit were eventually periodic with a cycle of `L` steps and `K` letters, the gate `m_0'(2^K - 3^L) = B'(w) > 0` with `m_0' < 0` gives `2^K < 3^L`, so one lap multiplies `r_j` by `3^L/2^K > 1` and `r_j -> infinity`, contradicting `B`. Hence the `p_j` are pairwise distinct. (The two known negative cycles have `3^L/2^K = 3/2` and `9/8`.)

*Step 3 (capacity sidecar, the (D2) analogue).* The `p_j`, `1 <= j <= N`, are distinct integers coprime to 3 below `p_0/A + (B/(3A)) N`, of which there are at most `(2/3)(p_0/A + (B/(3A)) N) + 1`; dividing by `N` and letting `N -> infinity` gives `B/A >= 9/2`. (Collatz's odd-and-coprime count gives `9`.) Not needed below.

*Step 4 (fixed-factor density-zero lemma).* For `0 < eps <= 1` let `E_eps = {p > 0, 3 !| p : G_-^l(p) >= eps p for all l >= 0}`. Then `E_eps` has relative natural density zero among the integers coprime to 3. Proof. Fix `J`. The letters `k_1..k_J` of `G_-` at `p` depend only on `p mod 3^(J+1)` (extended lane Theorem 4.1 for `G`, transported by the negation `p -> -p`, which permutes the unit classes mod `3^(J+1)`, exactly as its Theorem 6.2 states for `E_-`; three-adic lane Theorem 4.1 for every `G_b`; verified here for `J <= 6` on every unit class with lifts `t = 1, 2, 5`). So the bad set `{p : 2^(K_J) >= (eps/2) 3^J}` is a union of unit classes mod `3^(J+1)` and its relative density equals its Haar measure, which by Markov's inequality is at most `E[2^(K_J)]/((eps/2) 3^J) = 3(7/3)^(J-1)/((eps/2) 3^J) = (2/eps)(7/9)^(J-1)`, using `E[2^(K_J)] = 3(7/3)^(J-1)` (extended lane Theorem 4.3, transported by the same negation, which preserves the class counts; verified exactly here for `J <= 8`: `3, 7, 49/3, 343/9, 2401/27, 16807/81, 117649/243, 823543/729`, and the observed bad fractions at `eps = 1`, e.g. `0.084743` at `J = 8` against the bound `0.344365`). On the good set, `G_-^J(p) = (2^(K_J) p + B_J)/3^J < (eps/2) p + B_J/3^J`, and the intercept is bounded uniformly in `p`: `B_J = sum_{s<=J} 3^(s-1) 2^(K_J - K_s) <= 2^(K_J)(3^J - 1)/2 < 8^J 3^J/2` since `K_J <= 3J`, so `B_J/3^J < 8^J/2 <= (eps/2) p` as soon as `p >= 8^J/eps`. Hence every good `p >= 8^J/eps` has `G_-^J(p) < eps p` and is not in `E_eps`: `E_eps` is contained in the bad set together with a finite set, so its upper relative density is at most `(2/eps)(7/9)^(J-1)`. Let `J -> infinity`. QED. (The inequality `B_J <= 2^(K_J)(3^J-1)/2` is asserted on every unit class mod `3^(J+1)` for `J <= 8`; the general case is the termwise bound `2^(K_J-K_s) <= 2^(K_J)`.)

*Step 5 (contradiction).* By Step 1, for every `l >= 0`, `p_(j+l)/p_j >= (A/(3B))(j+l)/(p_0/A + (B/(3A)) j) >= (A/(3B)) j/(p_0/A + (B/(3A)) j)`, which tends to `A^2/B^2`; so there is `j_1` with `p_(j+l) >= eps p_j` for all `j >= j_1`, `l >= 0`, where `eps = A^2/(2B^2)`, i.e. `p_j in E_eps` for all `j >= j_1`. By Step 2 these `p_j` are distinct, and by Step 1 all `p_j` with `j <= (3A/B)(X - p_0/A)` are `<= X`; so `#(E_eps cap [1,X]) >= (3A/B) X - const`, a positive lower relative density, contradicting Step 4. QED.

Every step is written; the inherited ingredients are cited by path and re-verified on finite ranges, not re-proved. The synthesis' hypothesis (iv) is therefore PROVED on both sheets, but with different mechanisms: on the positive sheet the strip is excluded by positivity alone (S9, no density needed, mirroring the guards' `3n-1` case), on the negative sheet by the full 2a transfer (S10, mirroring the guards' `3n+1` case). What the theorem does not give, exactly as in the guards note: any control of unbounded excursions, any descent statement, or anything about S3.
