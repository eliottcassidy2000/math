## Common structure, without a universal equivalence claim

The useful common operation is conditioning on an actual shared object before taking a quotient. Endpoints, owners, frames, and common paths constrain how local observations can coexist. After that conditioning, the remaining ambiguity has a concrete carrier: a finite matching trade, a binary cycle, an affine phase, or a family of path incidence vectors.

Three questions must remain separate:
1. Is a proposed global object realizable?
2. Which realizable object does a signature identify, and up to which symmetry?
3. Does the identified object retain enough path-position transport to recover the native metagraph wiring?

A theorem answering one of these is not automatically a theorem answering the next. Every result packet declares its universe and the sidecar needed to cross that boundary.
