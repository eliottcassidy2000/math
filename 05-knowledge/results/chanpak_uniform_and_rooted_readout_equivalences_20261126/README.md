# What homogeneous hosts and marked clones can recover from a Hamiltonian-path count

The [previous session](../chanpak_small_fibers_two_port_boundaries_and_rooted_moves_20261126/README.md) gave pairs of modules that a uniform host cannot distinguish, and examples where a local clone does distinguish them. Here are converse theorems for both readouts, a single-scalar decoder, and a census of small positive clone experiments. None requires the Chan–Pak spectrum conjecture.

## 1. Uniform external access: exactly the path-cover polynomial

For a nonempty module \(M\), let \(A_j\) count ordered covers by \(j\) nonempty directed paths, and put \(P_M(z)=\sum_j A_j\binom zj\). In a homogeneous substitution any host skeleton that visits \(M\) in \(j\) runs reads \(A_j\). Hence equality of \(P_M\) is sufficient for equality of Hamiltonian counts in all such hosts.

For the converse use the strong host \(M\to B\to A\to M\), with \(A,B\) transitive chains each of length \(k\). Write its count \(R_k\), with \(R_0=H(M)\). A path using \(j\) runs of \(M\) has \(j-1\) compulsory runs of each chain between its first and last module runs. The possible prefixes are empty, \(A\), and \(BA\); the possible suffixes are empty, \(B\), and \(BA\). For each of these nine choices, multiply the corresponding two ordered chain-cover counts \(\ell!{k\brace\ell}\) to get its contribution to \(c_{k,j}\) in \(R_k=\sum_j c_{k,j}A_j\). No term with \(j>k+1\) survives. At \(j=k+1\) only the entirely empty prefix and suffix fit, giving \((k!)^2\). Reading \(R_0,\ldots,R_{n-1}\) therefore recovers the full polynomial for a module of size at most \(n\).

**A shorter scan at known size.** For a known size \(n\), the [Rédei–Berge expansion](https://arxiv.org/abs/2307.05569) has \(P_M(z)=z^n D_M(z^{-2})\), with \(D_M(0)=1\) and \(\deg D_M\le d=\lfloor(n-1)/2\rfloor\). The first \(d\) run counts determine \(P_M(1),\ldots,P_M(d)\), hence interpolate \(D_M\) with its constant term fixed. Thus the short probe family \(R_0,\ldots,R_{d-1}\) already suffices; when \(d=0\) the polynomial is fixed. All modules of size five or six need just \(R_0,R_1\) to test this equivalence.

**One measurement instead of a scan.** For a known upper size \(n\), each \(A_j\) is at most \(M_n=n!2^{n-1}\), by ordering vertices then marking cut positions. Take \(k\) large enough that
\[
(1+1/n)^k\ge 2(n+1),\qquad (1+1/n)^{2k}>36n M_n.
\]
The \(BA\) prefix and \(BA\) suffix allow \(j+1\) runs of each chain. By bounding the number of maps missing a color, their chain count is at least \((j+1)^k-(j+1)j^k\ge (j+1)^k/2\), for \(j\le n\). Therefore \(c_{k,j}\ge(j+1)^{2k}/4\). Conversely each earlier coefficient is at most \(9j^{2k}\), from the nine boundary choices and at most \(j\) runs per chain. These bounds imply \(M_n\sum_{i<j}c_{k,i}<c_{k,j}\). Greedy integer division of this one exact height by \(c_{k,n},c_{k,n-1},\ldots,c_{k,1}\) decodes \((A_n,\ldots,A_1)\) with no carry from lower places. This uses \(k=O(n^2\log(n+1))\); it trades size for a single measurement. At sizes five and six the replay used respectively 35 and 51 vertices in each chain, reconstructing the digit vectors from 57- and 90-digit heights.

## 2. Positive marked cloning: exactly the labelled cyclic-triple hypergraph

Fix a labelled base tournament. A positive clone test replaces each vertex by a nonempty transitive chain, with common orientations between parts. The full function of positive chain lengths agrees for two labelled bases if and only if the same labelled triples are directed cycles.

For necessity one fixed test per triple is enough. Clone the three vertices of a marked triple to size \(k\), leaving \(m\) singleton outsiders. If cyclic, repeating the three class labels in cyclic order gives at least \((k!)^3\) paths on their union. Each extends to a full path by repeatedly inserting a new vertex in a legal gap or endpoint. Such a gap exists by scanning the current path, and the original path is recovered by restricting the resulting order to the cloned vertices, so extensions are injective. If the triple is transitive, its blowup has a unique internal order. Fix any ordering of the outsiders and assign each of the \(3k\) long-part vertices to a gap. Sorting inside gaps gives at most \(m!(m+1)^{3k}\) possibilities. These bounds separate for \(k=4(m+1)^2\): the product of the largest \(k/2\) factors in \(k!\) alone gives a ratio of at least \(2^{3k/2}>m!\). One can of course use the least \(k\) satisfying the factorial inequality instead.

For sufficiency apply [Boussaïri–Ille–Lopez–Thomassé, Theorem 2](https://perso.ens-lyon.fr/stephan.thomasse/liste/bilt.pdf): identical labelled cyclic triples are equivalent to a sequence of inversions inside intervals (sets seen uniformly by each outside vertex). For one such inversion reverse each maximal contiguous interval-run of each path. This is a bijection on path covers, preserving colors and path supports: the endpoint arcs at the run boundaries are preserved by uniformity. The identical operation on cyclic orders preserves directed cycle packs with their exact vertex supports (if a cycle lies entirely inside the interval, reverse the cycle). In a substitution by any common replacement tournaments, lift each inversion to its union of parts, then invert each included part once to restore its given interior. Thus equal triangle hypergraphs give equal counts, all color polynomials and all support-marked cycle pack profiles even under arbitrary common replacements. In a prime labelled base there is no proper nontrivial interval; consequently only equality and whole converse survive all positive clone tests.

**One fixed scalar experiment if a surrounding host is allowed.** First clone vertex \(i\) to size \(2^{2^i}\). A cyclic triangle in the inflated tournament uses three distinct parts, and the number of cyclic triangles is the sum of \(2^{2^i+2^j+2^\ell}\) over cyclic labelled triples of the base. The exponent positions are distinct. The triangle count itself is the coefficient of \(z^{N-2}\) in \(P(z)\), divided by 2, where \(N\) is the inflated size. Put this inflated tournament in the one-measurement decoder of Section 1 and read the triangle bits. This stronger experiment is very large and adds an exterior host; it is not a claim about one experiment using only positive cloning.

## 3. What the small tests actually see

In the [small-fiber census notation](../chan_pak_count_fiber_grammar_and_hidden_cycle_trades_20261126/README.md), the pairs \((5,0),(5,1)\) at 9 and \((6,0),(6,11)\) at 17 give identical triangle-host readouts \(9,93,1965,64389\) and \(17,241,6729,286297\) respectively. Doubling roots \(\{0,1,2\}\) instead yields \(95\) versus \(281\) at 9 and \(191\) versus \(859\) at 17. The triangle is transitive in the first of each pair and cyclic in the second.

In addition, the replay exhausts all labelled tournaments of sizes three through five. The **vector** of tests that double each triple in turn classifies exactly the cyclic-triple hypergraph throughout this census (2, 11 and 208 distinct labelled hypergraphs). Already at size four one entry of the vector cannot be decoded by a universal numeric threshold: transitive-mark counts reach 47 while cyclic-mark counts can be 45. This is why the uniform one-test-per-triple theorem uses larger chains. The tiny vector test is only certified up to size five.
