# Five binary runs are necessary and sufficient to separate the F5 factors

**PROVED, computer-assisted finite modular lemma plus explicit physical construction.** This strengthens the two-run result in `FERMAT_GRAMMAR.md`. It does not assert minimal graph order, minimal root-change count, or coverage of arbitrary odd targets.

Let p=641 and q=6700417. For a word in O,Z, a run is a maximal nonempty constant block. The number of runs refers to a supplied rooted source recipe, excluding the final closing J.

**Theorem.**

1. For every O/Z source word with at most four runs, its closed C1 Hamiltonian-path count H satisfies q|H => p|H.
2. Five runs suffice to violate the implication. One source word is

       O^31 Z^15 O^9 Z^5 O^9.

   Its closure is a 72-vertex tournament with

       H=1182825546590390812645
        =176530139331685 * 6700417
        =275 mod 641.

Thus the minimum O/Z run complexity of a q-only divisibility witness is **exactly five**. Root changes in the source word are unnecessary. The shorter root-changing construction in the companion proof still gives a useful 36-vertex witness.

## Proof of the all-length obstruction

All O/Z sources retain d=1. For k>=1 put t=2^k. Directly summing the recurrence gives the full block actions

    O^k(D,E,U,1)=(D,0,tU,1),
    Z^k(D,E,U,1)=
       (D-E+U+(t-2)(U-1), 1, t(U-1)+1, 1).       (1)

The second identity holds already at k=1 and propagates by the Z rule. Because 2 has order64 modulo p and q, each **positive-length** run can be replaced modulo pq by its representative length in1,...,64. Empty runs must not be substituted: O erases E and Z sets E=1 even when 2^k=1. Retaining positivity is essential.

Every nonempty O/Z word with r runs has exactly one of the two alternating run patterns, beginning O or beginning Z. For r<=4, `probe_runs.cpp` applies (1) to both patterns and to every positive phase length in1,...,64. It checks the scalar F=D-E+U modulo pq. Exact counts of enumerated cases are:

- r=1:128;
- r=2:8192;
- r=3:524288;
- r=4:33554432.

No case has q|F and p not dividing F. The empty word gives3 and is harmless. This finite complete calculation, together with the block-period proof, certifies the all-length statement. It does not depend on a maximum word length or on statistical sampling.

Multiplication uses signed128-bit intermediates: pq=4294967297, so a residue product can exceed signed64-bit. The explicit modular reduction and __int128 are important safeguards. The final program exits nonzero for any violating phase or incorrect enumeration count.

## Explicit five-run escape

After the first four runs O^31 Z^15 O^9 Z^5, direct recurrence gives

    D=2233926147849043429,
    E=1,
    U=2305843008676839393,
    d=1.

Appending O^9 and closing gives D+512U, the displayed H. A standard-library Python verification checks the exact integer value and residues, while `graph_witnesses.json` records every directed edge of its literal tournament. The source has69 letters, starts from the transitive edge, and is closed by one birth, hence72 vertices.

Replacing the final run length9 by9+64t gives infinitely many five-run witnesses, all with residue275 modulo641 and divisible by6700417. Their values are D+U*2^(9+64t), and their graph orders are72+64t. Consequently the threshold is not witnessed only by one accidental count.

The exploratory `probe_five.cpp` found this example by a discrete-log lookup in the subgroup generated by2. Its hit count and its shortest found length are **not theorem claims**: it skips degenerate coefficient-zero cases. The certified theorem requires only one exact positive witness, verified separately. No claim that69 is the shortest source length is made.

## Direct graph validation and scope

The literal model begins with edge0->1 and root0. For each birth, all existing vertices point to the newborn, except that Z or J reverses the edge between the newborn and the current root. J then makes the newborn the new root; Z retains the old root. Appending the closing J produces the inherited C1 tournament.

`graph_witnesses.py` writes the full adjacency rows for both escape examples. `check_literal_dp.cpp` independently counts Hamiltonian paths by subset dynamic programming in18 graphs through order18, including all small prefixes and the complete13-letter root-change prefix with zero, one and two O continuations and closure. This validates the concrete physical interpretation without using the profile recurrence in the counting engine. These literal checks give4909 for the15-vertex source,10063 after its closure,16935 after OJ and28961 after OOJ.

The72-vertex witness's full path count is certified by the inherited exact source recurrence. The36-vertex witness now also has an independent full graph count: `FULL_GRAPH_COUNT.md` and `check_full_36_dp.cpp` compress the transitive20-O block and use a weighted subset DP on the16 outside vertices. Its coefficients16935 and6013 give16935+(2^20−2)*6013=6305092397. No infeasible full2^36 or2^72 subset DP is claimed. Strong connectivity/unique-cycle status is inherited from the physical C1 closure theorem; each adjacency file is checked directly to be a complete loopless tournament.

The proof-method lesson is precise: retain the complete source block map before using a modular obstruction. Increasing the number of binary runs can repair an obstruction even without any root change. Root-change count, run count, graph order, and scalar multiplicity are distinct complexity coordinates. Concurrent research on bounded root-change chambers concerns a different coordinate and supplies no dependency here.
