This is a bounded research board, not a claim of one invariant across all subjects. Each connection records its actual carrier, operation, retained property and obstruction.

## 1. Continuation state

Object: states x with named operations and an output. Question: when do equal outputs stay equal after every permitted context? Inherited mechanism: THM-840's kernel criterion and THM-2176's properly sided continuation quotient. New applications: module context budget; Fano syndrome; involution node-pair memory; independent credit masks.

Hostile: current H=171 at seven different syndromes has seven different specified one-line repairs. Cheapest test: apply one distinguishing direction. Uniformly averaging the directions changes the consumer and permits a smaller state.

## 2. Return words and matching

## 5. Linear rank versus realizable state

Object: the fixed-path complement involution observed only at tournament nodes. Operation: tau, not a random node walk. Representation: cyclic linear observer span and its positive realizations. For fiber-uniform initial impulses the projected return matrices alternate I and K; K^t corresponds to a different process that re-randomizes within each fiber. Arbitrary nonuniform sources additionally require the initial forcing sidecar eta=y1−Ky0.

The positive-state count and signed-linear dimension differ already at n5. An all-pure-initial-state requirement is essential for the positive lower bound. A small signed factorization is not automatically a labelled tiling system, stochastic state model or source ledger.

## 6. Actual clocks and native capacity

Object: independent source-owned capacities at a fixed arrival cut. Operation: request arbitrary permitted demand vectors, then allow the declared handoff between clock cells. Exact state: capacities by nonempty eligibility masks, for all nonnegative real demands or for all integral demands with integral capacities. Empty-mask capacity is invisible; a restricted demand alphabet may need less state. Boolean inversion tests whether a proposed response even has this independent-bank realization.

Hostile: rank min(|S|,2) on three obligations is a valid shared-gate network response but has a negative independent-mask coefficient. Retain the bottleneck rather than pretending it is another independent donor. This is a realizability obstruction, not an improvement of the already exact unrestricted scalar153N remainder calculation.
