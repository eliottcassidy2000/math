## 1. Two genuinely different tournament-to-code maps

[THM-481](../../../../01-canon/theorems/THM-481-paley-gauge-generates-gleason.md) identifies the binary row code of the bordered Paley tournament gauge with the extended quadratic-residue code for primes q≡7 mod8, crediting Kim–Solé2008, Proposition3. At q=23 this is the genuine [24,12,8] extended Golay code. The source is an adjacency/Paley arithmetic construction, not an arbitrary24-element set.

[THM-480](../../../../01-canon/theorems/THM-480-skew-tower-row-code-is-dplus.md) gives a contrasting doubling ladder with low-weight words. The same ambient dimension or a half-dimensional code does not force the same minimum distance or gluing. The exact warning is relevant to the paired-port code: parity and rank alone are insufficient.

Our source object is instead the24 continuation profiles over12 marked bases in [Session290](../../session290_core_descent_20261113/descent/PROOF.md). At the terminal length these are8 distinct literal adjacency arrays,12 distinct adjacency-plus-selection arrays, and24 port-marked charts. Thus even the word “graph” must say what marking is retained. The new ports lane measures the actual integral map and the paired information; it does not substitute the Paley code for it.

## 2. A real Leech lattice appearance that loses Hamilton data

[THM-4752](../../../../01-canon/theorems/THM-4752-tournament-scores-in-ii-25-1-backward-length-and-the-a24-deep-hole.md) gives a precise25-vertex score construction: v=(scores|70) in II_(25,1), v²=−2c3, and transitive score vectors are null cusps with Leech quotients. Every tournament has an A24-cusp score class, not an automatic Leech-vector realization preserving H. Its scope records equal-score tournaments with distinct H=657 and643. This is a useful model for the connection contract: the map is genuine, the lost observable is equally genuine.

The paired-port problem reverses that emphasis. It asks which extra marking makes future count observations distinguish objects that initially coincide. A lattice construction should therefore retain the continuation observer, not only a Gram matrix or common dimension.

## 3. Cluster mutation versus a change of presentation

The existing rank-two/Plücker and squarefree-path work is recovered by the cluster lane. Ordinary quiver mutation is an operation on integer skew-symmetric matrices; a tournament is the much narrower locus with every off-diagonal entry ±1. An exchange identity in a larger ring does not by itself give a tournament operation. Conversely, marked network elimination can be exact while retaining an enlarged carrier and refusing the false projection back to tournaments.

This matches Session290's core descent: forgetting a port choice can merge two terminal values while splitting their next values. The example4697→22585 versus4697→30329 is a direct failure of scalar state sufficiency. A lawful descent carries the port and graph sidecars.

## 4. The attached paper's larger grading, not a theorem transfer

Yuri J.F.Sulyma, *RO(G)-graded norms for de Rham-Witt forms*, arXiv:2611.12043v1, is the supplied45-page PDF. Its opening motivation explicitly says the larger representation grading separates filtrations and twists mixed together on the integer-graded diagonal; it need not create new arithmetic invariants. The norms section has genuine nonlinear carry terms. The Witt lane records hypotheses/equations and proves only its separately stated elementary path-polynomial/orbit bridge.

The analogy is exact at the level of a methodological question: what information does an observer collapse, and does the proposed operation preserve that collapse? It is not an identification of tournament endpoints with equivariant homotopy groups, nor of a formal norm with a tournament Hamilton count.

## 5. What would make the proposed bridges constructive?

For every lane the missing step is a physical realization compatible with its algebra:

- A code coupling must arise from actual ports, not an arbitrary relabelling of imported Golay coordinates.
- A cluster exchange must land in a tournament or have a proved tournament realization of its enlarged state.
- An additive combination or primitive-necklace quotient must be realized without erasing the absolute count and endpoint constraints.
- A local/numerical inverse must retain all initialized and continuation data.

These are testable obligations. The shared dimensions12/24, the exchange syntax, and the presence of p-adic norms motivate the investigations but pay none of those obligations by themselves.
