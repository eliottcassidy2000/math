## 1. `8/pi^2` is the coprime density of pairs of odd integers

**S1 (CITED classical, Euler product; PROVED here in two lines).** For a set `S` of primes let `d_S` be the density of pairs coprime with respect to all `p in S`. Independence of the residues modulo distinct primes (Chinese remainder theorem on `Z/(prod p)`) gives `d_S = prod_{p in S} (1 - 1/p^2)`, since a pair is divisible by `p` with density `1/p^2`. Over all primes this is `1/zeta(2) = 6/pi^2` (Dirichlet/Cesaro; CITED Hardy-Wright, ch. XVIII, section 18.5 "the average order of phi(n)"; the theorem NUMBER `332` printed in the `.out` is UNCITED-RECOLLECTION, the book was not opened). Among pairs of ODD integers the prime `2` never divides either coordinate, so the factor `(1 - 1/4)` is removed: `prod_{p odd}(1 - 1/p^2) = (6/pi^2)/(3/4) = 8/pi^2 = 0.8105694691`. Numerically the finite product over odd primes `p <= 2e6` is `0.810569495361107`, at distance `2.6222e-8` from `8/pi^2`, consistent with the tail bound `O(1/(2e6 log 2e6)) ~ 3e-8`. QED.

**S2 (FINITE-EXACT).** With `N = 10000` odd integers `1..19999` there are `100000000` ordered pairs. Moebius inversion (odd `d` only: `#{coprime} = sum_{d odd} mu(d) c(d)^2`, `c(d)` the number of odd multiples of `d` up to `19999`) gives `81058757`; an independent chunked `numpy.gcd` census over all `10^8` pairs gives `81058757` (the script raises if they differ). Density `81058757 / 100000000 = 0.81058757`, versus `8/pi^2 = 0.8105694691387022`; difference `1.8100861297831727e-05`, well inside the `O(log N / N) ~ 0.000921` error of the classical estimate. Contrast at the same size over ALL integers `1..N`: `60794971` coprime pairs, density `0.60794971` versus `6/pi^2 = 0.6079271018540267`.

## 3. The coding claim, refuted by counting

**S4 (PROVED, pigeonhole; FINITE-EXACT table).** There are `2^L` binary streams of length `L` and only `2^L - 1` binary strings of length `< L`. Any lossless (injective) code of all `L`-bit streams therefore assigns length `>= L` to at least one stream; for prefix-free codes on the uniform source, Kraft's inequality plus Shannon's source-coding theorem (CITED Shannon 1948) give mean length `>= L`. The table in the `.out` lists `L = 1, 2, 3, 4, 8, 16, 32, 64` with deficit `1` in every row (`2^64 = 18446744073709551616` streams versus `18446744073709551615` shorter strings). Minimal witness: `L = 1`.

**S5 (PROVED; FINITE-EXACT).** The "out-of-order suffix lookahead" reads the last `m` bits first and then the rest; as a map on streams this is the permutation `s -> s[L-m:] + s[:L-m]`, a bijection of `{0,1}^L`. Exhaustively for `L = 12`, `m = 4`: `4096` streams, `4096` distinct images. A bijection composed with an injective code is injective, so S4 applies unchanged: reading the file backwards cannot lower the pigeonhole bound. **PROVED (added by the audit, elementary):** for ANY source distribution on `{0,1}^L`, not only the uniform one, `H(sigma(X)) = H(X)` for every bijection `sigma` (entropy depends only on the multiset of probabilities), and the chain rule `H(X) = H(suffix) + H(prefix | suffix)` shows that "conditioning on the suffix" redistributes the entropy between the two parts without lowering the total; the audit `.out` (section A3) checks both identities numerically on a non-uniform source with `L = 12`, `m = 4`. So the paste's "collapses the entropy" is false for every source, not just the uniform one.

**S6 (PROVED; cites the scaffolding audit Theorem 5.1).** A tournament on `n` labelled vertices has `C(n,2)` arcs; fixing a Hamiltonian spine forces `n - 1` of them, leaving `T(n-2) = C(n,2) - (n-1) = C(n-1,2)` free arcs (identity checked for `3 <= n <= 12`).
