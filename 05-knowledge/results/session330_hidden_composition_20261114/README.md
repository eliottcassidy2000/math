# Session 330: hidden composition has a detection depth

The structural question behind \(4+7=5+6\) is not whether the totals match. It is **which experiments can still tell the two decompositions apart**. The following answers use actual tournaments, square-sum cycles and an older packing/Jacobian lens.

* **Same size, same two counts, different composition.** The ordinal splits 4+7 and 5+6 share \((H,Q(2))=(615,49920)\) and differ first at slot 3. The full difference is \(2z^3(z^2-1)(z^2-4)(z^2-2)\). One common triangle wrap hides the difference in the path count but moves it down a slot; two common wraps expose it in the path count. More generally the first differing slot moves down exactly one place at every common wrap, so repeated scalar measurements recover the full polynomial, not the tournament class. For the *crossed* cyclic splits there is no unpadded scalar overlap; one pad allows scalar matches that still fail the boundary tests. See [Hidden composition](HIDDEN_COMPOSITION.md).
* **Three measurements, one legal branch.** The two-reservoir seam has a bilinear response to independent padding. Three probes determine the complete response through a rank-one quadratic; a tournament inequality and parity rule exclude the second algebraic branch. This uses the same proof strategy as [the affine-Jacobian no-escape calculation](../../../01-canon/theorems/THM-3225-affine-jacobian-clutch-resultant-and-two-boundary-no-escape.md), not an implication for the planar Jacobian conjecture. The older [common-access audit](../planar_jc48_sep08_two_cusp_braid_audit.md) happens to contain 5723 as a row index; that occurrence has no established connection to tournament counts.
* **5,723 and 3,225 distinguish move languages.** Both are made by a 5-path Fermat block on eight-vertex strong sources, and both have two representations as \(a^2+2b^2\), the norm underlying the two-reservoir determinant. But 3225 is an old twin-doubling output, while 5723 is impossible for any uniform even transitive inflation. The new general proof is a modulus that grows with module divisibility. See [Arithmetic meets composition](ARITHMETIC_MEETS_COMPOSITION.md).
* **Golden eleven, versus a count that simply happens to be 11.** The old [golden-eleven note](../strong_balance_pisano_golden_eleven_20261014.md) identifies \(11=L_5=\operatorname{tr}(G^5)\) and \(55=F_{10}=\binom{11}{2}\) for the Fibonacci matrix \(G\). The traces at powers \(0,2,5\) are \(2,3,11\). Here the deepest positive inverse Fibonacci step at order seven exactly picks out a determinant-optimal two-probe pair in normalized lattice coordinates. A different equally sharp pair preserves the 99-unit channel, illustrating why one must keep the target guard. This is exact in the [golden probes](GOLDEN_PROBES.md); it is not a claim that raw \((H,Q)\) follow the Fibonacci recurrence.
* **Eleven-square packing shows the same need to keep the mark.** The [old marked lift](../eleven_squares_routing_bridges_20261007.md) distinguishes configurations whose reduced torus agrees. [Stromquist's original restricted-packing theorem](https://www.combinatorics.org/ojs/index.php/eljc/article/view/v10i1r8/0) gives an optimum of \(2+2\sqrt{8/9}\) for the \(0^\circ/45^\circ\) palette, beaten by the tilted Trump construction; fixing the angle palette discards real solutions. Conversely the repository's [packing octic calculation](../square11_octic_langlands_collatz_20261006.md) has degree-eight field with Galois closure \(S_8\): its stabilizer \(S_7\) is maximal, so no proper intermediate field, in particular no literal \(\mathbb Q(\sqrt5)\) subfield. The useful golden analogy is the *marked coordinate and exact inverse*, not the claim that the optimum side is a golden ratio expression.
* **Square sums: the entire height layer, not one coincidence.** Every four-cycle is an exact alternating identity of square sums plus a positive distinct lift. The four births at 99 all come from a common difference \(96=2^5\cdot3\), whose root pairs \((2,10),(5,11),(10,14)\) literally generate the four cycles. The first repeated-label cycle already gives a parity-preserving spanning exchange. At 30,013 the scaled \((1,5,7)\) and \((31,41,49)\) families activate together, share a top edge, and induce a theta: two possible repairs, but not independent ones. See [Square-cycle activation](SQUARE_CYCLE_ACTIVATION.md).

**Chan–Pak implication.** The measured tuple must be chosen for the exact operation to be repeated, and a candidate branch must remain physically executable at the next step. This packet supplies observers, sharp inverse probes, and an all-order obstruction to a natural inflation language. It does not supply a target-decreasing return for every odd count.
