## Reproduction

Requires nauty 2.9.3 (`gentourng`, `libnauty`, headers under `/opt/homebrew`), a C compiler,
Python 3 (standard library only). `scripts/run.sh` regenerates everything in about five minutes on
eight cores; the receipts were produced from the same data:

```
cc -O2 -I/opt/homebrew/include/nauty scripts/tourn_enum.c -L/opt/homebrew/lib -lnauty -o tourn_enum
gentourng 9 | ./tourn_enum 9 --fas --hpaths --c3canon --table t9.tsv --primes p9.txt   # 20 s; n = 10 in 8 parts with --noreg --compact
gentourng 7 | ./c3class 7            # brute-force C3-fibres, compared with prod(k!)*2^p in receipts/c3class-check.txt
DATA=. python3 scripts/species.py 9 p9.txt ; DATA=. python3 scripts/species10.py ; DATA=. python3 scripts/analyze.py ; python3 scripts/conn_check.py
DATA=. python3 scripts/chain_family.py   # the 2^(n-4) chain family = all strong classes with n-2 cyclic triples; primes iff gaps <= 2 (HYP-9413)
DATA=. python3 scripts/balanced_check.py # (C3, scores) exceptions = size-balanced prime nodes, n <= 7
```

Receipts `receipts/*-normal.txt` and `*-optimized.txt` (`python3 -O`) are byte-identical.
`data/` holds the full class tables for `n = 7, 8` (columns: canonical key, `|Aut|`, self-converse,
scores, `c3`, Slater index, `H`, strong components, tree signature, `log₂ N`, `C3` canonical hash),
the prime registries for `n = 7, 8` (arc lists, automorphism and anti-automorphism cycle types),
the 23-type cycle-index table through `n = 9`, the brute-force fibre sizes for `n <= 7`, and the
census summaries for `n = 8, 9, 10`. The `n = 9` table (23 MB) and `n = 10` tables (300 MB) are
regenerated by `run.sh`.
