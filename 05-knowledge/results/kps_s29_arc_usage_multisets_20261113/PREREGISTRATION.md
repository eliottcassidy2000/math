## Already computed (exploratory, reported not predicted)

- For every tournament class of orders 3-9, the multiset of arc weights was computed. An arc's weight is the number
  of Hamiltonian paths using it, and zeros (arcs left behind) are counted.
- Distinct multisets equal the merged classes at orders <= 6. There are 1, 2, 22 collision groups at orders 7, 8, 9.
- All of them are generated by three moves:
  - (i) redistributing singletons among nonempty runs;
  - (ii) flipping a strong core whose two neighbouring runs are nonempty;
  - (iii) global converse.
- Every multiset class has a single slot polynomial Q.

(377, 987, 2584 classes; generated by kps_s26 c1ext).
