# Root-surface ladder

`root_surface_ladder.svg` is an original vector summary of the audited complex-geometric hierarchy. It uses the nested linear forms E,E+x,E−x,E+z,E−z, followed by E+x+z, E−x−z, E+x−z, E−x+z. Triple counts along this particular chain are2,2,3,5,8; node counts are4,8,24,80,256. This finite list is not a claim of a continuing Fibonacci law. Other coordinate subsets can have different node counts.

Canonical invariants refer to minimal resolutions, while nodes refer to singular projective models. Degree-two forgetful arrows refer to the projective models, not asserted morphisms between their minimal resolutions. The torification obstruction is over C and is not an integer-point obstruction.

The SVG was XML-parsed, rendered with Inkscape, and visually inspected at1300×500. Text and arrows are legible without overlap. The review PNG is not a mathematical source dependency. Proof: `../toric-shared-roots/TORIFICATION_OBSTRUCTION.md` and its independent audit.
