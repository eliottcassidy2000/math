# What the new mechanisms change about spectrum completeness

The target remains: every positive odd number except7 and21 is H(T) for
some finite tournament. The exclusions, non3 reduction, and prime/7p reduction
are inherited. This session does not claim the universal realization theorem.

## 1. Small additive induction has a global obstruction

The induced-gap theorem is independent of any chosen construction grammar.
If A is induced in T and H(T)-H(A)=Delta>0, both counts and the inclusion can
be retained on at mostDelta+2 vertices. This is an exact decision kernel for
fixed gaps, not a sharp order bound at every gap. It forces
2H(A)<=(Delta+1)!, so a fixed additive step cannot continue indefinitely as
H grows. Exact gains2 and4 are fully classified. Neutral padding does not
repair this limitation.

This still permits a branching construction tree: witnesses of consecutive
counts can live on incomparable branches. It also permits rebuilding a
witness, replacing old vertices or arcs, and larger jumps. Every fixed nested
ray, and every finite union of them, has a zero-density image. The explicit
adjacent families2^k+1 and2^k+3 make the incomparability statement nonvacuous.

## 2. Change the distinguished vertex lawfully

The migration compiler enlarges what can be done while tracking only four
specific path-count coordinates. Attach a fresh block dominated by the old
parent, retain its actual edges to the old distinguished vertex, then re-mark
a fresh vertex. The compiler counts the needed path and cover configurations;
it is not a scalar rule or permission to treat arbitrary vectors as graphs.

For an authenticated nonnegative matrix bank, coordinatewise saturation at
M+1 is an exact finite quotient for output targets<=M. Reachability starts
at an actual seed and retains recipe witnesses. The arbitrary-strip alphabet
also stabilizes after a proved length bound, so its exclusions67 and173 are
all-depth and all-strip-length statements in that language. Mixed fresh
transitive blocks repair those two values by actual graphs. The fixed mixed
bank is an alternative grammar, not a proved superset of every strip map.

The new question is uniform acceptance, not whether each fixed bounded
reachability computation terminates. The capped finite automata depend on M;
a finite prefix does not establish all M. The wrong preliminary strip
coefficient is explicitly rejected and corrected in the constructor proof.

## 3. Future-response coordinates can decide actual states

The17-coordinate two-apex response space is inherited. What is added is a
finite measurement map: twelve suffix counts, with suffix length<=3, recover
both binary neighborhood codes. Decode-and-replay distinguishes actual states
from formal solutions of linear equations. It establishes actual-state
membership, not a positive answer to every scalar H query.

Singleton-SCC chain deletion is a DIFFERENT reduction. Retaining every marked
apex, it preserves H and the run budget, and proves the spine bound
5^m<=H^3 for any fixed number of apices. It does not preserve all continuation
responses. The word3333 has H1 but a different next0 response from the empty
word. Keeping these two interfaces separate is essential.

## 4. A universal construction needs growing resources

The capped-SCC budget J_b supplies an exact finite counting gate for bounded
feedback-arc constructions. Most odd targets, if realized, require at least
(1-o(1))log H/loglog H backward arcs. Six-arc families can be infinite and
still cannot cover an entire large dyadic interval. The fixed-budget
qualitative obstruction was already known; the growing budget and exact gate
are the refinement.

For fixed-apex words, sublogarithmically many letter changes represent only
H^o(1) targets. The spine-specific bound strengthens the explicit two-apex
threshold to log H/5 changes on a density-one target population. This does
not exclude two apices: an unrestricted word can itself have logarithmically
many changes. It argues against further concentrating on a fixed handful of
runs or repeating patterns.

## 5. A concrete nonbinary survivor, and the finite spectral boundary

A three-operation authenticated macro preserves L=g=0 and the invariant
I=8C-9t. Its exact response is F->80F+3I. From the specified actual seed,
I=-9 and repeated application gives

    F_k=(52*80^k+27)/79, k>=0,

with an explicit graph recipe adding seven vertices each time. This is not
an operation80H-27 on every tournament: its state invariant is load-bearing.
The profile requires F=1 mod26; even that congruence does not establish that
all such profiles are actual.

The finite search through four operations proves that two distinct nonzero
digits cannot share one output-normalized affine ray at any integer radix
within that bank and word-length bound. It allows signed intercepts and
checks every integer eigenvalue. It does not exclude longer macros,
zero-digit exceptions, multiple phases, or higher-dimensional invariant
regions. The positive radix80 family shows that migration can retain
nontrivial integer spectral growth; dismissing every migrating eigenvalue1
case would be false.

## Remaining proof obligation

A credible next construction must give an actual seed and a uniform,
source-preserving inverse or acceptance proof, with all needed state and
arithmetic guards. The four-state mixed bank and the directly decodable
two-apex language are concrete candidates. Neither is shown to accept every
eligible odd target here. All finite coverage figures and inherited
100-million-prefix work remain separate from that open assertion.
