# Reproducing the E14 certificate chain

All Python programs use only the standard library. C++ requires C++17.
The large potential is a reproducible build artifact, not a committed file.
The original producer took about20 CPU minutes and2.4GiB resident memory.
Its8-byte little-endian output occupies1962500000 bytes; use a disk-backed
scratch path rather than a memory-backed temporary directory when needed.

From this directory:

```sh
c++ -O3 -std=c++17 integer_probe_intrusive.cpp -o /tmp/integer-price
/tmp/integer-price 10 /path/to/disk/integer10.bin 2
sha256sum /path/to/disk/integer10.bin
```

Expected hash:
`9afc878aaaf0ff11b075678493f6ef935c1735afe4f81bdcd9a2e1282c652c31`.
The producer prints `tail=0`: its coarse40-letter entry bound is insufficient.
This is explicitly not the all-letter proof. The separate checker tests
all64 short letters and entries and then the65+ tails. Use the independent
checker and commands in the companion `../audit_collatz/` packet. A potential
file or hash without that successful replay does not certify the theorem.

Next reconstruct the entire near-tight graph and compare its exact receipt:

```sh
c++ -O3 -std=c++17 near_tight_corridor.cpp -o /tmp/near-tight
/tmp/near-tight 10 /path/to/disk/integer10.bin 2 2 10 > regenerated.json
cmp regenerated.json near_tight10_cpp.json
```

The final argument10 requests the necessary identity multiplier test modulo
5^10. This is stronger than just testing the E14 target modulo5^14. The
independent graph implementation and replay appear in the companion audit.
Its different traversal is compared by mathematical records rather than
by JSON byte formatting.

Small reproducible controls, including a separate FIFO scheduler and a
Python graph implementation, do not require the large potential:

```sh
python3 -B check_small_models.py
python3 -B -O check_small_models.py
python3 -B check_e14_closure.py
python3 -B -O check_e14_closure.py
```

The small-model controls regenerate E5,E6,E7 potentials under both scheduler
orders, compare exact bytes, and compare every near-tight clock/length pair
between Python and C++. The E14 arithmetic controls test the exact digit-sum
entry bank, all twelve terminal pairs, interpolation, native return fees,
tangent boundary invoices, unfinished-suffix margin and sharpness.

The inherited E10,R1 rational certificate is not regenerated by these
commands. Its pinned source and status are stated in `E14_CLOSURE.md`.
No all-layer estimate, convergence proof or Lean formalization is claimed.
