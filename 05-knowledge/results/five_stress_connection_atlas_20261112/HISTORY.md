## 1. Scope of the historical search

The saved `history_refs.txt` defines a frozen local Git universe, rather than
the continually changing main branch. The text-object manifest includes
78,446 distinct reachable objects discovered under `.md`, `.txt` or `.rst`
paths, totaling 56,587,125,074 bytes. Each object has one Git discovery path;
this is not an exhaustive rename history. Whole-blob lexical tag presence is
searched. Only the first eight matching lines are excerpted, with short
contextual prompt leads. Binary papers, inaccessible chats and history beyond
any shallow boundary are outside this universe.

The completed pass found36,903 matching blobs across8,486 discovery paths,
with5,962 exact baseline-at-path matches. It covered28,358 reachable commits;
415 commit subjects matched the query vocabulary. There were **zero matches**
for the narrow Neményi/isothermal/stress-trajectory query in this frozen
universe. The broad lateral word “stress” often means a stress test, so its
co-occurrence count must not be interpreted as elasticity evidence. Later
concurrent Sessions285–287 are handled separately in [INCOMING](INCOMING.md).

The authoritative final counts and limits are `history_stats.json`; the
compressed hit catalog retains exact blob IDs. `history_prompt_candidates.json.gz`
deduplicates excerpt text while retaining every recorded provenance. Neither
matching blobs nor contextual excerpts are counts of distinct human sessions.
The all-version bounded excerpt catalog contains2,884 normalized contextual
leads from1,343 discovery paths;83 include an explicit request marker. These
are separate from the largest-revision full-file attribution pass below.
Later prompts can be absent from the bounded excerpt index. Selective reading
and the following manually checked source attributions are a separate layer.

The vocabulary deliberately includes ordinary “five”, selected `5-object`
phrases, pentagons/quintics/Platonic geometry and the stress-net terms. It is
not every use of the digit 5, every five-element set written without that word,
or every mathematical idea related to five. Thirteen lateral vocabularies
index nearby topics; co-occurrence is a retrieval edge, never a theorem.

A second, full-file attribution pass chooses the largest available revision
of each of39,399 discovery paths (1,073,964,516 bytes). It searches every line
of each chosen source for explicit request-attribution markers, retaining
bounded context. It finds1,326 marker occurrences in446 five-bearing source

the retained context itself. The other945 are separately flagged. See the
[193-entry readable index](PROMPT-INDEX.md), the complete compressed catalog,
and `history_prompt_harvest_summary.json`. A largest revision may be an older,
uncorrected version. This pass improves prompt retrieval without pretending
to authenticate chats or to read every version in full.

## 4. A common organizing construction, with explicit limits

For a finite linear continuation model `(V, {A_s}, v, ell)`, retain the
reachable space R and quotient by

    N={x in R : ell A_w x=0 for every future word w}.

N is invariant under every allowed next operation, so R/N preserves every
future scalar response. This is the elementary linear form of the standard
minimal-realization/Hankel principle, not a new universal theorem. One
observation at one size gives only ker(ell), which need not be invariant.

The useful addition to a research ledger is to keep the **physical subset**,
integer lattice, endpoint markings, baseline and size/height beside R/N.
Linear combinations in a quotient need not be realizable graphs or stresses
with the required positivity or periods. This explains, in concrete settings,
why five-state descriptions can be powerful without settling coverage.

For the strip paper, reflection removes two persistent modes from its
particular scalar observer. For stress, four concyclic amplitude samples
lose a mode; full stress measurements can recover it. The square full-stress
failure is a separate placement obstruction, while a multiply connected
domain imposes periods. For tournament seeds,
the defect equation and the weighted continuation slope are different
observers; dropping either loses the next construction.

**Research proposal, OPEN:** organize birth families by the smallest
continuation-complete interface that also retains a constructive physical
inverse and an absolute height bound. The exact interval families and stable
clone births in [SEEDS](SEEDS.md) are test cases. No fixed finite interface for
all tournaments, or classification of every aspect of mathematics, is proved.
