# Session 65 concept board

Anchor: native guarded machine semantics. Niche: signed pair-orbit defects.
Wildcard: supersingular Frobenius and ternary exponent fibres.

| Source and map | Preserved predicate | Lost information / sidecar | Decisive hostile |
|---|---|---|---|
| Native tape -> exact section macro | Full configuration and native clock | Retain every guard and boundary cell | Same counts, different next macros |
| Binary word -> ordered TT3/C3 join | Isomorphism edit distance and exact word decoding | Origin, head, program and control remain marked | Adjacent zero blocks merge |
| Word tournament -> (H,c3) | Number of one bits | Word order and exact macro continuation | 01 versus 10 |
| Vertex permutation -> signed pair orbits | Full defect polynomial over all orientations | Actual arithmetic carrier is a separate input | Two transpositions have positive sign but minimum two |
| Supersingular points -> Frobenius involution | Fixed points/conjugate pairs and defect minimum | No canonical comparison relation supplied | p=37 has one conjugate pair |
| Exponent -> ternary residue tower | Finite lifting and signed orientation | Exponent parity and ordinary-integer realization | Coherent all-ones branch (0,-1) |

Closest inherited mechanisms are the order-join metric product (THM-2183),
transitive-quotient boundary (THM-2195), signed parity projection, and the
3-adic first-nonzero-digit tournament (THM-4754). Each theorem is retained
with its exact slug and source context in the source pins. The corrected near
miss is Coq subsumption: it preserves membership by one-way inclusion, not
equality of matching languages. Least-used sidecars are the physical origin,
endpoint-return sign, and exponent-parity coordinate.

A faithful representation does not certify an efficient closed native-word
grammar. Ambient inverse-limit survival does not imply an ordinary integer
survivor. Shared small numbers do not by themselves define a bridge.
