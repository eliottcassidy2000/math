### 1. MAJOR - (A): "`L` is exactly the lattice generated by the differences of `Y_n` for every `n >= 5`" is unproved as written

Sentence at fault (theorem, (A)): "`L` is exactly the lattice generated by the differences of `Y_n` for every
`n >= 5` (index `2^16` in `{d : d_1 = d_2}`)", inside the item typed PROVED, with the proof "`L` is the Z-span of
the differences of `Y_7`; `A_m L subset L` and `A_m y_ref - y_ref in L` for all four letters (finite exact check);
induction from level 7." That induction proves only `Y_n subset y_ref + L`, i.e. `L_n subset L` (`L_n` = the
difference lattice of level `n`). The reverse inclusion `L subset L_n` for *every* `n >= 5` is a universal
statement that the text supports only by the printed levels `5..12` (reach2) / `7..13` (collective). No letter is
unimodular (det `A_m = 0`, ranks 3, 4, 10, 12 on `Z^14`), so there is no trivial argument.

Repair (verified): for `n >= 2` all four letters act at vertex `n+1`, so for any fixed `y in Y_n`
`L_{n+1} = sum_m A_m L_n + sum_{m < m'} Z (A_m - A_{m'}) y`
(`A_m y_1 - A_{m'} y_2 = A_m (y_1 - y) + (A_m - A_{m'}) y - A_{m'} (y_2 - y)`, and conversely each generator is a
difference of two states of level `n+1`). If `L_n = L` and `y in y_ref + L`, then
`(A_m - A_{m'}) y in (A_m - A_{m'}) y_ref + A_m L + A_{m'} L`, so `L_{n+1} = L' := sum_m A_m L + sum Z (A_m - A_{m'}) y_ref`,
a fixed lattice. Own exact check: the HNF of the 52 + 6 generators of `L'` is the stated basis (`L' = L`: True);
it is also forced by the computed `L_5 = L_6 = L`. With `L_5 = L` (computed) the induction gives `L_n = L` for all
`n >= 5`. The claim is therefore true and PROVED once this step is added; as written it is a gap.

### 2. MAJOR - (B): the structural reading is false, including for the theorem's own examples

Sentence at fault (theorem, (B)): "The block's first vertex is a singleton strong component and its second
continues a chain of Moon's 2-blocks (THM-4744, factor `2^(2-1) + 1 = 3` per block)"; note, section 4: "the
first vertex of the block (`q+1 -> q`) is beaten by everything before `q` and beats everything after, so it is a
singleton strong component".

The inference is invalid: if the last letter of `u` is nonempty, `q -> q-1` (or `q -> q-2`) is an arc, and
`(q-1) -> (q+1) -> q -> (q-1)` is a 3-cycle, so `q+1` is not a singleton. Own condensations (Kosaraju, 1-based):
* `u = 1-.-2.12` (the theorem's second example): `u.B^k` is **strong** for `k = 1, 2, 3, 4` (`H = 11, 33, 95, 285`).
* `u = --.1-`: `u.B^k` strong for `k = 1..4` (`H = 5, 15, 45, 135`).
* `B^3`: components `[1] < [3] < [2, 4, 5, 6]`; `B^4`: `[1] < [3] < [2, 4, 5, 6, 7, 8]` - vertex 5, the first vertex
  of the third block, lies inside the chain component; only vertices 1 and 3 are singletons.

Correct statement (proved by the argument above): if `u` ends with the empty letter (`q` a sink of `u`), no arc
leaves `{q, q+1, ..., q+2k}` backwards, `q+1` is a singleton strong component, and for `u = --.--` the remaining
block vertices form the strong component `{q, q+2, ..., q+2k}` with `H = 5 * 3^(k-2)` (`k >= 2`): `5, 15, 45, 135`
`= f(4), f(6), f(8), f(10)`, Busch's minima, hence the optimal chain `IC(3, 2, ..., 2)` by THM-4744 (4) - a 3-block
followed by 2-blocks, not a chain of 2-blocks only. If the last letter of `u` is nonempty, the block vertices merge
into the component of `q`. The tripling itself is algebraic and unaffected (finding 6).

letter-invariance (A), the characteristic polynomial and the eventual exact tripling (B), the response-set data (C),
