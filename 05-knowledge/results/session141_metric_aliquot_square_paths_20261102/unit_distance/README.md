# Session141 unit-distance bridge

**Main result:** the first unit-distance configuration that cannot be partitioned
into three functional successor layers occurs exactly when u(n)>3n. The dated
AMP2025 bounds put this threshold in 25…28. One-layer deletion loss is exactly
m−n+t and is unchanged by subdivision.

Dense witnesses at n = 15,20,24,25,26 require at least 22,34,44,47,50 extra edges
beyond any one functional graph, and cannot be topologically routed into a
degree-three honeycomb because their branch degrees are too large. In contrast,
faithful plane unit-distance Cartesian products can have unbounded edge density
while remaining three-colorable. This precisely separates density, dynamics,
and the Hadwiger–Nelson coloring question.
