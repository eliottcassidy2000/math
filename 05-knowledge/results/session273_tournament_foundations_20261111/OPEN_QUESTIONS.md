## 1. Renewable endpoint resource after a gauge move

Input: the equal-order, equal-full-profile gauge packets in interfaces/PROOF.md.
Output sought: a finite menu of actual rooted operations, preserving an explicit
supply invariant, which realizes target-bearing inverse steps for every
sufficiently large odd h. The state must include exact H and rooted one-/two-path
coordinates (e,s,L,R), not only a projective ratio or a residue.

First experiment: classify how the terminal3→5 exposure changes these four

not a finite stock of triangle factors. Failure should identify the monotone

## 2. Arithmetic target maps versus invariant transports

Gauge loops cannot create missing values because they conserve the output.
Can a nonclosed operation take a physical source to a desired affine output
while the boundary potential is itself supplied by the source family? Prove
realizability and retain absolute scale. A formal rational edge weight is not a
tournament, and solving a prime-valuation equation is not realizing its state.

## 3. Compress the terminal symmetry response

The exact h_n^(N) conditioned Burnside formula proves existence of a class-uniform
birth kernel but can be expensive. Search prefix families for a small sufficient
state describing signed pair-orbits across the unseen boundary. A claimed
compression must pass the n4→n3 hostile and compare entire completion functions,
not current automorphism orders. This is a prediction/sampling question, not a
new exact A000568 value request.

## 4. When can a microscopic limit retain an arithmetic target?

The transitive-limit entropy theorem kills unqualified continuum inference.
Specify a compact marked-component/interface carrier and an integrability or
height-tightness condition that makes the exact target predicate closed. Then
show the actual tournament construction satisfies the condition. An abstract
compactification alone cannot make escaping witness sizes bounded.

## 5. Minimize a clock's predictive state without losing phase arrival

The rational interval Markov model is exact for each fixed speed row. Determine
its minimal predictive quotient or a certified lumping criterion for tournament
labels, rooted labels, or H. The (0,1,3,7) hostile rules out strong lumping by
instantaneous class in general. Do not infer non-Markovianity of every stationary
observed process solely from strong-lumping failure.

For LRC, a uniform depth bound for strict/equality witnesses remains necessary;
the number of interval states can grow with the speeds. No fixed-size row
controller has been constructed here.

patterns and arbitrary planar graphs need separate maps and positivity data.
