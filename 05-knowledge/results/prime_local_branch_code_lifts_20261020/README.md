# Prime-local branch, code, and lift bridges

Read [the proof report](PRIME_LOCAL_BRANCHES_CODES_AND_LIFTS.md).

1. PROVED: regular/complementary branch integrality for linear and affine gain-switching quotients over F_(p^s) and Z/p^s, with the sharp exception p=2,n=2. The two carriers have the same regular branch, not necessarily the same full orbit count.
2. CITED classical theory plus explicit elementary derivation: Pascal-row codes are repeated-root cyclic ideals, with their exact dual and minimum-distance staircase. No classical coding-theory priority is claimed.
3. PROVED scoped arithmetic: exact Jordan matrix order over Z/p^s, first carry-sensitive lift census at F=p+1 modulo p^2, and precise CRT composition. In this unipotent CRT family the local periods have disjoint prime supports, so total cycle counts multiply.
