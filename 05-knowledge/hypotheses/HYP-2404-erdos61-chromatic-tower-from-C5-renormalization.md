# HYP-2404: Erdos 61 -- the chromatic-4 targets are a Mycielski tower from C_5; a renormalization program

## The problem (OPEN)

If `G1, G2` both have chromatic number `aleph_1`, must there be a graph `G` with `chi(G)=4` (or even
`aleph_0`) that is a COMMON subgraph of both? Erdos: probably every `aleph_1`-chromatic graph contains
EVERY chromatic-4 graph of large girth -- which would give 61 (both contain all such, so they share one).

## The reduction

```
   UNAVOIDABILITY (every aleph_1-chromatic graph contains every chromatic-4 large-girth graph)  =>  61.
```
So 61 follows from forcing a fixed family of chromatic-4 (large-girth) graphs inside any `aleph_1`-chromatic
graph. Context: `aleph_1`-chromatic graphs ARE cycle-rich -- Erdos-Hajnal: they contain `C_4` (so the host
has girth `<= 4`), all finite bipartite graphs, and (Erdos-Hajnal-Shelah) all long odd cycles `C_{2k+1}`.
The OPEN part is the LARGE-GIRTH chromatic-4 target (sparse-but-chromatic), as subgraphs.

## The finite seed (VERIFIED): the targets are a Mycielski tower from C_5

The chromatic-4 (triangle-free) target is generated by the MYCIELSKI operation `M` from `C_5`:
```
   C_5 (chi=3, girth 5)  -M->  Grotzsch (chi=4, girth 4, |V|=11)  -M->  M^2(C_5) (chi=5, |V|=23) -> ...
```
`chi(M(G))=chi(G)+1` (an additive ladder), triangle-free preserved (girth `>=4`). VERIFIED:
`chi=3,4,5`, `alpha=2,5,11`, `#ind-sets=11,103,7407`. **C_5 = the Paley P_5 SEED of S725** (THM-130);
**Grotzsch = the canonical chromatic-4 finite seed of 61's target**. The Mycielski tower is a graph
TRANSFER -- the S720/721 ladder with `chi` as the additive coordinate.

## The renormalization program (creative, leveraging S725)

`aleph_1` (uncountable) is the "limit / cold fixed point"; the chromatic-4-large-girth targets are the
finite "hot" obstructions. The S725 renormalization principle (the limit restores what finite levels can
avoid -- limit ordinals restore partition relations, Chang) suggests:

> **PROGRAM:** prove the unavoidability of the chromatic-tower targets inside any `aleph_1`-chromatic
> graph by a tower/elementary-submodel argument -- the uncountable chromatic number is a fixed point that
> cannot avoid the whole finite obstruction tower, even though each finite level is individually avoidable.

Two sub-targets, by girth:
- **girth-4 (Mycielski) version:** does every `aleph_1`-chromatic graph contain a FIXED chromatic-4 graph
