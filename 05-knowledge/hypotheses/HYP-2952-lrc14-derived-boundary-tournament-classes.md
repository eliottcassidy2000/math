# HYP-2952: Derived-boundary tournament classes for AP/GW-kind rows

This note adds a deliberately fussy necessary-condition layer above HYP-2920.
The target is not another scalar filter.  The target is a reusable recipe:

```text
choose exact event vertices
choose a pairwise observable
choose a switch and tie Hamiltonian path
compute the achievable tournament isomorphism classes for fixed n
require every AP/GW-kind boundary row to land in the AP/GW class fiber.
```

The new calibration is that AP and Goddyn-Wong are indistinguishable by the
coarse strict-Haar test, by the denominator-14 unit-contact skeleton, and now
by a six-vertex apex-pressure tournament isomorphism class.

## Objects

For a finite row `S`, define

```text
O(S) = {t in R/Z : ||s*t|| > 1/14 for every s in S}
C(S) = {t in R/Z : ||s*t|| >= 1/14 for every s in S}.
```

`O(S)` is the strict-open safe set and `C(S)` is the threshold-closed safe
set.  AP and GW have `O(S)` of Haar measure `0`, while their threshold support
contains the six denominator-14 unit points

```text
U14/14 = {1,3,5,9,11,13}/14.
```

So AP and GW are boundary-only rows at threshold `1/14`; near/K33 `12->36`
and the petals are strict-Haar-positive rows.

For each `u in U14`, define the apex distance profile

```text
d_u^S(s) = min(s*u mod 14, 14 - (s*u mod 14)) in {1,...,7}
D_u^S(k) = #{s in S : d_u^S(s)=k}.
```

The first shared AP/GW condition is exact:

```text
D_u^S(1)=2 for every u in U14.
```

The two boundary speeds are the same unit-residue blockers as AP.  The
accelerated GW speed `24` is not a first-order boundary blocker; it is a
second-order petal repair for the interval opened by deleting `12`.

## Derived-boundary reading

The Tao-derived-multiplicative inspiration is formal rather than literal.
Tao's point is that some nonmultiplicative objects are best understood as
top coefficients of multiplicative families over rings with nilpotent
infinitesimals.  Here the analogous move is:

```text
AP is the multiplicative/base boundary product.
GW is a first derived boundary deformation of AP.
multi-accelerations are higher derived terms with cross packets.
```

Make this exact as follows.  Let

```text
A = {1,...,13}
Delta_u(S) = D_u^S - D_u^A.
```

A row is in the first derived AP/GW boundary stratum if:

1. `O(S)` has Haar measure `0`.
2. `C(S)` contains exactly the denominator-14 unit boundary support after the
   standard reductions.
3. `Delta_u(S)(1)=0` for every `u in U14`.
4. `Delta_u(S)=Delta_{14-u}(S)` for every antipodal unit pair.
5. The nonzero part of `Delta` is generated by a finite set of tail
   accelerations `v -> 2v`.
6. Each acceleration has a Goddyn-Wong/Jacobsthal nonunit repair window:

   ```text
   gcd(v,j)>1 for every j in [n-v+1, 2n-2v+1].
   ```

7. For two or more accelerations, the second derived cross packet is named and
   not silently scalarized.  If the cross packet is invisible, the row is a
   disjoint union of repairs, not a new AP/GW-kind atom.

Condition 7 is the nilpotent warning.  A first derivative can look linear; a
second derivative has a Leibniz cross term.  In LRC language the cross term
should show up as a splice, an incidence owner, a C27 transfer collision, a
unital two-chart obstruction, or a K33 state-lift packet.

## Apex-pressure tournament

Define a tournament `T_apex(S)` on the six vertices `U14`.

For two unit witnesses `u<v`, each speed votes for the witness where it lies
closer to the boundary:

```text
sigma_S(u,v) =
  sum_{s in S} sign(d_v^S(s) - d_u^S(s)).
```

Orient `u -> v` if `sigma_S(u,v) >= 0`; orient `v -> u` otherwise.  Ties are
therefore resolved by the Hamiltonian path

```text
1 -> 3 -> 5 -> 9 -> 11 -> 13.
```

This quotient preserves denominator-14 boundary pressure among the six unit
witnesses.  It destroys exact speed magnitude, off-apex denominators, and
strict-Haar-positive intervals; therefore exact `M`/Farey/C27/K33 labels must
remain attached.

## More necessary conditions for a third AP/GW-kind row

A third row of the same kind should satisfy all of the following before it is
allowed into the summit route.

1. **Boundary-null condition.**  `O(S)` has Haar measure `0`; otherwise the row
   is a positive open witness row, not AP/GW-kind.

2. **Unit contact multiplicity.**  Every `u in U14` has exactly two boundary
   contacts `d_u^S(s)=1`, and these contacts lie in the unit-residue odd
   skeleton.  The repair speeds are second-order, not first-order blockers.

3. **Literal complement binders.**  The six unit-boundary blocker pairs still
   bind by literal representative sums, not merely by residues:

   ```text
   1+13 = 3+11 = 5+9 = 14.
   ```

4. **Derived AP profile.**  The deviation `Delta_u(S)` is antipodally paired
   and generated by named tail accelerations.  Unnamed residue reshuffling is
   forbidden.

5. **Jacobsthal repair windows.**  Each deleted tail speed `v` must have a
   consecutive nonunit repair interval.  For LRC14, `v=12` is special because
   `[2,3]` contains no unit modulo `12`.  Other petals that pass coarse
   residue filters must still escape off apex.

6. **No cyclic apex pressure.**  `T_apex(S)` is the transitive six-vertex
   isomorphism class.  Cyclic classes are achievable by AP mutations but not
   by the named AP/GW low-frontier fiber.

7. **C27 shell compatibility.**  The row's transfer is either perfect AP,
   `H[12:g3]->D[3:g3]` like GW, a unit-petal transfer to be discharged by
   petal rigidity, or the `H[12:g3]->D[9:g9]` K33/Farey-child branch.  A new
   label must explain what C27 information it preserves.

8. **Unital chart discipline.**  If the row wants to share both the GW branch
   and the K33 branch, it must use multiple charts or split the `H12` pair.
   One raw `2-(28,4,1)` chart cannot contain both branches because of the
   repeated pair.

9. **Farey indecomposability.**  A scalar mediant or edge-density average is
   not a new obstruction.  It must lift to a typed incidence object.  In the
   Kuratowski analogy, `K5 + K3,3` is nonminimal; similarly, a row whose
   tournament packet decomposes as a disjoint union or substitution product is
   a combination of old atoms, not a third AP/GW atom.

10. **K33 threshold routing.**  Once the exact Farey numerator reaches `p>=3`,
    the branch must carry a complete-bipartite/minor-transitive packet or feed
    HYP-2908/THM-572.  It should not masquerade as a boundary-only AP/GW row.

11. **Continued-fraction denominator discipline.**  The Collatz/Farey
    inspiration suggests that sharp cycle obstructions arise when a logarithmic
    or rotation constant is pinned by a best-rational ladder.  In LRC14 this
    means the row must name its Farey neighbor to `1/14`, its determinant
    defect, and why no closer denominator opens an interval.

12. **Achievable-class certificate.**  For every chosen vertex functor `V` and
    switch `theta`, compute or prove

    ```text
    Ach_n(P,V,theta) = {[T_theta(S)] : S satisfies predicate P}
    ```

    for the fixed vertex count `n`.  A proof may then be a class-exclusion
    argument:

    ```text
    bad row -> required class C
    C not in Ach_n(P,V,theta)
    contradiction.
    ```

    The S148 calculation is the smallest instance: `n=6`, `P=AP
    single-residue mutation at the denominator-14 apex`, and `V=U14`.

## Proof target

The next theorem-shaped target is:

```text
After standard LRC14 reductions, any strict-Haar-zero threshold row has
transitive apex-pressure class and first-derived AP profile.  If it is not AP
or GW, then its derived cross packet is nonzero and forces either a positive
strict-Haar interval, a unit-petal two-block discharge, or the K33/HYP-2908
state-lift branch.
```

That would turn AP/GW from two named examples into the unique first-derived
boundary fiber, with all other low-frontier rows routed away by their
tournament isomorphism class or by the labelled packet they cannot hide.
