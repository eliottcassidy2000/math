## Claim

The tiling model becomes algorithmically useful when the growth step
`n -> n+1` is treated as a retained extension carrier, not as a fresh raw
unlabelled tournament.

There are two compatible compression laws.

1. **Diagonal layer sheet law.** Consecutive tiling layers of sizes `k` and
   `k+1` connected by all `k(k+1)` cross-lines should often be read as a
   boundary-potential sheet

   ```text
   e_ij = x_i XOR y_j.
   ```

   Then every rectangle has zero parity:

   ```text
   e_ij + e_i'j + e_ij' + e_i'j' = 0 mod 2.
   ```

   Thus the apparent `k^2+k` line values collapse to `k+(k+1)-1=2k`
   independent bits. The saved exponent is `k(k-1)`. Nonzero rectangle
   defects are the meaningful residuals: they are the places where a layer
   interaction is not generated by boundary words.

2. **One-vertex extension law.** For an unlabelled parent tournament class
   `[T]`, adding one vertex is governed by incident binary words on `V(T)`
   modulo `Aut(T)`. The rooted extension count is

   ```text
   E(n -> n+1)
     = sum_[T in A(n)] (1/|Aut(T)|) * sum_{g in Aut(T)} 2^{cycles(g)}
     = R(n+1),
   ```

   where `R(m)` is the number of rooted/perspective tournament classes on
   `m` vertices. The final passage to `A(m)` is a further unrooting quotient.

This explains the user's observed ladder:

```text
R(3)=4=A(4),  R(4)=12=A(5),
```

and also the first failure:

```text
R(5)=48 != A(6)=56.
```

So the pattern is real but not the direct recurrence for A000568. The exact
recurrence-shaped object is rooted extension state, not unrooted class count.

## Interpretation

The `k(k+1)` line sheet is a finite coboundary object. Its correct algebra is
closer to a rank-one sign matrix, a two-dimensional Haar product, or a
complete-bipartite incidence matrix with row/column potentials than to a
generic binary graph.

The one-vertex tournament extension is the same doctrine one categorical level
up. A labelled incident word has `2^n` possibilities, but the theorem-facing
object is the word orbit under `Aut(parent)`. Only after this rooted extension
stage should one quotient to unrooted child classes.

This gives an enumeration strategy:

1. Cache parent representatives and automorphism cycle indices.
2. Generate incident-word orbits, not all labelled incident words.
3. Extend representatives and keep the new root/deletion address.
4. Merge to unrooted classes only after recording which rooted states collide.
5. Use rectangle defects in fixed-path layer sheets as residual coordinates
   rather than enumerating every cross-line independently.

## Relation To Half-Tilings

The tempting statement "A000568(n) is the number of unique binary half-tilings
of a smaller size" is too strong as written. A safer replacement is:

> A000568 children are quotients of rooted/perspective extension half-tilings;
> early equalities occur when the perspective count happens to match the next
> unrooted count, but from `n=5` onward the quotient has visible excess or
> deficit.

Half-tiling symmetry is still central. Complement/reflection fixed domains
should be modeled by the joint action of the parent automorphism group and the
layer reflection involution. That is a Burnside calculation over a smaller
group, not plain A000568.

## Tournament Analysis

Vertices are layer carriers, not original tournament vertices:

```text
boundary words,
rank-one sheets,
parent classes,
parent word-orbits,
rooted children,
unrooted children,
rectangle-defect residuals.
```

Pairwise observable: amount of extension/perspective information retained
before quotient.

Switch/gauge: orient toward the carrier that retains more proof-relevant
address data without unnamed residual debt.

Tie Hamiltonian path:

```text
boundary_words > rank_one_sheet > parent_word_orbit >
rooted_child > unrooted_child > scalar_count
```

Challenged assumption: tournament analysis does not have to put the original
vertices of `T` at the vertices of the analysis tournament. Here the useful
vertices are proof states and extension carriers.
