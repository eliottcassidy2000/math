# HYP-3723 — the functional decomposition: the covering modulus is twice the staircase

## The decomposition (verified)
With `a(x) = x/2`, `b(x) = x+1`:
- `f(x) = b(x) if x even, x if x odd` = the **ODD member** of `{x, x+1}`;
- `g(x) = a(x) if x even, a(b(x)) if x odd` = `ceil(x/2)` = the **EVEN member of `{x,x+1}` divided by 2`;
- **`f(x) . g(x) = x(x+1)/2 = T_x`** (the triangular numbers) -- parity ROUTES the single `/2` onto whichever
  of `x, x+1` is even, keeping the odd one whole. Verified `x=1..12`.

This is the **single-integer shadow of the 2-adic descent** (THM-580): on a speed set the descent splits
`S = O u E` (odd/even) and halves the even part `E/2` -- exactly `f` (keep odd) and `a=/2` (halve even). The
recursion `g(x) = ceil(x/2)` iterated is the binary peel (`14 -> 7 -> 4 -> 2 -> 1`), the `f`-values being the
odd members at each level.

## The covering modulus IS twice the staircase plus one
The LRC covering modulus and killer are triangular:
> `Phi_6(n) = n^2 - n + 1 = 2 . T_(n-1) + 1`,   `killer = lcm(n-1,n) = n(n-1) = 2 . T_(n-1)`,
> `M = n / (2 T_(n-1) + 1)`,   recursively `Phi_6(n) = Phi_6(n-1) + 2(n-1)`.
Verified `n=3..14` (`n=14`: `T_13 = 91`, `2.91+1 = 183 = Phi_6(14)`, killer `182`). So the binding modulus is
literally `b(a^{-1}(T_(n-1)))` -- the staircase triangular number, doubled (`a^{-1} = x2`) and shifted
(`b = +1`). And the two consecutive triangulars FRAME each level:
- `T_(n-2) = C(n-1,2) = #tiles` (the staircase delta_(n-2), "everything is the triangle");
- `T_(n-1) = (Phi_6(n) - 1)/2` = the covering-modulus core.
The CF `n/Phi_6(n) = [0; n-1, n]` (HYP-3717) is just the two factors `n-1, n` of `2 T_(n-1) = (n-1)n`.

## The operation algebra (think even/odd, +/-, x / /)
The covering structure is generated by the dyadic-affine operation algebra acting on the triangular numbers,
recursively. The three dual pairs:
- **even/odd** (parity): the descent branch -- which of `{x,x+1}` is even (gets `/2`); `S = O u E`.
- **positive/negative** (sign): the antipodal binding pair `(1, -1)` -- the killer `2T_(n-1) = -1 mod
  Phi_6(n)`, and at the mediant `t=1/n` the killer lands at `0` (HYP-3718). The complement / `sigma`.
- **addition/division** (`b=+1` / `a=/2`): the `f.g = T_x` decomposition and `Phi_6 = 2T+1` (one `+1`, one
  `x2`); the descent's `/2`.
Everything recursively: `T_x = T_(x-1) + x`; `Phi_6(n) = Phi_6(n-1) + 2(n-1)`; `g = ceil(x/2)` iterated
(binary peel); the speed-set descent `S -> E/2`. The covering-min `M = n/(2T_(n-1)+1)`, the convergent escape
(HYP-3718), the hexagonal lift (HYP-3717) all sit on this triangular-number spine.

## Net
The owner's `f.g = T_x` is the parity-routed triangular decomposition -- the single-integer shadow of the
2-adic descent (`f` = keep the odd, `a=/2` = halve the even). The LRC covering modulus is exactly `2 T_(n-1)
+ 1` (twice the staircase plus one), the killer `2 T_(n-1)`, built recursively by `+2(n-1)`. So "everything
is the triangle" extends to the covering layer: the binding modulus, killer, CF, and covering-min are all
generated by `{even/odd, +1/-1, x2 / /2}` on the triangular numbers, recursively.
