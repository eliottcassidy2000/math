# HYP-3021: Pair-Good Decoy Generator Classification

## Claim

The pair-good decoy count from HYP-3019 is not a load-bearing invariant.  Every
pair-good decoy is generated by a modular tooth certificate:

```text
source pair lane + blocker residue tooth + active blocker deck
```

For a THM-524 pair-crossing time `t=p/q` in lowest terms, runner `c` blocks
exactly when

```text
14 * min(c*p mod q, q - (c*p mod q)) < q.
```

So a pair-good decoy is exactly a pair crossing where some blocker speed lands
strictly inside its `1/14` danger tooth.  The count can be large because many
source pairs cross inside the same few AP-core tooth regimes.

## Interpretation

The exact generator lemma replaces the worry "there are too many decoys" by a
finite sidecar grammar:

```text
pair source lane
source shell
blocker role
blocker depth bucket
zero-tooth flag
generator-cover size
top generator key
```

The AP core is the main decoy generator.  In AP-like rows, most pair crossings
are pair-good only before the AP-core tooth cover is applied.  This is expected:
the AP/GW boundary atoms already tile the denominator-14 sections tightly, so
most off-boundary pair crossings should hit a core danger tooth.
