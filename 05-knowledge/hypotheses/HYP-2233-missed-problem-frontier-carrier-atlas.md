# HYP-2233: Missed Important Problems Should Be Ranked by Repo-Leverage Carriers

## Claim

The next important outside problems for this workspace should be selected by a
carrier score, not by fame alone:

```text
repo leverage + near-term finite action + undercoverage + external importance
  - raw fame-chasing risk.
```

The useful target is a named problem whose small/restricted shadow can already
be expressed in repo-native terms: tournaments, deletion decks, unit-distance
direction support, finite-field incidence ledgers, closure/frequency carriers,
or OCF-style set-system cores.

This is a frontier-selection hypothesis, not a proof claim about any external
problem.

## Ranked Candidate Frontiers

1. **Hadwiger-Nelson / chromatic unit-distance graphs.**  This is the top
   actionable lane because the repo already has unit-distance Moser/Sawin
   carriers, direction masks, Hamiltonian-spine questions, and `chi`
   side-channel prompts.  First experiment: compute color-critical fingerprints
   for finite carriers: direction support, traceability, independence ratio,
   color-critical deletions, and tournament flip gauges.

2. **Graph reconstruction / deletion decks.**  The repo's endpoint-transfer,
   deletion-loss, old-projection, and sufficient-statistic language is a nearly
   literal deck-invariant machine.  First experiment: build a tournament
   card-deck atlas asking which of `H`, OCF coefficients, SCC packet data,
   score histograms, beta fibers, and deletion losses are reconstructible from
   vertex-deleted cards.

3. **Kakeya / Falconer / finite-field incidence geometry.**  The finite-field
   Kakeya theorem is a natural toy version for direction-coverage, and Falconer
   sits next to unit/distance energy.  First experiment: over `F_p^2`, compare
   direction lines, distance fibers, Paley-character orientations, and
   tournament fingerprints.

4. **Sunflower / robust sunflower / extractor set systems.**  OCF already
   treats disjoint odd-cycle packets as a partition function, but the repo does
   not yet retain hypergraph core side channels.  First experiment: scan
   odd-cycle support hypergraphs for sunflower cores and robust-sunflower
   thresholds, especially around H=63 exact-core rows versus THM-025 near-kill
   rows.

5. **Union-closed sets / Frankl frequency carriers.**  The conjecture's
   half-frequency witness is structurally close to cauldron closure,
   finite-sums, divisor carriers, and observer/source frequencies.  First
   experiment: enumerate small closure systems and compare two tournament
   quotients, one with vertices as elements and one with vertices as sets,
   measuring which quotient preserves majority-witness data.

6. **Caccetta-Haggkvist short directed cycles.**  This is already present in
   the repo, but it deserves consolidation as a bridge to LRC return-residue
   tests and directed-cycle obstructions.  First experiment: assemble a CH-vs-
   LRC return-residue atlas for `r=3` extremal oriented graphs.

7. **Erdos-Hajnal tournaments and blow-ups.**  THM-410 and S652's square-node
   substitution are literal blow-up carriers.  First experiment: test `H`-mass
   and OCF spectra on induced-pattern-free tournament families before trying
   to say anything about transitive-subtournament exponents.

8. **Distinct/pinned distances.**  This is the dual face of the unit-distance
   program: many repeated unit distances versus many distinct distances.  First
   experiment: run paired energy ledgers on finite point sets.

9. **Rota basis / Ryser-Brualdi-Stein / rainbow transversals.**  Important, but
   the broad keyword hit count is high and the exact carrier is not yet sharp.
   First experiment: model color/base obligations as a rainbow obstruction
   tournament with Hall-deficit and SCC data.

10. **Graceful tree labeling.**  Lower external leverage, but cheap to test as
    a difference-set carrier.  First experiment: caterpillar/spider graceful
    labels through pair-difference tournaments.

11. **Clay Millennium controls.**  These remain valuable as negative controls:
    if a supposed target ranks below Clay-scale controls on actionability, the
    repo should not pretend it is a near-term attack surface.
