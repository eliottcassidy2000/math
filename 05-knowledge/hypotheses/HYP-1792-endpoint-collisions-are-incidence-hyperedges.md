# HYP-1792: Endpoint Collisions Are Incidence Hyperedges

## Statement

The support-3 self-complementary collision columns in merged endpoint transfer
should be treated as a 3-uniform endpoint-incidence hypergraph, not as the
triangle set of the parent merged arc-flip metagraph.

Equivalently, the tempting strengthening

```text
every non-private SC collision owner triple is a clique in G_n/Z_2
```

is false.  The arity-three signal in HYP-1790 is real, but it is not generally
ordinary adjacency geometry.

## Evidence

`endpoint_collision_geometry_s95.py` builds the full parent merged arc-flip
metagraph and measures the induced edge count on each support-3 owner set.

For `5->6`, the unique collision owner triple is a clique:

```text
edge_count_spectrum = {3: 1}
owner kind tuple    = (NSC, SC, SC)
owner good-cut tuple = (3, 4, 4)
```

For `6->7`, the 14 collision owner triples already realize every possible
induced edge count:

```text
edge_count_spectrum = {0: 1, 1: 6, 2: 5, 3: 2}
owner good-cut tuples = {
  (3,4,5): 1,
  (3,5,5): 2,
  (4,5,5): 2,
  (5,5,5): 9
}
```

One collision has no parent-metagraph edges at all:

```text
child H=141, g=6, owners=[24,25,32],
owner kinds=[SC, NSC, SC],
owner H=[33, (33,33), 45],
parent_edges=[]
```

So the endpoint collision relation is not generated by cliques, paths, or any
single ordinary graph shape visible in the parent metagraph.

## Interpretation

HYP-1790 remains a strong ternary statement: non-private SC columns have odd
support exactly `3` in the tested range.  HYP-1792 refines what "ternary" means.
The three parents are three odd preimages of an endpoint-transfer boundary
column.  They need not be mutually adjacent by one arc flip.

This separates two structures:

```text
parent merged metagraph:   ordinary arc-flip adjacency
endpoint collision layer:  3-uniform transfer-incidence hyperedges
```

The rank problem in HYP-1791 should therefore be attacked as a hypergraph
incidence problem.  Reducing it to a clique-complex statement on `G_n/Z_2`
would lose examples already present at `6->7`.

HYP-1793 records the positive replacement: this incidence hypergraph appears
leaf-peelable through `6->7`, which would triangularize the collision block in
the correct category.
