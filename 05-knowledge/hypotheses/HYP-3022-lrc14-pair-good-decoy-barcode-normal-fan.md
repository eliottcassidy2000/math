# HYP-3022: LRC14 Pair-Good Decoy Barcode And Normal-Fan Refinement

## Claim

Pair-good decoys should be treated as generated switch objects with barcode and
active-normal-fan relations, not as a count to be bounded.

This refines HYP-3021's modular tooth classifier.  HYP-3021 proves the exact
source-lane plus blocker-tooth grammar; HYP-3022 adds where each generated
false switch sits relative to strict barcode bars and HYP-3018 active
bottleneck owner supports.

Definition used here:

```text
A pair-good decoy is a THM-524 pair-crossing candidate time where at least one
pair has equal distance >= 1/14, but the full row has min_v ||v t|| < 1/14.
```

Each decoy has an exact generator:

```text
row
candidate time t
good pair (a,b)
sum/diff lane
denominator a+b or |a-b|
pair gap
active blocker deck
barcode relation
normal-fan support relation
```

Thus the proof obligation is not "there are many decoys."  The obligation is
to prove that every generator class is blocked by its active deck or is routed
to a real barcode / normal-fan support certificate.

## Relation To Barcode Bars

Pair-good decoys are outside strict barcode bars by definition:

```text
actual_gap < 1/14.
```

So they are not alternative witnesses.  Their relationship to the barcode is
diagnostic:

```text
zero_bar_row:
  AP/GW boundary rows; the decoys cannot become bars without changing the row.

outside_bar_nearest:
  positive-open rows; the decoy is a blocked switch outside a real bar.

pair_is_bar_peak_support / pair_overlaps_bar_support:
  the same pair mechanism can be real elsewhere, but this switch is blocked.

blocker_is_bar_peak_support / blocker_overlaps_bar_support:
  the blocker is itself part of the row's actual normal fan, so the decoy is
  generated by competition between local support classes.

disjoint_from_bar_peak_supports:
  the decoy is a pure false switch and should be discharged by the explicit
  blocker deck and lane denominator.
```

## Relation To Active Bottleneck Owners

HYP-3018 says the theorem-facing data is the active normal fan:

```text
left threshold owners -> peak bottleneck owners -> right threshold owners.
```

HYP-3022 adds the complementary false-switch data:

```text
pair-good lane -> blocker deck.
```

Together they split pair crossings into two finite proof roles:

```text
real switch:
  contributes a barcode bar and active normal-fan peak support.

decoy switch:
  has a threshold-good pair, but an explicit blocker deck forces
  min_v ||v t|| < 1/14.
```

Therefore the proof should not count decoys.  It should prove a generation
lemma: every pair-good decoy is produced by a lane/shell/blocker grammar, and
each grammar class is either disjoint false-switch debt or overlaps a known
normal-fan support already handled by the barcode/endpoint/Fejer stack.
