# HYP-2947: LRC14 Measurable Rank Recombination Packet

This namespace is claimed for the S145 attempt to combine the recent POKE
carriers into one finite proof interface:

```text
exact M/Farey branch
-> C27 shell transfer
-> q=3 unital local chart
-> affine depth/order signature
-> K33/Kuratowski packet
-> HYP-2248 measurable address tax
-> PH-style bad-child rank
-> HYP-2908/THM-572 state-lift endpoint
```

The target is not a scalar proof.  The target is a recombination lemma for the
known low-frontier rows:

```text
Every low-frontier packet either
  (a) is tight AP/GW,
  (b) discharges through a unit C27 petal/two-swap strip,
  (c) or carries the nonunit K33/depth-14 state-lift address.
```

The session will test whether this split can be made into a measurable finite
rank:

```text
rank(packet) = uncharged nonunit/K33 obligations after exact M/Farey,
               C27 owner/carry, and product-measurable address labels.
```

The honest risk is that low-frontier labels may still recur in loose rows, so
the exact `M`/Farey branch and measurable owner/carry address must stay attached
throughout.
