# HYP-2109: tournament edges should be terminal states of left-middle-right pair automata

## Statement

For LRC-facing Tournament Analysis, the useful primitive is not always
`pair observable -> binary edge`.  It is often

```
pair event word -> 3-state automaton in {L, M, R} -> tournament edge,
```

where `L` and `R` are the two possible owners/sides and `M` is a visible
wall, tie, midpoint-corridor, or unresolved cover state.  A fixed Hamiltonian
tie path resolves terminal `M` only at the final projection step.

## Why this matters

The ordinary tournament forgets how an edge changed.  The three-state automaton
remembers the only legal flip gate: an edge that moves from left to right should
pass through `M`.  In LRC this is exactly the state that carries the hard
information:

- endpoint-cover circuits: `M` is the component still able to fit one common
  arc centre; `L/R` are left/right owner obstructions;
- HYP-2108 positivity: the impossible all-middle closure is the simultaneous
  midpoint-resonance circuit `P(S) <= 0`;
- HYP-2107 residue automata: `M` is a live bounded residue state before CRT or
  dominance kills it;
- apex/sheaf certificates: `M` is a gluing seam where a cheap-pair section has
  not yet chosen a side chart.

Thus "middle" is not indecision.  It is the mathematical wall that should be
audited before the binary tournament quotient erases it.

## S582 toy model

`04-computation/tournament_three_state_automaton_s582.py` implements two tiny
automata over `{L,M,R}` and projects their terminal states to a tournament using
the tie path `A -> B -> C -> D -> E`.

The wall automaton has zero direct `L <-> R` transitions: side changes must pass
through `M`.  Compared with a last-nonmiddle rule, it changes one projected edge
while preserving the score histogram, one-SCC status, directed triangle count
`3`, and Hamiltonian path count `9`; the triangle support changes because the
middle state `CE` is resolved by the tie path.  The point is not the sample
graph; it is the proof discipline: edge flips become wall-crossing events, not
anonymous orientation changes.

## Tournament Analysis

Vertices in the S582 demo are pair automata in a toy alphabet.  For LRC, the
better vertex sets to try are components of `G(S')`, endpoint owners, cover arc
centres, residue states, proof obligations, and gluing germs.  Runners are only
one possible quotient.

Pairwise observable: the event word in `{L,M,R}` generated by endpoint owner,
midpoint phase, residue compatibility, or certificate-gluing status.

Switch/gauge: terminal `L` beats terminal `R`; terminal `M` is resolved by an
explicit tie Hamiltonian path, and should also be reported as a separate
middle-state count.

Fingerprints: score histogram, directed cycles, SCCs, Hamiltonian-path count,
edge flips, and especially the number of flips whose trace passes through `M`.

## Assumption challenge

Preserved predicate: which side currently owns a pairwise obstruction, and which
pairs remain in the middle corridor before projection.

Destroyed information: exact interval lengths, exact residues, and continuous
time phases.  These must remain as labels or weights if the proof needs their
sizes.

Challenged assumption: a tournament edge is not necessarily a raw comparison of
two runners.  It can be the terminal state of a regular language that has
already compressed a local proof search.

## Next theorem target

Prove an LRC-specific no-closed-middle lemma:

```
if every local endpoint/residue automaton stays terminal M around the circuit,
then the HYP-2108 midpoint average bound or the HYP-2107 bounded CRT guard fails.
```

If true, every proposed tight cover either exits to an `L/R` owner obstruction
with a private pivot, or remains all-middle and is killed by circuit positivity.
