# HYP-3052: Tournament diagonal-layer transport and half-tiling quotient laws

## Claim

The tournament tiling growth step should be treated as a diagonal transport
orbit DAG:

```text
parent isomorphism class C
  + diagonal word w in {0,1}^n / Aut(C)
  -> rooted child class
  -> unrooted child class sink after deletion-fiber quotient.
```

This is the algebraically efficient version of the user's diagonal-layer
picture.  The `k^2+k` lines are best interpreted as the complete bipartite
position carrier `K_{k,k+1}` between geometric tile layers of sizes `k` and
`k+1`.  Those lines are not the complete graph between all binary words.
Their labels are generated by two diagonal words, so the line matrix has exact
rank-one redundancies.

At the first S211 shifted failure surface, the direct growth map is exact:

```text
5 -> 6:
  raw labelled diagonal extensions = 12 * 2^5 = 384
  parent-automorphism diagonal word orbits = 296
  rooted 6-tournament count = 296
  unrooted 6-tournament sinks = 56
```

Thus the missing payload in `P(5)=48` versus `U(6)=56` is not a numerical
half-tiling bijection.  It is the diagonal incident word, modulo the parent
automorphism group, followed by the deletion-fiber quotient.

## Exact Laws

For two consecutive layer words

```text
w in {0,1}^k,     u in {0,1}^{k+1},
```

write `a=sum(w)` and `b=sum(u)`.  The complete position carrier
`K_{k,k+1}` has line-label counts:

```text
N00=(k-a)(k+1-b)
N01=(k-a)b
N10=a(k+1-b)
N11=ab
```

So every count matrix satisfies:

```text
N00 * N11 = N01 * N10.
```

This is the first algebraic efficiency: `k(k+1)` pair-lines collapse to two
word weights for coarse line counts, and to `2k+1` bits for full recovery of
the two words.

The aligned diagonal and the link bit carry the next cycle increment.  If
`ell=u_k` is the edge between the two newest vertices, then the number of
directed triangles using both newest vertices is:

```text
#{i<k : w_i = ell and u_i != ell}.
```

The score update is affine:

```text
old vertex i gains w_i + u_i,
vertex k gains k - sum(w) + u_k,
newest vertex has outdegree k+1 - sum(u).
```

These formulas are small enough to be sidecar fields rather than recomputed
from the full labelled tiling.

## Half-Tiling Check

The user's suggested half-tiling count correspondence is close in spirit but
not correct as a raw enumeration.  The script checks:

```text
n  U(n)  rooted_P(n)  2^half(n-1)  2^half(n)  self_converse_classes
3     2            4             1          2                      2
4     4           12             2          4                      2
5    12           48             4         16                      8
6    56          296            16         64                     12
```

So `U(n)` is not the number of binary half-tilings of size `n-1` or `n`.
Symmetry along the fold detects the self-converse branch locus, but even that
class count is not generally `U(n-1)`.

The useful replacement is:

```text
half-tiling = converse-fold branch/fundamental-domain input;
diagonal transport orbit DAG = exact recursive growth object.
```

## Duplication Laws

1. **Parent-automorphism duplication.**  Raw words in `{0,1}^n` duplicate
   when the parent tournament has automorphisms.  Quotienting by `Aut(parent)`
   gives rooted child classes.
2. **Deletion-fiber duplication.**  Rooted child classes duplicate inside a
   single unrooted child class.  The multiplicity is the number of vertex
   orbits of the child.
3. **Position-line duplication.**  The `K_{k,k+1}` line carrier has
   `k(k+1)` lines, but binary labels come from two words.  The count matrix is
   rank one, and the aligned diagonal plus link bit gives the two-newest
   triangle increment.
4. **Converse-fold duplication.**  The half-tiling fold removes converse
   duplicates and marks the branch locus.  It is not itself the unlabelled
   tournament quotient.
