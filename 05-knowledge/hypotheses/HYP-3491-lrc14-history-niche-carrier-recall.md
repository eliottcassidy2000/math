# HYP-3491: LRC14 History Niche-Carrier Recall Atlas

## Claim

A scan back through the repo history suggests that several older "niche"
threads were not exhausted.  Their useful form is not the original famous
topic or analogy, but the exact proof carrier that the repo already extracted.

The current HYP-3490/HYP-3484 frontier makes six underused bridges especially
worth reattaching:

1. **Colored Nerode / partition-lattice carrier.**  HYP-3474 already asked
   which colored-gate quotients preserve route predicates.  HYP-3490 gives a
   new target predicate: whether every E/branch-touched blocker label has
   dead-cover multiplicity `1`.  HYP-3513 executes this finite test: `C`,
   `F`, `N`, and `T` already reconstruct private-firewall status, while the
   full HYP-3490 route still needs sidecar `R` or a route-reconstruction
   theorem.
2. **Label-component Menger/Green carrier.**  HYP-3437 and HYP-3236 should be
   reused at the dead-cover incidence level.  HYP-3490 is exactly a cut
   statement on the bipartite graph `dead component <-> blocker label`:
   multiplicity-one labels cannot remove projection edges.  Random031 then
   asks for a separate Green/Dirichlet seam-complement model where the
   max-delta seam has zero phase current and the bypass carries the `12` hits.
3. **`C=27` two-adic carry-lift carrier.**  HYP-3484's `C=2n-1=27` sidecar
   should absorb the old p-adic/Krasner/Hensel prompt discipline.  The useful
   version is not "non-Archimedean geometry" in the abstract, but an exact
   stress test: preserve or perturb seam owners modulo `27`, endpoint residues
   `(1,9) mod 14`, and the mod-`8` 2-adic square guardrail, then watch whether
   seam deletion remains invisible and bypass deletion still accounts for
   exactly `12` hits.
4. **Function-compression constancy carrier.**  HYP-3150/HYP-3151/HYP-3199
   should be pointed at HYP-3490.  The target function is no longer a toy
   operation such as `a^b`, but
   `can a union of touched E/branch labels delete a dead-cover projection edge?`
   A quotient is legal only if this target is constant on its fibers, or if a
   named sidecar reconstructs the lost label multiplicity.
5. **Owner-cut / Schwarz-Christoffel / charal carrier.**  HYP-3419 converted
   the Bring/SC/BDH/Menger prompt into bounded owner-cut recursion.  It should
   now be applied to the seven-owner random031 seam and to the six private
   singleton pockets.  The theorem-shaped object is an endpoint-owner
   transversal or Farkas/Green current, not a Bring radical or BDH scalar.
6. **Joukowski/Hermite-Biehler/Perron root-motion carrier.**  HYP-3222 and
   HYP-3153 remain useful as bulk and cap-side guardrails after the finite
   terminal packet is discharged.  They should not replace HYP-3490's finite
   firewall, but they may explain why the AP/consecutive sector extremal is
   the global side of the same compression law.
