# HYP-2872: the even-graph minor quotient is not the H-obstruction closure

Kuratowski/Wagner and Robertson-Seymour are the right analogy for asking which
operations preserve the object, but the exact fixed-path/even-graph audit says
they are not the right closure for the tournament Hamiltonian-path count `H`.

In the fixed-Hamiltonian-path cube, every tournament is represented after
choosing one Hamiltonian path and relabelling it as

```text
0 -> 1 -> ... -> n-1.
```

The free arcs are the pairs `(i,j)` with `j>i+1`, hence there are
`C(n-1,2)` bits.  The audit uses the concrete triangle-basis bijection from
these bits to the cycle space of `K_n`: the free arc `(i,j)` is the coefficient
of the triangle `(0,i+1,j)`.  This is the useful labelled form of the
tournament/even-graph equinumerosity.

The graph-minor style operations then fail in two different ways.

1. **Degree-2 suppression is too coarse in the GF(2) even-graph quotient.**
   Through `n=7`, deterministic GF(2) smoothing sends `25414` rooted
   `n=7` tournaments to the same empty terminal core while their `H` values
   range over `77` distinct odd values from `1` to `189`.  The reason is
   structural: in the cycle-space quotient, smoothing a degree-2 vertex toggles
   the chord modulo `2`, so a triangle can vanish.  This is not Kuratowski
   topological-minor suppression, which preserves subdivision type rather than
   cancelling cycles mod `2`.

2. **GF(2) edge contraction preserves even degree but is not `H`-monotone.**
   The audit checked `344064` one-edge contractions at `n=7`, all staying in
   even graphs.  But the induced fixed-path tournament `H` can increase:
   an `n=7` parent with `H=31` contracts an even edge `(2,3)` to an `n=6`
   child with `H=33`.  It can also decrease: the triangle shadow at `n=4`
   with `H=3` contracts to the empty `n=3` shadow with `H=1`.

So the forbidden values `{7,21}` should not be pursued as forbidden minors of
the even-graph shadow.  The even-graph quotient is a cycle-space address, not
an `H`-complete minor object.

The positive redirect is the existing one: `H` respects strong-component
condensation, not graph minors.  Strong components are the irreducible blocks,
`H(T)=prod_i H(C_i)`, and `{7,21}` live as forbidden values in the
multiplicative semigroup of strong-tournament/OCF conflict-graph cores.  The
minor-theory analogy is still useful as a guardrail: it says to separate the
minor-closed skeleton from the contraction-sensitive correction, exactly as
THM-520 does for the Alcuin `tau/+1` split.

Post-pull S33 connection: mac-mini's simultaneous idea batch framed permanent
forbidden `H` values as a multiplicative ideal generated by missing strong
primes.  HYP-2872 is compatible with that framing.  It only rejects the
stronger move that arbitrary even-graph contraction/suppression should be the
minor order.  Any useful Wagner-style order for `H` needs a preservation
theorem, likely via strong-component condensation or OCF-packet reductions with
an explicit `H`-factor ledger.
