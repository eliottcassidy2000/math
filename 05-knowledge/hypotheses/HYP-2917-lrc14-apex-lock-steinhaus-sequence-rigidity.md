# HYP-2917: apex-lock versus tightness is the right Steinhaus sequence split

The current three-gap census should be phrased as a two-stage theorem, not as a
raw residue classification.

For a primitive 13-speed row `S`, put the observer and the thirteen runner
residues on the denominator-14 clock at `t=a/14`, `a in (Z/14Z)^*`.  Retain
collisions as zero cyclic gaps.  This gives a **Steinhaus gap word** of length
`14`:

```text
G_a(S) = cyclic gaps of {0} union {a*s mod 14 : s in S}.
```

Also define the **apex-lock** predicate:

```text
max_a min_s distance_14(a*s,0) = 1.
```

If the maximum is greater than `1`, some denominator-14 unit point already gives
strict slack `M(S)>1/14`.  If the maximum is `0`, a multiple of `14` blocks the
apex point.  Thus tight rows can live only in the apex-locked boundary, while
covering rows must be handled by off-apex/analytic arguments.

## Exact findings from S123

The AP row has uniform gap word at every denominator-14 unit:

```text
gap partition ((1,14)), Steinhaus energy 0.
```

The Goddyn-Wong row `{1,...,11,13,24}` has exactly one collision and one missing
clock slot at every unit:

```text
gap partition ((0,1),(1,12),(2,1)), Steinhaus energy 2.
```

The important warning is that this coarse gap word is **not sufficient**.  The
row `{1,...,11,13,36}` has the same one-collision/one-gap partition and is
apex-locked, but it is globally loose:

```text
M({1,...,11,13,36}) = 3/41 > 1/14,
argmax = 17/41.
```

Likewise, the covering row `{1,...,11,13,84}` has the same coarse gap partition
but is apex-blocked by the multiple of `14` and escapes off apex:

```text
M({1,...,11,13,84}) = 7/89 > 1/14.
```

So the missing theorem is not "classify denominator-14 residue profiles."  It is
the stronger statement that every apex-locked non-AP/GW reduced row has an
off-apex escape.

## Sharp proof target

The revised STAR route is:

```text
1. denominator-14 sequence filter:
   direct slack / apex-locked / apex-blocked is finite and exact;

2. off-apex escape theorem:
   every non-AP/GW apex-locked reduced row has M(S)>1/14;

3. covering/scale-separated rows:
   use the existing comb/Weyl/equidistribution machinery, since a multiple
   of 14 blocks the apex clock and residue-only arguments cannot certify them.
```

This makes the three-gap rigidity characterization more honest and more
usable.  The AP/GW rows are the only tested rows where the apex-lock survives
the global exact-M check without escaping off the denominator-14 clock.  The
next proof obligation is to turn that into a theorem, probably by bounding the
first off-apex binding-pair denominator generated by any non-GW lift of the
one-collision/one-gap packet.
