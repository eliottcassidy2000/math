# HYP-2892: q=3 unital pair frame and Hodge refinement for the LRC14 residual leak

This refines HYP-2891.  The unital/Clebsch/truncated-octahedral prompt does
not close LRC14 by a new analogy, but it gives a sharper finite carrier split
for HYP-2890's residual leak:

```text
positive same-frequency additive-energy packet
  + pair-packet tight frames
  + Coxeter/octahedral curl bounds for labelled residuals
  => AP-facing residual-leak inequality.
```

The useful principle is the same one that corrected scalar additive energy in
HYP-2889: choose the right finite quotient before scalarizing.

Post-rebase guardrail from KPS S31m/S31n: this is not a sparse-design
exact-tiling route.  The structured difference-closed threshold tilers are the
full residue system `Z_14 \ {0}` and its dilates, while the Goddyn-Wong
`{1,...,11,13,24}` row is a sporadic tight tiler outside that class.  The
`q=3` unital below is only a pair-slot averaging frame for the k=8 residual
after the HYP-2890 same-frequency packet has been subtracted.

S107/HYP-2894 adds the realizability guardrail: the `q=3` unital cannot be
realized as a canonical `S8`-invariant four-edge block design on the `K8`
pair slots.  Any useful unital application therefore needs a labelled or
weighted category-1 map from the AP-dilate plus Goddyn-Wong tight-locus atlas.

### 1. The q=3 Hermitian unital is a k=8 pair-slot frame

MathWorld's combinatorial unital has parameters

```text
v=q^3+1, block_size=q+1, lambda=1.
```

For `q=3`, the exact Hermitian construction over `GF(9)` gives:

```text
points=28
secant blocks=63
line intersections={1:28, 4:63}
point replication r=9
pair replication lambda=1
```

This is proof-relevant because

```text
28 = C(8,2).
```

Thus the `q=3` unital can be read as a tight frame on the pair slots of the
k=8 AP/difference-profile layer.  Its incidence matrix satisfies

```text
N^T N = 8 I + J.
```

Each block has size `4`, matching the arity of additive-energy quadruple
packets.  A plausible k=8 finite certificate would map pair slots to unital
points and prove every unital block has nonpositive labelled residual leak
after subtracting the same-frequency `A*` packet.

### 2. Clebsch is a folded-cube parity frame

The Clebsch graph prompt contributes a second tight finite smoother:

```text
vertices=16, edges=40, degree=5
SRG parameters=(16,5,0,2)
closed neighborhoods form a 2-(16,6,2) design
closed_neighborhood^T closed_neighborhood = 4 I + 2 J.
```

This is not a direct replacement for the unital pair-slot frame.  Its best use
is a folded-cube/parity quotient for labelled residual packets: it is
triangle-free, pair-uniform after adding loops, and has only the folded parity
information retained.  That is exactly the kind of finite smoothing that scalar
energy loses.

### 3. The truncated octahedral graph is the Coxeter curl carrier

The truncated octahedral graph is the Bruhat/Cayley graph of `S4` generated by
adjacent transpositions.  The exact audit gives:

```text
vertices=24, edges=36, degree=3
edge colors s1,s2,s3 each occur 12 times
square commutation faces=6
hex braid faces=8
cycle rank=13
face count=14 with one spherical relation.
```

This is the cleanest explanation of why one-step compression in HYP-2889 is
false.  A local edge move can lower `p0`; the invariant object is not an edge
monotone but the curl around Coxeter square and braid hexagon faces.

The finite low-depth residual-leak atlas should therefore treat local
compression defects as a 1-cochain on the truncated-octahedral graph, then
prove that all square/hex curl is either a finite AP/Freiman wall or has the
right sign after the HYP-2890 same-frequency packet is subtracted.

### 4. HYP-2887 is the support-six octahedral subcarrier

The existing HYP-2887 carrier reappears as the smaller line graph `L(K4)`:

```text
vertices=6, edges=12, degree=4
cycle rank=7
triangular faces=8 with one spherical relation.
```

So the graph prompt is not random.  The truncated-octahedral Coxeter complex is
a local-compression/curl carrier, while the octahedral `L(K4)` complex is the
support-six repeated-packet subcarrier.  Both are Hodge-style statements on a
sphere: control divergence and face curl, and no independent harmonic current
remains.

## Proof target


HYP-2892 proposes a carrier split, subordinate to the HYP-2891 labelled

```text

  q=3 unital frame for k=8 pair slots, Clebsch folded-cube frame for parity packets

labelled residual part:
  truncated-octahedral Bruhat curl for local compression defects
  octahedral L(K4) curl for repeated support-six packets
```

The next concrete computation is to attach the S104 residual-leak value


to Bruhat edges and square/hex faces for low-depth near-AP rows, especially the
k=9 pressure row `(0,2,4,6,7,8,10,12,14)`.  If all positive edge leaks are
face-curl boundaries or unital/Clebsch block averages, the residual-leak lemma
becomes a finite Hodge certificate plus the existing HYP-2636 tail.
