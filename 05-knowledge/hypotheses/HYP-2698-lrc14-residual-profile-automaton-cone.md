# HYP-2698 - Residual-Profile Automaton Cone

## Claim

The residual profiles in HYP-2697 should be represented as generated words

```text
x -> w_x(R),    R subset {1,...,6},
```

not merely as arbitrary averaged vectors in `Q^64`.  At fixed slow coordinate
`x`, adding an independent carrier updates the residual mask distribution by a
finite OR/deletion automaton on the 64 sector masks.  The proof target is to
characterize the cone generated by these automaton words and prove the
consecutive-block compression inequality against that generated cone.

The better coordinate is the pointwise miss-zeta transform

```text
Z_x(A) = Pr(A is contained in the residual mask at slow coordinate x).
```

For a context made of independent clusters `C_i`,

```text
Z_context,x(A) = product_i Z_C_i,x(A).
```

This factorization happens before averaging over `x`.  Thus the generated cone
is not the full positive orthant and not even just the convex hull of averaged
residual profiles; it is the image of product words under the final
`x`-integration.

## Evidence

The exact scout
`04-computation/lrc14_residual_profile_automaton_cone_codex_s63.py` stores its
run in
`05-knowledge/results/lrc14_residual_profile_automaton_cone_codex_s63.out`.

S63 also corrected the exact arbitrary-shape wall refinement used by S62/S63:
for a random-phase carrier with offsets `C`, the hit-mask law changes when
pairwise offset-difference cuts cross, so the breakpoint set must include
denominators `7*|a-b|` for `a,b in C`, not only `7*|a|`.  This matters for
nonconsecutive shapes; coherent blocks already contained all their pairwise
differences.

For coherent-block contexts of size `r=0..8` (integer partitions as in
THM-557), the generated residual profiles are a small family: `1,1,2,3,5,7,11,
15,22` contexts respectively.  Their supports are constrained even when they
eventually reach most or all of the 64 masks.  Examples:

```text
r=5: support range 59..63, dominant layers 2 or 3
r=6: support range 60..64, dominant layers 1 or 2
r=8: support range 60..64, dominant layers 0, 1, or 2
```

The pointwise miss-zeta factorization was checked exactly for context
`(4,2,1)` at `x=5/37`; for instance

```text
Pr({1} still missed)       = 131274/469567
Pr({1,2} still missed)     = 60000/469567
Pr({4,5,6} still missed)   = 19436/469567.
```

Most importantly, the S62 coordinatewise counterexamples all lose against every
coherent generated context scanned for total nonzero cluster size `m=7..11`:

```text
K=(0,1,2),     C=(0,1,3):       worst margin 20/16807
K=(0,1,2,3),   C=(0,1,2,4):     worst margin 37/16807
K=(0,1,2,3,4), C=(0,1,2,3,5):   worst margin 199/24010
```

An exact frontier scan of near-consecutive challengers also found no coherent
generated-context failures:

```text
size=3: 4 challengers, 240 tests, worst 20/16807
size=4: 7 challengers, 287 tests, worst 37/16807
size=5: 8 challengers, 224 tests, worst 199/24010
size=6: 8 challengers, 144 tests, worst 12027/2352980
```

The weakest contexts are all-singleton or near-all-singleton contexts.  This
points to a sharper lemma: prove compression first for the singleton-product
word, then show merging singleton context carriers into coherent blocks only
improves the margin.

For all-singleton contexts the cone inequality collapses exactly to a
hit-count kernel.  If `r` independent singleton carriers form the context and
the candidate hit mask has size `h`, then the context covers the remaining
`6-h` sectors with weight

```text
g_r(6-h) = 7^-r * sum_{j=0}^{6-h} (-1)^j binom(6-h,j) (7-j)^r.
```

The script asserts that this hit-count formula equals the direct 64-mask
computation for the weakest singleton cases.  The corresponding exact margins
are the same four frontier minima:

```text
r=4, size 3: 20/16807
r=3, size 4: 37/16807
r=2, size 5: 199/24010
r=5, size 6: 12027/2352980.
```

## Rule-110 Analogy

The analogy is structural, not literal: Rule 110 is useful because a simple
binary local update generates a constrained language of space-time words rather
than arbitrary binary arrays.  Here the local update is sector-mask OR
convolution / residual deletion; tournaments likewise evolve by local edge-bit
choices.  The intended transfer is "keep the generated word and update law
until the proof scalar is forced," not "replace LRC by Rule 110."

Matthew Cook's Rule 110 proof is a useful warning label: universality comes
from gliders on a periodic background generated by a local rule, so the
generated language is the object.  In HYP-2698 the analogue is much more
monotone: residual sectors can only be deleted.  That monotonicity is exactly
why the miss-zeta product coordinate is plausible.

Source anchor for the analogy: Matthew Cook, "Universality in Elementary
Cellular Automata," Complex Systems 15(1), 2004,
`https://www.complex-systems.com/abstracts/v15_i01_a01/`.

## Proof Route

1. **Pointwise generated cone.**  Work with `Z_x(A)=Pr(A subset residual)`.
   Prove and use the exact product law `Z_context,x=prod_i Z_i,x`.
2. **Singleton-product base lemma.**  Prove the all-singleton context case as a
   hit-count majorization inequality using the explicit kernel `g_r`.
3. **Möbius lift.**  Recover the residual distribution `w_x(R)` by Möbius
   inversion only after the product structure has been used.
4. **Compression inequality.**  Prove
   `int sum_R w_x(R)(q_K,x(R)-q_C,x(R)) dx >= 0` for product words generated by
   allowable contexts.
5. **Context extremizer.**  Exact evidence says all-singleton contexts are the
   weakest coherent contexts for the S62 challengers.  Try to prove this
   context-side extremality and then combine with THM-557.
6. **Label handoff.**  Keep enough sector labels to hand off near-equality
   cases to HYP-2696/THM-558's unpaid-closure transfer-tax classifier.
