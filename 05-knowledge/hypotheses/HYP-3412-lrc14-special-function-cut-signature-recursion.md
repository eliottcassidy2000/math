## Claim

The useful content of the Bring radical / Schwarz-Christoffel / BDH / Menger /
Soldner / Sophie Germain / HLW / Krasner / Mertens prompt set is not a new
black-box theorem import.  It is a recursive signature discipline:

```text
compressed signature is legal only when the theorem exit is constant on its
fibers; otherwise add the first sidecar exposed by a mixed fiber or cut.
```

On the HYP-3406 expanded bank through `(single_limit,two_swap_limit)=(72,20)`,
the live separator remains endpoint-owner data, but two compressed
owner-derived signals are surprisingly strong:

```text
residue + Schwarz-Christoffel-style cut_angle_word  -> 0 mixed fibers
residue + Krasner-style local radius word           -> 0 mixed fibers
residue + full endpoint owner support               -> 0 mixed fibers
```

Meanwhile BDH-style variance, Sophie-quartic splitting, the honest Bring
branch alarm, and a small PGF/root-curve proxy do not by themselves kill every
mixed theorem-exit fiber on this bank.

So the next proof-facing hypothesis is:

> endpoint-owner support may admit a lower-payload cut/current or local-radius
> compression, but only if that compression is proved to preserve theorem-exit
> purity on enlarged banks and not merely tuned to the present sample.

## Concept Translation

- Bring radical: not a solution method here; it is an alarm for unresolved
  degree-five or branch payload.  If a quotient crosses the Abel-Ruffini wall,
  keep branch data instead of scalarizing.
- Schwarz-Christoffel mapping: endpoint-owner supports become boundary turn
  words.  On the scanned bank, `cut_angle_word` is as separating as full owner
  support.
- Barban-Davenport-Halberstam: use mean-square residue fluctuation as a
  variance ledger.  It leaves `2` mixed fibers here, so it is diagnostic rather
  than terminal.
- Menger cuts: mixed fibers should be studied as source-sink ambiguity graphs.
  A useful sidecar is a small separator hitting all bad paths.
- Ramanujan-Soldner constant: useful only as a first-zero normalization motif;
  do not treat the numerical constant as LRC evidence.
- Sophie Germain identity: verified for `64` small integer pairs in the script;
  useful as a quartic split / degree-four guardrail, not as a terminal proof.
- Hermite-Lindemann-Weierstrass: a reminder that ordered analytic branches
  cannot be collapsed just because symmetric shadows agree.
- Krasner's lemma: the best new concrete signal after SC is a local owner ball;
  same local radius may let a theorem exit lift stably.
- Meissel-Mertens: a residual correction ledger after a main density term; on
  this bank, residual variance cannot replace owner/cut data.
