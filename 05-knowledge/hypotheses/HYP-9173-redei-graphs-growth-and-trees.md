title: "Redei graphs (spanning oriented graphs with an odd embedding count in every n-tournament): (a) the largest has r(n) = o(u(n)) arcs, possibly linear in n; (b) a tree is good (every orientation parity-rigid) iff it is hereditarily symmetric (every subtree has a nontrivial automorphism); (c) for n >= 8 the Redei 'path + chords' graphs are exactly P_n and P_n + (0, n-1) (n even), resp. P_n and P_n + {(0, n-2), (1, n-1)} (n odd)"
status: >
  OPEN.
  (a) r(n) = 0, 1, 2, 4, 6, 8, 9, 10, 11 for n = 1..9 (FINITE-EXACT), against u(n) = 1, 2, 4, 6, 8, 9, 11, 14 (n = 2..9).
  The gap u - r = 0, ..., 0, 1, 3 opens at n = 8.
  (b) Proved in one direction: hereditarily symmetric trees are good, and asymmetric trees are not. FINITE-EXACT for all
  trees on <= 8 vertices, where a tree is not good iff it contains the spider S(1,2,3).
  (c) FINITE-EXACT for n <= 9; PROVED for n = 10, 11 by heredity plus explicit witnesses; reduces to finitely many explicit
  refutations per n.
