# HYP-1790: Merged SC Collision Columns Are Ternary

## Statement

In complement-merged endpoint transfer, every self-complementary child column
that is not private has odd support exactly `3`.

Equivalently, each non-private SC child node is reached oddly from exactly
three merged parent nodes.

## Evidence

Exact transitions `2->3` through `6->7`:

```text
non-private SC columns: [0, 0, 0, 1, 14]
non-private SC support spectra:
  2->3: {}
  3->4: {}
  4->5: {}
  5->6: {3: 1}
  6->7: {3: 14}
```

The first collision:

```text
child n=6: H=29, good-cut=5, owners have good-cut tuple (3,4,4)
```

At child `n=7`, the owner good-cut tuples of the 14 collision columns are:

```text
{(3,4,5): 1, (3,5,5): 2, (4,5,5): 2, (5,5,5): 9}
```

The child Hamiltonian path counts in these 14 columns are:

```text
[41, 61, 71, 79, 83, 91, 115, 127, 133, 141, 143, 151, 159, 159]
```

## Interpretation

The merged endpoint boundary says SC columns have odd support. Private columns
are support `1`; HYP-1790 says the first failure mode is not arbitrary odd
support but exactly support `3`.

This makes the collision layer look like a ternary relation:

```text
three parent nodes  --->  one strongly connected SC child pivot collision.
```

That arity echoes other tournament threads where triples are the first
irreducible obstruction: directed 3-cycles, beta-3 generators, and the
Krawtchouk/cubic residual. This may be the endpoint-transfer version of the
same cubic obstruction.

## Geometry Refinement

HYP-1792 rules out the strongest naive geometric reading.  The three owner
parents are not necessarily a triangle in the parent merged arc-flip graph.
At `6->7`, their induced edge counts are `{0:1,1:6,2:5,3:2}`.  Thus the
support-3 relation is endpoint-transfer incidence geometry, not ordinary
metagraph clique geometry.
