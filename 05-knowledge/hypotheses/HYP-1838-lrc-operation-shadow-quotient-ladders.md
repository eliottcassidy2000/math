# HYP-1838: LRC quotient ladders are operation-shadow residues

## Statement

The recursive Lonely Runner denominator tower is seeing the same operation
shadow split as the natural-number mode graphs:

```text
addition       -> transitive completion
multiplication -> divisibility residue
```

For threshold denominator `n`, the LRC unit endpoint skeleton is the additive
completion/equality layer, while composite quotient ladders are the
multiplicative residue layer.  The first quotient ladder should be controlled
by the largest proper divisor of `n`.

## Evidence

`lrc_operation_shadow_bridge_s377.py` combines the S365 operation graph metrics
with the stored S376 LRC recursive atlas.

In the stored exact LRC rows `n=2..18`, every composite denominator with a
quotient ladder has best ladder divisor equal to the largest proper divisor:

```text
n=4,6,8,9,10,12,14,15,16,18: ladder_d = lpd(n)
```

The new exact largest-proper-divisor scan reproduces the same stored best
ladder channel in those rows:

```text
n=14: lpd=7,  best skip=6,  gap/th=0.005411, unprotected=84
n=16: lpd=8,  best skip=14, gap/th=0.007576, unprotected=140
n=18: lpd=9,  best skip=8,  gap/th=0.005682, unprotected=176
```

The composite pressure ranking by `unprotected endpoints / gap_ratio` starts:

```text
n=18, n=16, n=14, n=15, n=12, n=10.
```

This makes `n=14` feel less isolated: it is the first high-pressure member of
a larger largest-proper-divisor quotient family.

The bridge also compares product-sum defect data.  In product-sum equations,
ones repair multiplicative excess:

```text
prod(C) - sum(C) = number of ones.
```

In LRC, unit endpoints are the boundary mass that must be protected by
denominator-divisible speeds.  Both are places where additive slack repairs a
multiplicative defect, and both preserve the leak data of the repair.

## Predictions

1. For every composite denominator `n`, the best quotient-ladder family among
   one-divisor ladders is generated by `lpd(n) = n / spf(n)`.
2. A full all-divisor search may have rare ties, but any strict non-`lpd`
   winner should coincide with a multi-factor product-sum packing transition.
3. The first useful LRC endpoint-transfer matrix should use divisor-DAG rows:
   unit layer, `lpd(n)` quotient layer, then lower divisor layers.
4. The high-pressure sequence `18,16,14,15,...` should predict where
   endpoint-protection proofs need more than scalar-puncture curvature.
5. Product-sum multi-factor wins at arities `5,8,11,12,13,14,17,18,...`
   should be compared against LRC transition events, because both indicate
   that a binary divisor layer is no longer the whole story.
