# HYP-3053: Tournament diagonal-layer flow and half-tiling quotient laws

## Claim

The user's diagonal tiling model has a clean algebraic carrier.

Read a labelled `n`-tournament as a binary upper-triangular half-tiling.  Up
to reversing the diagonal order, the tile layers have sizes
`1,2,...,n-1`.  Between consecutive layers of sizes `k` and `k+1`, the
proposed `k^2+k` lines are the edges of `K_{k,k+1}`.

If a line records the parity/equality observation `x_a + y_b` over `GF(2)`,
then the line system is the coboundary/cut-space map

```text
delta : F_2^V -> F_2^E,
delta(x)(uv) = x_u + x_v.
```

For the complete bipartite line block,

```text
line_count = k(k+1)
rank       = k + (k+1) - 1 = 2k
redundancy = k(k+1) - 2k = k(k-1).
```

Equivalently, the `k(k+1)` lines are a cut-space presentation, not
independent state.  A spanning-tree basis of `2k` lines determines every
other line by

```text
L(a,b) = L(a,b0) + L(a0,b) + L(a0,b0).
```

The redundancy is not noise.  It is exactly the cycle space of `K_{k,k+1}`,
generated by rectangle laws

```text
L(a,b) + L(a,b') + L(a',b) + L(a',b') = 0.
```

Thus the inter-layer flow is an efficient duplication law: store layer
potentials, not all pair lines; keep 4-cycle failures as consistency
certificates or as evidence that an omitted sidecar is carrying real data.

Globally, adjacent-layer flow through all full tournament tiles has

```text
tiles       = C(n,2)
lines       = sum_{k=1}^{n-2} k(k+1) = 2*C(n,3)
rank        = C(n,2) - 1
redundancy  = 2*C(n,3) - C(n,2) + 1.
```

The global redundancy decomposes as

```text
2*C(n,3) - C(n,2) + 1 = 2*C(n-1,3) + C(n-2,2).
```

Here `2*C(n-1,3)` is the sum of local rectangle cycle spaces, while
`C(n-2,2)` counts the extra hourglass cycles spanning adjacent layer bridges.

The only invisible bit for pure XOR line observations is global complement.
For the fixed Hamiltonian path half-tiling, the free nonpath tiles have

```text
tiles       = C(n-1,2)
lines       = 2*C(n-1,3)
rank        = C(n-1,2) - 1       (n >= 3)
```

So the user's `k^2+k` lines are most useful as a high-redundancy proof
carrier, not as independent data.

## A000568 Reading

The exact relation to A000568 is:

```text
unlabelled tournaments on n vertices
  = binary upper-triangular half-tilings on n labels / S_n.
```

A fixed Hamiltonian path gives a smaller half-tiling cube with
`C(n-1,2)` free nonpath bits.  By Redei, every tournament has a Hamiltonian
path, so this cube surjects onto the A000568 classes.  It is not a bijection.
For ordered Hamiltonian paths, the fiber over an isomorphism class `T` is

```text
fixed-path presentations of T = H(T) / |Aut(T)|,
```

where `H(T)` is the number of Hamiltonian paths and `Aut(T)` is the automorphism
group.  The automorphism group acts freely on Hamiltonian paths, so the fixed
path bitstrings are Hamiltonian-path orbits.

The S217 script verifies this through `n=6`:

```text
n=3: fixed_tilings=2    iso_classes=2   fiber_hist={1: 2}
n=4: fixed_tilings=8    iso_classes=4   fiber_hist={1: 3, 5: 1}
n=5: fixed_tilings=64   iso_classes=12  fiber_hist={1: 4, 3: 1, 5: 3, 9: 2, 11: 1, 13: 1}
n=6: fixed_tilings=1024 iso_classes=56  H_over_Aut_check=True
```

This sharpens the "smaller half-tiling" idea.  Fixed-path half-tilings are a
cover of A000568 classes.  A000568 is obtained only after quotienting by the
full relabelling/path-presentation redundancy.

Path reversal plus tournament converse acts as diagonal reflection on the
fixed-path half-tiling bits.  That `Z2` quotient is useful but still far too
large:

```text
n=4: U(n)=4,  Z2 fixed-path quotient=6
n=5: U(n)=12, Z2 fixed-path quotient=40
n=6: U(n)=56, Z2 fixed-path quotient=544
```

So diagonal symmetry is a sidecar quotient, not the A000568 quotient itself.

## Duplication Laws

The tiling model exposes three levels of duplication.

1. **Local rectangle duplication.**  Inside each `K_{k,k+1}` layer bridge,
   all redundant line observations are generated by 4-cycle parity laws.
2. **Global potential duplication.**  All adjacent-layer line observations
   reconstruct the half-tiling only up to global complement, with rank
   `#tiles - 1`.
3. **Hourglass duplication.**  After summing local rectangles, the global
   adjacent-layer graph still has `C(n-2,2)` bridge-to-bridge cycles.
4. **Presentation duplication.**  Fixed-path half-tilings duplicate an
   unlabelled class by `H(T)/|Aut(T)|`; diagonal path-reversal/converse
   symmetry removes only one visible `Z2` part of that duplication.

For LRC this suggests a proof-carrier rule:

```text
do not count duplicated lines;
classify the generator of the duplication.
```

This is the same lesson as HYP-3021/HYP-3022 for pair-good decoys and
HYP-3031/HYP-2991 for Haar/fixed-margin squares.  The proof object is the
lane/shell/rectangle generator and its owner or barcode relation, not the raw
number of false switches or inter-layer lines.

## LRC Translation

The layer-flow carrier should be attached to labelled LRC packets as a
sidecar with fields like:

```text
tile_layer_id
interlayer_bridge_id
rectangle_cycle_basis_id
line_potential_word
cycle_defect_word
fixed_path_presentation_count
path_reversal_converse_orbit
owner/barcode support on each line
```

If the line observations satisfy every rectangle law, the line system can be
compressed to layer potentials.  If a rectangle law fails after adding LRC
payload, the failed rectangle is a named hidden-coordinate witness: an
endpoint owner, barcode bar, active normal-fan support, route label, or
proof-obligation sidecar was not actually redundant.

The rank statements above are only for the XOR/equality shadow.  Once a line
carries owner labels, directions, active bottleneck data, barcode support, or
other nonlinear LRC payload, the graph is the skeleton and the extra payload
must be checked by sidecar equations.

This gives an algebraic version of the controlled-forgetting rule:

```text
line quotient is legal
  only if every rectangle defect is zero,
  every hourglass residue is zero,
  reconstructed from layer potentials,
  dual-annihilated,
  descended familywise,
  or routed to named residual debt.
```
