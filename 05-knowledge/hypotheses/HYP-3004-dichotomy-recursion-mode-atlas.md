# HYP-3004: Dichotomy Recursion Mode Atlas

## Claim

The repo's repeated dichotomies are not separate metaphors.  They are mode
switches for deciding which coordinate a quotient is allowed to forget:

```text
odd/even                unit propagation vs 2-adic projection defect
positive/negative       observer-blind gauge vs pair-visible cut
addition/multiplication denominator pincer vs unit/product orbit
+1,/2                   affine residue defect vs valuation descent
*2,+2                   vertical 2-adic tree descent vs horizontal line motion
sum/product/fraction    aggregate -> factor -> boundary memory -> next aggregate
```

The useful abstraction is a labelled switchboard:

```text
binary split + preserved predicate + destroyed coordinate + recursion law.
```

Used alone, each split becomes a false scalar quotient.  Used with its retained
labels, it routes LRC14 packets to the correct proof currency.

This is the mode-switch companion to HYP-3002's curried packet functional tower:
the curried tower says a quotient is a partial evaluation, while this atlas says
common dichotomies are the partial-evaluation modes that most often destroy or
preserve LRC proof data.

After rebasing onto S171, HYP-3003/LTI-153 is the narrower
summand/multiplicand Farey-basis merge.  This atlas keeps that as its
add/multiply subcase and broadens the same guardrail to parity, sign, dyadic,
Collatz, triune, smoothing, and other recursion modes.

## Why This Helps

The same guardrail recurs across the prior work:

- Odd/even is not just parity.  It is whether doubling stays inside an orbit or
  collapses a CRT coordinate.
- Positive/negative is not extra freedom for LRC witnesses.  It is an
  observer-blind cover whose cuts expose pair-sum shell partners.
- Addition/multiplication is not a choice of arithmetic taste.  Addition creates
  endpoint denominators; multiplication transports witness orbits and product
  shells.
- `+1,/2` and `*2,+2` are recursion-mode pairs.  One side is affine or
  archimedean motion; the other is valuation depth.
- Sum/product/fraction/recursion is the projection-repair cycle: aggregate,
  factor, remember the boundary branch, then unroll to the next aggregate.
