# HYP-3102: LRC14 First-Obstruction Cocycle Generation

## Claim

HYP-3095 says the remaining LRC14 proof should be a gluing theorem over
observer charts.  HYP-3071 says the first legal sidecar tooth and the
cycle-class image are already visible in exact residual matrices.  HYP-3102
turns those facts into a single obstruction-theory target:

```text
Every illegal quotient or failed chart overlap emits a first obstruction
cochain.  The quotient is legal only if that cochain is zero, exact,
generated by named certificate cycles, dual-annihilated, descended to a
smaller family, stopped at AP/GW boundary equality, or routed to the named
F7/THM-572 state-lift coordinate.
```

This is the controlled-forgetting ladder in cohomological form.  It is not a
new scalar invariant.  It is a finite syndrome calculus for deciding when a
forgotten observer-extension payload has been paid for.

## The Object

For a quotient `q:X -> Y` and a next observer/cut operation `o`, let

```text
sigma_q,o(x) = observer-extension cut payload of x
```

be the hidden coordinate that the quotient would like to forget.  On a fiber
pair `(x,x')` with `q(x)=q(x')`, define the first difference

```text
omega_q,o(x,x') = sigma_q,o(x) - sigma_q,o(x').
```

The quotient is legal for the LRC predicate only if `omega_q,o` is discharged.
The possible discharge modes are:

```text
zero_on_fiber
reconstructed_by_sidecar
coboundary_or_cycle_boundary
dual_annihilated_by_certificate
familywise_descended
AP_GW_boundary_stop
F7_THM572_state_lift_debt
```

HYP-2997 already framed this as a cocycle normal-form atlas.  HYP-3054 and
HYP-3056 turned the missing coordinate into an observer-extension/cut payload
orbit.  HYP-3071 supplied the first exact residual matrix.  HYP-3102 asks for
the theorem that joins them.

The incoming S258 observer-gluing scout is the zero-th instance of this
syndrome language.  It places direct component data, CRT lift status,
pair/Pascal scissors shadows, mod-7/mod-14 residue signatures, Farey lanes,
destroyed coordinates, and terminal exits on the same sample rows.  Its
conclusion is not that any one chart wins; live residual rows still carry debt
in the normalized arc chart, moment/Perron chart, branch/K33 shuttle chart,
finite denominator budget, and uniform component bound.  HYP-3102 turns that
list of debts into first obstruction coordinates rather than informal TODOs.

The incoming S64/THM-577 cap result also matters here.  It makes the
pair/Pascal cap values for `k>=10` symbolic through the closed-form forbidden
arc overlap formula.  In the obstruction basis below, that means
`pascal_pair_mass_defect` should be tested as a generated/finite-remainder
coordinate before it is treated as an independent obstruction.

## Exact Sequence Target

The finite-address packet sheaf should admit an exact obstruction sequence of
the following form:

```text

  --d0-->
C^1(route/status-changing overlaps)
  --d1-->
C^2(route triples)
  -> H_obs
```

and a certificate map

```text
Cert_cycles -> H_obs.
```

The proof target is:

```text
For every THM-573 residual packet, its first nonzero obstruction class in
H_obs is either in the image of Cert_cycles, dual-annihilated, descended,
AP/GW boundary-stopped, or equal to the named phantom F7 coordinate that
must be handled by a THM-572 state lift.
```

Read this way, the HYP-3071 rank calculation becomes a theorem-shaped
statement.  The template basis has `13` atoms and known generators of rank
`12`; the single intentionally unspanned atom is `phantom_f7_class`.  The
remaining task is to replace the template rows with actual HYP-2963 packet
cochains and prove that the rank behavior is stable under the finite-address
normalizer.

## The Controlled-Forgetting Ladder

The ladder for a proof quotient is:

```text
level 0: scalar shadow
level 1: observer/cut payload
level 2: first obstruction cochain
level 3: certificate-cycle generation or dual annihilation
level 4: state-lift / F7 named debt
```

A quotient may descend one level only if the next level is retained or
discharged.  This is the same rule behind the A000568 observer-extension
payloads, the AP/GW owner-current boundary atoms, rectangle/hourglass residues,
Haar zeta squares, primitive-period decks, partial-cube Theta classes, and the
K33 state-lift target.

The useful cross-disciplinary translations are:

- sheaf/Čech cohomology: chart overlaps carry obstruction classes;
- Hodge decomposition: split exact, coexact/dual-annihilated, and harmonic/F7
  components;
- electrical networks and chip-firing: endpoint-owner currents are divergence
  or boundary potentials;
- error-correcting codes: sidecars are parity checks and obstruction classes
  are syndromes;
- Kalman observability: sidecar columns must separate route/status fibers;
- matroid circuits/cocircuits: endpoint walls and proof cycles generate the
  same finite dependency language;
- discrete exterior calculus: d0/d1 are the actual finite coboundary maps;
- obstruction theory: a local chart family glues exactly when the first
  obstruction vanishes or is killed by a named lift.

The incoming S31ah tournament-certificate engine supplies useful vocabulary
for this ledger: H-spectrum, Redei-parity, Landau score constraints,
cycle-census, forbidden-Omega, Newton/real-rootedness, transfer symmetry,
H-max, and winding encodings are all certificate generators only after their
retained vertex set is declared.  The S65 baby-Hodge cross-check adds a
separate warning: the `(c3,c5)=(8,10)` hole is a `c5`/power-sum exclusion in
the regular score fiber, while the forbidden-H `{7,21}` mechanism is a
different alpha/conflict-graph event.  HYP-3102 must therefore label
obstructions by mechanism, not only by a scalar hole.
