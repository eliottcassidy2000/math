# HYP-9316 — the first homotopy of a curve's derived arc space is a Cramer syzygy

## Setting

Let `f(x, y)` be quasi-homogeneous of weight `d`, with `wt x = a` and `wt y = b`.
- Its derived arc space is the Koszul complex of the jets `f_n = [t^n] f(x(t), y(t))` (weight `d + n`) on
  `C[x_j, y_j]` (weights `a + j`, `b + j`). This is Docampo-Miller-Overton-Walker 2026, Thm 4.2: the derived jets of
  `R//(f)` are `LJ(R)//(f, f', ...)`, with homotopy the Koszul homology (Rem. 4.5).
- The Euler characteristic is `E(t) = Π_(n>=0)(1 - t^(d+n)) / Π_(j>=0)((1 - t^(a+j))(1 - t^(b+j)))`.
- `H_0` is the arc algebra, and `HS(H_0) = E` exactly below the first weight `w_1` with `H_1 ≠ 0`.
- For the cusp (`a, b, d = 2, 3, 6`), kind-pasteur found `HS(H_0) = E` through weight 33 and different at 34
  (13436 vs 13435).

## Mechanism

Suppose `K + 1` consecutive jets `f_s, ..., f_(s+K)` lie in a **proper** ideal `Q = (h_1, ..., h_K)` generated by `K`
monomials of positive weight in the jet variables.
- Write `f_l = Σ_j A_(lj) h_j`.
- Cramer's rule gives `Σ_l (-1)^l det(A_l) f_l = 0`, where `A_l` is `A` with row `l` deleted.
- This syzygy has weight `w(Q) = Σ_l (d + l) - Σ_j wt(h_j)`, and it is nonzero when `A` has rank `K`.
- The unit ideal must be excluded. `Q = (1)` with `K = 1` gives `f_1 e_0 - f_0 e_1`, which is a Koszul boundary.

**Cusp.** On the contact locus `x_0 = x_1 = y_0 = y_1 = y_2 = 0` (arcs with `ord x >= 2`, `ord y >= 3`), `f` vanishes
to order 6. So the six jets `f_0..f_5` lie in a five-generator ideal, and
`w = (6+7+...+11) - (2+3+3+4+5) = 51 - 17 = 34`.
- This is the contact locus computing `lct = codim/order = 5/6`.
- It matches Anderson-Stapledon 2013, Ex. 7.6/8.8: the jet schemes of the weighted cusp are pure-dimensional only for
  `m < 5`.

## Statement

`w_1 = min w(Q)`. The minimum runs over proper ideals `Q` generated by `K` positive-weight monomials in the jet
variables that contain `K + 1` consecutive jets with coefficient matrix of rank `K`.
- **The searched class.** The S44 script searches pure powers of `x_0..x_(i-1)`, `y_0..y_(k-1)` with exponents
  `<= 4`, and the first `K + 1` jets.
- The audit's wider search (pure powers on arbitrary subsets of jet variables `j <= 4`, `e <= 4`, windows starting at
  `f_0`, `f_1` or `f_2`) gives the same minima for all 14 curves tested.

## Context

- **Corrected log-canonical statement** (audit m11). The published lci theorems assume normality. The relevant ones
  are Mustață 2001, Thm 3.4 / Conj. 3.5; Ein-Mustață, Amer. J. Math. 126 (2004), Thm 1.3; and Ein-Mustață-Yasuda
  2003 (normal divisors). A singular plane curve is never normal. For a plane curve `C` the following are equivalent:
  - `dim J_m(C) = m+1` for all `m`;
  - the pair `(A^2, C)` is log canonical (lct = 1) [Mustață, JAMS 15 (2002), Thm 0.1 / Cor. 0.2];
  - `C` has at worst nodes [Mustață 2001, Rem. 4.3];
  - the derived arc space is classical [Docampo-Miller-Overton-Walker 2026, Cor. 4.9 / 4.13].

  When these fail, a contact locus with `codim < order` carries surplus jets in a smaller ideal, which gives a Cramer
  syzygy.
- **Prior art for the framework.** The framework is DMOW 2026 and Gaitsgory-Rozenblyum 2014 (§9.2). The Koszul complex
  of the jets of `x^2`, with `H_1` generated by the Euler syzygies, is in Gorsky-Oblomkov-Rasmussen 2013 (see HYP-9315(a)).
- **What appears new.** The audit found neither of these anywhere in the literature:
  - the Cramer mechanism with `K >= 2`;
  - any of the first-deviation weights (34, 10, 16, 11, 29, 31).
- **W-algebra link** (audit L2). `C[l, w]/(w^2 - l^3)` with weights (2,3) is the C_2-algebra of `W_3` at `c = -2`, and
  `w^2 - l^5` with weights (2,5) arises for `W(2,5)` (Arakawa-Linshaw). So the cusp and A4 gradings are C_2-algebras of
  known W-algebras.
- **Fat points.** For the fat point `x^N` (kind-pasteur S1, section 1.3), the same mechanism with the principal ideal
  `(x_0^(N-1))` containing `f_0, f_1` gives the Euler syzygy at weight `2N + 3`.

## Falsifiers

- A curve whose first deviation is below the predicted minimum.
- A curve whose predicted Cramer syzygy is a Koszul boundary, so that the first deviation lies above the prediction.
