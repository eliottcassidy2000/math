## The equidecomposition (verified + formalized)
A tournament's canonical **equidecomposition** is its strongly-connected-component decomposition: the condensation
is a transitive order on the SCCs, and a Hamiltonian path threads them in that order. So (the **equinumerosity**)
`Ham(T) ≅ ∏ᵢ Ham(SCCᵢ)`, hence **`H(T) = ∏ᵢ H(SCCᵢ)`** — H is multiplicative over the SCC equidecomposition.
Verified: holds on 20000 random tournaments per `n = 2..7`.

## The reframing: forbidden = no atom-factorization
Define an **atom** = an H-value of a *strongly-connected* tournament (the "prime"/indecomposable tournaments).
Then **the achievable H-spectrum = the multiplicative monoid generated by the atoms**, and the **forbidden values =
integers with no factorization into atoms.** This converts the whole forbidden-spectrum question into multiplicative
number theory of the atom set.

### The atom spectrum (computed, exhaustive n≤6, sampled n=7)
`n=3:{3}, n=4:{5}, n=5:{9,11,13,15}, n=6:{15,17,19,23,25,27,29,31,33,37,41,43,45}, n=7:{25,…,189}`. Key absences:
**7, 21, 63 are NEVER atoms** (no strongly-connected tournament has H=7·3ᵏ — the strengthened THM-029/079).

### Why 7·3ᵏ is forbidden (formalized)
`7·3ᵏ`'s only divisors that are multiples of 7 are `{7·3ʲ : j≤k}` (since `7,3` are distinct primes). If none of these
is an atom, then in any atom-product `= 7·3ᵏ`, the prime 7 must divide some atom `a`, forcing `a = 7·3ʲ` — a
contradiction. So `7·3ᵏ` has no atom-factorization ⟹ forbidden. **Formalized (sorry-free):**
`Math/Tournaments/ForbiddenHSpectrum.lean` `forbidden_seven_mul_three_pow` (the full `7·3ᵏ` family from the atom
hypothesis), `forbidden_seven_and_twentyone` (the named `k=0,1` gaps).

## The sharp reduction
The infinite forbidden family `{7·3ᵏ}` now follows **uniformly** from ONE atom statement: *no strongly-connected
tournament has `H = 7·3ʲ`*. THM-029/079 prove `j=0,1` (and computation `j=2`); the conjecture is all `j`. This is the
sharpest target: prove `7·3ʲ ∉ atoms` for all `j` (a single strongly-connected-tournament impossibility), and the
entire `7·3ᵏ` forbidden ladder follows by the formalized arithmetic.
