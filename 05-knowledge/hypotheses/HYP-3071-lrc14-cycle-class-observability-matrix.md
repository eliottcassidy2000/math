# HYP-3071: LRC14 Cycle-Class Observability Matrix

The two remaining proof angles that look most structural are the same object
viewed from two sides:

```text
observability side:
  Which retained sidecar first separates route/status-changing residual pairs?

cycle-class side:
  Which named certificate cycles generate the emitted residual cochain?
```

This hypothesis turns that into a matrix protocol.  Rows are residual proof
obligations.  Columns are either separating sidecars or certificate-cycle
generators.  A residual row is discharged only when it is separated,
generated, dual-annihilated, descended, stopped at AP/GW boundary equality, or
emitted as a named F7/THM-572 class.

Concurrent S233/S234 work claimed the Desargues-median and median owner/root
spine, S235 claimed the medianized route-center gate, and S236/HYP-3070 claimed
the route-triple center-control addendum.  This matrix should therefore not
emit anonymous residual rows: every row should carry `root_object`,
`owner_object`, `median_center_status`, and legal center-control status when
those fields are available, so the cycle-class image is tested after the
owner/root coordinates and route-center obligations that make triples
well-centered.

## Proof Angles

### Angle A: Observability-First Residual Proof

Work fiberwise inside the `15` strict-open residual coarse ET+unit fibers.
The route leak after the coarse gate is killed by the first separating sidecar:

```text
arc topology for 13 fibers,
safe-component stalk for 2 fibers.
```

This suggests a family lemma:

```text
post-status residual route mixing
  => owner-strip arc topology split
  or coarse safe-component stalk split
  before exact M / route fallback.
```

The proof would then use primitive decks, Haar zeta, endpoint-owner currents,
or exact magnitude only after the local tooth order has been exhausted.

### Angle B: Hodge-Style Cycle Generation

Replace every residual row by a cochain in a named coefficient basis.  The
certificate columns are AP/GW boundary cycles, endpoint-owner boundaries,
Ramanujan period characters, Haar zipper squares, observer-cut boundaries,
rectangle/hourglass cycles, partial-cube Theta classes, simplex face
boundaries, Roth-Minkowski walls, octahedral face curls, Toeplitz noncollapse
gates, and K33 state-lift incidences.

The theorem target is:

```text
Every primitive non-AP/GW residual cochain is in the span of named certificate
cycles, dual-annihilated, descended to a smaller family, or mapped to a
specific THM-572/F7 state-lift class.
```

This is HYP-3066 made operational.
