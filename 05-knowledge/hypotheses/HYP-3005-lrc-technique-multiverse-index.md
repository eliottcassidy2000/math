# HYP-3005: LRC Technique Multiverse Index

HYP-3005 records a broad synthesis pass over the repo's tournament,
metagraph, series, analytic-sieve, Haar/Fejer, cocycle, state-lift, and
workflow techniques.  The output is the `LTM-*` annex:

```text
00-navigation/LRC-TECHNIQUE-MULTIVERSE-INDEX.md
```

The annex is meant as a pull-from / contribute-to surface.  It does not claim
to prove LRC14.  It claims that the most useful proof technology now lives in a
typed multiverse of carriers, and that each carrier should declare its vertex
set, pairwise observable, gauge, preserved LRC predicate, destroyed
information, guardrail, and next pull.

## Tournament Analysis

Vertices are technique families, not runners.  Alternate vertex sets were
explicitly considered: runners, gaps, endpoint owners, fixed sections, section
boundaries, wall events, residues, cover arcs, Fourier modes, Haar rectangles,
matroid circuits, Fejer atom banks, state-lift obligations, and proof
obligations.

The pairwise observable compares retained LRC predicate payload:

```text
predicate, exact_scale, topology, endpoint, arithmetic, harmonic, metagraph,
formal, residual, transfer
```

The binary gauge rotates priority by the pair of families and orients toward
the family retaining more of the first differing payload dimension.  Ties use
the Hamiltonian path

```text
proof_sheaf_zipper > tournament_metagraph > packet_families >
topology_boundary_discrepancy > harmonic_fourier_certificate >
arithmetic_sieve_series > analytic_sieve_smoothing >
state_lift_geometry_cross > computation_formal_forum
```

The family tournament fingerprint is:

```text
score_hist={2: 1, 3: 1, 4: 4, 5: 3}
directed_3cycles=26
scc_sizes=[9]
edge_flips_against_tie_path=21
hamiltonian_path_count=2397
```

The all-family SCC is the useful conclusion.  These techniques do not form a
single ladder.  Proof-sheaf, metagraph, packet, topology, harmonic, arithmetic,
analytic, state-lift, and formal/forum carriers can each dominate on different
retained coordinates.

The `n=8` summit projection, using the first eight families, has canonical
edge word

```text
0000011000101000110000000000
```

with `score_hist={2:1,3:2,4:5}`, `directed_3cycles=19`, one SCC of size `8`,
and `591` Hamiltonian paths.  This gives future agents a concrete tournament
isomorphism-class fingerprint to compare against when they revise the family
taxonomy.

## LRC Pull

The immediate proof-facing pulls are:

```text
1. Build the emitted-cocycle C1 matrix on HYP-2963 packet banks.
2. Add exact M/qdiv, Haar class, Ramanujan projector, Fejer manifest,
   endpoint owner, and state-lift debt to packet schemas.
3. Compute source-marked tournament spectra for AP, GW, K33, petal,
   covering, and hard Fejer rows.
4. Run fiber-mixing tests on mu, mu^2/phi, divisor, spectrum, and any
   proposed scalar.
5. Define F7 as a finite state lift, harmonic current, or named cohomology
   class.
```

The challenged assumption is that one vertex type should govern the whole LRC
proof.  HYP-3005 instead treats each proof obligation as choosing its own
faithful tournament vertex set, with the quotient loss stated before any
invariant is trusted.
