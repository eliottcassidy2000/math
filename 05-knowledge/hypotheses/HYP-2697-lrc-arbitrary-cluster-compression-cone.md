# HYP-2697 - Arbitrary Cluster Compression Cone

## Claim

The remaining arbitrary-shape step in HYP-2694 should not be formulated as
coordinatewise stochastic dominance of a consecutive cluster.

For a bounded far-cluster shape `C` and a residual sector set
`R subset {1,...,6}`, define the residual capacity

```text
q_C(R) = Pr_{x,phi}(C covers every sector in R).
```

The tempting compression lemma

```text
q_C(R) <= q_K(R) for all R,
K={0,1,...,|C|-1},
```

is false.  The correct target is a **context-weighted cone theorem**:

```text
For every residual profile w_R generated by a decorrelated LRC context,
sum_R w_R q_C(R) <= sum_R w_R q_K(R),
```

where `K` is the coherent consecutive block of the same size.  Equivalently,
arbitrary bounded shapes may outperform `K` on small residual sets, but LRC
contexts put enough weight on large residual sets that the weighted functional
is still maximized by `K`.

Together with THM-557, this would give the route:

```text
arbitrary shapes
  -> compress by the residual-profile cone to coherent blocks
  -> merge coherent split blocks by THM-557's split gaps
  -> spend cap margin + split gap on HYP-2684 joint carrier error.
```

Incoming HYP-2696/THM-558 supplies a complementary local ledger after this
compression step: once a row is routed into the sector-state insertion model,
`Delta U4=mass(1->0)-mass(5->4)-4 mass(6->5)` identifies exactly which
one-missed closures remain unpaid by high-tail tax.  Thus HYP-2697 should keep
residual profiles labeled enough to hand off compressed contexts to the
transfer-tax packet classifier.

S63/HYP-2698 sharpens the word "generated": at fixed slow coordinate `x`, a
context residual profile should be carried in miss-zeta coordinates
`Z_x(A)=Pr(A subset residual)`, where independent context clusters satisfy the
pointwise product law `Z_context,x(A)=prod_i Z_i,x(A)` before `x`-averaging.
The cone theorem should be proved on these product words, not on arbitrary
averaged residual vectors.

## Tournament Analysis

This hypothesis deliberately changes what may be a vertex.

Possible vertex sets tested in S62:

- cluster shapes;
- residual sector requirements `R`;
- proof lenses / obligations.

For the size-8 shape tournament, edges oriented by full-cover scalar give a
transitive tournament with `K8` as source.  Reorienting by residual-majority on
the same selected shapes keeps the same order in the scout, but the exact
residual-vector failures show that other switches can flip individual edges.
Thus the proof should not scalarize too early: the switch must be the actual
context residual profile.

The proof-lens tournament ranks:

```text
split_vs_single_margin
> single_block_diagonal_freeze
> context_weighted_cone
> full_cover_scalar
> joint_multi_carrier_error
> coordinatewise_residual_dominance
```

The rejected vertex set is "individual residual coordinates with arbitrary
positive weights"; it destroys the LRC predicate by forgetting which residual
profiles can arise from cluster contexts.

## Proof Route

1. **Residual cone characterization.**  Describe the convex cone generated by
   residual profiles of decorrelated cluster contexts.  These profiles are not
   arbitrary; they come from unions of independent carrier laws sharing the
   same slow `x`.  HYP-2698 refines this to a miss-zeta product-word
   characterization.
2. **Consecutive maximizes on the cone.**  Prove the linear inequality
   `sum_R w_R(q_K(R)-q_C(R))>=0` for every context-generated profile `w`.
   The exact counterexamples show this can only hold after using the cone
   restrictions.
3. **Merge coherent blocks.**  Apply THM-557.  Nontrivial splits lose at least
   the explicit split gaps recorded there.
4. **Spend analytic error.**  The joint carrier discrepancy only needs to fit
   inside `cap margin + split gap`, not inside a tiny standalone absolute
   envelope.

## Status

No LRC14 proof is claimed.  HYP-2697 refines HYP-2694 by replacing a false
stochastic-dominance compression with a sharper weighted residual-profile cone
obligation.
