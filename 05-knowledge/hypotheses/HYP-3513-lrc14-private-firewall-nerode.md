# HYP-3513: LRC14 Private-Firewall Nerode Audit

## Claim

HYP-3513 executes the first HYP-3491 follow-up: join the HYP-3474
colored-gate partition-lattice axes to the finite HYP-3490 private-label
firewall split and ask which quotients preserve the new predicate.

The answer is sharper than expected.  Existing HYP-3474 axes already
reconstruct the private-firewall bit and the three-way
`nondead/nonprivate/private` status: `C`, `F`, `N`, and `T` are each pure.
However, no subset of the existing axes preserves the full HYP-3490 route
split.  The route still needs an explicit sidecar `R` or a reconstruction
theorem.

## Assumption Challenge

Candidate vertices considered: runners, arcs, raw row names, colored gate
axes, route sidecars, projection edge labels, touched label multiplicity
classes, component-label incidence, and proof obligations.

The chosen carrier vertices are quotient fibers generated by HYP-3474 axes
and HYP-3490 sidecars.  The quotient preserves `private_firewall_status`,
the stronger `nondead/nonprivate/private` status, and, when `R` is included,
the full HYP-3490 route.

It destroys raw interval geometry, exact gate order, owner-current locality,
and row identity.  The challenged assumption is that the theorem must retain
row names or a bespoke HYP-3490 graph object.  For the private bit, the
existing colored-gate quotient already has enough information; for route, it
does not.

## Proof Pull

The next theorem-shaped target is not another broad quotient search.  It is a
finite incidence-cut lemma proving that the compact sidecars `I` and `Q` are
really just the dead-component/blocker-label multiplicity-one condition, stated
without row names.

The route split remains separate:

```text
private status
  -> existing colored axes C/F/N/T already decide it
  -> I/Q give the compact multiplicity-one formulation
  -> prove the incidence-cut lemma

HYP-3490 route
  -> not preserved by K,N,T,S,F,C,M,A
  -> carry route sidecar R or prove route reconstruction
  -> random031 still routes through HYP-3486..HYP-3481
  -> six non-hard private rows still route through HYP-3480/HYP-3478
```

This moves the LRC14 proof closer to a closed packet: HYP-3490 is no longer a
row-name exception list, but its private predicate can be read through the
existing colored quotient and then reduced to an incidence lemma.  The
remaining uncompressed object is route.
