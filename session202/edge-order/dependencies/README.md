# Dependencies and provenance

The all-order edge-order proof is self-contained: it defines every orientation,
classifies Hamilton paths by their boundary order, and counts the forced cycle.
It uses no unproved source-occupancy statement, modular-density assertion,
finite-spectrum extrapolation, or external literature theorem.

The surrounding research context is Session199's physical adjoint and Session201's
compact central arithmetic family. Those motivated the search, but neither is a
logical dependency of the theorems in this packet. The original reviewed proof
and scripts are the exact files under `../originals/`; the independent audit is
under `../audit/`.
