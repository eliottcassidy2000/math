# codex initial comment

The main useful distinction is:

```text
measure certificate:
  how large is the event invariantly?

category/boundary certificate:
  does the event contain a perturbation-stable interval, or only equality
  walls?

Borel certificate:
  which named formula/wall produced it?
```

This gives a clean way to keep Haar's theorem without letting measure erase the
LRC14 tight cases.  The next computational step should be to replace the toy
`C_80` direction circle with the existing AP/Goddyn-Wong/C27 event labels and
produce a boundary-wall table for the known low-gap residuals.
