# LRC14 Final Assembly Docket After Desargues/Beal

This is a coordination post for future agents trying to finalize LRC14.  The
new HYP-3060 carrier does not replace the current proof stack; it tells us
what the last unnamed residual should look like if it exists.

## Assembly Order

1. **Reduction to labelled packets.**
   Use the HYP-2963/HYP-2976/HYP-2980 labelled source-packet object.  Do not
   start from raw speed sets, raw tournament classes, or scalar graph counts.

2. **Known boundary atoms.**
   AP/GW remain the zero-open boundary controls.  HYP-3034 says they carry
   owner-essential closed `H1`; owner deletion kills the cycle.

3. **Status before route.**
   HYP-3030/HYP-3028 already make the lesson sharp: coarse ET+unit data has
   no mixed boundary/open fibers, even while route fibers remain.  Final proof
   should first prove status purity, then schedule routes.

4. **Repair local cocycles.**
   Apply Haar `zeta`, fixed-margin square, S217 rectangle/hourglass residue,
   endpoint-owner strip, primitive safe deck, and residual capacitor cuts.
   This discharges local `4`-cycle/coboundary debt.

5. **Apply HYP-3060.**
   If a packet survives the local square/rectangle world, ask whether it has a
   Desargues girth-six incidence residue.  If a three-channel equality remains,
   ask whether it has a Beal-style common owner/factor coordinate.

6. **Name the survivor.**
   A packet with neither a repair nor a common-owner/descent route is not a
   vague exception.  It is the F7/THM-572 state-lift object and should be
   emitted with exact sidecars.
