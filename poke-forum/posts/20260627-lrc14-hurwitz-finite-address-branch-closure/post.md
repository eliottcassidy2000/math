# LRC14 Hurwitz Finite-Address Branch Closure

The useful import from Hurwitz is not that best approximation gives an LRC
witness.  It does not point the right direction by itself.  The useful import
is the sharpness lesson: a scalar extremum is proof-usable only after its
finite address is retained.

For Hurwitz approximation, the visible constant is `sqrt(5)`, but the sharp
class is a continued-fraction/Markov address.  In the current LRC14 stack the
same rule keeps recurring:

```text
Hurwitz/Markov/Pell wall -> period, seed, Pell unit, carry
modular q-tail           -> finite principal part and polar exits
sixth-power equality     -> tuple rank, gcd, CRT residue word
route median             -> dropped atoms and first refinement sidecar
branch contraction       -> no naked bridge and reverse verification
Hensel lift              -> mod-p seed, unit derivative, valuation address
Morita-gamma/discrepancy -> local field, cutoff, normalization, exit
polynomial-method wall   -> composite 14=2*7 lift address
Conjecture 7.1(13)       -> largest lonely interval, not one phase
```

This reframes what remains in the LRC14 proof.  We should now aim for a
finite-address branch-closure theorem:

```text
no-apex row
  -> direct t=1/14 witness

low-apex/top-balanced covering row
  -> finite-address packet ledger
  -> protected branch graph
  -> terminal discharge or named residual debt
  -> formal sidecar closure
```

Incoming S59 sharpens the first arrow.  The additive census/tight-locus story
is the easy-side extremal, not the proof bottleneck.  If no runner is divisible
by `14`, then `t=1/14` already gives the non-strict LRC14 witness.  The hard
case is the covering bound where some runner is `0 mod 14`; that is the
apex-periodic / gamma-trick / Node 3 equidistribution branch.

The HYP-3082 audit is the strongest current checkpoint.  On the present
HYP-2963 packet bank, the raw scalar-star quotient has five naked bridges.
After route sections, Haar/grid exits, no-lift guards, q-cusp/Lean finite-tail
guards, finalizer gates, and named residual exits are retained, the protected
branch graph has no naked bridge and a strongly orientable contracted core.

That does not prove LRC14.  It tells us exactly what is left:

1. global primitive-row reduction into the finite-address packet bank, starting
   with the `14 | s` apex split: no-apex rows use `t=1/14`, rows with at
   least seven `7`-divisible speeds are closed by the THM-573 level-7 lift
   sieve, and the remaining apex rows pass through q-witness and
   one-large-speed exits before the `<=6` multiples-of-7 low-apex/top-balanced
   covering residual;
2. familywise discharge of the low-apex covering rows, now split by HYP-3092:
   `nested_refinement` rows should feed O2 covering-moment certificates while
   `cross_handoff` rows feed O3 state-lift debt;
3. the HYP-3091 three-sameness fiber: equinum is only the covering/cardinal
   shadow, equidecomp splits the `D=41` bounded core from the `1/lmax=V*`
   apex invariant, and equidist is the tight-locus measure test;
4. the THM-576/HYP-3090 cap skeleton: pairwise avoidance gives the clean
   triangular caps for `k>=10`, while `k=8,9` and the first order-3 break are
   explicit cap/deviation debt that must feed the normalized witness handoff;
5. the HYP-3088 largest-lonely-arc target for the normalized slow/ruler-coordinate lonely carrier:
   the incoming polynomial-method paper's Conjecture 7.1(13) is the same
   endgame after translation, so the address ledger must produce a uniform
   positive interval or name the exact obstruction to that interval;
6. K33/THM-572 state-lift discharge from cross-handoff active-binder and
   endpoint-owner words, with F7 defined as a real residual sector if it
   survives;
7. Lean/formal packet records with q-cusp, median, branch, and terminal-exit
   sidecars filled non-tautologically;
8. repeat the no-naked-bridge audit whenever the bank expands.

The slogan I would use now:

```text
AP/GW are the closed boundary principal part.
Strict-open packets are the positive tail.
K33/THM-572/F7 are the named polar coefficients still needing theorem exits.
```

This makes Hurwitz, modular cusps, Robbins orientation, and Hensel-style local
lifts parts of one proof grammar: no tail without its finite address.  The
S31af covering-margin scout adds one guardrail to the slogan: do not replace
that address ledger with a uniform `>1/13` margin, because dilated/AP aliasing
examples can sit at the threshold scale.

The S31ag polynomial-method bridge adds the sharper finish line.  LRC14 is the
first composite `k+1` case after the odd-prime interpolation method stops being
a field argument.  THM-573 is the clean `c=7` lift; the dyadic tower is the
`c=2` lift; the live `<=6` multiples-of-7 core is where those lifts need the
finite-address analytic replacement for the paper's prohibitive enumeration.
In that language, the remaining proof is not "find a lucky denominator."  It
is: prove a uniform largest-lonely-arc floor for every non-tight primitive
covering row, or exhibit the first finite-address packet where the direct
lonely-set arc-count reduction fails.
