# LRC14 Hodge-Cycle Lifting Carrier

This post introduces HYP-3066 / LTI-213 / LTT-111.

The Hodge conjecture should be used here as a realizability template, not as a
theorem we are importing.  The useful principle is:

```text
positivity is not realization.
```

In the true Hodge conjecture, a rational cohomology class of type `(p,p)` is
expected to come from algebraic cycles.  For LRC14 the analogue is:

```text
a closed, positivity-feasible packet cochain must be generated by named
certificate cycles, or it must become a specific F7/THM-572 residual class.
```

## Why this belongs in the repo

The repo already has the warning signs.

- Baby Hodge: tournament holes such as `(c3,c5)=(8,10)` are moment-feasible
  and still not realized.  Continuous PSD/flag/moment positivity does not cut
  the hole.
- HYP-2530: odd Faulhaber moment positivity is only the one-particle shadow;
  the obstruction lives in compatibility and integrality packets.
- HYP-2887: the LRC14 support-six repeated packet is an octahedral current on
  `L(K4)`.  After low-height walls, divergence and triangular face curls are
  the real carriers, and the sphere has no independent harmonic one-current.
- HYP-2995/HYP-2997: the current LRC14 proof object is already a cochain
  complex on labelled packet fibers.

HYP-3066 says to make this explicit with a cycle-class map.

## Dictionary

```text
Hodge class:
  a closed packet cochain that survives type/positivity filters.

Algebraic cycle:
  a named certificate generator: AP/GW boundary atom, Fejer dual form,
  Ramanujan exact-period character, Haar zipper square, endpoint-owner
  potential, observer-cut boundary, C27/unital transfer, K33/state-lift
  incidence, octahedral face curl, partial-cube Theta class, simplex face
  boundary, or Roth-Minkowski low-height wall.

Cycle-class map:
  certificate generators -> residual packet cohomology.

F7:
  not an anonymous hard row; a concrete non-generated residual class with a
  coefficient ring, representative cochain, failed generators, and THM-572
  state-lift target.
```

## Immediate pull

Build a small exact cycle-class matrix on a HYP-2963 sample.  Rows are emitted
residual cochains.  Columns are named certificate generators.  Use exact
rational row reduction to decide which residuals are generated by known cycles,
which descend to smaller families, and which need a new F7 representative.

This is the LRC version of the Hodge discipline: a positive shadow is not
enough; we need an actual generating cycle or a named obstruction.
