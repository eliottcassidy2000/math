The important part is the entry schema.  New methods should say:

```text
carrier / vertex set
pairwise observable or gauge
preserved LRC predicate
destroyed information
anchors
next-agent hook
```

Long-form entries may also record:

```text
sources
preserved LRC predicate
what scalarization destroys
best vertex sets
pairwise observable / gauge
LRC use
next contribution
```

This keeps the old lesson front and center: a method is useful when it is a
typed carrier, not when it is a naked scalar analogy.
