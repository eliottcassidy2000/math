## Session Meat

The useful common feature is the same in all four imported themes:

```text
local atoms are not enough; keep the recombination address.
```

`J37` is the visual model.  It has the same local vertex-figure shadow as the
rhombicuboctahedral lane, but the global twist splits vertices into different
orbits.  This is exactly the LRC14 warning: residue histograms, sector counts,
and even support-6 coimage summaries can be pseudo-uniform unless the
carry/owner twist is recorded.

Paris-Harrington supplies the recursion form of that address.  A bad coloring
is not just a coloring with no witness; it is a node in an outer-extension tree.
The missing invariant is the child-rank profile after the initial segment is
named.  For LRC14, the analogous node is an owner/carry fiber with no certified
lonely witness after known low-height walls have been deleted.

The Beurling-Selberg wall is the analytic version.  Nonnegative pointwise
minorants scalarize the sharp safe set so hard that only the zero certificate
survives.  The signed bandlimited route may still work, but only if the
defects remain labelled by support, residue, bandlimit, and relation hyperplane.

The pentagonal/tetrahedral split says how to combine finite and signed work.
Euler's pentagonal product is an exact signed-cancellation carrier; the
tetrahedral Pollock program is a finite defect-pair carrier.  LRC14 appears to
need both:

```text
finite low-height support-6 wall deletion
+ signed reciprocal theta/Dedekind tail on the relation hyperplane
```

The concrete proposal is a node-squared proof-carrier tournament.  Base vertices
are proof obligations, not runners:

```text
low-height anti-coset wall
PH bad-child rank
projective support-6 coimage
signed reciprocal theta tail
owner/carry geometry
Beurling-Selberg defect label
cluster-collapse quotient
```

Each vertex then carries an internal tournament over the same list, specialized
to one row or one carry fiber.  This ports THM-410/S652 square-blowup thinking
from tournament enumeration into the LRC14 proof search.

## Random Repo Niche

The closest niche is HYP-2448's Iravanian/Cohn certificate-state atlas.  The
quartic `x^4 - 10x^2 + 1` has false integer-trace recombination candidates, so
first-trace subset-sum data is necessary but not sufficient.  That is the same
lesson as J37: a recombination test can look locally plausible while the global
factor address is wrong.

For support-6 enumeration, the constructive echo is a `3+3` meet-in-middle
relation enumerator.  Hash partial sums by integer height, mod-7 residue, and
denominator/residue class; then recombine only anti-coset survivors.  This is
Iravanian-style recombination as an enumeration speedup, but pointed at the
LRC14 relation lattice rather than polynomial factors.
