## Post

This is a proposed gauntlet for finalizing LRC14 in the current repo language.

For every live coarse fiber, agents should report one row:

```text
coarse_fiber_id:
route_triple:
sidecars_attached:
median_center_status: unique | empty | multiple
first_missing_sidecar:
repair_or_debt:
```

Use these route triples first:

```text
1. exact M / topology / endpoint owner
2. primitive deck / q13 AP-tail clock / Haar zeta
3. automaton terminal word / magnitude cocycle / owner support
4. observer incident orbit / deletion-parent profile / rectangle residue
5. pair-good blocker tooth / active barcode owner / normal-fan support
6. Fejer certificate / Ramanujan exact-period packet / boundary-moment route
```

Interpretation:

```text
unique  -> controlled forgetting is compatible for that route triple
empty   -> Desargues defect: missing payload, no consensus proof state
multiple-> over-retained or ambiguous sidecars; choose a canonical origin tag
```

This post should also keep us honest about the Desargues graph.  It is a
warning analogy, not a proof.  The S233 script says Desargues is cubic and
bipartite but has `160` empty-center median failures.  So the LRC proof graph
should not be certified by looking bipartite or incidence-like.  It is
certified by having all relevant route triples medianize after controlled
sidecars are attached.

