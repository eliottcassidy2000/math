## Three Niche Seeds

1. Haar's theorem gives the invariant measure on the compact phase groups where
   LRC safe/danger sets live.
2. Borel and Baire distinctions warn that measure/category quotients can erase
   the endpoint witnesses that tight LRC rows need.
3. Any-angle path planning suggests a sixth proof-search algorithm: plan through
   safe intervals and taut boundary owners, not through a fixed rational grid.

## Source-Backed Facts

Haar's theorem says that a locally compact group has a nonzero left Haar
measure, unique up to positive scaling after regularity and compact-finiteness
are imposed.  On compact groups this is normalized to total mass `1`.  This is
the right invariant terrain for LRC phase tori and orbit closures:

- <https://en.wikipedia.org/wiki/Haar_measure>
- <https://www.math.uchicago.edu/~may/VIGRE/VIGRE2010/REUPapers/Gleason.pdf>

Borel sets are usually generated by open sets.  Baire sets are a smaller or
better-behaved sigma-algebra in some non-second-countable settings, and the
property of Baire is the statement that a set is open modulo a meager set.  The
warning for us is two-sided: Haar measure can throw away null endpoints, while
Baire-category quotients can throw away meager endpoints.  Therefore the proof
must retain the actual Borel/Baire code or boundary owner when an endpoint is
proof-live:

- <https://en.wikipedia.org/wiki/Borel_set>
- <https://en.wikipedia.org/wiki/Baire_set>
- <https://topology.lmf.cnrs.fr/borel-sets-analytic-sets-and-the-baire-property/>

The any-angle path-planning literature starts from grid A* but relaxes the
heading constraint.  Field D* interpolates through weighted grids; Theta* uses
line-of-sight from a node's parent; Block A* uses local distance databases;
ANYA searches intervals and taut paths; CWave propagates wavefronts with
geometric primitives:

- <https://en.wikipedia.org/wiki/Any-angle_path_planning>
- <https://idm-lab.org/bib/abstracts/papers/aimag13.pdf>
- <https://jair.org/index.php/jair/article/view/11004>
- <https://www.cambridge.org/core/journals/robotica/article/cwave-theory-and-practice-of-a-fast-singlesource-anyangle-path-planning-algorithm/15B1D45E7C4467A0C33020525ABD9B33>

## Synthesis

The LRC phase space is a compact group, so Haar measure is the canonical
interior metric.  For a speed set `S`, the map

```text
tau -> (v tau)_v in T^S
```

pushes circle Haar measure to Haar measure on the closed orbit determined by
the integer relation lattice.  That makes Haar the right analogue of terrain
cost in any-angle planning.

But Haar measure is not the whole LRC.  The tight rows are exactly the warning:

```text
positive Haar measure  => open interval witness
zero Haar measure      => endpoint/boundary witness may still prove LRC
```

Baire category gives the dual warning.  A singleton endpoint is also meager.
So replacing an exact safe set by its measure algebra or by its Baire-property
class can erase the same proof-live boundary.  The useful object is:

```text
regular open safe interior
+ exact Borel/Baire boundary code
+ owner/carry selector for the endpoint
```

## The Sixth Algorithm: HBT*

Call the proposed sixth proof planner:

```text
HBT* = Haar-Baire Taut star
```

It is not meant as a literal robotics algorithm.  It is a proof-search carrier
for LRC14, inspired by the any-angle family.

### State

```text
(regular_open_safe_packet,
 boundary_owner_code,
 relation_lattice_or_coimage_class,
 low_height_wall_ledger,
 PH_bad_child_rank)
```

The state is not a runner, a clock tick, or a grid vertex.  It is a coded safe
region together with the boundary information needed if Haar measure becomes
zero.

### Propagation Rules

**Field D* analogue.**  Use Haar measure and regularity to interpolate through
positive-measure interiors.  If a row has `p_0>0`, stop early: it has an open
lonely interval.

**Theta* analogue.**  If a parent owner has direct line-of-sight to a successor
endpoint witness, bypass intermediate carry states.  In LRC terms:

```text
parent owner -> successor witness
```

is allowed only when the exact Borel boundary code proves the same witness.

**Block A* analogue.**  Precompute local databases for AP/Vstar/`2AP` carry
fibers, low-height support-6 walls, and q=3/C27 branch packets.  These are
local distance databases in proof space.

**ANYA analogue.**  Use intervals as nodes.  A safe component or boundary arc
is the atomic state, and a taut LRC path is one where every change of proof
direction wraps tightly around a named danger arc, support-six wall, or
owner/carry endpoint.

**CWave analogue.**  Propagate signed wavefronts through the relation lattice:

```text
sum n_i e_i = 0,
K(n)=C_d(n mod 7)/(n_1 ... n_6).
```

The primitives are relation hyperplanes, projective coimage classes, and
deleted anti-cosets rather than grid edges.

**New HBT* rule.**  When Haar mass is positive, use measure.  When Haar mass
falls to zero, switch strata and keep the Baire/Borel boundary owner instead
of declaring the state dead.  The priority queue ranks states by:

```text
cap_margin_deficit
+ unresolved_low_height_wall_count
+ unsigned/signed tail gap
+ PH_bad_child_rank
```

This is the missing sixth move: a proof planner that knows the difference
between "no interior" and "no witness."

## Working Verdict

The current LRC14 route should not ask:

```text
can Haar measure prove every row positive?
```

It should ask:

```text
can every row be routed by HBT* into either
  positive Haar interior,
  named endpoint wall,
  finite low-height wall ledger,
  or a decreasing PH bad-child rank?
```

That reframes the proof search as any-angle planning on a compact group:
Haar for the open terrain, Baire/Borel codes for the boundary, and owner/carry
rank for the escape branches that try to stay unnamed.
