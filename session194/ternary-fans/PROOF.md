## 2. Definitions and the general endpoint-matching lemma

For a tournament T, H(T) counts directed Hamiltonian vertex words. For a root t, e_t counts those ending at t, and

    R_t(T) = sum_{S subset V(T)-{t}} H(T[S]) s_t(T[V(T) minus S]),

where H(empty)=1 and s_t counts Hamiltonian words starting at t. Thus R counts ordered spanning two-path covers whose second path is nonempty and starts at t; the first path may be empty.

For rooted A at a and B at b, form J(A,B) by taking A -> B^op and reversing only the cross arc a -> b. The old arc becomes b -> a. If x=(h_A,e_a,R_a) and y=(h_B,e_b,R_b), the inherited exact path decomposition is

    H(J(A,B)) = h_A h_B - e_a e_b + R_a R_b.       (1)

For clarity, every adjacency list below describes B, not B^op. The converse is taken when building J.

**Endpoint-matching lemma.** Suppose three actual rooted tournaments B,B_2,B_4 have triples

    y=(h,e,R),
    y_2=(3h,3e-2,3R),
    y_4=(3h,3e-4,3R).

For every rooted tournament A, let N=H(J(A,B)). Then

    H(J(A,B_2))=3N+2e_a(A),
    H(J(A,B_4))=3N+4e_a(A).                       (2)

In particular, if e_a(A)=1, the two outputs realize 3N+2 and 3N+4.

**Proof.** Substitute each physical triple into (1), and subtract three times the parent expression. All h_A and R_a coefficients cancel, leaving respectively 2e_a and 4e_a. No coefficient is represented by a nonphysical formal triple; every core is supplied below. QED.

This is a construction theorem for the displayed input family. It does not say that every attainable N has such a presentation, or that either output has another endpoint-one mark.

## 3. A single parent core and two literal births

Rows are outgoing-neighbor bitmasks on vertices 0,...,n-1. The root is always **b=1**.

    B   = [2,4,97,39,15,83,27]
    B_2 = [2,4,225,39,15,83,155,59]
    B_4 = [2,4,225,39,15,211,155,27].

The independently checked rooted profiles are

    B:   (H,e_1,R_1) = (57,15,57),
    B_2: (H,e_1,R_1) = (171,43,171),
    B_4: (H,e_1,R_1) = (171,41,171).

All three cores are strong. B_2 is obtained from B by adding vertex 7 with outgoing old-neighbor mask 59, meaning old out-neighbors {0,1,3,4,5}. B_4 instead gives vertex 7 outgoing mask 27, with old out-neighbors {0,1,3,4}. Every old vertex name, every old arc and the root are unchanged.

Consequently **J(A,B_2) and J(A,B_4) are each obtained from J(A,B) by adding exactly one vertex**, with every old arc unchanged. The new vertex is dominated by all vertices of A. On the B part its incidences are the converse of the preceding masks. In J(A,B_2), its outgoing old-B neighbors are {2,6}; in J(A,B_4), they are {2,5,6}. The seam b -> a is untouched.

This preserves the entire parent as an **induced subtournament**, not as a module. The new vertex has mixed incidences with the old B vertices, so neither a module-preservation assertion nor a substitution-product formula is involved.

Thus every endpoint-one rooted A gives the actual induced fan

    J(A,B) -> J(A,B_2), with H changing N -> 3N+2,
    J(A,B) -> J(A,B_4), with H changing N -> 3N+4.  (3)

These are alternative births, not a sequence in which both vertices are added.

### Why the small core works: a C2 ear on the regular five-tournament

This is not just an unexplained equality of bank rows. Put

    U=[24,9,3,20,6], rooted at r=0.

Every vertex has out-degree two. Its exact rooted profile is (15,3,21). Add x whose sole outgoing arc into U is x -> r, then y with U -> y -> x. Write the resulting core in the order y,x,U, so its root x is vertex 1. This is exactly B above.

For an arbitrary rooted U, this C2 ear has

    H(C2(U,r))=H(U)+2R_r(U),
    e_x(C2(U,r))=H(U),
    R_x(C2(U,r))=H(C2(U,r)).

The first identity is (1) with the two-vertex gadget y->x, whose converse rooted at x has triple (1,0,2). For the second, a Hamilton path ending at x must have y immediately before x, leaving an arbitrary U-path. For the third, R_x-H counts the two-path covers whose first path ends at an out-neighbor of x. That neighbor must be r. If the second path is not the singleton x, it uses r immediately after x, a contradiction. If it is the singleton x, the first path contains y, which has no outgoing arc within that first path and must be its last vertex, again a contradiction. Thus the difference vanishes.

The two births take place inside U. With the old labels 0,...,4, give the new vertex outgoing mask14 or mask6:

    U_2=[56,9,3,20,38,14],  (H,e_r,R_r)=(43,6,64),
    U_4=[56,9,3,52,38,6],  (H,e_r,R_r)=(41,5,65).

They preserve r and all old arcs. Their counts obey

    (H(U_2),R_r(U_2))=(3*15-2,3*21+1),
    (H(U_4),R_r(U_4))=(3*15-4,3*21+2).

Thus both scale H+2R by exactly three while shifting H itself by the two desired amounts. The C2 ear turns this fixed-H+2R balance into endpoint coefficients 43 and 41. This explains the ternary fan's mechanism. The six small profiles are independently checked by literal permutation/cut counting in `verify_structure_and_atoms.py`.

## 4. Arbitrary even binary words supply endpoint-one inputs

For a nonnegative integer v, T(v) has an apex a and a transitive chain whose apex outgoing incidences are the bits of v, most significant first. For v=0 use the empty word, so T(0) is a singleton. Let

    g(0)=1,
    g(2u+1)=g(u),
    g(2u)=g(u)+u+(u mod 2).

The rooted triple of T(v) is

    (g(v), [v even], v+1).

This includes e(0)=1. Every even v therefore satisfies the hypothesis in (3), with no restriction on word length or the number of binary runs. The parent count is

    N(v) = 57g(v)-15+57(v+1)
         = 57[g(v)+v]+42
         = 57g(2v)+42,                            (4)

where the last equality uses **v even**, so g(2v)=g(v)+v. The graph input parameter is v throughout; 2v only appears in the simplified scalar expression.

The children have counts

    3N(v)+2 = 171g(2v)+128,
    3N(v)+4 = 171g(2v)+130.                       (5)

Both are produced by a single induced birth from the same marked physical parent. For even v>0, the canonical word starts in 1 and ends in 0, so T(v) is strong. For v=0 it is a singleton. Since B,B_2,B_4 are strong, the one reversed seam makes each of these joins strong. In the singleton case, its outgoing arcs to B^op-{b}, the seam b->a and strongness of B^op give the same conclusion.

Examples:

| v | N(v) | 3N(v)+2 | 3N(v)+4 |
|---:|---:|---:|---:|
| 0 | 99 | 299 | 301=7*43 |
| 2 | 327 | 983 | 985 |
| 4 | 555 | 1667 | 1669 |
| 6 | 669 | 2009 | 2011 |

The table is illustrative; primality or seven-times-prime status is not needed for the identities. In particular, 301 supplies a seven-times-prime atom, and 983,1667,1669 supply prime atoms. No infinitude of prime or 7p values in this parameter family is asserted.

Infinitely many distinct parent values are certain: for v=2^k, k>=1, g(2v)=2^(k+1)+1, so N(v)=114*2^k+99 tends to infinity. The theorem allows much more than these clock words: it accepts every even v, including unbounded binary alternation.

## 6. Failure boundaries and the remaining coverage question

1. For odd v, the input endpoint count is zero. Formula (2) then gives **3N for both children**, not 3N+2 or 3N+4. This hostile branch is checked directly.
2. There is a uniform obstruction to literal return: for every rooted A, none of the three special joins has an endpoint-one mark anywhere. The next subsection proves this, strengthening the v=0 hostile example.
3. The parent H57 fan is genuinely induced, but its parent counts are 3 modulo 6 and divisible by 3. It does not repair the particular induced H41 -> H127 obstruction or establish universal induced ternary growth.
4. The S193 prime-lane induction would be closed only by proving that these families, other direct constructions and valid smaller-parent operations cover every residual prime/7p target. No such covering argument is supplied here. A new arithmetic representation or a returning richer interface remains necessary.
5. A matching of triples alone would be insufficient without physical witnesses. This packet supplies them and checks the whole output graph, rather than only the arithmetic formula.

### Uniform endpoint-one non-return theorem

This stronger theorem was found during the independent `session194-gadgets-audit` review. Its endpoint decomposition and finite constants are also checked in the supplementary verifier here.

For a core C rooted at b=1, let s_x count Hamilton paths starting at x, let c_x count those starting at x and ending at b, and let D_x count ordered covers by two nonempty paths starting at b and x respectively. Literal enumeration gives:

    C=B:
    s=[3,3,3,11,13,11,13]
    c=[0,0,3,3,3,3,3]
    D=[3,0,3,11,13,11,13]

    C=B_2:
    s=[7,7,7,22,27,22,38,41]
    c=[0,0,7,6,7,6,8,9]
    D=[7,0,7,22,27,22,38,41]

    C=B_4:
    s=[7,7,7,21,23,33,43,30]
    c=[0,0,7,5,5,9,9,6]
    D=[7,0,7,21,23,33,43,30].

If the output endpoint x lies in A, every such Hamilton path uses the backward seam and finishes in its second A run. Its count equals s_b(C) times the number of A covers whose second path starts at a and ends at x. It is therefore a multiple of 3 for B and of 7 for either child, possibly zero but never one.

If the output endpoint x lies in C^op, the seam decomposition instead gives

    e_x(J)=h_A s_x-e_a c_x+R_a D_x.

For x other than core vertex 2, the arrays give s_x-c_x at least q, where q=3 for B and q=7 for its children. Since h_A>=e_a and h_A>=1, the displayed count is at least q. At core vertex 2, s_2=c_2=D_2=q, so its endpoint count is q(h_A-e_a+R_a)>=q. Here R_a>=1 follows by taking the singleton a as the second path and a Hamilton path of A-a as the first, with the empty first path allowed when A is a singleton.

Consequently no endpoint-one mark exists at any vertex of any literal special output. When the output is strong, every endpoint count is positive and hence at least 3 or 7. This prevents recycling these graphs as the next endpoint-one A in the same lemma. It does not exclude reconstructing the same count, changing old arcs, using the graph in a different role, or maintaining a richer interface.
