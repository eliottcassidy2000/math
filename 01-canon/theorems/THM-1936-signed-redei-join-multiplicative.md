# THM-1936 — The signed Rédei count is join-multiplicative; the |R|-spectrum factors over strong components

**Status:** PROVED (elementary; verified exhaustively n ≤ 6).
**Author:** mac-mini-2026-07-21-S160.
**Descends from:** Rédei's theorem (# Hamiltonian paths is odd); the signed count `R(T)` introduced by mac-mini-S159 (HYP-8640 follow-up); the order-join algebra of boxeph-S193 (THM-1862, `H` multiplicative under `▷`).

## Definitions

For a tournament `T` on vertex set `{0,…,n−1}` (adjacency `A`, `A[u][v]=1` iff `u→v`), a
**Hamiltonian path** is a vertex ordering `π = (π₀,…,π_{n−1}) ∈ S_n` with `A[πᵢ][πᵢ₊₁]=1`
for all `i`. The **signed Rédei count** is
```
    R(T) = Σ_{Hamiltonian paths π} sgn(π),
```
`sgn(π)` = sign of `π` as a one-line permutation. `R(T)` is a *pseudo-invariant*: relabeling
vertices by `σ` multiplies `R` by `sgn(σ)`, so **|R(T)| is a tournament invariant**.

The **order-join** `T₁ ▷ T₂` places `V(T₁)` before `V(T₂)` and orients every cross-arc
`T₁ → T₂`. Every tournament is uniquely the join-chain of its strong components
(condensation), so `(tournaments, ▷)` is a monoid freely generated by the strong tournaments.

## Statement

With the natural labeling `V(T₁) < V(T₂)`,
```
    R(T₁ ▷ T₂) = R(T₁) · R(T₂).
```
Hence `R` is a homomorphism from the join-monoid to `(ℤ, ·)`, and
```
    |R(T)| = ∏_{C strong component of T} |R(C)|.
```
`|R|` is a **strong-component invariant**; adding a source or sink vertex preserves `|R|`
(`R({v}) = 1`). This is the **signed refinement of THM-1862** (`H` multiplicative under `▷`).

## Proof

**Path factorization.** In `T₁▷T₂` all cross-arcs go `T₁→T₂`, so once a Hamiltonian path
enters `T₂` it cannot return to `T₁`. A Hamiltonian path therefore visits all of `T₁` first,
then all of `T₂`: it is `(π₁ ‖ π₂)` where `π₁` is a Hamiltonian path of `T₁`, `π₂` of `T₂`,
joined by the (always present) bridge arc `last(π₁) → first(π₂)`. This is the bijection behind
`H(T₁▷T₂)=H(T₁)H(T₂)` (THM-1862).

**Sign factorization.** Label `V(T₁)={0,…,n₁−1}`, `V(T₂)={n₁,…,n−1}`. The concatenation
`π=(π₁‖π₂)` has three kinds of inversion pairs: within block 1 (`inv π₁`), within block 2
(`inv π₂`), and cross pairs `(i,j)` with `i` in block 1, `j` in block 2. A cross pair has
position `i<j` and values `π(i)∈{0,…,n₁−1} < π(j)∈{n₁,…,n−1}`, hence is **never** an
inversion. So `inv(π)=inv(π₁)+inv(π₂)` and `sgn(π)=sgn(π₁)sgn(π₂)`. Therefore
```
    R(T₁▷T₂) = Σ_{π₁} Σ_{π₂} sgn(π₁)sgn(π₂) = (Σ_{π₁} sgn π₁)(Σ_{π₂} sgn π₂) = R(T₁)R(T₂). ∎
```

Taking `|·|` removes the labeling dependence; iterating over the condensation gives the
strong-component product. Verified exhaustively for all tournaments `n ≤ 6`.

## Corollary — the |R|-spectrum and mac-mini-S159's gap question

The achievable values of `|R|` on `n` vertices are exactly the **products of strong-atom
`|R|`-values over compositions of `n` into strong pieces**. The strong-atom spectra:

| n | strong `|R|` values |
|---|---|
| 3 | {3} |
| 4 | {1} |
| 5 | {3,5,7,11,15} |
| 6 | {1,3,5,7,9,11,13} |

Products over compositions reproduce the full `|R|`-spectrum exactly (verified `n≤6`):
`n=5 → {1,3,5,7,11,15}`, `n=6 → {1,3,5,7,9,11,13,15}`.

**This answers S159's "why are 9 and 13 absent at n=5?":** `9 = 3·3` requires two 3-cycles,
i.e. ≥ 6 vertices; `13` is prime and its smallest strong realizer has 6 vertices. Neither is a
product achievable on 5 vertices, so both are absent at `n=5` and both appear at `n=6`. The
gap is a **multiplicative** phenomenon, not an arithmetic accident.

**Non-corollary (recorded to prevent a tempting error):** `|R(T)|=1 ⟺ T transitive` is
**FALSE** — the strong 4-tournament has `H=3`, `R=±1`, so `|R|=1` for a non-transitive strong
tournament (24 labelings at `n=4`; 7920 strong `n=6`). Strong tournaments *can* be sign-balanced.

## Remarks

- **Not a determinant/Pfaffian collapse.** `R ≠ ±det(M)` for the natural candidates
  (`A, I±A, A±Aᵀ, …`) at `n=5`; `R = Pf(A−Aᵀ)` holds only for `n ≤ 4` (off by ±2 at `n≥5`).
  So, exactly as S159 found for `H`, the *signed* count also has no simple linear-algebraic
  collapse — its only clean algebra is the join-multiplicativity above. The `max|R|` sequence
  `3,3,15,15,147,…` is **not** the double factorial (`7!!=105 ≠ 147`); the small-`n` match was
  a coincidence.
- **Algorithmic:** `|R|` reduces in poly time to its strong components (condensation), like `H`.
- **Meaning:** the *sign-imbalance* of Hamiltonian paths (`#even − #odd`) is a
  strong-component-local quantity; `R≡H (mod 2)` (so `R` is odd and never 0 — Rédei), while the
  join structure controls its magnitude.
