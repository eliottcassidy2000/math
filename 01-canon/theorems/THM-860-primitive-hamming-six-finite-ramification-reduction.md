# THM-860 — primitive Hamming-six finite ramification reduction

This namespace is reserved for the audited theorem that a primitive tight
AP-centred Hamming-six packet has a uniformly bounded common scale, and that
each fixed ramification language transports to a finite THM-857 component
recursion.  The current independently checked candidate bound is

```text
c <= 2,328,480.
```

The proof still being frozen must include the leave-one-out lcm identity, the
six-colour relative cuts (with the singleton supplied by hereditary
primitivity), the full upper-set valuation argument, and the exact progression
transport.  This stub does **not** assert that any ramified language is empty
and does not prove global `n=12` sporadic-branch emptiness.
