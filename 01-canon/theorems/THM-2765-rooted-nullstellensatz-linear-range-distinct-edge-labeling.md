# THM-2765 -- rooted leading monomials and linear-range tree labels

**RESERVED / UNPROVED EMPTY STUB.**

Reserved for the proposed exact rooted-tree leading-monomial argument: the
vertex-injectivity Vandermonde times the squared edge-difference discriminant
has candidate leading monomial `product_(j>=2)x_j^(3j-5)` under a
parent-before-child order.  If the coefficient and grid application survive
hostile audit, Combinatorial Nullstellensatz would give every `n`-vertex tree
an injective integer labeling in `{0,...,3n-5}` with pairwise distinct
absolute edge differences.  This would be a range-relaxed theorem, not the
Graceful Tree Conjecture.  No statement in this stub is proved or available
for dependency use.
