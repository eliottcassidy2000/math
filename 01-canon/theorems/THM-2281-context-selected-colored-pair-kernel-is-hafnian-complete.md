# THM-2281 -- the exact pair object retains its selectors

The inherited-color amplitude of Krenn--Gu--Soltesz is a sum over an
entire perfect-matching fiber. That warning is sometimes read too broadly
as saying that pair data itself must fail. The sharper statement is:

```text
unselected or scalarized pair shadow:      insufficient;
endpoint-color-selected weighted kernel:   exact;
global response:                           hafnian contraction.
```

Thus global higher-order interference can be generated by an exactly
pair-local primitive. The primitive remains exact only while its selector
indices, complex weights, and contraction law are retained.

The closest proved mechanism is THM-2267's exact tropical product of
eligibility selectors and a switch kernel. Its canonical hostile example
keeps every static owner stalk fixed while changing the transition gluing.
The least-used relevant sidecar is the literal Krenn matching-fiber sum.
Here the gluing family is the family of perfect pairings, and the coefficient
algebra is sum--product rather than min--plus.

## 1. Endpoint-colored pair kernels

Let `R` be a commutative semiring with zero and unit, let `C` be a nonempty
finite color set, and let `V` be a finite labelled vertex set. An
endpoint-colored weighted multigraph `G` consists of finitely many loopless
edge occurrences. An edge `e` with endpoints `{i,j}` has

```text
a weight w_e in R,
a color gamma_e(i) in C at endpoint i,
a color gamma_e(j) in C at endpoint j.              (1)
```

Parallel edge occurrences remain distinct. This is the multigraph setting
used by the inherited-vertex-color problem; complex weights specialize
`R` to `C`.

For distinct vertices `i,j` and colors `a,b`, define the aggregated colored
pair kernel

```text
A_G(i,a;j,b)
 =sum_(
     e with endpoints {i,j},
     gamma_e(i)=a,
     gamma_e(j)=b
   ) w_e.                                           (2)
```

An empty sum is zero. Reversing the displayed endpoints gives

```text
A_G(i,a;j,b)=A_G(j,b;i,a).                          (3)
```

For a vertex coloring `c:V->C`, select the scalar symmetric matrix

```text
A_G[c]_(i,j)=A_G(i,c(i);j,c(j)),
A_G[c]_(i,i)=0.                                    (4)
```

Write `Pair(V)` for the perfect pairings of `V`. For a symmetric zero-
diagonal matrix `B` over `R`, define its semiring hafnian by

```text
haf_R(B)
 =sum_(pi in Pair(V)) product_({i,j} in pi) B_(i,j). (5)
```

If `|V|` is odd, the pairing family is empty and the hafnian is zero.

The inherited-color amplitude is

```text
W_G(c)
 =sum_(
    perfect edge matchings M whose inherited coloring is c
   )
   product_(e in M) w_e.                            (6)
```

Different choices of parallel edge occurrences count as different edge
matchings.

> **Theorem 1 (selected-kernel hafnian law).**
>
> ```text
> W_G(c)=haf_R(A_G[c])                              (7)
> ```
>
> for every endpoint-colored weighted multigraph and every vertex
> coloring.

### Proof

Map each perfect edge matching to its underlying perfect pairing of the
vertices. Fix a pairing `pi`. For each pair `{i,j}` in `pi`, the eligible
edge occurrences are exactly those summed in
`A_G(i,c(i);j,c(j))`. Choices on different vertex pairs are independent.
Distributivity therefore gives

```text
sum_(
  edge matchings over pi with inherited coloring c
 )
 product_e w_e

=product_({i,j} in pi) A_G(i,c(i);j,c(j)).          (8)
```

Summing (8) over all perfect pairings proves (7). QED.

Equation (7) identifies one harmless quotient. Parallel edges with the same
endpoints and the same endpoint colors may be replaced by one edge whose
weight is their sum. Their individual identities are never needed by an
inherited-color amplitude. In contrast, summing across different endpoint-
color pairs is not harmless.

## 2. Exact contextual completeness

A **graph extension context** for a graph on `V` is a finite
endpoint-colored weighted multigraph `H` on a finite labelled superset
`U superset V`. The response of `G` in the context `(H,c)` is

```text
W_(G union H)(c),              c:U->C,              (9)
```

where edge occurrences are combined as a multiset. Equivalently, the two
colored pair kernels are added entrywise after extending `A_G` by zero
outside `V`.

> **Theorem 2 (leaf-complete continuation theorem).** For two graphs
> `G,G'` on the same labelled vertex set and with the same color set, the
> following are equivalent:
>
> ```text
> (i)  A_G=A_(G');
>
> (ii) W_(G union H)(c)=W_(G' union H)(c)
>      for every finite extension H and every coloring c.  (10)
> ```
>
> If the kernels differ, a distinguishing context can be chosen with at
> most `|V|-2` new vertices, each a degree-one leaf.

### Proof

If the kernels agree, then after adding the same context they still agree.
Theorem 1 gives equal amplitudes for every coloring, proving `(i)=>(ii)`.

Conversely, suppose

```text
A_G(i,a;j,b) != A_(G')(i,a;j,b)                    (11)
```

for some distinct `i,j` and some colors `a,b`. For each
`k in V\{i,j}`, add a new leaf `k*` and a single edge `{k,k*}` of unit
weight. Choose any endpoint colors for that edge. Query a coloring which
uses those colors on every forced leaf edge and uses colors `a,b` at
`i,j`.

Every perfect matching of the extended graph must use every edge
`{k,k*}`, because `k*` has degree one. After those edges are removed, only
`i` and `j` remain, so they must be paired. All forced edges have weight
one. The two responses are therefore precisely the two sides of (11), and
they differ. This proves `(ii)=>(i)` and the stated leaf bound. QED.

Hence

```text
G -> A_G                                                (12)
```

realizes exactly the contextual equivalence quotient for all inherited-
color amplitude queries. This is stronger than saying that `A_G` is a
sufficient statistic: every kernel coordinate has a finite continuation
probe. It does **not** say that the unextended response vector
`(W_G(c))_c` recovers `A_G`.

If `|V|=n` and `|C|=d`, applying the leaf probe once for every unordered
vertex pair and every ordered endpoint-color pair reconstructs the entire
kernel using at most

```text
binom(n,2)d^2                                         (12a)
```

amplitude queries, each with at most `n-2` new vertices. No claim of
optimal query complexity is made.

The response also composes cleanly under disjoint union. If `G` and `H`
have disjoint vertex sets and there are no cross edges, then every perfect
matching splits uniquely, so

```text
W_(G disjoint_union H)(c disjoint_union d)
 =W_G(c) W_H(d).                                    (13)
```

Equivalently, the selected kernel is block diagonal and the hafnian of that
block diagonal is the product of the two hafnians. Thus the full coloring
response is a tensor under disjoint union.

## 3. The two-vertex selector-erasure collision

The endpoint-color indices in (2) are necessary. Take

```text
V={1,2},                  C={r,b}.                  (14)
```

Let `G` have two parallel unit-weight edges: one colored `(r,r)` and one
colored `(b,b)`. Let `G'` have two parallel unit-weight edges, both colored
`(r,r)`.

After endpoint colors are erased, the two inputs are literally the same
weighted multigraph: two parallel edges, each of weight one, between the
same two vertices. In particular they have the same uncolored support,
edge multiplicity, and uncolored pair-weight sum. But in coloring order
`(rr,rb,br,bb)`,

```text
(W_G(c))_c  =(1,0,0,1),
(W_(G')(c))_c=(2,0,0,0).                            (15)
```

In kernel language, the uncolored collapse

```text
q(A)_(i,j)=sum_(a,b in C) A(i,a;j,b)                (16)
```

has

```text
q(A_G)=q(A_(G'))=2,                                 (17)
```

while the `rr` selectors give `1` and `2`. Therefore equality after (16)
is not stable under the selector operations (4): it is not a congruence of
the context-selected contraction algebra.

Any uncolored support relation or tournament constructed solely from this
erased data gives the same output on `G` and `G'` and therefore cannot
determine the inherited-color response. This is a concrete quotient
failure, not a claim that every use of tournaments is invalid.

## 4. Phase erasure and the semiring test

Endpoint-color support is still insufficient if complex weights are
discarded. On the same two vertices, take two parallel `(r,r)` edges. Give
them weights

```text
(1,-1) in H,                   (1,1) in H'.         (18)
```

The endpoint-colored incidence multigraphs are identical after weights are
forgotten, but

```text
(W_H(c))_c  =(0,0,0,0),
(W_(H')(c))_c=(2,0,0,0).                            (19)
```

The first graph cancels inside one matching fiber; the second reinforces.
A binary support map on complex numbers is not additive:

```text
supp(1)=supp(-1)=1,
supp(1+(-1))=0 != 1=supp(1) OR supp(-1).            (20)
```

There is a precise positive criterion.

> **Theorem 3 (semiring transport).** If
> `phi:R->S` is a homomorphism of commutative semirings, applying `phi` to
> every edge weight commutes with every inherited-color amplitude:
>
> ```text
> phi(W_G^R(c))=W_(phi G)^S(c).                      (21)
> ```

This follows immediately from the finite sum--product expression (6), or
from (7). Thus a scalarization is automatically safe for the predicate it
retains when it is a semiring homomorphism and keeps the selectors and
pairing family. The collisions (15) and (19) isolate the two independent
ways this can fail:

```text
drop selector indices;
use a coefficient quotient which does not preserve sums/products. (22)
```

## 5. Relation to knots, owner transitions, and higher dividends

The theorem supplies a shared validity test, not an identification of three
different objects.

| system | local/context carrier | contraction family | coefficient algebra |
|---|---|---|---|
| inherited coloring | `A_G(i,a;j,b)` plus coloring selector | perfect pairings / hafnian | complex sum--product |
| THM-2267 owner transitions | eligibility projectors plus switch kernel | ordered paths or cycles | min--plus |
| THM-2176 knots | continuation kernel `P_K(a,b)` | arbitrary intermediate knots | min--plus |

In each row, a quotient intended for composition must preserve the stated
selectors, the contraction family, and the target predicate. The analogies
stop there:

1. THM-2259 proves that atomic pair defects in an abstract metric monoid can
   miss genuine higher Boolean dividends. This theorem does not contradict
   it. The Krenn input is already a pair-factor model; its global
   higher-order response is generated by hafnian contraction of the full
   selected pair tensor.
2. THM-2267 proves that static owner overlaps lose transition gluing.
   Retaining the ordered eligibility projectors and switch kernel repairs
   that loss. No hafnian occurs there.
3. THM-2176's knot kernel ranges over arbitrary Gordian intermediates.
   The bounded forced-leaf separation in Theorem 2 has no proved knot
   analogue. In particular, this theorem computes no unknotting number and
   does not reduce the Gordian continuation kernel to pair data.

A Möbius or Fourier transform of the coloring response can be useful for
displaying global interference, just as higher dividends display metric-
monoid interaction. It is a derived coordinate on the contracted response,
not a replacement for the selected pair kernel under arbitrary graph
extensions.

## 6. Exact audit and loss ledger

The verification script independently compares the direct matching-fiber
sum with the selected-kernel hafnian on `746,496` exact integer evaluations
of four-vertex colored multigraphs. It also checks:

```text
selector-erasure collision: (1,0,0,1) versus (2,0,0,0);
phase-erasure collision:    (0,0,0,0) versus (2,0,0,0);
ten forced-leaf probes on a five-vertex hostile graph bank. (23)
```

The proof, rather than the finite audit, establishes the all-size theorem.

The exact information ledger is:

```text
raw edge occurrences
  -> aggregate only same-pair, same-endpoint-color parallels
  -> retain A_G(i,a;j,b)
  -> select by the full queried coloring
  -> contract over perfect pairings.
```

The first arrow loses information which no inherited-color amplitude can
observe. Erasing colors, weights, zeros, phase, or the matching contraction
loses observable information, as the two-vertex witnesses show. QED.
