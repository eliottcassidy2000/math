# THM-3020 -- the K-calculus closes

THM-3019 section 4 proved SFC(2) for `f = a + b z` by integration by parts,
and identified the obstruction to generalising: for `s >= 2` or `p >= 1`
there is no polynomial `u` with `u g' = c g`, so integrating by parts opens
onto the two-parameter family

```text
K(alpha,beta) = int_0^inf t^alpha (1+lam t^s)^beta e^{-t} dt
              = sum_{j=0}^{beta} C(beta,j) (alpha+sj)! lam^j,
I_m = K(pm, m),
```

"instead of closing on the `I_m`". This file closes it.

## 1. The alpha-direction is diagonal (K1)

Let `theta = lam d/dlam`, so `theta lam^j = j lam^j`. Then

```text
K(alpha+1,beta) = (alpha+1+s theta) K(alpha,beta),                    (K1)
```

because `(alpha+sj+1)! = (alpha+sj+1)(alpha+sj)!`. Iterating,
`K(alpha,beta) = V_alpha(theta) K(0,beta)` with
`V_alpha(X) = prod_{i=1}^{alpha}(i+sX)`. **Every `alpha`-index is a diagonal
(multiplier) operator applied to `alpha = 0`** -- the family is not
two-parameter at all.

## 2. The beta-direction, and the closure (K2), (K3)

From `(1+lam t^s)^{beta+1} = (1+lam t^s)^beta + lam t^s (1+lam t^s)^beta`,

```text
K(alpha,beta+1) = K(alpha,beta) + lam K(alpha+s,beta).                (K2)
```

Combining (K1) and (K2) with `I_{m+1} = K(pm+p, m+1)`:

```text
I_{m+1} = [ P_1(theta) + lam P_2(theta) ] I_m,
P_1(X) = prod_{i=1}^{p}   (pm+i+sX),
P_2(X) = prod_{i=1}^{p+s} (pm+i+sX).                                  (K3)
```

**This is the closure.** For every `p >= 0` and `s >= 1`, the passage
`I_m -> I_{m+1}` stays inside the cyclic `C[lam,theta]`-module generated by
`I_m`; the `K(alpha,beta)` are all diagonal transforms of the single
sequence. The `p = 0, s = 1` case of (K3) is `I_{m+1} = (1 + lam(1+theta))I_m`,
which is THM-3019's recurrence `I_m = 1 + m lam I_{m-1}` in operator form.

Verified symbolically for `s = 1,2,3`, `p = 0,1,2`, `m = 1..4`.

## 3. The ODE and a universal multiplicity bound (K4)

The coefficient recursion `(j+1)c_{j+1} = (m-j) prod_{i=1}^{s}(pm+sj+i) c_j`
is, in operator form,

```text
I_m' = (m - theta) prod_{i=1}^{s} (pm + s theta + i) I_m.              (K4)
```

This is a linear ODE of order `s+1`; its top-order term is
`-s^s lam^{s+1} d^{s+1}/dlam^{s+1}`, so **every `lam != 0` is an ordinary
point**. A nonzero solution therefore vanishes to order at most `s` there:

```text
mult_{lam_0}(I_m) <= s     for every p, s and every lam_0 != 0.
```

(`lam_0 = 0` is never a root: `I_m(0) = (pm)! != 0`.)

## 4. Consequences at p = 0 (K5)

Here (K3) reads `I_{m+1} = (1 + lam W(theta))I_m`, `W = V_s`. Let `lam_0` be a
common root of `I_m, I_{m+1}`, of multiplicity `mu >= 1` in `I_m`. Then
`W(theta)I_m` vanishes at `lam_0`, and matching orders in (K4) forces
`mult(W(theta) I_m) = mu`. But `W(theta)` has order `s` and, on a function of
multiplicity `mu >= s`, lowers the multiplicity by exactly `s` (leading
coefficient proportional to `mu(mu-1)...(mu-s+1) != 0`). Hence

```text
mu <= s-1,        and       mult(I_{m+1}) >= mu + 1.
```

For `s = 1` this gives `mu <= 0`, contradicting `mu >= 1`:

**SFC(2) holds for `p = 0`, `s = 1` at every window `k`** -- recovering
THM-3019 (S4) from the calculus, and now as one case of a general bound.

## 5. The equal-degree reduction (K6)

Taking `alpha = 0`, `beta = m` in (K2) gives `I_{m+1} = K(0,m) + lam K(s,m)`.
Since `I_m(0) = 1 != 0`, `lam` is a unit modulo `I_m`, so

```text
gcd(I_m, I_{m+1}) = gcd(K(0,m), lam K(s,m)) = gcd(K(0,m), K(s,m)).
```

Therefore, for `p = 0`,

```text
SFC(2) at window k   <=>   Res( K(0,k+1), K(s,k+1) ) != 0,             (K6)
```

a resultant of two polynomials of the **same** degree `m = k+1`, whose
coefficient vectors differ only by the diagonal multiplier

```text
w_j = prod_{i=1}^{s} (sj+i) = (sj+s)!/(sj)!,   strictly increasing in j.
```

This replaces the original mismatched pair `(I_m, I_{m+1})` of degrees
`m, m+1` by a Hadamard-type pair of equal degree: `A(lam) = sum a_j lam^j`
and `B(lam) = sum a_j w_j lam^j` with `a_j = C(m,j)(sj)! > 0`. Verified
symbolically for `s = 1..4`, `m = 1..6`.

## 6. Scope

The gap named in THM-3019 is closed **as a calculus**: (K1)-(K3) show the
`K(alpha,beta)` never leave a cyclic module, and (K4) supplies a universal
multiplicity bound for all `p, s`. What is *not* closed is the conjecture:
`s = 1, p = 0` is proved, and for `s >= 2` the problem is now the sharp
equal-degree question (K6) -- can a positive-coefficient polynomial and its
Hadamard product with the increasing multiplier `w_j` share a root?
**[SETTLED by THM-3021: as posed the answer is YES -- `45 + 14 lam + lam^2`
is a counterexample at `s = 2` -- so positivity of coefficients is the wrong
hypothesis and no Polya-Schur argument can work. The surviving content is
squarefreeness of the Appell sequence `Phi_n(z) = int (z-u)^n dnu(u)`.]** The
`p >= 1` families need the full (K3), where `P_1, P_2` depend on `m` and the
multiplicity argument of section 4 weakens (the two terms have orders `p` and
`p+s`, so no order matching is forced).

Referee: (K1)-(K4) verified symbolically as above; (K6) identity and gcd
equality verified for `s = 1..4`, `m = 1..6`.
