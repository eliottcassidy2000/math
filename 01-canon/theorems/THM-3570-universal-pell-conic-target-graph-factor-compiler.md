# THM-3570 -- universal Pell-conic target-graph factor compiler

**RESERVED / UNPROVED EMPTY STUB.**  Reserved for the proposed equivalence
between reducibility of an arbitrary target-graph core cubic and a rational
parameter `q` satisfying `phi=4(q^2+bq+4a)/q^3`, with root
`x=-2q/(q^2+2bq+12a)`.  No theorem is asserted until the converse conic
parametrization, exceptional points, and zero/root cases are fully audited.
