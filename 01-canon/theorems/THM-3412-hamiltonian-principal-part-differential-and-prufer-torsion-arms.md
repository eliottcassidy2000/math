# THM-3412 -- Hamiltonian principal-part differential and Prüfer torsion arms

**PROVED + VERIFIED-EXACT + INDEPENDENTLY DERIVATION-AUDITED.**

## 1. Inheritance and connection contract

[THM-3406](THM-3406-affine-modification-power-jets-and-principal-part-transgression.md)
identifies the full principal-part tower for a linear-in-`z` polynomial but
uses only one distinguished cycle, the localized Bezout class `eta`.
[THM-3386](THM-3386-linear-z-canonical-divergence-minimal-polynomial-collision-law.md)
computes the cyclic module generated by its transgression.  The question here
is what the Hamiltonian differential does to *every* principal part.

The answer separates three operations which do not commute:

```text
take finite cycles,       pass to the denominator associated graded,
take the filtered direct limit.                                      (1)
```

At a repeated root, taking the graded kernel first creates many classes which
do not lift to cycles.  Taking finite cycles first gives one growing Jordan
arm.  Taking the limit turns that arm into a Prüfer module.  Coincident
`f`-values merge the annihilator of one diagonal class, but they do not merge
the full root arms.

| item | exact content |
|---|---|
| source | the filtered two-term complex `(Q_q,Dbar)` inside `Pi=S/R` |
| target | finite cycle/cokernel modules, their persistent limit, and `C_P` |
| map | `nabla_q`, multiplication by `g` between levels, and the connecting map `delta` |
| preserved | factor arm, root multiplicity slope, `P`-primary support, and denominator depth |
| lost by collision annihilators | the number of roots over one `f`-value |
| lost by `ker` after `gr` | the extension equations needed to lift a graded cycle |
| required sidecar | the filtered kernel, not only the graded kernel or one cyclic class |
| cheapest hostile | `f=x,g=x^3,q=2`: finite cycles have one block `4`, but the graded kernel has blocks `3,1` |

## 2. The full finite differential

Let `K` be a field of characteristic zero.  Put

```text
R=K[x,z],                P=f(x)+g(x)z,               0!=g in K[x],
t=P-f(x)=g(x)z,          B=K[P,x]=K[x,t],            I=(g,t),       (2)
S=R[g^(-1)]=B[g^(-1)],   Pi=S/R,
Q_q=(g^(-q)B+R)/R = B/I^q.                                           (3)
```

The last equality, the injective transition

```text
iota_q:Q_q -> Q_(q+1),                 [a] |-> [ga],                 (4)
```

and the grade

```text
G_q=Q_q/Q_(q-1)=B/(g,t^q)                                      (q>=1) (5)
```

are the exact affine-modification filtration of THM-3406.

Assume the gradient row is unimodular:

```text
(P_x,g)=R.                                                          (6)
```

Let

```text
D=D_P=P_x partial_z-g partial_x.                                    (7)
```

Since `D(P)=0`, its expression on `B=K[P,x]=K[x,t]` is

```text
D=g(f' partial_t-partial_x).                                        (8)
```

Also `D(g)=-gg'`.  Direct differentiation therefore gives the complete
numerator formula

```text
D(a/g^q)=nabla_q(a)/g^q,
nabla_q=g(f' partial_t-partial_x)+qg'.                               (9)
```

The operator `nabla_q` preserves `I^q`; equivalently, `(9)` descends to the
induced differential on `Q_q`.  This also follows intrinsically because
`a/g^q in R` implies `D(a/g^q) in R`.  The transition is a chain map, since

```text
nabla_(q+1)(ga)=g nabla_q(a).                                      (10)
```

Thus no denominator correction term is missing from `(9)`.

Let

```text
s=the monic radical of g,
c=the monic gcd(g,g'),          d=deg(g), r=deg(s), m=deg(c)=d-r.    (11)
```

Condition `(6)` is equivalent, for nonconstant `g`, to

```text
g=lambda product_alpha (x-alpha)^(e_alpha),
e_alpha>=2 for every geometric root alpha,       gcd(f',g)=1.       (12)
```

In particular `(g)=(sc)`, `c` has root multiplicity `e_alpha-1`, and both
`g` and `g'` are divisible by `c`.

Define the finite cycle module

```text
Z_q=ker(nabla_q:B/I^q -> B/I^q).                                   (13)
```

Reduction of coefficients gives a canonical surjection

```text
rho_q:B/I^q -> B/(c,t^q).                                           (14)
```

It is well-defined because `I^q` is contained in `(c,t^q)`.  Equations
`(9)` and `(11)` give `rho_q nabla_q=0`.  In fact the sequence

```text
0 -> Z_q -> B/I^q --nabla_q--> B/I^q --rho_q--> B/(c,t^q) -> 0      (15)
```

is exact for every `q>=1`.  Consequently

```text
dim_K Z_q=dim_K coker(nabla_q)=qm.                                  (16)
```

The right-hand identification in `(15)` is canonical.  The following useful
identification of the kernel is an isomorphism of `K[P]`-modules, but is not
canonical:

```text
Z_q ~= K[x]/(c^q),                    P acts as multiplication by f(x).
                                                                         (17)
```

## 3. Proof by the root-local recurrence

All modules in `(15)` are finite over `K`.  Extend scalars to an algebraic
closure `k`, apply the CRT root idempotents, and complete at one root `alpha`.
Write

```text
b=f(alpha),               e=ord_alpha(g)>=2.                         (18)
```

Because `f'(alpha)!=0`, `y=f(x)-b` is a formal parameter.  Scaling `z` by a
formal unit turns `g z` into `y^e w`.  This local coordinate change has unit
Jacobian, so it changes the Hamiltonian operator by a unit and preserves its
kernel and cokernel.  It is therefore enough to take

```text
f=y,                 g=y^e,                 t=y^e w.                 (19)
```

The local level is

```text
A_(e,q)=k[y,t]/(y^e,t)^q
       =span{y^a t^j:0<=j<q, 0<=a<e(q-j)}.                           (20)
```

On its displayed basis, `(9)` is the exact two-term rule

```text
nabla_q(y^a t^j)
 =(qe-a)y^(a+e-1)t^j+j y^(a+e)t^(j-1).                              (21)
```

It raises total `(y,t)`-degree by `e-1`.  For a homogeneous vector

```text
v=sum_j c_j y^(n-j)t^j,                                              (22)
```

the coefficient equations are the bidiagonal recurrence

```text
(qe-n+j)c_j+(j+1)c_(j+1)=0.                                        (23)
```

The endpoint restrictions in `(20)`, together with the nonzero coefficients
in `(23)`, give one kernel line in each degree

```text
n=q,q+1,...,eq-1                                                    (24)
```

and no kernel line in any other degree.  Multiplication by

```text
P-b=y+t                                                             (25)
```

joins the consecutive lines nontrivially.  Hence the local kernel is one
Jordan block:

```text
Z_(q,alpha)=k[P]/(P-b)^(q(e-1)).                                    (26)
```

There is also an explicit lowest-degree generator.  Holding `P` fixed,
`D=-y^e partial_y`; a primitive of `w^(q-1)` is

```text
h_(e,q)=sum_(j=0)^(q-1)
  [(-1)^j binom(q-1,j)/(eq-j-1)]
  (P-b)^(q-1-j)y^(j-eq+1).                                         (27)
```

Its numerator `a_(e,q)=y^(eq)h_(e,q)` is homogeneous of degree `q`, lies in
`A_(e,q)`, and satisfies

```text
D(h_(e,q))=w^(q-1),           nabla_q(a_(e,q)) in (y^e,t)^q.         (28)
```

The classes `(P-b)^j a_(e,q)` for `0<=j<q(e-1)` are nonzero and exhaust
the lines `(24)`; the next power vanishes.  This gives a second proof of
`(26)` and records the transgression target.

The local target of `rho_q` is

```text
k[y,t]/(y^(e-1),t^q),                                               (29)
```

of dimension `q(e-1)`.  Formula `(21)` gives
`im(nabla_q) subset ker(rho_q)`, and `(24)` makes their dimensions equal.
This proves exactness in `(15)` after a faithfully flat extension, hence over
`K`.

Over `k`, `(26)` yields the full root decomposition

```text
Z_q tensor_K k
 = direct_sum_(g(alpha)=0) k[P]/(P-f(alpha))^(q(e_alpha-1)).         (30)
```

The root summands remain separate when several roots have the same value of
`f`.  Comparing `(30)` with the root decomposition of `K[x]/c^q` proves
`(17)` by the classification of finite modules over the PID `K[P]`.  Choosing
generators, and therefore the isomorphism in `(17)`, is noncanonical.

## 4. The associated-graded exact complex and its false extra cycles

Reduce `(9)` modulo `(g,t^q)`.  The first summand vanishes, so the differential
on `G_q` is simply

```text
gr_q(Dbar)=multiplication by qg'.                                   (31)
```

Characteristic zero is used here: `q` is a unit.  Since
`gcd(g,g')=c`, multiplication by `s` gives the exact four-term complex

```text
0 -> B/(c,t^q) --times s--> B/(g,t^q)
  --times qg'--> B/(g,t^q) -> B/(c,t^q) -> 0.                       (32)
```

Thus the graded kernel and cokernel are both canonically modeled by
`B/(c,t^q)` and both have dimension `qm`.

The `P`-module structures on the finite kernel and finite cokernel are very
different.  At a root of multiplicity `e`, the kernel has the single block
`q(e-1)` from `(26)`.  On the cokernel `(29)`, multiplication by
`P-b=y+t` has the characteristic-zero Clebsch--Gordan block sizes

```text
q+e-2, q+e-4, ..., |q-(e-1)|+1,                                   (33)
```

one for each `0<=j<min(q,e-1)`.  For example, `e=3,q=2` gives the kernel
block `4` but cokernel/graded-kernel blocks `3,1`.  This is the smallest
non-self-dual hostile.

Put the inherited filtration on the full cycle module

```text
V=ker(Dbar:Pi->Pi),             F_q V=V intersect Q_q=Z_q.           (34)
```

Taking symbols gives a natural injection

```text
gr_q^F(V) -> ker(gr_q(Dbar):G_q->G_q).                              (35)
```

Its source, by `(30)` and the transition calculation below, is

```text
gr_q^F(V) tensor_K k
 =direct_sum_alpha k[P]/(P-f(alpha))^(e_alpha-1),                    (36)
```

and has dimension `m`, independent of `q`.  Its target has dimension `qm`.
Therefore the kernel-after-associated-graded operation overcounts the true
liftable symbols by the sharp amount

```text
dim_K coker((35))=(q-1)m.                                           (37)
```

At `q=1` there is no deficit.  For every `q>1` and nonconstant `c`, the
deficit is positive.  The destroyed datum is exactly the sequence of lower
denominator equations `(23)` required to lift a top symbol.

## 5. Persistence and one Prüfer arm per root

Transition `(4)` restricts to an injection `Z_(q-1)->Z_q`.  On the local
cyclic module `(26)`, its image is necessarily the unique submodule of length
`(q-1)(e-1)`.  Equivalently, after choosing a generator it is multiplication
by `(P-b)^(e-1)`.  This proves `(36)` and gives

```text
V tensor_K k
 =direct_sum_(g(alpha)=0)
   k[P,(P-f(alpha))^(-1)]/k[P].                                    (38)
```

Each summand in `(38)` is the Prüfer module at the indicated maximal ideal.
Roots with equal `f`-value contribute multiple copies of the same Prüfer
module.  They do not fuse into one longer arm.

Over `K`, the compatible filtered identification can be written

```text
(V,F_bullet) ~= colim_q(K[x]/c^q, times c)
              =K[x,c^(-1)]/K[x],                                  (39)
```

with `P` acting as `f(x)`.  The filtration `F_qV`, its CRT factor summands,
and its embedding in `Pi` are canonical.  The displayed identification in
`(39)` requires compatible cyclic generators and is noncanonical.

The cokernel persistence goes in the opposite direction.  Under the
canonical description `(15)`, the map induced by `(4)` is

```text
B/(c,t^q) -> B/(c,t^(q+1)),              [a] |-> [ga]=0.             (40)
```

Hence every finite cokernel class dies at the next level.  Filtered colimits
are exact, so

```text
coker(Dbar:Pi->Pi)=0.                                                (41)
```

The finite `H^1` terms in `(15)` are therefore ephemeral; the persistent
objects are precisely the cycle arms `(38)`.

## 6. The complete response-module split

Let

```text
C_P=R/D(R),                 C_S=S/D(S).                              (42)
```

THM-3406 gives the connecting injection

```text
delta:V -> C_P,                 delta([h])=[D(h)].                   (43)
```

The long exact sequence of the two-term localization complexes, together
with `(41)`, is the short exact sequence

```text
0 -> V --delta--> C_P -> C_S -> 0.                                  (44)
```

Holding `P` fixed gives `D=-g partial_x` on `S`.  The map

```text
[a] in C_S |-> [-a dx/g]                                            (45)
```

identifies `C_S` with the algebraic de Rham cohomology of
`K[x,g^(-1)]`, tensored with `K[P]`.  The simple-pole forms

```text
dx/s, x dx/s, ..., x^(r-1) dx/s                                    (46)
```

are a basis.  Equivalently,

```text
C_S=direct_sum_(j=0)^(r-1) K[P][c x^j] ~= K[P]^r.                   (47)
```

The representatives `c x^j` already lie in `R`, so `(47)` supplies an
explicit `K[P]`-linear section of `(44)`.  Consequently

```text
C_P ~= K[P]^r direct-sum V
    ~= K[P]^r direct-sum K[x,c^(-1)]/K[x].                          (48)
```

The torsion submodule and its denominator filtration are canonical:

```text
tors_(K[P])(C_P)=delta(V).                                          (49)
```

Indeed `V` is elementwise torsion by `(17)`, whereas `C_S` is free.  The
chosen free basis/section in `(47)` and the principal-part model in `(39)`
make `(48)` explicit, but the direct-sum identification is not intrinsic.

If `g` is a unit, then `s=c=1`, `r=m=0`, `Pi=V=C_P=0`, and every displayed
formula has its empty interpretation.

## 7. Exact polynomial invariants and the diagonal Bezout class

Let `psi` and `chi` be the monic minimal polynomials of multiplication by
`f` on `K[x]/s` and `K[x]/g`, respectively, as in THM-3406.  Put

```text
kappa=chi/psi,
Omega(T)=det(T-m_f | K[x]/c)
        =Res_x(c(x),T-f(x)).                                        (50)
```

Then `kappa` is the minimal polynomial of `f` on `K[x]/c`.  The finite
kernel invariants are

```text
Ann_(K[P])(Z_q)=(kappa(P)^q),
charpoly(P | Z_q)=Omega(T)^q.                                      (51)
```

Every persistence quotient `F_qV/F_(q-1)V` has minimal polynomial `kappa`
and characteristic polynomial `Omega`.  The canonical cokernel in `(15)`
has

```text
Ann_(K[P])(B/(c,t^q))=(kappa psi^(q-1)),
charpoly(P | B/(c,t^q))=Omega(T)^q.                                 (52)
```

Over `k`, if

```text
M_b=max{e_alpha:f(alpha)=b},                                        (53)
```

then `(52)` has local annihilator exponent `q+M_b-2`, in agreement with
the largest block in `(33)`.

The canonical Bezout cycle `eta` of THM-3406 occupies only a diagonal slice
of this full module.  On a root arm of multiplicity `e`, its nonzero
component is the unique length-`e` submodule of `F_2V`; its intersection
with `F_1V` is `(P-b)eta`, of length `e-1`.  If several roots have the same
value `b`, the cyclic span of the tuple uses the least common multiple of
their annihilators, hence only the maximum `M_b`.  Thus

```text
Ann(K[P]eta)=(chi),                                                  (54)
```

while `(30)` and `(38)` retain every collided arm separately.  The nonsplit
`psi/chi` support--thickness sequence of THM-3406 is the first two-level
window of this infinite persistence picture, not the whole torsion module.

## 8. Frozen controls and scope

The exact companion freezes the following mutually separating cases.

| control | finite kernel over the displayed base field | feature |
|---|---|---|
| `f=x, g=x^e` | `K[P]/P^(q(e-1))` | one root; slope `e-1` |
| `f=x, g=x^2(x-1)^3` | `K[P]/P^q direct-sum K[P]/(P-1)^(2q)` | distinct values |
| `f=x^2, g=(x^2-1)^2` | two copies of `K[P]/(P-1)^q` | equal-value collision, not fusion |
| `f=x^2, g=(x-1)^2(x+1)^3` | blocks `q,2q` at `P=1` | unequal collided slopes |
| `f=x, g=(x^2+1)^2` over `Q` | `Q[P]/(P^2+1)^q` | nonsplit irreducible arm |
| `f=x^2, g=(x^2+1)^2` over `Q` | two copies of `Q[P]/(P+1)^q` | nonsplit root collision |

The first control with `e=3,q=2` also freezes the sharp warning `(33)--(37)`.
The equal collision freezes the distinction between the diagonal class
`Ann(eta)=(P-1)^2` and the two independent persistent root arms.

Characteristic zero is essential to `(12)`, `(23)`, `(27)`, `(31)`, and the
de Rham calculation.  THM-3406's Frobenius hostile shows that even the
connecting injection can fail in characteristic `p`.

Finally, this theorem completely computes a response sidecar only after the
presentation `P=f(x)+g(x)z` is given.  By THM-2063 that stratum is already
tame.  Nothing here proves that a general Keller pair admits such an affine
modification, that its boundary filtration is an ordinary power filtration,
or that these torsion arms control an inverse cover.  No new `JC(2)`, `DC(2)`,
`A4/S4`, or nonmonomial terminal case follows.
