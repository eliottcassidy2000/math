# THM-4986 - the spanning-tree twin of the 7/21 proof

Proofs: [PROOF.md §6](../../05-knowledge/results/genesis_20261109/PROOF.md). Dictionary table:
[note](../../05-knowledge/results/genesis_20261109/README.md).

1. **(PROVED) Block floor.** If B is 2-connected and simple with m >= 3 vertices, then tau(B) >= m, with equality iff
   B = C_m.
2. **(KNOWN) The 2-hole.** {tau(G) : G connected simple} = {1} ∪ {N >= 3}. The proof runs as follows:
   - tau is the product over blocks;
   - bridges have tau = 1;
   - nontrivial blocks have tau >= 3 by (1);
   - 2 is prime;
   - cycles give every N >= 3.
3. **(PROVED) Crevasse lemma.**
   - (i) If the count is the product over irreducible blocks and every finite family of blocks is the block family of
     some structure, then the set of counts is the multiplicative monoid generated by Irr = the set of irreducible
     counts.
   - (ii) If moreover the floor F(m) of irreducible counts at order m is nondecreasing and unbounded, then whether v is
     in Irr is decided by the finitely many orders m <= B(v) = max{m : F(m) <= v}.

   (Audit G1, m11: (i) needs only multiplicativity and realizability; the floor does its work in (ii).) Instances:

   | world | blocks | floor | gaps |
   | --- | --- | --- | --- |
   | tournaments | strong components | Busch's f(m) | 7 and 21: 7 prime in (f(4), f(5)), and 21 = 3·7 with 21 not in Irr(<= 6) |
   | simple graphs | blocks | F(m) = m | 2: prime in (1, 3) |

4. **(ANALOGY, exact anchors) The dictionary**:

   | tournaments | simple graphs |
   | --- | --- |
   | condensation (linear) | block-cut tree |
   | H multiplicative | tau multiplicative |
   | transitive (H = 1) | tree (tau = 1) |
   | insertion lemma (equality iff a singleton component is added) | tau(G) >= deg(v)·tau(G - v) for non-cut v (equality iff v is pendant) |
   | Moon chains | ear decompositions |
   | Busch floor and interval chains | cycle floor and cycles |
   | crevasses (5, 9), (15, 25) | crevasse (1, 3) |
   | OCF I(Omega, 2) | Kirchhoff det L_0 |
   | first creators, n(h) | Sedláček's minimal graphs, alpha(N) |
   | bof-Royle conjecture (Chan-Pak, Conj. 6.2) | cycles fill all N >= 3 |
   | born at the floor bound: 3, 5, 9, 11, 13, 17, 19, 23, 35, 39, 63 (THM-4942 (6)) | fixed points of alpha: 3, 4, 5, 6, 7, 10, 13, 22 (Nebeský 1973) |

5. **(PROVED / FINITE-EXACT) The opposite first-creator mechanism.**
   - Tournaments: R_H(n) = max H(n - 1)·2^(n - 1)/n! is 0.667, 0.667, 0.571, 0.600, 0.466, 0.474, 0.404, 0.407 for
     n = 5..12; 0.349 <= R_H(13) <= 0.751; R_H(14) >= 0.3495.
   - Graphs: R_tau(m) = 2^(m - 1)(m - 1)^(m - 3)/m^(m - 2) >= 2^(m - 1)/(e·m) -> infinity.
   - FINITE-EXACT tau-spectra of orders <= 8, all labelled graphs:

     | m | connected labelled graphs | values abs(S_tau(m)) | max tau | new values | labelled share new |
     | --- | --- | --- | --- | --- | --- |
     | 4 | 38 | 5 | 16 | 3 | 0.2632 |
     | 5 | 728 | 16 | 125 | 11 | 0.3475 |
     | 6 | 26,704 | 65 | 1,296 | 49 | 0.4190 |
     | 7 | 1,866,256 | 386 | 16,807 | 321 | 0.5150 |
     | 8 | 251,548,592 | 3,700 | 262,144 | 3,314 | 0.5719 |

     abs(S_tau(m)) reproduces OEIS A182290 (1, 1, 2, 5, 16, 65, 386, 3700, ...) and the connected counts reproduce A001187, which validates `tau_share.c`. The spectrum is sparse: 3,700 values below 262,144. Tournament spectra are nearly solid below their maximum (1,520 of the 1,679 odd values up to 3,357 at order 9).
