# THM-5151 - exact strong/decomposable slot pairs, R-factor sites, one-apex B, a prime pair

Notation and inherited facts follow PROOF.md section 0.

- Q_T(t) = sum_j F_j(T) binom(t, j) counts path covers in t labelled slots, with empty slots allowed.
- Q is multiplicative over ordinal sums (THM-3166).
- Q_T = sum over odd-cycle packings P of 2^|P| t^(u(P)+|P|) (Grinberg–Stanley 1.39; Session 310).
- ord_0(Q_T) counts singleton and odd strong components once and even strong components twice (Session 310).

**(1) Shape.** Strong X of order >= 3 and non-strong Z with Q_X = Q_Z force |X| even and Z = Z1 => Z2, each Z_i a
singleton or of odd order and strong, with at most one singleton.

**(2) R-factors and sites.** Put R_S = Q_S / t^ord_0(S) for strong S, with R_TT1 = 1. Then

    Q_T = t^beta prod R_(S_i),   beta = s + o + 2e   (singleton, odd nontrivial, even strong components).

- Equal Q is equivalent to equal beta and equal R-product.
- For Q_T = Q_T', s(T') - s(T) = (o - o') + 2(e - e').
- The largest number of trailing sites over all realizations of Q is cap(Q) = beta - mu(R), where mu(R) is the least
  o + 2e among factorizations of R into R-factors of nontrivial strong tournaments.
- For Session 310's B^r, cap <= 2r - 1, and exceeding their r sites requires a merge.

**(3) No small odd merge.** For odd strong Y1, Y2 with |Y1| + |Y2| <= 10 there is no Z with
Q(Y1 => Y2) = Q(Z -> TT1).

**(4) Census to order 9.**

| order | H | strong classes (all C = 1) | partners |
|---:|---:|---:|---|
| 6 | 15 | 2 | Y5 -> TT1, Y5 code 152 (identical odd-cycle census) |
| 8 | 45 | 3 | C3 => Y5', Y5' code 739 |
| 8 | 95 | 2 (Session 310's B and converse) | A -> TT1, A any of 5 order-7 classes of one profile |

There are none at odd orders, by (1).

**(5) Uniquely Hamiltonian slice.** One-vertex extension with canonical forms from the unique Hamiltonian cycle
gives 1, 3, 8, 21, 55, 144, 377, 987, 2584 classes at orders 4..12.

- Order 10, exactly 6 collide:
  - H = 153: partner C3 => Y7;
  - H = 219: partner C3 => Y7; both members one-apex;
  - H = 317: partner Y9 -> TT1.
- Order 12: none collides with a (3,9) or (5,7) block sum.
- Outside C = 1 at order 10 (S3: strong tournaments with at most 5 backward arcs): the fourth profile H = 333
  has C = 5, in exactly 2 isomorphism classes (a converse pair). One member is
  X = (1002,1020,1017,1008,481,704,896,768,544,16), and its partner is C3 => Y7 with Y7 = classgen code 43104
  (H = 111).

**(6) One-apex.** Let O(w) have apex x and transitive body 1 -> 2 -> ... -> m (i -> j for i < j, so vertex 1 is
the body's top-ranked vertex), with w_i = 1 iff body vertex i beats x. Then

    Q = t^(m+1) + 2 sum_(a<b, w_a=0, w_b=1) sum_(l>=1) binom(b-a-1, 2l-2) t^(m+1-2l).

- O(w) is strong iff w_1 = 0 and w_m = 1, and then C = 1.
- Session 310's B ≅ O(0011111): the apex beats the two top-ranked body vertices and loses to the other five.
- The order-6 member is O(01001).
- For O(m,k) = O(0^m 1^k), H = 2 + (2^m - 1)(2^k - 1) (Session 191 (5); its words use the complementary letters).

**(7) Prime pair and clock.** Take X = (254,508,120,112,224,192,128,268,637,255) and
Y = (378,380,505,496,224,448,384,259,16).

- Q_X = t Q_Y, H = 317, Q_Y(2) = 9280.
- In Π with N = X^r rebased to Y^r -> TT_r:

      H_k = 60 P_M(3) 9280^r 2^(r-k) 3^k + 317^r H(M),   k = 0..r.

- With M = TT3, r = 2: 558,047,332,489 (prime) -> 837,070,948,489 -> 7 × 179,372,338,927.

**(8) Clock divisibility.** For a prime l not dividing 6c, l | I + c 2^(r-k) 3^k iff
(3/2)^k ≡ -I/(c 2^r) (mod l). For l = 7, where 3/2 is a primitive root:

- if 7 does not divide cI, exactly one k in every 6 consecutive gives a multiple of 7;
- if 7 | I but 7 does not divide c, none does.

**(9) Site budget.** If Q/t is realizable, cap(Q/t) = cap(Q) - 1. So cap(Q_N) does not change under Q-neutral
rebases of the right module and drops by one per transfer. The total number of transfers is at most
cap(Q_(N_0)): through order 9 this is s + d (detachable even components), and in general it is conjectured to be
the same (HYP-9678 (C)).

**(10) Partner cycles.**

- If Q_X = Q_(Y -> TT1), then C(Y) = c_(n-1)(X) + 2 d(X).
- If Q_X = Q(Y1 => Y2), then c_(n-1)(X) + 2 d(X) = 2 C(Y1) C(Y2).
- For strong one-apex X = O(w), c_(n-1)(X) = (n-3) + [w_2 = 0] + [w_(n-2) = 1].
