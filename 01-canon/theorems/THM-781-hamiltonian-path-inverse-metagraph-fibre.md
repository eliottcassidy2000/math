# THM-781 — Hamiltonian-path inversion of merged tournament-tiling fibres

Namespace claim for the exact two-way correspondence requested by the owner.

Known at reservation time: a fixed-path staircase tiling determines a labelled
tournament, hence its canonical isomorphism code and converse-merged orbit.
For an unmerged tournament class represented by `T`, the expected direct
inverse is the set of normalized tilings obtained from Hamiltonian paths of
`T`, modulo `Aut(T)`, suggesting fibre cardinality
`H(T)/|Aut(T)|`.

Still missing at reservation time: an executable path-normalization inverse,
proof that its duplicate quotient is exactly the automorphism action, equality
with every committed inverse fibre through `n=7`, and the precise doubling rule
for non-self-converse merged nodes.
