# THM-350: Finite Unordered Bucket Balance Layer

## Statement

Let `alpha` be a finite set, let

```text
q : alpha -> beta
```

be a bucket map, and let `moves` be a finite set of moves with action

```text
step : move -> alpha -> alpha.
```

For a bucket `b`, let `selfHalf(b)` and `crossHalf(b)` be the oriented
internal and escaping half-line sets from THM-348.

If the selected moves act as fixed-point-free involutions on `alpha`, then
`selfHalf(b).card` is even. Define

```text
internalLineCount(b) = selfHalf(b).card / 2.
```

Then

```text
2*internalLineCount(b) + crossHalf(b).card = |q^{-1}(b)| * |moves|.
```

Equivalently, the abstract oriented balance of THM-348 and the finite
fixed-point-free involution orbit lemma yield the unordered-line balance.

## Partner Map

The Lean development also introduces the natural partner map

```text
pairHalf(step)(x,u) = (step(u,x), u).
```

It proves:

- if each selected `step(u)` is involutive, then `pairHalf` is involutive;
- internal half-lines are closed under `pairHalf`;
- if each selected `step(u)` is fixed-point-free, then no internal half-line is
  paired with itself.
- a finite fixed-point-free involution has even cardinality;
- therefore fixed-point-free involutive move systems have even internal
  half-line cardinality and satisfy the unordered bucket balance.

Thus the route to the full tiling-cube specialization is sharply localized:
instantiate `step(u,x)=x xor u` for nonzero tiling masks. This final
Boolean-cube specialization is now proved as THM-351.

THM-352 adds the transport-matrix version: after defining
`transportHalf(b,c)` by target bucket, the off-diagonal row sum is exactly
`crossHalf(b)`, so this unordered balance becomes a row checksum for quotient
transport computations.

## Relation to THM-346 and THM-348

THM-348 is the unconditional oriented conservation law:

```text
|selfHalf_b| + |crossHalf_b| = |fiber_b| * |moves|.
```

THM-350 is the formal algebraic bridge from this identity to an unordered
formula for fixed-point-free involutive move systems:

```text
2*internalLineCount_b + |crossHalf_b| = |fiber_b| * |moves|.
```

THM-346 is the tiling-hypercube instance where the pairing is generated by
nonzero masks. THM-350 proves the full abstract orbit-parity bridge, and
THM-351 proves the Boolean mask specialization.

## Mathematical Reading

The useful distinction is no longer "proved versus unproved bucket balance."
The conservation, orbit parity, unordered algebra, and Boolean-mask
specialization are now proved in Lean.

```text
finite half-line conservation
+ fixed-point-free partner orbit structure
= unordered quotient transport law.
```

This pattern should apply not only to tiling masks, but to any finite
perturbation system whose moves are fixed-point-free involutions.
