# THM-224: Up-Laplacian ∂₂∂₂^T on K_n Has Eigenvalue n

## Statement

Let ∂₂ be the simplicial boundary operator from 2-chains to 1-chains on
the complete graph K_n (equivalently, the complete simplex Δ_{n-1}).

The matrix ∂₂^T ∂₂ (= C^T C where C is the transitive triple constraint
matrix for the transitive tournament) has:
- Nonzero eigenvalues all equal to **n**, with multiplicity (n-1)(n-2)/2
- Zero eigenvalue with multiplicity n-1

Equivalently: **∂₂^T ∂₂ = n · P** where P is the orthogonal projection
onto im(∂₂^T).

## Matrix Structure

C^T C is E × E where E = n(n-1)/2, indexed by undirected edges.

- Diagonal: (C^T C)_{(a,b),(a,b)} = **n-2** (edge appears in n-2 triples)
- Off-diagonal with shared vertex: (C^T C)_{(a,b),(a,c)} = **±1**
  - Sign = +1 if a is the "middle" vertex (between b and c in ordering)
  - Sign = -1 if a is an "extreme" vertex
- Off-diagonal without shared vertex: (C^T C)_{(a,b),(c,d)} = **0**

## Connection to β₁

For the transitive tournament T_n:
- rank(C) = (n-1)(n-2)/2 = E - (n-1) (maximal, giving β₁ = 0)
- nullity(C) = n-1 (the potential differences: h(i,j) = f(j) - f(i))

For a general tournament T:
- The constraint matrix C_T is a SUBMATRIX of rows from C
  (only transitive triples contribute constraints)
- β₁(T) = 0 ⟺ rank(C_T) = (n-1)(n-2)/2 (same as transitive)
- β₁(T) = 1 ⟺ rank(C_T) = (n-1)(n-2)/2 - 1

The rank deficiency occurs when removing rows (cyclic triples) causes
the submatrix to lose rank. Since C^T C = n·P, the constraints are
"maximally redundant" — each constraint can be recovered from the others
via the simplicial dependency relations (generated by 4-vertex subsets).

## Proof

**Step 1.** The symmetric group S_n acts on the edge space ℝ^E and the
triple space ℝ^T by permuting vertices. The boundary operator ∂₂ is
S_n-equivariant: σ ∘ ∂₂ = ∂₂ ∘ σ for all σ ∈ S_n.

**Step 2.** The up-Laplacian L_up = ∂₂^T ∂₂ commutes with the S_n action
on ℝ^E. By Schur's lemma, L_up acts as a scalar on each irreducible
S_n-subspace of ℝ^E.

**Step 3.** The edge space ℝ^E decomposes under S_n into two irreducible
representations:
- The "gradient" subspace im(∂₁^T) ≅ V_{[n-1,1]} of dimension n-1
  (spanned by ∂₁^T(v) = Σ_{w~v} e_{vw} for each vertex v)
- The "curl" subspace ker(∂₁) ∩ im(∂₂^T)^⊥ ⊕ im(∂₂^T)

Actually, ℝ^E decomposes as:
- im(∂₁^T): dimension n-1, the gradient 1-forms
- ker(∂₁) ∩ ker(∂₂^T)^T: dimension 0 (H₁ = 0 for simplex)
- im(∂₂^T): dimension (n-1)(n-2)/2, the exact 1-forms from 2-chains

On im(∂₁^T): L_up = 0 (since ∂₂^T ∂₂ ∂₁^T = 0 by ∂₁ ∂₂ = 0).
On im(∂₂^T): L_up acts as a scalar c.

**Step 4.** Compute c from the trace:
tr(L_up) = tr(∂₂^T ∂₂) = Σ ||∂₂(e)||² = 3 · C(n,3) = n(n-1)(n-2)/2
(each triple has 3 nonzero entries of magnitude 1).

Since L_up = c·P with rank(P) = (n-1)(n-2)/2:
tr(L_up) = c · (n-1)(n-2)/2

So c = n(n-1)(n-2)/2 ÷ (n-1)(n-2)/2 = **n**. ∎

## Consequences

1. **All singular values of ∂₂ on K_n equal √n.**
2. **The constraint matrix C has condition number 1** (on its column space).
3. **The redundancy ratio is (n-3)/n**: of C(n,3) constraints, only (n-1)(n-2)/2
   are independent, giving max_rank/C(n,3) = 3/n.
4. **β₁ is a DISCRETE invariant**: rank can only be (n-1)(n-2)/2 or one less,
   because the uniform spectrum means removing constraints either preserves
   rank (removed row was in span of others) or drops it by exactly 1.
