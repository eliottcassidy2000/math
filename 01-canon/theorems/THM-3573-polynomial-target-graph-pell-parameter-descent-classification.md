# THM-3573 -- polynomial target-graph Pell-parameter descent classification

**PROVED + VERIFIED-EXACT + INDEPENDENTLY PROOF/HOSTILE-AUDITED.**  The
rational parameter in THM-3570 has no hidden polynomial-descent branch.
Every factor-bearing nonzero polynomial target graph is generated by one
nonzero polynomial denominator, and the old `1 mod 3` degree gate becomes an
exact classification rather than only a necessary congruence.

Throughout, put

```text
R0=C[a,b],                         K=C(a,b).
```

The theorem concerns the fixed THM-1300 target-graph core cubic and does not
assert that one of its source factors is an affine plane.

## 1. Statement

Let `0!=phi in R0`.  THM-3570 says that its core cubic is reducible over `K`
if and only if some `q in K*` satisfies

```text
phi=4(q^2+bq+4a)/q^3.                                  (1)
```

For such a polynomial `phi`, every parameter `q` satisfying `(1)` has the
form

```text
q=1/H,                    0!=H in R0.                  (2)
```

Conversely, every nonzero `H in R0` gives a nonzero polynomial row

```text
phi_H=4H(1+bH+4aH^2)                                   (3)
```

whose core cubic is reducible.  Thus `(2)--(3)` classify the polynomial
descent of every rational parameter in THM-3570.

If

```text
m=deg_a(H),
```

then

```text
deg_a(phi_H)=3m+1.                                     (4)
```

In particular, every and only the resonant `a`-degrees `1 mod 3` occur.
This recovers THM-3564's necessary degree gate and realizes every one of its
allowed degrees.

The phrase "classify" here concerns pairs `(q,phi)`.  A fixed `phi` could in
principle have several rational roots of THM-3570's parameter cubic and hence
several associated `H`; no injectivity of the map `H -> phi_H` is claimed.

## 2. The numerator is a unit

Write a putative parameter in reduced form

```text
q=N/D,                    N,D in R0, gcd(N,D)=1.        (5)
```

Substituting `(5)` in `(1)` gives

```text
phi=4D(N^2+bND+4aD^2)/N^3.                             (6)
```

Since `phi` is polynomial and `N` is coprime to `D`, the UFD `R0` gives

```text
N^3 | N^2+bND+4aD^2.                                   (7)
```

Reducing `(7)` modulo `N` and using `gcd(N,D)=1` yields

```text
N | a.                                                  (8)
```

The element `a` is irreducible in `C[a,b]`, so `N` is either a unit or an
associate of `a`.  It remains to exclude the apparent second branch.

Suppose

```text
N=c a,                         c in C*.                 (9)
```

Then `(7)` requires `a^2` to divide

```text
V=c^2 a+bcD+4D^2.                                      (10)
```

Expand

```text
D=D0(b)+aD1(b)+a^2D2(b)+... .                           (11)
```

Because `a` and `D` are coprime, `D0!=0`.  The constant and linear
coefficients of `(10)` are

```text
[a^0]V = D0(bc+4D0),
[a^1]V = c^2+(bc+8D0)D1.                               (12)
```

Their required vanishing first gives

```text
D0=-bc/4,                                               (13)
```

and then

```text
c(c-bD1)=0.                                             (14)
```

Thus `D1=c/b`, which is not an element of `C[b]`.  This contradiction
excludes `(9)`.  Hence `N` is a unit.  Rescaling the reduced pair in `(5)`
now gives exactly `q=1/H`, and `(1)` becomes `(3)`.

Conversely, `(3)` is visibly polynomial.  It is also nonzero: if
`1+bH+4aH^2=0`, then `H(b+4aH)=-1`, so `H` is a unit of `C[a,b]`; but a
nonzero constant `H` leaves an uncancellable `bH` term.  This completes the
classification.

## 3. Exact degree law

Let the leading `a`-coefficient of `H` be `h_m(b)!=0`.  The three terms in
`(3)` have `a`-degrees at most

```text
m,                         2m,                         3m+1.
```

The last is strictly largest for every `m>=0`, and its coefficient is
`16h_m(b)^3`.  There is therefore no top-row cancellation, proving `(4)`.

The case `m=0` is exactly the first resonance.  Setting

```text
H=-h(b)/2
```

recovers THM-3565:

```text
phi=-2h^3a+b h^2-2h.                                   (15)
```

The first new resonance, `deg_a(phi)=4`, is completely parametrized by

```text
H=u(b)a+v(b),                    u!=0.                  (16)
```

Expanding `(3)` gives

```text
phi = 16u^3 a^4
    + 48u^2v a^3
    + 4u(bu+12v^2)a^2
    + 4(2buv+u+4v^3)a
    + 4v(bv+1).                                         (17)
```

Thus even the first open degree has a rigid cube/tangent leading packet,
not an arbitrary quartic target graph.

## 4. Polynomial factor packet

Put

```text
U=1+bH+4aH^2,
R=1+2bH+12aH^2,
M=48a^2H^2+8abH+16a-b^2.                               (18)
```

For THM-3570's core cubic

```text
E_phi(X)=L_phi X^3+(4+3bphi)X+2phi,
L_phi=27a^2phi^2+18abphi+16a-b^3phi-b^2,               (19)
```

substitution of `(3)` gives the exact identities

```text
L_phi=R^2M,
E_phi(X)=(RX+2H)(RMX^2-2HMX+4U).                       (20)
```

The first factor supplies THM-3570's rational root

```text
X=-2H/R.                                                (21)
```

The quadratic cofactor has discriminant

```text
-4M(2+3bH+12aH^2)^2.                                   (22)
```

Thus its remaining factor behavior is controlled by the square class of
`-M`; polynomial descent does not erase that sidecar.

As a hostile control, take `H=a`.  Then

```text
phi=4a+4ba^2+16a^4.                                    (23)
```

Here

```text
-M=b^2-8a^2b-48a^4-16a
```

is a nonsquare in `C(a,b)`: viewed as a quadratic in `b`, its discriminant is

```text
64a(4a^3+1),                                            (24)
```

which is nonsquare in `C(a)`.  Hence `(23)` has exactly the compiled rational
linear factor and an irreducible quadratic cofactor.  This prevents the
classification from being misread as complete splitting.

## 5. Preserved and destroyed information

The map in this theorem is

```text
polynomial denominator H
  -> rational Pell parameter q=1/H
  -> polynomial target graph phi_H
  -> one rational core factor.                          (25)
```
