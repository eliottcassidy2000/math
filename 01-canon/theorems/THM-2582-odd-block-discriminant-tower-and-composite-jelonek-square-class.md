# THM-2582 -- odd blocks carry the outer discriminant class

**RESERVED / UNPROVED EMPTY STUB.**

Reserved for the field-level discriminant-of-a-norm law: an odd-degree
family of conjugate polynomial blocks contributes the discriminant class of
the indexing extension because its cross-block resultant is alternating.
The intended fixed-map application combines this law with the exact norm
identity for the sporadic cubic Keller map to decide globally whether the
degree-nine `x`-eliminant of `F o F` has odd square-free part `H` rather than
`L H`.  No statement about a general Keller map, higher tower level, JC(2),
or discriminant scheme multiplicities is reserved.
