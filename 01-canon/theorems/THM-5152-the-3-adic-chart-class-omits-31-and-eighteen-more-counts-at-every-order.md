# THM-5152 - the 3-adic chart class omits 31 and eighteen more counts at every order

Let G be the grammar generated from a vertex by ordinal joins X => Y and cyclic joins C3[X,Y,Z]; its spectrum is
Session 268's. Session 312 proves that the switching closure of G is exactly the class C of 3-adic determinant
orientations chi(det(v_i, v_j)), v_i in Q_3^2: the tournaments read off the digit-reversed address chart.

**(1) What is proved: an inclusion.**
- C is hereditary.
- Deleting singleton components keeps both membership in C and H.
- H is the product over the strong components.
- Busch's bound: f(n) = min{3^a 5^b : 2a + 3b = n − 1} = 3, 5, 9, 15, 25, 45, 75, 125, 225, 375 for n = 3..12.

So every value below B attained by C is a product of values of strong members of C of order <= n_0, where
f(n_0 + 1) >= B. A prime or 7p value missed by those strong members is missed at every order (7 is never a count,
THM-1370).

The converse fails. C is not closed under ordinal sums: no strong order-5 member with H = 13 stays in C after adding
a sink or a source. A composite value whose factors are all chart values may therefore still be omitted. By
heredity, it suffices to test the singleton-free ordinal sums of the relevant strong members, in every order.

**(2) Computation.** The grammar classes are canonical modular-decomposition trees, counted 1, 1, 2, 4, 9, 24, 65,
182, 528, 1,558, 4,674 at orders 1..11. All 2^(n−1) switches of each were computed. The cores for 125, 215, 267, 305
were tested by the audit.

**(3) Omissions below f(12) = 375, at every order:**

    7, 21, 31, 35, 53, 113, 127, 149, 173, 181, 203, 215, 217, 251, 263, 267, 277, 287, 305, 341, 343

- primes (11): 7, 31, 53, 113, 127, 149, 173, 181, 251, 263, 277;
- 7p (5): 21, 35, 203, 217, 287;
- other (5): 215 = 5 · 43, 267 = 3 · 89, 305 = 5 · 61, 341 = 11 · 31, 343 = 7^3.

For 215, 267 and 305 every factor is a chart value. They are omitted because the ordinal sums S4 ⇄ T43, C3 ⇄ T89 and
S4 ⇄ T61 (and their padded versions) leave C. Every other odd value below 375 is attained, 125 only at order 12.

Every value here except 7 and 21 is an ordinary Hamiltonian-path count; for example the order-6 tournament with rows
(36, 17, 2, 7, 13, 30) has H = 31. So the address chart is a strictly smaller target language than the full
spectrum.
