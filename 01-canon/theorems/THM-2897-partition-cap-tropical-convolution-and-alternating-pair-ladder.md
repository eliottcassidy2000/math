# THM-2897 -- partition-cap tropical convolution and alternating pair ladder

## 1. The cap sequence

Let `(Omega,mu)` be a finite measure space, let `C` be measurable with

```text
h=mu(C)>0,
```

and let `(D_v)_(v in V)` be measurable danger sets.  For a finite set
`S subset V`, put

```text
U_C(S)=mu(C intersect union_(v in S) D_v).                    (1)
```

Fix a set `P` of forbidden labels and assume that `V minus P` contains at
least `p` labels.  For `0<=j<=p`, define

```text
beta_0(P)=0,
beta_j(P)=sup {
  U_C(S) : S subset V minus P, |S|=j
}.                                                           (2)
```

More generally, suppose a primitive cap bank `B_j(P)` is available for
`j` in a set `J subset {1,...,p}`:

```text
beta_j(P)<=B_j(P).                                           (3)
```

No attainment is required.  The labels in different blocks below must be
distinct in the putative cover, but the cap maximizers need not be.  This
loss can weaken the estimate and cannot invalidate it.

## 2. Partition-cap theorem

If

```text
p=lambda_1+...+lambda_r,       lambda_i in J,                (4)
```

then every `p`-set `Q subset V minus P` satisfies

```text
U_C(Q)<=B_(lambda_1)(P)+...+B_(lambda_r)(P).                 (5)
```

Consequently, if the right side of `(5)` is strictly below `h`, no such
`Q` covers `C`.

### Proof

Partition `Q` into disjoint blocks `Q_1,...,Q_r` with
`|Q_i|=lambda_i`.  Subadditivity and `(3)` give

```text
U_C(Q)
 <=sum_i U_C(Q_i)
 <=sum_i B_(lambda_i)(P).                                   (6)
```

If the last quantity is below `h`, then `U_C(Q)<mu(C)`, so `Q` does not
cover `C`.  QED.

The best bound generated by a primitive bank is its tropical, or min-plus,
convolution closure.  Put

```text
F_0(P)=0,
F_k(P)=min_(j in J, j<=k) [F_(k-j)(P)+B_j(P)]                (7)
```

whenever `k` is representable by parts in `J`.  Repeated application of
`(5)` gives

```text
beta_k(P)<=F_k(P).                                          (8)
```

Thus `F_p(P)<h` is a sufficient no-cover certificate.  Equivalently, the
vertices are slot counts and an addition gate `(r,s)->r+s` sends two cap
values to their sum; competing decompositions are joined by a minimum.
This is the exact summand graph underlying the self-similar cover ladder.

## 3. The alternating pair ladder

Take `J={1,2}`.  Write

```text
q=B_1(P),       B=B_2(P).                                   (9)
```

Replacing `B` by `min(B,2q)` preserves `(3)`, so assume `B<=2q`.  Formula
`(7)` then becomes

```text
F_(2m)(P)=mB,
F_(2m+1)(P)=q+mB.                                          (10)
```

This follows immediately by induction: an even slot count is tiled by
pairs, while an odd slot count has one singleton left over.  In particular,

```text
four remaining labels:       2B<h  implies no cover,
five remaining labels:     q+2B<h  implies no cover.        (11)
```

The first line is exactly the pair-partition terminal used in THM-2888.
The second is its correct one-step successor for the seven-body/six-slot
rung after a first apex.  The alternation is parity of the **number of
remaining proof obligations**, not parity of the speed labels; it supplies
no two-adic descent by itself.

One may also use several primitive sizes.  For example, at five slots,

```text
F_5(P)<=min(
  B_1+2B_2,
  B_2+B_3,
  B_1+B_4,
  B_5
).                                                          (12)
```

The last entry is the original five-cover problem and is useful only when
obtained independently; inserting it as an assumption would be circular.
The lower-order entries are the noncircular computational routes.

## 4. Monotone ordered-apex bootstrap

Now use the marked ordered-apex state of THM-2893.  For an apex `a`, let

```text
C_a=C minus D_a,       h_a=mu(C_a),                          (13)
```

and let `P` record the already forbidden gate labels.  Compute cap banks on
the literal carrier `C_a` using only labels outside `P union {a}`.  Exact
caps `(2)` satisfy

```text
P subset P'  implies  beta_j(P')<=beta_j(P).                 (14)
```

The same conclusion holds for any chosen upper-cap bank that is explicitly
monotone under deletion.  Its tropical closure is then monotone:

```text
F_k(P')<=F_k(P).                                            (15)
```

Therefore

```text
Gamma_a(P) : F_(p-1)(P)<h_a                                (16)
```

is an inflationary activation predicate of exactly the kind used in
THM-2893's scalar bootstrap.  Starting from any ordered seed whose own
branches are certified on their actual suffixes, repeatedly activate every
remaining apex satisfying `(16)`.  If all gate apices activate, the root is
closed.

This permits scalar, pair, and triple caps to coexist in one target-set
selection problem.  At the present `j=6` frontier, the cheapest new
predicate is

```text
largest allowed singleton coverage
  + 2*(allowed global pair-union cap) < h_a.                (17)
```

Both the literal residual and the excluded-prefix sidecar are essential.
Dropping the sidecar replaces suffix caps by larger global caps; trying to
recover it from the unmarked residual conflicts with THM-2894.

## 5. Boundary, lost information, and scope

The strict inequality in `(5)`, `(11)`, or `(16)` is load-bearing.  Equality
does not exclude a cover.  Partition caps also forget cross-block overlap
and compatibility of separate maximizers.  Hence they are sufficient
certificates, not equivalences; a failed cap inequality is not evidence for
a cover.

The connection data are:

```text
source:       lower-order exact union caps on a literal carrier;
target:       a no-cover certificate for a larger slot count;
map:          integer-partition / min-plus convolution;
preserved:    subadditive upper control and forbidden-label monotonicity;
destroyed:    cross-block overlap and common-maximizer compatibility;
sidecar:      literal carrier, excluded labels, and ordered apex state;
cheapest test at five slots: q+2B_2<h.
```

No finite LRC atlas is asserted here.  In particular, the theorem does not
prove `(17)` on the THM-2896 branches, close the seven-body rung, or prove
LRC(14).  Its consequence is architectural: the next exact census should
test the alternating pair certificate before paying for triple caps or
heavy-flag residual enumeration. ∎
