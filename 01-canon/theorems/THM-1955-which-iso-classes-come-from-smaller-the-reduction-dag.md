# THM-1955 — which iso classes come from smaller subtournaments

## 1. The owner's three "recursion modes" are circulant character sums

A circulant tournament on ℤ/n has connection set `C` (one of each pair `{k, n−k}`) and eigenvalues
`λ_j = Σ_{k∈C} ω^{jk}`, `ω = e^{2πi/n}`. Writing `ε_k = +1` if `k∈C` else `−1`,
```
        Σ_{k=1}^{n−1} ε_k ω^{jk} = 2λ_j + 1     (j ≠ 0)   ≡   "A+B+C−D−E−F = G".
```
The three sign-strings are the canonical connection-set characters:

| mode | signs (k=1..6) | connection set | tournament | eigenvalue |
|---|---|---|---|---|
| `A+B+C−D−E−F` | `+ + + − − −` | `{1,2,3}` = sign(sin 2πk/7) | **interval / rotational** | Dirichlet/Chebyshev |
| `A+B−C+D−E−F` | `+ + − + − −` | `{1,2,4}` = Legendre (k/7) | **Paley-7 (QR)** | Gauss sum |
| `A+B−C` | `+ + −` | `{1}` on ℤ/3 | **3-cycle** | ±i√3 |

**Refinement of THM-1925(c).** `Re(λ_j) = −1/2` for **every** ℤ/p circulant tournament (j≠0): the
two members of a pair `{k, n−k}` share `cos(2πjk/n)`, so the real part is `½·Σ_{k=1}^{n−1}cos = −½`
independent of `C`. Hence `2λ_j+1` is **pure imaginary** for all modes. The modes differ only in the
**imaginary (sine) part** `Im λ_j = Σ_{k∈C} sin(2πjk/n)`:
- **Paley/Legendre** — `|2λ_j+1| = √7` for all `j` (**flat**, the Gauss sum `|g(χ)|=√p`; kps's zero-
  spread pole, THM-1880).
- **Interval** — spread values (**Dirichlet** `D_m`, which *vanishes* at the roots of unity, so its
  real part is `−1/2` too — this is why THM-1925(c)'s `(D_m−1)/2` equals `−1/2` there).

So the mode is exactly the choice of **additive (interval) vs multiplicative (Legendre) character**
on the ±k pairs; "flat vs spread" is Paley vs interval.

## 2. The reduction DAG: which classes come from smaller ones

An iso class "comes from smaller subtournament classes" in exactly two ways:

**(i) REDUCIBLE** — an order-join composite `T = T₁ ▷ T₂` (equivalently: has a dominant/dominated
vertex, i.e. is not strongly connected). Then `char_A`, `H` (THM-1862), the signed-Rédei `R`
(mac-mini THM-1936), and the zeta `ζ` (THM-1926) **all factor over the strong components** — the
class's invariants are *products* of strictly-smaller strong-class invariants.

**(ii) CIRCULANT** — a strong tournament that is `ℤ/n`-character-generated by a mode.

The strong non-circulant tournaments are the **prime atoms** (genuinely new at their `n`). Census:

```
  n : total  reducible   strong-prime   circulant(⊂strong)
  3 :   2       1             1              1
  4 :   4       3             1              0
  5 :  12       6             6              1
  6 :  56      21            35              0
  7 : 456     103           353              2
```

Circulant (mode-generated) classes are **rare** (`1,0,1,0,2`): the character recursion builds only a
thin thread. The order-join recursion builds the reducible bulk (`1,3,6,21,103`). Everything else is
prime. So "which iso classes come from smaller through these recursions" = the reducible ones (via
order-join, the *literal-subtournament* recursion) plus the circulant ones (via the ℤ/n character
modes); the rest are irreducible.

## 3. The deck recursion (the literal-subtournament recursion)

For the `n` vertex-deleted subtournaments `T−v₁,…,T−vₙ` (the "deck" — `A,B,…,G` for n=7):
```
        char_A'(x) = Σ_i char_{T−v_i}(x),        Σ_i c₃(T−v_i) = (n−3)·c₃(T)     (verified n≤6).
```
The **unsigned** deck sum is the derivative of the characteristic polynomial. A **signed** deck sum
`Σ_i ε_i char_{T−v_i}` is a twisted functional; on a vertex-transitive (circulant) tournament all
decks coincide, so it collapses to `(Σε_i)·char_D` and vanishes iff the mode is sign-balanced. The
character modes of §1 live on the group ℤ/n (building the circulant *atoms*), while the deck
recursion lives on the vertices (relating a class to its subtournament classes) — the two "recursions"
are the two faces of the reduction DAG.
