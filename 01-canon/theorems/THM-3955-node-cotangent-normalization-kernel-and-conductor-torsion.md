# THM-3955 -- node cotangent normalization kernel and conductor torsion

**PROVED.**  Let `k` be any field, put

```text
A = k[x,y],                 B = A/(xy),
Btilde = k[x] direct_sum k[y],
```

where `B -> Btilde` is the normalization map obtained by restricting to the
two branches.  Write

```text
E = Omega_(A/k) tensor_A B = B dx direct_sum B dy,
T = torsion_B Omega_(B/k),
K = ker(E -> Omega_(B/k)/T).
```

Here torsion means the elements annihilated by a nonzerodivisor of `B`,
equivalently the differentials vanishing at every generic point.  (Using
"annihilated by a nonzero element" would be wrong for this non-domain.)

Then the conormal sequence and normalization map have the exact local form

```text
0 -> B*d(xy) -> K -> T -> 0,
T = k*tau,                  tau = x dy = -y dx,
Omega_(B/k)/T  ~=  Omega_(Btilde/k),
K = (y) dx direct_sum (x) dy
  = B*d(xy) + B*(x dy),
K/(B*d(xy)) ~= k.[x dy].                                  (1)
```

In particular `x dy` is a nonzero ambient differential, is not conormal, and
maps to a torsion differential which normalization erases.  Therefore the
two vanishings

```text
H^0(conormal tensor L)=0,
H^0(torsion-free cotangent tensor L)=0
```

do **not**, as a sheaf-theoretic implication, force vanishing of the ambient
cotangent restriction: the missing term is the preimage of conductor torsion.
This last sentence is a local failure mechanism, not an assertion that a
particular local class globalizes for a given line bundle.

## Proof

The conormal presentation is

```text
B --d(xy)--> B dx direct_sum B dy -> Omega_(B/k) -> 0,
1 |-> y dx + x dy.                                      (2)
```

The first arrow is injective.  Indeed, if `c x=c y=0` in `B`, then
`c` lies in `ann(x) intersect ann(y)=(y) intersect (x)=0`.

The normalization identifies

```text
B = {(p(x),q(y)) in k[x] direct_sum k[y] : p(0)=q(0)}.  (3)
```

The induced map on differentials sends

```text
a dx+b dy |-> (a(x,0) dx, b(0,y) dy).                  (4)
```

Its kernel consists of representatives with `a in (y)` and `b in (x)`.
Write `a=y alpha(y)` and `b=x beta(x)`.  Relation (2), together with
`x^2 dy=y^2 dx=0`, gives

```text
a dx+b dy = (beta(0)-alpha(0))*tau.                    (5)
```

Conversely every scalar multiple of `tau=x dy` occurs.  The element `tau`
is killed by both `x` and `y`, hence by the nonzerodivisor `x+y`, so it is
torsion.  It is nonzero: if `(0,x)=c(y,x)` in `B^2`, then `cy=0` forces
`c=xd`; the other coordinate would give `x(xd-1)=0`, hence
`xd-1 in (y)`, impossible after evaluation at the origin.  Thus the kernel
of `Omega_B -> Omega_Btilde` is exactly `k tau`.

The target of (4) is torsion-free as a `B`-module, and (4) is surjective:
an arbitrary `p(x)dx` on the first branch is lifted by a coefficient whose
branch pair is `(p(x),p(0))`, and similarly on the second branch.  Hence
`Omega_B/T ~= Omega_Btilde`, proving the middle assertion of (1).

Finally `K` is the inverse image of `T` under the quotient in (2).  Therefore
the kernel of `K -> T` is exactly `B*d(xy)`, while `x dy` maps to the
generator `tau`.  Equivalently, direct use of (4) gives

```text
K=(y) dx direct_sum (x) dy
 =B*d(xy)+B*(x dy),
K/B*d(xy) ~= B/(x,y) ~= k.
```

This proves (1).  No characteristic restriction was used.  In characteristic
two the displayed sign disappears, so `tau=x dy=y dx`; all conclusions,
including injectivity of the conormal map, remain unchanged.

## Typed transfer and boundary

This theorem gives an unconditional local model for two otherwise distinct
normalization losses:

1. corrected THM-3944/MISTAKE-466 has a Kummer boundary class on the original
   nonnormal regular locus which does not extend over the normalization;
2. Lemma 10.3 of Alpoge's August 2026 S6 manuscript claims to globalize the
   cotangent class in (1) on its nonnormal cusp fibre.

The shared operation is precise: replace an object by its normalization and
then discard conductor-supported data.  The mathematical payloads are not
the same (`mu_3` torsors versus Kähler differentials), so no theorem transfers
between them without the conductor sidecar.

Notice the type boundary: `Omega_(B/k)/T -> Omega_(Btilde/k)` itself is an
isomorphism.  The extra conductor kernel occurs one stage earlier in
`E -> Omega_(B/k)/T`; it is not a kernel between torsion-free and normalized
differentials.

This isomorphism is special to the two-branch curve node.  THM-3957 proves
that for the triple surface crossing `xyz=0`, torsion-free differentials inject
but do not surject onto normalized differentials; the cokernel is supported on
the three double axes.  Thus (1) must not be extrapolated across a
positive-dimensional conductor without a branch-mismatch sidecar.

Nothing here proves that the manuscript's local models glue, that its global
section is nonzero, that its topology is `S6`, or that the Hopf problem is
solved.  It only proves that a reduction from ambient differentials to
conormal plus torsion-free differentials can lose a genuine node-supported
class.
