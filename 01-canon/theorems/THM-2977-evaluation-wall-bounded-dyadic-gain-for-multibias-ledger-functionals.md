# THM-2977 -- the evaluation wall

Frame: THM-2966 spine normal form; doubled deficits `delta` at cells
`(z, o)`; the choice lattice is generated by `delta -> delta + 2` inside
each budget box. Fix a rational depth law `d_m = floor(g1 m / g2) + D0`
(`gcd(g1, g2) = 1`), level `M`, `A = A_M = M + d_M + 1`. Fix biases
`p_j = a_j / b_j`, `j = 1..J`, in lowest terms with `a_j, b_j` odd and
`b_j - a_j = 2^{s_j} u_j`, `u_j` odd, `s_j >= 2` (the certificate
engineering; both (27) biases qualify with `s_A = 7, s_B = 6`). For
integer weights `x_j`, WLOG `min_j v_2(x_j) = 0`, set

```text
Psi = sum_j x_j N_j,    N_j = 2 D_M(p_j) b_j^A  in  Z.
```

## W1 (exact AP of evaluation cells)

For every `m`, `d_{m + g2} = d_m + g1` exactly, so the `o = 1` cell
positions `z_m = m + d_m` satisfy `z_{m + g2} = z_m + (g1 + g2)`: within
each residue class of `m mod g2` the `z`-positions form an arithmetic
progression of exact stride `h = g1 + g2`, of length `>= J` once
`M >= g2 (J - 1) + 1`. *Proof:* `floor(g1(m + g2)/g2) = g1 + floor(g1
m / g2)`. QED.

## W2 (finite-difference kill with LTE cost: K is bounded)

A shift at cell `(z, 1)` changes `Psi` by `2 g(z)`,
`g(z) = sum_j y_j r_j^z` with `y_j = x_j u_j 2^{s_j} b_j^{A-1}` and
`r_j = a_j / b_j`, a 2-adic unit `== 1 (mod 2^{s_j})` (because
`a_j == b_j mod 2^{s_j}`). Suppose `v_2(g(z)) >= kappa` on the length-`J`
stride-`h` AP of W1. For fixed `j`, apply the `J - 1` operators
`T_{j'} : g(z) -> g(z + h) - r_{j'}^h g(z)` (coefficients are 2-adic
integers, so `v_2 >= kappa` is preserved); each `T_{j'}` annihilates the
`j'` term, leaving

```text
y_j r_j^{z_0} prod_{j' != j} (r_j^h - r_{j'}^h),
```

whence, by the lifting-the-exponent identity
`v_2(rho^h - 1) = v_2(rho - 1) + v_2(h)` for `rho = r_{j'} / r_j == 1
(mod 4)`:

```text
kappa <= v_2(x_j) + s_j
         + sum_{j' != j} [ v_2(a_j b_{j'} - a_{j'} b_j) + v_2(h) ].
```

Taking the best `j` and adding the shift factor 2:

```text
K <= 1 + min_j [ v_2(x_j) + s_j + sum_{j' != j}
     ( v_2(a_j b_{j'} - a_{j'} b_j) + v_2(g1 + g2) ) ]  =:  1 + C,
```

with `C` independent of `M` (and of the weights, once
`min v_2(x_j) = 0`). *Referee R3:* the bound holds for the certificate
pair and a hostile pair across four depth laws and 12 random weight
vectors each; at the certificate pair the true `K` (in `Psi` units) is
`7`, the bound `13`. QED.

## W3 (the wall)

The proved necessary envelope `|D_M(p)| <= (p^{M+1} + q^{M+1})/2` gives

```text
|Psi| <= B = sum_j |x_j| (a_j^{M+1} + (b_j - a_j)^{M+1}) b_j^{d_M},
B >= (b_{j*} - a_{j*})^{M+1} >= 2^{s_min (M+1)}.
```

`[-B, B]` contains `2B + 1 > 2^{K}` consecutive integers — hence every
residue class mod `2^K` — as soon as `s_min (M+1) >= K`, i.e. for every
`M >= M_0 := K / s_min` (at the certificate pair `K <= 13`, `s_min = 6`:
`M_0 = 1`, margin then growing `~ 35` bits per level, referee R4).
Therefore **no argument of the form "the forced residue of `Psi` mod
`2^K` is incompatible with `|Psi| <= B`" can exist at any level**: the
forced-residue class always meets the envelope interval. QED.

## Scope and consequences

1. **Class closed, not search closed.** Combined with lane G2
   (`laneG2-padic-phi-findings.md`): the invariant content of the whole
   evaluation class is a bounded number of bits, that content is pure
   boundary bookkeeping (`Psi_forced = 64 [ (M+1) d_M + floor((M+1)/2) ]
   mod 128` at the certificate coupling), and by W2/W3 no residue-vs-size
   contradiction is available. So **certificate (27) is not an
   evaluation bound** in this class; per lane G2 sec. 5 it must gate a
   rate/entropy (tropical) dual. The odd engineering of the biases
   survives as a checksum-alignment device, not a smallness mechanism.
2. **Mixed multi-level functionals** (weights across several `M`):
   the single-bias telescoping case is closed exactly by lane G2 T6
   ("dollar-for-dollar": any modulus gained by weight divisibility is
   paid back in the envelope); the fully general mixed multi-bias case
   reduces to the same deepest-row `o = 1` pinning and is left
   CITED-SKETCH here — it affects no live reading of (27).
3. **Limits of the wall.** The wall assumes the size side comes from the
   proved archimedean envelope at rational biases. A genuinely 2-adic
   envelope (forced `v_2(N_M) -> infinity`) would evade it; nothing in
   current canon supplies one.
