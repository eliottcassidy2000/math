# THM-4881 - the reachable set of the span-2 ribbon transfer

Setting (THM-4880): `y(u) in Z^14` is the reduced state of a span-2 ribbon word, `y(empty) = e_1`, `H(u) = y_2(u)`,
`y_1 = y_2` on nonempty words, and the letters act by the integer matrices `A_{--}, A_{1-}, A_{-2}, A_{12}` of
`span2_intrep.txt`. `Y_n` is the set of states of words of length `n`.

**(A) Congruence coset.** Let `y_ref = y(--.--) = (1, 1, 0, 2, 0, ..., 0)` and let `L` have the echelon basis
`2e_1 + 2e_2, 2e_3, ..., 2e_12, 4e_13 + 4e_14, 8e_14`. Then `Y_n subset y_ref + L` for every `n >= 1`. Equivalently:
`H` odd; `y_3, ..., y_12` even; `y_13 = 0 (mod 4)`; `y_14 = y_13 (mod 8)`. `L` is exactly the lattice generated by
the differences of `Y_n` for every `n >= 5` (index `2^16` in `{d : d_1 = d_2}`); levels 3 and 4 generate proper
sublattices (indices 128 and 16384). *Proof.* Containment: `L` is the Z-span of the differences of `Y_7`; `A_m L
subset L` and `A_m y_ref - y_ref in L` for all four letters (finite exact check), so the coset is invariant, and
levels 1-7 lie in it. Exactness (audit): the difference lattice `L_n` of `Y_n` obeys `L_(n+1) = sum_m A_m L_n +
Z{(A_m - A_m') y_ref : m, m'}`, because the differences of level `n + 1` are the `A_m (y - y') + (A_m - A_m') y'`;
the Hermite form of the right-hand side with `L_n = L` is `L`, so `L_n = L` for all `n >= 5`.

**(B) Exact tripling.** `A_B = A_{-2} A_{1-}` (the block `1-.-2`) has characteristic polynomial `x^13 (x - 3)` and
rank 4 (`A_{1-} A_{-2}`: the same polynomial, rank 3; the six ordered two-letter blocks `--.-2`, `--.12`, `1-.-2`,
`-2.--`, `-2.1-`, `12.--` all have this polynomial); hence `A_B = 3P + N` with `P` idempotent of rank one,
`PN = NP = 0`, `N^4 = 0`, and the row identity `e_H A_B^4 = 3 e_H A_B^3` holds exactly while `e_H A_B^3 != 3 e_H A_B^2`,
so `H(u B^k) = 3^{k-3} H(u B^3)` for every word `u` and `k >= 3`, and `k = 3` is sharp: `H(B^k) = 1, 1, 5, 15, 45, 135,
...`; `H(1-.-2.12.B^k) = 1, 11, 33, 95, 285, 855, ...` (the near-join block `--.-2` triples from `k = 1`). Reading:
when `u` ends with a sink, the block's first vertex (`q + 1 -> q`) is a singleton strong component and the rest is
Moon's chain `IC(3, 2, ..., 2)` with `H = 5 * 3^(k-2)` (THM-4744, factor `2^(2-1) + 1 = 3` per 2-block); when `u`
ends with a nonempty letter the first vertex joins the chain component (both displayed examples are strong for small
`k`) and only the eventual factor 3 survives. The residual `H(uB) - 3H(u)` is unbounded (witness `u = (12)^n`,
THM-4880 (H1)), so this is multiplicative structure only.

**(C) Sparse response sets, known exactly.** For the last vertex `t` of `u`, `(h, e, R) = (H(u), e_t(u), R_t(u))` is
read off `A_{--} y(u)`. The pruned state sets `S_n = {y(u) : |u| = n, H(u) <= 99}` are a fixed point from length 12
(`S_12 = S_13 = S_14`, 2,865 states), so every reduced state with `H <= 99` of any word is a state of a word of
length `<= 12`, and the sets `B(h) = {R : (h, e, R) occurs}` are known exactly for every odd `h <= 99` (bsets.py
lists them for `R <= 4h`). They are sparse: the density among the parity-admissible integers of `[h, 4h]` is
0.03-0.17 for `17 <= h <= 99` (e.g. `h = 63`: 6 of 190; `h = 99`: 34 of 298) and 0.21-0.75 for `h <= 15` (`h = 9`:
8 of 28). Every root of every tournament of orders `<= 8` gives denser but still sparse sets (17-56 % for `h <= 45`;
for `h <= 27` these contain the ribbon sets strictly; for larger `h` orders above 8 contribute and the comparison is
incomplete). Hence the near-join induction (`N = h + 2R` with dense `R`-sets, HYP-9453 (2)) is not the mechanism of
the ribbon tiling law; the covering of every odd number `<= 100,000` except 7, 21, 47 (THM-4880) is collective
across `h`.

**(D) Residues and exponential sums (FINITE-EXACT data; the trends NUMERICAL).** Words of length `n` number
`2 * 4^(n-2)` (the first letter is empty, the second has one bit). On the solid window `[49, d_n]` of level `n <= 13`
the counts `H(u)` are equidistributed modulo 7, 8, 16 (deviation `<= 0.03` at `n = 13`) and biased modulo 3, 5, 9
(deviation 0.21, 0.16, 0.13 at `n = 13`, growing with `n`). The normalised exponential sums `|sum_{|u| = n} e(theta
H(u))| / #words` are exactly 1 at `theta = 1/2` (`H` is odd), decrease at `1/7, 1/8, 1/16, 3/11, 5/13` and at
irrational `theta` (e.g. `theta = 0.1234...`: 0.062, 0.031, 0.003 at `n = 9, 11, 13`), and grow at `1/3` (0.190,
0.265, 0.324), `1/5` (0.165, 0.186, 0.227) and `1/10` (0.214 at `n = 13`). Multiplicities `r_n(N)` on the window:
medians 79, 108, 100, 304, 232 for `n = 9..13` (the script normalises by `4^(n-1)`, twice the word count, which
halves these medians relative to the true counts per word; the ratios are unaffected). `E log H` grows by 0.534 per
letter from `n = 9` on (`(1/n) E log H = 0.386 ... 0.443` for `n = 8..13` is the poorer estimator).

**(E) Proximality.** The two largest eigenvalue moduli are 1.839 / 0.737 (`1-`), 2.288 / 1.255 (`-2`), 2.563 / 1.346
(`12`), 3.000 / 0.000 (`1-.-2`), 4.745 / 0.604 (`1-.12`), 5.236 / 1.576 (`-2.12`).

Consequence for the search for a collective invariant (HYP-9474): no local invariant survives - quotient and digit
systems (THM-4880 (G), (H)), arithmetic progressions ((H2)), dense response sets ((C)), dense extension sets (THM-4880
note, section 9) - and the surviving formulation is distributional: an integer-scale local limit law for the linear
random walk `y -> A_a y`, whose major arcs are the rationals with denominators `2 * 3^i * 5^j` (the factor 2 because
`H` is odd). The random-matrix frame (Guivarc'h-Le Page, Benoist-Quint) is cited as context only: it assumes
invertible matrices, while the letters have ranks 3, 4, 10, 12.
