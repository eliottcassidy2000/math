# THM-2845 -- local residue versus split trace observability

**RESERVED / UNPROVED EMPTY STUB.**

Reserved for the proposed classification of linear scalar unit detectors
on finite-dimensional associative algebras: exact detection is possible
precisely for a local algebra whose residue division algebra is the base
field, while split products admit trace-zero units with a sharp
`F_2` parity exception.  The intended theorem synthesizes THM-2839's
modular group-algebra augmentation and THM-2815/2842's split Laguerre
trace boundary.  No mathematical claim is made by this reservation.
