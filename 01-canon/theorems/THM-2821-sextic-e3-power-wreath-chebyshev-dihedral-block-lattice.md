# THM-2821 -- the two sextic carriers have different 2/3 block lattices

**RESERVED / UNPROVED EMPTY STUB.**

No mathematical claim is established by this reservation.  The intended
target is an exact monodromy and functional-decomposition classification
for THM-2817's two unmarked sextic response carriers:

```text
power inner cubic:       monodromy (C3 x C3) semidirect C2, order 18;
Chebyshev inner cubic:   dihedral monodromy, order 12.
```

The proposed sharp distinction is that the power carrier has only the
three-sheet-then-two-sheet block system, whereas the Chebyshev carrier has
both the `3 then 2` and `2 then 3` systems because its response is even in
the centered source coordinate.  Promotion requires an exact permutation
group computation, a proof of the complete block lattice and functional
factorizations, an independent affine/accessory cross-check, and a precise
scope boundary: a block system of one rational response does not lift
without a sidecar to a polynomial Keller-map decomposition, `JC(2)`, or
`DC(2)`.
