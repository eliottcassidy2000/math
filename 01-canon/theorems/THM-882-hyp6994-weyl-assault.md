# THM-882 — the HYP-6994 assault: what fell, what resisted

## 1. The w-freeness lemma (proved, one line)

S_w(n) = Σ_k ε_k e(nw·p_k) depends on nw mod P (positions have denominator | P). For
gcd(w, P) = 1 the map n ↦ nw permutes Z_P∖{0}, so max_{n≠0}|S_w(n)| is the SAME for every
coprime w and dominates every non-coprime w (whose frequency set is a subgroup subset). ∎
> **HYP-6994 for a cluster is ONE finite scan — for all w and all sections simultaneously.**

## 2. Per-instance proofs (executed)

Exhaustive scans over the full Z_P (P = 420, 420, 2100, 2100, 15540):
max_{n≠0}|S(n)|²/M = 14.00 (t=6), 7.60 (t=12), 8.28 (t=25), 11.67 (t=50), 12.86 (t=37),
worst over all seven sections each. **HYP-6994 holds with C = 14 on the scanned family**,
so Q_s ≤ 2π²·C_P·14·M ≤ (14π²/3)·M there (THM-881 P3) — sharp O(diam) with explicit
constant, for all w, per instance. The constant shows no drift in t (14.0 at t=6 down to
11.7–12.9 at t=37..50).
