## Setting

Fix h ∈ (0, 1/2), w = 2h (LRC(14): h = 1/14, w = 1/7). For distinct nonzero integers
U = {u_1, …, u_k} define on the torus T² = (ℝ/ℤ)² (Haar probability measure vol) the **bands**

    B_i = {(x, c) ∈ T² : ‖c − u_i x‖ < h},

and A(U) := 1 − vol(∪_i B_i). By Fubini, A(U) = ∫₀¹ meas{x : ‖u_i x − c‖ ≥ h ∀i} dc = E_c[L^c(U)]
— the c-averaged (shifted-target-averaged) lonely measure, the floor object of the c-ruler
architecture (HYP-3953: witnessG2 = ∫_{G_P}(gap surplus) and the (⋆)-census run over A-type
joints).

## Statement

**(i) Singles.** vol(B_i) = w.

**(ii) Pair independence, exact.** For i ≠ j: vol(B_i ∩ B_j) = w². (No arithmetic correction of
any kind; contrast THM-594(B)'s two-branch law for the fixed-target pair overlap on the x-circle.)

**(iii) d-fold overlaps are subtorus box volumes.** For S ⊆ U with |S| = d ≥ 2, let
Λ_S := {m ∈ ℤ^S : Σ_i m_i = 0 and Σ_i m_i u_i = 0} (the sum-zero relation lattice, rank d − 2).
Then

    vol(∩_{i∈S} B_i) = γ_S((−h, h)^S),

where γ_S is the Haar probability measure of the 2-dimensional subtorus
H_S = {y ∈ T^S : Σ m_i y_i = 0 for all m ∈ Λ_S}. Two computable forms:
- **(chart form — the exact algorithm)** Order S so that u_1 < u_2, D := u_2 − u_1. Then
      vol(∩_S B_i) = (1/D) Σ_{r=0}^{D−1} Area{(a,b) ∈ (−h,h)² : ‖α_i a + β_i b + δ_i(r)‖ < h, i ≥ 3},
  with α_i = (u_2 − u_i)/D, β_i = (u_i − u_1)/D, δ_i(r) = r(u_2 − u_i)(u_i − u_1)/D · (1/D)-type
  rational shifts obtained from x = (a − b + r)/D, c = a + u_1 x; each condition is affine with
  rational coefficients, so each sheet's region is a finite union of rational polygons and the
  volume is an EXACT RATIONAL, computable by polygon clipping.
- **(Fourier form — the structure)** vol(∩_S B_i) = Σ_{m∈Λ_S} Π_i ŵ_h(m_i), with ŵ_h(0) = w and
  ŵ_h(s) = sin(2πsh)/(πs); for d = 3 the lattice is rank 1, generated by the primitive
  (u_3−u_2, u_1−u_3, u_2−u_1)/g, and the series converges absolutely (∝ Σ 1/t³).
  Special value: for an arithmetic-progression triple (relation (1, −2, 1)) the volume is 2h².

**(iv) Invariances.** A(U + s) = A(U) for s ∈ ℤ (shear (x,c) ↦ (x, c + sx) ∈ SL₂(ℤ)-action) and
A(dU) = A(U) for d ≥ 1 ((x,c) ↦ (dx, c) pushes Haar to Haar). Hence A is a functional of the
difference pattern of U up to dilation.

**(v) Inclusion–exclusion.** A(U) = 1 − kw + C(k,2)w² − Σ_{|S|=3} vol(∩_S B) + … is a finite sum of
exact rationals: the c-averaged ledger is symbolic. The only arithmetic input enters at d ≥ 3
through the relation lattices Λ_S; small-coefficient relations carry the largest volumes (AP
maximal at d = 3), which is why AP-structured patterns minimize A.

## Proof

**Lemma (push).** Any continuous surjective homomorphism φ of compact abelian groups pushes Haar
to Haar (the pushforward is translation-invariant and a probability measure). ∎

(i) φ_i(x,c) = c − u_i x is a continuous homomorphism T² → T, surjective (already surjective in
c for fixed x). B_i = φ_i⁻¹(−h, h), so vol(B_i) = w by the Lemma.

(ii) Φ_{ij}(x,c) = (c − u_i x, c − u_j x) is the homomorphism T² → T² with integer matrix
M = [[−u_i, 1], [−u_j, 1]], det M = u_i − u_j ≠ 0. An integer matrix with nonzero determinant
defines a surjective endomorphism of T² (its image is a closed subgroup of full dimension, hence
all of T², T² being connected; concretely M·T² ⊇ M·(det M · T²) = … or: the image contains
(det M)·T² = T²). By the Lemma, vol(B_i ∩ B_j) = vol(Φ_{ij}⁻¹((−h,h)²)) = w².

(iii) Φ_S : T² → T^S, (x,c) ↦ (c − u_i x)_i is a homomorphism; its image is the closed connected
subgroup H = im Φ_S. By Pontryagin duality, H = {y : χ_m(y) = 1 whenever χ_m ∘ Φ_S ≡ 1}; and
χ_m(Φ_S(x,c)) = e((Σm_i)c − (Σm_i u_i)x) is trivial iff Σm_i = 0 and Σm_i u_i = 0, i.e. m ∈ Λ_S.
So H = H_S as claimed; Λ_S is the kernel of m ↦ (Σm_i, Σm_i u_i), a rank-2 map for distinct u_i
(two of the columns (1, u_i) are independent), so rank Λ_S = d − 2 and dim H_S = 2. The Lemma
gives (Φ_S)_* vol = γ_S, hence vol(∩B_i) = γ_S(box).
- Chart form: the fibers of Φ_S over its image have |ker Φ_S| = D points on each sheet class;
  parameterizing by (a, b) = (c − u_1 x, c − u_2 x) and solving x = (a − b + r)/D (r = 0..D−1),
  c = a + u_1 x enumerates the D sheets; each further coordinate c − u_i x is affine in (a, b, r)
  with rational coefficients, giving the stated polygon-area average. (This is the algorithm used
  by the verification script and the symbolic census engine.)
- Fourier form: γ_S has Fourier coefficients γ̂_S(m) = 1_{Λ_S}(m) (characters trivial on H_S are
  exactly Λ_S); the box indicator has coefficients Πŵ_h(m_i); Parseval gives the series. For
  d = 3, Λ_S = ℤ·m⁰ with m⁰ primitive as stated; |Πŵ_h(tm⁰_i)| ≤ C/t³ gives absolute convergence
  (the box boundary meets H_S in γ_S-measure zero since H_S is connected and not contained in any
  face). AP value: with relation (1,−2,1), on H_S the coordinates satisfy y_3 = 2y_2 − y_1 with
  (y_1, y_2) Haar on T² (the chart with D = 1); Area{|y_1|<h, |y_2|<h, ‖2y_2 − y_1‖<h}
  = ∫_{|y_2|<h}(2h − 2|y_2|)dy_2 = 2h². ∎

(iv) Shear: σ_s(x,c) = (x, c + sx) is the SL₂(ℤ) map [[1,0],[s,1]], a measure-preserving
automorphism of T²; ‖(c + sx) − (u_i + s)x‖ = ‖c − u_i x‖, so σ_s maps the band system of U to
that of U + s. Dilation: δ_d(x,c) = (dx, c) is a surjective endomorphism (Lemma applies);
‖c − (du_i)x‖ = ‖c − u_i(dx)‖, so the band system of dU pulls back to that of U. ∎

(v) Immediate from (i)–(iii) and finite inclusion–exclusion. ∎
