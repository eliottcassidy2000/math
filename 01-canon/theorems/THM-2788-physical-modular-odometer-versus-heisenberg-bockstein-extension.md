# THM-2788 -- physical modular odometer versus Heisenberg Bockstein extension

**RESERVED / UNPROVED EMPTY STUB.**

Proposed scope: distinguish the physical group generated on
`Z/p^2 Z` by dilation `n -> (1+p)n` and the actual odometer `n -> n+1`
from the carry-suppressed Heisenberg action.  The two extensions have the
same central commutator form but different `p`-power/Bockstein coordinates
for odd `p`; at `p=2` they coincide with `D_8`.  The intended theorem will
state the exact actions, cocycles, order spectra, minimal-carrier boundary,
and the typed consequence for THM-2779/2782.

Until a proof is written, exactly replayed, independently audited, and this
file is promoted, it is not a proved result or a proved dependency.
