# THM-3314 -- product-Gamma endpoint diagonal and centered-current counit obstruction

**PROVED algebraically + VERIFIED-EXACT on the declared three-face bank.**

The theorem answers two different “copy” questions.  A removed endpoint state
has a native group-like image and can be duplicated algebraically.  A centered
response obligation cannot be cloned in any counital linear coalgebra.  The
conditional controller copy requires still more: a shared ancestry object and
a typed face/origin assignment.

## 1. Native group-like endpoint

Let `Sym` carry its usual alphabet coproduct

```text
Delta p_k=p_k tensor 1+1 tensor p_k.                         (1)
```

For a removed pole multiset `sigma`, define the constant-term-one formal unit

```text
g_sigma(X)
 = product_(r in sigma,x in X)(1+rx)^(-1)
 = exp(sum_(k>=1)(-1)^k p_k(sigma)p_k(X)/k).                 (2)
```

Because every `p_k(X)` is primitive,

```text
Delta g_sigma=g_sigma tensor g_sigma,                        (3)
g_sigma(X+Y)=g_sigma(X)g_sigma(Y).                           (4)
```

Multiset union is multiplication:

```text
g_(sigma disjoint-union tau)=g_sigma g_tau.                  (5)
```

Thus `(3)` is multiplicative, cocommutative and coassociative.  It does not
double a homogeneous degree because `g_sigma` is a formal unit, not a
homogeneous state polynomial.

## 2. What a face-tag split adds

For the labelled face set use the unshuffle coalgebra

```text
Delta_F[A]=sum_(B disjoint-union C=A)[B] tensor [C].         (6)
```

For `A={F13,F23}`, both ordered terms

```text
[F13] tensor [F23],           [F23] tensor [F13]             (7)
```

have coefficient one.  Tensoring `(3)` with one chosen component of `(7)`
gives

```text
[F13,F23]g_b -> ([F13]g_b) tensor ([F23]g_b).                (8)
```

Equation `(8)` retains the exact removed endpoint in each factor, so each
face's response coordinates can be recomputed.  But selecting an ordered
component of the full unshuffle and assigning it to “released” versus “old”
origin is additional structure.  The full coproduct also contains the reverse
assignment and the unit/pair terms.  No inherited controller edge chooses
among them.

## 4. Counit obstruction for centered currents

Let `(C,Delta,epsilon)` be any counital linear coalgebra.  If an element `c`
were group-like in the copying sense

```text
Delta(c)=c tensor c,                                        (12)
```

then the left counit law would give

```text
c=(epsilon tensor id)Delta(c)=epsilon(c)c.                  (13)
```

Therefore

```text
epsilon(c)=0 and Delta(c)=c tensor c  imply  c=0.            (14)
```

For every one of the 35 states, both faces, and maintained degrees `5` through
`14`, the normalized partition response current is nonzero and has exact
augmentation zero.  The finite census is

```text
35 states x 2 faces x 10 degrees = 700,
700 nonzero, 700 augmentation-zero.                         (15)
```

Hence none of these response obligations can satisfy `(12)` in a counital
linear coalgebra.

The native coproduct shows the forced correction.  With `f_0=1` and
`U=f_a-f_0`, group-likeness of `f_a` gives

```text
Delta(U)=U tensor 1+1 tensor U+U tensor U,                  (16)
```

not only the last term.  The one-sided terms are required by the counit and
propagate through the polarized factorial invariants.  The endpoint can be
copied and two centered currents recomputed; one centered obligation cannot
be cloned into two.

Linearity also limits the classical diagonal.  For basis states `b,c`,

```text
Delta(e_b+e_c)=e_b tensor e_b+e_c tensor e_c,                (17)
```

whereas the nonlinear tensor square has two extra cross terms.  The endpoint
coalgebra copies known classical states, not arbitrary signed response
superpositions.

The product-Gamma unit and response vector depend on `(face,endpoint)`, not on
the start or actual chosen path.  Any map factoring through that endpoint is
constant on the displayed fibre and therefore cannot recover several distinct
histories simultaneously.  Equation `(3)` copies the endpoint state, not the
`COPY_FROM_SHARED_ANCESTRY` link required by the conditional controller.

## 6. Strongest survivor and boundary

The exact source-to-target contract is

```text
source:      removed-state formal unit plus pair face tag;
target:      two face-tagged response-algebra factors;
map:         group-like endpoint coproduct plus ordered unshuffle component;
preserved:   endpoint state and factorwise response recomputation;
```

The next lawful candidate is an ancestry-decorated comodule, span, or
pullback: copy a classical path identifier and the group-like endpoint, then
recompute each centered face obligation.  Such an extension would still have
to derive an `F12` activation gate and a typed origin assignment.  This
theorem does not derive that extension and proves no FC(3), SFC(3), GMC,
positivity, or chronology statement.
