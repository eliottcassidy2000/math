# THM-3914 -- the decic boundary class is a hidden hyperbolic plane

**RESERVED / PROVISIONAL PROOF CANDIDATE + VERIFIED-EXACT; awaiting
independent hostile audit.**

Work over an algebraically closed field `k` of characteristic zero.  Let `Q`
be a normal integral affine surface and let `Y` be a smooth projective
resolution/compactification for which

```text
Y minus D = Q_reg.                                          (1)
```

Include every irreducible component of `D`, and let `R` be the subgroup of
`Pic(Y)` generated by their classes.  Assume that the intersection matrix
of these classes is nondegenerate and has an integral orthogonal
decomposition

```text
R = K_10 orthogonal_sum R_0,

K_10 = Z B_+ + Z B_-,             Gram(K_10)=[-4  5],      (2)
                                                 [ 5 -4]

3 does not divide det(R_0).                                (3)
```

The block `R_0` may include affine exceptional curves and the unimodular
`[-1]` blocks introduced by boundary blowups.  Equation `(2)` is an
assumption about the **actual** removed-divisor lattice, not merely a
submatrix selected from it.  Finally assume

```text
Pic(Y)[3]=0.                                                (4)
```

Put

```text
T=B_++B_-,                         w=B_+-B_-.               (5)
```

Then the following are equivalent:

1. `Cl(Q)[3]` is nonzero;
2. the unique order-three boundary discriminant class globalizes to
   `Pic(Y)`;
3. there is a necessarily unique class `v in Pic(Y)` with

   ```text
   3v=w;                                                    (6)
   ```

4. there is a necessarily unique class `D_- in Pic(Y)` with

   ```text
   3D_-=T+B_-.                                              (7)
   ```

When these conditions hold, set `D_+=T-D_-`.  One has the exact identities

```text
D_-=B_-+v,                  D_+=B_+-v,
v=D_+-D_-,                  T=D_++D_-,                     (8)

B_+=2D_+-D_-,               B_-=2D_--D_+,
3D_+=T+B_+,                 3D_-=T+B_-.                    (9)
```

The intersection ledger is

```text
T^2=2,        w^2=-18,      T w=0,
v^2=-2,       T v=0,
D_+^2=D_-^2=0,              D_+ D_-=1.                    (10)
```

Thus adjoining the globalized class does not merely give an unspecified
overlattice.  It gives the unique index-three integral enlargement

```text
K_10  subset  U=Z D_+ + Z D_-,

Gram_U(D_+,D_-)=[0 1],             [U:K_10]=3.             (11)
                     [1 0]
```

In the torsion-free numerical lattice `Pic(Y)/Pic(Y)_tors`, this copy of
`U` is primitive and splits orthogonally.  Here `(4)` already forces
`Pic^0(Y)=0`: a positive-dimensional Picard variety over `k` would have
nonzero three-torsion.  No torsion-freeness or unimodularity of the whole
Picard lattice is being assumed.

## 1. The unique decic boundary residue

The elementary boundary arithmetic is

```text
det(K_10)=-9,                       Smith(K_10)=diag(1,9).
                                                                  (12)
```

The vector

```text
g=w/3=(B_+-B_-)/3                                      (13)
```

pairs with `(B_+,B_-)` as `(-3,3)` and has square `-2`.  Hence it
represents the unique order-three subgroup of

```text
A_K=K_10^*/K_10 = Z/9.                                    (14)
```

It is integrally isotropic.  This is the `d=10 mod 18` permission row of
THM-3912 in its simplest representative.  The point of the present theorem
is to identify the extra global structure required for that permitted
residue to occur inside `Pic(Y)`.

The direct residue enumeration is also useful.  If

```text
y=aB_+ + bB_-,                  a,b in Z/3,                (15)
```

then `y/3` pairs integrally with `K_10` exactly when `a+b=0 mod 3`.
The only nonzero solutions are `(1,-1)` and `(-1,1)`, and both have integral
self-pairing.  There is no second boundary direction hidden by the
determinant calculation.

## 2. The actual class-group quotient forces divisibility

The divisor sequence for `(1)` is

```text
Cl(Q)=Pic(Q_reg)=Pic(Y)/R.                                  (16)
```

Suppose that a nonzero class killed by three is represented by `x in
Pic(Y)`.  Write `3x=y in R`.  If `y` belonged to `3R`, then `(4)` would make
`x` differ from an element of `R` by zero, contrary to nontriviality.  Thus
`y/3` is a nonzero order-three class in `A_R`.

By `(2),(3)`, the `R_0` discriminant group has no three-primary part, while
`(14)` has exactly one order-three subgroup.  After replacing `x` by `-x`
if necessary, equality of the two discriminant classes says exactly that
there is an `r in R` with

```text
y-w=3r,                 and hence 3(x-r)=w.                 (17)
```

Therefore `v=x-r` is an honest Picard class satisfying `(6)`; no equality
only in `Pic(Y) tensor Q` is being promoted to an integral one.  This step
uses the actual direct decomposition of `R`; a visible boundary submatrix
inside a larger, nonorthogonal three-primary lattice would not suffice.

Conversely, if `3v=w`, then the image of `v` in `Pic(Y)/R` is killed by
three.  It is nonzero because `w` is not divisible by three in the direct
summand `K_10`.  This proves the equivalence of clauses 1--3.  Assumption
`(4)` also makes the cubic root `v` unique.

## 3. No hidden parity hypothesis

Starting from `(6)`, define directly

```text
D_-=B_-+v.                                                  (18)
```

Then

```text
3D_-=3B_-+w=B_++2B_-=T+B_-,                               (19)
```

so `(7)` follows without dividing an arbitrary Picard class by two.  In
fact, `(6)` gives

```text
T-v=2(B_-+v),                    D_-=(T-v)/2.              (20)
```

Thus the often tempting parity step is a consequence, not an assumption.
Conversely, if `(7)` holds, then

```text
v=D_--B_- = T-2D_-                                        (21)
```

satisfies `3v=w`.  This proves clause 4 and both directions of the claimed
equivalence.

Equations `(8)--(10)` now follow by substitution into `(2)`.  Relative to
the ordered basis `(D_+,D_-)`, the old boundary vectors are

```text
B_+=(2,-1),                         B_-=(-1,2).             (22)
```

The coordinate matrix has determinant three and pulls the hyperbolic Gram
matrix in `(11)` back to `K_10`.  Since `U` is unimodular, its image in the
free numerical Picard lattice is automatically primitive and an orthogonal
direct summand.  This proves `(11)` without assuming that the ambient
lattice is unimodular.

If the deck involution extends to `Y` and exchanges `B_+,B_-`, then `(4)`
also gives

```text
tau(v)=-v,                         tau(D_+)=D_-.             (23)
```

## 4. What the isotropic classes do not say

The classes `D_+,D_-` are integral Picard classes, but the theorem does not
make them effective.  Although `(9)` says that their cubes have effective
representatives, effectiveness does not descend through taking a line-
bundle cube.  Nor are these classes nef:

```text
D_+ B_+=-1,                         D_- B_-=-1.             (24)
```

Consequently their square zero does not define a pencil or fibration.  If,
under extra hypotheses, `D_-` were effective, then `(24)` would force
`B_-` to be a fixed component and the residual effective class would be
`v=D_--B_-`, with `T v=0`.  For ample `T` this is impossible.  When `T` is
the nef pullback of an ample line class on a resolution, it forces the
residue into the contracted exceptional lattice.  These are useful next
tests, not conclusions of the theorem.

THM-3913 supplies a genuine one-place decic cubic order and hence a genuine
quadratic-resolvent three-class.  Its current proof does not compute an
orthogonal, three-prime finite exceptional block or establish `(4)` in the
form required above.  Therefore the present theorem does **not** silently
identify the THM-3913 Kummer class with the pure boundary residue.  It gives
the exact diagnostic: after those two missing checks, boundary-only
globalization would force the hyperbolic packet `(8)--(11)`.

## 5. Scope and replay

This theorem fails to apply if a finite exceptional block contributes
three-primary discriminant, if the boundary is not orthogonal to the rest
of the actual removed lattice, or if `Pic(Y)[3]` is nonzero.  Merely having
the numerical pair `D^2=0,T D=1` is not enough: the exact cubic-root equation
`3D=T+B_-` is load-bearing.  The theorem proves neither a plane atlas nor a
Jacobian counterexample.
