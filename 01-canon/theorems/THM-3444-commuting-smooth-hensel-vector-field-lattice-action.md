# THM-3444 -- commuting smooth Hensel vector fields give a free lattice action

**RESERVED / UNPROVED EMPTY STUB.**

Reserved for the independently auditable higher-rank extension of THM-3442.
The intended datum is a commuting `r`-tuple of genuine automorphisms of a
smooth `p`-adic scheme, all congruent to the identity at one depth, whose
first-carry vector fields are pointwise linearly independent.  The expected
target is a free `(Z/p^(a-c)Z)^r` action on each depth-`c` Hensel fibre, with
an exact orbit-bank invoice and a first-lift converse.  This stub contains no
proved claim and has no proved dependencies.
