# THM-4719 — window completeness of 3-smooth ladders

## Setting

For coprime `(q, p)`, `q > p ≥ 1`, the ladder is `L(q,p) = {ℓ_i = 2^i 3^(j(i)) : 0 ≤ i ≤ q−2}` with `j(i) = p − 1 − ⌊(i+1)p/q⌋` (THM-4717 (1)); `m = min L`, `M = max L`. Note `ℓ_0 = 3^(p−1)` and `ℓ_(q−2) = 2^(q−2)`. A 3-smooth number is `2^a 3^b`, `a, b ≥ 0`.

## Statements

1. **Criterion (PROVED).** `L(q,p)` is exactly the set of 3-smooth numbers in `[m, M]` iff `M < 3m` and `M < min(2^(q−1), 3^p)`.

2. **Census (FINITE-EXACT, `q ≤ 60`).** The complete shapes are the 14 listed in the title; the ratio `M/m` runs `1.5, 2, 2, 2.25, 2.53, 2.67, 2.67, 2.67, 2.67, 2.81, 2.81, 2.85, 2.96, 2.96`. Every convergent and semiconvergent of `log_3 2 = [0; 1, 1, 1, 2, 2, 3, 1, 5, …]` with `q ≤ 60` (`2/3, 3/5, 5/8, 7/11, 12/19, 17/27, 29/46`) is complete; so are the golden shapes `(13, 8)`, `(21, 13)` and `(3,1), (5,2), (7,4), (29,18), (35,22)`; the shapes `(30, 19)` and `(49, 31)`, with `|q log_3 2 − p| = 0.072, 0.084`, are not.

3. **Pythagorean scale (PROVED from 1 and THM-4717).** For a complete shape the sorted balanced free cycle of `3x + (2^q − 3^p)` is `n_min` plus the partial sums of the consecutive 3-smooth numbers of `[m, M]` in the intercept order; its consecutive ratios of differences are the Pythagorean intervals `3/2, 4/3, 9/8, 32/27, 256/243, …` of the window, e.g. `3x + 13`: differences `48, 54, 64, 72, 81, 96, 108` (ratios `9/8, 32/27, 9/8, 9/8, 32/27, 9/8`, i.e. `1 : 9/8 : 4/3 : 3/2 : 27/16 : 2 : 9/4`), the Pythagorean pentatonic scale on `48` continued through the octave.

## Proof of 1

The ladder has exactly one element in each column `i = 0, …, q−2` of the lattice `(i, b)`, at height `j(i)`. A 3-smooth number `2^i 3^b` in `[m, M]` not in `L` is either (a) in a ladder column with `b ≠ j(i)`, or (b) in a column `i ≥ q−1`. (b): the smallest such number is `2^(q−1)` (`b = 0`), so (b) is excluded iff `M < 2^(q−1)`; similarly a number with `b ≥ p` is at least `3^p`, excluded iff `M < 3^p` (every ladder element has `b ≤ p−1`). (a): if `M < 3m` then every `ℓ_i ∈ [m, M]` satisfies `3ℓ_i > M` and `ℓ_i/3 < m`, so no other height in its column lies in the window; conversely if `M ≥ 3m` then `3m` is a 3-smooth number in `[m, M]` in the column of `m`, at a height different from `j`, hence an intruder. ∎
