# THM-5152 - the 3-adic chart class omits 31 and sixteen more counts at every order

Let G be the grammar generated from a vertex by ordinal joins X => Y and cyclic joins C3[X,Y,Z]. Its spectrum is
Session 268's. Session 312 proves that the switching closure of G is exactly the class C of 3-adic determinant
orientations chi(det(v_i, v_j)), v_i in Q_3^2: the tournaments read off the digit-reversed address chart.

**(1) Decision procedure.**
- C is hereditary.
- Deleting singleton components keeps both membership in C and H.
- H is the product over the strong components.
- A strong tournament of order n has H >= f(n) = min{3^a 5^b : 2a + 3b = n − 1}, the Busch values 3, 5, 9, 15, 25,
  45, 75, 125, 225, 375 for n = 3..12.

Hence the odd values below B attained by C form the multiplicative closure, within [1, B), of the values attained
by strong members of order <= n_0, where f(n_0 + 1) >= B. A prime or 7p value missed there is missed at every order,
since 7 is never a count (THM-1370).

**(2) Computation.** The grammar classes are canonical modular-decomposition trees, counted 1, 1, 2, 4, 9, 24, 65,
182, 528, 1,558, 4,674 at orders 1..11. All 2^(n−1) switches of each were computed.

**(3) Omissions below f(12) = 375, at every order:**

    7, 21, 31, 35, 53, 113, 127, 149, 173, 181, 203, 217, 251, 263, 277, 287, 341, 343

- primes: 7, 31, 53, 113, 127, 149, 173, 181, 251, 263, 277;
- 7p: 21, 35, 203, 217, 287;
- other: 341 = 11 · 31 and 343 = 7^3.

Every value here except 7 and 21 is an ordinary Hamiltonian-path count; for example the order-6 tournament with rows
(36, 17, 2, 7, 13, 30) has H = 31. So the address chart, in which valuations recover ancestry and leading digits
recover orientation, is a strictly smaller target language than the full spectrum. Prime and 7p selection needs
module interiors or port data outside the chart, as Session 312's D-boundary and Session 313's physical switches
indicate.
