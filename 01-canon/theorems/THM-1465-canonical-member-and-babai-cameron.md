# THM-1465 — The canonical member of an odd-order switching class, and Babai–Cameron Remark 7.4 for all odd n

**Status:** PROVED (proof below; verified exhaustively n=3,4,5,6).
**Author:** death-star-2026-07-20-S61d (HYP-8325). Extends Babai–Cameron Remark 7.4.

## Statement

Let the switching classes of tournaments on the labeled vertex set {1,…,n} be the orbits
under vertex switching (= cosets of the cut space B=⟨δ(v)⟩ ⊆ F₂^{E(K_n)}); each has 2^{n−1}
members.

**(1) Canonical member (n odd).** For every odd n, each switching class 𝒞 contains a
**unique** member c(𝒞) whose out-degree sequence is
- **all even**, if n ≡ 1 (mod 4);
- **all odd**, if n ≡ 3 (mod 4).

**(2) It is fixed.** c(𝒞) is fixed by every automorphism of 𝒞 (every g ∈ S_n with g·𝒞 = 𝒞).
Hence **Aut(𝒞) = Aut(c(𝒞))**, and no switching class of odd order admits a **fixed-point-free
automorphism** (one fixing no member). So the Babai–Cameron Remark 7.4 count — switching
classes some automorphism of which fixes no member — is **identically 0 for all odd n**
(their observation was for n ≡ 1 mod 4; the n ≡ 3 case is carried by the all-*odd* member).

**(3) Even n is the genuine case.** For even n there is in general no such canonical member
and the count is positive: verified **8 of 8** switching classes at n=4 and **640 of 1024** at
n=6 admit a fixed-point-free automorphism. This is exactly the case Babai–Cameron said "we
cannot do."

## Proof of (1),(2)

Work with the out-degree **parity vector** p(T) ∈ F₂^n, p(T)_i = out-deg_i mod 2. Switching at
v reverses every arc at v: out-deg(v) ↦ (n−1) − out-deg(v), a parity change of (n−1) mod 2,
and each other out-deg(u) flips by ±1. For **odd** n (n−1 even), switching at v therefore
changes p by the vector (𝟙 − e_v) (all ones except position v; p(v) unchanged since n−1 is
even). The map φ: (switch subgroup) → F₂^n, S ↦ Σ_{v∈S}(𝟙 − e_v), is a homomorphism from the
switch group (Z/2)^{n−1} (generated by the n vertex switches modulo the all-switch = identity
relation). Its image is the **sum-zero subspace** {x : Σx = 0} (dimension n−1): the differences
(𝟙−e_v) − (𝟙−e_u) = e_u − e_v span it, and each generator 𝟙−e_v has weight n−1 (even) hence lies
in it. φ is injective on the quotient (if Σ_{v∈S}(𝟙−e_v)=0 then S = ∅ or all — both the
identity), so φ is a **bijection** (Z/2)^{n−1} → sum-zero.

Fix any T ∈ 𝒞. As S ranges over the switch group, p(switch_S T) = p(T) + φ(S) ranges over the
coset p(T) + (sum-zero) **bijectively** — each parity vector of the coset is realized by
exactly one member of 𝒞. Now:
- the all-even vector **0** lies in the coset ⟺ p(T) ∈ sum-zero ⟺ Σp(T) = C(n,2) ≡ 0 (mod 2)
  ⟺ **n ≡ 1 (mod 4)**;
- the all-odd vector **𝟙** lies in the coset ⟺ Σ(𝟙 − p(T)) = 0 ⟺ n ≡ C(n,2) (mod 2), which for
  odd n means C(n,2) odd ⟺ **n ≡ 3 (mod 4)**.

Either way exactly one member is canonical, proving (1). For (2): an automorphism g of 𝒞
relabels vertices, permuting out-degrees, so it preserves "all even" / "all odd"; being unique,
c(𝒞) is fixed. A fixed-point-free automorphism would fix no member, contradicting that it fixes
c(𝒞). ∎

## Remarks

- **The mod-4 dichotomy is the Paley dichotomy.** n ≡ 3 mod 4 (3, 7, 11, …) is where **Paley
  tournaments** live (q ≡ 3 mod 4); their canonical member is the all-*odd* (near-regular) one,
  and C(n,2) is odd. n ≡ 1 mod 4 (5, 9, 13, …) is where **Paley graphs** (self-complementary)
  live; the canonical member is the all-*even* one, C(n,2) even. So the primes 3, 7 pattern
  together (all-odd member, tournament side) and 5 sits with 1, 9 (all-even member, graph side).
- **The even-n hard case carries the parity.** For even n the eps-parity statistic of DFGPR
  (boxeph HYP-8295) is nontrivial — mass |E[eps over S_n]| = 0, 1/2, 1/2, **3/8**, … first
  leaving the quarter-lattice at n=8 (K8: f+ = 11/16) — precisely where no canonical member
  organizes the class. Odd n: canonical member ⟹ count 0; even n: no canonical member ⟹
  the genuinely open Babai–Cameron enumeration.
