# THM-4860 — the prime square-sum graph: residues, Chebyshev's bias, and the 25 primes below 100

Let `G` be the graph on the primes with `p ∼ q` iff `p + q` is a perfect square, and `G_N` its restriction to the primes below `N`.

**(a) Bipartite by residue mod 4.** `A = {2} ∪ {p ≡ 1 (mod 4)}` and `B = {p ≡ 3 (mod 4)}` are the two sides of every `G_N`; moreover every neighbour of 2 is `≡ 7 (mod 8)`.
*Proof.* For odd `p, q`, `p + q` is even, so a square `p + q` is `≡ 0 (mod 4)`, forcing `{p, q} ≡ {1, 3} (mod 4)`. For `q` odd, `2 + q` is an odd square, `≡ 1 (mod 8)`, so `q ≡ 7 (mod 8)`, in particular `q ∈ B`. ∎

**(b) Mod 3.** Two primes `≡ 1 (mod 3)` are never adjacent: their sum is `≡ 2`, a non-residue mod 3. ∎ (Both (a) and (b) were also checked by brute force on all 85,035 edges of `G_{10^5}`.)

**(c) The 25 primes below 100.** `G_{100}` has 24 edges (squares 9, 16, 16, 25, 36×4, 49, 64×5, 81, 100×6, 144×3), a component of 22 and the isolated primes 37, 43, 67 (first prime partners 107, 101, 257; all three are non-supersingular). Leaves: 19, 31, 73, 79, 89. On Ogg's layers: Fi22 `{2,3,5,7,11,13}` induces the perfect matching `2–7, 3–13, 5–11`; `B∖Fi22 = {17,19,23,31,47}` the path `19–17–47` with 23, 31 internally isolated; `M∖B = {29,41,59,71}` the perfect matching `29–71, 41–59` (both sums 100); the non-supersingular pentads `{37,43,53,61,67}` and `{73,79,83,89,97}` are edgeless. By (a) the sides of `M∖B` are `29, 41 | 59, 71`, so a matching must pair across, and `29–71, 41–59` is the only pairing with square sums (the other gives 88, 112). On the fifteen supersingular primes the sides have sizes 6 and 9, so no Hamiltonian path exists by imbalance alone (session32 proved it by the leaf count). Null model: among the ten non-supersingular primes below 100 the only edge is `61–83`, and 70 of the 126 splits into two pentads leave both halves edgeless; the owner's size split is not distinguished. NUMEROLOGY.

**(d) Prime square-sum paths and Chebyshev's bias.** If the primes below `N` can be arranged so that consecutive sums are squares (a Hamiltonian path of `G_N`), then `G_N` has no isolated vertex, at most two leaves, and, by (a), `| |A| − |B| | ≤ 1`, i.e. `π(N;3,4) − π(N;1,4) ∈ {0, 1, 2}`; a Hamiltonian cycle needs bias exactly 1 and minimum degree 2. Tracking the three conditions over all prime bounds `N < 700,000`: the bias lies in `{0,1,2}` at 400 bounds, but **no bound below 615,731 satisfies all three** (the first Chebyshev window near 26,861 fails on isolated and leaf primes); the 323 bounds that pass are exactly `615,731 ≤ N ≤ 634,199`, the second Chebyshev window; and **no bound below 700,000 passes the cycle conditions** (a leaf prime is present at every bias-1 bound; at 700,000 the only leaf is 582,451 with the single partner 362,333). At `N = 615,731`: 50,283 primes, 930,345 edges, one leaf, four primes of degree 2, `|A| − |B| = −1`. ∎ (FINITE-EXACT; `scripts/prime_path_scan.py 700000`.)

**(d′) The mod-12 refinement.** By (a) and (b), a prime `≡ 1 (mod 12)` is adjacent only to primes `≡ 11 (mod 12)` and to 3, and a prime `≡ 7 (mod 12)` only to primes `≡ 5 (mod 12)` and to 2 (checked on all edges below `10^5`). In a Hamiltonian path a class with `c` vertices and `e` endpoints carries `2c − e` path edges, all of which must land in its partner class of capacity `2c′ − e′`; hence `c_1 ≤ c_11 + 2` and `c_7 ≤ c_5 + 2` (with `c_r` the number of primes `≡ r (mod 12)` below `N`; the `+2` absorbs the two endpoints and the primes 2 and 3). Below `5·10^6` the three count conditions (mod 4, class 1, class 7) hold exactly on the bounds in `(100, 27,031] ∪ [615,731, 634,199]`; at `N = 615,731` the margins are `c_1 − c_11 = −44`, `c_7 − c_5 = −43`, so the window is not excluded. ∎ (FINITE-EXACT; `scripts/prime_path_mod12.py`.)

**(d″) The mod-36 partner law.** If `p ≡ 1 (mod 12)` is adjacent to `q` then `p + q ≡ 0 (mod 12)`, so `36 | p + q` and `q ≡ −p (mod 36)`; hence the classes `1, 13, 25 (mod 36)` are adjacent only to `35, 23, 11 (mod 36)` (and to 3), the classes `7, 19, 31` only to `29, 17, 5` (and to 2), and six pair conditions `c_a ≤ c_{a′} + 2` are necessary. Below `5·10^6` the mod-4 balance and the six pair conditions hold only for `N ∈ (100, 27,031] ∪ [617,039, 634,199]`; at `N = 615,731` the pair `(25, 11)` fails (`4,183` against `4,178`). ∎ (Law checked on all edges below `10^5`; `scripts/prime_path_mod36.py`.)

**(e) The 2-matching obstruction.** Let `ν₂(G)` be the maximum number of edges of a spanning subgraph with all degrees `≤ 2`; a Hamiltonian path forces `ν₂(G_N) ≥ n − 1`. For the bipartite `G_N`, `ν₂` is a maximum flow (A-vertices and B-vertices with capacities `min(deg, 2)`, edges with capacity 1), computed exactly. `ν₂(G_{615,731}) = 50,274 = n − 9`, so there is **no Hamiltonian path at `N = 615,731`**; the minimum cut is the Hall certificate `S` = the 4,183 primes `≡ 25 (mod 36)` below `N`, `N(S)` = the 4,178 primes `≡ 11 (mod 36)` and the prime 3, capacity `8,358 < 8,366`. The 21 count-admissible bounds `615,731 ≤ N ≤ 617,051` all have `ν₂ ≤ n − 2` (gaps `−8` to `−1`); `N = 617,053` is the first with `ν₂ = n − 1`. ∎ (FINITE-EXACT, `scripts/prime_path_2matching.py`; certificate re-verified from the adjacency lists.)

**(e′) The segment condition.** For a restricted class `a` with partner class `a′` and shared special prime `s` (3 for `a ∈ {1, 13, 25}`, 2 for `a ∈ {7, 19, 31}`), the path edges inside `X_a = (class a) ∪ (class a′) ∪ {s}` form a forest containing the `2c_a − e_a` edges at class `a`, so `2c_a − e_a ≤ |X_a| − 1 = c_a + c_{a′}`, i.e. `c_a − c_{a′} ≤ e_a`, where `e_a ≤ 2` is the number of global endpoints in class `a`; the endpoints lie both in B when `|B| = |A| + 1`, one on each side when `|A| = |B|`, both in A when `|A| = |B| + 1`, and a leaf prime is always an endpoint. At `N = 617,053`: `|B| = |A| + 1`, so `e_25 = 0`, but `c_25 − c_11 = 1`: **no Hamiltonian path**, although `ν₂ = n − 1`. At `N = 617,039` the counts allow `e_25 = 2` but `|A| = |B| + 1` forces both endpoints into A while the leaf `582,451` is in B (`ν₂ = n − 2`). Below `5·10^6` the segment conditions hold only for `N ∈ (100, 1,423] ∪ [26,821, 27,031] ∪ [617,039, 634,199]`. ∎ (`scripts/prime_path_mod36.py` (iv).)

**(f) Existence and minimality.** The first 50,396 primes, `2, 3, …, 617,053` (all primes below `617,059`), can be arranged in a row in which every one of the 50,395 consecutive sums is a perfect square. The row begins `582,451, 362,333, 293,767, 381,917, 313,639, 391,961` and ends `244,451, 256,813, 351,587, 616,669`; 245 distinct square roots occur, from 6 to 1,110. It was built from the maximum 2-matching of (e) by merging its cycles into its path with 2-opt exchanges and 3-opt insertions (`scripts/prime_path_flow.py`, deterministic with seed 1, 10 seconds), is stored in the packet (`data/prime_path_N617059.txt`, SHA-256 `f6f520ee0f74371834b9c0de533232764febd35158649e65c1de2243e0f00491`) and is checked by an independent verifier (`scripts/prime_path_verify.py`). By (d), (d′), (e) no bound below `617,053` admits such an arrangement, and (e′) excludes `617,053`; hence **50,396 is the least number of initial primes admitting a square-sum arrangement**. The structure is forced: `|A| = |B|`, the A-endpoint is a class-25 prime (`616,669 ≡ 25 (mod 36)`) and the `(25, 11)` piece is one segment through the prime 3. ∎ (CONSTRUCTION, VERIFIED; minimality FINITE-EXACT.)
