# THM-2783 -- weighted long walls and the binary/ternary coding fork

**RESERVED / UNPROVED EMPTY STUB.**

No mathematical claim is established by this reservation.  The intended
target is the arbitrary-wall extension of the signed-component determinant
formula, the exact equivalence between universal nonvanishing and distinct
Boolean subset sums, and the sharp integer-height distinction between binary
null avoidance and balanced-ternary reconstruction of all
`{-1,0,1}` tree states.  Promotion must keep these arithmetic coding roles
separate from an actual `PSL_2(Z)=C_2*C_3` action and must not claim a
graceful-tree, Keller, `JC(2)`, `DC(2)`, or `LRC(14)` consequence.
