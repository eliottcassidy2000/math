# THM-5154 - the arc-usage multiset is complete up to run slides, core flips and converse, to order 9

For an arc u -> v let W(u,v) be the number of Hamiltonian paths that use it. The **arc-usage multiset** of T is the
multiset {W(u,v)}, with the zero weights (arcs left behind) counted. Converse reverses every path, so the multiset
is a converse invariant. The weights sum to (n − 1) H.

**(A) Invariance (proved).** Write T = R_0 => S_1 => R_1 => ... => S_k => R_k, with nontrivial strong cores S_i and
transitive runs R_i of r_i >= 0 singletons. Put h = prod H(S_i). By the ordered SCC product (Session 319):

- each run has r_i − 1 inner arcs, each of weight h;
- the seam from a nonempty run R_(i−1) into S_i has weights s_(S_i)(v) h/H(S_i), one for each v in S_i;
- the seam from S_i into a nonempty run R_i has weights e_(S_i)(u) h/H(S_i);
- an empty run between two cores gives seam weights e_(S_i)(u) s_(S_(i+1))(v) h/(H(S_i) H(S_(i+1)));
- arcs inside a core have weights W_(S_i) h/H(S_i);
- every other arc has weight 0.

So the multiset depends only on four things:
- the cores;
- which runs are empty;
- the count sum_i (r_i − 1)_+ = (sum_i r_i) − #(nonempty runs);
- for each core flanked on both sides by nonempty runs, only the union of its start and end weights, which converse
  swaps.

W_(S^op) is W_S reversed. Q is multiplicative, commutative over ordinal sums, and converse-invariant. This proves
the invariance under moves (i)-(iii).

**(B) Completeness to order 9 (finite-exact).**

| n | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---:|---:|---:|---:|---:|---:|---:|
| merged classes | 2 | 3 | 10 | 34 | 272 | 3528 | 97144 |
| distinct arc-usage multisets | 2 | 3 | 10 | 34 | 271 | 3526 | 97121 |
| collision groups | 0 | 0 | 0 | 0 | 1 | 2 | 22 |

Every collision group is generated by moves (i)-(iii). Examples:
- at order 7, TT1 => C3 => TT3 against the self-converse TT2 => C3 => TT2;
- at order 9, TT2 => S => TT1 against TT2 => S^op => TT1 for order-6 cores S, and TT2 => C3 => TT1 => C3 against
  TT1 => C3 => TT2 => C3.

The moves fix Q and act trivially on strong tournaments. Beyond order 10 other coincidences occur (see status). So through order 9 the multiset determines the slot
polynomial of every tournament, and determines every strong tournament up to converse.

**(C) The strong slice beyond order 9.** Of the uniquely Hamiltonian classes, the self-converse ones number 13, 47,
34 at orders 10, 11, 12. The multisets give exactly 195, 517, 1309 values: one per class up to converse.
