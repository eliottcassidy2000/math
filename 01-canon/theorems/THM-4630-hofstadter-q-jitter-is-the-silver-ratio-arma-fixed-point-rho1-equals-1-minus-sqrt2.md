# THM-4630 — the silver-ratio fixed point of Hofstadter's Q

## Setting

`Q(1) = Q(2) = 1`, `Q(n) = Q(p) + Q(q)` with `p = p(n) = n - Q(n-1)`, `q = q(n) = n - Q(n-2)`; `d(n) = Q(n)/n - 1/2`; `s(n) = (p/n) d(p) + (q/n) d(q)`. Generation `k` is `[2^k, 2^(k+1))`.

## Statement

1. **(Exact; PROVED on every legal prefix.)** `d(n) + (1/2)(1 - 1/n) d(n-1) + (1/2)(1 - 2/n) d(n-2) = s(n) + 3/(4n)` for every legal `n >= 3`, and `q(n+1) = p(n) + 1` whenever both indices are defined. The backward indices satisfy `p/n = 1/2 + 1/(2n) - (1 - 1/n) d(n-1)`, `q/n = 1/2 + 1/n - (1 - 2/n) d(n-2)`.

2. **(The fixed point; PROVED under H1-H3.)** Assume, within a generation, (H1) the sampled values `d(p(n))` and `d(q(n))` are uncorrelated with each other and with every other source value except through the shared adjacent index of 1 (`q(n+1) = p(n) + 1`), (H2) the weights `p/n`, `q/n` may be replaced by `1/2`, and (H3) the autocorrelation function `rho` of `d` is the same in consecutive generations. Then `s` is a stationary input with `var(s) = var_prev/2`, where `var_prev` is the variance of the sampled values, and autocorrelation `rho_s(1) = c = rho(1)/2`, `rho_s(l) = 0` for `l >= 2`; `d` is the ARMA(2,1) output `d(n) = -d(n-1)/2 - d(n-2)/2 + s(n)` (dropping `O(1/n)`), whose Yule-Walker equations
   `gamma(0) = -gamma(1)/2 - gamma(2)/2 + sigma^2 (1 - c/2)`, `gamma(1) = -gamma(0)/2 - gamma(1)/2 + sigma^2 c`, `gamma(2) = -gamma(1)/2 - gamma(0)/2`
   together with `c = gamma(1)/(2 gamma(0))` give `rho(1)^2 - 2 rho(1) - 1 = 0`. Hence
   `rho(1) = 1 - sqrt 2 = -0.414214`, `c = (1 - sqrt 2)/2 = -0.207107`, `var(d)/var(s) = (3 + sqrt 2)/(4 - sqrt 2) = 1 + 1/sqrt 2 = 1.707107`,
   `var_prev/var(d) = 2 var(s)/var(d) = 4 - 2 sqrt 2 = 1.171573` for the sampled variance; if the sampled variance equals the previous generation's, the jitter variance falls by that factor per generation and `rms(Q(n) - n/2) ~ n^(1 - log2(4 - 2 sqrt 2)/2) = n^0.88579`; the full autocorrelation is `rho(l) = int_0^pi |H(w)|^2 (1 + 2c cos w) cos(l w) dw / int_0^pi |H(w)|^2 (1 + 2c cos w) dw` with `H(w) = 1/(1 + e^(-iw)/2 + e^(-2iw)/2)`, whose poles `(-1 +- i sqrt 7)/4` have modulus `1/sqrt 2` and period `2 pi/arg = 3.2519`: `rho(1..12) = -0.414, -0.293, +0.354, -0.030, -0.162, +0.096, +0.033, -0.064, +0.016, +0.024, -0.020, -0.002`.
3. **(Data; NUMERICAL, `Q` exact to `2^30`.)** On the octaves `2^20, 2^22, 2^24, 2^26`: `rho(1) = -0.41379, -0.41438, -0.41425, -0.41422`; `rho_s(1) = -0.20683, -0.20733, -0.20708, -0.20716`; `var(d)/var(s) = 1.70991, 1.70697, 1.70656, 1.70699`; `corr(d(p(n)), d(q(n))) = +0.0017, +0.0003, -0.0002, +0.0001`; `corr(d(p(n)), d(p(n+1)))` and `corr(d(q(n)), d(p(n+1)))` below `0.002`; `corr(d(q(n+1)), d(p(n)+1)) = 1.00000` (the index identity); mean `p/n = 0.50000`, standard deviation `0.010, 0.0085, 0.0072, 0.0062`. The autocorrelation at lags `1..12` is `-0.414, -0.293, +0.353, -0.030, -0.162, +0.096, +0.033, -0.064, +0.014, +0.025, -0.019, -0.004` at `2^22`, within `0.002` of the `2^28` row from `2^20` on and within `0.02` at `2^12` and `2^16`; the dominant short period in the periodogram is `3.03-3.31` (the pole period is `3.2519`; the spectral peak of the fixed point is at `3.18`). The rms of `d` per generation (`meta_fibonacci_resonator_20261013.out`) gives consecutive variance ratios with mean `1.178 +- 0.006` over `k = 14..28`, 13 of 15 above the model's `1.1716` (at `2^20` the sampled variance is `0.7%` below the generation variance: ratio `1.168` for the sampled, `1.177` for the generation variance), i.e. a measured generation exponent `0.882-0.884` against the model's `0.886` for the sampled variance. The increments `Q(n) - Q(n-1)` are large (`rms((Q(n) - Q(n-1))/n) = 0.010` at `2^26`; the fraction with `|Q(n) - Q(n-1)| <= 2` is below `1e-4`), which is why the two backward indices sample the previous generation at unrelated positions (H1).

## Proof

**1.** `Q(n)/n = (p/n)(1/2 + d(p)) + (q/n)(1/2 + d(q)) = (p + q)/(2n) + s(n)` and `p + q = 2n - Q(n-1) - Q(n-2) = 2n - (n-1)(1/2 + d(n-1)) - (n-2)(1/2 + d(n-2)) = n + 3/2 - (n-1) d(n-1) - (n-2) d(n-2)`; divide by `2n`. The index identity: `q(n+1) = n + 1 - Q(n-1) = p(n) + 1`. ∎

**2.** *The input.* `cov(s(n), s(n+1))`: of the four products, only `d(p(n)) d(q(n+1)) = d(p(n)) d(p(n)+1)` is correlated under H1, with weight `1/4` by H2: `cov = gamma_prev(1)/4`; `var(s) = (1/4 + 1/4) var_prev` by H1-H2; so `c = rho_prev(1)/2 = rho(1)/2` by H3, and `cov(s(n), s(n+l)) = 0` for `l >= 2` (no shared or adjacent indices). *The output.* With `x_n = d(n)`, `phi_1 = phi_2 = -1/2`, and `E[x_(n-l) s_n] = sigma^2 (h_(-l) + c (h_(-l-1) + h_(-l+1)))` for the impulse response `h_0 = 1`, `h_1 = -1/2`, ... (`h_j = 0` for `j < 0`), the Yule-Walker equations are as displayed (`E[x_n s_n] = sigma^2 (1 - c/2)`, `E[x_(n-1) s_n] = sigma^2 c`, `E[x_(n-l) s_n] = 0` for `l >= 2`). Writing `rho = gamma(1)/gamma(0)` and `t = sigma^2/gamma(0)`: the second equation gives `rho = -1/3 + (2/3) t c`, the first with the third gives `t = (3/4)(1 + rho/3)/(1 - c/2)`; with `c = rho/2`, `rho = -1/3 + (rho/4)(1 + rho/3)/(1 - rho/4)`, i.e. `(rho + 1/3)(1 - rho/4) = (rho/4)(1 + rho/3)`, i.e. `rho^2 - 2 rho - 1 = 0`, whose root in `(-1, 1)` is `1 - sqrt 2`. Then `1/t = (4/3)(1 - rho/4)/(1 + rho/3) = (3 + sqrt 2)/(4 - sqrt 2) = 1 + sqrt 2/2`, and `var_prev = 2 sigma^2 = 2 gamma(0)/(1 + 1/sqrt 2) = (4 - 2 sqrt 2) gamma(0)`. The spectral form of `rho(l)` is the ARMA spectral density `|H|^2 (1 + 2c cos w)`; the poles of `H` are the roots of `z^2 + z/2 + 1/2`. ∎

## Reading

Under the unproved sampling and stationary-envelope assumptions, the model explains Q's measured jitter as follows: its two backward indices overshoot by the previous deviations; the overshoot feeds the last two deviations back with weight `-1/2`, a damped resonator of period `3.25`, and the indices scatter the previous generation's chaos into a white input. The only correlation the input keeps is the one the index identity `q(n+1) = p(n) + 1` forces, and that single lag closes the loop: the lag-1 correlation must satisfy `rho^2 - 2 rho - 1 = 0`. The model predicts the measured second-order statistics, including an rms fluctuation exponent near 0.886. This is not an unconditional growth theorem for Q. A subsequent exact calculation gives the full correlation update `(r-1)/(3-r)`, its two-step Pell conjugacy and variance law; see [golden/nested section 6](../../05-knowledge/results/golden_nested_trees_20261013c.md#6-incoming-q-covariance-work-a-genuine-two-step-pell-mechanism). That continuation independently checks the finite Q identities through 2^16; it does not prove the sampling assumptions or audit the entire original numerical census.
