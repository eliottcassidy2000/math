# THM-1097 — reserved sharp three-comb component theorem

For a nine-speed core `P subset {1,...,12}` and ordered killers

```text
13 max(P) < k1 < k2 < k3,
```

the target is to prove that

```text
S(P) minus (D_k1 union D_k2 union D_k3)
```

has a component longer than `1/(7k3)`.  The constant is matched to the sharp
single-comb discrepancy

```text
|J intersect D_k| <= |J|/7 + 6/(49k),
```

so a fourth killer `k4>k3` cannot cover that component.

The analytic mass/component estimate is automatic once `ell(P) k1>=7` and
gives explicit rational cutoffs below that threshold.  A preliminary exact
count of the deliberately guarded finite complement is `39,778,595` triples
over all `C(12,9)=220` cores.  This page reserves the theorem namespace while
that bank is independently audited and scanned.  It is not yet a theorem and
does not yet promote the uniform `r=4` stratum.
