# THM-4118 -- ear response lattices and stateful unit components

**PROVED ELEMENTARY REDUCTIONS + VERIFIED-EXACT + INDEPENDENTLY AUDITED.**

THM-4114 shows why rank and positivity alone do not force a solid ear image.
This theorem isolates the exact arithmetic obstruction and then adds the
smallest stateful sidecar that does certify intervals. The arithmetic lattice
is complete as a congruence invariant; it is deliberately not claimed to be
a completeness criterion for feasible cut states.

## 1. Exact response lattice

Let `T` be a strong tournament on `V`, with `n=|V|>=3`. For `S subseteq V`,
let `T+x_S` orient

```text
x -> i  iff  i in S,
```

and put

```text
F_T(S)=H(T+x_S),             H=H(T).                       (1)
```

The constant cuts make `x` a source or sink, so

```text
F_T(emptyset)=F_T(V)=H.                                   (2)
```

Define the singleton response and symmetric pair curvature

```text
A_i=F_T({i})-H,
K_ij=F_T({i})+F_T({j})-F_T({i,j})-H.                      (3)
```

In THM-4097's boundary notation, `K_ij=Q_ij+Q_ji`. Hence the directed-cut
formula expands exactly as

```text
boxed: F_T(S)=H+sum_(i in S) A_i
                  -sum_({i,j} subseteq S) K_ij.           (4)
```

Let `D=2^V minus {emptyset,V}` be the nonconstant-cut domain and set

```text
d_T=gcd({A_i:i in V} union {K_ij:i<j}).                   (5)
```

> **Theorem 1 (exact response lattice).** The additive subgroup generated by
> all nonconstant response increments is
>
> ```text
> <F_T(S)-H:S in D>_Z = d_T Z.                            (6)
> ```

Indeed, `(4)` puts every response increment in the group generated by the
coefficients. Conversely, every singleton belongs to `D`, so `(6)` recovers
`A_i`; because `n>=3`, every pair also belongs to `D`, and

```text
K_ij=A_i+A_j-(F_T({i,j})-H).                              (7)
```

Thus the two groups agree. Every tournament has odd `H`, so all `F_T(S)` are
odd and every generator in `(5)` is even. Moreover some exposed-gap count is
positive along a Hamiltonian path of `T`, so `d_T>0`. Therefore

```text
F_T(S)=H modulo d_T                    for every S,        (8)
d_T is a positive even integer.                            (9)
```

In particular, if one parent realizes two consecutive odd values, then
`d_T|2`, hence necessarily `d_T=2`.

## 2. Stateful unit-component compiler

Make a graph `G_T` with vertex set `D`. Two cuts are eligible neighbours if
one is obtained from the other by either

1. flipping one coordinate; or
2. exchanging one vertex in and one vertex out, preserving cardinality.

Retain an eligible edge exactly when its response change is `0` or `+/-2`.

> **Theorem 2 (unit-component interval).** If `C` is a connected component
> of `G_T`, then
>
> ```text
> F_T(C)={min F_T(C), min F_T(C)+2, ..., max F_T(C)}.       (10)
> ```

Choose cut states in `C` attaining the minimum and maximum, and take a path
between them. Its odd response changes only by `0,+/-2`; the discrete
intermediate-value property forces every intervening odd value to occur.
This proves `(10)`.

The graph is computed directly from `(A,K)`. For `i notin S`, the half-step
flip marginal is

```text
(F_T(S union {i})-F_T(S))/2
 =A_i/2-sum_(j in S)K_ij/2.                              (11)
```

Thus unit magnitudes without their state labels are insufficient: the
availability of a unit move depends on the current cut.

There is also an exact multi-component compiler. Attach interval `(10)` to
every chosen component, possibly from different parents, and connect two
intervals when they overlap or their nearest endpoints differ by `2`. Every
connected component of this interval-overlap graph has solid odd union. This
uses scalar adjacency only at the second stage; it does not invent a physical
cut edge between distinct state components.

## 3. Sharp arithmetic hostiles

For the finite rows below, tournament codes use lexicographically ordered
pairs, least-significant bit first, with bit `1` meaning `i->j`. Cut masks use
bit `i=1` exactly when `x->i`.

Strong order-five code `8` has

```text
H=9,       d_T=2,
image F_T={15,17,19,23,25,27,29,33,37,41}.                (12)
```

The missing value `21` proves that the exact one-coset condition `d_T=2` is
not sufficient. Its combined flip/exchange unit graph has ten components;
the largest certified interval is only `15:2:19`. Code `1015` is code `8`
under the relabelling `(4,3,2,1,0)`.

The THM-4111 companion code `759` has

```text
H=9,       d_T=2,
image F_T={15,17,19,23,29,31,33,37,43};                  (13)
```

its unit graph has seven components, with largest interval `29:2:33`.
Nevertheless three explicitly state-certified component intervals are

```text
code 8:    [23,25] at masks 16 -> 18,
code 8:    [27,29] at masks  5 -> 21,
code 759:  [29,33] at masks  5 -> 9 -> 17.               (14)
```

The first two touch by `2`; the last two overlap at `29`. The interval graph
therefore certifies every odd value in `23:2:33`. The `25` to `27` join is
scalar adjacency, not a cut move inside code `8`.

The opposite congruence boundary occurs at strong order-six code `30571`:

```text
H=45,      d_T=6,
image F_T={93,111,123,129,135,141,153,159,189}
          subset 3+6Z.                                   (15)
```

Among the `35` strong order-six isomorphism classes, exactly `34` have
`d_T=2` and this one has `d_T=6`. None has a solid individual image.

## 4. Exact finite boundary

The labelled strong-parent census is

| base order | strong parents | solid images | `d_T=2` | one unit component spans the image |
|---:|---:|---:|---:|---:|
| `3` | `2` | `2` | `2` | `2` |
| `4` | `24` | `24` | `24` | `24` |
| `5` | `544` | `0` | `544` | `0` |

Thus order five is simultaneously the first failure of individual solidity
and the minimal proof that a saturated response coset does not organize the
feasible cut states. At order six the nontrivial `d_T=6` obstruction first
appears among strong isomorphism classes.

This does not by itself explain THM-4097's entire order-nine interval, which
uses extensive overlap across many parents. The theorem supplies no uniform
component-width or cross-parent overlap bound. The new sidecar is the
labelled unit-state component and its certified interval, not the gcd, rank,
or unlabelled semigroup of possible move sizes.
