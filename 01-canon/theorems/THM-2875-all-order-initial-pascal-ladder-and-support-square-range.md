# THM-2875 -- all-order initial Pascal ladder and support-square range

**PROVED + VERIFIED-EXACT + INDEPENDENTLY HOSTILE-AUDITED.**

Put

```text
L(s^q)=q!,                 f_j=s^j/j!,
d_j=f_(j+1)-f_j.                                      (1)
```

Fix an integer `m>=2` and a finite nonzero cone element

```text
W=sum_(j>=0) mu_j d_j,              mu_j>=0.           (2)
```

Define

```text
D_n=L(d_n W),             R_n^[m]=L(d_n W^m),
S_n^[m]=R_n^[m]/D_n.                                  (3)
```

If

```text
j_*=min{j:mu_j>0},                                     (4)
```

then

```text
S_(n+1)^[m]>S_n^[m]                                    (5)
```

for every

```text
0<=n<=(m-1)(j_*+1)^2.                                 (6)
```

In particular, without any support restriction,

```text
S_0^[m]<S_1^[m]<...<S_m^[m].                          (7)
```

There is a sharper polarized form.  For an `(m+1)`-tuple
`x=(x_0,...,x_m)`, put

```text
b_i=x_i+1,          r=m+1,          B=sum_i b_i,
a=n+1.                                                  (8)
```

Its polarized kernel is positive whenever, for every pair `b_i<b_j`,

```text
b_i sum_(ell!=i,j)b_ell>=n.                            (9)
```

The condition is vacuous if all `b_i` are equal.  Consequently every
single ray `W=lambda d_j`, `lambda>0`, has the strict ladder `(5)` for
all `n>=0`.

The theorem is deliberately not an all-row multi-ray result.  The
remaining regime beyond `(6)` is isolated in Section 8.

## 1. Exact all-order product expansion

For positive integers

```text
b=(b_1,...,b_k),                    B=sum_i b_i,        (10)
```

direct expansion in the normalized factorial basis gives

```text
product_i d_(b_i-1)
 =1/product_i b_i! *
  sum_(q=0)^k (-1)^q e_q(b)(B-q)! f_(B-q).             (11)
```

Since

```text
f_t=1+sum_(h=0)^(t-1)d_h,                              (12)
```

there is a unique triangular expansion

```text
product_i d_(b_i-1)
 =L(product_i d_(b_i-1))
  +sum_(h=0)^(B-1) Q_h(b)d_h,                          (13)
```

where

```text
Q_h(b)
 =1/product_i b_i! *
  sum_(q=0)^min(k,B-h-1)
   (-1)^q e_q(b)(B-q)!.                               (14)
```

Every coefficient `Q_h(b)` is nonnegative.  Indeed,

```text
f_p d_q
 =binom(p+q,p-1)f_(p+q)
  +binom(p+q+1,p)d_(p+q),                              (15)

d_p d_q
 =binom(p+q,p)f_(p+q)
  +binom(p+q+2,p+1)d_(p+q+1),                         (16)
```

where the first coefficient in `(15)` is zero for `p=0`.  Thus the cone
generated by the `f_p` and `d_q` is multiplicatively closed.  Flattening
every positive `f_t` by `(12)` gives nonnegative constant and
`d`-coefficients.  Uniqueness of the triangular basis identifies them
with `(13)--(14)`.

This is the all-order positive factorial-difference semiring behind the
proof.  Positivity of its output measures alone is not enough to orient
the ratio; the cyclic polarization below is load-bearing.

## 2. Rook and marked-cycle tensor

For a list of positive block sizes `c=(c_1,...,c_k)`, define

```text
A(c_1,...,c_k)
 =sum_(q=0)^k (-1)^q e_q(c)
    (sum_i c_i-q)!.                                    (17)
```

Take an `sum_i c_i` square permutation board.  Distinguish `k` rows and
partition the columns into private blocks of sizes `c_i`; in distinguished
row `i`, forbid its own block.  Rook inclusion--exclusion makes `A(c)` the
number of avoiding permutations.

Equivalently, write

```text
c_i=1+|O_i|                                           (18)
```

and distinguish a mark `z_i` with private ordinary-label set `O_i`.
Then `A(c)` counts permutations in which

```text
z_i is not a singleton cycle, and
the predecessor of z_i is not in O_i.                 (19)
```

The two descriptions give the exact tensor identity

```text
L(product_i d_(c_i-1))=A(c_1,...,c_k)/product_i c_i!. (20)
```

For two blocks, the unique block derangement gives

```text
A(a,b)=ab(a+b-2)!,                                    (21)
```

and hence

```text
H_n(x):=L(d_n d_x)=binom(n+x,n)>0.                    (22)
```

## 3. Private-label insertion

Let `c` denote a possibly empty list of remaining blocks and put

```text
N=a+sum_i c_i.                                        (23)
```

Then

```text
A(a+1,c)>=N A(a,c).                                   (24)
```

To prove `(24)`, start with an admitted permutation on the old `N`
labels and add a new private label `*` for the `a`-mark.  The usual
permutation insertion has `N+1` choices: make `*` a singleton, or insert
it immediately after one of the `N` old labels.  Exactly one choice is
forbidden, namely insertion immediately before its own mark.  All other
marks keep an allowed predecessor: if `*` becomes their predecessor,
then it belongs to the disjoint private set of the `a`-mark, not theirs.
Deleting `*` recovers the old permutation, so the `N` admitted extensions
are disjoint.

If there are at least three marked blocks, `(24)` is strict.  Choose two
other marks `z_1,z_2`.  The enlarged permutation having the cycle
`(z_1,*)`, all remaining marks in one cycle, and all ordinary labels in
singleton cycles is admitted.  Deleting `*` makes `z_1` singleton, so
this permutation is not among the extensions counted above.

For exactly two blocks, `(21)` shows that equality in `(24)` occurs
exactly when the unchanged block has size one.  This is a useful hostile
boundary for the insertion argument.

## 4. Fully polarized response kernel

For `x=(x_0,...,x_m)`, define

```text
K_n(x)
 =sum_(i=0)^m [
    L(d_(n+1) product_(j!=i)d_(x_j)) H_n(x_i)
   -L(d_n product_(j!=i)d_(x_j)) H_(n+1)(x_i)
  ].                                                   (25)
```

Expanding `(2)` and symmetrizing all `m+1` dummy indices gives

```text
R_(n+1)^[m]D_n-R_n^[m]D_(n+1)
 =1/(m+1) sum_x (product_i mu_(x_i))K_n(x).            (26)
```

Repeated labels remain repeated in `(25)--(26)`.

Use `(8)` and multiply `(25)` by the common positive denominator

```text
a!(a+1)! product_i b_i!.                              (27)
```

Equations `(20)--(22)` give the exact integer numerator

```text
I
 =sum_i [
   A(a+1,b_(-i))A(a,b_i)
   -A(a,b_(-i))A(a+1,b_i)
  ],                                                   (28)
```

where `b_(-i)` means that `b_i` is omitted.

Apply `(24)` to each first factor in `(28)`.  Since its old board has
`a+B-b_i` labels, and using `(21)`, define

```text
w_i
 =b_i(a+b_i-2)! A(a,b_(-i))>0.                        (29)
```

The strict insertion statement applies because every large factor in
`(28)` has `r=m+1>=3` marked blocks.  Exact simplification yields

```text
I
 >sum_i w_i[1+aB-(2a+1)b_i].                          (30)
```

Thus the alternating determinant is reduced to one weighted-mean
inequality.

## 5. Weight comparison

Suppose `b_i=x<y=b_j` and let

```text
R=B-x-y=sum_(ell!=i,j)b_ell.                          (31)
```

In the weight `w_i`, the large rook factor contains the `y`-block,
whereas in `w_j` it contains the `x`-block.  Repeated use of `(24)` while
growing that block from `x` to `y` gives

```text
w_i/w_j
 >x/y product_(t=x)^(y-1)
      (a+R+t)/(a+t-1).                                (32)
```

If

```text
xR>=a-1,                                              (33)
```

then for every `t>=x`,

```text
(a+R+t)/(a+t-1)>=(t+1)/t,                             (34)
```

because the cross-multiplied difference is `tR-a+1>=0`.  The right side
of `(32)` therefore telescopes to at least one, and strict insertion
gives

```text
b_i<b_j  implies  w_i>w_j.                            (35)
```

Condition `(9)` is exactly `(33)` for every unequal pair.

## 6. Rearrangement and strictness

Sort the `b_i` increasingly.  Under `(9)`, the corresponding weights are
decreasing, and the pairwise covariance identity gives

```text
r sum_i w_i b_i-B sum_i w_i
 =sum_(i<j)(w_i-w_j)(b_i-b_j)<=0.                     (36)
```

Consequently,

```text
sum_i w_i b_i/sum_i w_i<=B/r.                         (37)
```

On the other hand,

```text
(1+aB)/(2a+1)-B/r
 =[r+(a(r-2)-1)B]/[r(2a+1)]>0                        (38)
```

for `r>=3`, `a>=1`.  Therefore the lower bound in `(30)` is strictly
positive:

```text
sum_i w_i[1+aB-(2a+1)b_i]>0.                          (39)
```

Equations `(27)--(30)` prove

```text
K_n(x)>0                                              (40)
```

whenever `(9)` holds.  If all `b_i` are equal, the weights in `(29)` are
equal and `(37)` is equality, while `(38)` remains strict.  This proves
the all-row single-ray assertion.

## 7. From the tuple gate to the support-square range

For every occupied tuple in `(26)`,

```text
b_i>=b_*:=j_*+1.                                      (41)
```

After removing two entries, exactly

```text
r-2=m-1
```

entries remain.  Hence for every unequal pair,

```text
b_i sum_(ell!=i,j)b_ell
 >=(m-1)b_*^2.                                        (42)
```

Thus `(6)` implies the tuple gate `(9)` for every occupied monomial.
Every such monomial has positive coefficient in `(26)`, and at least one
is occupied.  Therefore

```text
R_(n+1)^[m]D_n-R_n^[m]D_(n+1)>0.                     (43)
```

The denominators are positive by `(2)` and `(22)`, so `(43)` is exactly
the strict quotient inequality `(5)`.  Since `b_*>=1`, `(6)` contains
every `0<=n<=m-1`, proving `(7)`.

## 8. All-zero residue and the open high-row regime

Let `Der(q)` denote the derangement number

```text
Der(q)=q! sum_(h=0)^q (-1)^h/h!.                      (44)
```

This notation is distinct from factorial.  At `n=0` and
`x_0=...=x_m=0`, put `X=s-1=d_0`.  Then

```text
d_1=(X^2-1)/2,             L(X^q)=Der(q).             (45)
```

Consequently,

```text
K_0(0,...,0)
 =(m+1)/2 [
   (m-1)Der(m+1)+m Der(m)
  ].                                                   (46)
```

For `m=2,...,7`, these exact values are

```text
6, 48, 420, 3840, 38010, 407904.                      (47)
```

For `m=1`, `(46)` is zero, matching the constant ratio
`L(d_nW)/L(d_nW)=1`; this is the sharp order boundary.

The values `(47)` are proved all-zero residues.  The companion finds
them as the minima only in the explicit finite universe

```text
m=2,...,7,       n=0,       0<=x_i<=5.               (48)
```

No global-minimum statement follows from `(48)`.

For multi-ray cones, the range

```text
n>(m-1)(j_*+1)^2                                (49)
```

remains open.  The sufficient antitone mechanism genuinely fails there:
for

```text
a=4,                 b=(1,1,2),
```

the weights are

```text
(8928,8928,9216),                                    (50)
```

so the larger block receives larger weight.  Nevertheless the exact
lower numerator, full cleared numerator, and kernel are

```text
133632,                   172800,                   30, (51)
```

respectively.  Thus failure of `(9)` is not a counterexample to the
all-order conjecture.

Exact experiments further suggest that the lower bound `(30)`, after
`a=n+1`, has nonnegative Newton coefficients.  That observation remains
finite evidence.  A proof would need to classify the iterated shielding
chains created when deletion of a new private label reveals another
mark's singleton or forbidden predecessor.

## 9. Signed hostile and scope

Nonnegativity in `(2)` is load-bearing.  For

```text
W=d_0-(14/29)d_1,              m=3,              n=0,
```

both denominators are positive:

```text
D_0=15/29,                       D_1=1/29,
```

but

```text
R_1^[3]D_0-R_0^[3]D_1=-5422944/707281<0.             (52)
```

The theorem is an initial/support-sensitive response result, not an
all-row theorem.  THM-2866 remains stronger at the specific cubic order:
it proves the `m=3` ladder for every row and uses it to exclude the
vanishing-quartic-harmonic branch.  THM-2875 does not close the surviving
shared cubic--quartic multipole-line branch, because that branch still
lacks a lawful multiplier/lowering observation.  Nor does this theorem
prove SFC, provide arbitrary signed or complex coefficient control, or
replace the existing GMC2 proof.
