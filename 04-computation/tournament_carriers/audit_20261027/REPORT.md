## NOTES

**N1. Full necessity is true; HYP-9435(1) can be closed.**

*Theorem.* Let D be an oriented excess −1 carrier with A = Aut(D). The following are equivalent:
- (a) D is linearly trijective;
- (b) χ(G^K) = 1 for every subgroup K ≤ A;
- (c) χ(G^⟨g⟩) = 1 for every element g ∈ A.

*Notation.* Write v_K = |V^K|, e_K = |E^K|, x_K = |X^K|, and δ_K = v_K − e_K − 1. For a K-invariant component C, let
c_K(C) = χ(C∩G^K) − χ(C).

- **L1 (twins).**
  - Suppose components C ≠ C′ are isomorphic as oriented graphs via φ.
  - Then τ = φ⊔φ⁻¹⊔id lies in A, and δ(⟨τ⟩) = −2χ(C).
  - Under (a), Part 4(i) gives χ(C) = 0. Under (c) this is immediate.
- **L2 (sign).** Assume every twinned component has χ = 0. Then δ_K = Σ_{K-invariant C} c_K(C) ≥ 0 for every K, for
  these reasons:
  - components not fixed by K have twins, so they contribute 0;
  - for invariant C with C^K nonempty, c_K(C) = rank H_1(C, C^K) ≥ 0;
  - if C^K is empty, C is not a tree, so c_K(C) = −χ(C) ≥ 0.

  In particular v_K ≥ 1, so A fixes a vertex.
- **L3 (solvable subgroups, assuming (a)).**
  - The ψ = 0 mark gives C(x_K,2) = C(v_K−1,2) + δ_K with 0 ≤ δ_K ≤ v_K−1.
  - Since these bounds are consecutive triangular numbers, φ_K := x_K − v_K + 1 lies in {−1, 0, 1}, and φ_K = 0
    forces δ_K = 0.
  - Let H ◁ H′ with prime index p. Fixed points of H′/H on X^H and on V^H give φ_H ≡ φ_{H′} (mod p).
  - For p ≥ 3 this forces equality. For p = 2 the ψ ≠ 0 mark gives equality directly.
  - Since φ_1 = 0, every solvable (in particular every cyclic) K has δ_K = 0. So (a) ⇒ (c).
- **L4 (cyclic implies all).** Assume twins have χ = 0 and δ(⟨h⟩) = 0 for every h.
  - Fix K and a K-invariant component C. By L2, each term c_{⟨h⟩}(C) vanishes.
  - If C is a tree, c_K(C) = 0.
  - If some C^h is empty, then χ(C) = 0 and C^K is empty, so c_K(C) = 0.
  - Otherwise each C^h is connected and contains every cycle of C, hence contains its 2-core.
  - So C^K = ∩ C^h contains the 2-core and is connected: the unique path from a fixed vertex to the 2-core is itself
    fixed. Thus χ(C^K) = χ(C).
  - Therefore δ_K = 0, giving (c) ⇒ (b). Part 2 gives (b) ⇒ (a). ∎

*Consequences:*
- In a linear carrier, components with χ ≠ 0 are pairwise non-isomorphic (so ≥ 2 isolates means non-linear), and A
  fixes a vertex.
- The census observation "cyclic version = all-subgroup version" is now a theorem.
- The "rigidity of j = 1" in HYP-9435(2) is proved.
- The full-group hypothesis is used only in L1; Part 8 shows it cannot be dropped.

*Numerical support (n ≤ 8):*

- L2: δ_K ≥ 0 for every subgroup on all 5580 twin-free carriers with |A| ≤ 200.
- Cyclic version of (C) ⇔ all-subgroup version: no exceptions.
- Linear ⇒ A fixes a vertex: no exceptions.
