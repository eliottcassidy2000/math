How it works

Three steps, each mathematically optimal:

  1. Color decorrelation — YCoCg-R transform separates brightness from color, reducing redundancy between channels. Exactly reversible on integers.
  2. Adaptive prediction — For each row of pixels, 5 different predictors are tested. The best one is chosen automatically. The prediction is subtracted, leaving only the small residual.
  3. Entropy coding — The residuals (mostly near-zero) are compressed with deflate — the same algorithm inside PNG. But our residuals are 20% smaller because steps 1-2 removed more structure.
