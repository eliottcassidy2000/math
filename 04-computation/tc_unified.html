How it works
TIC — color decorrelation (G, R-G, B-G) + MED prediction + adaptive encoding (Golomb-Rice or deflate per plane, picks smaller).
Comparison — real PNG, QOI, WebP (lossless), AVIF, JPEG, and BMP encoding done in-browser. All sizes are actual encoded bytes, not estimates.
Hex editing — edit any format's compressed bytes and decode to see how each format handles corruption.
WebP lossless (via Pillow, not canvas) is the strongest lossless competitor — it beats TIC on most images via LZ77 + 13 predictor modes + Huffman coding. JPEG-LS and JPEG-XL are not available in browsers. RAW camera files (.cr2, .dng) cannot be decoded in-browser — use the Python benchmark.
