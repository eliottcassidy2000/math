## 0. Method and independence

- **Own code only.** All code lives in this directory and imports nothing from the author's modules:
  - `alin.py`: linear algebra over `fmpq_mat` / `nmod_mat`;
  - `virmod.py`: Virasoro vacuum module;
  - `sl2mod.py`: affine sl2 with `(e|f)=1`, `(h|h)=2`;
  - `n4mod.py`: small N=4 algebra, with a super-PBW basis and super-polynomial `gr`.
- **Maximal submodules are computed from scratch.** The rule is: `w ∈ M_D` iff `X·w ∈ M` for a set `X` of positive
  modes that generates the positive part:
  - Virasoro: `L_1`, `L_2`;
  - affine sl2: `e_1`, `h_1`, `f_1`;
  - small N=4: `L_1`, `L_2`, `J_1`, `G_{1/2}`.

  No character formula is used to certify maximality. Characters are cross-checks only.
- **Arc ideal `J`.** Built two ways: from spanning sets `m·d^s g`, and by the recursion
  `J_D = (I_0)_D + Σ_x x·J_{D−wt x} + d J_{D−1}`.
- **Exactness.** THM-4671, THM-4672 up to weight 8, and §1.3 are exact. Range extensions are mod `2^31−1`, with a
  second prime `2^31−19` where stated.

### 1.2 THM-4672 (exact over Q through weight 8; mod p through 12, two primes through 11)

- **Characters.** `dim L_D` from scratch is 1, 3, 9, 22, 46, 93, 176, 319, 562. This equals the Z_2-even βγ

  - `(I_0)_D` equals the ideal generated by the 5 quartics for D ≤ 10.

    generators are even, so there are no sign issues.

  - Weight 7: spin 2 in Li degree 2, and these are new generators.
  - Weight 8: dimension 8 in Li degree 3, spin 2 + spin 1, with the spin 1 new.
  - Mod p it continues 18, 38, 71, 122, with new spin-2 generators at weight 12 (Li 6).
- **Weight-7 representative.** The displayed vector lies in grI and not in J.
- **Hilbert series.** `HS(C[x]/J)` = 1, 3, 9, 22, 46, 93, 176, 324, 570, then 978 mod p.
- **Item 5, exact.**

  - Cas² ∉ I_0 and Cas³ ∈ I_0.
  - For 5 ≤ D ≤ 10, `dim (R_V)_D = 2D+1`. The nilradical is 5-dimensional.

## 2. Findings

### MINOR

**m1. THM-4671 novelty overclaim.**
- Andrews-van Ekeren-Heluani (arXiv:2005.10769), §1.6 and §2.4 second Lemma, give the lowest piece of ker π for every
  Vir_{3,p'}: `b(p') = (9−2p')/(3(p'−2)) L_{-5}L_{-2}^{p'−2} + L_{-4}L_{-3}L_{-2}^{p'−3}`.
- This equals `(2(N−2)/3) b_N` modulo J, with N = p'−1. Checked for p' = 4, 5, 7, 8, 10, 11.
- Their Ising combination is exactly `w − (64/429)u − (31/286)L_{-1}^3 v` with THM-4671's u. That corresponds to
  16A = 429 and B = −17/48.

*Repair* (THM-4671 status):
> AEH 2020 (§1.6, §2.4) give the lowest piece of ker π for every Vir_{3,p'} (b(p') ≡ (2(N−2)/3) b_N mod J) and use
> the lift u for Ising. New here: all p ≥ 4 (the same b_N for every model with p ≥ 3 and given N), the closed form of
> A and its factorization, and the uniform proof.

Mirror this in note §3.1.

**m2. THM-4671, proof of part 3, case p = 2: false as written.**
- Checked exactly for (2,5), (2,7), (2,9), (2,11), (2,13): `u = B L_{-1}^3 v ≠ 0`.
- What vanishes is `u − B L_{-1}^3 v`. It is the image of the level-3 singular vector
  `(L_{-2}L_{-1} − N L_{-3} − B L_{-1}^3)|2N⟩`. The conclusion ker π = 0 still stands.

*Repair:*
> Since I_{2N+3} = span(L_{-1}^3 v, L_{-3} v) has no nonzero element of length < N, u = B L_{-1}^3 v in V^c. Hence
> grI_{2N+3} = J_{2N+3}.

**m3. THM-4671 "Universality" remark: false as written.**
- Vir_{4,5} and Vir_{2,13} have the same R_V = C[x]/(x^6).
- But `grI_{(15,6)}` is `span(d³f, b_6)` for Vir_{4,5} and only `span(d³f)` for Vir_{2,13}.

*Repair:* "It depends only on N, for every model with p ≥ 3; it is not determined by R_V alone."

**m4. HYP-9293 Drinfeld-Sokolov paragraph, and note §4 "mirrors THM-4671 (a ↔ p)": false as written.**
- DS gives `Vir_{min(a,b), max(a,b)}`, so THM-4671's criterion is `min(a,b) ≥ 3`, not `a ≥ 3`.
- A is symmetric, with factors `(a−1)(a−2)(b−1)(b−2)`, not "(a−2) and (b−1)".
- For the three b = 2 non-free levels (k = −1/2, 1/2, 3/2), the DS images Vir_{2,3}, Vir_{2,5}, Vir_{2,7} are trivial
  or classically free. The existing caveat covers only (3,2).

*Repair:* "The parallel holds exactly when min(a,b) ≥ 3; for b = 2 the Virasoro image is free while L_k(sl2) is not."

**m5. THM-4672 title and note §5: "exceeds the Schur index … from q^7 on".**
- This is shown only at q^7 and q^8 exactly. The referee's mod-p runs reach q^12 and the author's reach q^14.
- Excess at every n ≥ 7 is not proved.

*Repair:* "first exceeds at q^7 (324 vs 319); strict excess verified through q^8 exactly and q^14 mod p".

**m6. THM-4672 typing inconsistency.**
- The statement says item 5 holds "exactly", but the status types it "FINITE-EXACT mod p".
- It is exactly true: Cas² ∉ (I_0)_4 and Cas³ ∈ (I_0)_6 over Q, equivalently dim (R_V)_6 = 13 = dim C[N]_6.

*Repair:* retype item 5 in the status as exact.

**m7. Citation of arXiv:2507.06294v1.**
- The result is Theorem 3.1, stated at the start of §3 and proved in §3.2.3.
- There is no "Step 5". The two sources of null vectors are the enumerated items after eq. (3.44).

*Repair:* fix the references in THM-4672 and note §5.1.

**m8. Note intro: "In a 4d N=2 SCFT, X_V is the Higgs branch (as a scheme)" is wrong.**
- It contradicts §5, which says "conjecturally (X_V)_red".
- It contradicts THM-4672: R_V is non-reduced (Cas ≠ 0 = Cas³), while C²/Z_2 is reduced.

*Repair:* "the reduced associated variety is conjecturally the Higgs branch; X_V can be non-reduced (THM-4672)".

**m9. Note §1.3: "H_2 first appears at 4N+7" fails for N = 2.**
- For N = 2, H_2 first appears at weight 17 (= 4N+9); H_2 is zero at 15 and 16.
- This comes from two independent implementations: exact (`koszul_audit.py`) and two primes (`koszul_check2.py`).
  For N = 3, 4, 5 it does hold (19, 23, 27).
- Also, "kernels sit inside H_1" only shows `dim ker π_w ≤ dim H_1(w)`; no map is given.

*Repair:* "for N = 3, 4, 5 (N = 2: 17)", and state the inequality as an inequality.

**m10. Note §5a: "The boundary models … are classically free" is stated as fact.**
- Only Vir_{2,q} and integrable sl2 are theorems.
- The boundary sl2 and W_3 cases are HYP-9293 and HYP-9297.

*Repair:* "conjecturally (HYP-9293, HYP-9297) classically free; verified in the computed ranges".
