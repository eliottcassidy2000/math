## Method and independence

All code is from scratch in this directory and imports none of the author's modules.

- **`vamod.py`: the engine.** It works mod p on a PBW vacuum module, computed by recursive super-commutation with
  memoisation.
  - The maximal submodule is the radical of the contravariant form, block by block in (weight, charge). The form is
    built from every leftmost creation mode, so no generating set is assumed.
  - gr I comes from echelon forms with columns ordered by Li degree.
  - The arc ideal is built recursively: J_D = I0_D + Σ x·J_{D−x} + ∂J_{D−1}.
  - Minimal generators are counted by graded Nakayama. The code asserts J ⊂ gr I.
- **`aud_algebras.py`: the algebras.** N=2 (NS sector) and W₃, written from the brackets given in the audit request.
  - **Consistency test (`consistency_test.py`).** X(Yv) ∓ Y(Xv) = [X,Y}v on random states: 0 failures in 557 tests for
    N=2, and 0 in 278 for W₃ at c = −114/7 and at c = 4/5.
  - **Power check.** Perturbing β by 10% gives 57 failures in 145 tests, so the test has power. The Gram matrices are
    symmetric.
- **`run_sl3_audit.py`:** affine sl₃ built from matrix units.
- **Arc spaces (`arc_audit.py`, `run_arc_audit.py`, `cusp_block_check.py`, `modulus_locus.py`):** pure commutative
  algebra, bigraded by (weight, Li degree).
- **`schur_audit.py`:** q-series and contour integrals.
