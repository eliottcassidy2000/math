How it works

  1. Decorrelate — G, R−G, B−G. Each channel becomes independent.
  2. Predict — MED prediction with flat-region run detection.
  3. Adaptive encode — Mosaic v4: multiple predictors (MED, Paeth, Sub, Up), color transforms (G-RG-BG, YCoCg-R), palette mode, 4:2:0 chroma, and per-plane backend selection (GR, deflate, brotli, zstd, lzma). Picks smallest.

The hex editor shows actual compressed bytes. Edit any byte, click the image — the decoder runs on your modified data. Toggle Draw mode to paint on the image and watch the compression update live.
