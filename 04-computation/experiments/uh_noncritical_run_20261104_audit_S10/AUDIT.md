## Proof audit (note, section 2), step by step

**Lemma 1 (insertion).** Correct.
1. T - v is strong of order >= 3, so it is Hamiltonian by Camion.
2. On every Hamiltonian cycle Z' of T - v, the cyclic I/O word of v contains both letters, so an I -> O switch exists.
3. The map from (Z', switch) to a Hamiltonian cycle of T is injective: deleting v and closing u -> w recovers both.
4. hc(T) = 1 therefore forces exactly one Z' = C' and exactly one switch.
5. One switch means one I-run and one O-run.
6. Hence v- is the last vertex of the I-run, v+ is the first vertex of the O-run, and C' = C - v + (v- -> v+).

Checks: on every labelled UH tournament of orders 4-7, the cycle of T - v equals C - v + (v- -> v+). On every class of
orders 4-14, hc(T - v) = 1 for every non-critical v.

**(A).**
- N+(v) is the O-run of C', which starts at v+ and has at most n - 2 elements, so it does not reach v-.
- Propagation: since n >= 4, the cycle v -> v++ -> ... -> v- -> v is genuine and avoids exactly v+.
- The dual statement follows by reversal.

Correct.

**Lemma 2.** Correct.

**(B).**
- Moon gives NC non-empty. Propagation gives NC = V and a round tournament with every k(u) >= 2.
- Odd n: the +2 walk is a second Hamiltonian cycle.
- Even n:
  - n = 4 is impossible, since 6 < 8;
  - n(n - 1)/2 > 2n for n >= 6 gives w with k(w) >= 3;
  - with u_0 = w+++, the walk u_0, u_2, ..., u_(n-2), u_(n-1), u_1, ..., u_(n-3), u_0 has steps +2 (n - 2 times), +1
    once (an arc of C) and +3 once (w -> w+++, which needs k(w) >= 3);
  - n = 6 checked by hand.
- The index bookkeeping was verified for every even n in [6, 200].
- On every round tournament with all steps >= 2 at n = 5..13, the constructed walk is a second Hamiltonian cycle. The
  counts of labelled step sequences are 1, 8, 29, 80, 193, 432, 925, 1928, 3953.
- Side observation, FINITE-EXACT and not claimed: the minimum hc over these is 2^(n-4) at n = 5..11.

Correct.

**(C).**
- NC is a proper non-empty subset of V.
- Each maximal run ends at a vertex with a critical successor, which is a sole exit by contraposition of (A).
- Two sole exits are adjacent. Three would close a 3-cycle with no out-arc, which is impossible for n >= 4.
- At most one sole exit is non-critical, so there is exactly one run.
- r >= 2.
- The uniqueness of the non-critical sole entry and exit, and the Shelor parent, follow.

Correct.

**(D).**
- *Internal arcs.* d+(u) >= 2 and d-(u+) >= 2 by Lemma 2. (A) gives u -> u++ and u- -> u+. The two Hamiltonian paths
  u+ ~> u and u -> u++ ~> u- -> u+ make T - e strong.
- *Critical w.*
  - The Hamiltonian path w+ ~> w- of T - w crosses the condensation Q_1 => ... => Q_m in order, each component in one
    block.
  - A second arc from w into Q_1 would give a second Hamiltonian cycle; |Q_1| >= 3, so Q_1 is Hamiltonian.
- *The count* n - r + 1 is right.
- *Top diagonal.* The A_n cut argument is correct.

At every critical vertex of every class of orders 4-16, the component structure was checked directly: w+ is in Q_1,
w- is in Q_m, w -> w+ is the only arc into Q_1, and w- -> w is the only arc out of Q_m.

Correct.

**(E).** Automorphisms are rotations fixing {x} or {x, x+}, so the group is trivial for n >= 4. Correct.

**(F).**
- *Forward map.* x- -> y for n >= 4, so T - x is Hamiltonian, hence uniquely Hamiltonian with y a sole exit.
- *Backward map.* hc(T' + x) = s_y(T') = s_(y+)(T' - y) = hc(T') = 1.
- The sole exits of T' + x are exactly {x, y}, and x is recognisable.
- *Counts.*
  - b(n) = a(n - 1) + 2b(n - 1) for n >= 5, with b(4) = 1.

  - The Fibonacci algebra was checked symbolically and for n <= 60.

Correct (remark 10).

**Lemma 3.** A Hamiltonian cycle of U^p enters y from p and leaves to some z != p. This is a bijection with the
Hamiltonian paths of U ending at p, for |U| >= 2. Correct.

**(G).** Correct.
- *Sole entries are admissible.* Every sole entry of U is admissible (remark 9).
- *Base.* For S_4, e = (1, 1, 2, 1). The five Hamiltonian paths 0123, 1230, 1302, 2301, 3012 were enumerated by hand.
  adm = {1, 0, 3} = {y, y-, y--}.
- *Step.* For T of order m >= 5, with U = T - y of order >= 4 and p_0 = y-:
  - p = y: e = e_(p_0)(U) = 1.
  - p = p_0: y must come first, so e = e_(p_0)(U) = 1.
  - Otherwise e_p(T) = [e_p(U) - hp_U(p_0, p)] + W(p_0, p). The bracket counts the paths with y first. W counts the
    paths A, y, B, where A ends at p_0 and B is non-empty, ends at p, and starts away from p_0, so y beats it.
  - P_p = C_U - (p -> p+), split after p_0, gives W >= 1.
  - If p+ != p_0, P_p is also counted in the bracket, so e_p(T) >= 2.
  - If p = p_0- and p_0 is a sole entry, the path is forced to start p_0, y. Then e_p(T) = e_p(U - p_0) = hc(U) = 1
    by Lemma 3.

    neither admissible in U when |U| >= 4. So e_p(T) >= e_p(U) >= 2.
- *Bijection.* T maps to (T - y, y-) by (C) and (E), with inverse (U, p) maps to U^p.

- *Counts.* u(m + 1) = 2u(m) + b(m) and b(m + 1) = u(m) + b(m) give u(m + 1) = 3u(m) - u(m - 1), hence F(2m - 6).
  Checked.

**(H).** Correct.

- Non-critical vertices v != p of U stay non-critical in T, because y has an in-arc from p and out-arcs into U - v.

- x_U != p, because y_U != x_U (r >= 2), y_U- is critical, and y_U-- is critical when y_U- is a sole entry. So x_U is

- *Recurrence.* N(m + 1, r) = N(m, r) + N(m, r - 1) + N_2(m, r - 2) and N_2(m + 1, r) = N(m, r) + N_2(m, r - 1).
