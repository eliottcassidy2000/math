    (Theoret. Comput. Sci. 1015 (2024) 114776 per the repository's THM-4887; journal data not re-checked here).
    Section 6.5 "Hamiltonian paths in tournaments": "it is not known if (h - 1)/2 is almost complete";
    "Conjecture 6.2. Function h takes all odd values except 7 and 21."; made by MathOverflow user bof and Gordon

    "almost complete" = the value set contains all but finitely many integers. No counting-function bound stated.
