1. Block law (KNOWN: Session 193 concatenation law / THM-4890 (A), in the q-normalisation)
   2 q(A 2^m + B) = 2 q(A) + 2 q(B) + A rev_m(B) + (A mod 2) B_(m-1)        (0 <= B < 2^m).
   Three blocks h = P | x | Z, x of w bits, Z of s bits, c = c_s(Z) = 2^(s+1) - rev_s(Z) in (2^s, 2^(s+1)]:
   x(h) = K(P, Z) + Phi_{P,c}(x),   Phi_{P,c}(x) = c x - P rev_w(x) - 2 q(x) - (P mod 2) x_(w-1) - (c mod 2) x_0.
   Z -> c_s(Z) is a bijection onto the integers of (2^s, 2^(s+1)].

2. Collision equation
   Two words of the same length with the same count: h = P | x | Z, h' = P | x' | Z, where P is the common prefix
   (t' >= 1 bits), Z the common suffix (s >= 0 bits) and the windows x != x' (w bits) differ in the top bit and
   in the bottom bit.  With X = x - x', Xi = rev_w x - rev_w x' (both odd):
       c X - P Xi = gamma,   gamma = 2 (q(x) - q(x')) + (P mod 2)(x_(w-1) - x'_(w-1)) + (c mod 2)(x_0 - x'_0),
       |gamma| <= 2^w.
   For fixed (x, x') and fixed parities of P and c the solutions (P, c) lie on one lattice line with step
   (X, Xi)/g, g = gcd(X, Xi); so
       #{(P, c) in [2^(t'-1), 2^t') x (2^s, 2^(s+1)]} <= 4 (1 + g min(2^(t'-1)/|X|, 2^s/|Xi|))
                                                     <= 4 (1 + 2^max(t'-1, s) g / max(|X|, |Xi|)).

3. Bounded carries
   If |X|, |Xi| >= 2^(w - rho) then a solution forces |s - t'| <= rho + 2.
   Words without a run of more than R equal bits: |X|, |Xi| >= 2^(w-1-R), so |s - t'| <= R + 3.
   With R = ceil(log2 n) + 2 at least a quarter of the n-bit words are run-free.

4. The sum S_w
   S_w = sum over ordered pairs x != x' of w-bit words with X, Xi odd of gcd(X, Xi)/max(|X|, |Xi|)
       = sum over these pairs of 1/M,  M = height of the primitive direction of (X, Xi).
   CLAIM:  S_w <= C w^3 2^(3w/2).     (Numerically S_w is about 6^(w/2) = 2^(1.29 w).)
   Elementary version (no exponential sums):  S_w <= C w (6 sqrt 2)^(w/2) = 2^(1.5425 w).

5. Consequence
   E = number of ordered colliding pairs of run-free n-bit words with a common prefix of length >= t:
       E <= sum over t' >= t, |s - t'| <= R + 3 of [4 * 4^w + 4 * 2^max(t'-1,s) S_w],  w = n - t' - s.
   With S_w <= C w^3 2^(3w/2) and n = 4t:  E <= C n^7 2^n.
   Distinct values >= |W|^2 / (2^(t-1) (|W| + E)) >= c 2^(n-t)/n^7 = c 2^(3n/4)/n^7.
   With S_w <= C w 2^(beta w):  n = t (2 beta - 1)/(beta - 1), exponent beta/(2 beta - 1)
   (beta = 2: 2/3;  beta = 1.5425: 0.7398;  beta = 3/2: 3/4).  The "1" terms cap the method at 3/4.
