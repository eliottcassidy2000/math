B.1  ONE-APEX UNIQUENESS FOR EVERY k  (the finisher left it OPEN beyond k = 24).
Notation of P4: W a nonempty subset of {1..k}, V = sum 2^(p-1), U = sum 2^(k-p) over p in W,
Wd = c1 + sum_{f<e in W} 2^(e-f-1), c1 = #{p : p, p+1 in W}, sigma = [1 in W], eps = [k in W].
Claim.  F(W) := V U - (2^k - 1)(Wd + sigma eps) >= 0, with equality iff W = {1..k}.
Proof.  V U = sum_{p,q in W} 2^(k-1+p-q) = 2^(k-1)|W| + sum_{f<e} (2^(k-1+d) + 2^(k-1-d)), d = e - f, and
2^(k-1+d) - (2^k - 1) 2^(d-1) = 2^(d-1).  Hence
    F(W) = 2^(k-1)|W| + sum_{f<e in W} (2^(k-1-d) + 2^(d-1)) - (2^k - 1)(c1 + sigma eps).                      (*)
Split W into maximal runs R_1 < ... < R_s of lengths r_i.  A run of length r has r - d pairs at distance d and r - 1
adjacent pairs, so its own contribution to (*) is
    S(r) = 2^(k-1) r + sum_{d=1}^{r-1} (r - d)(2^(k-1-d) + 2^(d-1)) - (2^k - 1)(r - 1) = 2^(k-r) + 2^r - 2 >= 1
(sum (r-d) 2^(-d) = r - 2 + 2^(1-r), sum (r-d) 2^(d-1) = 2^r - r - 1).  Pairs in different runs contribute positive
terms X(R_i, R_j).  So F(W) = sum S(r_i) + sum_{i<j} X(R_i, R_j) - (2^k - 1) sigma eps.
 - sigma eps = 0: F >= sum S(r_i) >= 1.
 - sigma eps = 1, s = 1: W = {1..k}, F = S(k) - (2^k - 1) = 0.
 - sigma eps = 1, s >= 2: R_1 = {1..r_1}, R_s = {k-r_s+1..k}, r_1 + r_s <= k - 1, and
   X(R_1, R_s) >= sum_{p in R_1, q in R_s} 2^(q-p-1) = (2^k - 2^(k-r_s))(1 - 2^(-r_1)), so
   F >= S(r_1) + S(r_s) + X(R_1, R_s) - (2^k - 1) >= 2^(r_1) + 2^(r_s) + 2^(k-r_1-r_s) - 3 >= 3.           QED
Consequence (with the criterion of P4): for every k the only word in {a, c} with an exact class of multiplier 2^k
that contains a state with g != 0 is a^k.  Multiplier 1: for W nonempty, lambda = (0, -sigma, V, -Wd),
mu = lambda (N - I) = (0, sigma, V (2^k - 1), -sigma eps - V U), mu N = V 2^k (0, 0, 2^k - 1, -U), so on C(N; 1)
(2^k - 1) B = U g; an actual state has B >= g >= 1 and U <= 2^k - 1, hence W is full, B = g, and then mu s = 0 gives
e = g and H' - H = lambda s = g - e = 0: no exact translation in the one-apex system, for every k.
Checked numerically: (*) and both lower bounds for all W with k <= 16; zeros and minima for k <= 24.
The closed form of P4 itself is KNOWN: Session 198 DIGIT_BLOCK.md, equation (1) (D' = D + U A - E eps_0 - d C(A),
E' = d t, U' = B U - d R), credited in THM-4882 (1).

B.2  THE 17-DIMENSIONAL TWO-MARK REPRESENTATION IS EXACT FOR EVERY BASE  (the lane interpolated it on bases of
order <= 5 and sampled it on orders 6, 7; the finisher's P2 is a sketch).
Trace lemma.  Let (T; z1, z2), |T| >= 2, z1 != z2, and let a word w of the 12 operations add the vertex set X.
Every arc from X to T ends at z1 or z2 (a new vertex beats only current marks; marks that have moved are in X).
Put W_i = the new vertices that beat z_i.  Then T - {z1, z2} => X, z_i -> X - W_i, W_i -> z_i.  Cut a Hamiltonian
path of T u X into maximal T-segments and X-segments.  A T-segment is initial or entered from X, and then starts
at z1 or z2; so there are at most three T-segments: at most one initial one (it comes first) and at most one
entered at each mark.  An X-vertex before a segment entered at z_i must lie in W_i; an X-vertex after a T-segment
that ends at z_i must lie outside W_i; no other condition links X and T.  Hence the number of completions on X
depends only on the DESCRIPTOR of the trace: the kinds of the segments (initial / entered at z1 / entered at z2) in
their order and the end type of each (z1, z2, other).  Counting traces by descriptor (the two orders of two entered
segments have the same trace count) gives 25 numbers t_1(T), ..., t_25(T):
  7:  one segment (initial: end z1, z2, other; entered at z1: end z2, other; entered at z2: end z1, other);
  10: (initial I, entered Z_i), i = 1, 2: (I end z_j; Z_i = {z_i} / end other), (I end other; Z_i = {z_i} / end z_j / other);
  4:  (Z_1, Z_2): Z_i = {z_i} or end other;      4: (I, Z_1, Z_2): the same four end types.
So H(T.w) = sum_k c_w(k) t_k(T) for every base, with coefficients that depend on w only.                      (**)
Finite facts (V7): the trace vectors of the two-marked tournaments of order <= 5 have rank 25 (ranks 2, 9, 21, 25, 25
for orders <= 2, ..., 6); (**) holds numerically for all 157 words of length <= 2 on all 302 bases of order <= 5
(coefficients solved on 25 bases, 277 further bases each); the 61,608 identities x(T.o)_k = (A_o x(T))_k
(17 state words, 12 operations) hold on all 302 bases of order <= 5 by own direct counts.
Conclusion.  Each identity is a linear relation between functionals of the form (**); it holds on a set of bases
whose trace vectors span Q^25, so the coefficient vectors agree and it holds for EVERY two-marked tournament.  By
induction x(T.w) = A_w x(T) for every base and every word.  So the Hankel rank of the two-mark system is exactly 17
and every computation of the lane or the finisher that goes through twomark_rep_5_3.json is exact.
