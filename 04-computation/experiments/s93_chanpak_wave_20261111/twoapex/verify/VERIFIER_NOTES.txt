3. TWO SHORT PROOFS THE FINISHER LISTED AS NOT WRITTEN (verifier's; not audited by a third party)

 (a) Strict negativity of the a-a interaction (FINISHER_PROOFS P7 gives <= 0; the data give <= -2 for n <= 10).
     Claim: for every n >= 2, every b in {0,1}^n and every i < j, the coefficient of a_i a_j in H(., b) is <= -1.
     By P7 it is minus the number of valid configurations of two kinds; it suffices to exhibit one.
     Case b_i = 0.  Arrangement 0 (path [R1] u [R2] v [R3]; conditions on b: b(last R2) = 0, R3 empty or
       b(first R3) = 1), with last(R1) = j, first(R2) = i.  Let m be the least index > j with b_m = 1, if any.
       R1 = [1, j] minus {i};  R2 = {i} and the indices strictly between j and m (all indices > j if m does not
       exist);  R3 = [m, n] (empty if m does not exist).  Then first(R2) = i, last(R2) is i (b_i = 0) or an index
       in (j, m) (b = 0 by minimality of m), and first(R3) = m has b_m = 1.  Valid.
     Case b_i = 1.  Arrangement 1 (path [R1] v [R2] u [R3]; conditions on b: R1 empty or b(last R1) = 0,
       b(first R2) = 1), the pair being {last(R2), first(R3)}.  Put Sp = [1, j) minus {i}.
       (1) If some k > j has b_k = 0: R2 = {i}, R1 = Sp and k, R3 = [j, n] minus {k}.
       (2) Else if Sp is empty: R2 = {i}, R1 empty, R3 = [j, n].
       (3) Else if b(max Sp) = 0: R2 = {i}, R1 = Sp, R3 = [j, n].
       In (1)-(3) last(R2) = i, first(R3) = j, first(R2) = i has b = 1, and R1 is empty or ends at an index with b = 0.
       (4) Else (Sp nonempty, b(max Sp) = 1, b = 1 on (j, n]): take last(R2) = j, first(R3) = i, R3 = {i} and (j, n].
           If b = 1 on all of Sp: R1 empty, R2 = Sp and j (its first element is in Sp, b = 1).
           Otherwise let z be the largest index of Sp with b_z = 0 (z < max Sp): R1 = {k in Sp : k <= z} (last z,
           b_z = 0), R2 = {k in Sp : k > z} and j (its first element is in Sp, above z, so b = 1; its last is j).
     In every case a valid configuration exists.  QED.
     Consequence: H is affine on no 2-cube spanned by two bits of the same apex, for every n (by the converse
     symmetry the same holds for two bits of b).  This does NOT exclude mixed cubes: e1 lists thousands of affine
     2-cubes with one a-flip and one b-flip, and the affine 3-cubes with increments (2, 2, 10).

 (b) H(3^p 0^q) exactly, and the constant 4.
     Let A = {s_1..s_p} (letters 3: u, v -> A) and B = {s_(p+1)..s_n} (letters 0: B -> u, v).  For both
     arrangements the conditions of P1 read: R1 empty or R1 meets B; R2 empty or (R2 meets A and R2 meets B);
     R3 empty or R3 meets A; and R2 nonempty for arrangement 1.  Hence
        H(3^p 0^q) = sum over the pairs (set of colours used on A, set of colours used on B) satisfying these
                     conditions of  w * surj(p, |colours on A|) * surj(q, |colours on B|),   w = 2 if colour 2 is
                     used, 1 otherwise  (surj(m, k) = number of surjections of an m-set onto a k-set).
     Checked against the transfer for all p, q <= 8 (v1_core.out, F2).  The bad events per arrangement are
     E1: R1 nonempty inside A (at most 3^p 2^q colourings), E2: R2 nonempty inside B (2^p 3^q), E3: R2 nonempty
     inside A (3^p 2^q), E4: R3 nonempty inside B (2^p 3^q); the union bound gives
        2 * 3^n - 4 (3^p 2^q + 2^p 3^q) - 2^n <= H(3^p 0^q) <= 2 * 3^n      (all p, q),
     and each |E_i| is its bound minus 2^n while the pairwise intersections have at most 2^n, 3^p, 2^n, 0, 3^q, 2^n
     elements, so by Bonferroni, for p = q,  (1 - H/(2 * 3^n)) / (2/3)^p = 4 + O((2/3)^p + (1/2)^p).  QED.
