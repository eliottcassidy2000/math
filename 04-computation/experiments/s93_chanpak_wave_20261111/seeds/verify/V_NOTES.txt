S93 Chan-Pak wave, lane "seeds": receipts of the adversarial verifier (2026-11-11, after the finisher)
=================================================================================================
Nothing here changes a status upward.  The Chan-Pak conjecture stays OPEN.
All programs of this folder are the verifier's own (C kernel vk_c_source.txt, written from the definitions of
THM-5130; two python scripts).  No code of the lane or of the finisher is imported.  The intermediate tables
(*.bin) and the executable were removed after the runs; to rebuild:
    gcc -O2 -fopenmp -x c vk_c_source.txt -o vk
    vk selftest | neutral n ../cls_n.txt | example | small n ../cls_n.txt minv_small_n.bin | extcount ../cls_9.txt 9
    vk mass n ../cls_n.txt | part P 32 ../cls_9.txt minv_part_P_32.bin | lowH 224 450 ../cls_9.txt minv_lowH_224.bin
    vk certs ../certs_plus_full.txt 1 | certs ../certs_minus_full.txt -1 | oneapex 14 | towers K
    vk twoapex n 0 0 two_slopes_n.bin   (n = 10 in two halves: 0 524288 two_slopes_10a.bin, 524288 1048576 two_slopes_10b.bin)
    python v_tables.py ; python v_small.py ; python v_twoapex_slopes.py
Every run took less than 2.1 minutes on 4 threads.
