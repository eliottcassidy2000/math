0. Setting (THM-5126, THM-5130)
-------------------------------
H(T) = number of Hamiltonian paths of a tournament T, S = set of its values.  For a tournament B and a vertex set O:
  Q_B(e, f) = number of ordered pairs (P1, P2) of disjoint nonempty paths covering B, P1 ending at e, P2 starting at f;
  W_ef = Q_B(e, f) + Q_B(f, e);   W_B(O) = sum of W_ef over the pairs {e, f} of O;
  U_B(o) = number of ordered pairs (P1, P2) covering B with P2 starting at o, P1 possibly empty;  U_B(O) = sum over O;
  r = H(B) - W_B(O) (offset),  M = U_B(O) (slope),  E = End_B(O),  h = H(B).
Closing law (KNOWN, THM-5126 (A), THM-5130): the tournament T_t(B, O) = (B => TT_t => v, v -> O, B - O -> v) has
H = r + 2^t M for t >= 1.  Seed: r = 1.  Anti-seed: r = -1.  Sink rule (KNOWN): adding a sink to B gives (r, 2M, h, 0).
Gadget (X, P), constants H_X, Pi = Pi_2(X), w = W_X(P), w3, sigma = Start_X(P), u = U_X(P), eps = End_X(P),
nu = V_X(P), u3, r_X = H_X - w, kappa_X = Pi - 2w - 2 w3; gadget law (KNOWN, THM-5130 (A)):
  r+ = r_X r + kappa_X M,  M+ = u (r + h) + (4u - 2 sigma + 2 u3) M - sigma E,  h+ = H_X r + Pi M,
  E+ = eps (r - h) + nu M      for the pair (B => X => v with v -> O, P).
All of this was recounted here: a_verify.out (V1-V6: literal enumeration of vertex orders against the subset
recursions; closing law on 3,294 + 275,072 cases), c_towers (T0: 1,042 towers), c_neutral_verify (84 closings).

1. Seeds with |O| = 2 are balanced arcs                                              [PROVED; in substance KNOWN]
-----------------------------------------------------------------------------------------------------------------
Theorem 1.  Let e -> f in B, let B' be B with this arc reversed, and for an arc x -> y of a tournament T let
w_T(x -> y) be the number of Hamiltonian paths of T through that arc.  Then
      Q_B(e, f) = w_B(e -> f),      Q_B(f, e) = w_B'(f -> e),      r(B, {e, f}) = H(B') - 2 w_B'(f -> e).
Hence (B, {e, f}) is a seed iff the arc f -> e of B' lies on exactly (H(B') - 1)/2 Hamiltonian paths of B', and an
anti-seed iff it lies on (H(B') + 1)/2 of them.
Proof.  A cover (P1, P2) with P1 ending at e and P2 starting at f is the Hamiltonian path P1 P2 of B cut at the arc
e -> f, and conversely.  A cover with P1 ending at f and P2 starting at e uses no arc between e and f inside P1 or P2
(they are the last and the first vertex), so it is a cover of B' as well, where it is the Hamiltonian path P1 P2 cut at
f -> e.  Let A be the number of Hamiltonian paths of B in which e, f are not consecutive; these are also the
Hamiltonian paths of B' in which they are not consecutive.  Then H(B) = A + w_B(e -> f), H(B') = A + w_B'(f -> e), and
r = H(B) - Q_B(e, f) - Q_B(f, e) = A - w_B'(f -> e) = H(B') - 2 w_B'(f -> e).  QED
Status: THM-5130 (F4) has the equivalent statement "the pair is unit iff the number of Hamiltonian paths of B avoiding
the arc ef is one more than Q_B(f, e)".  Checked: a_verify.out V3 (80,880 arcs, literal counts).
Remark (KNOWN reading, THM-5126 (B1)).  A seed is the same thing as a tournament K = T_1(B, O) with a vertex x (the
tail vertex) of out-degree one that is a doubling vertex: H(K) = 1 + 2M and c_2(K, x) = M.

2. Transitive tails: all vertex sets P                                                     [PROVED, every order]
-----------------------------------------------------------------------------------------------------------------
Theorem 2.  Let X = TT_a (vertices 1 -> 2 -> ... -> a) and P a subset of its vertices.  For a pair i < j of P put
d = j - i.  Then
   (a)  W_X(P) = sum over the pairs of P of (2^(d-1) + [d = 1]),
        kappa_X(P) = 2^a (1 - sum over the pairs of P of phi(d)),   phi(d) = (1 + 3^(d-1)) / 2^d.
   (b)  phi(1) = phi(2) = 1 and phi(d) > 1 for d >= 3.  Hence kappa_X(P) > 0 iff |P| <= 1, and kappa_X(P) = 0 iff P is
        one pair at distance 1 or 2.  In particular the gadgets (X, P) with H(X) = 1 and kappa_X(P) = 0 are exactly
        the transitive pairs at distance 1 or 2: the last sentence of HYP-9662 (D) is true at every order.
   (c)  (No other transport through a transitive tail.)  Let (B, O) be a seed or an anti-seed and P any vertex set of
        X = TT_a.  If the pair (B => X => v with v -> O, P) has offset +1 or -1, then P is a pair at distance 1 or 2
        (and then the offset is -r for every base).
Proof.  (a) w and w3 are sums over the ordered pairs e != f of P of quantities that depend on (X, e, f) only; these
were computed in THM-5130 (B) (in TT_a a vertex set carries one path, so covers are ordered set partitions): for the
pair {i, j}: Q(i, j) = [d = 1], Q(j, i) = 2^(d-1), and with a third nonempty block 2^(a-d-1) - [d = 1] and
2^(a-d-1) 3^(d-1) - 2^(d-1).  So the pair contributes 2^(d-1) + [d = 1] to w and 2^(a-d-1)(1 + 3^(d-1)) - [d = 1]
- 2^(d-1) to w3, that is 2^(a-d)(1 + 3^(d-1)) = 2^a phi(d) to 2w + 2 w3, and Pi_2(TT_a) = 2^a.
(b) phi(d+1)/phi(d) = (1 + 3^d) / (2 + 2 * 3^(d-1)) > 1 iff 3^(d-1) > 1 iff d >= 2.  With k pairs the sum is >= k, with
equality iff all distances are <= 2; it equals 1 iff k = 1 and d <= 2.  (Three vertices give three pairs.)
(c) Write r = +-1 for the offset of (B, O) and M >= 1 for its slope; r+ = r_X r + kappa_X M with r_X = 1 - W_X(P).
An anti-seed has |O| >= 2 (W = H + 1 > 0), so M >= 2 H(B) >= 2 by U_B(o) >= H(B) (THM-5130 (F1)); M = 2 would force
B transitive and U(o) = 1 for two vertices o, but U(j) = 2^(n-j) in TT_n; so M >= 3 for an anti-seed.
 |P| <= 1: w = w3 = 0 for |P| = 0 and for |P| = 1, so r_X = 1, kappa_X = 2^a and r+ = r + 2^a M >= -1 + 2 * 3 = 5 if
   r = -1, and >= 3 if r = 1.
 |P| = 2, d <= 2: r_X = -1, kappa_X = 0, r+ = -r.
 |P| = 2, d >= 3: r_X = 1 - 2^(d-1), kappa_X = -2^(a-d) psi(d) with psi(d) = 3^(d-1) + 1 - 2^d; psi(3) = 2, and
   psi(d) > 2^(d-1) for d >= 4, because (3/2)^(d-1) > 3 there.  If r = 1 then r+ <= -3 - 2M < -1.  If r = -1 then
   r+ = 2^(d-1) - 1 - 2^(a-d) psi(d) M, and r+ = +1 or -1 needs 2^(a-d) psi(d) M = 2^(d-1) - 2 or 2^(d-1).  For d = 3
   this reads 2^(a-3) M = 1 or 2, impossible because M >= 3.  For d >= 4 the left side is >= 3 psi(d) > 2^(d-1).
 |P| >= 3: at least three pairs, so sum phi >= 3 and |kappa_X| = 2^a (sum phi - 1) >= (2/3) 2^a sum phi
   >= (2/3) W_X(P), because 2^a phi(d) = 2^(a-d)(1 + 3^(d-1)) >= 2^(d-1) + [d = 1] (a >= d).  Also W_X(P) >= 6.  If
   r = 1 then r+ = 1 - W_X(P) - |kappa_X| M < -1.  If r = -1 then r+ = W_X(P) - 1 - |kappa_X| M
   <= W_X(P) - 1 - 2 W_X(P) < -1 (M >= 3).
So |r+| = 1 only for a pair at distance 1 or 2.  QED

2'. An identity for kappa of a pair                                                                     [PROVED]
-----------------------------------------------------------------------------------------------------------------
Let e -> f in X, X' = X with this arc reversed, and Pi_2(X - ef) = number of covers (A, B) of X by two possibly empty
paths in which e and f are not consecutive.  Then  kappa_X({e, f}) = 2 Pi_2(X - ef) - Pi_2(X').
Proof.  Pi_2(X) - Pi_2(X - ef) counts the covers (A, B) in which e is followed by f; cutting there gives a triple
(D1, D2, D3) with D1 ending at e, D2 starting at f and D3 possibly empty, in two ways (D3 = B or D3 = A):
2 Q(e, f) + 2 Q3(e, f).  In the same way Pi_2(X') - Pi_2(X - ef) = 2 Q(f, e) + 2 Q3(f, e).  Since
kappa = Pi_2(X) - 2 (Q(e,f) + Q(f,e)) - 2 (Q3(e,f) + Q3(f,e)), the claim follows.  QED     (a_verify.out V6.)
So a pair is neutral iff exactly half of the covers of X' by two possibly empty paths use the arc f -> e.

Lemma G (padding).                                                                                      [PROVED]
Let (X, P) be a gadget and X' = TT_(i-1) => X => TT_m (i >= 1, m >= 0), with the same P.  Then
   H' = H,  Pi' = 2^(i-1+m) Pi,  W' = W,  r_X' = r_X,  kappa' = 2^(i-1+m) kappa,
   u' = 2^m u,  sigma' = [i = 1] sigma,  eps' = [m = 0] eps,  nu' = 2^(i-1) nu,
   u3' = (2u - sigma + u3) 2^(i-1) 3^m - 2^(m+1) u + [i = 1] sigma,
   4u' - 2 sigma' + 2 u3' = c 2^(i-1) 3^m   with  c = 2 (2u - sigma + u3).
Proof.  Let S = TT_(i-1), T = TT_m.  A path of X' is a run of S, then a possibly empty path of X, then a run of T, and
every such concatenation is a path.  So a tuple of disjoint paths covering X' is a tuple of possibly empty paths
covering X together with a distribution of the vertices of S and of T over the paths; a path that starts in X gets no
vertex of S, a path that ends in X gets no vertex of T.
 Pi': 2^(i-1) 2^m Pi.   Q'(e, f) = Q(e, f) (S goes to D1, T to D2), so W' = W, H' = H, r_X' = r_X.
 Q3'(e, f): S to D1 or D3, T to D2 or D3; if the X-part of D3 is nonempty: 2^(i-1+m) Q3; if it is empty, D3 needs a
 vertex of S or T: (2^(i-1+m) - 1) Q.  So W3' = 2^(i-1+m) (W3 + W) - W and kappa' = 2^(i-1+m)(Pi - 2W - 2W3).
 u': S to P1, T free: 2^m u.   sigma', eps': a Hamiltonian path starting (ending) in X exists only if S (T) is empty.
 nu' = 2^(i-1) nu by symmetry.
 u3': triples (D, D', D'') of nonempty paths, D starting at o in P.  X-parts (E, E', E'') with E', E'' possibly empty:
 Start(o) + 2 (U(o) - Start(o)) + u3(o) of them; S to D' or D'': 2^(i-1); T anywhere: 3^m.  Remove D' empty
 (S to D'', T to D or D'', X-parts counted by U(o)): 2^m U(o); the same for D''; add back both empty (i = 1, T to D,
 X-parts counted by Start(o)).  Sum over o in P.  The last line is arithmetic.  QED
(For X = one vertex this is THM-5130 (H1); for a transitive pair, THM-5130 (B).  Checked on the 28 padded gadgets of
order 9: c_gen_towers_26.out, line G1.)
Corollary (level map of a padded unit neutral gadget, rho = r_X = +-1, kappa = 0):
   r+ = rho r,   h+ = H r + 2^(i-1+m) Pi M,   M+ = 2^m u (r + h) + c 2^(i-1) 3^m M - [i = 1] sigma E,
   E+ = [m = 0] eps (r - h) + 2^(i-1) nu M.
For the transitive pairs (H, Pi, u, sigma, eps, nu, c) = (1, 2^(delta+1), alpha, 1, 1, alpha, 2 gamma),
(alpha, gamma) = (3, 5), (5, 13): this is THM-5130 (1).

4. Towers are thin                                                                                      [PROVED]
-----------------------------------------------------------------------------------------------------------------
Let G be a finite set of unit neutral gadgets, each with constants (rho, H, Pi, u, sigma, c, eps, nu).  A G-tower is
obtained from a transitive base ((TT_n, {p}), state (1, 2^g, 1, [g = 0]), g = n - p; or a transitive pair, state
(-1, alpha 2^m, 1, [m = 0])) by finitely many levels (g, i, m), g in G, i >= 1, m >= 0 (the padded gadget of Lemma G).
For G = {the two transitive pairs} these are the towers of THM-5130 (C).  Put
   lambda(g, i, m) = c_g 2^(i-1) 3^m - [i = 1] sigma_g,      rho_G(s) = sum over (g, i, m) of lambda(g, i, m)^(-s).
Theorem 4.  (a) Every level multiplies the slope by at least lambda: M+ >= lambda(g, i, m) M.
(b) For every s > 0 with rho_G(s) < 1 there is C with: the number of G-tower states with slope <= X, hence the number
of distinct slopes of G-towers that are <= X, hence the number of integers N <= X of the form r + 2^t M (t >= 1) with
(r, M) offset and slope of a G-tower, is at most C X^s.
(c) For the towers of THM-5130: rho(s) = sum over delta in {1, 2} of [ sum_{m >= 0} (2 gamma 3^m - 1)^(-s)
+ gamma^(-s) 4^(-s) / ((1 - 2^(-s))(1 - 3^(-s))) ], gamma = 5, 13, and rho(s) = 1 at sigma_0 = 0.788507...; so the
number of tower slopes below X, and the number of path counts below X that lie on a tower ray, is O(X^s) for every
s > 0.788507.  In particular the towers have density zero, at every depth together.
With the unit neutral gadgets of order 8: sigma_0 = 0.792831; of orders 8 and 9: sigma_0 = 0.797044.
Proof.  (a) r + h >= 0 because h >= 1 and r = +-1; E = End_B(O) <= H(B) <= U_B(o) for every o (THM-5130 (F1)), so
E <= M.  Insert into the level map: M+ >= c 2^(i-1) 3^m M - [i = 1] sigma M.  Also lambda >= c - sigma >= u >= 2:
c - sigma = 4u - 3 sigma + 2 u3, sigma <= u, and u = U_X(P) >= |P| H(X) >= 2.
(b) Let N(Y) be the number of finite sequences of levels with product of the lambda at most Y.  If rho_G(s) < 1 then
N(Y) <= sum over sequences of (Y / prod lambda)^s = Y^s sum_k rho_G(s)^k = Y^s / (1 - rho_G(s)).  A tower state is
determined by its base state and its sequence of levels, and by (a) its slope is at least M_0 prod lambda.  So the
number of states with slope <= X is at most sum over base states of N(X / M_0) <= X^s (1 - rho_G(s))^(-1)
sum over base states of M_0^(-s), and the base slopes are 2^g (g >= 0), 3 * 2^m, 5 * 2^m (m >= 0): a convergent sum.
For the values: N - r = 2^t M <= X + 1, so their number is at most sum_{t >= 1} C ((X + 1)/2^t)^s.
(c) lambda = 2 gamma 3^m - 1 for i = 1 and gamma 2^i 3^m for i >= 2; sum the geometric series.  Numerical root:
c_towers_30.out (T1), c_gen_towers_26.out (G2).  QED

6. One-apex bases                                                                                        [mixed]
-----------------------------------------------------------------------------------------------------------------
B(y): spine z_1 -> ... -> z_n (z_i -> z_j for i < j), apex a, a -> z_i iff y_i = 1.  Write
I(y) = sum over i < k with y_i = 1, y_k = 0 of 2^(k-i-1),  J(y) = #{k : y_k = 0, y_(k+1) = 1},
val(y) = sum_i y_i 2^(n-i).
Theorem 6.  (a) H(B(y)) = [y_1 = 1] + [y_n = 0] + J(y) + I(y).
(b) U_B(a) = 1 + val(y): the slope of the apex is an affine function of the word.
(c) W_{a z_j} = p_j + q_j + [j = n or y_(j+1) = 1] + [j = 1 or y_(j-1) = 0], where
    p_j = sum_{i < j} y_i 2^(j-1-i),  q_j = sum_{k > j} (1 - y_k) 2^(k-j-1).
(d) Let B(y) be strong (y_1 = 1, y_n = 0, n >= 2).  The pair (B(y), {a, z_j}) is a seed exactly in the following
    cases: y = 1 0^(n-1), j = 1;  y = 1^(n-1) 0, j = n;  y = 110, j = 1;  y = 100, j = 3.  The slopes of the two
    families are 3 * 2^(n-1); those of the two exceptional pairs are 16 and 11.
Proof.  A Hamiltonian path is S1 a S2 with S1, S2 increasing runs partitioning the spine, last(S1) -> a (bit 0) and
a -> first(S2) (bit 1).  (a) S1 empty: [y_1 = 1].  S2 empty: [y_n = 0].  Otherwise let z_k = max S1 (y_k = 0) and
z_i = min S2 (y_i = 1); all vertices above k are in S2 and all below i in S1.  If i > k then i = k + 1 and the
partition is determined: J(y).  If i < k the k - i - 1 vertices between are free: 2^(k-i-1).
(b) P2 = a S2 with S2 empty (1 cover: P1 = the spine) or min S2 = z_i with y_i = 1; the vertices below i are in P1 and
those above are free: 2^(n-i).
(c) Q(z_j, a): P1 is a run with maximum z_j, P2 = a S2, S2 contains everything above j.  If min S2 = z_i with i < j:
y_i = 1, vertices between free: 2^(j-1-i), total p_j.  If S2 is exactly the set above j: one cover iff j = n or
y_(j+1) = 1.  Q(a, z_j): P1 = S1 a, P2 a run with minimum z_j; S1 contains everything below j.  If max S1 = z_k,
k > j: y_k = 0 and 2^(k-j-1) choices, total q_j.  If S1 is exactly the set below j: one cover iff j = 1 or
y_(j-1) = 0.
(d) Let Y = y_1 .. y_(j-1), Z = y_(j+1) .. y_n, p = p_j, q = q_j.  Splitting the pairs of I(y):
I(y) = I(Y) + I(Z) + 2pq + (q if y_j = 1, p if y_j = 0).  With beta = 2 + J(y) - [j = n or y_(j+1) = 1]
- [j = 1 or y_(j-1) = 0] >= J(y) >= 0:
     r = beta + I(Y) + I(Z) + p (2q - 1)  if y_j = 1,        r = beta + I(Y) + I(Z) + q (2p - 1)  if y_j = 0.
 y_j = 1 (so j < n and q >= 1, because y_n = 0).  If j = 1: p = 0, beta = 1 + J - [y_2 = 1], r = 1 iff
 J + I(Z) = [y_2 = 1].  For y_2 = 0 this means Z = 0^(n-1) (no inversion, no 01 junction, last letter 0).  For
 y_2 = 1, Z begins with 1 and ends with 0, so I(Z) >= 2^(n-3) (n >= 3), and I(Z) + J = 1 forces n = 3, y = 110.
 If j >= 2: p >= 2^(j-2) >= 1, so p (2q - 1) >= 1 and r = 1 forces beta = 0, p = q = 1, hence j = 2, y_3 = 0 and
 y_k = 1 for k > 3; with y_n = 0 this is y = 110, j = 2, where beta = 2.  No solution.
 y_j = 0 (so j > 1 and p >= 1).  If j = n: q = 0, beta = 1 + J - [y_(n-1) = 0], r = 1 iff J + I(Y) = [y_(n-1) = 0].
 For y_(n-1) = 1: Y has no inversion and begins with 1, so Y = 1^(n-1).  For y_(n-1) = 0: Y begins with 1 and ends
 with 0, I(Y) >= 2^(n-3), so n = 3, y = 100.  If j < n: q >= 1, q (2p - 1) >= 1, so beta = 0 and p = q = 1: j = 2,
 n = 3, y = 100, where beta = 2.  No solution.
 Slopes: for y = 1 0^(n-1), U(a) = 1 + 2^(n-1) by (b); U(z_1) = 2^(n-1) (P2 = z_1 S, P1 the rest with a last) +
 2^(n-1) - 1 (P2 = z_1 S' a, S' nonempty); total 3 * 2^(n-1).  For y = 1^(n-1) 0, U(a) = 1 + 2^n - 2 by (b);
 U(z_n) = 1 (P2 = z_n, P1 = a z_1 ... z_(n-1)) + 2^(n-1) (P2 = z_n a S, S any run of z_1 .. z_(n-1)); total
 3 * 2^(n-1).  The two exceptional slopes are read from the census.  QED
