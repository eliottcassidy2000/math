# seam_gadget_density_20261104 (kind-pasteur-2026-11-04-S11, HYP-9470)

Programs for the thickness of the seam-gadget semigroup (SEAM.md three-coordinate transfer).

- `gadget_matrices.c`: all tournaments of order N up to isomorphism, generated by vertex extension of the order N-1
  classes with a score-pruned minimum-mask canonical form. For every class and every port pair (entry u, exit z) it
  computes the SEAM matrix M from three spanning prefixes, with responses (1,1,1), (1,0,2) and (3,1,3), by subset
  dynamic programming on the seamed tournament.
  - Build: `gcc -O2 -o gadget_matrices gadget_matrices.c`.
  - Run: `./gadget_matrices N | sort -u > matsN.txt`.
  - Class counts 1, 1, 2, 4, 12, 56, 456 at N = 1-7. Distinct matrices 1, 4, 12, 44, 220, 1660, 20500.
  - Orders <= 6 were cross-checked against an independent labelled enumeration (all labelled tournaments, deduped by
    matrix) and orders <= 5 against SEAM's own `seam_transfer.py matrix()`.
- `density.py`: D_k(t) on the plane S = 0. Run: `python3 density.py K mats1.txt ... matsK.txt`.
- `seam_bfs.c`: breadth-first search of SEAM states (H, S, R) under a list of matrices.
  - Seeds: (1,1,1), (1,0,2), (3,1,3), (1,0,4), (1,0,8), (1,0,16).
  - Expands states with H <= X and R <= X, and records every odd H <= X attained.
  - Writes the states with S = 0 to `pstates.txt`.
  - Build: `gcc -O2 -o seam_bfs seam_bfs.c`. Run: `./seam_bfs X allmats.txt` (the matrices of all orders concatenated).
- `fill.py`: fill fractions of the two pre-registered bands from `pstates.txt`.
