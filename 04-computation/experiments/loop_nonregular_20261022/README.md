# Loop expansion beyond regular tournaments (opus-2026-10-22-S54)

This directory supports [HYP-9369](../../../05-knowledge/hypotheses/HYP-9369-almost-regular-loop-predictor-at-scale-complete-n10-census-and-the-joint-remainder.md), [HYP-9370](../../../05-knowledge/hypotheses/HYP-9370-zero-free-disc-of-the-forest-polynomial-for-almost-regular-tournaments.md) and [THM-4761](../../../01-canon/theorems/THM-4761-random-tournaments-the-forest-identity-is-the-walsh-chaos-decomposition-of-kappa.md).

The weight-graded predictor itself is Session30's ([packet](../../../05-knowledge/results/session30_nonregular_loops_20261022/SYNTHESIS.md)). `crosscheck_s30.py` and `budget_cw.py` import it unchanged.

## Data

All files are produced by `ar_tool.c`. Build with `gcc -O2 -o ar_tool ar_tool.c`. Binaries are not committed. Every line is `code H [aut]`, where `code` is the upper-triangle bit string with `1` at `(i, j)`, `i < j`, iff `i → j`.

| file | content |
|---|---|
| `ar{4,6,8,10}_classes.txt` | all almost-regular classes (1, 5, 85, 13,333) with `|Aut|` (`ar_tool classes n target seed`) |
| `ar{12,14,16,20}_samples.txt` | 3000, 3000, 1500, 300 samples from the 3-cycle-reversal chain (`ar_tool sample n count seed`) |
| `rand{12,14}_samples.txt` | uniformly random tournaments (`ar_tool random n count seed`) |

The regular completions `reg*_completions.txt` are regenerated by `complete_regular.py` (not committed). Completeness of the class lists: `count_regular.py` computes the labelled regular `(n+1)`-tournament counts 24, 2640, 3,230,080 and 48,251,508,480. These equal the labelled masses `Σ n!/|Aut|`.
