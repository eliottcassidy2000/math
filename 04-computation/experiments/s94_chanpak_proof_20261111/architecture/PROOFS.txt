P1.  Multiplicative reduction (KNOWN: THM-4094 Theorem 6.1, lanes p and 7p with the carry atoms 49, 63, 343;
     restated because the session context omitted 343).

Statement.  Assume (i) S is closed under multiplication (order join: H(T1 => T2) = H(T1) H(T2)), (ii) 1 in S,
(iii) 7, 21 not in S (THM-1370).  Then  S = {odd N >= 1} - {7, 21}  if and only if S contains
    (a) every odd prime p != 7,   (b) 49, 63 and 343,   (c) 7p for every prime p other than 3 and 7.
None of 49, 63, 343 can be dropped; in particular 343 = 7^3 is needed.

Proof.  "Only if" is trivial.  "If": let N be odd, N not in {7, 21}, N = 7^a m with 7 not dividing m.
  a = 0:           N is a product of primes != 7 (the empty product is 1).
  a even, >= 2:    N = 49^(a/2) m.
  a odd, >= 3:     N = 343 * 49^((a-3)/2) * m.
  a = 1:           m is not 1 or 3.  If a prime p != 3 divides m:  N = (7p)(m/p), and m/p is a product of primes != 7.
                   Otherwise m = 3^b with b >= 2:  N = 63 * 3^(b-2).
In each case N is a product of elements of S.  Necessity of 343: its only factorisations into integers > 1 are
343, 7 * 49, 7 * 7 * 7, and 7 is not in S; so 343 in S cannot come from (a), (c), 49, 63.  Same for 49 (= 7 * 7) and
63 (= 7 * 9 = 3 * 21 = 3 * 3 * 7).  QED

Exact check (reduction_check.py / .out): for all odd N <= 2,000,000 the monoid generated by (a), (b), (c) misses
exactly 7 and 21; without 343 it misses exactly 7, 21, 343, 1029, 16807, 50421, 823543 (= 7^a and 3 * 7^a, a odd >= 3).

Corollary (with THM-4885 (D): every odd N <= 2^35 other than 7, 21 is in S).  The conjecture is equivalent to:
every prime p > 2^35 is in S, and 7p is in S for every prime p > 2^35 / 7.

P2.  The shape of a proof by "finite computation + written induction" (certificate lemma).  Elementary.

Setting.  d >= 1; a start state x_0 in Z^d; integer matrices G_1, ..., G_m in M_d(Z); a linear readout lam: Z^d -> Z.
Assume the system is PHYSICAL: x_0 is the state of a marked tournament, and for every marked tournament with state x
and every b there is a marked tournament with state G_b x, and lam(state) is its number of Hamiltonian paths (or a
value r + 2^t M of a closing).  Examples in canon, valid for ALL states with no side condition:
   - port chains, d = 3, state (h, E, O), nonnegative block matrices (THM-5070 (1));
   - pairs (B, O), d = 4, state (r, M, h, E), gadget matrices G(X, P) (THM-5130 (A)), readouts h and r + 2^t M;
   - two-apex words, d = 17 (seam rank), four letter matrices (THM-4878 / S93 lane twoapex TA-03).
Orbit: Orb = {G_w x_0 : w a word}.  Every lam(x), x in Orb, is in S.

Certificate.  A set C of lattice points, a function nu: C -> {0, 1, 2, ...} and numbers R, N_0 such that
   (i)   [return]  for every x in C with nu(x) > R there are b and x' in C with G_b x' = x and nu(x') < nu(x);
   (ii)  [base]    every x in C with nu(x) <= R lies in Orb;
   (iii) [readout] every odd N >= N_0 equals lam(x) for some x in C.
Lemma.  If a certificate exists then every odd N >= N_0 is in S.
Proof.  By induction on nu(x), every x in C lies in Orb: for nu(x) <= R this is (ii); for nu(x) > R, (i) gives
x = G_b x' with x' in C and nu(x') < nu(x), x' in Orb by induction, hence x in Orb.  Then (iii).  QED

Finite checkability (polyhedral certificates).  Let K be a closed rational polyhedral cone with nonempty interior,
nu a linear form with positive integer values on the nonzero lattice points of K, q >= 1, A a set of residue classes
modulo q, R_0 >= 1, and C = {x in K ∩ Z^d : x mod q in A, nu(x) >= R_0}.  Suppose every G_b is invertible over Q,
G_b K ⊆ K, and nu(y) < nu(G_b y) <= L nu(y) for y in K - {0}.  Put Q = q * lcm_b |det G_b|.  For a class c modulo Q
with c mod q in A let B(c) = {b : G_b^(-1) c is integral and its class modulo q lies in A}; this depends only on c,
because for x = c (mod Q) the vector G_b^(-1) x - G_b^(-1) c = adj(G_b)(x - c)/det G_b lies in q Z^d.
Claim.  (i) holds for some R if and only if  K ⊆ union over b in B(c) of G_b(K)  for every such class c; and then
R = L R_0 works.
Proof.  Sufficiency: let x in C with nu(x) > L R_0 and class c.  Then x in G_b K for some b in B(c), so
x' = G_b^(-1) x lies in K, is integral with class in A, and R_0 < nu(x)/L <= nu(x') < nu(x): x' in C.  Necessity: if
some point of K is outside the closed set V = union of the G_b(K), b in B(c), then K - V contains an open cone (K is
convex with nonempty interior and V is a closed cone), which contains lattice points x = c (mod Q) with nu(x)
arbitrarily large; such an x has no preimage in C under any b (b must lie in B(c) for integrality and class, and
then x would lie in G_b K), so (i) fails for every R.  QED
Each cone inclusion is decidable by linear programming; (ii) is a finite enumeration (the lattice points of C with
nu <= L R_0 must be orbit states) and (iii) a finite check on the linear readout.  So a polyhedral certificate is a
finite object and the proof it gives is the induction above.  No certificate of any kind is known; P3 shows why none
exists with the objects enumerated so far.

P3.  Necessary conditions for a polyhedral certificate.  Elementary counting.

Let C = K ∩ (classes A mod q) as in P2, with density delta > 0 of the classes, D(T) = {x in K : nu(x) <= T}.
(a) Orbit exponent.  #(Orb ∩ D(T)) >= #(C ∩ D(T)) - O(1) = delta vol(D(1)) T^d (1 + o(1)).  So the number of distinct
    orbit states of height at most T must grow like T^d, the full dimension.
    Proof: C is contained in Orb by the Lemma of P2, and lattice points of a cone section are counted by volume.  QED
(b) Volume inequality.  sum over b of  vol(G_b K ∩ D(1)) / (|det G_b| vol(D(1)))  >= 1; in particular
    sum_b 1/|det G_b| >= 1.
    Proof: by (i), every x in C with R < nu(x) <= T is G_b x' with x' in C, so
    #(C ∩ D(T)) - O(1) <= sum_b #{x' in C : nu(G_b x') <= T} = sum_b delta vol{y in K : nu(G_b y) <= 1} T^d (1 + o(1)),
    and vol{y in K : nu(G_b y) <= 1} = vol(G_b K ∩ D(1)) / |det G_b| <= vol(D(1)) / |det G_b| since G_b K ⊆ K.
    Divide by delta vol(D(1)) T^d.  QED
Remarks (data, not proofs).
  - The weak form sum 1/|det| >= 1 is NOT the obstruction for port chains: over the invertible block matrices of
    order <= 3, 4, 5, 6 the sum is 17/4, 10.553, 30.862, 99.565 (det_density.py / .out, exact rationals; 4, 8, 18, 46
    of the matrices are unimodular).  The obstruction is geometric: the images G_b K are thin subcones.
  - (a) fails numerically for every system enumerated: port chains d = 3: exponents 1.24, 1.50, 1.69, 1.84 for block
    order <= 3, 4, 5, 6 (S93 lane thinorbit, T4; NUMERICAL); the closed two-dimensional quotient (h, R) = (D, U):
    0.81, 1.16 for order <= 4, 5 against 2; dimension 1 (exact affine maps on H): no non-commuting pair at any
    enumerated size (S93 lane digits, D3-D13; FINITE-EXACT).  So no polyhedral certificate exists with these objects.
  - A certificate need not be polyhedral (C may be a thin, digitally defined set); P3 says nothing about those.

P4.  One-exit extension in source coordinates (KNOWN: the one-exit extension law THM-4862 (a) / THM-4865, and
     U_B(o) = H(B) + sum over out-neighbours x of o of Q_B(x, o), S93 lane seeds S1; recorded because the route map
     reads the window law in these coordinates).  A first draft of this item claimed H(B) = 2h - e, U_B(y) = 2h; that
     was WRONG (it assumed that the predecessor of y beats x) and is withdrawn; the statement below is the checked one.

Statement.  Let (B', x) be a rooted tournament with h = H(B'), e = End_B'(x) (Hamiltonian paths ending at x) and
u = U_B'(x) (ordered covers (P1, P2) of B' by disjoint paths, P2 starting at x, P1 possibly empty).  Let B = B' + y
with y -> x and every other vertex of B' beating y.  Then
        H(B) = h - e + u,      U_B(y) = h + u,      End_B(y) = h - e,      and u >= h.
So (B, y) is a one-vertex source with (offset, slope) = (D, U) = (h - e + u, h + u), D = U - e, and D + 2^t U is in S
for t >= 1 (closing law).
Proof.  Hamiltonian paths of B.  (1) y last: the vertex before y is the last vertex of a Hamiltonian path of B' and
must beat y, i.e. differ from x: h - e paths; these are the paths ending at y.  (2) y not last: its successor is its
only out-neighbour x, and its predecessor a (if any) beats y automatically since a != x.  Cutting the path at y gives
an ordered pair (P1, P2) of disjoint paths covering B' with P2 starting at x and P1 possibly empty, and every such
pair arises exactly once: u paths.  Total h - e + u.  Covers counted by U_B(y): P2 = (y) and P1 a Hamiltonian path of
B' (h covers), or P2 = y x ..., and then (P1, P2 - y) is a cover counted by u (u covers).  Finally u >= h: for a
Hamiltonian path of B' cut it just before x.  QED
Exact check: p4_check.py / .out, all 5,405 rooted labelled tournaments of orders 1..5, 0 failures.
Reading.  The state needed to iterate is (h, e, u), three coordinates (the port-chain state of THM-5070 in other
coordinates); the pair (h, u) alone is not closed (HYP-9453, status).  The "window law" routes (HYP-9453 (2),
HYP-9454 (1), (6), HYP-9659 (C), HYP-9661 (A)) are statements about the two-dimensional set of pairs (D, U) or
(h, u - e): each asks that this set meets every line of a pencil.  They are OPEN.
