Types: PROVED (proof here), KNOWN (prior art named), CITED, FINITE-EXACT (exhaustive, exact integers, range stated).

Notation.  H(T) = number of Hamiltonian paths; H(empty) = 1.  For a tournament T and x != y in V(T):
  s(x), e(x) = number of Hamiltonian paths starting / ending at x;
  Q(x, y)    = number of ordered pairs (P1, P2) of disjoint NONEMPTY paths covering V(T), P1 ending at x, P2 starting
               at y;      W_xy = Q(x, y) + Q(y, x);
  U'(x)      = number of ordered pairs (P1, P2) covering V(T), P1 ending at x, P2 possibly empty  (= e(x) + sum_y Q(x,y)).
  T + v_B    = T with a new vertex v, x -> v for x in B, v -> y for y not in B.
  j! p_j(C)  = number of ordered partitions of V(C) into j nonempty directed paths (p_j = unordered).

0. CORRECTION of a formula in the lane brief                                             [PROVED / KNOWN]
-----------------------------------------------------------------------------------------------------
The brief states: "H(T + v) = H(T) + sum over arcs a -> b with a in A (out-set of v), b in B (in-set) of the number
of Hamiltonian paths through that arc (so H(T + v) = 2H(T) - #paths starting at u when v loses only to u)".
This is FALSE.  Counterexample: T = one arc a -> b, v -> a, b -> v.  Then T + v is the 3-cycle, H = 3; the formula
gives 1 + 1 = 2 (and "2H - s(u)" with u = b gives 2 - 0 = 2, an even number).
What the right-hand side counts: a Hamiltonian path of T + v in which the two neighbours of v are joined, in T, by an
arc in the direction of the path, is a Hamiltonian path x_1..x_n of T with v inserted at a place B|A (or in front of
x_1 in A, or behind x_n in B); the number of such places is 1 + #(places A|B), which gives H(T) + sum_{a->b} mu(a->b).
Missing: the paths .. x v y .. with x in B, y in A and y -> x in T.
Correct statements (all KNOWN in the repository; re-derived and machine-checked here):
 (0.1) Cut law (THM-4114; THM-5122 "F(x) = h + 2 a^T x - (1/2) x^T W x"; THM-5126 (A)):
          H(T + v_B) = H(T) + sum_{x in B} (U'(x) - s(x)) - sum_{pairs {x,y} of B} W_xy.
       Proof.  A Hamiltonian path of T + v is (P1, v, P2) with P1 empty or ending in B and P2 empty or starting outside
       B.  With b = indicator of B:  H = sum_y (1-b_y) s(y) + sum_x b_x e(x) + sum_{x != y} b_x (1-b_y) Q(x,y); expand,
       use sum_y s(y) = H(T).  QED
       Single in-neighbour u:  H(T + v_{u}) = H(T) + U'(u) - s(u) = 2H(T) - s(u) + D(u),
       D(u) = #{covers (P1 u)(y P2) with y -> u} >= 0   (U'(u) = H(T) + D(u): the covers with u -> y, together with
       those with P2 empty, are the Hamiltonian paths of T cut behind u).  The brief's formula is the case D(u) = 0.
 (0.2) Claim A (THM-4876 (1), THM-070):  H(T + v) = H(T) + 2 sum over odd cycles c through v of H(T - (V(c) - v)).
 Check: arc_cube_*.out line (A) (every labelled tournament of order <= 7): the mixed second difference of H in two
 arcs at a common vertex is never 0 and has absolute value >= 2, as (0.1) + Lemma 1 predict.

1. Lemma 1 (coupling floor)                                         [KNOWN: THM-5122 "W_ij >= 2 H(C - i - j) > 0"]
-----------------------------------------------------------------------------------------------------
For every tournament T and x != y:  W_xy >= 2 H(T - x - y) >= 2.
Self-contained proof (insertion).  Let R = V(T) - {x, y}.  If R is empty, Q(x,y) = Q(y,x) = 1.  Otherwise let
r_1 .. r_m be a Hamiltonian path of T[R] and give r in R the type a (r -> x, r -> y), b (x -> r, y -> r),
c (r -> x, y -> r) or d (x -> r, r -> y).  Put t_0 = a, t_(m+1) = b (virtual).  For 0 <= i <= m the pair
(r_1..r_i x)(y r_(i+1)..r_m) is a cover counted by Q(x, y) iff t_i in {a, c} and t_(i+1) in {b, c}; the pair
(r_1..r_i y)(x r_(i+1)..r_m) is counted by Q(y, x) iff t_i in {a, d} and t_(i+1) in {b, d}.  Let i be the last index
with t_0 = .. = t_i = a: the step t_i -> t_(i+1) is a -> b (two covers), a -> c (one) or a -> d (one).  Let j be the
least index with t_(j+1) = .. = t_(m+1) = b: the step t_j -> t_(j+1) is a -> b (two covers), c -> b or d -> b (one).
If i = j the step is a -> b: two covers.  If i != j: one cover at each of two different places.  A cover determines the
path r_1..r_m and the place, so different (path, place, order of x,y) give different covers.  QED

2. Theorem A (additive arc sets are matchings; exponent barrier for one affine cube)                  [mixed]
-----------------------------------------------------------------------------------------------------
For a tournament T on n vertices and a set E of k pairs of vertices let T^sigma (sigma in {0,1}^E) be T with the arcs
on the pairs e with sigma_e = 1 reversed.  Call E AFFINE if H(T^sigma) = h_0 + sum_e delta_e sigma_e on the whole cube.
 (a) [KNOWN in substance: THM-4114 (ear cube: every pair interaction strictly negative, no additive 2-cube),
     THM-5122 (capacity k <= floor(|C|/2) for exchange families at one root); stated here for arbitrary arc cubes]
     If E is affine, its pairs are pairwise disjoint; hence k <= floor(n/2).
     Proof.  Let {v,x}, {v,y} be in E and fix the other coordinates.  The four tournaments are (T' - v) + v_B with B
     ranging over B_0, B_0 + x, B_0 + y, B_0 + x + y; by (0.1) the mixed second difference is -W_xy(T' - v) <= -2
     (Lemma 1), not 0.  QED
 (b) [PROVED from (a), Busch's minimum (CITED: Busch 2006, as used in THM-4744 (3)) and FINITE-EXACT at n = 6]
     If E is affine and every T^sigma is strong, the cube has at most 2^floor(n/2) values, each >= h_min(n), where
     h_min(n) = 3*5^((n-3)/3), 5^((n-1)/3), 9*5^((n-5)/3) for n = 0, 1, 2 mod 3, so h_min(n) >= 5^((n-1)/3).  Hence
          #values <= 2^(n/2) <= sqrt(2) * (min value)^theta,   theta = 3 / (2 log_2 5) = 0.64603...
     and for n >= 3, n != 5, and X >= 3 no strong affine arc cube of order n contains all odd numbers of [X, 2X].
     At n = 5 there is exactly one exception (FINITE-EXACT, squares_values.out): 120 labelled affine squares with
     values 9, 11, 13, 15 = 9 + {0,2} + {0,4}, all odd numbers of [8, 16] and the whole spectrum of the strong
     tournaments of order 5.  So this square is the only strong affine arc cube, at any order, whose value set
     contains all odd numbers of an interval [X, 2X] with X >= 3.
     Proof of the last sentence.  All odd numbers of [X, 2X] must be >= h_min(n), so the interval contains at least
     (h_min(n) - 1)/2 odd numbers (X even, X = h_min - 1, is the smallest case), and at least two (X >= 3).
     n = 3, 4: every strong tournament has H = 3, resp. 5: one value.  n = 6: h_min = 15, seven values are needed; a
     cube of dimension <= 2 has at most 4, and all 3,900 affine 3-cubes of order 6 have a zero increment
     (arc_cube_456.out (C)), hence at most 4 values.  n = 7, 8, 9: (25-1)/2 = 12 > 2^3, (45-1)/2 = 22 > 2^4,
     (75-1)/2 = 37 > 2^4.  Step n -> n+3: h_min(n+3) = 5 h_min(n) and 2^floor((n+3)/2) <= 4 * 2^floor(n/2), so
     (h_min(n) - 1)/2 > 2^floor(n/2) implies (5 h_min(n) - 1)/2 > 5 * 2^floor(n/2) > 2^floor((n+3)/2).  QED
     (An earlier draft of this proof used the count (X+1)/2 for odd X only and missed the n = 5 square; the
     exhaustive list of squares_values.out caught it.)
 Scope (honest).  (b) is about ONE cube whose 2^k members are all strong of the same order; it does not bound unions
 of cubes, nor cubes whose members change their strong component.  THM-5117 has affine exchange cubes of every
 dimension (order 7k+1, spacing 50*37^(k-2)), THM-4960/5000 have k+1 consecutive odd counts on 12k+13 vertices; (b)
 says that even an ideal positional cube (increments 2, 4, 8, ..) has too few digits: n/2 against log_2 h_min(n) =
 0.774 n.  A binary expansion argument "arc usages 1, 2, 4, .., 2^k" (direction (ii) of the brief) is therefore
 impossible inside one strong arc cube, at every order.

3. Theorem B (module law; the mixed term never vanishes in a strong context)                      [PROVED]
-----------------------------------------------------------------------------------------------------
Let T0 be a tournament, u != v two vertices, C1, C2 tournaments, and T = T0[u := C1, v := C2] (C1, C2 substituted as
modules).  A (j,k)-walk of T0 is a sequence of vertices with consecutive terms joined by arcs of T0 in the direction of
the sequence, in which u occurs exactly j times, v exactly k times and every other vertex exactly once; c_jk >= 0 is
their number.
 (a) H(T) = sum_{j,k >= 1} c_jk (j! p_j(C1)) (k! p_k(C2)).
     [The one-module, visits <= 2 case is the closing law THM-5126 (A)/THM-5130; THM-5124 (4) is the full-cut case.
      I did not find the two-module statement in 01-canon (grep "substitution|module|lexicographic" in THM-50xx-51xx).]
     Proof.  In a Hamiltonian path of T contract every maximal run of vertices of C1 to u and every maximal run of
     vertices of C2 to v: since C1, C2 are modules, the result is a (j,k)-walk of T0 (two consecutive runs of the same
     module would be one run, so consecutive terms are distinct and joined by an arc), and the runs form an ordered
     partition of V(C1) into j paths and of V(C2) into k paths.  Conversely every (j,k)-walk and every pair of ordered
     partitions give a Hamiltonian path.  QED
     For C_i = TT_t: j! p_j(TT_t) = j! S(t, j) = sum_i (-1)^(j-i) C(j,i) i^t, so
     H(T0[u := TT_s, v := TT_t]) = sum_{i,l >= 1} d_il i^s l^t  with d_il = sum_{j>=i,k>=l} (-1)^(j-i+k-l) C(j,i) C(k,l) c_jk.
 (b) If T0 is strong of order n >= 3 then c_22 >= 1 for every pair u != v.
     Proof.  T0 has a Hamiltonian cycle (Camion) x_1 = u, x_2, .., x_n, x_1; let v = x_k (k >= 2).  If u -> v the
     sequence x_1 x_2 .. x_n x_1 x_k is a (2,2)-walk: the arcs are those of the cycle and x_1 -> x_k; u occurs at places
     1 and n+1, v at places k and n+2, all others once.  If v -> u the sequence x_k x_1 x_2 .. x_n x_1 is a (2,2)-walk.
     QED
 (c) Consequences.  (i) H(T0[u := C1, v := C2]) >= c_22 * 2p_2(C1) * 2p_2(C2) >= (2^|C1| - 2)(2^|C2| - 2) in a strong
     context (p_2(C) >= 2^(|C|-1) - 1: every vertex set of a tournament carries a path).
     (ii) No additive separation: the functions i^s l^t (i, l >= 1) are linearly independent on pairs (s,t) of
     positive integers, the matrix (d_il)_(i,l>=2) is obtained from (c_jk)_(j,k>=2) by a unitriangular transformation,
     and c_22 > 0; so in a strong context H(T0[u := TT_s, v := TT_t]) is NEVER of the form alpha(s) + beta(t).
     In particular there is no strong two-port context with N = A + B 2^s + C 2^t, and no family
     N = A + 2^(t_1) + .. + 2^(t_m) (numbers of bounded binary weight) by module substitution into a strong context.
     (iii) Homogeneity: for one module, H(T0[u := C]) = sum_j c_j j! p_j(C) is a linear form WITHOUT constant term in
     the path-cover vector of C; it is a function of H(C) alone on all tournaments C iff c_j = 0 for all j >= 2
     (test on C = TT_t: sum_j c_j j! S(t,j) is constant in t iff c_j = 0 for j >= 2, all c_j being >= 0), i.e. iff u
     lies on no cycle of T0, and then H = H(T0) H(C).  So module substitution into a fixed context realizes no exact
     map H -> alpha H + beta with beta != 0, and no exact map other than a multiplication.  (All-order analogue, for
     substitution, of the S93 "digits" finding; their vertex-extension rules are not covered by this statement.)
 Checks: module_law.out (V1) 300 random two-module instances, context order 3..6, modules of order 1..3, exact, no
 failure; (V2) every labelled strong tournament of order 3..6 and every port pair (340,390 pairs): min c_22 = 1, 1,
 1, 2 at n = 3, 4, 5, 6.

5''. FINITE-EXACT data and a remark on direction (i), balanced arcs (balanced_arcs.out)
-----------------------------------------------------------------------------------------------------
An arc x -> y of T is balanced if it lies on (H - 1)/2 Hamiltonian paths (seed, S93 Theorem 1), anti-balanced if on
(H + 1)/2.  Exhaustive over all labelled tournaments:
  order 4: 40 of 64 have a balanced arc (none of the 24 strong ones); order 5: 840 of 1,024 (strong: 360 of 544);
  order 6: 21,120 of 32,768 (strong: 11,520 of 22,320 = 0.516); order 7: 532,560 of 2,097,152 (strong: 267,120 of
  1,677,488 = 0.159).  Anti-balanced: 64, 760, 15,840, 409,920.
  H-values of order 7 (77 values): 37 admit a balanced arc at order 7, 33 an anti-balanced arc, 27 neither
  (61, 79, 83, 85, 89, 93, 95, 99, 103, 105, 111, 121, 125, ..., 189: the upper part of the spectrum).
Remark [PROVED, trivial].  sum over the arcs of T of mu(arc) = (n - 1) H(T), so the mean usage of an arc is 2H/n, and
sum_y mu(x -> y) = H - e(x): a vertex has at most two balanced out-arcs when H >= 5, and a balanced or anti-balanced
arc carries about n/4 times the mean usage.  So balanced arcs are not a property of typical tournaments with a given H:
the share of strong tournaments that have one falls from 0.66 (order 5) to 0.16 (order 7), and 40 of the 77 values
of order 7 are not attained by any tournament of order 7 with a balanced arc; an induction on N through balanced
arcs has to construct special tournaments, which is the seed problem of S93 unchanged.

6. Route assessment (plain)
-----------------------------------------------------------------------------------------------------
No route to a proof of Chan-Pak was found in this lane.  What is closed, at every order:
 - subset-sum / binary expansion over arcs at one vertex (cut bits): every pair interaction is <= -2 (KNOWN);
 - a positional additive system on arcs anywhere: at most n/2 digits against log_2 h_min(n) = 0.774 n (Theorem A);
   the only exact binary digit block is {9, 11, 13, 15} at order 5;
 - additively separable multi-parameter families by module substitution into a strong context: the mixed term
   c_22 * 2p_2(C1) * 2p_2(C2) is always present, every such family with transitive modules is a linear combination
   of products i^s l^t with a nonzero mixed part, and no substitution realizes H -> alpha H + beta with beta != 0
   (Theorem B).
What every exact mechanism examined here and in the repository has in common: the free integer parameters enter
exponentially (module sizes), or additively with at most O(n) unit steps at an exponentially large baseline.  A
proof needs either a family with growing multiplicity and a distribution argument for it (several apexes; S93
two-apex lane), or a non-additive decoding with carries; neither is supplied here.
