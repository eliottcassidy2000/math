\section{The Problem and the Formula}

A \textbf{tournament} is a complete directed graph: every pair has a winner.
Think elections, round-robin leagues, pairwise preference surveys.
The question open since R\'{e}dei (1934): \emph{how many directed Hamiltonian paths
does a tournament on $n$ vertices have?}

Call this $H(T)$. R\'{e}dei proved $H(T)$ is always odd; we now have a closed-form:
\vspace{-1pt}
\begin{equation*}
  \boxed{H(T) \;=\; I\!\left(\Omega(T),\, 2\right) \;=\; 1 + 2\alpha_1 + 4\alpha_2 + 8\alpha_3 + \cdots}
\end{equation*}
\vspace{-3pt}

$\Omega(T)$ is the \emph{odd-cycle conflict graph}: vertices are odd cycles of $T$,
edges connect pairs sharing a vertex; $\alpha_k$ counts independent $k$-sets
(pairwise vertex-disjoint odd cycles).
Proved in 2024 by Grinberg--Stanley (arXiv:2412.10572).
\textbf{Our system rediscovered it via six independent routes} before finding the
preprint, then fully verified it through $n\leq 8$ (8\,M+ tournaments, zero failures).

\begin{itemize}
  \item \textbf{Ranking entropy:} $H(T)$ measures how contested a ranking is.
    Large $H$: many valid orderings coexist. Small $H$: outcome nearly forced.
    The $\alpha_k$ decomposition reveals structure invisible in $H$ alone.
  \item \textbf{Deletion-contraction} (proved, any digraph):
    $H(D) = H(D\setminus e) + H(D/e)$.
    Enables divide-and-conquer with $O(2^w \cdot n)$ complexity for treewidth-$w$ graphs.
\end{itemize}

\section{Engineering Innovations}

\subsection*{1.\ Small-Prime Gaussian Elimination — 8$\times$ memory, multi-prime certified,
  GPU-ready}

\textbf{The contribution is packaging, not invention.}
Modular rank over $\mathbb{F}_p$ is known; we integrated it into a topological boundary-matrix
pipeline with a novel two-prime certification protocol:
reduce mod $p_1 < 256$ (store as \texttt{uint8}), compute rank, repeat at independent $p_2$;
agreement proves the result equals the true integer rank with no floating-point error
possible ($100\%$ certification rate through $T_{11}$).

\subsection*{2.\ Circulant Eigenspace Collapse — $n\times$ speedup, stronger than Tang--Yau (Feb 2026)}

Tang and Yau (arXiv:2602.04140, Feb 2026) proved symbol-matrix stability at generic~$t$.
\textbf{THM-125 (March 2026):} the symbol matrix is \emph{identically constant}
— an elementary two-line algebraic proof (tail of any valid path is itself a valid path;
hence face$_0$ contributes no $t$-power; hence $M_m(t) = M_m(1)$).
All $n$ eigenspaces share identical boundary ranks:
\textbf{compute one rank, multiply by~$n$}.
Gains: $T_{11}$ $11\times$, $T_{19}$ $19\times$, scaling to $p\times$ for any $T_p$.

\textbf{Applies wherever $\mathbb{Z}_n$ symmetry appears:}
QC-LDPC parity-check design (5G/WiFi/DVB-S2), ring network Laplacians,
lattice gauge theories with toroidal boundaries, spectral clustering on circulant graphs.
