\begin{center}
{\Large\bfseries A New Integer Sequence from Tournaments}
\end{center}

\medskip

Define $W(n) = \displaystyle\sum_{\substack{\sigma \in S_n \\ \text{no unit descents}}} 2^{\#\{\text{unit ascents of } \sigma\}}$, summing over permutations $\sigma$ of $\{0,\ldots,n{-}1\}$ with no position $j$ where $\sigma(j{+}1) = \sigma(j) - 1$.

\[
W(n) = 1,\; 2,\; 8,\; 32,\; 158,\; 928,\; 6350,\; 49752,\; 439670,\; 4327904,\; 46963358,\; \ldots
\]

This sequence is \textbf{not in the OEIS}. It satisfies $W(n)/n! = 1 + \mathrm{CV}^2(H)$, where $H$ is the Hamiltonian path count over random tournaments. Its generating function involves the $x$-tribonacci recurrence $F(N{+}3) = F(N{+}2) + xF(N{+}1) + xF(N)$ with bivariate GF
\[
\sum_{N \geq 0} F(N,x)\, y^N = \frac{1 + 2xy + xy^2}{1 - y - xy^2 - xy^3}.
\]
At $x = 1$, the dominant eigenvalue is the tribonacci constant $\tau = 1.8393\ldots$
