## Proof audit

The cyclic context count is an integer bilinear form in the finite unordered-cover kernel K. Actual transitive tournaments of orders1 through n+1 give the lower unit-triangular Stirling cover matrix. Multiplying K on both sides by it preserves the gcd of all entries in both directions. Thus the first kernel-gcd identification uses only physical test inputs.

Write a_k=(k!)² gamma_k u_k. The Newton coefficients vanish below r=k+1, so every nonzero normalized kernel coefficient has an integer factorial ratio. In diagonal position(k,k), k>=2, the coefficient on a_k is exactly one and all other involved coordinates have smaller index. The first two entries give the displayed matrices with determinants four. This includes d=1: the missing a_1 is zero, but K_12 is still a valid kernel entry. The physical gcd C is odd because every actual tournament Hamilton count is odd. Consequently C|4a_k implies C|a_k. The reverse divisibility is immediate from the integer entry expansions. The formal even-evaluation example x³+x correctly demonstrates why that oddness step cannot be omitted.

The required diagonal positions stop at k=d-1. Together with entries11 and12 they lie in the leading L-by-L block, L=max(2,d-1). The restricted Stirling matrix is again integer unit triangular, so the smaller square bank of actual transitive inputs has the full gcd C. This covers n=1 and n=2 without deleting an input or introducing a zero-vertex block. It is a sufficient bank, not a claim of minimum size.

The central-factorial coordinate k=0 is H(V), so C|H(V). Coordinatewise factorial weighting gives g|G|C. For each prime, the minimum of A_k+t K_k at t=0,1,2 is concave, proving gC|G². The divisibility(k!)²|gamma_k bounds factorial valuations and gives the stated sharp exponent restrictions, including valuation-one rigidity. The implication for a target prime or7p is correctly scoped: ordinary content plus H(V)<=N already forces C|N. The only nonsquarefree target49 is handled separately using C|H(V), rather than incorrectly treating valuation bounds as equalities in all cases.

The larger example is an actual tournament. The three levels9,27,81 are distinct and saturate the exponent bounds. Two cyclic output counts certify the cyclic gcd at most81, while the kernel proves universal divisibility by81 for that restricted family. The matching-context output is a different physical whole-module substitution, not a cyclic two-block context; its count is27 modulo81. The proof does not mistake a gcd for an attained Hamilton count.
