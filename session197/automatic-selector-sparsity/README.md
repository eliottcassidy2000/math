# Automatic fixed-prefix selectors are sparse

A synchronous regular selected-witness relation for any fixed physical final-gadget prefix has a strict subunit-power counting bound. Any finite bank with recoverable prefix tags therefore covers a zero proportion of prime targets and of seven-times-prime targets.

This is an obstruction to a specified finite-state inverse strategy, not to the scalar image, nonautomatic inverses, growing prefix banks, or unrestricted tournament constructions.
