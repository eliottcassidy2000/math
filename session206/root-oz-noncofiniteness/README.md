# Root O/Z noncofiniteness and d=1 bank collapse

This standalone packet proves an all-order upper density bound for the rooted-edge O/Z scalar image, shows every nontrivial physical d=1 seed has its tail image inside that same root image, and supplies a sufficient noncofiniteness test for mixed finite banks. The test excludes a concrete two-member bank containing the root and a JJO seed that adds the scalar 29.

It does not prove impossibility for every finite bank, an exact image density, arbitrarily long consecutive gaps, or a claim about the unrestricted tournament spectrum.

Read `ROOT_OBSTRUCTION.md`. Its capacity and tail-formula dependencies are frozen under `dependencies/`; independent reviews are under `audit/`. Run `python3 verify.py` and `python3 -O verify.py`. These executable checks are finite regression checks, not substitutes for the all-order proofs. `SHA256SUMS` records all frozen release files except itself.
