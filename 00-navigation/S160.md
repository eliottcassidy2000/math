# Session 160: ordered programs and tournament constructions

This session uses ordered FRACTRAN rules and the exact-spectrum conjecture as creative starting points. The conjecture that tournament Hamilton-path counts are all positive odd integers except 7 and 21 remains **hypothetical**. Encoding an integer into a witness or a graph statistic is not the same as constructing a tournament with that integer as its Hamilton-path count.

- [Priority tilings](../05-knowledge/results/session160_ordered_programs_20261103/priority_tilings/NOTE.md) implement first-applicable FRACTRAN selection with marked-path colors and an external controller. A 15-vertex chord observation encodes guard patterns and blue complements, but the unmarked graph alone is not a dynamical state or a simulation.
- [Metagraph hub](../05-knowledge/results/session160_ordered_programs_20261103/metagraph/NOTE.md) gives an all-order cycle hub and a checked seven-state ordered engine using actual black lines. The priority rules and intermediate phase are supplied externally; this finite construction is not a universal machine.
- [Adaptive codes](../05-knowledge/results/session160_ordered_programs_20261103/adaptive_codes/NOTE.md) injectively encode integers in counts of strong, including self-converse, tournaments and realize every nonnegative integer as a triangle statistic. Neither statement asserts that the target integer equals the Hamilton-path count.
- [Tournament instruction set](../05-knowledge/results/session160_ordered_programs_20261103/instructions/NOTE.md) uses strong witnesses whose counts decode integer states, simulates ordered rational instructions at that state level, and derives exact digit and affine count rules. Its dyadic sum identities do not furnish a single-tournament sum assembler.
- [Conditional spectrum atoms](../05-knowledge/results/session160_ordered_programs_20261103/axioms/NOTE.md) develops arithmetic consequences of the conjectural spectrum and credits the prior THM-4094 two-lane reduction. The 3969 example has two actual ordinal-sum witnesses with different component counts; equality of the proposed elasticity with 5/2 is conditional.

Each note records proofs, dependencies, and reproducible finite controls. None establishes the missing global spectrum inclusion or claims novelty against the entire literature.
