# Session 172: memory, arithmetic dynamics, and contextual read heads

This session separates exact finite-horizon information, memory preserved under continuation, and arithmetic descent. It improves the physical tournament storage construction while making the limits of symbolic Collatz arguments explicit.

1. [Contextual memory growth](../05-knowledge/results/session172_memory_dynamics_20261103/synthesis/NOTE.md): a proved synthesis explains when response classes stabilize into an autonomous quotient and identifies concrete remaining research targets.
2. [Future-observer geometry](../05-knowledge/results/session172_memory_dynamics_20261103/observers/NOTE.md): affine full-branch systems have exact b-adic response memory. Identical observer geometry can coexist with different positive-integer behavior.
3. [Collatz parity tapes and descent certificates](../05-knowledge/results/session172_memory_dynamics_20261103/collatz/NOTE.md): literal tournament storage realizes every finite parity word; exact cylinder thresholds distinguish information from descent. Classical density-one stopping is not universal convergence.
4. [Strong tournament storage](../05-knowledge/results/session172_memory_dynamics_20261103/spectrum/NOTE.md): one feedback vertex makes the entire storage family strongly connected while preserving full-profile blindness, distance protection, and addressed readout. Its unique articulation prevents 2-vertex-strongness.
5. [Carry read heads and positive-state cost](../05-knowledge/results/session172_memory_dynamics_20261103/carry/NOTE.md): an external matrix probe reads the carry hidden from triangular trace contexts; exact positive state models need one state per contextual class. The probe is not a legal Collatz step.
6. [Quadratic graph response memory](../05-knowledge/results/session172_memory_dynamics_20261103/squares/NOTE.md): endpoint and two-path records characterize every one-vertex Hamilton response, with sharp linear rank over all labelled graphs. A two-step counterexample shows that this record is not closed under continuation. Square-sum examples are arithmetic specializations, not new all-order existence results.

All five computational packets include exact standalone controls and independent audit controls with matching normal and optimized Python outputs. Their all-order claims rest on proofs, not finite enumeration. The synthesis received an independent mathematical audit. Collatz convergence, the main Hamilton-count spectrum conjecture, and general square-sum existence remain open.
