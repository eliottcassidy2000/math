# Session 195: recursive tournament pieces and the {7,21} spectrum

2026-11-05. **The full Hamiltonian-path spectrum remains open.** This session built exact recursive classifications and physical composition rules, and checked their limitations. No finite census is presented as an all-order coverage proof.

## Constructive recursive interfaces

- [Three-coordinate moving-root interface](../session195/rooted-interfaces/PROOF.md): an exact, reusable composition law for rooted tournament pieces. A complete order-at-most-five bank gives all odd counts through 20,000 except 7, 21, 67, 163, 173, 247, 511. [Five explicit six-vertex pieces](../session195/rooted-interfaces/FIVE_GADGET_EXTENSION.md) fill the latter five gaps while keeping the same interface.
- [Four-coordinate combined grammar](../session195/combined-growth/PROOF.md): adds stationary-root operations. With the original 65 gadget signatures it misses 7, 21, 67, 173 through 20,000. [Two explicit six-vertex pieces](../session195/gadget-extension/PROOF.md) fill 67 and 173; an independently replayed arbitrary-depth state search then reaches every positive odd value through 20,000 except 7 and 21. The target bound is finite; it is not an eventual-coverage claim.
- [Logarithmic growth](../session195/logarithmic-growth/PROOF.md): every count attained by the enlarged grammar has a logarithmic-length construction, and bounded-target membership can be decided by a finite search. This does not imply that every admissible target is attained.

The Session 194 source records an independent one-arc coverage check through 2^20. The present 20,000 result is valuable for its small recursive grammar, not as a new overall numerical coverage record.

## Structural classifications

- [Strong-core growth](../session195/strong-structure/PROOF.md): a strong induced core can grow to the ambient tournament one strong vertex at a time exactly when its smallest containing module is the whole tournament. A sharp count threshold guarantees this; mixed singletons and two-vertex ears yield a universal strong-growth grammar.
- [Endpoint-one recursion](../session195/endpoint-recursion/PROOF.md): an exact recursive decomposition and returning interface for all tournaments with a Hamiltonian endpoint of count one. This class cannot realize 13 at any order.
- [Elementary-grammar bridge](../session195/endpoint-grammar-bridge/PROOF.md): the scalar support of the elementary A,K,D grammar equals the endpoint-one scalar support, by explicit graph compilation.
- [Endpoint-typed path-cover algebra](../session195/pathcover-algebra/PROOF.md): exact composition for colored pieces with nonuniform cross arcs. Its polynomial state can grow, and a rank argument rules out a universal fixed-dimensional bilinear interface for the specified class of gluing contexts.

## Induction barriers

- [Equal-response moving-root barrier](../session195/rooted-interfaces/EQUAL_RESPONSE_BARRIER.md): even a primitive state can fail to reach its literal ternary children using moving-root operations alone.
- [Binary-ready return barrier](../session195/full-binary-return/PROOF.md): once the deletion count is at least three, a binary-ready state can return to that interface only via repetitions of K, even allowing arbitrary rooted gadgets. This is an interface-specific obstruction, not a disproof of scalar coverage.
- [Zero-slack classification](../session195/zero-slack/PROOF.md): the rooted merge slack is zero exactly when the root has outdegree at most one. A [reviewed refinement](../session195/zero-slack/UNIVERSAL_BOUND.md) proves that bounded-deletion zero-slack representations yield only O(log X) distinct counts through X across all tournaments.

Each packet includes verifiers and any necessary data, and was independently reviewed. The enlarged-grammar 20,000 census retained 2,584,754 states; its completeness applies to arbitrary operation depth within the stated finite bank. Independent graph enumeration and separate implementations checked the physical operations, inventories and witnesses.

## Remaining question

The central missing step is an all-order inverse-target argument or another construction that proves every required prime and 7p atom is attainable. Neither logarithmic witness bounds nor a finite exact census proves that claim. Multiple root switches outside the blocked interfaces remain available, so the recorded obstructions do not settle the enlarged grammar or the full spectrum.
