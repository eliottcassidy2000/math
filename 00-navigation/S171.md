# Session 171: knots, information, and contextual recoverability

The organizing question is operational: which hidden states become recoverable when the allowed experiment changes? This session connects literal tournament storage, Hamilton-count readouts, coding distance, transport quotients, torus-knot slopes, and compositional boundary responses. It distinguishes physical tournaments, pinned transport sheets, and marked knots rather than identifying them by analogy.

1. [Contextual recoverability](../05-knowledge/results/session171_knots_information_20261103/synthesis/NOTE.md): a proved session-level theorem characterizes exact task recovery by response fibers, quantifies remaining uncertainty, and identifies linear blind spaces. It joins the concrete constructions below without claiming new general information theory.
2. [Tournament storage and Hamilton read heads](../05-knowledge/results/session171_knots_information_20261103/information/NOTE.md): Reed–Muller words become pairwise nonisomorphic equal-profile tournaments with exact arc-distance protection. A fixed one-vertex attachment reads an addressed bit through Hamilton counts 17 versus 19. [The update barrier](../05-knowledge/results/session171_knots_information_20261103/information/UPDATE_BARRIER.md) separates robust storage from a connected update path.
3. [Observation and Fisher information](../05-knowledge/results/session171_knots_information_20261103/fisher/NOTE.md): probe rank determines uniform uncertainty, while the answerable character space determines which local statistical signals survive. Statistical evidence is distinguished from a deterministic identity certificate.
4. [Winding codes and hidden returns](../05-knowledge/results/session171_knots_information_20261103/winding_codes/NOTE.md): intermediate covers of the physical six-state seed torus correspond to binary codes; the first hidden nonzero return takes exactly three times the code distance in literal arc flips. These are pinned return sheets, not new isomorphism classes.
5. [Torus knots and transport](../05-knowledge/results/session171_knots_information_20261103/knots/NOTE.md): finite nilpotent images of torus-knot groups are cyclic, finite deck signatures conceal unbounded marked knot genus, and physical flip schedules have explicit winding constraints. A torus, its knot complement, and a tournament flip complex remain distinct spaces.
6. [Sufficient interfaces and boundary response](../05-knowledge/results/session171_knots_information_20261103/framework/NOTE.md): continuation-closed blind spaces characterize valid compression, while square-zero visited-vertex data gives exact Hamilton-path responses under order-independent elimination. No polynomial-size compression is claimed.

Every computational packet includes standalone exact controls, independent audit controls, and matching normal/optimized Python outputs. General results rest on the displayed proofs, not extrapolation from finite tests. The packets received independent mathematical audits; repository-wide CI is a separate verification surface.

The main Hamilton-count spectrum conjecture remains open. These constructions establish recoverability and protected transport within existing count families; they do not create the missing prime realization lanes. The synthesis ends with targeted next experiments connecting context separation to genuinely coupled arithmetic constructions.
