# A conditional route to the odd threshold 23

**The implication and finite certificates are independently audited. F(8,137) remains OPEN.** No unconditional eventual threshold is claimed.

For a rooted tournament U, define B(U)=H(U)+L(U)-start(U), where L is the actual root-ending two-path-cover response. The open condition asks that every odd B>=137 and each r in {1,2} have a physical rooted U and an integer j with 0<=j<=8 satisfying B(U)=B-2j and start(U)=r+3j. The audited four-core compiler then realizes 3B+2r.

The proof combines that unproved uniform hypothesis with 194 literal seeds for odd values from 23 through 409 and ordered triangle joins. If the hypothesis is proved, every odd count at least 23 follows. This criterion is sufficient, not asserted necessary. Its failure would not refute the unrestricted spectrum.

The finite data verify both residues at every odd base from 137 through 997, using 862 actual rooted source graphs. They do not verify any larger base. The compiler validates each supplied graph and profile, then explicitly stops when a needed certificate is missing. Target 3001 is a missing-certificate control at base 999, not a nonexistence claim.

Run the standalone author controls as shown in PROOF.md. Run audit/check_certificates.py and audit/check_compiler.py, including their -O forms, for the independent literal replay and rejection tests. The audit also checks a 34-vertex triangle-join output without claiming a large subset-DP count.

The physical additive dependency is frozen under dependencies/ and published at commit 150e50fc16d9ec57c596872559b9823b1612f3fe. Source-bank completeness is not required: every finite witness is verified from its adjacency rows. The new SCC normalization and relative attainable-base variation remain separate research and are not included in this release.
