# A strict density limit for the four paired O/Z carriers

**PROVED, independently audited in the stated scope.** This is a bound for the four particular carrier orbits in `../staggered-paired-carriers/PROOF.md`, not for all physical sources and not for F(8,137).

Let S be the set of adjusted bases X generated by those four paired seeds using any finite O/Z word. Repeated bases are counted only once. Then

    limsup_(M->infinity) |S intersect [1,M]| / M
       <= 693609731 / 93988567442
        < 0.0075.                                  (1)

Consequently S has upper relative density less than1.5 percent among the odd positive integers. In particular these four O/Z carrier orbits do not contain an odd tail. This is an explicit stopping boundary for this carrier menu, even though each of its bases has both staggered certificates.

## Proof

For any one seed let its initial row be (X0,e0,V0,d), and put A=V0-d>0. Under both letters, the exact row law from `../staggered-paired-carriers/PROOF.md` implies

    V_k >= 2^k A+d.

The initial row satisfies e0<=d, and every subsequent e is0 or d. Also X never decreases. If a nonempty normalized word ends in Z and has length n, its last letter therefore adds at least2^(n-1)A to X. Thus its output obeys

    X >= X0+2^(n-1)A.                            (2)

A normalized word is obtained by deleting its terminal run of O letters, which preserves X. There is one empty word, and exactly2^(n-1) words of length n ending in Z. Therefore, if a base is at most M, its normalized length n satisfies2^(n-1)<=M/A. Summing the geometric count through the largest possible n gives the safe bound

    number of represented bases <= 1+2M/A.

This is an upper bound even when distinct words collide. Summing over the four seeds yields

    |S intersect [1,M]| <= 4+2M*(1/1012+1/898+1/1582+1/1046).

The sum of reciprocals is693609731/187977134884, proving(1). Dividing instead by the number of odd integers at most M doubles the limiting upper bound to693609731/46994283721, which is strictly less than3/200. Since an odd tail has relative density1 among the odds, the claimed noncoverage follows. QED.

The crucial distinction is between simultaneous positive instances and a sufficiently large scalar image. This result bounds only the selected four-seed language. Other seeds, root-changing J moves with a richer coupled state, and actual sources outside any such grammar are not excluded.

`check_density.py` checks the exact rational arithmetic and the last-Z growth inequality on all binary words of lengths through12 from the four rows. The geometric counting argument, not this finite control, proves the asymptotic bound.
