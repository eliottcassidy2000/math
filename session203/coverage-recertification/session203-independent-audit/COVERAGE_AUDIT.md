# Corrected replay of the inherited odd-count prefix

Status: **PASS; independent review of this correction packet requested before publication.**

## Result and exact scope

A corrected full replay of the independent S78 implementation certifies that **every odd integer 1<=N<=4,294,967,295 except 7 and 21** is the Hamiltonian-path count of an actual tournament in its F1/F2 construction families. The cap is 2^32, which is even. This recertifies an inherited finite result; it does not increase its range and proves no eventual threshold or unrestricted all-order spectrum theorem.

The inherited statement is THM-4875 (D), adopted at commit `baba886cbe54a4eb47c7d8a8ceafdee8e4fd5b98`. Its construction and bank were already independently audited. This packet corrects and replays that audit's implementation. It is not a third independently authored full-range sieve.

## Defect and repair

The inherited `gfast(v)` indexes a 2^16-entry table by `v>>16`. Its F0 loop includes v=2^32, which indexes 65536 out of bounds. A deterministic isolated harness reproduces this with both address- and undefined-behavior sanitizer diagnostics (`BOUNDARY_SANITIZER.txt`).

For the legacy one-apex recurrence in that program, g(0)=1, g(2v+1)=g(v), and g(2v)=g(v)+v+(v mod2). Induction gives g(2^k)=2^k+1 for k>=1. Hence the intended F0 endpoint g(2^32)=4,294,967,297 is above the target cap and should never contribute. This alone does not certify the old compiled run, since an invalid read could create a spurious mark.

`aud_cover_corrected.c` falls back to the direct formula when `v>>16>=65536`, and deterministically checks 2^32−2,2^32−1,2^32 against both direct and recursive definitions. The corrected endpoint harness passes address/undefined sanitizers with leak detection disabled because LeakSanitizer is incompatible with the execution environment's ptrace setup. `S78_ENDPOINT_FIX.patch` is a reviewable source patch; original tracked files were not edited.

## Full recertification

The corrected full 32 pass was built with `-DNOF0`: **F0 was skipped entirely**. F1 and F2 alone mark all intended targets except 7 and 21. No F0 redundancy assumption or old final bitset is used.

- 47,964,383,242 F1 index pairs; 134,010,742,236 F2 evaluations.
- 2,732 rooted triples, regenerated by the inherited independent generator from all 2,131,019 labeled tournaments of orders 1..7, rooted at vertex 0. The regenerated bank matches the frozen bank byte for byte.
- All 22 per-dyadic-block F1 miss counts match the archived independent run.
- Exit status 0. Full output: `CORRECTED_NOF0_32.out`. Machine-readable receipt: `COVERAGE_REPLAY_RESULT.json`.

Every tested F1/F2 value is physical by the inherited exact one-arc-join formulas. Their necessary product bounds include the whole index domains used by this finite constructor. Counts and loop counters fit signed 64-bit arithmetic. The final scan visits every odd target; it is not a sample or a check only of an inherited miss list. The old packet contains no saved full bitset, so this pass reconstructed it.
