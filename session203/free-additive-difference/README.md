**PROVED, independently audited in the stated scope.**

The base H(P_s) is correlated with s. No arbitrary base, full-profile rebase, closed iteration, interval coverage, or eventual threshold is claimed. PROOF.md contains only the audited positive result; the exploratory negative companion is excluded.
