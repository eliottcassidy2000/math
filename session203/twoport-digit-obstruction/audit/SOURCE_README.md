# Two-port digit obstruction

A finite exact certificate rules out the smallest fixed-context one-state
binary architecture with two retained ports and one new vertex per digit.
It allows arbitrary actual starting tournaments and arbitrary affine shift,
and does not require a bound on root-start count.

Read PROOF.md for the statement and its limits. Run verify.py with Python3;
no third-party package is required. NORMAL.json and OPTIMIZED.json record
normal and optimized interpreter replays. The exact rational certificate
has1,176 cases. This is an obstruction, not an F(8,137) construction.
