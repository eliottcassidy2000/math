# Explicit digit formulas for physical source blocks

This independently reviewed packet gives a closed formula for every retained-root O/Z source block using one binary integer, bit reversal and the one-apex path-count function g. A complementary-bit identity cancels the quadratic bit terms in a difference. The packet also derives explicit fixed-left C2 scalar expressions and an exact free-integer parameterization when these blocks alternate with the physical J operation.

These are constructive identities and an arithmetic reduction. They do not prove exact or cofinite odd-target coverage, and a difference of physical counts is not claimed to be a physical count.

Run `python3 check_digit_block.py` and `python3 -O check_digit_block.py` from this directory. Both frozen receipts agree. The independent review includes a separate literal graph check of the block and graft formulas; that check is evidence for the identities, not a range-coverage argument.

`dependencies/` contains the unchanged reviewed source-grammar and C2 bilinear proof inputs. The immutable links in the proof identify their published versions. The manifest covers this release, including the review. Exploratory scalar-range scans are deliberately not included.
