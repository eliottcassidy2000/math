# Finite-parameter source coverage and an open arithmetic lemma

This independently reviewed packet isolates a physical family using at most four arbitrary gadget indices and one terminal power-of-two index, together with C2 pairings of two explicit one-apex sources. Sink absorption removes all internal sink runs. Every represented count n has a physical witness on at most floor(log2 n)+10 vertices.

The frozen exact certificate covers all odd targets from3 through100,001 except7 and21 after six literal repairs. The restricted arithmetic family itself misses eight specified values in that range. A precise sufficient assertion that it covers every odd n>1861 is stated as OPEN, not inferred from the computation. This is a finite-arity proof route, not a proof of universal or cofinite coverage, and not a claim that all sources have bounded gadget depth.

Run `python3 verify.py` and `python3 -O verify.py`. The standard-library program reconstructs every selected positive certificate, checks all gadget constants independently, validates the graph-order bound, and counts each repair graph literally. Both frozen receipts agree. The independent audit and unchanged proof inputs are included.

Later adversarial scans and alternative smaller-arity candidate families are not part of this release. Its theorem, finite bound and conditional scope are exactly those of the reviewed proof.
