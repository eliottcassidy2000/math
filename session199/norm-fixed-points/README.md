# Physical fixed points of the norm-coordinate swap

Classifies the actual source fixed points of y↔z in N(v,v)=x²+4yz.
Their values are exactly13 and41h², with h a balanced source count.
This is not a restriction on general diagonal C2 or independent-source counts.

Depends on the adjacent, unchanged `source-norm-capacity` packet.
Run `python3 verify.py`, `python3 -O verify.py`, and `python3 audit/independent.py`.
The two main outputs match. The independent audit pins the proof and verifier.
