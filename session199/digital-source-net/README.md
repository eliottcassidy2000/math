# Actual sources and a binary digital net

This independently reviewed packet proves an exact product formula for the
Hamilton count of a canonical source, including its positive zero-run carry.
It then proves an O(log U) discrepancy bound jointly in source height and
normalized Hamilton count. Every point retains an explicit O/Z graph recipe.

The result gives physical joint distribution, not exact integer scalar coverage.
The old forty-template two-index coverage lemma remains open. The separate
exploratory fixed-bank scans are not part of this packet.

Run `python verify.py` and `python -O verify.py`. The receipts must agree.
The verifier independently evaluates the physical O/Z recurrence, checks the
exact rational identity on 100,000 initial indices and 2,048 large integers,
and checks 3,883 finite anchored/rectangle instances. The all-order arguments
are in PROOF.md, not inferred from these tests.

Frozen ONE_APEX_SOURCE.md and POSITIVE_SOURCE_GRAMMAR.md are the inherited
physical inputs. QUANTIZATION_PROVENANCE.md is an unrelated methodological
source, not a mathematical dependency. No LRC theorem is transferred.
