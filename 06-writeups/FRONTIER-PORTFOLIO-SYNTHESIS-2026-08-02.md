## Bold reframes that survived hostile tests

### A. Acyclicity has opposite values for different consumers

A forest has maximal independent boundary information, so it is ideal for
reconstructing signed differences.  The same absence of cycles leaves a
global potential, so it is fatal for covering all weak-order assignments.
The transferable lesson is not “use forests” or “use cycles”; it is to compute
the circuit rank seen by the named operation.

### B. Choose a portfolio of local observers

The factorial and JC arguments both win by making one face uniquely visible
at a local place.  In the factorial problem, the place is a prime and the
observer is the lower Newton polygon.  In the JC problem, the place is a
response zero and the observer is a valuation fan.  Their shared workflow is
legitimate:

```text
choose place -> normalize -> list face slopes/orders -> retain units or
coefficients -> prove separation -> test the first overlap.                  (15)
```

The objects themselves are not identified.  When slopes overlap, change the
place, add residue data, or cancel a proved common face by an exact syzygy;
do not infer that the target objects coincide.  THM-3143 is the positive
control for the third option.

### C. A closed form should be an operation conjugacy

The useful sequence formulas here are not fitted scalar recurrences.  The
quadratic factorial recurrence comes from integration by parts, the tournament
transform from a rational quotient-walk kernel conjugated by finite
differences (accelerated by exponential-series convolution), and the LRC
totient formula from divisor inclusion--exclusion.
Each formula names the state it must carry and the operation under which it
closes.  “Closed form” is therefore best treated as a finite or controlled
state conjugacy, with the first discarded derivative/profile as the hostile.
Factorial normalization may reveal a diagonal asymptotic without producing a
fixed recurrence; THM-3213's `lambda^r/r` tail is the mandatory control.

### D. Death, transport, and refinement are different operations

Speed insertion deletes LRC divisor layers.  Pole stripping is virtual-letter
subtraction.  Forest boundary is a signed lift.  None is automatically a
positive mass transport.  Before invoking monotonicity, add a cemetery state,
an upset dual, or a transverse selector explicitly and test whether that
addition preserves the original target predicate.

### E. The binary/ternary modular frame is a sidecar-completion problem

The formal grammar `PSL_2(Z)=C2*C3` is useful only after typing both moves on
one carrier.  The genuine `C3` action rotates a **rooted labelled input
triple** of complete tournament endpoint jets.  The substitution output is
invariant under this rotation and forgets the root, even though its full jet
retains the output path-cover profile.  On the quartic/cubic-resolvent side,
`S4/V4=S3` retains the quotient while losing the point of the `V4` lift
torsor; a candidate `C2` generator must therefore be a pointed involution.

THM-3141 proves that the intrinsic four-point torsor is already too small for
a faithful modular action.  After choosing an origin, nonzero translation,
and cyclic orientation, the pair flip `S` and pair-cycle `R` satisfy the extra
relation `(SR)^3=1` and generate

```text
V4 semidirect C3=A4=PSL_2(F3).                              (16)
```

In `PSL_2(Z)`, `(SR)^3=T^3` is nontrivial, and THM-3141 proves this is the
first extra relation in reduced syllable length.  Thus the four-point object
is exactly the level-three congruence shadow; MISTAKE-352 records the corrected
lineage.

No common carrier or faithful modular action is proved.  The strongest
survivor is a typed search grammar:

```text
ternary sidecar = complete endpoint jet + rooted labelled triple;
binary sidecar = pointed V4 half-system + pair orientation;
lift sidecar = Gamma(3)/Farey coordinate + one common physical atom.        (17)
```

The cheapest decisive test is already the reduced word `(SR)^3`: it separates
the modular carrier from its mod-three shadow.  The live task is to build the
lost `Gamma(3)`/Farey coordinate on a common physical carrier and then vary
the root, endpoint jet, and pointed `V4` origin independently.  Until then
`C2*C3` is a search grammar, not a common action.

### G. Closed-path cancellation demands an owner or branch sidecar

THM-3211 and THM-3215 expose a sharper cross-domain pattern.  The LRC first
correction is the exact phase coboundary `B(phi_1)-B(phi_0)`; the selected-root

The missing coordinates are different and must not be conflated.  LRC now has
the exact residue-periodic `g^-2` functional but still needs its physical cell

multiple-root or infinity seams, and a physical carrier.  Moreover,
an arbitrary nonzero reflection word is not automatically a nontrivial Cech
loop: only composable chart transitions telescope.  The procedural payoff is
exact—when the first obstruction is a coboundary, search the quotient sidecar
that prevents the physically relevant path from closing trivially.

## Procedural exploration loop

For every new object or analogy:

1. name the source, target, map, and exact predicate consumed downstream;
2. list what the map forgets and the smallest plausible restoring sidecar;
3. run the cheapest hostile at an equality, composite, DAG, same-scalar, or
   coarsest-upset boundary;
4. if it passes, extend until a mechanism appears, not merely more data;
5. if it fails, record the minimal witness, first failed implication,
   strongest survivor, and a new typed question;
6. compare the result with every object on the live concept board.

This loop is the common research method behind the promoted results.  It is
also the main defense against false cross-frontier synthesis: a shared
formula is interesting only after the operation and lost coordinate are
named.
