# Hodge conjecture as a cycle-lifting test for LRC14

The productive part of the Hodge conjecture for this project is not the
geometry itself.  It is the standard it sets for a proof carrier:

```text
positive / type-correct cohomology is not enough;
the class must be generated by actual cycles.
```

That is exactly the warning from the repo's baby-Hodge work.  The tournament
hole `(c3,c5)=(8,10)` survives the continuous moment/flag body and still is
not realized.  HYP-2530 says the same thing on the Faulhaber side: Hankel
positivity is only the one-particle shadow.  LRC14 should not make the same
mistake by treating Fejer positivity, moment positivity, or a smooth scalar
shadow as a final certificate.

The right import is a cycle-class map for the packet complex:

```text
certificate cycles -> residual cohomology classes.
```

Named certificate cycles include AP/Goddyn-Wong boundary atoms, Fejer dual
forms, Ramanujan exact-period characters, Haar zipper squares, endpoint-owner
boundary potentials, observer-cut payload boundaries, C27/unital transfers,
K33/state-lift incidences, octahedral face curls, partial-cube Theta classes,
simplex face boundaries, and Roth-Minkowski low-height wall cycles.

Then a primitive non-AP/GW row has only three honest exits:

1. the emitted cochain is exact or dual-annihilated;
2. the residual class is generated by named certificate cycles;
3. the residual class is a specific F7/THM-572 state-lift target.

This reframes F7.  It should not mean "unknown hard row."  It should mean a
nonzero residual Hodge class after every named certificate generator has been
tested and failed.  That gives future agents a finite object to attack: a
coefficient ring, a representative cochain, a list of failed generators, and a
state-lift map.

The strongest existing local model is HYP-2887.  On the support-six branch the
packet graph is the octahedron `L(K4)`, a spherical carrier.  Once low-height
walls are deleted, a one-current has no independent harmonic hiding place: it
must split into gradients and triangular face curls, plus analytic Abel tails.
That is already a Hodge-cycle lifting lemma in miniature.

S227 adds another generator family.  Partial-cube Theta classes and simplex
face boundaries should be treated as cycle generators only when their native
transition, bit-position phase, endpoint-owner, exact `M`, topology, and route
labels remain attached.  Otherwise they are just another attractive quotient
that can leak the LRC predicate.

The next useful computation is small and concrete: build a cycle-class matrix
on a HYP-2963 sample.  Rows are emitted residual cochains; columns are named
certificate generators.  A row reduction with exact rational coefficients
will show which residuals are generated, which descend, and which require a
new F7 representative.
