HYP-3150 reserved the factor-through wall.  This continuation makes it
executable: stop asking whether a quotient is true as a class statement and
ask which functions survive it.

The prompt's `a+b`, `a*b`, `a^b`, `b^a` are the cleanest possible local test.
Two are symmetric shadows; two are ordered channels.  That distinction is the
same one showing up everywhere else: a score class or PGF aggregate can be
right and still fail to carry the proof function.

For n=3, the two-node graph is exact but incomplete:

```text
C -> T always
T -> C with probability 1/3
T -> T with probability 2/3
```

The missing datum is the minority edge inside `T`.  Worpitzky then refines the
transitive fiber with the descent row `1,4,1`; for degree 4 the matching row is
`1,11,11,1`.  This makes Worpitzky a finite-difference/function basis for
ordered path data, not decoration.

For n=4, the key compression is not linear:

```text
x = a OR c
y = b OR c
```

It is class-preserving, but no affine `GF(2)^3 -> GF(2)^2` map is.  That is
the canary lesson in exact finite form: the trick works because the target
function is the four-class color map and because all `S` bulk states may be
folded into `(1,1)`.  A different target function could make the same
compression illegal.

For k=8, the same language says the remaining hard core is legal because the
target resolvent never exceeds degree 4 and the centered quartic has no odd
terms:

```text
(t-1)(t-2)(t-4)(t-5) = u^4 - 5u^2 + 4,  u=t-3.
```

So the Abel-Ruffini analogy should be used precisely: LRC14 is still inside
the solvable quartic window.  The current proof obligation is to make the
bounded-core packet descend to that biquadratic page without destroying the
target function.  If a row needs the ordered channel, keep it.  If a row only
needs the symmetric shadow, compress it.  If it uses the canary OR trick, prove
fiber constancy or record restoration debt.

```text

even: +6 S4

```

with the odd/Worpitzky face larger on `consec_8`.  So the even degree-4 wall is
not the whole proof object; it is the solvable page that still needs the odd
