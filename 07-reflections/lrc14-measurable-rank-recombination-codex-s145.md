# LRC14 Measurable Rank Recombination, S145

S145 makes the current POKE route more concrete.  It does not prove LRC14, but
it turns a wide family of analogies into a finite packet language for the exact
two-swap low frontier.

## Result

The computation reuses the S138 exact AP two-swap scan through added values
`<=40`, applies the rigorous `q_threshold>=14` filter, and audits `8674` exact
rows.  The low frontier is completely labelled:

```text
M<=3/41 rows = 3
M<=2/27 rows = 7
unknown low atoms = 0
```

The seven `M<=2/27` rows split into:

```text
rank 0: AP, GW, P10, P13, P10+GW
rank 1: K33, P10+K33
```

Here rank counts uncharged nonunit K33 obligations after exact `M`/Farey,
C27 owner/carry labels, q=3 unital chart choice, affine order, and
Haar/Borel witness address are retained.

## What Changed

Before S145, the route had many compatible carriers:

```text
Farey exactness,
C27 shell transfers,
q=3 unital charts,
affine depth 14,
K33/Kuratowski minors,
PH bad-child rank,

```

S145 puts them in one packet table.  The useful theorem shape is no longer
"find a stronger scalar count."  It is:

```text
every low bad atom recombines into AP/GW tightness,
unit-petal discharge, or K33/state-lift obligation.
```

## Depth 14

The affine-depth signature is order sensitive.  For the linked chain

```text
GW -> K33 -> P10
```

the component depths `[3,4,1]` produce suffix depths `[8,5,1]` and total `14`.
All other permutations miss `14`.  This makes the depth-14 signal a retained
address, not a numerological equality.

## Measurable Structure

The Borel/Baire/Haar layer is not decorative.  The preserved predicate is:

```text
0 < Haar(GOOD cap G_P)
```

after the packet labels survive.  Quotienting by global phase is safe because
it is a compact-group translation on `R/Z`.  Forgetting C27 owner/carry labels,
unital chart choice, K33 incidence, or owner-private deletion is not safe until
an invariant measurable action proves that the witness event survives.

This is the HYP-2248 address-tax lesson in the LRC14 language.

Incoming HYP-2948/HYP-2949 sharpen this with regular-open boundary fronts.
Their exact calibration says AP and GW are endpoint-only at threshold `1/14`,
while near/K33 `12->36`, petal `10->20`, and petal `13->26` have strict safe
masses `1/1260`, `1/980`, and `1/182`.  This fits S145: the boundary-front
carrier measures the packets, but it should not replace the C27/K33 owner
address.

## External Analogies

The Iravanian recombination paper is useful as a proof-design analogy:
factoring local real pieces is not the end; the subset recombination address is
the computational object.  Euler's pentagonal/log-derivative route is similar:
the sparse signed product becomes a recurrence only after the correct product
address is retained.

The LRC analogue is:

```text
local low-frontier atoms
-> packet recombination address
-> finite rank
-> state-lift endpoint
```

## Tournament Analysis


The pairwise observable is branch retention, address retention, measurability,
state-lift fit, rank control, and anti-scalar guard.  The resulting tournament
is transitive with one Hamiltonian path, putting raw scalar count last.
