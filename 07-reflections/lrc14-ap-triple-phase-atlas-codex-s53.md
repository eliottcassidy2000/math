# LRC14 AP-Triple Phase Atlas

codex-2026-06-20-S53

## Summary

The rank-one relation `u-2v+w=0` is not the missing invariant.  AP triples
`(m,m+1,m+2)` keep that relation fixed, but the signed Newton order word,
pair-tax shadow, packet signs, and cube-root imbalance vary with both `m` and
the bounded core.

Incoming KPS S19 refutes the scalar `C(k)=sup w|Delta_w|` route and then
sharpens the surviving route: prove a Weyl/decorrelation lemma and compare to
the exact decorrelated plateau bound `Q(k-1) < cap_k`.  The AP-triple packet
atlas should therefore not be used to revive a one-number discrepancy bound.
It should be used as a phase coordinate inside the surviving coverage route:

```text
wide structure -> decorrelated p0 <= Q(k-1),
rank-one resonance -> finite phase atlas,
high-rank resonance -> signed relation-lattice cancellation.
```

## Finding

For named AP-triple families through `m=120`, the top rows keep large direct
cap margins.  The core-family tournament is transitive:

```text
consec8 > direct_p0_leader_core > dilated > s51_top_dev_core > third_pocket_mixed_core
```

Selected all-core banks for `m=15,16,22,28,42` all have direct-p0 leaders far
below cap.  The tightest of these is the existing small-offset row at `m=15`:

```text
row=(0,9,10,11,12,13,14,15,16,17)
p0=2290763/5717712
margin=1164997/5717712
```

The proof-lens leaders differ.  For example at `m=15`, direct `p0`, actual
residual, pair-tax shadow, triple packet, and Eisenstein imbalance select four
different rows.  At later offsets the direct leader moves to even/dilated
cores, but the margins remain large.

## Interpretation

The rank-one AP branch is a finite-atlas problem plus a decorrelation/glue
problem, not a scalar discrepancy problem.  The packet signs are useful because
they tell the proof which finite resonant model it is in; they do not by
themselves identify cap risk.
