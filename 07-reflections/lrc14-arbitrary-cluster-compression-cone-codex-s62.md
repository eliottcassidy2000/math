# Arbitrary cluster compression is a cone theorem, not dominance

**codex-2026-06-20-S62.**  The prompt asked for arbitrary bounded cluster shape
compression and suggested Tournament Analysis, but warned that the vertices and
edges might need to be abstract.  That warning was exactly right.

The obvious theorem is false.  For a cluster shape `C`, define

```text
q_C(R)=Pr_{x,phi}(C covers every sector in R)
```

for residual requirements `R subset {1,...,6}`.  If the consecutive block `K`
dominated `q_C(R)` coordinatewise, then compression would be immediate in every
independent context.  But S62 found exact failures:

```text
(0,1,3) beats (0,1,2) by 5/294 on several 3-sector residuals.
(0,1,2,4) beats (0,1,2,3) by 3/196 on several 4-sector residuals.
(0,1,2,3,5) beats (0,1,2,3,4) by 37/2940 on several 4-sector residuals.
```

S63 later refined the exact breakpoint set for arbitrary nonconsecutive
carriers by adding pairwise offset-difference walls.  That changed the size-4
and size-5 constants above but not the qualitative conclusion.

These challengers do not improve full cover; for sizes below 6 full cover is
zero anyway.  The lesson is that spread shapes can be better at covering a
small named residual packet while still being worse at the all-six completion
that drives `p0`.

## The Correct Vertex

The right vertex is not a runner, not a cluster, and not even a residual sector.
It is a **residual profile generated by a context**.  A context is the union of
the other decorrelated clusters at the same slow coordinate `x`; it induces
weights

```text
w_R = Pr(context leaves exactly the residual requirement R, or at least needs R)
```

depending on the chosen normalization.  Compression should say:

```text
sum_R w_R q_C(R) <= sum_R w_R q_K(R)
```

for every `w` in the cone generated by actual LRC contexts.  It is not true for
arbitrary nonnegative `w`.

This is a useful narrowing.  The bad residual-coordinate gains in S62 are on
small or sparse `R`; the full-cover scalar and split-context beams still point
at consecutive/coherent blocks as the dangerous shapes.

## Tournament Read

S62 tried three vertex sets:

- cluster shapes;
- residual requirements;
- proof lenses.

The size-8 shape tournament under the full-cover scalar is transitive with
`K8` as source.  Under residual-majority on the selected shapes it stayed
transitive in the same order, but the exact coordinate failures show the switch
can flip local edges if a proof uses arbitrary residual weights.

The proof-lens tournament is the useful one:

```text
split_vs_single_margin
> single_block_diagonal_freeze
> context_weighted_cone
> full_cover_scalar
> joint_multi_carrier_error
> coordinatewise_residual_dominance
```

That ordering says where to spend proof effort.  THM-557 already closed
single-block extremality and large-`M` diagonal-freeze for the coherent quotient.
The missing middle is not another scalar scan.  It is a cone characterization.

## Next Lemma Shape

Let `mu_C,x` be the carrier law over hit masks for shape `C` at slow coordinate
`x`.  A context profile is obtained by convolving other `mu_i,x` and reading
the residual mask distribution.  The compression lemma should be a pointwise-in-
`x` or integrated-in-`x` inequality over that generated cone:

```text
<w_x, q_K,x-q_C,x> >= 0.
```

Pointwise may still be too strong; S62 only proves that coordinatewise is too
strong.  But the algebraic object is now visible: a finite `64`-coordinate cone
of subset masks with zeta-transform structure.  This is a plausible place for
linear programming dual certificates or a Farkas separation search.  If a
separating context exists, it will be a real obstruction; if not, the dual
certificate should become the compression proof.
