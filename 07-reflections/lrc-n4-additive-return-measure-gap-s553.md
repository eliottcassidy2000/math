# LRC n=4: additive-return triples are solved

THM-392 solved the adjacent family `(1,q,q+1)`.  The next small non-adjacent
rows in the S552 scan were additive-return triples:

```text
(2,3,5), (2,5,7), (3,10,13), (3,5,8), ...
```

THM-393 now proves an exact formula for every primitive generator pair
`(a,b)`, with speeds `(a,b,a+b)`.

For `a,b` both odd:

```text
a+b = 0 mod 4:  M(a,b) = (ab - 1)/(16ab)
a+b = 2 mod 4:  M(a,b) = (ab + 3)/(16ab)
```

For exactly one even generator, with even `e`, odd `o`, and `c=a+b`:

```text
e = 0 mod 4:  M(a,b) = (oc + 1)/(16oc)
e = 2 mod 4:  M(a,b) = (oc - 3)/(16oc)
```

The payoff is the same measure gap inside this whole family:

```text
zero only at generators {1,2} -> speeds (1,2,3),
positive minimum only at generators {1,6} -> speeds (1,6,7), M=1/28.
```

So the first non-adjacent obstruction was not a counter-branch.  It folds back
into the same `1/28` story.

The proof grammar is the THM-392 moving-window argument with one extra layer.
Use the speed-`a` safe arcs

```text
t = (2h+1)/(2a) + u,       |u| <= 1/(4a).
```

Then `{a t}=1/2+a u`, and the pair of speeds `b,a+b` becomes a single moving
condition on `{b t}`.  For `u>=0`, `{b t}` must lie in `[3/4-au,3/4]`; for
`u<=0`, it must lie in `[1/4,1/4-au]`.  Since multiplication by `b` permutes
the odd residues modulo `2a`, the final sum is only a quarter-grid residue
calculation.  The deficit cases are exactly the rows where the moving window
approaches the quarter grid from outside.

This connects to the doubled-prime / parity-lift thread without proving that
thread wholesale.  The sharp positive additive-return row is generated by
`1+6=7`; the even generator `6=2*3` sits in the `e=2 mod 4` deficit case, and
the product `o(a+b)=7` is the smallest nonzero denominator after the AP
denominator `3`.

Concurrent-mainline note after rebasing over oracle S550o/S552: the resonance
energy sufficient condition and the doubled-apex spectral-gap computation are
compatible with this theorem.  In particular, oracle S552 identifies the
second minimax collar at n=4 with the doubled-apex surplus margin `1/28`.
THM-393 sees the same number from the measure side: after the AP denominator
`3`, the smallest nonzero additive-return deficit denominator is `7`, coming
from generators `{1,6}` and speeds `(1,6,7)`.  These are different observables
-- collar margin versus safe measure -- but they single out the same doubled
apex edge of the n=4 extremal basin.
