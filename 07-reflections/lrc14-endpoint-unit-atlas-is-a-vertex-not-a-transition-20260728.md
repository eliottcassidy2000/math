# Endpoint units are vertices, not a chronology

The endpoint guard-danger calculation repairs a real hole, but at a lower
categorical level than the one that now blocks LRC(14).

For the full `162 x 13` bank of positive endpoint rails and target sections,
one global normalization has content

```text
86814 = 2 * 3^2 * 7 * 13 * 53,
```

and `1770/2106` normalized slices are primitive seven-clock units.  Seven
fixed target sections work on all `84` source/clock cells.  The cleanest is
`q=0`: choose endpoint arrival `12` for sources `5,7` and endpoint arrival `0`
for every other source.  All `84` selected slices are units and the selected
bank retains the same global content.

This says that endpoint coefficient scarcity was not the obstruction.  A
source-dependent endpoint selector can furnish every vertex of the desired
atlas without local reprimitivization.

THM-2684 explains why that still does not furnish an edge.  Its complete
THM-2584 rail envelope is the three-tooth set

```text
[0,1/28) union [13/28,15/28) union [27/28,1).
```

Under the physical handoff `D(x)={13x}`, only equal-arrival teeth meet.  Every
positive raw three-return then repeats a shallow clock and violates the stored
nonconstant-edge grammar.  Intersecting the one-event unit atlas with more
downstream selectors cannot revive this empty support.

The loss ledger is therefore sharp:

```text
source object:  endpoint present-danger x delayed-danger common-x packet
target object:  globally primitive source/clock/section unit atlas
preserved:      positivity, source, clock, endpoint, section, global content
forgotten:      adjacent-event witness and its base-thirteen state transport
missing map:    a lawful transition between two selected endpoint vertices
hostile:        THM-2684's full-bank three-event D nilpotence
```

The next useful endpoint experiment must change one of the inputs to that
hostile: the parent carrier, the handoff, the boundary correspondence, or the
edge grammar.  Another selector on the same inherited `D` chain cannot help.

The cheapest first test has now been completed.  THM-2684's signed addendum
shows that the reflected handoff `x -> {-13x}` swaps the endpoint teeth and
fixes the central tooth, but its square is still `x -> {13^2x}`.  Its three
raw cylinders are therefore the same cylinders as for `D`, with reflected
arrival words, and the correctly reflected following shallow label again
equals the current owner.  The signed candidate is a genuine typed covariance,
not merely a cosmetic circle symmetry, but it still dies on the same clock
diagonal.  A next transporter must leave the unshifted signed-dilation family,
not merely reverse its orientation.
