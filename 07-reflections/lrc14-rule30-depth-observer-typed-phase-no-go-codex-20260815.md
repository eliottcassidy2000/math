## The exact centre-at-depth observer

Use the standard Rule 30 local rule

```text
x_(t+1,j)=x_(t,j-1) XOR (x_(t,j) OR x_(t,j+1))
```

from the single black cell `x_(0,0)=1` and zero elsewhere.  Let `r_t=x_(t,0)`.
The companion constructs `r_0,...,r_256` in two disjoint ways: a sparse set of
black sites and a dense zero-padded row array.  They agree exactly, beginning

```text
r_0...r_19 = 11011100110001011001.
```

For a THM-2349 profile `p=(1,b,c)`, the most literal depth observer is

```text
A(p)=(r_1,r_b,r_c).                                  (1)
```

On the complete profile universe, `(1)` has only four fibres:

| Rule 30 signature | rows | repeated `(b=1)` | strict `(b>1)` |
|---|---:|---:|---:|
| `(1,0,0)` | 36 | 0 | 36 |
| `(1,0,1)` | 36 | 0 | 36 |
| `(1,1,0)` | 51 | 8 | 43 |
| `(1,1,1)` | 42 | 7 | 35 |

Thus the coarse observer loses even the distinction between the repeated
two-owner branch and the strict branch in two fibres.  This is not evidence
of randomness; it is a finite exact quotient-loss witness.

There is a sharp dichotomy.  If one repairs `(1)` by retaining the full
profile,

```text
B(p)=(p,A(p)),                                        (2)
```

then projection to `p` is an inverse to `(2)`.  The repaired observer has
`165` fibres because it is the graph of a deterministic function of the old
row.  It adds no owner, phase, magnitude, or chronology information.

This proves only the following typed no-go:

```text
Rule30 bits at the valuation depths are either
  coarse enough to lose an existing owner type, or
  attached to the full profile and informationally redundant.
```

It does not exclude a product carrier with genuinely new seed ancestry,
neighboring columns, or an independently retained LRC sidecar.

## Additive binary phase no-go, with its exact boundary

The current target phase group in THM-2334/2344 is

```text
G=F_13^2.
```

If a binary word is used additively under XOR, its state group is an
elementary abelian two-group `F_2^m`.  Every homomorphism

```text
phi:F_13^2 -> F_2^m                                  (3)
```

is zero.  Indeed, for any `g`,

```text
0=phi(13g)=13 phi(g)=phi(g),                         (4)
```

because scalar multiplication by the odd integer `13` is the identity in an
exponent-two group.  The companion exhausts every possible basis image in
`F_2^m` for `1<=m<=16` (`131,070` candidate images); only zero has order
dividing both `13` and `2`.

The word **additively** is load-bearing.  Four bits have sixteen states, so a
nonlinear labelling can encode thirteen phase labels, and a permutation of
those states can contain an exact `13`-cycle.  The companion constructs that
cycle and checks its order.  Such a device is not refuted by `(3)`--`(4)`, but
its explicit thirteen-state labelling is precisely a retained phase sidecar;
it is not supplied by the scalar Rule 30 centre bit.

Consequently the correct repair is a product state

```text
(explicit F_13^2 phase, typed owner/endpoint data, Rule30 chronology state),
```

not a quotient of the odd phase into XOR bits.

## The THM-2344 same-axis obstruction

The group-order mismatch is only a typing obstruction.  THM-2344 supplies the
geometric hostile.  In its same-axis model, let the left endpoint have residue
index `a`, the deep step have index `m`, and the right endpoint have

```text
b=a+m mod 13.
```

When the transported-word dilation is divisible by `13`, every one of its
harmonics has the same target residue.  At target shift `t`, the full phase is

```text
a t - b t + m t = 0 mod 13.                          (5)
```

The companion checks `(5)` on all `13^4=28,561` inert-axis, endpoint, deep-step,
and target-shift rows and pins the immutable THM-2344 script/output hashes.
THM-2344 proves the analytic nonzero amplitude and the sharper nonconstant
twelve-tooth example: all `169` full twists remain equal.

Therefore adding an arbitrarily complicated Rule 30 word along only this one
translated coordinate cannot be justified as the missing LRC phase.  The
next positive object needs at least two independently translated base
coordinates, or a cross-coordinate coupling, exactly as THM-2344 states.

## Why the literal `165` rows cannot carry SOP2 or SOP3

Chernikov's theorem does not turn the finite row ledger into a model-theoretic
order property.  A relation on a finite vertex set cannot witness SOP3's
required infinite sequence.  If `d_i=d_j` for some `i<j`, the forward
condition gives `Q(d_i,d_i)`; substituting the same element at all three
vertices realizes the forbidden directed triangle.  Likewise a finite
parameter set cannot realize an SOP2 tree: an infinite antichain repeats a
parameter whose formula is individually consistent along a branch but would
have to be inconsistent with itself.

A valid use would first lift a scalar row to an infinite physical space of
witnesses, phases, clocks, or coefficient packets and verify the paper's
consistency, inconsistency, indiscernibility, and compactness hypotheses there.
The finite scalar row can index such a fibre; it cannot replace it.
