# LRC14 Cycle-Class Observability Scout - S237

The most useful remaining proof angle is not another analogy.  It is a matrix.

The S199/S200 residual stack already says the coarse ET+unit gate protects
status but leaves `15` strict-open route-mixed fibers with `38` packets.  S237
turns that into an observability matrix.  The first local split is:

```text
arc_topology_compact: 13/15 fibers
coarse_safe_stalk:    15/15 fibers
```

So the clean proof shape is not "reattach exact M" and not "use route as a
key."  It is:

```text
coarse ET+unit status gate
-> owner-strip arc topology
-> safe-component stalk only for the two topology collisions
-> primitive deck / magnitude / direct certificate as later exits
```

The Hodge-cycle side gives the companion shape.  If a residual survives the
observability ladder, it should be a row in a cycle-class matrix
`Cert(P)->H_res(P)`.  Named columns are AP/GW boundary cycles, endpoint-owner
boundaries, Ramanujan period characters, Haar zipper squares, observer-cut
boundaries, rectangle/hourglass cycles, partial-cube Theta classes, simplex
face boundaries, Roth-Minkowski walls, octahedral face curls, Toeplitz
noncollapse gates, and K33 state lifts.

The template matrix intentionally has one missing basis atom:

```text
phantom_f7_class
```

That is the right discipline for F7.  It should mean an explicit residual
coordinate outside the current certificate image, with a coefficient ring,
representative cochain, failed generator list, and THM-572/state-lift target.
It should not mean "the row looked hard."

The concurrent HYP-3067/HYP-3068 median-owner spine changes the next emitter:
rows should also carry root object, owner object, and median-center status
before the cycle-class image is interpreted.  Otherwise the matrix risks
making a clean rank statement about a quotient that is still missing the
center object needed to compare route triples.
