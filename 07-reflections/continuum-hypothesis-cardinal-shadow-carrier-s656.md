# Continuum Hypothesis as Cardinal-Shadow Carrier (S656)

The Continuum Hypothesis is not just a famous question about infinity.  In this
workspace it is the cleanest possible example of a scalar shadow that cannot
decide its own meaning.

The scalar is `2^aleph_0`.  The missing channel is the model of set theory:
constructible universe, forcing extension, forcing-axiom world, or bare ZFC.
Once that channel changes, the same base axioms can see CH or not-CH.  So CH is
the adult version of the repo's recurring finite lesson:

```text
same scalar, different carrier, different predicate behavior.
```

That is exactly HYP-2187's equinumerosity/equidecomposability split.  A count is
not a scissors class.  Two tournament families can share an `H` value and still
split by `beta1` or odd-cycle packets.  Two graph shadows can have the same size
and fail to preserve the property Royle/even actually cares about.  CH is this
phenomenon with the universe itself as the side channel.

It is also exactly HYP-2185's infinite-Go warning.  The finite partition count
`Z(1)` forgets pole order and ordinal boundary fuel.  The value `omega*r` is not
just a bigger count; it is the state that remains after the finite cutoff is no
longer honest.  In CH language, the ordinal scaffolding can be preserved while
generic reals are added.  In Go/LRC language, the boundary shell can be fixed
while the lift/carry data changes the floor behavior.

The freshest connection is S655.  The `(14,21)` Goldbach/Lemoine diagonal looks
important, and it is, but it is not the active LRC wall.  The wall is carried by
odd complement pairs `(1,13),(5,9),(3,11)`, even slack, and C=27 gcd shells.
CH gives the same discipline in a colder setting: the cardinal slogan is not
the proof object.  The proof object is the model, generic, or absoluteness
certificate that says which slogans survive.

This suggests a practical finite protocol.

First, build scalar twins.  Find two objects with the same residue, same `H`,
same edge count, or same shell mass, then make their retained fibers differ.
This is the finite version of forcing not-CH while preserving ordinals.

Second, run an absoluteness audit.  Which predicates survive the lift?  In LRC,
does floor status survive replacing least-positive `Res_27` by a carry lift?  In
unit distance, does traceability survive changing from graph-only to geometric
embedding data?  In tournaments, does `H` survive endpoint-transfer, beta, SCC,
and OCF packet refinement?

Third, identify a constructible section.  This is the canonical representative,
the `L`-like section: AP/Vstar for LRC, Moser spine for unit distance, transitive
base path for tournaments.  It is valuable only after a lift-conservativity
theorem says no generic fiber can change the predicate.

Fourth, promote the surviving labels into the sufficient statistic.  This is
the actual progress move.  For LRC `n=14`, the statistic still looks like

```text
(Res_27 proof atom, owner route, carry cocycle, Cprime window)
```

with S655's odd-wall/gcd-shell labels appended.  For unit distance it is

```text
(unit-edge count, direction support, spine traceability,
 embedding faithfulness, obstruction core)
```

For H-spectra it is

```text
(H, SCC packet, OCF coefficients, beta fibers, endpoint-transfer labels).
```

The S656 tournament over proof routes being transitive is fitting.  There is no
mysterious cyclic preference among routes here.  The order is almost a work
ethic:

```text
forcing/generic channel
> inner-model section
> absoluteness audit
> fiber bridge
> sufficient statistic
> ordinal boundary transfer
> raw numerology.
```

The new finite technique I want to keep is a "forcing jackknife."  Take a solved
or nearly solved scalar quotient, then add controlled generic side channels:
carry bits, owner labels, endpoint decorations, direction masks, or OCF packet
coefficients.  If the target predicate changes, the scalar was not absolute.  If
it does not change across a large enough lift family, that becomes evidence for
a conservativity theorem.  This is exactly how S611/S612/S654 have already been
probing LRC `n=14`; S656 just gives the set-theoretic name for the move.

So the CH thread is not a new bridge by numerology.  It is a vocabulary upgrade:
cardinality is the shadow, forcing is the lift, inner models are canonical
sections, absoluteness is the theorem we need, and sufficient statistics are the
finite replacement for "the universe of sets."
