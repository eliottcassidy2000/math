# {12,24} vs {7,21}: base + its uniquely-exceptional smallest-special-multiple — a cross-mandate rigidity analogy

## The two sets, grounded

**`{7,21}` — the permanent H-gaps (tournaments).** `H(T)` = #Hamiltonian paths = `I(Ω(T),2)`, multiplicative
over conflict-graph components, `H = ∏ I(Cᵢ,2)`. Single range-`k` flips give `H = 1+2^{k-1}`, so the
non-overlapping monoid is generated by `{1+2^k} = {3,5,9,17,…}`. `7 ∉` this monoid (`7 ≠ 1+2^k`) and is
**forbidden** (THM-029). `21 = 3·7` is forbidden by **inheritance** — it would need a value-`7` component
(THM-115). Crucially, among multiples of 7, **only `21=3·7` is permanent**: `35=5·7` is a gap at `n=6` but
**filled at `n=7`**. So `{7,21}` = base atom `7` + its *uniquely-persistent* multiple `3·7`.

**`{12,24}` — the tight far-runners (LRC).** For the family `{1..11,13,X}`, `M(S)=1/14` (tight) **iff
`X ∈ {12,24}`**, both attained at `q*=14` (the 14th-root grid). `X=12` gives the AP `{1..13}` (runners on the
nonzero 14th roots — perfect equidistribution); `X=24=2·12` is the second tight shape. And it is *uniquely*
so: doubling a single AP runner `j→2j` preserves tightness **only for `j=12`** (verified all `j`; `j=7→14`,
`8→16`, … all go loose), and `36=3·12`, `48=4·12` are loose. So `{12,24}` = base `12` + its
*uniquely-tight* multiple `2·12`.

## The shared shape (the real analogy)

Both are **"a base value + its uniquely-exceptional smallest-special-multiple"**, exhaustive and persistent:

| | tournament `{7,21}` | LRC `{12,24}` |
|---|---|---|
| base | `7` (forbidden atom) | `12` (AP completion) |
| companion | `21 = 3·7` | `24 = 2·12` |
| the multiplier | `3 = 1+2` (smallest monoid generator) | `2` (the 2-adic, `14=2·7`) |
| uniqueness | only `3·7` permanent (`5·7` transient) | only `2·12` tight (`3·12` loose) |
| the special grid | the `2`-power monoid `{1+2^k}` | the 14th-root grid `q*=14` |
| role | **forbidden** (H-gap) | **tight** (M=1/14) |
| mechanism | multiplicative over Ω-components | landing safely on the root grid |

The sharpest point is **uniqueness**: in each domain, among all multiples of the base, exactly *one* — the
one by the domain's *smallest special multiplier* — is also exceptional, and it *persists* (permanent gap /
q*=14 tight) while its neighbors are generic (transient gap / loose). That is a genuine structural match,
not a numeric coincidence.

## The `7` resonance (noted, not overclaimed)

`7` sits at the base on the tournament side and inside `14 = 2·7` on the LRC side (the danger band
`1/14 = 1/(2·7)`, the heptagon, THM-503). The tournament's smallest special multiplier is `3 = 1+2`; the
LRC's is `2` — and `14 = 2·7` literally is "the LRC multiplier × the tournament base." This is suggestive:
the LRC side reads like a **2-adic doubling** of the tournament's odd/`7` structure (consistent with the
project's `H = 1+2·(…)` Rédei parity living on the odd side, and LRC(14) on the even `2·7` side). But I have
**no bijection** — the mechanisms differ (component product vs grid-landing) and the roles are opposite
(forbidden vs tight). So I record it as a resonance to test, not a proven identity.

## Honest assessment

- **Real:** the "base + uniquely-exceptional smallest-special-multiple" rigidity shape, matched on both sides
  with the uniqueness verified (35 transient / 36 loose). Both are two-element persistent exceptional cores

- **Resonant, unproven:** the shared `7` and the `14 = 2·(tournament base)` reading; whether the project's

- **Different:** roles (forbidden vs tight), mechanisms (multiplicative-over-components vs root-grid-landing),
  multipliers (`3` vs `2`).
