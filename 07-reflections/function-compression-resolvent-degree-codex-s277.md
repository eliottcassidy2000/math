# Function Compression / Degree-4 Guardrail Reflection

Hypothesis: HYP-3150
Session: codex-2026-06-28-S277
Status: synthesis plus exact finite scout; not a proof.

The useful move in the prompt is to stop treating the small tournaments as
objects to admire and start treating them as function-compression tests.

The pair quartet is the cleanest rule:

```text
a+b, a*b  : safe under unordered pair quotient
a^b, b^a  : unsafe without ordered sidecar
```

That rule explains why the K3 kernel and the n=4 canary/filler packets keep
reappearing.  The K3 score quotient preserves the two-state transition matrix,
but it forgets the minority edge.  The n=4 fixed-path quotient preserves the
visible class table, but it forgets that `S` has a five-word fiber.  The
four-fixed-arc model repairs this by fixing the `c` canary/filler coordinate
and turning `x,y` into an exact two-bit source.  These are not separate
examples.  They are the same test: what function must the proof evaluate after
the quotient?

This also makes the Abel-Ruffini cue sharper.  Saying "degree <= 4" is not a
magic finish.  It is only meaningful if the objects entering the degree-4
bounded-core resolvent are the real proof functions, not scalar shadows that
silently erased ordered data.  The HYP-3132/HYP-3142 k=8 carrier is tractable
because it is quartic/biquadratic with odd-coordinate resurrection and finite
sidecars.  If the upstream packet loses tip/tail order, fiber-PGF curves, the
canary slice, or the Worpitzky descent word, the apparent degree-four problem
can be an illegal projection of a generic branch problem.

The next proof-facing target should therefore be a function-compression
certificate on every local quotient feeding the terminal packet:

```text
quotient input
  -> target function payload
  -> fiber-constant / reconstructed / annihilated / named debt
  -> degree ceiling allowed only after legality is certified
```

For HYP-3140 this means the whole fiber PGF and Q-masked PGF, not only
`Rprime`.  For HYP-3141 this means directed edge tail/tip roles and
commutator defects, not raw arcs.  For HYP-3142 this means even-fold plus
odd-coordinate resurrection, not a raw quartic slogan.  For HYP-3143 through
HYP-3149 this means exact-order, live-core, filler, canary, and collision-fiber
fields before any tournament class table is used as theorem evidence.

The strongest short form:

```text

functions being forgotten.
```
