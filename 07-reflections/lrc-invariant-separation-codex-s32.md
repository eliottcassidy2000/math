# LRC Invariant Separation

This session made the word "invariant" feel a little less mystical.  The
question is not only which number we compute from a runner set.  It is also
where that number forgets its address.

The max-min side is the cleanest parable.  Sumset excess, fold count, fold
profile, and gap pattern all sound structural, but they mix exact `M(S)` fibers
almost immediately.  Even the optimal denominator is not enough.  The first
thing in the small bank that behaves like a determinant is the optimal clearance
word: denominator, folded residues, active runners, and crossing source.  That
is a tiny finite object living at the actual witness time.

The LRC14 sector side says the same thing with a different accent.  `L_y` is
determined by the missed-count histogram because it is defined as a valuation of
that histogram.  But that is only the scalar shadow.  HYP-2648's measured state
word carries the transition data, sector bias, fold target, moving endpoint
address, and signed transport coordinates that matter before the valuation is
taken.

So the right mental model is a finite addressed sheaf over the wall arrangement.
Atoms have mass.  Atoms carry labels.  Scalar invariants are valuations of
labelled atoms.  The proof stalls whenever we value first and then try to
recover the label from a number that has already forgotten it.

This also clarifies the tournament-analysis habit.  The vertices do not have to
be runners.  Here the useful tournament is on quotient maps: addressed sheaf,
clearance word, measured state word, histogram, Freiman labels, fold profile,
raw speeds.  The edge direction is information loss.  A scalar invariant earns
trust only if its fibers do not mix the target, or if the missing address has
been explicitly reattached.

My current guess is that the LRC14 proof wants a template theorem.  High `L_y`
rows must have low-complexity measured words of a very specific type; the AP and
the one-step near-AP defect should be the only dangerous templates.  Everything
else should reveal its escape route in the address: Freiman slack, signed
coimage cancellation, far-element plateau, or a more chaotic state transition
word.
