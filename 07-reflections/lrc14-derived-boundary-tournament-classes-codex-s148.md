# LRC14 Derived Boundary Tournament Classes

S148 tries to make the AP/Goddyn-Wong resemblance more structural.

The useful commonality is not just that both rows are tight.  It is that both
are boundary-only at the denominator-14 unit points.  Their strict safe set has
zero Haar measure, but their closed threshold support still remembers the six
unit witnesses.  Near/K33 and the petals are different animals: they already
have positive open safe intervals.

The Tao-derived-multiplicative analogy suggests a good mental model.  AP is
the base boundary product.  Goddyn-Wong is a first derived deformation: remove
one tail speed, add its acceleration, and repair the interval by a nonunit
Jacobsthal window.  A future multi-acceleration is not "more of the same"
unless the second derivative cross term is named.  In this repo's language,
that cross term should appear as a splice, C27 transfer collision, unital
two-chart obstruction, K33 owner packet, or HYP-2908 state-lift obligation.

The concrete Tournament Analysis quotient uses vertices

```text
1,3,5,9,11,13
```

not runners.  For each pair of unit witnesses, every speed votes for the
witness where it is closer to the boundary.  Ties use the Hamiltonian path
`1 -> 3 -> 5 -> 9 -> 11 -> 13`.  This gives a six-vertex tournament.

The computation is a useful guardrail.  There are 56 unlabeled tournaments on
six vertices, but the AP single-residue mutation quotient realizes only four.
The named low frontier, including AP, GW, near/K33, both petals, and the two
S138 splices, all land in the transitive class.  So cyclic apex-pressure class
is an immediate reason a proposed "AP/GW-kind" boundary row is misclassified.

After rebasing, this should be read beside the incoming S145 derived atom
scout.  That scout uses runner-pressure, residue-gap, acceleration-gate, and
node-squared local tournaments.  It independently finds that only site `12` is
Jacobsthal-admissible under `W(v)=[14-v,27-2v]`, and that coarse pressure
shells are too weak while gate/node-squared profiles discriminate inside the
AP/GW fiber.  The two views fit: the apex-pressure isomorphism class is a
front filter; the S145 labelled profiles are the sharper internal lenses.

The later packet-tournament source-core synthesis gives the natural outer
container.  There the vertices are labelled packet-equivalence classes and the
theorem target is that the zero-regular-open source SCC is just the AP/GW
orbit.  This note's six-unit class filter is one face of that packet theorem.

This quotient is intentionally not complete.  It forgets speed magnitude and
off-apex intervals.  That is why exact `M`, Farey branch, C27 transfer, unital
chart, and K33 packet labels stay attached.  The point is not to replace those
labels; it is to insert an isomorphism-class filter before scalarization.

The Kuratowski mediant prompt fits the same rule.  A graph-count mediant or
edge-density average is a disjoint-union ledger unless it lifts to a new
minimal incidence object.  Likewise, an LRC row made by combining repairs is
not a third AP/GW atom unless its tournament packet is indecomposable in the
chosen quotient.

The summit route I would now try is:

```text
strict-Haar-zero threshold row
  -> denominator-14 unit boundary support
  -> first-derived AP profile
  -> transitive apex-pressure class
  -> C27/unital/Farey labelled packet
  -> AP or GW, unless a named cross packet opens petal/K33/state-lift escape.
```

The assumption challenge remains active.  The vertices are not naturally
runners.  For this layer, the honest vertices are unit witnesses, signed
boundary contacts, shell transfers, and proof obligations.  That quotient
preserves the boundary predicate and destroys runner identity; using it safely
means never forgetting what it destroyed.
