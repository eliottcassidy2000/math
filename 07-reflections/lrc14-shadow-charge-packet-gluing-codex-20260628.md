# LRC14 shadow-charge packet gluing

The useful concurrent signal today was not another standalone metaphor.  The
index-theorem/Borsuk-Ulam notes, upstream HYP-3401 three-coordinate exactness,
upstream HYP-3402 owner-current/tropical wall angles, the `Q(sqrt(-7))`
reframes, HYP-3310's C6 residue-magnitude split, HYP-3311's actual sheaf
instantiation, S293's analytic-lifting ledger, and the S294
`Tropical_Current_Ledger` coordination all point at the same discipline: a
creative frame is proof-useful only after it names the coordinate it preserves
and the coordinate it destroys.

The new HYP-3403 scout makes this test concrete on the HYP-3311 bank.  C3 unit
slots plus quadratic balance still leave the same mixed theorem-exit fiber.
That is the honest failure mode of the most attractive ambient reframes: they
describe the AP/Goddyn-Wong binding saddle, but they do not separate the
current packet ambiguity.

The surprise is how low the first actual repair sits.  The nonunit covering
residue word alone kills mixed kernel and route fibers on the curated bank.
The `v2` word alone does not.  This does not globalize residue into a theorem;
same-residue height-debt fibers already appear in the divisor-loaded tails.
But it changes the next test from "find a grand topological proof" to a finite
packet question:

```text
where does covering-residue exactness first fail as the bank expands,
and which missing sidecar repairs it?
```

The exact-height oracle and analytic-lifting ledger both separate everything,
but that is too expensive to be a first quotient.  Exact height should be used
as a debt detector for enlarged same-residue families, not as a disguised row
hash.  The analytic-lifting ledger is a final glue layer after residue, v2,
height, owner, and transfer fields are named.

The resulting proof interface is sharper:

```text
unit C3 / index shadow:
  binding saddle descriptor.

Q(sqrt(-7)) shadow:
  quadratic sign and residue organizer.

covering residue sheaf:
  first actual theorem-exit repair on the current bank.

v2 / height / endpoint owner:
  debt fields for enlarged same-residue rows and hinge moves.

Tropical_Current_Ledger:
  the audit layer once residue-word exactness first leaks.
```

The next rigorous step is to enlarge from the curated HYP-2969 bank to a
broader HYP-2963 sample and force a first failure of residue-word exactness,
or else record a stronger finite theorem with the exact sidecar boundary.
