The useful correction after reading the incoming S153 classifier is that
HYP-2961 already names the counterexample families.  What it did not yet make
fully operational is what "family" should mean.

This pass proposes:

```text
family = fixed-margin labelled packet class.
sporadic = bounded singleton after family parameters are removed.
```

The arXiv fixed-margin swap-chain paper was useful as a proof-pattern, not as
an LRC theorem.  Its count-sector versus Johnson-sector split maps cleanly to
the LRC split between scalar qdiv/q-cover data and non-scalar boundary owner,
source-spectrum, C27/K33, and gK8 moment labels.

The small script found no counterexample and no `qdiv>14` zero-open row.  It
did find two shared packet signatures, including the real covering family
signal `12->84` / `12->168`.  Both rows are discharged by positive Haar-open
mass, but they show how a packet family should be represented.

The challenged assumption is now sharper: a counterexample family is not a
parametric list of rows and not a raw tournament isomorphism class.  It is the
fiber of a labelled incidence packet whose margins retain the LRC predicate.
Raw runner names can be forgotten only after qdiv, Haar-open status,
source-spectrum ownership, C27/unital labels, and K33/moment outputs are
attached.

Remaining hard work:

```text
1. Add gK8/L_y moment coordinates to the packet signature.
2. Stress L1 with many 14-multiples.
3. Search inside fixed-margin swap fibers, not only named representatives.
4. Prove or refute the three-feature reduction:
   count sector + boundary/source sector + moment/K33 sector.
```

This still does not prove LRC14.  It does give a better falsification target:
find a `qdiv>14` fixed-margin packet class with zero strict-open mass, no
positive moment image, and no K33/unit/AP-GW owner label.
