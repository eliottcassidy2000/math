# Equioscillation as autocorrelation, not analogy

The incoming HYP-3214 result changes the meaning of the prompt.  The
connection between equioscillation and autocorrelation is not a poetic bridge:
for the level-7 cyclotomic packet it is literally the same kernel.

```text
Fejer F_7
  = (de Moivre cubic)^2
  = Chebyshev V_7 double-zero / equioscillation object
  = positive-definite Delsarte kernel
  = triangular autocorrelation of an AP interval
```

So the right abstraction is:

```text
equioscillation = where the primal certificate is tight
autocorrelation = how the Fourier/Gram payload proves positivity
```

The new HYP-3245 scout adds a finite LRC14 readout.  If we compare the
ordinary difference-autocorrelation of each HYP-3202 trap support against the
AP interval, every non-AP trap has the same coarse motion: short lags lose
mass and outward lags gain exactly the same mass.  This is the clean
"out-correlation" reading.  The AP row is the Fejer/interval autocorrelation
law; the decoys are outward transports of that pair mass.

The fine type still matters.  Plucker traps have more ripple and sign changes.
The clean split-block Green row is almost a monotone low-to-high transport.
The mixed row is a flat outward shift.  This is why HYP-3225 remains necessary:
autocorrelation tells us there was outward pair-mass transport, but Green,
Rayleigh, and Plucker sidecars tell us how that transport becomes a legal
proof discharge.

The abstract pattern I would now measure is a commutator between projections.
Equioscillation records a contact word: alternating or repeated tight nodes in
the primal/root picture.  Autocorrelation records the Gram image
`h -> h * reverse(h)`: positive Fourier mass and lag overlap.  Shell magic,
conductance, modular sidecars, and scale-normal recursion are further
projections of the same object.  The AP packet may be the unique point where
these projections commute; each non-AP trap is then a typed commutator whose
mass leaves short lags and must be discharged by Green/Rayleigh/Plucker or
modular/scale labels.
