# LRC14 Private-Label Firewall Reflection

HYP-3490 turns the HYP-3476 pair-current failure into a structural statement.
The seven random projection-edge exceptions are exactly the rows where every
E/branch-touched blocker label is private to one dead component.  That means
no adjacent-label carrier built only from low-rank E/branch gates can remove a
dead-cover projection edge, no matter how many gates are combined.

This is a better proof object than the pair enumeration.  Pair-current was a
finite experiment; private-label multiplicity is a lemma-shaped certificate.
It says the compression failure is not commutativity, mirror symmetry, or
branch balance.  The missing coordinate is incidence multiplicity: the labels
remember endpoint color but not shared projection support.

The result also keeps the terminal split clean.  AP currentless rows are
non-private and close under HYP-3476 two-gate currents.  `random_covering_031`
is the unique private row that also carries hard mirror-orbit debt, so it
now routes through the HYP-3484 forbidden-seam flow geometry, HYP-3483
recursion-flow comparator, HYP-3482 seam atlas, HYP-3481 topology atlas, and
HYP-3455 gluing clause.
The other six private rows have no hard orbit.  After the completed HYP-3478
audit, those six are not vague
"small-touch" debt: all dead components are singleton mirror-paired `B0`/`B1`
owner packets with edgeless projections and no owner imbalance.  HYP-3480 then
sharpens the route: all `14` target dead components have complete branch-unit
touches and all seven mirror pairs have mirror-compatible branch-unit gates.
The terminal split is clean rows `062/086/101`, asymmetric row `001`, and
cover-delta minimum-shadow rows `039/074`, with endpoint-spine,
exact-period/state-lift, or signed-SPEC as backup rather than another current
deletion over the same labels.

Formalization hook: add a producer lemma of the form "if all labels in the
chosen deletion set have dead-cover multiplicity one, then the dead-cover
projection edge set is unchanged."  Then HYP-3490 supplies the finite premise
for exactly the seven random rows; HYP-3484/HYP-3483/HYP-3482/HYP-3481
supplies the random031 forbidden-seam-flow/recursion/seam/topology packet and
HYP-3480/HYP-3478 supplies the geometric terminal packet for six of them.
