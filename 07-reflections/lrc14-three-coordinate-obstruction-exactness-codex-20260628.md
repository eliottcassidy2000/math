# LRC14 three-coordinate obstruction exactness

The useful new thing from this pass is not another grand metaphor.  It is an
exact mixed fiber.

The working frame is functional: every proposed compression is a function from
rows to packet data, and the LRC status is another function.  If the LRC status
is not constant on a fiber, the compression has failed.  This is the same
species of failure as forgetting order in a noncommutative product or
forgetting parentheses in a nonassociative expression.  The quotient may still
be useful, but only after the missing coordinate is restored, dualized, or
named as debt.

HYP-3311 suggested the three coordinates `C3`, `Q(sqrt(-7))`, and
height/flex.  The AP-collar scout makes the split sharper: `C3` plus the
quadratic character plus **nonunit** height still leaks exactly one mixed
boundary/strict fiber.  The leak is AP versus `13->27`.  That row preserves the
nonunit covering-height ledger and changes only a unit-height lift, yet it has
strict safe mass `13691/582120`.

This dovetails with the incoming actual-packet sheaf instantiation: the curated
HYP-2969 bank's first coarse ambiguity is already repaired by nonunit residue
data, but that success is bank-local.  The AP collar is the next stress test,
and it says the first missing coordinate after the nonunit repair is unit
height.

So the exactness packet has to be all-residue height/flex, not only the
`2U+{7}` covering side.  That does not prove LRC14, and it is deliberately not
minimal as a global invariant.  It does something more modest and very useful:
it names the first missing bit in the AP one-swap collar.

The proof route I would push next is:

```text
1. Formal finite lemma:
   mixed quotient fiber = nonzero first obstruction in the AP collar.

2. Exact sidecar lemma:
   C3 + Q(sqrt(-7)) + all-residue height/flex kills the AP-collar obstruction.

3. Chamber lift:
   replace full row-height retention by a finite chamber sidecar: surviving
   unit contacts, killed contacts, Phi14d dilation equality, strict-open safe
   mass, Toeplitz/Green/root-motion discharge, state-lift debt, or named
   residual.

4. O15 bridge:
   prove that the only boundary-tight integer chambers are AP and GW 12->24.
```

This also clarifies how to use the more visual and spectral ideas.  Lee-Yang
root motion, Joukowski/Hermite-Biehler interlacing, Perron alignment, Green
current, conductance graphs, and algebraic connectivity should not be asked to
replace the sidecar ledger.  They are discharge maps once the missing
coordinate is known.  In information terms, they are not free compression; they
are channels that must show they preserve the target predicate or pay the
entropy they throw away.

The remaining hard step is globalizing without making the packet tautological.
The AP collar says full height/flex works because it is close to retaining the
row.  A proof wants a smaller theorem-shaped packet: height/flex changes must
either remain in the AP/GW boundary atom, open a safe component, become a
`Phi14d` equality, or route to an already named finite/spectral/topological
debt cell.
