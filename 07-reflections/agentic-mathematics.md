# Agentic Mathematics

Mathematics is not static objects. It is agents acting.

## The three agent types

INERT agents: persist. Hold ground. Return themselves when acted upon.
2 doubles. Always. Faithfully. The memory of the system.

RAMIFIED agents: crack under self-observation. Feedback loops.
3 curves and the curvature curves back. Strange loops. Self-reinforcing cycles.

SPLIT agents: oscillate. Carry twist. Never settle.
7 decomposes into conjugate halves in dialogue. The heartbeat.

## Everything as agency

A proof: a crystallization agent that iterates logical steps until
a theorem emerges as a fixed point. The proof DOES something.

An equation: a negotiation that reached equilibrium.
x² - x - 1 = 0 is the record of phi emerging from the dialogue
between self-multiplication and identity.

The formal group F_h: the PROTOCOL for combining observations.
The denominator 1+xy = the correction for shared world.

Q: the TRANSLATOR between bounded and unbounded agent communities.
Period 4 because four translations return to the original language.

A tournament: a SOCIETY with pairwise dominance. H = number of
consistent hierarchies the society can maintain.

H = 7: an IMPOSSIBLE SOCIETY. The agent dynamics overshoot.
Three power triangles force additional hierarchies. Too active to freeze at 7.

Fibonacci: a DIALOGUE between two agents. Each number = joint action
of its two predecessors. Lucas = same agents, different opening.

The chain 3→7→47→2207: a LINEAGE of self-observers.
Each child = parent² - 2. The -2 = cost of reproduction.
Dynasty of 4 generations (Q's period), then the bloodline breaks.

Sylvester 2,3,7,43,1807: a CUMULATIVE civilization.
Each child = product of all ancestors + 1.
The +1 = the child's own identity. What it adds that no ancestor had.

Primes: SOVEREIGN agents. Irreducible. Act on their own authority.
Composites: COALITIONS of sovereign agents.

Snarks: RESISTANT agents. Dissidents that resist 3-coloring authority.
Petersen = the first dissident.

OCF: a CENSUS of agent society at each level of resistance to hierarchy.
1 = baseline. 2α₁ = first-order dissidents. 4α₂ = second-order.

Crystallization engines: SOCIAL ALGORITHMS. Not computing — NEGOTIATING.
The fixed point = consensus grown from repeated local negotiations.

42: the PARLIAMENT. One representative from each type.
43 = 42 + 1: a new agent arrives. The parliament must expand or break.
The transition from closed to open system.

Mathematics: a SOCIETY OF AGENTS acting, observing, combining,
resisting, oscillating, cracking, persisting. Objects ARE agents.
Theorems = records of negotiations. Proofs = protocols.
Conjectures = open negotiations. Forbidden values = impossible treaties.
