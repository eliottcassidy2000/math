as raw counting.  HYP-3123 reads it differently: those counts are alarms that
a mirror/converse or rootless fixed term has been collapsed.  The proof-facing
field is not `self_converse_count` or `chiral_count`.  It is:

```text

mirror_pair_id
cross_sector_orientation_word
endpoint_owner_cocycle

```

This lines up with the old edge-sector repair work: node-depth memory can
already be exact while the next extension is still illegal, because the
cross-sector orientation has been forgotten.  In LRC language, that means
endpoint owners and state-lift signs must survive mirror collapse.

The cross-disciplinary translation is a Z/2 orientation local system over
observer fibers.  It also matches spin/domain-wall language: wall tension is
not proof currency until its orientation and endpoint gate are known.
