# LRC14 History Niche-Carrier Recall Reflection

The repo history does have missed material, but not in the form of more famous
names to paste onto LRC14.  The useful residue is the packet grammar those
names already forced us to build.

The highest-value old thread is HYP-3474's colored partition-lattice audit.
HYP-3490 added a crisp new target predicate: private label multiplicity.  That
should be fed back into the Nerode-style quotient question immediately.  If a
small packet such as `(C,M,R)` or full colored gate word plus component-label
incidence reconstructs the firewall status, then the private-label lemma can
be connected to the existing colored-gate formalization interface instead of
living as a one-off graph fact.

The second live bridge is Menger/Green.  HYP-3490 is a cut theorem in disguise:
deleting labels of multiplicity one cannot change the unlabelled dead-cover
projection.  HYP-3484 is a different cut theorem: deleting the seam changes no
phase routing, while deleting the bypass moves exactly twelve witnesses.  That
suggests two electrical models, one for label-component incidence and one for
seam-complement phase flow.

The older p-adic and non-Archimedean prompts should be demoted to exact carry
tests.  The only trustworthy import from the recent obscure post is the
ordinary 2-adic unit-square guardrail; the rest is vocabulary.  HYP-3484's
`C=27` carry sidecar gives a real test bed: perturb seam owners while
preserving or breaking mod-27 and mod-14 endpoint data, then measure whether
the seam/bypass split persists.

Function compression is the meta-guardrail tying this together.  The failed
compressions are no longer just commutativity or associativity examples.  The
live target function is whether a quotient preserves projection-edge deletion
under touched-label unions.  If the quotient forgets label multiplicity, it is
illegal unless a sidecar reconstructs it.

The practical next session should not be another broad analogy sweep.  It
should build the firewall Nerode audit, then a short incidence-cut proof note.
Those are the two bridges most likely to make HYP-3490 easier to formalize.
