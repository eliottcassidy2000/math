# Duodecimal observer-extension payload - S219

The prompt's `48 + 12 = 56` cue needs one correction before it becomes useful:

```text
48 + 12 = 60.
```

But that correction exposes the better identity:

```text
U(6) = P(5) + U(5) - U(4)
     = 48 + 12 - 4
     = 56.
```

So the dozen is not the first-failure additive defect.  It is a control slice
with a four-class overlap.  The actual defect is

```text
U(6)-P(5)=8=U(5)-U(4)=SC(6)-U(4).
```

The cleanest normalization is denominator `14`:

```text
P(5)/U(6) = 12/14,
U(5)/U(6) = 3/14,
U(4)/U(6) = 1/14,
12/14 + 3/14 - 1/14 = 1.
```

This is why the duodecimal signal feels real without being the raw gap:

```text
P(4)=U(5)=SC(6)=12.
```

It is also why the exact relation should not be promoted to a recurrence.  The
next row breaks the simple difference law:

```text

```
