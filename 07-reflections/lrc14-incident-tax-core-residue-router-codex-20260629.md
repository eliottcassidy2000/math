# LRC14 Incident Tax-Core Residue Router

This pass was useful because it separated two statements that were easy to
confuse.

The strict HYP-3437 overlap core is the proof-safe object.  It asks for a
subset of odd blockers whose own internal overlap tax beats the negative naive
deficit.  That audit is positive, but the AP-with-84 row really has strict rank
`6`, and the canonical tower mostly sits at rank `5`.

The incident quotient is a different object.  It lets an owner collect the
whole tax of every overlap atom it touches.  That collapses all `59` negative
rows to incident core size `1` or `2`:

```text
strict_rescue_rank_hist={2:7,4:2,5:48,6:2}
incident_core_size_hist={1:10,2:49}
```

This is not a proof.  It forgets the co-owner coordinate that makes an atom
taxable.  The value is that the lost coordinate is now named and measured.  The
remaining bridge is not "find enough tax"; it is:

```text
touched overlap atom
  -> legal strict subset tax
  -> endpoint atom bridge or survivor-gate word bridge
```

Endpoint-only transfer is too weak.  It covers the deficit in only `6/59`
negative rows.  The canonical AP row is the warning case: the incident core
`(11,13)` beats the deficit with margin `37/45045`, but endpoint-bounded tax is
only `0.908143` of the deficit.  Therefore the next proof move has to bring in
HYP-3436/HYP-3438 bad-core and survivor-gate words, or route the row to the
HYP-3431 corridor-fence theorem.

The residue signal is still strong.  The dominant incident core is `(11,13)` in
`48/59` negative rows.  Almost all incident cores are unit binding cores
(`57/59`), with two ramified apex-7 exceptions.  In the user's language:

```text
binding runners = units = C3 / 7-adic skeleton
covering runners = evens + apex-7
hinge = two-adic endpoint/survivor transfer
```

The `Qsqrt(-7)` character is not redundant with the `C3` slot.  The dominant
two-owner core has one `qr_plus` and one `qr_minus` owner, so a residue-only
packet must keep this quadratic sidecar or name the loss.

After rebasing over HYP-3453, the sharper next task is no longer just
HYP-3439/HYP-3438-facing.  Classify the `53` endpoint-tax failures by asking
whether the touched incident atom can be recovered as a rank-`<=2`
survivor-gate transversal whenever the component-cover obstruction is nonempty.
I expect the canonical tower to go through HYP-3431/HYP-3452/HYP-3454
corridor-fence, AP-tail phase, and endpoint-clock data, with noncanonical
failures split between HYP-3453 gate escapes, HYP-3455 finite gate-gluing
clauses, owner-current labels, and state-lift/exact-period debt.

The special-function prompts remain useful only as firewall language.  Mertens
or Euler-Mascheroni budgets can rank which endpoint debts to try first.
Ramanujan-Soldner is a balance-root metaphor for locating a finite transition.
Sophie Germain factorization names quartic height-wall splits.  Krasner names
local p-adic branch stability.  HLW is a no-free-slider guard.  None of those
objects can replace strict overlap atoms or survivor-gate labels.
