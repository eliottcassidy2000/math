# Sixth-power collisions as rank-sensitive LRC sidecars

This note extends the S244/HYP-3076 sixth-power collision sidecar.  S244
already names the ternary equation as native support-six relation data and the
binary equation as a padded, rank-lowered square-cube shadow; S248 adds the
packet certificate fields needed before either equality is used inside
route-state closure.  The older S242/HYP-3060 Gaussian-owner /
diagonal-current split remains the local arithmetic reading.

The useful part of the sixth-power prompt is still the contrast between two
equal-sum interfaces.  A two-lane equality

```text
a^6 + b^6 = d^6 + e^6
```

looks rigid in the bounded positive scan.  Through unordered pairs up to `250`
there are no non-permutation collisions.  That does not prove a global
Diophantine theorem, but it is enough to make the LRC proof-carrier lesson
sharp: if a quotient sees a two-lane sixth-power equality, it should retain
the unordered pair identity, gcd/primitive status, shared-term filter, and CRT
residue word.  Otherwise it has created a hidden-pair slider.

The three-lane equality

```text
a^6 + b^6 + c^6 = d^6 + e^6 + f^6
```

behaves differently.  Up to `80`, the scout finds five collision certificates,
including the primitive certificate:

```text
3^6 + 19^6 + 22^6 = 10^6 + 15^6 + 23^6
```

None of the sample certificates share a term, so they are not just a hidden
two-lane cancellation in the bounded window.  For LRC this is a route-triple
warning: three lanes can balance a power mass without becoming the same proof
state.  A median proof interface that only sees the scalar sum is unsafe.

This is a cleaner way to merge Fermat-Catalan, Roth-Minkowski, Moser/fibbinary,
and S240 medianization than treating sixth powers as another large theorem
analogy.  Fermat-Catalan contributes hyperbolic pressure: sixth powers are in
the high-exponent regime, so primitive relations should carry curvature debt.
Roth-Minkowski contributes the height fence: a relation among sixth powers
should be a low-height wall with primitive support and exceptional
approximant data, not just a numerical equality.  Moser/fibbinary and the
partial-cube/simplex lane contribute the route-triple geometry: three-lane
relations are exactly the kind of object that should be medianized only after
sidecars are closed.  HYP-3075's Hurwitz-Markov-Pell reservation supplies the
same meta-rule from another Diophantine direction: keep the address before
using the scalar coincidence.

The tournament-analysis assumption challenge is important here.  The vertices
are not runners, integers, or powers.  They are proof obligations:
two-lane rigidity gate, three-lane resonance graph, residue word, height
fence, route-state median sidecar, and raw scalar shadow.  Under the rank-2
gauge the rigidity gate outranks the resonance graph; under the rank-3 gauge
the order flips.  The raw equal-sum scalar is last in both gauges.
