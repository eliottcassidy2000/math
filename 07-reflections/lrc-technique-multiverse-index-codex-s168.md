# LRC Technique Multiverse Index Reflection

Session: codex-2026-06-24-S168

The useful shift in this pass was to stop asking for the next clever scalar
and instead index the carriers that have already survived repeated attacks.
The repo has learned the same lesson from many directions: tournament
isomorphism classes, divisor signatures, edge densities, Haar margins, Fejer
floating values, denominator charts, and source spectra are all useful only
after their forgotten coordinates are named.

## What Changed

The broad `LTI-*` index and the tournament-specific `LTT-*` index already had
the main material, but they were split by surface:

```text
LTI: broad LRC proof technology
LTT: tournament/metagraph-focused proof technology
```

The new `LTM-*` annex adds a third role:

```text
LTM: cross-surface cards that are allowed to be speculative, synthetic, and
     immediately reusable by future agents.
```

It deliberately pulls back in old tournament machinery alongside newer LRC14
proof infrastructure: A000568 source fibers, fixed Hamiltonian path tilings,
SC-NS metagraphs, OCF coimages, path homology, Walsh channels, qdiv/Farey
packets, Haar zeta switches, Fejer and Ramanujan certificates, mu and
mu^2/phi guardrails, large-sieve/smoothing/Kaczynski lanes, K33/C27 state
lifts, graph-minor analogies, octahedral currents, unit-distance endpoint
ears, irreducibility no-lift language, exact rational interval engines, Lean
cores, and forum/checkpoint workflow.

## Tournament Analysis

The vertices for the top-level tournament are technique families, not runners.
The pairwise observable is retained LRC payload:

```text
predicate, exact_scale, topology, endpoint, arithmetic, harmonic, metagraph,
formal, residual, transfer
```

The gauge rotates the priority order by each pair and orients toward the first
retained dimension that differs.  This is intentionally convoluted: it prevents
the family tournament from pretending that one scalar retention score settles
every comparison.

The output is strongly connected:

```text
score_hist={2: 1, 3: 1, 4: 4, 5: 3}
directed_3cycles=26
scc_sizes=[9]
edge_flips_against_tie_path=21
hamiltonian_path_count=2397
```

Interpretation: the technique space has real cycles.  Proof sheaves beat
arithmetic when exactness is the question; arithmetic beats harmonic estimates
when prime-power side labels are missing; harmonic certificates beat topology
when an interval proof has a formal dual; topology beats tournament shadows
when strict-open versus boundary-only is the predicate; tournament/metagraph
machinery beats computation when it exposes a lost vertex set.  No single
family is the summit.

## Assumption Challenge

The annex explicitly rejects runner-first tournament thinking.  Candidate
vertices for future passes include:

```text
runners, gaps, endpoint owners, fixed circle sections, section boundaries,
wall-crossing events, residues, cover arcs, Fourier modes, Haar rectangles,
matroid circuits, Fejer atom banks, state-lift obligations, and proof
obligations.
```

The preserved predicate changes with the vertex set.  A runner tournament
preserves a phase comparison; a Haar-rectangle tournament preserves local
product descent; a Fejer-bank tournament preserves dual certificate structure;
a state-lift tournament preserves hidden residual data.  The wrong vertex set
does not merely weaken a proof; it changes the theorem being tested.

## New Guardrail

Every future technique contribution should answer one exact question before
it asks for a computation:

```text
What LRC predicate is constant on the quotient fibers, reconstructible from
retained data, annihilated by a dual certificate, or routed to a named residual?
```

If the answer is missing, the technique is still welcome in the multiverse
annex, but only as a guardrail or diagnostic, not as a proof step.
