# LRC14 Hurwitz Finite-Address Branch-Closure Spine

The useful thing about revisiting Hurwitz is not the inequality itself.  It is
the sharpness mechanism.  The number `sqrt(5)` is visible, but the proof-facing
object is the finite continued-fraction/Markov address that makes the
golden-ratio class sharp.  That is now the right reading of the recent LRC14
stack.

The incoming work has converged on the same shape from several directions:

- HYP-3075: Hurwitz/Markov/Pell/cannonball and modular cusp tails need finite
  address sidecars.
- HYP-3077: legal median centers are often schedulers, not terminal atoms.
- HYP-3078/HYP-3079: q-series tails are legal only after finite principal
  parts, zero/pole persistence, and Lean-facing obligations are named.
- HYP-3080: sixth-power equalities need tuple/rank/residue certificates.
- HYP-3081/HYP-3082: quotient contraction is illegal if it creates a naked
  Robbins bridge; the current HYP-2963 bank has no naked bridges only after
  sidecars are attached.
- HYP-3084: Morita-gamma and Erdos-Turan discrepancy carriers are legal only
  as p-adic/local-field address sidecars with finite cutoff, normalization,
  Hensel seed, and terminal exit data attached.

So the remaining LRC14 proof is not "find one scalar."  It is:

```text
no-apex row
  -> direct t=1/14 witness

low-apex/top-balanced covering row
  -> finite-address packet
  -> protected branch graph
  -> terminal discharge or named residual
  -> Lean/formal sidecar closure
```

The remaining proof debt is explicit:

1. prove the global normalizer into the finite-address packet bank or a strict
   descent/exception atlas, now sharpened by the S59 covering-bound redirect
   and S31af THM-573: no-multiple-of-14 rows are witnessed at `t=1/14`,
   rows with at least seven `7`-divisible speeds are closed by the level-7
   lift sieve, and the live residual is low-apex/top-balanced with at most six
   `7`-multiples after q-witness and one-large-speed exits;
2. prove the covering-family discharge for the covering rows seen by HYP-3082;
3. define and discharge the three K33/THM-572 state-lift rows or make F7 a real
   residual theorem;
4. instantiate non-tautological Lean packet records with the q-cusp, branch,
   median, and terminal-exit fields filled;
5. rerun no-naked-bridge checks whenever the packet bank or sidecar vocabulary
   expands.

The creative synthesis is that every proof route has a principal part.  For a
modular function this is literal finite polar debt.  For LRC14 it is the finite
list of boundary atoms, endpoint owners, primitive clocks, branch kernels,
Hensel seeds, and residual exits that must be paid before an infinite family
argument can be trusted.  AP/GW are the closed boundary principal part;
strict-open rows are the positive tail; K33/THM-572/F7 are the named polar
coefficients still requiring theorem-level discharge.

Incoming S59 improves the priority order: the additive census is an easy-side
extremal, not the proof bottleneck.  The first FA-BC ledger should therefore
start with `apex_divisible_by_14_flag`: false gives the direct `t=1/14`
witness; true then records `multiple_of_7_profile`,
`level7_lift_sieve_status`, covering-margin aliasing status,
low-apex/top-balanced status, gamma-trick / Node 3 / bounded-atlas status,
p-adic/discrepancy sidecar status, and the protected branch-graph handoff.
The S31af covering-margin scout is a useful negative result: a uniform
`>1/13` margin cannot be assumed because dilated/AP aliasing can sit at the
threshold scale.

Incoming THM-576/HYP-3090 adds the positive cap-side result: pairwise
avoidance explains the triangular caps for `k>=10`; the live cap residue is
now the two deviation constants (`k=8,9`) plus the first higher-order break.
The FA-BC ledger should retain `cap_ratio_or_deviation_status` before any
moment/cap scalar is treated as a theorem object.

Incoming HYP-3091 adds the next useful split: positive safe mass is not the
proof object, because K33 rows are positive too.  The ledger has to record
`grid_class`, active binder owner word, and endpoint-owner transition word, so
`nested_refinement` rows can feed O2 covering discharge while `cross_handoff`
rows feed O3/THM-572 lift debt.

Incoming HYP-3088/HYP-3089 then add the normalized-arc and paper/V* target:
LRC14 is the composite `k+1=14=2*7` case where the field interpolation shortcut
fails, and Conjecture 7.1(13) becomes a uniform largest-lonely-arc floor for
the normalized slow/ruler-coordinate lonely carrier.  The FA-BC ledger should therefore record
`polynomial_composite_lift_status`, `direct_lonely_arc_count_status`, and
`largest_lonely_arc_floor` alongside the O2/O3 shuttle fields.
