The long synthesis pass suggests that the most fundamental object is not a
runner set, a residue multiset, a scalar minimum, or even a standalone
tournament class.  It is a retained source/kernel object.  The same shape
appears in several disconnected-looking threads:

- signed LRC needs a cut that selects shell partners;
- additive-energy projections need conjugate root-of-unity side channels;

The challenged assumption was: "If we use tournament analysis for 13 runners,
the vertices should be the 13 runners."  This session rejects that as the
default.  Runners, gaps, fixed sections, section boundaries, wall crossings,
residues, cover arcs, Fourier modes, exact-period packets, and proof
obligations were all considered.  The chosen tournament vertices are proof
lenses: qdiv gate, exact M/Farey node, Haar-Baire boundary, phase-spectrum
source walk, C27 carry, unital/affine packet, K33 state lift, gK8/L_y moment
image, PH-rank residual atlas, and raw scalar shadow.

The preserved predicate is: "does this quotient still know where the LRC
witness source or boundary debt lives?"  The destroyed information is exact row
identity, fine wall order, and exact denominator data unless reattached through
the pullback.  That is why the raw tournament impostors and C27 shell aliases
are useful failures: they show which quotients destroy too much.

The resulting protocol is HYP-2953.  It asks the bounded census to classify
rows by a source-spectrum pullback:

```text

+ Haar/Baire boundary owner

```

The desired empty bucket is "unnamed source kernel."  AP and Goddyn-Wong are
named zero-open denominator-14 source kernels; positive Haar mass, C27 petal
discharge, gK8/L_y slack, and K33/state lift are named exits.  A counterexample
has become much more concrete: a primitive row that lands in the unnamed bucket
after all these retained labels agree.

This does not prove LRC14.  It changes the next search from "find a lower M"
to "find a new source kernel."  That is a better target because it preserves
the novelty that earlier scalar and tournament shadows lost.
