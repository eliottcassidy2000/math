# LRC14 Labelled Packet Classification Theorem

The useful shift from the gauntlet plus boundary-moment bridge is that the
counterexample hunt now has a named last survivor.

Rebased over HYP-2960/HYP-2961/HYP-2962, this is the packet-level statement one
layer above the strict counterexample decision tree: HYP-2960 closes much of
the `qdiv=14` skeleton-gate subclassifier, HYP-2961 separates equality atoms
from actual `M<1/14` counterexample families, and HYP-2962 makes the
fixed-margin packet signature executable.

An LRC14 counterexample cannot be a qdiv witness row, a Haar-open row, AP/GW
boundary-only, a unit petal, a positive K33 seed, or a covering row with
positive strictness.  After S151, the only honest target is:

```text
F6 = a zero-open non-migrating boundary-moment kernel.
```

The arXiv fixed-margin swap-chain paper gives a proof architecture rather than
a theorem we can directly cite as an LRC result.  Its productive pattern is:

```text
fixed binary relation margins
  -> local swaps
  -> two-row heat-bath comparison
  -> three-row reduction
  -> scalar count sector plus Johnson harmonic sectors.
```

That maps cleanly onto the current LRC packet language:

```text
scalar sector:
  qdiv, exact M/Farey node, Haar mass

Johnson sectors:
  boundary owners, C27 shells, unital chart addresses, K33/state-lift debt
```

This is exactly the gap in the current proof route.  We can classify the scalar
sector locally with qdiv and Haar fronts.  What remains is proving the
non-scalar owner sectors are complete: every packet swap either migrates to a
safe family F0-F5 or lands in an explicit F6/F7 obligation.

## Practical Proof Order

1. Build the fixed-margin packet matrix.

   Rows should be speeds or local packet carriers.  Columns should be proof
   lenses: q-clock coverage, denominator-14 boundary owner, C27 shell,
   unital pair, K33 owner, exact-period unit, and boundary-moment sign.

2. Prove packet-swap connectivity.

   This is the direct analogue of the binary fixed-margin swap chain.  The
   point is not mixing; the point is that local 2x2 swaps should enumerate all
   rows with the same packet margins.

3. Reduce to three packet rows.

   This is the dangerous step.  If the reduction fails, the failure itself is a
   new F7 Johnson sector.

4. Audit three-row sectors.

   Scalar sectors should reproduce qdiv/exact M/Haar.  Non-scalar sectors
   should be exactly the known owner labels: AP/GW boundary, unit petals,
   K33/state lift, or covering moment signs.

5. Close F6 by boundary moments.

   Any zero-open non-migrating covering packet must either gain gK8/L_y slack
   or construct the HYP-2908/THM-572 state-lift contradiction.

## Guardrail

The fixed-margin theorem is not an excuse to forget LRC labels.  Its lesson is
the opposite: binary relations with fixed margins are tractable after one
knows which margins and sectors to keep.  For LRC14, the margins must retain
the observer-source predicate and the owner/state-lift labels.

The Tournament Analysis quotient deliberately does not use runners as
vertices.  I considered runners, gaps, denominator-14 sections, boundary-owner
events, wall crossings, residues, cover arcs, Fourier modes, circuit-like
packet dependencies, and proof obligations.  The chosen vertices are proof
families/obligations because they preserve the LRC observer-source predicate
and the route labels; they discard raw runner order and magnitude details once
those details have already been converted into exact scale, Haar status, and
owner/state-lift labels.
