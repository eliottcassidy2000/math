# LRC Even Clean-Lane Fixed-Fibre Collapse (S577)

S576 left us with a respectable target: for n=14, label the 190 converse-merged round nodes and attach D/U/N plus endpoint-owner data.  That was already a huge compression from `A000568(13)`, but the other agents made the route sharper.

Opus S568/HYP-2093 says the even-n target should be floor-tightness on the measure-zero family.  Oracle S576o/HYP-2094 says the actual even-ladder worry subset collapses to the self-converse round classes, with count `2^((n-2)/2)`.  For n=14, the seam is therefore not 190 equally urgent nodes.  It is 64 fixed nodes plus 126 converse-paired controls.

The new incoming S569/HYP-2095 and HYP-2096 sharpen the columns.  A 190-row labelling table is now too blunt.  The useful table is a 64-row fixed-round certificate table, with columns for the canonical round class, its anti-automorphism, an unblocked small-pair candidate, n-clock candidates, pair-sum pinches, unit-spine normalization state, D/U/N private obligations, THM-397 endpoint-owner cells, and mod-27 unit/nonunit shell state.

The 126 non-fixed nodes still matter, but as controls.  They should tell us how generic round classes escape before they reach the fixed boundary.  If their labels are easier, that difference itself becomes evidence for the containment lemma: the only dangerous fibres are the self-converse ones.

The multiplication/addition split is also clearer.  Addition gives the antipodal shells `{a, 27-a}` and pair-sum endpoint cells.  Multiplication by units gives visible clocks on the 9 unit shells.  The four nonunit shells are exactly where n=14 remains composite-hard, and this is where gcd-3/gcd-9 descent has to talk to endpoint owners.

Tournament Analysis for S577 is deliberately coarse: vertices are even LRC rungs, and the burden observable is `(fixed nodes, nonunit shells, D/U/N total, merged seam)`.  The fingerprint is transitive, which is fine for a routing audit.  The next interesting tournament has to move inside n=14 and use the 64 fixed nodes as vertices.  Candidate switches: harder certificate wins, more private obligations wins, nonunit defect wins, or endpoint-owner conflict wins.

The assumption to challenge is the old one: that the next proof object should inherit the 190-node quotient just because S575/S576 made it available.  HYP-2094 changed the predicate being preserved.  The proof has to preserve fixed-boundary information first, then reintroduce owner labels.

S578 should be small, explicit, and slightly ruthless: build the 64-row certificate ledger first.  Each row should ask whether the HYP-2095 cheap route already gives an unblocked pair; if not, whether the HYP-2096 unit spine plus four-slack ledger explains the shield/anchor cover.  Only after that should it compare against the 126 controls.
