# LRC Reset Horizon as a Speed-Family Gauge

The prompt reframes time in LRC in the right order.  A time snapshot is easy:
measure the present circular gaps, threshold ties, observer source status,
endpoint pressure, and half-turn tournament.  But the snapshot is not the
object.  The object is the orbit generated by the speed ratios.

For a chosen observer or runner frame `i`, the relevant velocity data are the
relative speeds

```text
Delta_i = { v_j - v_i : j != i }.
```

The relative configuration returns to its initial state at a positive time `P`
iff

```text
P * (v_j - v_i) is an integer for every j.
```

Equivalently, the relative speeds are commensurable: after factoring out a
common real unit `alpha_i`, they are an integer vector

```text
v_j - v_i = alpha_i * a_j,  a_j in Z.
```

With `gcd(a_j)=1`, the minimal relative reset period is `P_i = 1/alpha_i`.
If no such one-dimensional rational relation exists, the reset horizon is
infinite and the orbit is not a closed word; it is dense in a higher-rank
subtorus determined by the `Q`-rank of `Delta_i`.

So the time model now has three stacked clock layers:

```text
outer clock:     reset horizon / Q-rank of the relative speed line
endpoint clock:  walls ||(v_j-v_i)t|| = 1/n
phase clock:     half-turn walls t = m/(2 |(v_j-v_i)-(v_k-v_i)|)
```

T562/T563 separated endpoint and half-turn clocks.  This note adds the outer
clock: the finite period in which those wall systems close, or the proof that
they never close.

## Why This Is Not Just "Period Equals 1"

In the standard integer-normalized LRC model with a stationary observer and
primitive integer speeds, the absolute reset period is normalized away.  All
positions return at `t=1`.  That does not make the reset idea trivial.  It
means the useful invariant is not only the physical length of the period, but
the complexity of the closed word inside it:

```text
endpoint grid size:       roughly n * lcm(relative speeds)
half-turn wall grid size: roughly 2 * lcm(pairwise speed differences)
wrap reset count:         sum of positive relative speeds, after normalization
gap-race ledger size:     number and type of wrap resets before the period closes
```

If the speeds are real or only specified up to ratios, the first dichotomy is
sharper:

```text
commensurable family:    finite closed word, reset horizon P
incommensurable family:  no exact total reset, dense or quasiperiodic closure
```

The latter is not automatically harder.  If the orbit closure intersects the
open lonely target, density gives a hit.  The hard case is the thin
commensurable or boundary-only family where the closed word can repeatedly
thread the bad cells and must be repaired by compactified walls.

## Categorizing Speed Sets

For "does each runner ever become lonely?", do not use a single global period
unless the observer is fixed.  Each runner has its own relative frame.  A useful
speed-family fingerprint is the vector

```text
for each runner i:
  rank_i          = Q-rank of {v_j - v_i}
  P_i             = minimal relative reset period, or infinity
  endpoint_Q_i    = denominator/grid height for ||(v_j-v_i)t|| = 1/n
  phase_Q_i       = denominator/grid height for half-turn pair walls
  reset_ledger_i  = distribution of wrap resets by owner/residue/gap-race type
```

For integer speed sets, `rank_i=1` and `P_i` is finite in every frame, but the
grid heights and reset ledgers can vary strongly by observer.  That variation
is exactly where "each runner once becomes lonely" should be measured.  For
real speed families, `rank_i>1` separates no-reset systems from closed-word
systems before endpoint pressure is even considered.

This also clarifies scaling.  Multiplying all speeds by a constant rescales
time and changes physical `P_i`, but it does not change the projective speed
family.  The invariant should therefore be recorded either after a chosen
normalization or as a pair:

```text
(projective commensurability class, normalized reset complexity).
```

## Tournament Analysis Lens

Tournament vertices do not have to be runners.  Here are better candidates for
this time-model question:

```text
observer frames i
relative reset events
endpoint grid packets
half-turn corridor cells
commensurability relation generators
wrap-reset owners
proof obligations in the reset ledger
```

One concrete switchboard:

```text
vertices:
  observer frames i

pairwise observable:
  compare the normalized reset complexity needed before runner i versus runner j
  first reaches a closed/open lonely target

switch:
  i -> j if i has the shorter or lower-complexity certified horizon

tie Hamiltonian path:
  speed order, then index order

fingerprints:
  score histogram, SCCs, directed cycles, Hamiltonian path count, edge flips
  under scale/gate/CRT lifts
```

Another switchboard puts endpoint packets or wrap-reset owners as vertices and
orients by which packet protects, delays, or forces the next reset-wall hit.
That version preserves the LRC predicate less directly, but it may preserve the
proof object in HYP-1995: a compactified reset wall with both adjacent gaps
long.

## Assumption Challenge

The challenged assumption is that LRC time should be modeled as a single
parameter `t` after speeds are fixed.  That is true dynamically but incomplete
structurally.  The better quotient is:

```text
speed vector -> projective relative-speed family -> reset horizon or rank ->
finite word / dense closure -> endpoint and phase clock overlays -> witness.
```

What this quotient preserves:

```text
whether a runner frame has a finite closed search period, and how complicated
the endpoint/phase/reset ledger is inside that period.
```

What it destroys:

```text
absolute physical time scale, and some pointwise snapshot geometry unless the
endpoint and phase clocks are carried along as labels.
```

The research bet is that hard LRC families are not just "bad snapshots."  They
are low-rank, high-denominator closed words with unusually structured reset
ledgers.  Total reset length, or the proof that no total reset exists, is a
natural first coordinate for sorting those families.
