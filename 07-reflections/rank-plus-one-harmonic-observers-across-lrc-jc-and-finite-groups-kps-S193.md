## 2. Conditioning and rigidity are different resources

For normalized positive masks

```text
m_(a,b)=a delta_0+b delta_alpha-delta_beta,
a,b>0, a+b=1,                                       (5)
```

every weight choice detects nonconstancy.  Two special choices expose a
real tradeoff.

Equal rational weights have a smaller worst Fourier multiplier but all 169
eigenvalues are distinct.  Hence the full operator centralizer is the
polynomial algebra in one three-site convolution observable.

The maximin weights are

```text
y=2cos(2*pi/13),
(a_*,b_*)=(y/(y+1),1/(y+1)).                         (6)
```

They improve the amplitude gap by about 51 percent, but exactly thirteen
frequency pairs collide.  The centralizer dimension rises from `169` to
`195`.  The collision classes are

```text
{(u,u+1),(u+3,u+2)}, u in F13.                       (7)
```

Generic weights arbitrarily close to (6) recover simple spectrum, so this is
an exact-optimizer singularity rather than a broad incompatibility.  The
research lesson is precise:

```text
use equal weights when operation rigidity matters;
use cyclotomic weights when quantitative separation matters.          (8)
```

## 3. The exact finite-group generalization

THM-3668 shows that the mechanism is not essentially abelian.  If a finite
group needs `d` generators, every mean-zero convolution mask with only
constant harmonic functions needs at least `d+1` support sites.  A positive
`d+1`-site mask from any minimal generating tuple attains the bound.

The lower bound uses the proper subgroup generated by support differences.
The upper bound is the maximum-modulus principle on a strongly connected
weighted Cayley digraph.  Fourier characters are replaced by nontrivial
unitary irreducibles, on which triangle-equality rigidity makes every matrix
multiplier invertible.

This is a legitimate connection to the finite-quotient/group-theory lane.
It is **not** a route to non-soficity: on an infinite group a bounded harmonic
function need not attain its supremum, and a nontrivial Poisson boundary can
survive.  Finiteness is the destroyed coordinate.

## 4. The planar Jacobian connection and its missing sidecar

THM-3642's universal fourth-stable functional is

```text
lambda(P)=5/18 P(-1)-P(0)+13/18 P(1).               (9)
```

Thus `lambda(P)=0` says that the central branch value is a **positive weighted
average** of the two endpoint values.  This is the same local predicate as
(2), with unequal weights, and THM-3641's ordinary charts give a family of
such barycentric stencils.

The connection map is:

```text
source object:  a twist profile on a finite group;
target object:  a retained stable-jet profile on collision branches;
preserved predicate: vanishing of a positive mean-zero three-site stencil;
source closure: the translates form a strongly connected Cayley graph;
target loss: only one isolated retained triple is currently typed.     (10)
```

That last line blocks any JC consequence.  The three branch values in (9)
are not yet values of one profile transported by a native group action, and
there is no proved family of overlapping triples on which maximum-modulus
propagation is lawful.

The cheapest decisive JC experiment suggested by the LRC work is therefore:

1. generate all ordinary THM-3641 retained triples under admissible source
   reparametrizations that preserve the same stable coefficient;
2. use branch germs, not polynomials or folds, as vertices;
3. orient a weighted hyperedge from the averaged branch to its two parents;
4. test whether the resulting operation graph is strongly connected;
5. if it is, audit whether representative changes preserve the same `J_4`
   value rather than only its three-point quotient.

A positive result would turn all-cell zero debt into a global harmonic
rigidity statement.  Until the overlap/transport sidecar exists, the
similarity is inspiration only and gives neither a Keller pair nor a JC(2)
counterexample.

## 5. Horizontal-endomorphism analogy

THM-3665's simple spectrum gives

```text
Cent_End(C_m)=C[C_m].                                (11)
```

This is a finite exact analogue of the horizontal-endomorphism rigidity that
appears in the rank-two factorial/E-function discussion: one sparse
observable forces every commuting endomorphism to be generated by it.  The
map preserves the centralizer predicate but destroys differential algebra,
monodromy, and transcendence data.  Consequently (11) supplies a model and a
hostile test for proposed rigidity statements, not an implication toward
FC(2), E-functions, Furter rigidity, or the Jacobian conjecture.

THM-3667 is a useful warning for that lane: improving quantitative separation
can introduce exact spectral multiplicities and enlarge the horizontal
centralizer.  Any capacity optimization should be audited for this loss.
