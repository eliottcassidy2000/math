# Sparse-tail deficits are a generated-context basis problem

**codex-2026-06-20-S64.**  The live frontier after HYP-2700 is not "prove
consecutive dominates every residual coordinate."  That statement is already
false in HYP-2697.  The useful question is narrower: do the sparse coordinate
wins survive when the residual weights are generated by actual context
carriers?

The exact scout says no on the tested frontier.  Full bounded size `3` has many
raw coordinate wins, and the near-consecutive frontiers of sizes `4..6` have the
expected sparse failures.  The wins are geometrically legible in the `Z/7`
alphabet: mainly `|R|=3` gap signature `(1,2,4)`, adjacent-pair collars
`(1,6)`, and small packed collars such as `(1,1,5)` or `(1,1,1,4)`.  These are
not full-cover events; they are low-layer packets created by asking for named
colors.

Once a generated context is present, the failures disappear in the exact tests.
For total context size `7`, all singleton-product kernels are positive on every
tested sparse violator:

```text
size 3, r=4: min 20/16807
size 4, r=3: min 37/16807
size 5, r=2: min 199/24010
size 6, r=1: min 69/6860
```

Coherent context partitions do not make the margin smaller.  In every tested
row, the weakest context is the all-singleton word (`[1+1+...]`).  That is a
concrete proof route: prove the symmetric hit-count kernel inequality first,
then prove that merging singleton context carriers into coherent blocks is
monotone for the compression margin.

The all-singleton word is a literal finite cellular automaton.  If a residual
packet has size `j`, one singleton carrier deletes one of its sectors with
probability `j/7` and leaves it unchanged with probability `(7-j)/7`.  Iterating
that death rule gives exactly the kernel

```text
g_r(t)=7^-r sum_a (-1)^a binom(t,a)(7-a)^r.
```

So the next proof is not a mysterious 64-state inequality at first.  It starts
as a one-dimensional monotone deletion chain on residual-size states, with the
sector geometry entering only through the hit-count law of the candidate
cluster.  The 64-state miss-zeta automaton returns in the second step, when one
has to prove that coherent context blocks cannot be worse than the singleton
death-chain baseline.

The incoming HYP-2701 truewide survival gate is the right analogy.  Route B
became useful when it stopped using the raw moment basis and moved to survival
coordinates.  HYP-2702 should do the same thing for the sparse tail: raw
residual coordinates are the losing quotient; miss-zeta generated words are the
coordinate system that preserves the LRC predicate.

Tournament Analysis reflects that choice.  The vertices are proof carriers, not
runners or arcs, and the transitive order is:

```text
miss_zeta_product_word
> coherent_OR_contexts
> singleton_hit_count_kernel
> survival_basis_signal
> large_R_stratification
> raw_coordinate_weights
```

No proof is claimed.  The useful reduction is now sharper: the sparse tail
should be a singleton death-chain hit-count lemma plus a context-merging
monotonicity lemma, not a separate ad hoc finite check over residual
coordinates.
