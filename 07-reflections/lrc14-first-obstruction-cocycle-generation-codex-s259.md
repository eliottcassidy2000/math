# LRC14 First-Obstruction Cocycle Generation

The observer-sheaf route needs a way to say when a quotient is allowed to
forget.  The repo already has several versions of the answer: no-free-slider,
observer-cut payloads, cocycle normal forms, sidecar observability matrices,
route-state medians, and Hodge-cycle generation.  HYP-3102 compresses those
into one rule:

```text
the first thing a quotient forgets is a syndrome.
```

For a quotient `q` and next observer/cut operation `o`, the hidden payload is
`sigma_q,o`.  If two rows are in the same visible fiber but have different
payloads, their difference is the first obstruction cochain.  The quotient is
legal only if that cochain is zero, reconstructed by a sidecar, exact,
dual-annihilated, descended to a smaller family, stopped at AP/GW boundary
equality, or routed to a named F7/THM-572 lift.

The incoming S258 observer-gluing ledger is already written in this language
without naming it as such.  Direct components, CRT lift status, pair/Pascal
scissors fields, mod-7 signatures, Farey lanes, and terminal exits are all
sidecar columns on the same sample rows.  Rows with identical coarse terminal
status still split by scissors signatures and by direct component behavior.
That is a first-obstruction situation, not a reason to pick one scalar chart.

THM-577 gives the cap chart a symbolic backbone for `k>=10`, so the cap-side
obstruction is no longer just "search says so."  In the syndrome ledger, the
Pascal pair-mass defect should therefore be tested as generated by
closed-form overlap / finite-remainder data before promoting it to a new
independent basis atom.

This turns HYP-3071's matrix into a proof program rather than a scout result.
S237 found `15` strict-open residual fibers, first teeth
`arc_topology_compact=13` and `coarse_safe_stalk=2`, and a rational
cycle-class template with `13` atoms where known generators span `12`.  The
only intended missing basis vector is `phantom_f7_class`.

The creative synthesis is that many older cross-field motifs are just
different presentations of the same syndrome calculus:

```text
sheaf Cech overlap      -> chart-gluing obstruction
Hodge decomposition     -> exact / dual / harmonic split
electrical current      -> endpoint-owner conservation
LDPC code syndrome      -> sidecar parity check
Kalman observability    -> sidecar columns separate hidden states
matroid cocircuit       -> endpoint wall dependency
chip-firing             -> boundary current discharge
```

The incoming tournament-certificate engine and S65 baby-Hodge scout are good
stress tests for this language.  Certificate engines become legal generators
only after their vertex set is the retained proof carrier; the baby-Hodge
`(c3,c5)=(8,10)` hole is a `c5`/power-sum obstruction, not a forbidden-H
alpha event.  The first-obstruction ledger should therefore record the
mechanism class of each syndrome before trying to glue it away.

This gives a clean division of labor with HYP-3101.  HYP-3101 tries to prove
the topology chart has bounded components.  HYP-3102 asks whether that chart,
with its owner currents and normal-fan words, glues legally to arithmetic,
cap, moment, branch, and formal charts.

The next concrete artifact should be `lrc14_first_obstruction_syndrome_ledger`.
For each mixed residual fiber it should record:

```text
quotient_name
next_observer
visible_automorphism_group
observer_cut_payload_orbit
first_nonzero_sidecar_stage
first_obstruction_basis_vector
certificate_cycle_image_status
dual_annihilator_status
family_descent_status
AP_GW_boundary_stop_status
F7_THM572_state_lift_status
terminal_exit
```

If the ledger shows every non-F7 row generated or killed, then the hidden
observability sheaf becomes a finite exactness theorem.  If not, the first
unspanned coordinate is still valuable: it names the next missing sidecar
instead of leaving the proof stuck behind an anonymous residual bucket.
