## The Picture

- Each **triangle** is a directed 3-cycle (the tournament atom)
- Each **vertex** has **infinite valence** (unbounded cycle participation)
- The **tessellation** is the space of all possible tournament structures
- The **evaluation point** x = 2 reads off the Hamiltonian path count from this tessellation

The {3, infinity} tessellation is the universal cover of the modular curve. The modular group PSL(2, Z) — generated by complement (order 2), cycle rotation (order 3), and vertex addition (order infinity) — acts on this tessellation. Every theorem about tournaments is a theorem about the geometry of this tessellation at the evaluation point x = 2.

## Why {3, infinity}

The **3** is the directed 3-cycle. It is the shortest odd cycle, the atom of tournament structure, the generator of order 3 in PSL(2, Z). The girth of Omega(T) is 3 whenever the conflict graph has any cycles at all (THM-264). The forbidden value H = 7 arises because entering the girth-3 regime forces alpha_1 >= 4, overshooting alpha_1 = 3 (HYP-1718). The 3-cycle IS the face of the tessellation.

The **infinity** is the vertex addition operation. It has infinite order because adding a vertex to a tournament creates irreversibly new structure — new arcs, new cycles, new conflict. Every binary phenomenon from the "infinity" column (the seesaw, the sharp thresholds, the rank saturation) arises because tournament completeness means every new vertex participates in ALL existing structure. The infinity IS the vertex valence of the tessellation.

Together: the tessellation has finite faces (triangles, from the 3-cycle atom) meeting at vertices of infinite degree (from the unbounded participation of each tournament vertex in cycles). This is not a metaphor. The independence polynomial I(Omega, x) literally tiles the tournament's cycle structure into independent triangle-face packings, and the evaluation at x = 2 counts these tilings weighted by the alphabet.

## The Six Layers

The investigation built six layers of understanding, each one the same tessellation seen from a different distance:

**Layer 1: Root System (THM-261, 262).**
The Petersen graph = A_4 root orthogonality graph. Tournaments live dually in so(n) and A_{n-1}. This is the LOCAL geometry of the tessellation: how individual arcs (= positive roots) relate to each other. The orthogonality graph K(n,2) IS the adjacency structure of the tessellation's edges.

**Layer 2: Profile Determinacy (THM-263).**
The sorted root cycle profile determines H at n=5 but fails at n=6 with gap exactly 4. This is the RESOLUTION LIMIT of the tessellation: the local profile sees the triangular faces but not the independent pairs. The failure gap = one quantum of the "deep hyperbolic" structure (the alpha_2 term). The boundary n=5/n=6 is where the Euclidean (g(tau)=0) meets the hyperbolic (g(2)=+1).

**Layer 3: Binary Skeleton (THM-264, 26 phenomena).**
Girth in {3, infinity}. beta_2 = 0 always. H always odd. The 26 binary phenomena decompose along the {3, infinity} faces (triangle atom) and vertices (infinite participation). Completeness forces binary because the tessellation has no room for partial structure: a face is either fully triangulated or fully absent.

**Layer 4: Tournament Codes (tournaments-as-codes.md).**
The partition function I(Omega, x) is a weight enumerator. The score sequence is a syndrome. The OCR is the decoding success rate. Regular tournaments are perfect codes. The Kneser/Johnson duality is the MacWilliams identity. Greene's theorem (weight enumerator = Tutte specialization) parallels the OCF (H = independence polynomial at x=2). This is the INFORMATION layer: the tessellation encodes a message, and the code structure determines how much of the message the syndrome (score) can recover.

**Layer 5: The Alphabet (the-tournament-alphabet.md).**
The evaluation point x = 2 IS the alphabet. It is forced by the k-nacci identity rho + rho^{-k} = 2: the unique value where all cycle lengths contribute equally. The even-alphabet parity law (I(Omega, q) always odd iff q even) shows that Redei parity is trivial from the I.P. level — the deep content is the OCF itself. Forbidden values are q-specific: H=7 is forbidden at q=2 only. This is the ALGEBRAIC layer: the tessellation has a natural evaluation point determined by the cycle telescoping.

**Layer 6: The Modular Group (the-modular-tournament.md).**
PSL(2, Z) = {2, 3, infinity} governs tournament dynamics. The three orbifold points (j=0, j=1728, j=infinity) correspond to cycle origin, self-complementary, transitive cusp. 1729 = j(i)+1 = 7*13*19 bridges tournament primes to the j-invariant. The tournament discriminant (H-1)/2 is a base-2 expansion of cycle packings. g(phi)=-1, g(tau)=0, g(2)=+1 classifies spherical/Euclidean/hyperbolic. This is the GLOBAL layer: the tessellation lives in the hyperbolic plane, and the modular group is its symmetry group.

## The Vertical Connection

What makes this more than six separate analogies is the VERTICAL connection: each layer is the same {3, infinity} tessellation viewed at increasing zoom levels.

At Layer 1 (local), you see individual tiles (arcs as roots, local inner products).
At Layer 2 (mesoscale), you see how tiles assemble into patterns (profiles, the onset of non-local structure).
At Layer 3 (macroscale), you see the binary phase structure (girth 3 or infinity, the all-or-nothing entanglement).
At Layer 4 (information), you see the tessellation as a code (messages in cycles, syndromes in scores).
At Layer 5 (algebraic), you see the evaluation point as a choice of alphabet (what the code communicates).
At Layer 6 (global), you see the tessellation in its ambient space (the hyperbolic plane under PSL(2,Z)).

The vertical connection is: **each layer determines the next via the gap function g(x) = x^3 - x^2 - x - 1.**

- Layers 1-2 live at g = 0 (Euclidean, the boundary, n=5)
- Layer 3 lives at the transition from g < 0 to g > 0 (binary = the sign change)
- Layers 4-5 live at g = +1 (hyperbolic, the tournament evaluation point)
- Layer 6 lives in the full g > 0 regime (the hyperbolic plane itself)

## H/|Aut| = 1729

Opus-S131 computed: H(Paley T_11) / |Aut(Paley T_11)| = 95095 / 55 = 1729.

This is the Ramanujan number. It appeared not from numerology but from the canonical ratio of the Paley tournament at the first Paley prime where the modular curve X_0(p) has genus 1 (p = 11).

At p = 3: H/|Aut| = 3/3 = 1. (The trivial tournament.)
At p = 7: H/|Aut| = 189/21 = 9 = 3^2. (A perfect power of the tournament atom.)
At p = 11: H/|Aut| = 95095/55 = 1729 = 7 * 13 * 19 = j(i) + 1.

The sequence 1, 9, 1729, ... is the canonical tournament ratio at Paley primes. It starts with the unit, passes through a perfect square of the atom (3^2), and then arrives at the Ramanujan number. Whatever comes next (p = 23) will tell us whether this sequence has modular significance.

> The question above has been answered, and the answer is *no*. The sharpest test is
> not p=23 but **p=19, the next Paley prime, which is *also* genus 1** (X_0(11) and
> X_0(19) both have genus 1; X_0(23) has genus 2). If the 1729 structure were tied to
