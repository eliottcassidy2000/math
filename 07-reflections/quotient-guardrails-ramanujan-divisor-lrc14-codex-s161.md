# Quotient Guardrails, Ramanujan Divisors, and the LRC14 Kernel

The clean abstraction from the divisor/Ramanujan pass is that a useful
connection is not a resemblance between two scalars.  It is a map with a named
kernel.

For an LRC14 proof quotient `pi:X->Q`, the question is not "what did we keep?"
but "is the forgotten fiber harmless for the next predicate?"  The admissible
cases are narrow:

```text
P is constant on each quotient fiber;
the forgotten label is reconstructible from retained packet data;
the forgotten label is annihilated by an orthogonality or dual certificate;
the fiber is placed in a named residual bucket with endpoint/state labels.
```

Everything else is a lossy analogy.

is a divisor-fiber pushforward, multiplicative but not completely

The useful concepts are:

- Dirichlet convolution is coefficient multiplication for Dirichlet series;
  identities such as `d=1*1`, `sigma_k=Id_k*1`, `phi*1=Id`, and
  `mu*1=epsilon` are exact packet laws.
- Jordan `J_k` is higher-rank primitive capacity: `sum_{d|n} J_k(d)=n^k`.
- The divisor summatory function is lattice-point counting under a hyperbola;
  its error term is the boundary defect left by quotienting the product
  lattice.
- Ramanujan sums are primitive-unit power sums with lcm-period orthogonality.
  Murty's shifted form says the diagonal period remembers the shift by
  `c_q(h)`, which is tailor-made for endpoint sums/differences.
- Ramanujan sums as supercharacters say the unit-orbit quotient is legitimate
  only when the orbit character is retained.
