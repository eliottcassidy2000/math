# LRC14 Median Owner/Root Sidecar Spine - Codex S234

S233 left a clean warning: Desargues-like incidence can be organized, bipartite,
and theta-like while still failing the median test.  S234 turns that warning
into a smaller checklist for the next LRC14 proof push: the medianization table
has to record owner and root objects, not only route triples and sidecar names.

The useful pattern is consistent across three live threads.  In the q=23/B18Z6
residual, exact `M` and Haar zeta diagnose the diagonal but do not name the
endpoint owner.  In the A000568/rooted-perspective defect, the missing object
is rootless and cyclic, not a deeper rooted node cache.  In the Desargues/Beal
finalizer, the girth-six incidence address only becomes proof-facing when a
common-owner gate is retained.

The S234 script makes this concrete with six toy route fibers.  Five begin
with empty centers and one begins with multiple centers; after attaching the
first missing sidecar, all six become unique-center rows.  The sidecar
tournament is deliberately over proof obligations and owner/root objects, not
runners.  It is transitive, with `endpoint_owner_strip`, `observer_cut_orbit`,
and `exact_M_zeta` at the front and `raw_scalar_count` last.

This is still not a proof.  The next proof-relevant move is to run the same
ledger over actual HYP-2963 coarse fibers and emit:

```text
coarse_fiber_id
route_triple
coarse_shadow
root_object
owner_object
median_center_status
first_missing_sidecar
repair_or_debt
```

Assumption challenged: tournament vertices do not have to be runners, arcs, or
Desargues vertices.  For this step, proof obligations plus owner/root/sidecar
objects preserve the LRC predicate we need: boundary/open status and route
schedulability.  They intentionally remember the coordinates whose loss
creates empty or ambiguous median centers.
