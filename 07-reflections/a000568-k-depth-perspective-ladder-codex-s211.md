# A000568 k-depth perspective ladder - S211

The new thing this session is the clean separation between "recover the rooted
node type" and "recover the shifted A000568 extension payload."

In the user's shifted language, the first failure is `n=6`: A000568 has
`U(6)=56`, but all node perspectives on 5-vertex tournament classes contribute
only `P(5)=48`.  The k-depth experiment makes the failure sharper.  At
`m=5`, depth-1 node refinement gives `41` types and depth-2 gives all `48`
exact rooted types.  After that the node ladder stabilizes.  Therefore the
missing eight classes are not hidden one more node-neighborhood layer down.
They are incident-word or cross-coupling data that exact rooted nodes never
owned.

This is the same mechanism as the recent LRC14 controlled-forgetting stack:
coarse data is not useless, but every quotient has to say which coordinate it
forgot and how that coordinate returns.  HYP-2120 supplies the exact source
slice, HYP-2121 says the full-rooted gap is observer-coupling, HYP-3039 gives
the hidden-coordinate rule, and HYP-3043 makes the lens map.  S211 inserts a
small tournament laboratory between those statements.

The creative carrier menu I would pull next:

1. Directed-edge perspectives.  For `tail -> tip`, classify every other vertex
   by `(tail beats x, tip beats x)`, then keep the cross-sector orientation
   matrix.  This is the smallest honest incident-word lift.
2. Directed-cycle conflict perspectives.  These keep chirality and should be
   tested against the old HYP-1824/HYP-1825 eight-class bridge.
3. Transitive-clique insertion perspectives.  A rooted chain tells where an
   outside observer inserts.  This may be closer to the add-vertex map than a
   rooted node.
4. Edge-cycle incidence conflicts.  Use a bipartite object between edges and
   cyclic witnesses to see whether local sectors and cyclic debt cohere.
5. Endpoint-owner packet sheaves.  This is the LRC-facing version: source
   threshold arc, incident word, endpoint-owner labels, gap-pressure fiber, and
   proof-obligation automaton.

The incoming codex-S210 tournament matrix atlas should be folded into this
immediately.  Directed-edge sectors want a four-block sector matrix; cycle
conflict wants the skew sign matrix `S=A-A^T`; clique insertion wants a Schur
complement or low-rank update record; endpoint-owner packet sheaves want
boundary matrices whose rows are proof carriers rather than runners.  That
means the next exact edge-perspective script should emit both isomorphism
counts and matrix sidecars.

The important negative result is also useful: do not chase a pure k-depth node
definition as the final proof carrier.  It becomes an exact rooted cache by
depth 2 at the first failure, and exact rooted cache is still too small.  The
next lift must be edge/sector/cycle/clique/conflict data or the LRC analogue
of endpoint-owner labels.
