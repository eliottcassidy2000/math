# LRC14 Green-Current And Lorentzian Exchange Angles

This pass reads the newest mainline evidence as a request for certificates,
not more scalar diagnostics.  The bounded k=8 node is now heavily triangulated:
consecutive maximizes total covariance, each distance layer has no primitive
beater, AP support is the useful cyclotomic direction, naive compression and
naive exchange both leave traps, and Toeplitz/Perron/Joukowski all point at the
same spectral object.

The creative gap is that none of this yet gives a legal proof move for every
row.  HYP-3223 proposes two certificate languages for that gap.

Push-time rebase sharpened the boundary of the proposal.  HYP-3211 says the
octonion/Fano multiplicative apex belongs to the tournament face while the LRC
face is additive/cyclotomic.  HYP-3212 says the cap is a Chebyshev
equioscillation / Delsarte magic-function extremal.  HYP-3221 says
config-blind algebraic certificates fail at the apex-7 Lee-Yang obstruction
and the final rescue is analytic equidistribution.  So the Green/Lorentzian
packet should be read as a bounded k=8 certificate classifier, not as a claim
that algebra alone can close the R-block.

The second push-time rebase claimed HYP-3204/T1304/LTI-304/LTT-204 for the
ordered-tail exchange scout, which is directly useful: it prices central `q3`
mass against `q0+q6` bimodality.  I therefore moved this packet to
HYP-3223/T1323/LTI-323/LTT-223 and read it as a certificate supplier for the
ordered-tail exchange route, not as a competing HYP-3204.

The next rebase added HYP-3205, which is the compatibility layer this packet
needed.  HYP-3205 says AP/consec and doubled AP are the only rows tight across
the current certificate dictionary; HYP-3223 should now be treated as a
proposal for two more dictionary coordinates.  A successful Green-current or
Lorentzian test should not merely rank AP first.  It should explain the same
trap discharge that HYP-3205 predicts from the first failed coordinate.

First, read the covariance matrix as a Green kernel.  Then
`1^T C 1` is not just a covariance sum; it is current energy.  Consecutive
speeds should be tested as an extremal network: the row with minimum effective
resistance or maximum all-ones current capacity under the legal sidecars.  The
HYP-3202 traps become finite networks whose obstruction is a boundary leakage
or Schur-complement bottleneck.  This reuses older effective-resistance work in
the repo but points it at the current k=8 covariance bank instead of at a
global discrepancy scalar.

Second, read co-emptiness probabilities as a finite set function.  Pair
covariances, third cumulants, AP support, and exchange traps are all finite
differences of that set function.  The speculative target is a Lorentzian or
valuated-matroid chamber after orbit sidecars are retained.  In that language,
the traps are tropical Plucker defects or tied circuits, not evidence that the
AP extremality is accidental.

The strongest possible convergence would be:

```text
Schur-complement network edits = valuated exchange moves
AP support direction = normal vector of the correct exchange chamber
HYP-3202 finite traps = named circuit/bottleneck sidecars
```

That would turn the remaining k=8 proof target into a certificate ledger:
each primitive row either admits an electrical/Rayleigh edit, emits the missing
valuated-exchange sidecar, or lands in a finite discharged trap family.
The ledger is legal only if it keeps the arithmetic sidecars demanded by
HYP-3221 or hands them explicitly to the equidistribution route.
