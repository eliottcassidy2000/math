The integer-programming lens is a good fit for the earlier natural-number
mode split.

Every speed column has two coordinates:

```text
v = 2^h * odd_core
```

The odd core is the horizontal `x+2` chain.  The dyadic height is the vertical
`x*2` chain.  This is not just a way to sort integers; it is exactly how the
LRC constraints split.  Small-denominator and unit rows ask for divisibility
columns.  Endpoint rows ask for strict interval containment.  A counterexample
would have to choose `n-1` primitive columns satisfying both.

## What The S420 IP Rows Say

The unit layer is a one-row certificate:

```text
n=14 unit layer -> exact cover column 14
n=16 unit layer -> exact cover column 16
```

This is THM-360 in integer-program form.  Without an `n`-multiple, the unit
endpoint rows survive.

The `n=16` vertical invoice is already sharp.  Covering all endpoints owned by
a `16`-gate using lower speeds `1..15` has exact minimum nine:

```text
(1,3,5,7,8,9,11,13,15)
```

The solver returns the same set, up to greedy order, and every one of these
columns is forced by private endpoint rows.  So the local dyadic obstruction is
not soft.  It is a literal lower bound in a finite set cover.

The `n=14` composite row behaves differently.  The S380 gate ladder satisfies
every small-denominator divisibility row, so the horizontal sieve is paid.  But
its own endpoint rows are not closed:

```text
targets=2298
covered=2130
uncovered=168
uncovered prime depths:
  {2:+1,7:+1}:120
  {2:+3,7:+1}:48
```

Even worse for a disproof attempt, every ladder column is forced by some private
endpoint row.  The candidate is not failing because it contains waste.  It is
failing because every locally necessary column still does not pay the exported
product-depth rows.

## Reframe

The useful object is not a speed set alone.  It is the row/column incidence
system generated by the speed set:

```text
columns: speeds, typed by odd_core and dyadic height
rows:    small denominators, unit endpoints, protected endpoints
```

Initial segments are horizontal equality spines.  Gate repairs are vertical
divisibility moves.  Composite denominators create product-depth endpoint rows.

This suggests a proof architecture:

1. Use THM-366/THM-360 to force gate columns.
2. Use local endpoint set covers to invoice what those gates export.
3. Build a dual row-weight certificate showing no primitive `n-1` column set
   can pay both the horizontal sieve and the vertical endpoint debt.

For `n=16`, the dual is one-prime and should be dyadic.  For `n=14`, it should
live in the product of the `2`- and `7`-adic depth coordinates.
