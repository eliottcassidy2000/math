# LRC14 Recursive Sidecar Pattern Atlas Reflection

Date: 2026-06-28

This pass looked for recursive structure across the current LRC14 proof
threads rather than another new analogy.  The shared pattern is simple but
useful:

```text
quotient -> mixed theorem-exit fiber -> first missing sidecar
-> repaired quotient -> next quotient.
```

That turns the concrete finite lemma target into a recursion over legal
forgetful maps.  A quotient is legal only if the theorem exit is pure on its
fibers.  If it is not pure, the first missing coordinate is not a vague
obstruction; it becomes the next sidecar or a named debt.

HYP-3405 supplies the local base case.  In the AP one-swap collar, the first
visible loss after C3, `Q(sqrt(-7))`, covering layer, unit contacts, and
nonunit height is unit-height flex.  HYP-3406 supplies the enlarged-bank stress
test: residue fails immediately, height/v2 explains the first leak, but
height-persistent leaks escalate to endpoint-owner support.  HYP-3407 wraps
that as a labelled theorem router.  HYP-3408 adds the guardrail that named
constants and analytic shadows are not proof vertices unless they declare an
exact sidecar obligation.

The strongest new reframe is that the proof object is a stack of legal
forgetful maps, not one magic invariant.  That makes the recursive proof task
more concrete:

1. define the packet and its theorem-exit predicate;
2. compress by a proposed quotient;
3. find mixed fibers;
4. name the first destroyed coordinate;
5. repair the packet and recurse;
6. force every branch to AP/GW, strict-open mass, q-witness, H7/state lift,
   off-grid floor, exact-period/BDH exception, or named finite residual.

The top ranked operators were mixed-fiber resurrection, owner-cut recursion,
collar-to-bank lift, height-then-owner escalation, and finite chamber terminal
routing.  This ordering matters.  The next proof work should not jump straight
to BDH/Mertens averages or exotic scalar guardrails; it should first build the
owner-support Menger graph around the HYP-3406 leaks and keep the AP-collar
sidecar chain visible as the base case.

The most useful concrete test is now an API test: put HYP-3405 AP-vs-`13->27`
and HYP-3406 owner leaks behind the same quotient/fiber/repaired-quotient
interface.  If that works, extending beyond `(72,20)` becomes more than a
larger scan: it becomes a search for the first failure of the recursion rule
itself.

Assumption challenged: tournament vertices do not have to be runners, arcs,
residues, or constants.  For the current LRC14 proof route, the better vertex
set is recursion operators and proof obligations generated by mixed
theorem-exit fibers.  This preserves the LRC predicate and intentionally
destroys row identity and scalar motifs unless a later sidecar needs them.

for the two visible HYP-3406 owner-leak families.  Add terminal-exit labels
