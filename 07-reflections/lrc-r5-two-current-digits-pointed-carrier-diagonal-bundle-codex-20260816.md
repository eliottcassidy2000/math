## The stationary six-by-six transition is false

Write the six one-digit pointed trajectories as a `6 x (13*13*13)` matrix

```text

```

For fixed `r1`, form

```text
C_r1[p ; r0,s,t].
```

The stationary hypothesis asks for one matrix `K_r1` satisfying

```text

```

simultaneously for all `r0,s,t`.

The parent trajectory matrix has rank six, so such a matrix would be unique.
It does not exist for any of the 13 values of `r1`.  For `r1=0,6,12`, the
child rank is four and the parent/child union rank is ten.  For the other ten
values, the child rank is six and the union rank is twelve.  Hence every
stationary containment fails by exact rank, not merely by a chosen coordinate
solver.

The first residual witness occurs already at `r1=0`: the matrix reconstructed
from a nonsingular six-column parent minor predicts zero at child row 2,

