# Recursive Fourth Face, S672

The clean split is:

```text
fraction  = state
recursion = transition
```

The repo had been letting "fraction" carry both meanings.  Continued fractions,
carry continuants, deleted-card owners, branch sheets, and model/generic states
all remember a boundary.  But a recurrence does something stronger: it says how
that boundary evolves when the object is extended, iterated, or forced through
descent.

That is why Zhou-Markov is such a good anchor.  The integral itself is an
additive packet, denominator clearing is the product face, and a Lambert
continued fraction is the historical boundary method.  Their recurrence proof
uses a different object: a sequence that stays integral after clearing,
tends to zero, and cannot vanish permanently because the recurrence would
force a contradiction backwards.  The recurrence is a proof machine.

Paris-Harrington is the same lesson at maximum volume.  A coloring is static.
The relative largeness condition `|H| >= min(H)` is a tiny observer boundary.
But once that boundary is part of the recursive witness problem, the minimal
witness function outruns PA-provably total functions.  A microscopic boundary
condition changes the proof-strength class.

So the old loop

```text
sum -> product -> fraction -> sum
```

should become:

```text
sum -> product -> fraction -> recursion -> sum.
```

The last arrow is "unroll the transition."  A recursion gives the next additive
ledger: integral coefficients, proof-length growth, endpoint-child classes,
carry-loss rows, deletion/substitution losses, or online coloring game states.

For LRC14 this says: the carry-owner continuant is not yet the theorem.  It is
the fraction state.  The theorem is the recursion law saying every coherent
`+27` carry extension either remains in the floor family or pays strict tax.

For A000568 this says: the half-filter trace is the state.  The real target is
the endpoint recursion theorem:

```text
Aut(parent)-orbit incident cube
  -> raw child
  -> half-filter deck
  -> pure class fiber
```

for all `n`, not only through `n=8`.

For unit distance this says: edge counts and Eisenstein directions are still
static.  The proof object is a point-deletion frontier owner plus a slab/ear
extension recursion.

The face tournament in the S672 script came out transitive:

```text
recursion > fraction > product > sum > raw_scalar.
```

That feels right.  The trinity remains useful for diagnosing projections, but
recursion is the apex when the goal is a uniform theorem rather than a scalar
representation.

Working slogan:

```text
Find the boundary state, then prove its extension law.
```

That slogan is probably the bridge between colorings, outer-extension
usability, LRC14, endpoint A000568 enumeration, unit-distance constructions,
and the repo's micro-incompleteness thread.
