```text

```

see only the `E5` odd class on `I^j/I^(j+1)`.  Equation (1) shows that `R` is

It has a different type.  For a Keller mate, `Phi_Q` and `Psi_Q` are


Thus only `R_Q` modulo its additive constant, or its finite-place principal
part, is an elimination observable.  A nonzero constant value of `R_Q` is
allowed and must not be declared a contradiction.

## 3. Quotient the additive constant before using the row

Let

```text

```

and regard the Faber seed coefficients as constants for the base derivation.
The universal relative one-form envelope is generated by

```text

```

Differentiating the primitive row (10) produces a row with common 2-content
exactly `2^3`.  The Kähler module is free, so dividing this common content is
the canonical saturation of this one rational differential row.  Equivalently
the saturated row is

```text

```

Modulo two, (12) is exactly

```text
[0, a^7 da+a^8 dc, 0,0,0].                           (13)
```

Thus even the stronger universal one-form envelope has odd-column rank one.
The physical Keller equation is weaker: it contracts (13) with the single
actual trajectory tangent

```text

```

Failure of the stronger envelope to see `E3,E1` implies that no contraction
of it repairs the first grade.

It would be incorrect to assert that the full Kähler one-form vanishes along
a Keller trajectory.  Only its contraction (14) vanishes for a homogeneous
response defect.  The universal form is used here solely as a hostile upper
bound on what one derivative row could detect.
