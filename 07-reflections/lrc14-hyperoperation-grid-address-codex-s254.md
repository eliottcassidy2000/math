# LRC14 hyperoperation grid address synthesis

Source: codex-2026-06-27-S254.

This pass merges the user's hyperoperation prompt with the older
`x+2`/`x*2` space-filling grid work and the incoming THM-573 level-7 sieve.
After rebasing over the incoming covering/K33 shuttle and the later HYP-3086
sexy-prime namespace claim, then preserving the later HYP-3088/HYP-3089
polynomial-method reservations, the resulting artifact is HYP-3087.

The useful reading is not "a space-filling curve proves LRC14."  The curve is a
scheduler through operation cells.  It becomes theorem-relevant only when each
cell keeps the Farey root `(p,q)`, the operation lane, the current danger
deficit, endpoint owners, the level-7 lift status, and a terminal route or
named debt.

The merged dictionary is:

```text
p+q       additive shadow / horizontal `x+2` lane
p*q       product shadow / vertical `x*2` or factor-depth lane
q^p,p^q   exponential stress lanes, unsafe without retained root address
curve     adjacent repair order, not a proof by itself
```

This directly extends HYP-3003 and HYP-3004.  HYP-3003 already separated the
summand antidiagonal from the multiplicand hyperbola over the same Farey root.
HYP-3004 already read `*2,+2` as valuation descent versus horizontal motion.
The S511 operation-grid reflection supplied the missing LRC clock: static grid
labels do not move, but labels weighted by current pair-cell deficit do.

The incoming theorem changes the residual target.  THM-573 proves every
13-speed row with at least `7` multiples of `7` is lonely, so the active
covering residual is now at most `6` multiples of `7`, not merely at most `6`
multiples of `14`.  Therefore the product/vertical lane must record
`count_7_divisible`, `v7_depth`, and `level7_lift_status` before it can be used
in the finite-address branch-closure spine.

THM-576/HYP-3090 adds a cap-side coordinate.  Pairwise avoidance supplies the
clean triangular caps for `k>=10`, but `k=8,9` and the first order-3 break must
remain visible as deviation debt.  The grid cell should therefore retain
`cap_ratio_or_deviation_status` before it gets scalarized into a moment bound.

The rebase also brought in HYP-3094, the covering-moment / K33 state-lift
shuttle.  That shuttle is a direct exit grammar for the grid: nested-refinement
covering packets and cross-handoff K33 packets may both be positive-open, so
the hyperoperation carrier must keep grid class, active binders, and endpoint
owner transitions before any product lane or safe-mass shadow is trusted.

The later S31ag bridge adds one more target coordinate.  HYP-3087 identifies
the same `14=2*7` wall in the external polynomial-method paper, and HYP-3088
translates Conjecture 7.1(13) into a uniform largest-lonely-arc floor.  Thus an
operation-address cell is not complete merely because it routes through O2/O3;
it must also say whether it contributes to the normalized slow/ruler-coordinate arc
floor or names the packet where that floor reduction fails.

The improved proof shape is:

```text
primitive row
  -> 14-free q-witness exit
  -> level-7 lift sieve
  -> at-most-6-multiples-of-7 residual core
  -> danger-weighted operation-address packet
  -> finite-address branch packet
  -> covering/K33 shuttle when grid class demands it
  -> protected branch graph
  -> terminal discharge or named debt
  -> formal witness M>=1/14
```

Tournament Analysis is synthetic in this pass: no new script was run.  The
vertices are proof carriers rather than runners or raw grid points, with the
tie path:

```text
finite_address_branch_packet
> danger_weighted_operation_cell
> level7_lift_gate
> exact_farey_root_packet
> additive_x_plus_2_lane
> multiplicative_x_times_2_lane
```

The assumption challenged is the default choice of vertices.  Runners, arcs,
raw grid points, curve steps, hyperoperation lanes, `(p,q)` packets,
denominator shells, 7-adic lift classes, endpoint owners, branch nodes, and
proof obligations were all plausible.  The chosen quotient is the
operation-address packet because it is the smallest object in this list that
can preserve the LRC predicate after danger, endpoint ownership, and branch
exit data are retained.
