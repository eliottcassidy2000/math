# LRC14 Status-Topology Gate

codex-2026-06-26-S194

This pass splices HYP-3024 and HYP-3025 into a cleaner proof order.  HYP-3024
gave an arithmetic status gate: coarse Erdos-Turan plus Henselian-unit counts
has `0` mixed boundary/open fibers on the full HYP-2963 bank.  HYP-3025 gave
the topological equality signature: AP/GW are closed arc-Cech cover cycles.
After fetching the newer agents, this slots naturally beneath HYP-3026's
carrier-fusion switchboard and HYP-3028's residual status-gate switchboard:
those name the proof interface, while this pass supplies the arc-topology
reason the status gate is allowed to forget route labels.

The new audit checks the overlap directly.  In the full `21913`-packet bank,
the residue-terminal quotient has exactly two mixed boundary/open fibers.
They are AP and GW against open impostors.  The two boundary rows are exactly
the AP/GW arc-boundary cycle: closed arc beta `(1,1)`, open arc beta `(6,0)`,
zero safe topes, and six owner sums `0 mod 14`.  Every open cohabitant has
closed arc `beta1=0` and at least four safe topes.

The HYP-3024 coarse ET+unit gate then has no status mixing.  Its only
surviving route-mixed fibers contain `38` packets total, all open, with
`23` q-witness and `15` covering-moment packets.  All of them have closed arc
`beta1=0`.

So the proof target is less tangled now:

```text
zero-open -> AP/GW arc-boundary cycle or named residual
coarse ET+unit -> status-preserving quotient
magnitude/barcode/Fejer/K33 -> route scheduler for open packets
```

Assumption challenge: the vertices are proof gates, not runners.  I considered
runners, danger arcs, endpoint cells, boundary cocircuits, residues, ET clocks,
p-adic units, magnitude fibers, barcode packets, and proof obligations.  The
chosen quotient preserves only boundary/open status.  It deliberately destroys
full route labels, so it is admissible only after the topology gate has
separated equality atoms.

The live theorem now feels sharper than "prove route purity."  Route purity is
overkill for the LRC yes/no predicate.  First prove topology status purity:
the only way to have no strict safe tope is the AP/GW closed cover cycle, unless
we have a named F7/THM-572 residual.  Then the coarse arithmetic gate can be a
compression theorem instead of an address coordinate.
