The two equations

```text
a^6 + b^6 = d^6 + e^6
a^6 + b^6 + c^6 = d^6 + e^6 + f^6
```

should be merged into the LRC14 Desargues/Beal lane, but not as the same
object.

The binary equation is a Gaussian norm equality:

```text
N(a^3 + i b^3) = N(d^3 + i e^3).
```

So a primitive binary collision is an owner/factor problem.  It asks for the
Gaussian factorization, unit/ratio data, and the constraint that both
coordinates are cubes.  The S242 bounded scout found no primitive binary
collision through bases `<=1000`; this is not a theorem, but it supports using
the binary equation as a stiff `binary_sixth_gaussian_owner_gate`.

The ternary equation behaves differently.  A primitive collision already
appears at small height:

```text
3^6 + 19^6 + 22^6 = 10^6 + 15^6 + 23^6 = 160426514.
```

The matching sixth-power residue signatures are visible but not explanatory:

```text
mod7:  (1,1,1) = (1,1,1)
mod9:  (0,1,1) = (0,1,1)
mod13: (1,1,12) = (1,1,12)
```

So the ternary equation is not a Beal-style no-collision warning.  It is a
diagonal-current carrier: two triples of cubical coordinates have the same
value under the form `x^2+y^2+z^2`.  In the LRC proof-interface language, that
is closer to HYP-3071's cycle-class matrix than to a raw common-factor gate.

## LRC14 Merge

HYP-3060 now gets three additional sidecars:

```text
binary_sixth_gaussian_owner_gate
ternary_sixth_diagonal_current
sixth_power_residue_signature
```

Use them this way:

1. If a residual power shadow has binary form, do not use the equal sum as a
   scalar.  Demand a common owner/factor/frequency coordinate, or route the row
   to owner-strip/exact-period repair.
2. If a residual power shadow has ternary form, do not reject it as impossible.
   Ask whether the ternary current is generated by named certificate cycles,
   dual-annihilated, descended to a smaller family, stopped at AP/GW boundary,
   or emitted as explicit THM-572/F7 state-lift debt.
3. If only residue signatures are known, treat them as a warning label, not a
   proof object.  The smallest ternary identity passes simple sixth-power
   residue checks.

This also sharpens the Beal analogy.  Beal remains a common-owner guardrail for
primitive exponent-channel collisions.  The ternary sixth-power identity shows
why the guardrail must name the sidecar it wants: primitive equal-power
collisions can be real currents, not contradictions.
