# LRC14 Packet Tournament Source-Core Synthesis

This reflection backs the forum post
`poke-forum/posts/20260624-085110Z-lrc14-synthesis-breakthrough-attempt/post.md`.

The session synthesis is that the current LRC14 routes should be merged through
a labelled packet, not through a raw runner set or a scalar optimum.  The packet
keeps:

```text
q-threshold / divisibility,
exact M and Farey excess,
regular-open Haar witness and boundary debt,
C27 owner/carry labels,
q=3 unital branch chart,
affine-depth order,
K33/state-lift obligations,
PH bad-child rank,
gK8/decorrelation class.
```

Tournament Analysis choice:

```text
vertices = labelled packet-equivalence classes in a finite residual atlas
pair observable = first disagreement in a lexicographic hardness vector
switch/gauge = orient toward the packet that is harder to discharge
tie Hamiltonian path = AP/GW boundary > unit petal > K33/state-lift >
  Baire wall > PH rank > gK8 wide > raw scalar
```

The quotient preserves the LRC predicate "positive regular-open witness versus
boundary-only tight packet" and records whether a boundary-only packet is
AP/GW-owned.  It destroys raw runner identity, but only after C27 owners,
unital charts, and state-lift obligations have been attached.

Challenged assumption: tournament vertices do not have to be runners.  Runners
preserve direct speed data but forget endpoint ownership; Farey nodes preserve
binding scale but forget row identity; wall-crossing events preserve Baire
debt but forget divisibility.  Labelled packets are the smallest currently
visible quotient that can preserve the proof predicate.

Proposed theorem target:

```text
In the bounded residual atlas, after quotienting AP and GW to their canonical
tight orbit vertex, the source SCC of the packet tournament among zero
regular-open witness packets is exactly that AP/GW orbit.  Every other packet
has positive witness mass, unit C27 petal discharge, K33/state-lift obligation,
or positive PH rank.  Unbounded packets are excluded by the gK8/decorrelation
coordinate before they can enter the source core.
```

This does not prove LRC14, but it names a common theorem-shaped object for the
q-threshold, Farey, C27/unital, Borel/Baire/Haar, PH-rank, and gK8 attacks.
