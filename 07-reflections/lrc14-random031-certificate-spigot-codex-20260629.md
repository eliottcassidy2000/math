# LRC14 random031 certificate spigot

The spigot-algorithm reframe of HYP-3521/HYP-3520 is now executable evidence.

The useful analogy is not "digits of pi" as numerology.  It is the operational
rule: emit an output only when all possible future carry has been accounted for.
For random031, the possible carry is terminal proof debt: free-hole bracket
debt, owner-boundary debt, private-label firewall debt, and illegal
vertical-halfturn quotient debt.

The first experiment streams the HYP-3521 terminal certificates in branch/u
order and classifies each as an immediate digit, a predigit requiring bounded
carry, or an unsafe output.  It emits `77` terminal certificates from `79`
component events and covers all `282` cells.  The only held predigits are the
two first halves of HYP-3511 free-hole doublets; both are later emitted by
their mate, so there is no untyped pending carry.

The bypass is the key test.  It emits only after HYP-3520/HYP-3522 sidecars
name the owner-filtration carry:

```text
seam=(23,45,93,113,147,169,173)
transport=(23,93,113)
branch_boundary=(23,93,147,169)
bracket_lift=(147,169)
residual=(45,173)
```

This makes the hard pair a delayed-carry seam, not a phase-flow wall.  The
proof stream can pass through the complement, but the residual `(45,173)` must
remain typed proof debt until the owner-boundary lemma is formalized.

The practical consequence is a cleaner proof queue:

```text
ordinary route digit
free-hole single bracket digit
free-hole doublet predigit -> doublet digit
pure bypass owner-filtration digit with residual (45,173)
```

Every output still carries the HYP-3513 route sidecar `R` and the vertical
halfturn guard.
