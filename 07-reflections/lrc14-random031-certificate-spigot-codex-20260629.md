# LRC14 random031 certificate spigot

Reserved as the spigot-algorithm reframe of HYP-3521/HYP-3520.

The useful analogy is not "digits of pi" as numerology.  It is the operational
rule: emit an output only when all possible future carry has been accounted for.
For random031, the possible carry is terminal proof debt: free-hole bracket
debt, owner-boundary debt, private-label firewall debt, and illegal
vertical-halfturn quotient debt.

First experiment: stream the HYP-3521 terminal certificates in branch/u order
and classify each as an immediate digit, a predigit requiring a bounded carry
buffer, or an unsafe output.  The bypass should be the key test: it can be
emitted only if the HYP-3520 owner-current sidecar is attached.

Assumption challenge: consider vertices such as output certificates, carry
states, proof obligations, quotient guards, owner rows, free-hole packets,
fixed sections, and boundary events.  Do not start with runners or arcs.
