# LRC14 Source-Spectrum Pullback, S149

This session tried to see the missing picture rather than add one more
isolated carrier.

## What Became Fundamental

The most fundamental object is not:

```text
raw speed row,
single tournament,
residue class,
scalar M,
or Haar measure alone.
```

It is the source-labelled spectrum:

```text
t in R/Z
  -> threshold observer-source lift
  -> rooted tournament/packet class
  -> Farey binding node and retained packet labels.
```

HYP-2486 supplies the source predicate.  HYP-2928 supplies the spectrum that
remembers magnitude.  HYP-2947/HYP-2950 supply packet labels.  HYP-2951/HYP-2952
supply boundary filters.  The boundary-moment bridge and proof-DAG post supply
the covering-branch map.

## Two Cores

The history splits into two honest hard cores:

```text
qdiv=14:
  boundary source core.
  AP/GW should be the only zero-open apex source atoms, up to petal/K33 escape.

qdiv>14:
  covering source core.
  no fixed bounded denominator works, so exact-period packet boundaries must
  map to moment positivity or state-lift contradiction.
```

That explains why earlier proof attempts felt close but incomplete.  Many of
them were solving one core while silently assuming the other had been handled.

## New Shape

The synthesis is:

```text
source predicate
  + Farey spectrum
  + Haar/Baire boundary code
  + exact-period packet ownership
  + C27/unital/K33 labels
  + gK8/L_y moment image
  + THM-572 state lift
```

Everything else is a projection of this.

## Proof Attempt

The candidate theorem says every primitive row is routed by its source-spectrum
packet:

```text
qdiv<14: q-clock source witness.
qdiv=14: AP/GW, positive open witness, petal discharge, or K33 debt.
qdiv>14: boundary-moment positivity, impossible AP/GW kernel, or K33/H=7 lift.
```

This does not prove LRC14, but it names the exact missing lemmas and the exact
disproof target: a covering row with zero-open source boundary, zero
boundary-moment image, and no AP/GW or K33 kernel label.

## Assumption Challenge

I considered runners, gaps, Farey nodes, wall-crossing events, exact-period
units, cover arcs, Fourier modes, C27 shells, unital blocks, K33 packets,
missed-depth states, matroid circuits, and proof obligations as vertices.

The chosen quotient uses source-spectrum packets.  It preserves the observer
source predicate, binding scale, boundary/interior distinction, and discharge
labels.  It destroys raw runner identity only after ownership has been
recorded.  That is the smallest quotient I can currently see that does not
recreate one of the known false shortcuts.
