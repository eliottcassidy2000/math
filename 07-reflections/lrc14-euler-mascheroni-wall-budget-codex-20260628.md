# LRC14 Euler-Mascheroni Wall-Budget Reflection

The Euler-Mascheroni prompt is useful only after demotion.  HYP-3430 already
shows that the finite intercept `H_N - log N` is a scalar firewall, not a proof
object for LRC14.  This pass adds the reciprocal endpoint-budget companion:
owner tails can be normalized and ranked, but the finite proof object is still
a survivor interval with branch and endpoint labels.

The exact scout attached reciprocal budgets to HYP-3429 endpoint spines and
HYP-3427 wall windows.  The best endpoint-spine budgets are almost separated
(`144` distinct budgets across `150` rows, only `2` branch/kind collisions),
so the budget is a good ranking sidecar.  The full wall atlas is the guardrail:
`1197` of `1291` harmonic budgets collide across more than one wall signature.
Thus a Mertens/Euler-Mascheroni scalar destroys exactly the data the proof
needs: branch orientation, wall type, endpoint interval, and width.

Recursive pattern:

```text
exact endpoint certificate
-> optional harmonic priority queue
-> scalar collision detected
-> restore wall word / branch / endpoint spine
-> feed HYP-3425/HYP-3426/HYP-3427/HYP-3429 relocation
```

This matches the wider LRC14 sidecar recursion.  Constants and named analytic
normalizers are allowed only as ledgers that help order finite obligations.
They are illegal if they replace the theorem-facing quotient.

Concrete next use: when several rank-2 endpoint spines are available, try the
lowest reciprocal owner budget first, but accept it only after checking the
exact HYP-3429 certificate.  If a future proof tries to state a floor lemma in
terms of harmonic mass alone, HYP-3432 supplies the counter-audit: the scalar
mass is too collision-prone on the existing exact wall atlas.

Assumption challenged: the quotient vertices need not be runners.  Here the
useful vertices were endpoint-wall certificates, component spines, two-adic
loss ledgers, harmonic sidecars, and gamma-shadow normalizers.  The preserved
predicate is the existence of a legal survivor only at the endpoint-certificate
level; the harmonic quotient alone does not preserve it.
