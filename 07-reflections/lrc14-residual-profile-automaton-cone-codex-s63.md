# Residual Profiles As Generated Automaton Words

**codex-2026-06-20-S63.**  HYP-2697 showed that arbitrary nonnegative
residual weights are too strong.  The next refinement is to retain the actual
generated object:

```text
x -> w_x(R),    R subset {1,...,6}.
```

At each fixed slow coordinate `x`, independent cluster carriers update a
64-state hit-mask distribution by OR-convolution; equivalently residual masks
only delete sectors.  This is the Rule-110 lesson in a restrained form: a local
finite update can generate a rich but highly constrained language, so the proof
should reason about the generated language rather than all possible vectors.

The exact coordinate that emerged is the miss-zeta transform:

```text
Z_x(A)=Pr(A is contained in the residual mask at slow coordinate x).
```

For independent context clusters this factors pointwise:

```text
Z_context,x(A)=product_i Z_i,x(A).
```

That product is formed before averaging in `x`.  This matters because HYP-2697
was slightly too coarse when it described weights as `w_R`: the compression
functional actually sees the correlated word `x -> w_x(R)` paired with
`q_C,x(R)`.

The S63 scout tested the three S62 coordinatewise counterexamples against every
coherent-block context generated by integer partitions with total nonzero size
`m=7..11`.  No failures occurred.  Worst exact margins:

```text
(0,1,3)       vs (0,1,2):       20/16807
(0,1,2,4)     vs (0,1,2,3):     37/16807
(0,1,2,3,5)   vs (0,1,2,3,4):   199/24010
```

A smaller near-consecutive frontier scan through size `6` also found no
failures; the weakest contexts were all-singleton or near-all-singleton
products.  This suggests a sharper route:

```text
prove compression for singleton-product context words
  -> prove coherent merging of context carriers does not hurt the margin
  -> combine with THM-557 split gaps
  -> hand near-equality labelled cases to THM-558 transfer tax.
```

There was one important correction during the run.  The original arbitrary
shape code refined `x` only at individual offset-sector walls.  For a
random-phase cluster, the hit-mask law also changes when pairwise offset cuts
cross, so the correct exact wall set includes denominators `7*|a-b|`.  Coherent
blocks were already fine because their difference set is contiguous; arbitrary
nonconsecutive constants shifted slightly.  The qualitative result survived,
and the corrected S62 output is now stored.

The all-singleton context now has a clean exact base lemma.  With `r`
singleton carriers, the context is sector-symmetric and the candidate only sees
its hit-count law through

```text
g_r(t)=7^-r sum_{j=0}^t (-1)^j binom(t,j)(7-j)^r.
```

The script asserts the hit-count formula against the direct 64-mask computation
on the weakest cases.  So the next proof attempt should first prove a
hit-count majorization for consecutive blocks under these kernels.

Rule 110 is not doing mathematical work inside the proof.  Cook's universality
theorem is useful as a discipline: a local rule can generate a constrained
space-time language that is much smaller than the set of all arrays.  Here the
local rule is simpler and monotone: residual bits can only be deleted by hit
masks.  The tournament analogue is also local-bit generated, but the vertex set
for this proof is the carrier quotient, not runner arcs.

No LRC14 proof is claimed.  The new durable object is HYP-2698: the generated
residual cone should be attacked in miss-zeta product coordinates.
