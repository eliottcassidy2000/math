# Partition functions everywhere: H(T), the n+2 recursion, and the game spectrum

The prompt links infinite-Go ordinal game values (Hamkins, MO 299491), an `n+2`
recursion, and "partition functions everywhere." The repo's own S599t already
saw the spine; this session makes the key piece precise.

## H(T) is a partition function, and it factors like a game sum

- **Partition function.** `Z_n = Σ_{T on n} H(T) = #(tournament, Ham-path) pairs
  = n!·2^{C(n,2)−(n−1)}` (verified `n=2..5`). `H` is a sum over configurations
  of a count — a partition function in the literal statistical-mechanics sense.
- **Multiplicative over strong components.** `H(T) = ∏_i H(C_i)` over the
  strongly-connected components `C_i`. This is a **disjunctive game sum**: the
  components don't interact, and the global count is the product of local counts
  (the cluster/exponential-formula structure).

## The n→n+2 recursion (the "add a layer" gadget)

Adding a source and a sink wired transitively (boundary tiles `= 0`) preserves
`H`: `H_{n+2}(inner, 0) = H_n(inner)` (verified, 3000 trials). This is a recursive
gadget that extends the structure without changing the count — the tournament
analogue of the **recursive value-incrementing construction in infinite Go**,
where nesting gadgets builds positions of value `ω, ω·k, ω²`. Boundary tiles `≠ 0`
add the controlled increment terms.

## The gaps {7,21}, explained by the strong monoid

Because `H` is multiplicative over strong components,

> **achievable H = the multiplicative monoid generated by the STRONG (SC)
> H-values.**

The strong H-values (computed `n≤7`) are odd and **miss 7 and 21**. So the
*permanent* gaps `{7,21}` are exactly the odd numbers that are **never a strong
H-value at any `n` and not a product of strong values**: `7` is prime and
non-strong (THM-200 proves it non-strong for all `n`); `21 = 3·7` would need the
forbidden `7`. This reframes the impossibility question: *the H-gaps are gaps in
the **strong** spectrum, propagated multiplicatively.*

**Honesty note (a trap I fell into and corrected).** A bounded-`n` monoid
*looks* like it has extra gaps — `{7,21,35}` from `n≤6` strong values, `{7,21,63}`
from `n≤7`. But `35` becomes a strong value at `n=7`, `63` at `n=8`, `189` at
`n=8`. So `35, 63, 189` are **not** permanent gaps, and the tempting `7·3^k`
family is **refuted**. Only `{7,21}` are conjectured permanent (7 proved).

## The infinite-Go analogy (made precise)

| infinite Go (Hamkins) | tournaments |
|---|---|
| game value of a position (ordinal) | `H(T)` |
| disjunctive sum of games → value adds | strong-component split → `H` multiplies |
| indecomposable gadget values | strong (SC) H-values |
| achievable value spectrum | monoid generated by strong H-values |
| recursive value-building gadget | the `n→n+2` source/sink layer |
| ordinals unreachable by the recursion | the H-gaps `{7,21}` |

So the H-value spectrum *is* the tournament shadow of the infinite-Go ordinal
game-value spectrum: both are the reachable set of a recursive, sum-compatible
value function, and both have a structured set of unreachable values.

## The 0.014 numerology — honest assessment

The prompt notes `0.014` as both the unit-distance disproof excess and "the
shape-parameter growth for SC tournaments." Three numbers cluster near `0.014`:
- UD disproof excess `0.014` — a *lower bound* (Sawin), no closed form;
- `Cl₂(π/3) − 1 = 0.01494` — the SC tournament tropical constant (HYP-707),
  structurally grounded in the **prime-3 / Eisenstein angle `π/3`**;
- assorted root ratios (`~0.0143`) in the `n=6` root spectrum.

They are **numerically close but not shown equal.** The only one with a real home
is `Cl₂(π/3)−1` (prime-3). The shape parameter `s = α₁/√α₂` (SC tournaments
maximize it, ULC) is a genuine object, but "its growth rate `= 0.014`" is
**unverified** — likely a coincidence among prime-3-flavored constants unless a
derivation ties the SC `s`-growth to `Cl₂(π/3)`. I flag this rather than assert it.

## Partition functions everywhere — the species

`H(T)`, the LRC depth polynomial `P(z)`, the independence polynomial `I(Ω, x)`,
and combinatorial game values are **one species**: partition functions with a
multiplicative/cluster (disjunctive) structure over independent parts, whose
**achievable-value spectra have arithmetic gaps**. The gaps are where the
recursion + composition cannot reach — `{7,21}` for `H`, the impossible `M` for
LRC, the unreachable ordinals for Go. This is the unifying lens the whole arc has
been circling.
