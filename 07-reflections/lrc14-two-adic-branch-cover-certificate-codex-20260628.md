# LRC14 Two-Adic Branch-Cover Certificate

This pass made the two-adic relocation route feel more theorem-shaped after the
incoming HYP-3425 two-color Helly audit, HYP-3426 mirror reduction,
HYP-3427 wall-signature atlas, HYP-3428 two-adic loss ledger, and HYP-3429
endpoint-spine certificate, with HYP-3430 now supplying the scalar-firewall
warning against harmonic-tail-only closure and HYP-3431 supplying the canonical
`84m` corridor-fence base case.  HYP-3432 now supplies the reciprocal
wall-budget priority queue for endpoint debt.  HYP-3422 already had the right
interval target,
HYP-3425 identified the bad core `B0_odd cap B1_odd`, HYP-3426 reduced the
branch symmetry, HYP-3427 named the walls, HYP-3428 named the legal forgetting
risk, HYP-3429 compressed survivor endpoints, and HYP-3430 showed that
Euler-Mascheroni/Mertens/loglog tail scalars need endpoint sidecars before they
can talk to the floor.  HYP-3431 proves that this is not merely bookkeeping in
the canonical tower: the actual wall corridors survive for all `m`.  HYP-3435
changes the general object to a finite certificate:

```text
an even-good component,
a chosen branch cell,
and the active odd/even endpoint gates that keep it alive.
```

That is a better proof handle.  A failed row no longer just says "branch measure
zero"; it should emit a minimal cover of `E_safe` by two odd branch-bad
families, together with the even gates defining the component.  HYP-3425 is the
component-gap theorem shape, HYP-3426 and HYP-3427 tell us which branch and wall
data must survive, HYP-3428 supplies the loss-ledger guardrail, HYP-3429
supplies the endpoint-spine compression, HYP-3432 ranks which endpoint debt to
try first without accepting scalar debt as proof, and HYP-3435 is the active
endpoint ledger that should make those gaps classifiable.

The finite stress test did not find a failure.  It audited `135` primitive
covering rows, including structured AP-with-tail families and `120`
deterministic random covering rows.  Both branches were positive in every row,
and the tightest branch-union certificate remained the AP-with-84 row at exact
measure `1/105`.

The most useful surprise is that the selected active roles are mixed:
`odd_unit`, `even_R`, `seven_R`, and `14Q` all appear as active binders.  That
keeps us honest.  The proof cannot simply say "the 7-adic layer is irrelevant"
or "the odd layer is harmless."  The floor is two-adic, but the finite witness
still needs a role ledger so the other arithmetic species are routed rather
than erased.

This also clarifies how to use owner-current work.  HYP-3417 and HYP-3420 are
not the branch lemma, but they are exactly the right place to send small
endpoint-gate ledgers.  When a branch-cover attempt has a tiny mixed set of
odd/even gates, owner-current/Menger labels can name and discharge it.  The
interval theorem remains the floor carrier.

HYP-3423 remains the warning label.  A topology or C6/Galois quotient can
organize residue structure, but a branch-cover certificate is q-specific
magnitude data.  If a quotient forgets the endpoint gates and still claims the
covering floor, it has forgotten the thing that matters.

The HYP-3430 scalar firewall now attaches to the same lesson: analytic tails
can be useful calibrators for denominator entropy, but they are not proof
carriers unless the endpoint-owner, wall/loss, branch-cell, exact-period, or
state-lift sidecar is still present.
HYP-3432 makes the constructive version of that rule: reciprocal wall budgets
are excellent for prioritizing endpoint ledgers, and terrible as quotients once
they forget branch orientation or wall words.

The next proof-facing computation should invert the current script.  Instead of
recording successful midpoint witnesses, enumerate each component of
`E_safe(1/14)` and compute minimal certificates for a hypothetical cover by:

```text
odd_low_bad intervals for branch 0,
odd_high_bad intervals for branch 1,
even endpoint gates defining the component.
```

If every minimal cover is impossible by interval order, two-adic descent, or
owner-current routing, HYP-3422 becomes a finite lemma rather than a heuristic
relocation picture.

## Creative Extensions

Three reframes look worth trying next.

First, treat each `E_safe` component as a tiny courtroom.  Even gates define the
walls, odd low-bad intervals accuse branch `0`, and odd high-bad intervals
accuse branch `1`.  A counterexample has to convict both branches everywhere in
the room.  That suggests an interval jury theorem: every full conviction has a
small witness set of endpoint gates, and those small witness sets may already
be owner-current or two-adic descents in disguise.

Second, turn the branch pair into a two-color discrepancy problem.  On each
even-good component, branch `0` bad intervals and branch `1` bad intervals are
two colors of odd obstruction.  A successful covering counterexample needs both
colors at every point.  The Haar-product lessons say fixed margins are not
enough; the mixed color coefficient or endpoint cocircuit must be retained.
Here that mixed coefficient should be the low-bad/high-bad overlap pattern on
the finite ruler.

Third, view the selected branch witness as a legal quotient test.  The witness
for AP-with-84 is small but exact; if a quotient cannot reconstruct why
`t=2293/3920` survives, it is not allowed to claim the covering floor.  That
turns HYP-3435 into a guardrail for future simplifications: every simplification
must either preserve branch cells, reconstruct them from endpoint gates,
annihilate the missing coordinate by dual certificate, or name residual debt.
HYP-3430 adds one more acceptable exit: use a scalar tail only as a calibrated
shadow after the finite certificate data has survived.  HYP-3432 sharpens that
exit into a budgeted search order over labelled endpoint debt.
