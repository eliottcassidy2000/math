# LRC14 Owner-Current And Tropical-Wall Angles

The useful point in this session is the negative selection rule: do not turn
HYP-3311's residue-word success into the next proof slogan.  It was a real
bank-local separator, but the same line of work already says where it can fail:
same-residue height flex, endpoint-owner loss, and off-grid floor loss.

The two new angles deliberately target those failure modes.

## Endpoint Current

Endpoint owners should be treated as current boundaries, not labels.  If a
quotient removes an endpoint owner, the proof should be forced to say whether
the current is conserved, dualized by a Farkas/Green certificate, stopped by
AP/GW boundary H1, sent to an H7 state-lift sink, or named as debt.

This would sharpen a lot of older owner/barcode/normal-fan notes.  Instead of
asking whether owner sidecars distinguish rows, ask whether they satisfy a
conservation law that can survive descent.

## Tropical Wall

The tropical angle is the height-side counterpart.  HYP-3311 shows `v2` alone
can keep a mixed theorem-exit fiber alive.  HYP-3260 already has same-residue
height decoys.  So the next useful coordinate may be a bend, not a residue:
which valuation owner changes first, which Newton polygon edge becomes active,
or which secondary-fan wall is crossed.

This makes the `12->24` hinge a wall case rather than a numerology case.  A
same-residue or same-v2 flex should either cross a wall that gives positive
off-grid floor, land on the AP/GW hinge, or emit named height-discriminant debt.

## What To Test Next

The next computation should enlarge HYP-3311 and attach two new columns:

```text
owner_current_word
tropical_wall_word
```

Then classify the first leakage:

```text
residue exact
owner-current repairs residue failure
tropical wall repairs v2/height failure
both fail -> named debt
```

That is more theorem-facing than another scalar ranking because it turns each
forgetting failure into a conservation, wall-crossing, or debt statement.
