# Kakeya needles are an adaptive graphic rank, not a dimension analogy

*codex-S16, 2026-07-15. Exact general identity plus a finite exact n=12
near-AP audit. This does not prove that the sporadic branch is empty.*

## The rigorous connection

Fix a strict-safe prefix `E` and remaining danger combs

```text
A_i=E intersect D_(u_i),       D_u={t: ||ut||<=1/13}.
```

At `t in E`, let `S(t)={i:t in A_i}`.  Regard the comb labels as vertices of
`K_m`, and let `r(t)` be the graphic-matroid rank of the clique induced by
`S(t)`.  Then

```text
r(t)=max(|S(t)|-1,0),
1_(S(t)=empty)=1-|S(t)|+r(t).                              (1)
```

Consequently the uncovered safe mass has the exact all-order identity

```text
mu(E minus union_i D_(u_i))
 =mu(E)-sum_i mu(A_i)+integral_E r(t) dt.                  (2)
```

This is the non-decorative Kakeya connection.  The periodic combs are
directional needles, but their difficult statistic is not dimension.  It is
the spatially varying basis rank of the active direction bush.

Equation (2) also identifies exactly what Hunter--Kounias forgets.  For a
fixed spanning tree `T`, the edges of `T` induced by `S(t)` form a forest and
therefore number at most `r(t)`.  Hence

```text
integral r(t) dt
 >= max_T sum_(ij in T) mu(A_i intersect A_j).
```

The difference

```text
Gamma_E
 =integral_E max_T sum_(ij in T)1_(A_i)1_(A_j)
  -max_T integral_E sum_(ij in T)1_(A_i)1_(A_j)            (3)
```

is the **tree-adaptivity gap**.  THM-856 is the lower bound obtained by
discarding `Gamma_E`.  The open endpoint/third-moment language can therefore
be described more sharply: it is the cost of forcing one global pair-overlap
tree to represent bushes whose best tree changes over the safe set.

## A monotone localization lemma

Let `P` be any finite measurable partition of `E`.  For a cell `C`, give edge
`ij` weight `mu(C intersect A_i intersect A_j)` and write `MST_C` for its
maximum spanning-tree weight.  Put

```text
H_C=mu(C)-sum_i mu(C intersect A_i)+MST_C,
L(P)=sum_(C in P) max(0,H_C).                              (4)
```

Then

```text
0 <= L(P) <= mu(E minus union_i A_i).                      (5)
```

If `P'` refines `P`, then `L(P')>=L(P)`.  If `P` is the Boolean activation
atom partition generated by the `A_i`, equality holds in (5).

Proof: the fixed-tree forest inequality above gives `H_C` at most the
uncovered mass in `C`; clipping is therefore valid.  On splitting a cell,
`MST(w_1+w_2)<=MST(w_1)+MST(w_2)`, so refinement cannot decrease the clipped
sum.  On an activation atom with active set `S`, a tree can take exactly
`|S|-1` internal edges when `S` is nonempty, giving `H_C=0`; on the empty atom
`H_C=mu(C)`.  Thus the atom partition recovers the uncovered mass exactly.

This lemma is useful even before full atomization.  For the partition into
literal safe components,

```text
sum_C MST_C-MST_E <= Gamma_E,                              (6)
```

so component-to-component Kruskal-tree changes contribute certified positive
"bush credit."  It is a computable intermediate carrier strictly between the
global Hunter graph and exact interval union.  A rooted version first inserts
one needle, partitions the residual into its safe components, and applies the
six-comb union bound cellwise.  It crosses the seven-comb first-moment wall
without claiming a uniform global decorrelation estimate.

## Exact n=12 audit

The companion exact-Fraction script takes each first proper Hamming-one packet

```text
([12] minus {r}) union {r+13},       r=1,...,12,
```

uses its five smallest speeds as the prefix, and treats the other seven as
needles.  Exact endpoint atomization verifies (1)--(6) on every row.

One global Hunter tree is positive on only `3/12` packets.  Component-local
Hunter is positive on `12/12`, as is the rooted-six-comb screen.  For the
representative `r=6` packet the global bound is negative,

```text
global Hunter = -634/9009,
component-local clipped Hunter = 1/8151,
root at needle 12 = exact uncovered mass = 1/286.
```

This finite bank was already known loose by stronger Hamming recursion; the
new contribution is the general certificate and the measured fact that it
recovers all twelve rows while a global pair tree misses nine.  It is a method
test, not new sporadic-branch closure.

## Torus/Kakeya duality and its limit

There is an exact two-torus lift.  Let

```text
G_u={(t,ut):t in T} subset T^2,
H={y:||y||<=1/13}.
```

Then `D_u` is the `t`-projection of `G_u intersect (T times H)`, and cover of
`E` says that these fixed-slope graph sections project onto `E`.  Equivalently,
for the incidence operator

```text
(Tf)(u)=integral_E f(t)1_(D_u)(t)dt,
```

cover is equivalent to `integral_E f <= sum_u (Tf)(u)` for every nonnegative
`f`.  Endpoint-atom indicators are a finite exact dual test family.

This is closer to a fixed-intercept Nikodym/X-ray problem than to Euclidean
Kakeya.  Classical Kakeya lets one translate a needle independently in every
direction and asks about ambient dimension or measure.  LRC fixes all
intercepts to zero and asks about the one-dimensional projection of strip
hits.  Allowing independent phases `||ut-alpha_u||<=1/13` leaves the LRC
slice.  Therefore Besicovitch small-measure constructions, Kakeya maximal
estimates averaged over directions/translates, and Dvir's polynomial method
do not transfer as LRC theorems.  The transferable object is incidence
localization and its dual weights, not a dimension bound.

## Tournament analysis and challenged vertices

Using runners as tournament vertices is already too coarse because the key
pair weights are symmetric.  The audit instead uses the 21 pair-overlap
obligations as vertices.  Exact local overlap mass is the observable;
descending mass with lexicographic speed-pair ties is the Hamiltonian path.
Every component tournament is transitive (`score 0,...,20`, no directed
cycles, singleton SCCs, one Hamiltonian path), yet in the `r=6` witness the ten
safe components realize five distinct edge orders and five distinct Kruskal
trees, with `77` to `135` tournament edge flips from the global order.

The tournament preserves local Kruskal priority only when the original
`K_7` edge incidence is retained as a sidecar.  It destroys the activation
atoms and therefore the exact rank integral.  Better vertices, in increasing
fidelity, are

```text
runners -> pair obligations -> local Kruskal bases
        -> activation patterns S(t) -> literal endpoint atoms.
```

The proposed next experiment for the still-open radius-seven chart is thus
specific: compute component-local or one-pivot-localized Hunter credit before
adding a larger Fourier or Fano quotient.  If the localized credit is still
nonpositive, the residual names an explicit set of activation atoms rather
than an undifferentiated "third moment."  If it is positive, it supplies a
short exact cover certificate without executing the full atom union.
