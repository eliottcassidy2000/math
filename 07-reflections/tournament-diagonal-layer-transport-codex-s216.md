# Tournament diagonal-layer transport - S216

The useful correction in this pass is that the user's `k^2+k` edge set should
live between geometric tile positions, not between binary word values.

Once that is fixed, the algebra gets clean.  Consecutive diagonal layers of
lengths `k` and `k+1` have the complete position carrier `K_{k,k+1}`, but the
binary labels on its lines are generated by two words `w` and `u`.  The line
count matrix is rank one:

```text
N00*N11 = N01*N10.
```

So the carrier has many lines, but those lines are not many independent
coordinates.  They are a structured redundancy.  The aligned diagonal plus the
link bit `u_k` is the part that updates directed triangles using the two newest
vertices:

```text
#{i<k : w_i = u_k and u_i != u_k}.
```

The exact tournament recursion is:

```text
parent class + diagonal word orbit under Aut(parent)
  -> rooted child class
  -> unrooted child sink through deletion fibers.
```

The small exact table is satisfying:

```text
5 -> 6:
raw labelled extensions = 384
parent-aut word orbits = rooted 6-count = 296
unrooted sinks = 56
```

This now sits after HYP-3051 rather than replacing it.  HYP-3051 gives the
rooted layer-extension sheet: `k^2+k` apparent lines collapse to boundary
potential data before unrooting.  This pass keeps going through the unrooting
fiber, records the deletion-parent multiplicities, and checks the half-tiling
count temptation directly.

That is the mechanism behind the S211 perspective defect.  The old comparison
`P(5)=48` versus `U(6)=56` was trying to compare a rooted cache one size too
small with unrooted child classes one size up.  The missing object is the
diagonal incident word, not deeper node memory and not a raw half-tiling count.

After the HYP-3049 edge-perspective lift, that same missing object has a second
name: an ordered-pair sector deck around `(old root, new observer)`.  Its first
non-redundant extension column is `cross_sector_orientation_word`.  So the
diagonal-layer law gives the recursive source of the payload, while the
edge-sector law gives the smallest observed column that separates the six-class
fiber.

The half-tiling idea still matters, just in a more precise role.  It is the
converse-fold branch/fundamental-domain input.  It explains symmetric
diagonal behavior and self-converse structure, but `U(n)` is not the number of
binary half-tilings of size `n-1` or `n`.  The script's check makes the
guardrail concrete: `U(6)=56`, while `2^half(5)=16`,
`2^half(6)=64`, and self-converse 6-classes are `12`.

For LRC this says: do not keep raw tournament class, raw half-tiling count, or
raw position-line count as the proof state.  Keep the transport sidecar:
parent class, diagonal word orbit, position-line profile, aligned pair counts,
newest link bit, deletion-parent fiber, and endpoint-owner/proof-obligation
labels.  That is exactly the controlled-forgetting rhythm from HYP-3039 and
HYP-3047, but now attached to the growth layer itself.
