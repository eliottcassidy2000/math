## Inheritance pass and beach search

The assigned antecedent was the conditional operation in the prior


The closest proved response mechanism is THM-3110.  Its formal response
algebra is generated by normalized monomials `f_t`, with the underlying
power sums primitive and the formal exponentials group-like.  The canonical
hostile is still the minimal blocker

```text

```

and the corrected near miss is still that an `F12` reset deletes an
obligation but releases no state register.  The least-used relevant sidecar
was not another controller bit.  It was THM-3110's group-like normalization.

The beach search compared six older operations.

- **Polarization.**  THM-3110 constructs the factorial invariants from
  collision differences `U=f_a-f_0` and `V=f_b-f_a`.  These are differences
  of group-like elements, not themselves group-like.
- **Coalgebra.**  The symmetric-function coproduct is induced by disjoint
  alphabet union.  It is the natural place to ask whether a removed pole
  multiset can be seen twice.
- **Diagonal versus physical action.**  THM-2870 warns that an algebraically
  full action need not intertwine a physical diagonal.  Here the warning
  becomes a typing separation between a formal state unit, a response
  current, and a controller transition.
- **Correlated diagonal.**  THM-2884 shows that a diagonal fibre product can
  be a genuine carrier while still losing origin character and ancestry
  carry.  The same kind of boundary appears here.
- **Proof obligations.**  THM-3115 and THM-3127 organize each normalized
  response as a zero-mass partition current.  Zero mass is precisely the
  augmentation condition that obstructs cloning the current.
- **Face tags.**  THM-3278 makes the origin bit a static cut coordinate.  A
  labelled-set unshuffle can split a pair tag algebraically, but this does
  not make the tag a released physical register.

This changes the question.  “Does a diagonal exist?” has two different
answers depending on which object is asked to cross it.

## Source, target, map, predicate and loss

Let `Sym` carry its usual alphabet coproduct

```text
Delta p_k = p_k tensor 1 + 1 tensor p_k.                (2)
```

For a physical removed pole multiset `sigma`, define the formal unit

```text
g_sigma(X)
 = product_(r in sigma, x in X) (1+r x)^(-1)
 = exp(sum_(k>=1) (-1)^k p_k(sigma)p_k(X)/k).           (3)
```

Because the `p_k(X)` are primitive,

```text
Delta g_sigma = g_sigma tensor g_sigma.                 (4)
```

Equivalently,

```text
g_sigma(X+Y)=g_sigma(X)g_sigma(Y).                       (5)
```

This is the exact product-Gamma endpoint diagonal.  It is not a metaphor and
does not suffer the naive degree-doubling obstruction: `g_sigma` is a
constant-term-one formal unit, not a homogeneous state polynomial.  Multiset
union is multiplication, so

```text
g_(sigma disjoint-union tau)=g_sigma g_tau,              (6)
```

and `(4)` is multiplicative, cocommutative and coassociative.

For the face obligation, use the full labelled-set coalgebra

```text
Delta_F [A] = sum_(B disjoint-union C=A) [B] tensor [C]. (7)
```

The ordered component

```text
[F13,F23] --> [F13] tensor [F23]                         (8)
```

has coefficient one, as does its reverse.  Tensoring `(4)` and `(8)` gives
the smallest algebraic candidate

```text
[F13,F23] g_b
  --> ([F13]g_b) tensor ([F23]g_b).                      (9)
```

The exact ledger for `(9)` is:

```text
source:    pair face tag and removed-state unit g_b;
target:    two face-tagged response-algebra factors;
map:       group-like endpoint coproduct times the ordered unshuffle component;
predicate: exact endpoint state, hence exact recomputation of each face's
           response coordinates and reset-directed singleton choices;
loss:      selected response row, actual path ancestry, released/old origin
           assignment, activation by the F12 certificate, and chronology.
```

The ordered projection in `(8)` is already new controller structure.  The
full coalgebra `(7)` also contains the unit/pair, pair/unit, and reverse
components.  Selecting one term and attaching its factors to the released
and old origins is not an inherited physical edge.

## First failed law: centered obligations cannot be group-like

The positive endpoint result does not extend to the response obligation.
For each face, state and maintained degree, the normalized partition current
has augmentation zero:

```text
epsilon(c)=sum_mu c_mu=0.                                (13)
```

The scout checks all

```text
35 states x 2 faces x 10 degrees = 700 currents.         (14)
```

Every one is nonzero and every one has exact mass zero.

Now let `(C,Delta,epsilon)` be any counital linear coalgebra.  If a response
current were copied by

```text
Delta(c)=c tensor c,                                     (15)
```

then applying the left counit would give

```text
c=(epsilon tensor id)Delta(c)=epsilon(c)c=0.             (16)
```

Hence no nonzero centered current can satisfy `(15)`.  This is the first
failed algebraic law, before positivity or scheduling enters.

The native coproduct displays the missing terms directly.  Since `f_0=1`
and `U=f_a-f_0`, one has

```text
Delta(U)
 =U tensor 1 + 1 tensor U + U tensor U,                 (17)
```

not merely `U tensor U`.  The one-sided terms in `(17)` are forced by the
counit.  The same issue propagates through the polarized factorial
invariants.  Consequently the response algebra can copy the group-like
state unit and then **recompute** two centered currents, but it cannot clone
one centered proof obligation into two.

The linearity boundary is visible even before using `(13)`.  For two known
basis states `b,c`, the classical diagonal sends

```text
e_b+e_c --> e_b tensor e_b + e_c tensor e_c.            (18)
```

The nonlinear square contains the two additional cross terms.  Thus the
endpoint coalgebra copies a known classical state, not an arbitrary signed
response superposition.

## Second failed law: endpoint algebra cannot recover actual ancestry

The rows-`{16,17}` generated closure has a unique blocker for each of the
`94` starts, but its endpoint fibres contain many row-labelled paths:

| blocker | starts | min paths/start | max paths/start | total paths |
|---|---:|---:|---:|---:|
| `C union {1,2}` | 47 | 6 | 95,694 | 224,770 |
| `C union {1}` | 16 | 6 | 3,796 | 6,330 |
| `C union {2}` | 24 | 6 | 12,310 | 26,440 |
| `C` | 7 | 6 | 106 | 370 |

The product-Gamma element and response vector depend on `(face,b)`, not on
the start or path.  Distinct actual histories therefore have the same image.
No function factoring through that endpoint image can return the actual
chosen history: it would have to take one value on a fibre and equal several
different paths simultaneously.

Equation `(4)` consequently copies `b`; it does not supply the
`COPY_FROM_SHARED_ANCESTRY` link required in `(1)`.  This is an
information-loss obstruction rather than a sign obstruction.

## Strongest survivor and the changed next object

The strongest exact survivor is:

```text
the product-Gamma response algebra has a native group-like diagonal on the
removed endpoint alphabet; after adjoining a face-set unshuffle and retaining
the two factors separately, it recomputes successful singleton continuations
on every tested blocker.                                  (19)
```

What fails is the proposed interpretation of `(19)` as a comultiplication of
the proof obligation itself.  The correct next object is therefore not
another coproduct on centered currents.  It is an **ancestry-decorated
comodule or span**:

```text
actual shared path --endpoint--> group-like state unit
       |                              |
       | immutable provenance         | facewise coaction/recomputation
       v                              v
two registers sharing one path ID   M_13 tensor M_23.   (20)
```

Such a construction could avoid cloning a zero-mass current: it would copy a
classical path identifier, copy the group-like endpoint unit, and recompute
each centered obligation in its own face module.  It would still have to
derive three things absent here:

1. an inherited or independently justified path/provenance object;
2. a gate tying the `F12` completion certificate to the current pair path;
3. a typed assignment of the two output factors to the released and old
   origins without asserting a shared chronology.

The cheapest next decisive test is therefore a pullback, not a larger row
search: retain one exact shared path ID and ask whether the `F12` certificate
and pair path have a lawful common source object from which the endpoint
coaction `(9)` descends.  Failure should be recorded as a missing pullback or
provenance law; success would still be a new carrier extension, not inherited
`FC(3)` mathematics.
