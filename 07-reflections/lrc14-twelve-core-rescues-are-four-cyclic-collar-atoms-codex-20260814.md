## 4. Why q=6 gives seven rows, not nine

The q=6 minimal edge is

```text
E={3,8,11,13}.                                        (6)
```

With one core clock, a body needs one more transverse speed.  Six choices are
inert on the cover phase set:

```text
x in {1,5,7,9,10,14}.                                 (7)
```

For every such `x`, the full cover set of `E union {x}` is still exactly
`A_6`, so core clock `1` traps it.  A two-clock body uses `E` itself with core
`{1,2}`.  These give `6+1=7` rescues.

The omitted extensions `x=2,4` are not cosmetic exclusions.  They enlarge the
cover set through every strict core boundary; in particular `t=1/84` and its
sixth-translates become transverse-cover points while core clock `1` is exactly
on its open boundary.  Thus strictness supplies a hostile control separating
inert extension from active extension.

## 6. Boolean, Fourier, and tournament views

Each atom has the Boolean form

```text

```

where `+` denotes translated union.  This is a much smaller carrier than the
raw sheet-by-speed incidence table.  It preserves the exact core-containment
predicate while forgetting which non-boundary owner certifies an interior
point; equation `(3)` is the sidecar that restores that ownership.

Fourier-dually, `(9)` is the convolution of a finite subgroup/coset comb with
a symmetric collar indicator.  The q=3 centre comb has support on modes
divisible by three, while the q=6 comb has support on modes divisible by six;
the parity fill `(5)` is therefore a literal mode filter.  This may be a useful
small hostile model for the repo's spectral-closure program, but it is not a
7-by-13 bispectrum nonvanishing proof.

A tournament sees still less.  It can order the active owners at an interior
point or orient which endpoint owner enters first.  It cannot retain the
radial magnitudes, simultaneous antipodal loss at q=6, or containment inside a
core interval.  The faithful object is a cyclically translated, owner-labelled
interval complex.
