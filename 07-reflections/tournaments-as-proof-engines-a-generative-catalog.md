## The meta-structure: every tournament proof is (ENCODE) × (LEVER) × (MODE)
A tournament is a complete asymmetric relation carrying **rigid invariants** — facts that *must* hold. A
proof using tournaments is generated by three independent choices:

- **ENCODE** — what are the vertices, what is the arc?
  vertices ∈ {elements, pairs, residues, odd-cycles, packets, configs, primes, dims, time-intervals,
  sectors, moments, colors}; arc = an asymmetric relation {dominates, beats-by-majority, contains, divides,
  overlaps-more, precedes, has-larger-invariant, resonates}.
- **LEVER** — which rigid invariant is the engine (see table below).
- **MODE** — {OBSTRUCT (disprove), TRANSFER (prove), COUNT (enumerate), BOUND (extremal), CLASSIFY (quotient)}.

Crossing these *generates* techniques. The known forbidden-H proof is `(vertices=odd-cycles, arc=share-a-vertex)
× (LEVER=H-spectrum hole) × (MODE=obstruct)`. Below: the levers, then 12 generated techniques (novel ones ★).

## The 12 generated techniques
**OBSTRUCT (disprove by landing in a hole / violating rigidity)**
1. **Forbidden-H transfer.** Encode X so its truth ⟺ a tournament with `H∈{7,21}`. Land in the hole ⟹ X false. *(the canonical one.)*
2. ★ **Realizability-hole = forbidden-H.** Any "value is moment/flag-feasible but not realizable" problem (numerical-semigroup gaps, baby-Hodge cycle-count holes) **is** a forbidden-H instance: the realizable set of an additive tournament invariant has holes. Show the target lands in a hole. *Target: baby-Hodge holes (OPEN-Q-099); the cap dips.*
3. **Completeness-forcing amplifier.** Encode X so that "every pair is related" forces a contradiction-generating substructure (the THM-029 5-cycle). *Target: any "this sparse partial structure can't be completed."*
4. **Even-cycle-blindness counterexample (THM-454).** Find what an invariant ignores; build two objects equal on it, differing in truth. *Target: disprove "invariant determines property."*

**TRANSFER (prove by satisfying a tournament theorem)**
5. **Rédei parity (Z/2).** Force an odd/even count via #Hamiltonian-paths. *Target: parity degeneracies — the apex-7 antipodal pigeonhole (HYP-2907).*
6. ★ **Score-majorization / exchange.** Encode X as a tournament; a Schur-convex functional extremizes at the score-majorization extreme (transitive = consec / regular = balanced). The **improvement digraph** on configs is a tournament; if it is **transitive (no 3-cycles)**, greedy/exchange reaches the unique optimum. *Applied to cap optimality — see "what applying it revealed" below.*
7. **Ramsey bound (Erdős–Moser).** Every tournament on `≥2^k` vertices has a transitive sub-tournament of size `k+1`. Encode X; if X forbids large transitive subsets, `n` is bounded. *Target: cap the size of a structure.*
8. **Landau feasibility.** A target score/degree profile is realizable iff Landau holds; violate ⟹ impossible. *Target: degree-constrained existence.*

**BOUND / CLASSIFY / COUNT**
9. ★ **Winding-tournament IVT / continuity obstruction.** Encode a *continuous* family as a path in the metagraph (the winding tournament `T(t)`). `H(T(t))` is a discrete invariant; if the family must interpolate across a **forbidden value** (a spectrum hole the path can't occupy), the family is **disconnected / must jump**. An intermediate-value obstruction powered by the spectral gap. *Target: the V\* crossover (a real jump!), phase transitions in continuous families.*
10. ★ **H-gradient thermometer.** `G_n` has a strong `H`-gradient (most edges H-increasing). Encode a process as a walk on `G_n`; the gradient is a Lyapunov/monovariant ⟹ termination/convergence. *Target: termination/convergence proofs.*
11. **SCC-factorization sieve.** `H=∏H(C_i)`; a composite target needs a factorization into realizable factors. `21=3·7` with `7` forbidden ⟹ forces connectedness. *Target: multiplicative-invariant realizability (dip denominators).*
12. **Metagraph chromatic lower bound.** `χ(G_n)=n−1`, `χ(E_n)` larger. Encode a partition/coloring as the metagraph ⟹ a forced lower bound on parts/colors. *Target: covering/partition lower bounds.*

## What applying #6 (exchange) revealed — a diagnostic, not a proof (VERIFIED S65)
Applied the improvement-tournament/exchange technique to my own open frontier — the cap-minimizer optimality
(THM-576/577, value symbolic, optimality open). `04-computation/lrc_cap_optimality_exchange_macmini_S65.py`:
- **Bounded:** the minimizer is identical over speeds `{1..13},{1..16},{1..20}` — no unbounded speed helps, so
  **optimality is a finite check** (a positive, reusable fact).
- **j≤4 (k≥9):** greedy descent reaches the top-cluster — the exchange argument *works*.
- **j=5 (k=8):** greedy gets **stuck** at `{1,10,11,12,13}` while the true min is the break config
  `{1,5,7,8,9}`; the single-swap improvement digraph has **4 spurious local minima** at j=3
  `({1,12,13},{2,9,11},{3,10,11},{5,8,9})` — i.e. it is **NON-transitive (has 3-cycles)**.
> **The technique's verdict: cap-optimality has no clean exchange proof because the config improvement
> tournament is non-transitive; the difficulty (k=8 break) IS that non-transitivity, and optimality reduces
> to a finite check (bounded minimizer + finitely many local minima to rule out).** The tournament lens
> turned "why is this hard" into a precise statement — exactly the diagnostic mode of #6.

## Three applications this session (verdicts; full detail in HYP-3099)
- **#6 exchange → cap-optimality (App A):** *diagnostic.* The minimizer is **bounded** (finite check), but the
  config improvement tournament is **non-transitive** (4 spurious local minima at j=3; greedy stuck at the k=8
  break). No clean exchange proof; the difficulty IS the non-transitivity.
- **#2 realizability-hole → baby-Hodge (App B):** *corrects an over-claim.* Holes like `(8,10)` are **c5/spectral**
  exclusions (neighbors carry realizable `H=41,43`), **orthogonal** to the α₂/forbidden-H gap (THM-499 two-layer).
  Forbidden-H closes only the `{7,21}` α₂-family; the deep bridge (THM-200 directed-C5 = E₇ pentagon) is OPEN.
- **#1/#5 forbidden-H → apex-7 ↔ H=7 (App C):** *refutes a slogan.* Coincidence: the winding tournament avoids
  H=7 *vacuously*; the real apex-7 is `n/2` antipodal diameters = a **triangle-free perfect matching** (opposite
  of K₃). The genuine lever is the **order-2 antipodal / odd-|Aut|** obstruction (reduces to consec-maximizes).

**Meta:** the techniques here mostly *diagnose* and twice *refute a false bridge with evidence* — killing
seductive coincidences is half the value of the catalog.

## How to use this catalog
For any target: pick the MODE (disprove → 1-4; prove → 5-8; bound/count → 9-12); choose an ENCODE that makes
the relevant LEVER bite; check the lever's exact constraint against the target. The novel levers (★ 2, 6, 9,
10) are the under-explored frontier.
