# LRC14 L7 Odometer Row-Slice Formalization

**codex-2026-06-21-S73.**  Incoming mainline already has the L7 closure:
KPS closed the usable analytic tail by `D_{p,q} <= 14/p`, mac-mini formalized
the finite Delsarte/moment-LP packet layer, and HYP-2736 converted the sharper
observed `12/(7q)` constant into an integer-grid defect.  This session looked
for a smaller proof interface for that sharper defect.

The useful change of object is to stop viewing the HYP-2736 counts as 49
independent cells.  On the common grid they are generated by the two-clock word

```text
t -> (floor(t/p), floor(t/q)) mod 7,  0 <= t < 7*p*q.
```

The exact scout `04-computation/lrc14_l7_odometer_row_slice_codex_s73.py`
checks `q<=300` and finds three reductions with no failures:

```text
rowdef_i(p,q) is the same for every row i;
rows are cyclic shifts by s=p*q^{-1} mod 7 when q is invertible mod 7;
defect_sum(p,q)=49*rowdef_0(p,q).
```

So the sharp HYP-2736 inequality is equivalent to

```text
rowdef_0(p,q)=sum_j |7*c_0j-pq| <= 12p.
```

This is the formal target.  It is a one-dimensional balance statement about a
generated odometer row word.  It should be much easier to make Lean-facing than
the continuous torus line or a two-dimensional discrepancy statement.

This also clarifies a broader repo lesson.  The miss-zeta/generated-word work
was not merely analogy: it warned us to keep generated languages until the
right quotient appears.  In the complicated residual-profile problem the
generated language is a 64-mask product cone; in L7 it is only two clocks.
Scalarizing first makes the problem look like a 49-cell discrepancy.  Keeping
the word reveals a row-slice balance lemma.

No new LRC closure is claimed here.  HYP-2730 already gives the closure-quality
tail.  HYP-2737 is a route toward a sharper, cleaner, machine-checkable
replacement for that tail constant and a better proof-obligation ledger for
THM-562.

**Pull update.**  HYP-2739 now proves the row-slice target by an exact
residue-only closed form, so this reflection should be read as the
formalization interface for that proof rather than as an open analytic route.
HYP-2741 also corrects the broader L7 status: the finite-f1 convergence rate
is fixed rigorously, but r>=3 pairwise lift, base-size domination, and the
upstream consec-max theorem remain honest obligations.
