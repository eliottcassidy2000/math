


## Tournament sequences: centered spectrum plus signed coronal

Cut switching is intrinsic: it reverses exactly the arcs crossing a signed
vertex cut.  For `C=2A-J` and `d~-d`, put

```text

N_d(z)=d^T adj(I-zC)d.                                      (24)
```

```text
det(I-2zA(T^d))=P-zN_d,
G_(T^d)(2z)=N_d/(P-zN_d).                                   (25)
```

Thus `P` plus the first `n` signed moments `d^TC^kd` compiles the complete
total-walk sequence and a degree-at-most-`n` recurrence.  The online form is

```text
s_0=u_0=n,
s_k=u_k+sum_(i<k)u_i s_(k-1-i),        s_k=2^k w_k.          (26)
```

```text

E det(I-2zA(T^d))=(1-nz)P+z^2P'.                            (27)
```

Individual sequences still need `N_d`.  The transitive triangle switched at

```text

```

This is the sharp hostile against spectrum-plus-cut-size.  The signed coronal
restores total walks, not Hamiltonian paths, path covers, SCC order or

## Four connections that survive typing

### 1. Minimum support measures the first compatibility failure

LRC tail rows, cyclic FC monomial supports and static relation edges acquire
exact arities.  Proper support respectively has a feasible common table, is
excluded by moment resultants, or has no observer-visible affine kernel
relation.  These are analogous stopping measures, not shared objects.

### 2. Invariant plus pointed observer is often the minimal compiler

```text
Jacobian:   trace/norm + tautological root t;
tournament: centered polynomial P + signed coronal N_d;
sequence:   scalar mass + primitive kernel direction/stabilizer;
factorial:  endpoint unit + provenance/face assignment.                    (29)
```

Forgetting the pointed coordinate produces a valid quotient, but not the
target.  Restoring more than the named sidecar is unnecessary for the stated
predicate and still insufficient for stronger predicates.

### 3. A unit identity must be typed by what it multiplies

The Jacobian pair `(U,W)` consists of units but multiplies localized gradient
relations that already vanish.  The factorial endpoint is group-like but its
centered current is not.  In both cases the algebraic positive signal survives
while the tempting physical interpretation fails at a preceding type gate.

### 4. Closed forms need a numerator sidecar and a head ledger

The tournament formula needs `N_d`, not only `P`.  The static graph compiler
needs the visible zero-mode head before denominator cancellation, not only its
resolvent denominator.  Efficient sequence work should therefore retain

```text
operator denominator + observer numerator + finite exceptional head.       (30)
```

This is more robust than fitting recurrences from a prefix and more compact
than recomputing the entire state space after a local operation.
