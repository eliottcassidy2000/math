# LRC14 Cocycle-Sheaf Exactness

The cleanest way to read the current stack is that every successful route has
been secretly asking the same question: what cocycle did this quotient forget?

HYP-2991 made that concrete for the Haar square.  The row and column margins
are the visible quotient; `zeta(T)=T00-T01-T10+T11` is the hidden coordinate.
Once that is named, the surrounding work starts to line up.  HYP-2986's
boundary cocircuits are endpoint-current cocycles.  HYP-2979's Ramanujan sums
are exact-period character cocycles.  HYP-2974/HYP-2981 Fejer certificates are
dual cochains pairing negatively with the danger multiplicity.  HYP-2984 and
HYP-2985 record smoothing boundary defects.  HYP-2171's carry data is a lift
cocycle over the residue quotient.  HYP-2027's pair tensions are literal
coboundaries, `w_ij=v_j-v_i`, with zero triangle coboundary.

The breakthrough shape is an exactness statement, not a new scalar.  Put
labelled packets in `C0`, emitted local proof debts in `C1`, and incompatible
or unnamed residuals in `C2`.  LRC14 should follow if primitive non-AP/GW rows
are exact at `C1`: every emitted cocycle is the boundary of a known certificate,
annihilated by a dual, restricted to a smaller family, or routed to the named
THM-572/F7 summand.

This reframes AP/GW as boundary cohomology rather than failures.  They are
closed equality atoms with zero open mass and taut endpoint currents.  It also
reframes F7: it cannot remain "whatever is left."  It has to be a cohomology
class with a declared base, differential, and preserved LRC predicate.

The S167 tournament reinforces the point.  The top path starts with global
certificate handoff debt, then the local Haar zeta, then exposure kernels.  But
the middle layer has a five-carrier SCC: Ramanujan exact-period, smoothing
boundary, tope/cocircuit, Fejer dual, and path-homology witness carriers trade
dominance depending on the retained coordinate.  That is the signature of a
multi-cochain object.  Linear ranking is the wrong shape there.

The next finite experiment should stop producing more unrelated ledgers and
instead assemble the first actual coboundary matrix over a bounded packet bank:
rows for labelled packet fibers, columns for emitted cocycles, and labels for
which certificate kills each coordinate.  If all positive rows become exact and
only AP/GW plus named THM-572/F7 classes remain, the current proof stack has a
single summit statement.
